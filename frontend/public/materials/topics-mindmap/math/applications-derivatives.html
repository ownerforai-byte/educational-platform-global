✅ Clarity notes — Applications of Derivatives

Mix-ups fixed:
  • Maxima vs Minima vs f″<0 top — test: f″>0 bottom (Second derivative sign?)
  • Increasing vs Decreasing vs f′>0 — test: f′<0 (Slope up or down?)
  • Tangent vs Normal vs slope m=f′ — test: slope −1/m (Perpendicular? normal)
Exam traps:
  • ⛔ f′=0 is suspect, NOT verdict — test it
  • ⛔ Rate problems: differentiate w.r.t. TIME, chain rule
  • ⛔ Approximation Δy≈f′Δx; % errors add
Memory hooks:
  • 💡 MAX-MINUS: f″ minus = max
  • 💡 TAN-NORM: normal is negative reciprocal
  • 💡 RATE-T: always via dt
