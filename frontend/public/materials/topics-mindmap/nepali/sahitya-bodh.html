✅ Clarity notes — साहित्य-बोध

Mix-ups fixed:
  • भाव vs विचार vs अनुभूति — test: तर्क/मत (महसुस?)
  • पात्र vs चरित्र vs व्यक्ति (को) — test: गुण (कस्तो) (को वा कस्तो?)
  • कथानक vs सन्देश vs घटना-क्रम — test: सिकाइ (के भयो vs के सिक्यो?)
Exam traps:
  • ⛔ शीर्षकसँग तर्क अनिवार्य (किन उपयुक्त?)
  • ⛔ प्रमाण-पङ्क्ति बिना भाव-अङ्क काटिन्छ
  • ⛔ समीक्षामा एक पक्षीय = कम नम्बर
Memory hooks:
  • 💡 BHAV-AANSU: भाव=अनुभूति
  • 💡 PATRA-KO: पात्र=को
  • 💡 SHIRSHAK-KINA: किन? तर्क

🔤 Word watch — same word, different meaning (topic + word level)

  • 🔤 पात्र — HERE: व्यक्ति | ELSEWHERE: भाँडो? फरक! (test: व्यक्ति वा भाँडो?)

📋 Formula sheet list — साहित्य-बोध (same as diagram, selectable)

  1. कविता बोध: भाव + लय + बिम्ब ● कवि-परिचय जोड्ने ● लय-ताल = ध्वनि-प्रवाह
  2. कथा बोध: कथानक-पात्र-परिवेश ● मूल सन्देश ● क-प-प = कथानक-पात्र-परिवेश
  3. पात्र-चरित्र: मुख्य/सहायक छुट्याउने ● गुण-दोष सूची ● को/कस्तो = व्यक्ति/गुण
  4. भाव/विचार: केन्द्रीय भाव एक वाक्य ● प्रमाण-पङ्क्ति ● केन्द्र-वाक्य = एक वाक्य भाव
  5. शीर्षक चयन: शीर्षक-संगति कारण ● वैकल्पिक शीर्षक + तर्क ● किन उपयुक्त? = तर्क अनिवार्य

🔨 Decoder list — साहित्य-बोध (same as diagram, selectable)

  1. कविता बोध = कवित-ाबोध → “कवित” + “ाबोध” (means: e.g. भाव + लय + बिम्ब)
  2. पात्र-चरित्र = पा-त्र-चरि-त्र → “पा” + tool + “चरि” + tool (means: e.g. मुख्य/सहायक छुट्याउने)
  3. शीर्षक चयन = शीर्-षकचय-न → “शीर्” + “षकचय” + “न” (means: e.g. शीर्षक-संगति कारण)
  4. बिम्ब-चित्र = बिम्-बचि-त्र → “बिम्” + “बचि” + tool (means: मानसिक तस्बिर)
  5. कवि-सन्दर्भ = कवि-सन्-दर्भ → “कवि” + together + “दर्भ” (means: जीवन-काल)
  6. सन्देश-वाक्य = सन्-देशव-ाक्य → together + “देशव” + “ाक्य” (means: एक वाक्य सिकाइ)
  7. क-प-प = कपप → “कपप” (means: कथानक-पात्र-परिवेश)
  8. प्रमाण-संवाद = प्र-माणस-ंवाद → forth + “माणस” + “ंवाद” (means: बोलीबाट पुष्टि)
  9. को/कस्तो = कोकस-्तो → “कोकस” + “्तो” (means: व्यक्ति/गुण)
  10. पङ्क्ति-प्रमाण = पङ्क-्ति-प्र-माण → “पङ्क” + “्ति” + forth + “माण” (means: लाइन उद्धरण)
  11. केन्द्र-वाक्य = केन्-द्रव-ाक्य → “केन्” + “द्रव” + “ाक्य” (means: एक वाक्य भाव)
  12. किन उपयुक्त? = किनउ-पयुक-्त → “किनउ” + “पयुक” + “्त” (means: तर्क अनिवार्य)
  13. वैकल्पिक शीर्षक = वैकल-्पिक-शीर्-षक → “वैकल” + “्पिक” + “शीर्” + “षक” (means: आफ्नै प्रस्ताव)
  14. प्रमाणसहित = प्र-माणस-हित → forth + “माणस” + “हित” (means: उदाहरण दिने)
  15. राम्रो+कमजोर = राम्-रोकम-जोर → “राम्” + “रोकम” + “जोर” (means: दुवै पक्ष)
