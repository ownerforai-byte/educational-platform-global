✅ Clarity notes — उखान-टुक्का र अर्थ

Mix-ups fixed:
  • उखान vs टुक्का vs पूरा भनाइ — test: वाक्यांश (एक्लै?)
  • शाब्दिक vs भावार्थ vs शब्दको अर्थ — test: लुकेको अर्थ (गहिरो?)
  • कान काट्नु vs आँखा छल्नु vs ठग्नु — test: छल्नु (काम?)
Exam traps:
  • ⛔ उखानको भावार्थ लेख्ने, शब्दार्थ होइन
  • ⛔ वाक्य-प्रयोग बिना नम्बर काटिन्छ
  • ⛔ सन्दर्भ नमिलेको प्रयोग = गलत
Memory hooks:
  • 💡 NACHNA-BAHANA: नाच्न-आँगन
  • 💡 KAAN-THAG: कान=ठगी
  • 💡 BHAV-LEKH: भाव लेख

🔨 Decoder list — उखान-टुक्का र अर्थ (same as diagram, selectable)

  1. उखान परिचय = उखान-परि-चय → “उखान” + around + “चय” (means: e.g. पुस्तैनी भनाइ (अर्थ गहिरो))
  2. लोकोक्ति प्रयोग = लोको-क्ति-प्र-योग → “लोको” + “क्ति” + forth + “योग” (means: e.g. सन्दर्भ मिलाएर)
  3. वाक्य-प्रयोग = वाक्-य-प्र-योग → “वाक्” + “य” + forth + “योग” (means: e.g. आफ्नै वाक्य बनाउने)
  4. पुस्तैनी ज्ञान = पुस्-तैनी-ज्ञ-ान → “पुस्” + “तैनी” + knower + “ान” (means: अनुभव-निचोड)
  5. उखान पूरा = उखान-पूरा → “उखान” + “पूरा” (means: पूर्ण भनाइ)
  6. कान काट्नु = कानक-ाट्न-ु → “कानक” + “ाट्न” + “ु” (means: ठग्नु)
  7. आँखा छल्नु = आँखा-छल्न-ु → “आँखा” + “छल्न” + “ु” (means: छल्नु)
  8. सन्दर्भ मिलाउने = सन्-दर्भ-मिला-उने → together + “दर्भ” + “मिला” + “उने” (means: ठाउँ हेरेर)
  9. गलत हास्यास्पद = गलतह-ास्य-ास्प-द → “गलतह” + “ास्य” + “ास्प” + “द” (means: नमिले हाँसो)
  10. ठग्नु/छल्नु = ठग्न-ुछल्-नु → “ठग्न” + “ुछल्” + “नु” (means: नजिक अर्थ)
  11. जोडी-कार्ड = जोडी-कार्-ड → “जोडी” + “कार्” + “ड” (means: तुलना चार्ट)
  12. आफ्नै वाक्य = आफ्न-ैवाक-्य → “आफ्न” + “ैवाक” + “्य” (means: मौलिक प्रयोग)
  13. ५ वाक्य नियम = ५वाक-्यनि-यम → “५वाक” + “्यनि” + “यम” (means: दैनिक अभ्यास)
  14. ५० कोर सूची = ५०को-रसूच-ी → “५०को” + “रसूच” + “ी” (means: परीक्षा-योग्य)
  15. +१० साप्ताहिक = १०सा-प्ता-हिक → “१०सा” + “प्ता” + “हिक” (means: थप्दै जाने)
