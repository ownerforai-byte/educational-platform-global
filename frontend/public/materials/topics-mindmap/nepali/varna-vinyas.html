वर्णविन्यास र ह्रस्व-दीर्घ

1. स्वर वर्ण

  • अ, आ, इ, ई, उ, ऊ, ऋ, ए, ऐ, ओ, औ
  • ह्रस्व: अ, इ, उ, ऋ · दीर्घ: बाँकी

2. व्यञ्जन वर्ण

  • क-ज्ञ सम्म ३३ वटा
  • वर्ग: क, च, ट, त, प + अन्तस्थ, ऊष्म

3. ह्रस्व-दीर्घ नियम

  • एउटै शब्दमा अर्थ फेर्ने जोडी: दिन/दीन
  • लेख्दा उच्चारण सुनेर छुट्याउने

4. संयुक्ताक्षर

  • क्ष, त्र, ज्ञ, श्र विशेष चिन्ह
  • हलन्तले जोडिने रूप (पङ्क्ति)

5. अनुस्वार-विसर्ग

  • अं (ङ/न/म ध्वनि) नाकबाट
  • अः विसर्ग — तत्सममा मात्र

6. शुद्धाशुद्धि

  • श/स/ष छुट्याउने अभ्यास
  • ज्ञ/ग्य, क्ष/छ भ्रम हटाउने

✅ Clarity notes — वर्णविन्यास र ह्रस्व-दीर्घ

Mix-ups fixed:
  • ह्रस्व vs दीर्घ vs छोटो स्वर — test: लामो स्वर (लम्बाइ?)
  • श vs स vs ष vs तालव्य/दन्त्य/मूर्धन्य — test: स्थान फरक (जिब्रो कहाँ?)
  • क्ष vs ज्ञ vs क्+ष — test: ज्+ञ (पहिलो ध्वनि?)
Exam traps:
  • ⛔ दिन/दीन, कुल/कूल जस्ता जोडी छुट्याउनैपर्छ
  • ⛔ अनुस्वारलाई न/म सँग साट्नु हुँदैन
  • ⛔ ज्ञ = ग्य लेख्नु गलत
Memory hooks:
  • 💡 HRASVA-CHHOTO: ह्रस्व छोटो
  • 💡 TRI-SHA: श-स-ष स्थान
  • 💡 GYA-JNA: ज्ञ छुट्टै

🔨 Decoder list — वर्णविन्यास र ह्रस्व-दीर्घ (same as diagram, selectable)

  1. स्वर वर्ण = स्व-रवर्-ण → self + “रवर्” + “ण” (means: e.g. अ, आ, इ, ई, उ, ऊ, ऋ, ए, ऐ, ओ, औ)
  2. ह्रस्व-दीर्घ नियम = ह्र-स्व-दीर्-घनिय-म → “ह्र” + self + “दीर्” + “घनिय” + “म” (means: e.g. एउटै शब्दमा अर्थ फेर्ने जोडी: दिन/दीन)
  3. अनुस्वार-विसर्ग = अनु-स्व-ारवि-सर्ग → after + self + “ारवि” + creation/flow (means: e.g. अं (ङ/न/म ध्वनि) नाकबाट)
  4. स्वर ११ = स्व-र११ → self + “र११” (means: अ–औ गणना)
  5. ह्रस्व ३+ = ह्र-स्व३ → “ह्र” + “स्व३” (means: अ इ उ ऋ छोटा)
  6. अन्तस्थ यरलव = अन्-तस्थ-यरलव → not + “तस्थ” + “यरलव” (means: य र ल व)
  7. क-वर्ग = कवर्-ग → “कवर्” + “ग” (means: क ख ग घ ङ)
  8. दिन/दीन = दिनद-ीन → “दिनद” + “ीन” (means: day बनाम poor)
  9. कुल/कूल = कुलक-ूल → “कुलक” + “ूल” (means: वंश बनाम किनार)
  10. त्र त्+र = त्र-त्र → tool + tool (means: त+र जोड)
  11. ज्ञ ज्+ञ = ज्ञ-ज्ञ → knower + knower (means: ज्ञानको ज्ञ)
  12. अः विसर्ग = अःवि-सर्ग → “अःवि” + creation/flow (means: तत्सम मात्र)
  13. अं नाके = अंना-के → “अंना” + “के” (means: ङ/न/म ध्वनि)
  14. ज्ञ/ग्य भ्रम = ज्ञ-ग्यभ-्रम → knower + “ग्यभ” + “्रम” (means: ज्ञ छुट्टै)
  15. श/स/ष स्थान = शसष-स्था-न → “शसष” + “स्था” + “न” (means: तालु/दन्त/मूर्धा)
