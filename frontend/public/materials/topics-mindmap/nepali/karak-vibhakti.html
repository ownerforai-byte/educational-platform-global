✅ Clarity notes — कारक र विभक्ति

Mix-ups fixed:
  • ले vs लाई vs कर्ता (गर्ने) — test: कर्म (पर्ने) (भूमिका?)
  • बाट vs द्वारा vs छुट्टिने/स्थान — test: साधन/एजेन्ट (अर्थ?)
  • को vs मा vs सम्बन्ध — test: स्थान (जोड?)
Exam traps:
  • ⛔ रामले रामलाई — ले/लाई एउटै वाक्यमा फरक
  • ⛔ करणमा ले, कर्तामा पनि ले — क्रिया हेरेर छुट्याउने
  • ⛔ सम्प्रदानमा दिने-भाव हुनैपर्छ
Memory hooks:
  • 💡 LE-GARNE, LAI-PARNE
  • 💡 BATA-CHHUTNE: बाट छुट्टिने
  • 💡 MA-THAU: मा ठाउँ

🔨 Decoder list — कारक र विभक्ति (same as diagram, selectable)

  1. कर्ता-प्रथमा = कर्त-ा-प्र-थमा → “कर्त” + “ा” + forth + “थमा” (means: e.g. काम गर्ने (रामले — ले!))
  2. करण-तृतीया = करणत-ृतीय-ा → “करणत” + “ृतीय” + “ा” (means: e.g. साधन (कलमले, हातले))
  3. अपादान-पञ्चमी = अपाद-ानपञ-्चमी → “अपाद” + “ानपञ” + “्चमी” (means: e.g. छुट्टिने (घरबाट, डरले))
  4. प्रथमा शून्य = प्र-थमाश-ून्य → forth + “थमाश” + “ून्य” (means: राम (कर्ता))
  5. रामले कर्ता = रामल-ेकर्-ता → “रामल” + “ेकर्” + “ता” (means: गर्ने + ले)
  6. प्रति/निम्ति = प्रति-निम्-ति → towards + “निम्” + “ति” (means: लक्ष्य चिन्ह)
  7. के/कसलाई test = केकस-लाई-test → “केकस” + “लाई” + witness (means: प्रश्नले चिन्छ)
  8. कलमले साधन = कलमल-ेसाध-न → “कलमल” + “ेसाध” + “न” (means: करण + ले)
  9. द्वारा एजेन्ट = द्वा-राएज-ेन्ट → “द्वा” + “राएज” + “ेन्ट” (means: मार्फत)
  10. सम्प्रदान सर्त = सम्-प्र-दानस-र्त → together + forth + “दानस” + “र्त” (means: दान हुनैपर्छ)
  11. गरिबलाई दान = गरिब-लाईद-ान → “गरिब” + “लाईद” + “ान” (means: दिने-भाव)
  12. घरबाट छुट्टिने = घरबा-टछुट-्टिन-े → “घरबा” + “टछुट” + “्टिन” + “े” (means: स्थान-विच्छेद)
  13. डरले/लाजले = डरले-लाजल-े → “डरले” + “लाजल” + “े” (means: भाव-अपादान)
  14. रामको सम्बन्ध = रामक-ो-सम्-बन्ध → “रामक” + “ो” + together + “बन्ध” (means: को/की/का)
  15. घरमा स्थान = घरमा-स्था-न → “घरमा” + “स्था” + “न” (means: मा/माथि)
