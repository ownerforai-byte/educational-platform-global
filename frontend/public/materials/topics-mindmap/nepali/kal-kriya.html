1. वर्तमान काल

  • छ/छन् (जान्छ)
  • बानी + सत्य (सूर्य उदाउँछ)

2. भूत काल

  • यो/ए (गयो, खाए)
  • सामान्य/अपूर्ण/पूर्ण भेद

3. भविष्यत् काल

  • ने/नेछ (जानेछ)

4. आज्ञार्थ/विध्यर्थ

  • जा! गर! (आज्ञा)
  • गरियोस् (विधि/प्रार्थना)

5. सकर्मक-अकर्मक

  • कर्म चाहिने (खानु)
  • नचाहिने (जानु, सुत्नु)

6. प्रेरणार्थक

  • गराउनु (अरूबाट)
  • पढाउनु, लेखाउनु

✅ Clarity notes — काल र क्रिया

Mix-ups fixed:
  • वर्तमान vs भविष्य vs छ/छन् — test: ने/नेछ (चिन्ह?)
  • सकर्मक vs अकर्मक vs कर्म चाहिन्छ — test: चाहिँदैन (के/कसलाई?)
  • आज्ञा vs विधि vs आदेश (!) — test: प्रार्थना (गरियोस्) (स्वर?)
Exam traps:
  • ⛔ खानु सकर्मक (के खाने?), जानु अकर्मक — 'के' प्रश्नले छुट्याउने
  • ⛔ भूतमा यो/ए; भविष्यमा ने — अन्त्य हेर्ने
  • ⛔ प्रेरणार्थकमा -ाउ (गराउनु) अनिवार्य
Memory hooks:
  • 💡 CHA-CHHAN: वर्तमान
  • 💡 YO-E: भूत
  • 💡 NE-BHAVISHYA: भविष्य

  3. भविष्यत् काल: ने/नेछ (जानेछ) ● सङ्कल्प/अनुमान ● जानेछ भविष्य = ने/नेछ

🔨 Decoder list — काल र क्रिया (same as diagram, selectable)

  1. वर्तमान काल = वर्त-मानक-ाल → “वर्त” + “मानक” + “ाल” (means: e.g. छ/छन् (जान्छ))
  2. भविष्यत् काल = भविष-्यत्-काल → “भविष” + “्यत्” + “काल” (means: e.g. ने/नेछ (जानेछ))
  3. सकर्मक-अकर्मक = सकर्-मकअक-र्मक → “सकर्” + “मकअक” + “र्मक” (means: e.g. कर्म चाहिने (खानु))
  4. जान्छ वर्तमान = जान्-छवर्-तमान → “जान्” + “छवर्” + “तमान” (means: छ/छन् चिन्ह)
  5. बानी सत्य = बानी-सत्य → “बानी” + “सत्य” (means: सूर्य उदाउँछ)
  6. गयो भूत = गयोभ-ूत → “गयोभ” + “ूत” (means: यो/ए अन्त्य)
  7. खाए पूर्ण = खाएप-ूर्ण → “खाएप” + “ूर्ण” (means: सकियो)
  8. अनुमान = अनु-मान → after + “मान” (means: होला सायद)
  9. जानेछ भविष्य = जाने-छभवि-ष्य → “जाने” + “छभवि” + “ष्य” (means: ने/नेछ)
  10. गरियोस् विधि = गरिय-ो-स्व-िधि → “गरिय” + “ो” + self + “िधि” (means: विनम्र प्रार्थना)
  11. जा! आदेश = जाआद-ेश → “जाआद” + “ेश” (means: आज्ञा छोटो)
  12. के-test = के-test → “के” + witness (means: कर्म छ?)
  13. खानु सकर्मक = खानु-सकर्-मक → “खानु” + “सकर्” + “मक” (means: के खाने? उत्तर)
  14. गराउनु प्रेरणा = गराउ-नु-प्र-ेरणा → “गराउ” + “नु” + forth + “ेरणा” (means: अरूबाट -ाउ)
  15. दोहोरो प्रेरणा = दोहो-रो-प्र-ेरणा → “दोहो” + “रो” + forth + “ेरणा” (means: गरवाउनु)
