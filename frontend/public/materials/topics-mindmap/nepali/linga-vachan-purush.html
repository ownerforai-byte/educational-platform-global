✅ Clarity notes — लिङ्ग, वचन र पुरुष

Mix-ups fixed:
  • तिमी vs तपाईं vs सामान्य — test: आदर (कसलाई?)
  • पुलिङ्ग vs नपुंसक vs लिङ्ग छुट्टिन्छ — test: तटस्थ (लिङ्ग?)

  • ⛔ सर्वनाम-क्रिया समन्वय अनिवार्य

🔨 Decoder list — लिङ्ग, वचन र पुरुष (same as diagram, selectable)

  1. पुलिङ्ग-स्त्रीलिङ्ग = पुलि-ङ्गस-्-त्र-ीलिङ-्ग → “पुलि” + “ङ्गस” + “्” + tool + “ीलिङ” + “्ग” (means: e.g. पुलिङ्ग: राम, घर)
  2. एकवचन-बहुवचन = एक-वचन-बहु-वचन → “एक” + speech + “बहु” + speech (means: e.g. एक → हरू/हरू थपिने)
  3. मध्यम पुरुष = मध्य-मपुर-ुष → “मध्य” + “मपुर” + “ुष” (means: e.g. तँ/तिमी/तपाईं)
  4. राम पुलिङ्ग = रामप-ुलिङ-्ग → “रामप” + “ुलिङ” + “्ग” (means: पुलिङ्ग उदाहरण)
  5. सीता स्त्री = सीता-स्-त्री → “सीता” + “स्” + “त्री” (means: स्त्री उदाहरण)
  6. फल नपुंसक = फलनप-ुंसक → “फलनप” + “ुंसक” (means: तटस्थ वस्तु)
  7. जल नपुंसक = जलनप-ुंसक → “जलनप” + “ुंसक” (means: तरल तटस्थ)
  8. म→हामी = महा-मी → great + “मी” (means: सर्वनाम फेरिन्छ)
  9. हरू थपिने = हरूथ-पिने → “हरूथ” + “पिने” (means: बहुवचन चिन्ह)
  10. ऊ/उनी = ऊउनी → “ऊउनी” (means: अन्य व्यक्ति)
  11. क्रिया तेस्रो = क्रि-याते-स्रो → “क्रि” + “याते” + “स्रो” (means: गर्छ/गर्छन्)
  12. तँ/तिमी/तपाईं = तँति-मीतप-ाईं → “तँति” + “मीतप” + “ाईं” (means: ३ स्तर आदर)
  13. साथी=तिमी = साथी-तिमी → “साथी” + “तिमी” (means: सामान्य)
  14. म बोल्ने = मबोल-्ने → “मबोल” + “्ने” (means: आफैं)
  15. हामी समूह = हामी-समूह → “हामी” + “समूह” (means: म+अरू)
