उपसर्ग र प्रत्यय

1. उपसर्ग परिचय

  • धातु अगाडि (प्र, अनु, सम्)
  • २२ वटा संस्कृत उपसर्ग

2. तद्धित प्रत्यय

  • नाममा लाग्ने (त्व, ता, इक)
  • मानव→मानवता

3. कृदन्त प्रत्यय

  • धातुमा लाग्ने (तव्य, अनीय)
  • पठ्+तव्य=पठितव्य

4. स्त्री-प्रत्यय

  • आ, ई, नी (छात्र→छात्रा)
  • पुलिङ्ग→स्त्रीलिङ्ग

5. अर्थ-परिवर्तन

  • उपसर्गले उल्टो अर्थ (आगत→विगत)
  • प्रत्ययले शब्द-भेद फेर्छ

6. प्रयोग अभ्यास

  • एउटै धातु + फरक उपसर्ग
  • वाक्यमा प्रयोग गरेर पक्का

✅ Clarity notes — उपसर्ग र प्रत्यय

Mix-ups fixed:
  • उपसर्ग vs प्रत्यय vs अगाडि लाग्छ — test: पछाडि लाग्छ (कता?)
  • तद्धित vs कृदन्त vs नाममा — test: धातुमा (मूल के?)
  • आगत vs विगत vs आ = आएको — test: वि = गएको (दिशा?)
Exam traps:
  • ⛔ प्र+हार=प्रहार (ह आक्रान्त) — सन्दर्भ हेर्ने
  • ⛔ तव्य/अनीय = 'योग्य' अर्थ (पठनीय=पढ्नयोग्य)
  • ⛔ स्त्री-प्रत्ययमा ह्रस्व-दीर्घ नसार्ने
Memory hooks:
  • 💡 AGADI-UPA: उपसर्ग अगाडि
  • 💡 PACHHADI-PRA: प्रत्यय पछाडि
  • 💡 TA-TVA: ता/त्व भाववाचक

📋 Formula sheet list — उपसर्ग र प्रत्यय (same as diagram, selectable)

  1. उपसर्ग परिचय: धातु अगाडि (प्र, अनु, सम्) ● २२ वटा संस्कृत उपसर्ग ● प्र-आगाडि = प्रचार, प्रगति
  2. तद्धित प्रत्यय: नाममा लाग्ने (त्व, ता, इक) ● मानव→मानवता ● मानवता = मानव+ता
  3. कृदन्त प्रत्यय: धातुमा लाग्ने (तव्य, अनीय) ● पठ्+तव्य=पठितव्य ● पठ्+तव्य = पठितव्य (योग्य)
  4. स्त्री-प्रत्यय: आ, ई, नी (छात्र→छात्रा) ● पुलिङ्ग→स्त्रीलिङ्ग ● छात्रा = छात्र+आ
  5. अर्थ-परिवर्तन: उपसर्गले उल्टो अर्थ (आगत→विगत) ● प्रत्ययले शब्द-भेद फेर्छ ● आगत/विगत = आएको/गएको
  6. प्रयोग अभ्यास: एउटै धातु + फरक उपसर्ग ● वाक्यमा प्रयोग गरेर पक्का ● एउटै धातु = फरक उपसर्ग जोड

🔨 Decoder list — उपसर्ग र प्रत्यय (same as diagram, selectable)

  1. उपसर्ग परिचय = उप-सर्ग-परि-चय → “उप” + creation/flow + around + “चय” (means: e.g. धातु अगाडि (प्र, अनु, सम्))
  2. कृदन्त प्रत्यय = कृदन-्त-प्र-त्यय → “कृदन” + “्त” + forth + “त्यय” (means: e.g. धातुमा लाग्ने (तव्य, अनीय))
  3. अर्थ-परिवर्तन = अर्थ-परि-वर्त-न → “अर्थ” + around + “वर्त” + “न” (means: e.g. उपसर्गले उल्टो अर्थ (आगत→विगत))
  4. धातु-मूल = धातु-मूल → root + “मूल” (means: क्रिया-जरो)
  5. प्र-आगाडि = प्र-आगाड-ि → forth + “आगाड” + “ि” (means: प्रचार, प्रगति)
  6. ता/त्व भाव = ता-त्व-भाव → “ता” + -ness + “भाव” (means: भाववाचक)
  7. इक-सम्बन्धी = इक-सम्-बन्ध-ी → “इक” + together + “बन्ध” + “ी” (means: मासिक, वार्षिक)
  8. पठ्+तव्य = पठ्-तव्य → read + fit-to (means: पठितव्य (योग्य))
  9. तव्य/अनीय = तव्य-अनीय → fit-to + fit-to (means: योग्य अर्थ)
  10. छात्रा = छा-त्रा → “छा” + “त्रा” (means: छात्र+आ)
  11. ई/नी नियम = ईनीन-ियम → “ईनीन” + “ियम” (means: नदी, युवती)
  12. उपसर्ग-उल्टो = उप-सर्ग-उल्ट-ो → “उप” + creation/flow + “उल्ट” + “ो” (means: अर्थ फेर्छ)
  13. आगत/विगत = आगतव-िगत → “आगतव” + “िगत” (means: आएको/गएको)
  14. एउटै धातु = एउटै-धातु → “एउटै” + root (means: फरक उपसर्ग जोड)
  15. साप्ताहिक test = साप्-ताहि-क-test → “साप्” + “ताहि” + “क” + witness (means: दोहोर्याउने)
