Active & Passive Voice

1. Voice Rules

  • Active: doer first (Ram ate)
  • Passive: be + V3 (was eaten)

2. Tense-wise Passives

  • is/are + V3 (present)
  • was/were + V3; has been + V3

3. Modals in Passive

  • can/must/should + be + V3
  • Keep modal, add be

4. Imperatives & Questions

  • Let + be + V3 (shut → let be shut)
  • Wh- + be-verb first (who→by whom)

5. Agent with 'by'

  • Keep by + doer when needed
  • Drop by when doer is unknown/obvious

6. Common Errors

  • No passive for intransitives (go, die)
  • Double be (is was done ✗)

✅ Clarity notes — Active & Passive Voice

Mix-ups fixed:
  • Active vs Passive vs doer first — test: action first (Who matters?)
  • by-kept vs by-dropped vs doer important/new — test: unknown or obvious (Say who?)
  • Transitive vs Intransitive vs has object → passive OK — test: no object → no passive (Object?)
Exam traps:
  • ⛔ Intransitive verbs (go, die, sleep) have NO passive
  • ⛔ Double 'be' (is was done) is always wrong
  • ⛔ Tense of be must match original tense
Memory hooks:
  • 💡 BE-V3: be + V3 always
  • 💡 BYE-BYE: drop by when obvious
  • 💡 TRANS-OK: object means passive possible
