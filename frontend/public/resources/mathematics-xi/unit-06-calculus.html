Unit 6 — Calculus

Mathematics XI (Mat. 007)  •  NEB Grade 11  •  48 teaching hours  •  Exercise solutions + conceptual bank

The largest unit and the one that decides most grades. It runs in one direction (limit → continuity → derivative → applications) and then reverses (anti-derivative → definite integral → area). Each exercise below is written in the exact form NEB expects: state the form, remove the indeterminacy, then quote the answer.

Where the 48 hours are examined.

  • 2 marks — a standard limit, a derivative of a simple function, or a continuity verdict.
  • 4 marks — first-principles derivative, product/quotient/chain combination, monotonicity interval, one integration.
  • 5–6 marks — maxima/minima with the second-derivative test and a conclusion sentence, integration by parts, or area between two curves.

The three most valuable habits: name the indeterminate form (0/0, ∞/∞, 1^∞) before simplifying; write +C for every indefinite integral; and finish optimisation questions with a sentence that answers the question asked.

Exercise 6.1 — Limits and indeterminate forms

Q1. Evaluate limx→2 (x² − 4)/(x − 2).

At x = 2 the expression is 0/0, an indeterminate form. Factor and cancel (valid for x ≠ 2):

(x² − 4)/(x − 2) = (x−2)(x+2)/(x−2) = x + 2 → 4

lim = 4

Q2. Evaluate limx→0 sin 3x / x and limx→0 sin 5x / sin 2x.

Use the standard limit limθ→0 sinθ/θ = 1.

sin3x/x = 3·(sin3x)/(3x) → 3(1) = 3 sin5x/sin2x = (sin5x/5x)(2x/sin2x)(5/2) → 1·1·(5/2) = 5/2

3 and 5/2

Q3. Evaluate limx→0 (1 − cos 2x)/x².

1 − cos2x = 2sin²x ⇒ (1 − cos2x)/x² = 2(sinx/x)² → 2(1)² = 2

lim = 2

Q4. Evaluate limx→∞ (3x² + 2x + 1)/(5x² − x).

Divide numerator and denominator by the highest power x²:

(3 + 2/x + 1/x²)/(5 − 1/x) → 3/5 as x → ∞

lim = 3/5

Q5. Evaluate limx→0 (√(1+x) − 1)/x.

Rationalise the numerator by multiplying by the conjugate:

[(√(1+x) − 1)(√(1+x) + 1)] / [x(√(1+x) + 1)] = (1 + x − 1)/[x(√(1+x)+1)] = x/[x(√(1+x)+1)] = 1/(√(1+x)+1) → 1/2

lim = 1/2

Q6. Evaluate limx→1 (x³ − 1)/(x − 1).

x³ − 1 = (x−1)(x² + x + 1) ⇒ limit = x² + x + 1 at x = 1 = 3

lim = 3

Q7. Evaluate limx→0 (ex − 1)/x and limx→0 log(1+x)/x.

Both are standard limits quoted in the syllabus:

lim (eˣ − 1)/x = 1 lim log(1+x)/x = 1

Both limits equal 1

Q8. Evaluate limx→3 (x² − 9)/(x² − 5x + 6).

0/0 form. Factor both quadratics:

(x−3)(x+3) / [(x−3)(x−2)] = (x+3)/(x−2) → 6/1 = 6

lim = 6

Q9. Evaluate limx→∞ (1 + 1/x)x.

This is the standard 1∞ form whose value is the base of natural logarithms.

lim = e  (and lim (1 + a/x)x = ea)

Q10. Evaluate limx→0 (tan x)/x and limx→0 (1 − cos x)/x.

tanx/x = (sinx/x)(1/cosx) → 1·1 = 1 (1 − cosx)/x = [2sin²(x/2)]/x = sin(x/2)·[sin(x/2)/(x/2)] → 0·1 = 0

1 and 0

Q11. Evaluate limx→0 (√(3+x) − √3)/x.

Multiply by the conjugate: (3 + x − 3) / [x(√(3+x) + √3)] = 1/(√(3+x) + √3) → 1/(2√3)

lim = 1/(2√3)

Q12. Evaluate limx→2 (x³ − 8)/(x² − 4).

x³ − 8 = (x−2)(x² + 2x + 4); x² − 4 = (x−2)(x+2) ⇒ (x² + 2x + 4)/(x + 2) → (4 + 4 + 4)/4 = 3

lim = 3

Exercise 6.2 — Continuity and discontinuity

Q1. Test f(x) = (x² − 1)/(x − 1) for x ≠ 1, f(1) = 2, at x = 1.

Continuity at a needs three things: f(a) exists, the limit exists, and they are equal.

f(1) = 2 lim(x→1) (x²−1)/(x−1) = lim (x+1) = 2

The limit equals the value, so f is continuous at x = 1.

Q2. Show that f(x) = |x| is continuous at x = 0.

Left limit: lim(x→0⁻) |x| = lim(−x) = 0 Right limit: lim(x→0⁺) |x| = lim(x) = 0 f(0) = 0

Left limit = right limit = f(0).

f is continuous at x = 0 (but not differentiable there, because the slopes differ).

Q3. The function f(x) = (x² − 4)/(x − 2) is undefined at x = 2. What kind of discontinuity is it and how is it removed?

lim(x→2) (x²−4)/(x−2) = lim(x+2) = 4 (finite)

The limit exists but f(2) is not defined, so the discontinuity is removable. Define f(2) = 4 to make the function continuous.

Removable discontinuity; repair by setting f(2) = 4.

Q4. Discuss the continuity of f(x) = 1/x at x = 0.

f(0) is undefined and |f(x)| → ∞ as x → 0 from either side, so there is no finite limit.

Infinite discontinuity at x = 0.

Q5. Find k so that f(x) = (x² − 9)/(x − 3) for x ≠ 3 and f(3) = k is continuous at x = 3.

lim(x→3) (x²−9)/(x−3) = lim(x+3) = 6 For continuity, k = 6

k = 6

Q6. Find k so that f(x) = sin x/x for x ≠ 0, f(0) = k is continuous at 0.

lim(x→0) sinx/x = 1 ⇒ k = 1

k = 1

Q7. Is the greatest-integer function f(x) = [x] continuous at x = 1?

lim(x→1⁻) [x] = 0, lim(x→1⁺) [x] = 1, [1] = 1

The one-sided limits differ, so the limit does not exist.

Discontinuous at x = 1 — a jump discontinuity of size 1.

Q8. Show that a function that is differentiable at a point must be continuous there.

Differentiability means f′(a) = limh→0 [f(a+h) − f(a)]/h exists. Then

lim(h→0) [f(a+h) − f(a)] = lim h · [f(a+h) − f(a)]/h = 0 · f′(a) = 0

So f(a+h) → f(a): differentiability implies continuity. The converse fails (|x| at 0).

Q9. For which x is f(x) = 1/(x² − 4) discontinuous?

The denominator vanishes at x² = 4, i.e. x = ±2, where the function is undefined and blows up.

Discontinuous at x = 2 and x = −2 (infinite discontinuity); continuous on ℝ − {−2, 2}.

Q10. Sketch the graph of a function with a removable discontinuity at x = 1 and describe it.

Example: y = (x² − 1)/(x − 1) is the line y = x + 1 with a hole at (1, 2). The graph is a straight line missing a single point.

A straight line with one open circle — the missing point is the removable discontinuity.

Exercise 6.3 — Derivatives from first principles

The one definition to write every time. f′(x) = limh→0 [f(x+h) − f(x)]/h. For a first-principles question the marks are for expanding f(x+h), cancelling the h, and only then letting h → 0 — never for quoting the answer.

Q1. Find the derivative of f(x) = x² from first principles.

f′(x) = lim(h→0) [(x+h)² − x²]/h = lim [x² + 2xh + h² − x²]/h = lim [2xh + h²]/h = lim (2x + h) = 2x

f′(x) = 2x

Q2. Find the derivative of f(x) = √x from first principles.

f′(x) = lim(h→0) [√(x+h) − √x]/h Multiply by the conjugate: = lim [ (x+h) − x ] / [ h(√(x+h) + √x) ] = lim h / [ h(√(x+h) + √x) ] = 1/(2√x)

f′(x) = 1/(2√x), x > 0

Q3. Differentiate f(x) = 1/x from first principles.

f′(x) = lim(h→0) [1/(x+h) − 1/x]/h = lim [ (x − (x+h)) / (x(x+h)) ] / h = lim [ −h / (x(x+h)) ] / h = lim −1/(x(x+h)) = −1/x²

f′(x) = −1/x², x ≠ 0

Q4. Differentiate sin x from first principles.

f′(x) = lim(h→0) [sin(x+h) − sinx]/h Using sinA − sinB = 2cos((A+B)/2)sin((A−B)/2): = lim [2cos(x + h/2) sin(h/2)]/h = lim cos(x + h/2) · [sin(h/2)/(h/2)] = cosx · 1 = cosx

d/dx (sinx) = cosx

Q5. Differentiate x³ from first principles.

[(x+h)³ − x³]/h = [x³ + 3x²h + 3xh² + h³ − x³]/h = 3x² + 3xh + h² → 3x²

d/dx (x³) = 3x²

Q6. Differentiate ex from first principles.

f′(x) = lim(h→0) [e^(x+h) − eˣ]/h = eˣ lim(h→0) (e^h − 1)/h = eˣ · 1 = eˣ

d/dx (eˣ) = eˣ — the exponential is its own derivative

Exercise 6.4 — Rules of differentiation

Q1. Differentiate y = x³ + 2x² − 5x + 7.

dy/dx = 3x² + 4x − 5 (constant differentiates to 0)

dy/dx = 3x² + 4x − 5

Q2. Differentiate y = x² sin x (product rule).

(uv)′ = u′v + uv′ with u = x², v = sinx dy/dx = 2x sinx + x² cosx

dy/dx = 2x sinx + x² cosx

Q3. Differentiate y = (x + 1)/(x − 1) (quotient rule).

dy/dx = [ (x−1)(1) − (x+1)(1) ] / (x−1)² = (x − 1 − x − 1)/(x−1)² = −2/(x−1)²

dy/dx = −2/(x−1)², x ≠ 1

Q4. Differentiate y = (3x + 1)⁵ and y = sin(x³) (chain rule).

y = (3x+1)⁵: dy/dx = 5(3x+1)⁴ · 3 = 15(3x+1)⁴ y = sin(x³): dy/dx = cos(x³) · 3x² = 3x² cos(x³)

15(3x+1)⁴ and 3x²cos(x³)

Q5. Differentiate y = e2x and y = ln(x² + 1).

d/dx e^(2x) = e^(2x) · 2 = 2e^(2x) d/dx ln(x²+1) = (2x)/(x²+1)

2e2x and 2x/(x²+1)

Q6. Differentiate y = tan⁻¹(x²).

d/dx tan⁻¹u = u′/(1+u²) with u = x², u′ = 2x dy/dx = 2x/(1 + x⁴)

dy/dx = 2x/(1 + x⁴)

Q7. Differentiate y = ax and y = ln(sin x).

d/dx aˣ = aˣ ln a d/dx ln(sinx) = (cosx)/(sinx) = cotx

ax ln a and cot x

Q8. Differentiate y = sin²x.

Chain rule with u = sinx:

dy/dx = 2 sinx cosx = sin2x

dy/dx = sin 2x

Q9. Differentiate y = x ex and y = √(x² + 1).

d/dx (xeˣ) = eˣ + xeˣ = eˣ(1 + x) d/dx √(x²+1) = (1/2)(x²+1)^(−1/2) · 2x = x/√(x²+1)

ex(1+x) and x/√(x²+1)

Q10. Differentiate y = x²/√(x+1) using the quotient and chain rules.

u = x², u′ = 2x; v = (x+1)^(1/2), v′ = 1/(2√(x+1)) dy/dx = [2x√(x+1) − x²/(2√(x+1))] / (x+1) = [4x(x+1) − x²] / [2(x+1)^(3/2)] = x(3x + 4) / [2(x+1)^(3/2)]

dy/dx = x(3x+4)/[2(x+1)3/2]

Exercise 6.5 — Implicit, parametric, logarithmic and higher-order

Q1. Find dy/dx for x² + y² = 25.

Differentiate both sides with respect to x, treating y as a function of x: 2x + 2y(dy/dx) = 0 ⇒ dy/dx = −x/y

dy/dx = −x/y

Q2. Find dy/dx for x³ + y³ = 3xy.

3x² + 3y²(dy/dx) = 3y + 3x(dy/dx) 3x² − 3y = 3x(dy/dx) − 3y²(dy/dx) dy/dx = (x² − y)/(x − y²) = (y − x²)/(y² − x)

dy/dx = (y − x²)/(y² − x)

Q3. Find dy/dx for the parametric curve x = at², y = 2at.

dx/dt = 2at, dy/dt = 2a dy/dx = (dy/dt)/(dx/dt) = 2a/(2at) = 1/t

dy/dx = 1/t

Q4. Find dy/dx for x = a cosθ, y = b sinθ.

dx/dθ = −a sinθ, dy/dθ = b cosθ dy/dx = (b cosθ)/(−a sinθ) = −(b/a)cotθ

dy/dx = −(b/a)cotθ

Q5. Find dy/dx for y = xx using logarithmic differentiation.

ln y = x ln x Differentiate implicitly: (1/y)(dy/dx) = ln x + x(1/x) = ln x + 1 ⇒ dy/dx = y(1 + ln x) = xˣ(1 + ln x)

dy/dx = xx(1 + ln x)

Q6. Find the second derivative of y = x⁴ − 2x³.

y′ = 4x³ − 6x² y″ = 12x² − 12x = 12x(x − 1)

y″ = 12x(x−1)

Q7. Find y″ for y = e2x and y = sin x.

y = e^(2x): y′ = 2e^(2x), y″ = 4e^(2x) y = sinx: y′ = cosx, y″ = −sinx

4e2x and −sin x

Q8. If y = x ln x, show that y″ = 1/x.

y′ = ln x + x(1/x) = ln x + 1 y″ = 1/x

y″ = 1/x  (proved)

Q9. Find the third derivative of y = x⁴ − 2x³.

y′ = 4x³ − 6x², y″ = 12x² − 12x, y‴ = 24x − 12

y‴ = 24x − 12

Q10. If x = 2t², y = t³, find dy/dx and d²y/dx².

dx/dt = 4t, dy/dt = 3t² ⇒ dy/dx = 3t²/(4t) = 3t/4 d²y/dx² = (d/dt)(3t/4) ÷ (dx/dt) = (3/4)/(4t) = 3/(16t)

dy/dx = 3t/4, d²y/dx² = 3/(16t)

Exercise 6.6 — Monotonicity, extrema, tangents and concavity

Q1. Find the intervals where f(x) = x³ − 3x + 2 is increasing or decreasing, and its extreme values.

f′(x) = 3x² − 3 = 3(x−1)(x+1) = 0 ⇒ x = ±1 Sign of f′: + on (−∞,−1), − on (−1,1), + on (1,∞) f(−1) = −1 + 3 + 2 = 4, f(1) = 1 − 3 + 2 = 0

Increasing on (−∞,−1) ∪ (1,∞), decreasing on (−1,1); local maximum 4 at x = −1, local minimum 0 at x = 1.

Q2. Find the local extreme values of f(x) = 2x³ − 9x² + 12x.

f′(x) = 6x² − 18x + 12 = 6(x−1)(x−2) = 0 ⇒ x = 1, 2 f(1) = 2 − 9 + 12 = 5, f(2) = 16 − 36 + 24 = 4

Second derivative test: f″ = 12x − 18; f″(1) = −6 < 0 (max), f″(2) = 6 > 0 (min).

Local maximum 5 at x = 1; local minimum 4 at x = 2.

Q3. Find the tangent to y = x² at (2, 4).

dy/dx = 2x ⇒ slope at x = 2 is 4 y − 4 = 4(x − 2) ⇒ y = 4x − 4

y = 4x − 4

Q4. Find the normal to y = x² at (1, 1).

Tangent slope = 2(1) = 2 ⇒ normal slope = −1/2 y − 1 = −(1/2)(x − 1) ⇒ 2y − 2 = −x + 1

x + 2y = 3

Q5. Discuss the concavity of y = x³ and find its point of inflection.

y′ = 3x², y″ = 6x y″ > 0 for x > 0 (concave up), y″ < 0 for x < 0 (concave down) y″ = 0 at x = 0, where the concavity changes sign

Concave down on (−∞,0), concave up on (0,∞); inflection at (0,0).

Q6. Show that f(x) = x + 1/x has a minimum value 2 for x > 0.

f′(x) = 1 − 1/x² = 0 ⇒ x² = 1 ⇒ x = 1 (positive branch) f″(x) = 2/x³ > 0 for x > 0 ⇒ minimum f(1) = 1 + 1 = 2

Minimum value 2 at x = 1 (proved)

Q7. A rectangle has perimeter 40. Find its maximum area.

Let sides be x and 20 − x (since 2(x + y) = 40) A = x(20 − x) = 20x − x² dA/dx = 20 − 2x = 0 ⇒ x = 10 d²A/dx² = −2 < 0 ⇒ maximum A = 10 × 10 = 100

Maximum area = 100 square units, attained by the square 10 × 10.

Q8. Find the rate of change of the area of a circle with respect to its radius, and evaluate it at r = 5.

A = πr² ⇒ dA/dr = 2πr At r = 5: dA/dr = 10π

dA/dr = 2πr; at r = 5 it is 10π square units per unit increase in r.

Q9. Find the points of inflection of y = x³ − 3x².

y′ = 3x² − 6x, y″ = 6x − 6 = 0 ⇒ x = 1 y(1) = 1 − 3 = −2; y″ changes sign at x = 1

Point of inflection (1, −2)

Q10. Find the greatest and least values of f(x) = x³ − 12x on [0, 3].

f′(x) = 3x² − 12 = 0 ⇒ x = ±2; only x = 2 lies in [0,3] f(0) = 0, f(2) = 8 − 24 = −16, f(3) = 27 − 36 = −9

Greatest value 0 (at x = 0); least value −16 (at x = 2).

Exercise 6.7 — Anti-derivatives: standard, substitution, by parts

Q1. Integrate x⁵ and (3x² + 2x + 1).

∫x⁵ dx = x⁶/6 + C ∫(3x² + 2x + 1)dx = x³ + x² + x + C

x6/6 + C and x3 + x2 + x + C

Q2. Integrate 1/x², √x and 1/x.

∫x⁻² dx = x⁻¹/(−1) + C = −1/x + C ∫x^(1/2) dx = x^(3/2)/(3/2) + C = (2/3)x^(3/2) + C ∫(1/x)dx = ln|x| + C

−1/x + C; (2/3)x3/2 + C; ln|x| + C

Q3. Integrate sin 3x, cos 2x and e5x.

∫sin3x dx = −cos3x/3 + C ∫cos2x dx = sin2x/2 + C ∫e^(5x) dx = e^(5x)/5 + C

−cos3x/3 + C; sin2x/2 + C; e5x/5 + C

Q4. Evaluate ∫2x(x² + 1)⁵ dx by substitution.

Put u = x² + 1 ⇒ du = 2x dx ∫u⁵ du = u⁶/6 + C = (x²+1)⁶/6 + C

(x²+1)6/6 + C

Q5. Evaluate ∫x/(x² + 1) dx.

u = x² + 1, du = 2x dx ⇒ x dx = du/2 ∫(1/u)(du/2) = ½ ln|u| + C = ½ ln(x²+1) + C

½ ln(x² + 1) + C

Q6. Evaluate ∫sin²x cos x dx and ∫ex²·2x dx.

u = sinx ⇒ du = cosx dx ∫u² du = u³/3 + C = sin³x/3 + C u = x² ⇒ du = 2x dx ∫e^u du = e^u + C = e^(x²) + C

sin3x/3 + C and ex² + C

Q7. Evaluate ∫x ex dx by parts.

∫u dv = uv − ∫v du; take u = x, dv = eˣdx ⇒ du = dx, v = eˣ = xeˣ − ∫eˣ dx = xeˣ − eˣ + C

ex(x − 1) + C

Q8. Evaluate ∫x cos x dx.

u = x, dv = cosx dx ⇒ du = dx, v = sinx = x sinx − ∫sinx dx = x sinx + cosx + C

x sinx + cosx + C

Q9. Evaluate ∫x sin x dx.

u = x, dv = sinx dx ⇒ du = dx, v = −cosx = −x cosx + ∫cosx dx = −x cosx + sinx + C

sin x − x cos x + C

Q10. Evaluate ∫ln x dx.

u = lnx, dv = dx ⇒ du = dx/x, v = x = x lnx − ∫x(1/x)dx = x lnx − ∫1 dx = x lnx − x + C

x ln x − x + C

Q11. Evaluate ∫x² ln x dx.

u = lnx, dv = x²dx ⇒ du = dx/x, v = x³/3 = (x³/3)lnx − ∫(x³/3)(1/x)dx = (x³/3)lnx − (1/3)∫x²dx = (x³/3)lnx − x³/9 + C

(x3/3)ln x − x3/9 + C

Q12. Evaluate ∫(2x + 3)⁴ dx.

u = 2x + 3 ⇒ du = 2dx ⇒ dx = du/2 ∫u⁴(du/2) = u⁵/10 + C = (2x+3)⁵/10 + C

(2x+3)5/10 + C

Exercise 6.8 — Definite integrals and area

Q1. Evaluate ∫₀² x² dx.

∫₀² x² dx = [x³/3]₀² = 8/3 − 0 = 8/3

8/3

Q2. Evaluate ∫₀π/2 sin x dx and ∫₀π/2 cos x dx.

∫₀^(π/2) sinx dx = [−cosx]₀^(π/2) = 0 + 1 = 1 ∫₀^(π/2) cosx dx = [sinx]₀^(π/2) = 1 − 0 = 1

Both equal 1

Q3. Evaluate ∫₁² (1/x) dx and ∫₀¹ ex dx.

∫₁² dx/x = [ln|x|]₁² = ln2 − ln1 = ln2 ∫₀¹ eˣ dx = [eˣ]₀¹ = e − 1

ln 2 and e − 1

Q4. Evaluate ∫₀² (3x² + 2x) dx.

[x³ + x²]₀² = (8 + 4) − 0 = 12

12

Q5. Evaluate ∫₋₁¹ x³ dx and explain the answer geometrically.

x³ is an odd function integrated over a symmetric interval, so the signed areas above and below the axis cancel:

[x⁴/4]₋₁¹ = 1/4 − 1/4 = 0

0 — the two signed areas cancel exactly.

Q6. Evaluate ∫₀π sin x dx.

[−cosx]₀^π = −cosπ + cos0 = 1 + 1 = 2

2

Q7. Find the area under y = x² between x = 0 and x = 2.

Area = ∫₀² x² dx = [x³/3]₀² = 8/3

Area = 8/3 square units

Q8. Find the area between y = x and y = x² from x = 0 to x = 1.

On [0,1], x ≥ x², so the upper curve is y = x.

Area = ∫₀¹ (x − x²)dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6

Area = 1/6 square units

Q9. Find the area under y = 1/x from x = 1 to x = e.

∫₁^e (1/x)dx = [ln x]₁^e = ln e − ln 1 = 1

Area = 1 square unit

Q10. Find the area enclosed between y = 4 and y = x².

The curves meet where x² = 4, i.e. x = ±2. Between them, 4 ≥ x².

Area = ∫₋₂² (4 − x²)dx = [4x − x³/3]₋₂² = (8 − 8/3) − (−8 + 8/3) = 16 − 16/3 = 32/3

Area = 32/3 square units

Q11. Evaluate ∫₁⁴ √x dx.

∫x^(1/2)dx = (2/3)x^(3/2) (2/3)[4^(3/2) − 1^(3/2)] = (2/3)(8 − 1) = 14/3

14/3

Q12. Evaluate ∫₀¹ x ex dx.

From Exercise 6.7 Q7, an anti-derivative is ex(x − 1).

[eˣ(x−1)]₀¹ = e(0) − 1(−1) = 1

1

Exercise 6.9 — Topic-by-topic extension

Eight topics, one level harder: limits that need algebraic surgery first, a continuity constant to be found, first principles on a surd, and integration questions where the right substitution is not announced.

Topic 1 — Limits and indeterminate forms

Q1. Evaluate lim(x→2) (x³ − 8)/(x − 2).

Form 0/0, so factor the difference of cubes:

x³ − 8 = (x − 2)(x² + 2x + 4) limit = 4 + 4 + 4 = 12

12

Q2. Evaluate lim(x→0) (√(x + 4) − 2)/x.

Concept drills — why, what, where

Calculus questions are decided before any algebra starts: is the form indeterminate, is the function continuous, which rule applies, and is the answer an area or a signed integral. These drills train those decisions.

D1. Spot the error. A student writes (uv)′ = u′v′ and differentiates x²sin x as 2x cos x. What is missing?

The product rule has two terms: u′v + uv′ = 2x sinx + x² cosx. The written answer drops the second product and pairs the wrong factors.

Why it works: a change in u and a change in v both contribute to the change in the product. Where you use it: every product — say both terms aloud before writing.

D2. Method choice. You meet lim(x→1) (x² − 1)/(x − 1). What is the first step, before any algebra?

Substitute x = 1. A 0/0 result means the limit is indeterminate and needs factorisation or rationalisation; a finite result means you are already done.

Why it works: for continuous functions the limit equals the value. Where you use it: first line of every limit — it also identifies the form.

D3. What does it claim? f′(c) = 0 — does that guarantee an extremum at c?

No. f(x) = x³ has f′(0) = 0, but the point is a horizontal inflexion, not a maximum or minimum. Stationary ≠ extremum; you must check the sign change of f′.

Why it works: zero slope is necessary for a smooth extremum, not sufficient. Where you use it: extrema questions — justify with a sign change or the second derivative.

D4. Predict without computing. Where is y = |x − 3| not differentiable, and what is the derivative either side?

At x = 3: the left derivative is −1 and the right is +1, so the corner has no tangent. Everywhere else the derivative is −1 or +1.

Why it works: differentiability fails wherever two one-sided slopes disagree. Where you use it: any modulus function — locate the corner first.

D5. Counterexample hunt. “Continuous implies differentiable.” Refute it with the smallest example you know.

f(x) = |x| at x = 0: continuous (the graph is unbroken) yet not differentiable (sharp corner). Continuity is strictly weaker.

Why it works: continuity constrains the value, differentiability constrains the slope. Where you use it: continuity/differentiability discussion items.

D6. Why the sign? What does f″(x) > 0 say about the shape, and why does that identify a minimum?

f″ > 0 means the slope is increasing, so the curve is concave upward — a bowl. At a point of zero slope, a bowl must be at its lowest point, hence a minimum.

Why it works: concavity describes how the slope changes. Where you use it: the second-derivative test and “show the curve is concave up” items.

D7. Where to use it. What does +C encode, and where does it disappear?

It encodes the whole family of antiderivatives, which differ by a vertical shift. It cancels in a definite integral because F(b) − F(a) subtracts it away.

Why it works: a constant has zero derivative, so differentiation cannot see it. Where you use it: +C on every indefinite integral, never on a definite one.

D8. Necessity check. Before applying the second-derivative test at a point, what must be true?

f′(c) must actually be zero. Applying f″ alone at a non-stationary point reports the concavity, not whether an extremum exists there.

Why it works: the test classifies stationary points only. Where you use it: show f′(c) = 0 first, then the sign of f″.

D9. Order of operations. In d/dx sin(x²), why must the inner function be differentiated too?

Because a change in x reaches the sine through the inner square, so the outer rate must be multiplied by the inner rate: cos(x²)·2x. Omitting 2x is the commonest chain-rule error.

Why it works: rates compose multiplicatively. Where you use it: every composite — differentiate outside-in, then multiply by the inside.

D10. Read the sign. f′(x) < 0 on (0, 3). What does that mean, and what does it forbid?

The function is strictly decreasing there, so it cannot have an interior minimum — only possibly at an endpoint. Any claimed interior minimum in (0, 3) contradicts the sign of f′.

Why it works: the sign of the derivative is the direction of the graph. Where you use it: monotonicity intervals and “no interior extremum” arguments.

D11. Where it beats the formula. Why is ∫x e^(x²) dx solved by substitution while ∫x cos x dx needs parts?

In the first, the factor x is (up to a constant) the derivative of the inner x², so the integrand is a chain-rule pattern. In the second, x and cos x belong to unrelated families, so no substitution exists — the product must be dismantled by parts.

Why it works: substitution reverses the chain rule; parts reverses the product rule. Where you use it: look for a present inner derivative first.

D12. Where to stop. On a closed interval [a, b], where can the absolute maximum occur?

Only at interior stationary points or at the endpoints a and b. Testing stationary points alone is the classic error — with y = x on [1, 2] the maximum is at an endpoint.

Why it works: the extreme value theorem confines extrema to critical points and boundaries. Where you use it: “greatest/least value on the interval” questions.

Conceptual bank — 2-mark questions with model answers

C1. Define the limit of a function at a point.

limx→a f(x) = L means that as x approaches a (from either side, without reaching a), f(x) can be made as close to L as we wish. The value f(a) itself plays no part in the limit.

C2. State the three conditions for continuity of f at x = a.

(i) f(a) is defined, (ii) limx→a f(x) exists (left and right limits agree), (iii) the limit equals f(a).

C3. Name the standard indeterminate forms.

0/0, ∞/∞, 0·∞, ∞ − ∞, 1∞, 00, ∞0. Each needs algebraic work, a standard limit, or a logarithm before it can be evaluated.

C4. Why is limx→0 (sin x)/x = 1 important?

It is the standard limit that makes every trigonometric derivative work: d/dx sinx and d/dx cosx both reduce to it in first principles, and limits like sin(kx)/x follow from it.

C5. What is the geometric meaning of dy/dx at a point?

It is the slope of the tangent to the curve at that point, i.e. the instantaneous rate at which y changes with x.

C6. Distinguish Δy/Δx from dy/dx.

Δy/Δx is the average rate of change over a finite chord; dy/dx is the limit of that ratio as Δx → 0, the instantaneous rate — the slope of the tangent rather than the chord.

C7. When is a differentiable function increasing on an interval?

When f′(x) ≥ 0 throughout the interval (strictly increasing where f′(x) > 0). Decreasing corresponds to f′(x) ≤ 0.

C8. State the second derivative test for a local extremum at a stationary point.

At f′(a) = 0: if f″(a) < 0 there is a local maximum; if f″(a) > 0 a local minimum; if f″(a) = 0 the test fails and the first-derivative sign change must be checked.

C9. Why does every indefinite integral carry + C?

Because anti-differentiation is not unique: constants differentiate to zero, so all primitives differ by an additive constant. The +C records the whole family of curves.

C10. Distinguish a definite from an indefinite integral.

An indefinite integral is a function (family of primitives) with +C; a definite integral is a number obtained by evaluating the primitive between the two limits, with the constants cancelling.

C11. What does a definite integral represent geometrically?

The signed area between the curve, the x-axis and the two vertical lines x = a, x = b — areas below the axis count as negative.

C12. Evaluate ∫₋aa x³ dx and state the general rule used.

Because x³ is odd and the interval is symmetric, the integral is 0. Rule: ∫₋ₐᵃ f(x)dx = 0 for any odd f.

C13. Does continuity imply differentiability?

No. f(x) = |x| is continuous at 0 but has no derivative there because the left and right slopes are −1 and +1. Differentiability does imply continuity.

C14. What is a point of inflection?

A point where the concavity changes sign, normally where f″(x) = 0 and f″ changes sign across it.

C15. Differentiate a constant and explain the result.

d/dx (c) = 0, because a constant function is a horizontal line whose slope is zero (and its rate of change is zero).

C16. What does concave upward mean, and what does it imply about f″?

The tangent lies below the curve and the slope is increasing; algebraically f″(x) > 0 on the interval.

C17. State the product rule and the quotient rule.

(uv)′ = u′v + uv′;   (u/v)′ = (u′v − uv′)/v², v ≠ 0.

C18. Why do we prefer substitution for ∫2x(x²+1)⁵dx instead of expanding?

Substitution recognises 2x as the derivative of the inner function, reducing the integral to ∫u⁵du. Expanding a fifth power would be long and error-prone; the substitution does it in two lines.

C19. Distinguish a left-hand from a right-hand limit.

lim(x→a⁻) f(x) uses values of x just below a; lim(x→a⁺) uses values just above. Both are one-sided limits.

C20. When does lim(x→a) f(x) exist?

Only when the two one-sided limits exist and are equal. If they differ, the limit does not exist — as with |x|/x at 0.

C21. Define the derivative as a rate of change.

f′(x) = lim(h→0) [f(x + h) − f(x)]/h measures how fast the output changes per unit change in the input. Geometrically it is the slope of the tangent.

C22. What does dy/dx mean, and is it a fraction?

It is the derivative of y with respect to x — a single symbol for the limit of Δy/Δx. It can be manipulated like a fraction in the chain rule but is not literally one.

C23. Why is f(x) = |x| not differentiable at x = 0?

The left derivative is −1 and the right derivative is +1. They are unequal, so no unique tangent slope exists and the graph has a sharp corner.

C24. State the chain rule.

If y = f(u) and u = g(x), then dy/dx = f′(u) · g′(x) = (dy/du)(du/dx). It is used for every composite function.

C25. Is the derivative of a product the product of the derivatives?

No. (uv)′ = u′v + uv′. Taking u = v = x shows the difference at once: correct answer 2x, wrong answer 1.

C26. What is a stationary point?

A point where f′(x) = 0 — the tangent is horizontal. It may be a maximum, a minimum, or a point of inflexion.

C27. Distinguish a local from an absolute extremum.

A local extremum is highest/lowest near that point; an absolute extremum is highest/lowest over the whole stated interval. On a closed interval, absolute extrema occur at stationary points or endpoints.

C28. State the second-derivative test for a stationary point.

At f′(c) = 0: f″(c) < 0 gives a local maximum, f″(c) > 0 a local minimum, and f″(c) = 0 is inconclusive (use the first-derivative test).

C29. What is a point of inflexion?

A point where the concavity changes sign; f″ passes through zero there. It is not necessarily stationary — e.g. x³ at the origin, or the middle of a cubic in general.

C30. Define an antiderivative.

F is an antiderivative of f if F′ = f. All antiderivatives differ by a constant, which is why an indefinite integral carries + C.

C31. What does the fundamental theorem of calculus give you?

It links the two operations: ∫ₐᵇ f(x)dx = F(b) − F(a), where F is any antiderivative of f. So a definite integral is evaluated by antidifferentiation.

C32. State two basic properties of definite integrals.

∫ₐᵇ f = −∫ᵦᵃ f (reversing the limits changes the sign) and ∫ₐᵃ f = 0. Also ∫ₐᵇ = ∫ₐᶜ + ∫꜀ᵇ for a point c between a and b.

C33. Why does ∫(1/x)dx = ln|x| + C and not ln x + C?

Because 1/x is defined for negative x too. The absolute value keeps the antiderivative valid on both sides of the discontinuity at 0.

C34. Why is ∫eˣ dx = eˣ + C?

Because the derivative of eˣ is eˣ, so eˣ is its own antiderivative — the only function (up to a constant factor) with that property.

C35. State the integration-by-parts formula and when to use it.

∫u dv = uv − ∫v du. Use it for a product of unlike functions, choosing u by the order inverse-trig, log, algebraic, trig, exponential.

C36. How do you convert the indeterminate form 0 × ∞?

Rewrite the product as a quotient, e.g. f·g = f/(1/g), turning it into 0/0 or ∞/∞ so the limit rules apply.

C37. Define continuity on an interval.

f is continuous on (a, b) if it is continuous at every point of it, and on [a, b] if in addition the right limit at a and the left limit at b match the function values.

C38. What is a removable discontinuity?

A point where the limit exists but differs from (or is undefined at) the function value, as in (x² − 1)/(x − 1) at x = 1. Redefining f(1) = 2 removes it.

C39. What does a negative definite integral mean?

That the region lies below the x-axis over that interval. A definite integral gives signed area, not just geometric area.

C40. State the derivative of sin x, cos x and tan x.

(sin x)′ = cos x, (cos x)′ = −sin x, (tan x)′ = sec²x. The sign on cos x is the standard place where marks are lost.

C41. Why does the derivative of a constant vanish?

A constant does not change, so its rate of change is zero; geometrically its graph is horizontal, giving slope 0.

C42. What is the relation between differentiability and continuity?

Differentiable ⇒ continuous, but not conversely: |x| is continuous at 0 and not differentiable there. So continuity is necessary but not sufficient.

L7. [5] Find the tangent to x² + y² = 25 at the point (3, 4).

Differentiating implicitly: 2x + 2y(dy/dx) = 0 ⇒ dy/dx = −x/y At (3,4): slope = −3/4 y − 4 = −(3/4)(x − 3) ⇒ 4y − 16 = −3x + 9

3x + 4y = 25

L8. [6] If x = a(θ − sinθ) and y = a(1 − cosθ), find dy/dx.

dx/dθ = a(1 − cosθ) dy/dθ = a sinθ ⇒ dy/dx = a sinθ / a(1 − cosθ) = sinθ/(1 − cosθ) Using sinθ = 2sin(θ/2)cos(θ/2) and 1 − cosθ = 2sin²(θ/2): = [2sin(θ/2)cos(θ/2)]/[2sin²(θ/2)] = cot(θ/2)

dy/dx = cot(θ/2)

Trap 1 — dropping +C. A missing +C in an indefinite integral is a guaranteed mark loss; it is not optional.

Trap 2 — separating a fraction across a limit. (x²−4)/(x−2) is not x²/(x−2) − 4/(x−2); factor the numerator first.

Trap 3 — assuming f′(a) = 0 means an extremum. y = x³ has f′(0) = 0 but no extremum — always check the sign change or f″.

Trap 4 — saying "continuous ⇒ differentiable". |x − 2| is the standard counterexample; continuity is necessary but not sufficient.

Trap 5 — subtracting the limits in the wrong order. ∫ₐᵇ = F(b) − F(a); a reversed order flips the sign.

Trap 6 — ignoring which curve is on top. In an area question, test a point in the interval: ∫(upper − lower), not ∫(lower − upper).

Trap 7 — forgetting the chain rule's inner derivative. d/dx sin(x³) = 3x²cos(x³), not cos(x³).
