Algebra of complex numbers Modulus and argument long answer

L1.For z = (2 + i)/(1 − i), (a) write z in the form a + ib, (b) find |z| and arg z, (c) verify that z·z̄ = |z|². [6]

  1. H1. Multiply numerator and denominator by the conjugate 1 + i.
  2. H2. The denominator becomes 1² + 1² = 2.
  3. H3. |z| = √(a² + b²) and z z̄ = a² + b² identically.

Given: z = (2 + i)/(1 − i) Required: a + ib form, modulus, argument, and the identity z z̄ = |z|² 1. z = (2 + i)(1 + i)/[(1 − i)(1 + i)] = (2 + 2i + i + i²)/2 2. = (2 + 3i − 1)/2 = (1 + 3i)/2 = 1/2 + (3/2)i 3. |z| = √((1/2)² + (3/2)²) = √(10/4) = √10/2 4. a, b > 0 ⇒ first quadrant; arg z = tan⁻¹(3) ≈ 71.6° 5. z z̄ = (1/2)² + (3/2)² = 10/4 = 5/2 6. |z|² = (√10/2)² = 10/4 = 5/2 ✓

z = 1/2 + (3/2)i; |z| = √10/2, arg z = tan⁻¹3 ≈ 71.6°; z z̄ = |z|² = 5/2.
