Double and half angles Double angle long answer

L1.If sin A + cos A = 1/2, find (a) sin 2A and (b) sin³A + cos³A. [6]

  1. H1. Square the given equation: sin²A + 2sinAcosA + cos²A = 1/4.
  2. H2. sin²A + cos²A = 1, so 2sinAcosA = sin 2A is immediate.
  3. H3. For the cubes use x³ + y³ = (x + y)(x² − xy + y²) with xy = sinAcosA.

Given: sinA + cosA = 1/2 Required: sin2A and sin³A + cos³A 1. square: (sinA + cosA)² = 1 + sin2A = 1/4 2. sin2A = 1/4 − 1 = −3/4 3. sinAcosA = (sin2A)/2 = −3/8 4. sin³A + cos³A = (sinA + cosA)(sin²A − sinAcosA + cos²A) 5. = (1/2)(1 − (−3/8)) = (1/2)(11/8) 6. = 11/16

(a) sin 2A = −3/4 (b) sin³A + cos³A = 11/16.

Marking split — squaring step 1.5 + sin2A 1.5 + identity for cubes 1.5 + substitution 1.5 = 6
Common pitfall — Writing sin²A + cos²A = 2, or losing the negative sign of sin2A after squaring.
