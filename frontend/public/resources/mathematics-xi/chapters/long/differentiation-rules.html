Chain rule Product, chain long answer

L1.Differentiate (a) y = x² sin x, (b) y = ln(x² + 1), (c) y = e^{3x} cos 2x. [6]

  1. H1. (a) is a product: u = x², v = sinx.
  2. H2. (b) is a chain: the inner function is x² + 1, whose derivative is 2x.
  3. H3. (c) is a product of two exponentials-trig terms — apply the product rule with the chain inside each factor.

Given: three functions Required: each derivative, simplified 1. (a) y′ = 2x sinx + x² cosx 2. (b) y = ln u with u = x² + 1 ⇒ y′ = (1/u)(2x) = 2x/(x² + 1) 3. (c) u = e^{3x}, u′ = 3e^{3x}; v = cos2x, v′ = −2sin2x 4. y′ = 3e^{3x}cos2x + e^{3x}(−2sin2x) 5. = e^{3x}(3cos2x − 2sin2x) 6. each answer is left in factored form, ready for sign analysis

(a) 2x sinx + x² cosx (b) 2x/(x² + 1) (c) e^{3x}(3cos2x − 2sin2x).

Marking split — each part 2
Common pitfall — Forgetting the inner derivative: ln(x² + 1)′ is not 1/(x² + 1), and cos2x′ is not −sin2x.
