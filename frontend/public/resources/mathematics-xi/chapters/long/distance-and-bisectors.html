Perpendicular distance Parallel lines long answer

L1.The parallel lines are 3x + 4y = 12 and 3x + 4y = 2. (a) Find the distance between them. (b) Find the equation of the line midway between them. (c) Verify that any point of that middle line is equidistant from both. [6]

  1. H1. Bring both equations to the form 3x + 4y + c = 0 with the same A and B.
  2. H2. The gap between parallel lines is |c₁ − c₂|/√(A² + B²).
  3. H3. The middle line has c equal to the average of the two constants.

Given: L₁: 3x + 4y − 12 = 0, L₂: 3x + 4y − 2 = 0 Required: the gap, the midline, and the equidistance check 1. √(A² + B²) = √(9 + 16) = 5 2. d = |−12 − (−2)|/5 = 10/5 = 2 3. midline: 3x + 4y = (12 + 2)/2 = 7 ⇒ 3x + 4y − 7 = 0 4. take P(1, 1) on the midline: |3 + 4 − 12|/5 = 1 and |3 + 4 − 2|/5 = 1 5. both distances equal 1 = d/2 ✓ 6. any point of the midline lies exactly halfway across

distance = 2 units; midline 3x + 4y = 7, and every point of it is 1 unit from each line.

Marking split — distance formula 2 + midline 2 + equidistance verification 2 = 6
Common pitfall — Using c₁ − c₂ without first making the A and B coefficients identical in both equations.
