L1.Evaluate (a) ∫ x ln x dx, (b) ∫ cos²x dx. [6]

  1. H1. (a) is a product: take u = ln x and dv = x dx.
  2. H2. For (b) replace cos²x by (1 + cos 2x)/2.
  3. H3. Both answers need the constant of integration.

Given: two indefinite integrals Required: each antiderivative, with + C 1. (a) u = lnx, dv = x dx ⇒ du = dx/x, v = x²/2 2. ∫x lnx dx = (x²/2)lnx − ∫(x²/2)(1/x)dx 3. = (x²/2)lnx − ∫(x/2)dx = (x²/2)lnx − x²/4 + C 4. (b) cos²x = (1 + cos2x)/2 5. ∫cos²x dx = x/2 + (sin2x)/4 + C 6. differentiate back: d/dx[x/2 + sin2x/4] = 1/2 + cos2x/2 = cos²x ✓

(a) (x²/2)ln x − x²/4 + C (b) x/2 + (sin 2x)/4 + C.

Marking split — by-parts setup 2 + completed integral 1.5 + half-angle 1.5 + constant 1 = 6
Common pitfall — Dropping + C, or integrating cos²x as sin³x/3 (that would be for sin²x cosx).
