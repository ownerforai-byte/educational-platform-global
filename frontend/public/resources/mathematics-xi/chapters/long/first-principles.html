L1.Differentiate from first principles: (a) y = x³, (b) y = sin x. [6]

  1. H1. Write dy/dx = lim(h→0) [f(x + h) − f(x)]/h.
  2. H2. For x³ expand (x + h)³ and keep the terms that do not vanish with h.
  3. H3. For sinx use sin(x + h) = sinx cosh + cosx sinh and the limits sinh/h → 1, (cosh − 1)/h → 0.

Given: y = x³ and y = sinx Required: each derivative from the definition 1. (a) [(x + h)³ − x³]/h = [3x²h + 3xh² + h³]/h = 3x² + 3xh + h² 2. as h → 0 this gives 3x² 3. (b) [sin(x + h) − sinx]/h = [sinx cosh + cosx sinh − sinx]/h 4. = sinx(cosh − 1)/h + cosx (sinh/h) 5. limits: (cosh − 1)/h → 0 and sinh/h → 1 6. dy/dx = cosx

(a) dy/dx = 3x² (b) dy/dx = cos x.

Marking split — expansion 1.5 + limit 1.5 + identity 1.5 + standard limits 1.5 = 6
Common pitfall — Cancelling h before letting h → 0 — h may only be removed after the quotient is simplified.
