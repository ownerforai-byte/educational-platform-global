L1.Show that 6x² + 5xy − 6y² = 0 represents a pair of straight lines. (a) Find the separate equations. (b) Find the angle between them and state whether they are perpendicular. [6]

  1. H1. Treat the expression as a quadratic in x and factor it.
  2. H2. Each linear factor equal to zero is one line through the origin.
  3. H3. For ax² + 2hxy + by² = 0, tanθ = 2√(h² − ab)/(a + b).

Given: 6x² + 5xy − 6y² = 0 Required: the two lines, the angle, and perpendicularity 1. factor: (2x + 3y)(3x − 2y) = 6x² − 4xy + 9xy − 6y² ✓ 2. the lines are 2x + 3y = 0 and 3x − 2y = 0 3. here a = 6, 2h = 5, b = −6 ⇒ h = 5/2 4. a + b = 0 ⇒ tanθ is infinite ⇒ θ = 90° 5. slopes: −2/3 and 3/2, whose product is −1 6. both lines pass through the origin, so the pair is a right-angled cross

the lines are 2x + 3y = 0 and 3x − 2y = 0; the angle between them is 90° (m₁m₂ = −1).

Marking split — factorisation 2 + separate lines 2 + angle 2 = 6
Common pitfall — Reading b as +6. The sign of b comes from the y² coefficient −6, and it decides perpendicularity.
