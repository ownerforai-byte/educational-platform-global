Equations reducible to quadratics Reducible to quadratic long answer

L1.Solve cos 2θ + 3 cos θ + 2 = 0 completely, and list the solutions that lie in [0, 2π]. [6]

  1. H1. Replace cos2θ by 2cos²θ − 1 so the equation involves only cosθ.
  2. H2. The result 2cos²θ + 3cosθ + 1 = 0 factorises as (2cosθ + 1)(cosθ + 1).
  3. H3. Write each family, then pick the members inside one revolution.

Given: cos2θ + 3cosθ + 2 = 0 Required: the general solution and the members in [0, 2π] 1. 2cos²θ − 1 + 3cosθ + 2 = 0 ⇒ 2cos²θ + 3cosθ + 1 = 0 2. (2cosθ + 1)(cosθ + 1) = 0 ⇒ cosθ = −1/2 or cosθ = −1 3. cosθ = −1/2 = cos(2π/3) ⇒ θ = 2nπ ± 2π/3 4. cosθ = −1 = cos π ⇒ θ = (2n + 1)π 5. in [0, 2π]: 2π/3, 4π/3 from the first family and π from the second 6. check θ = 2π/3: cos(4π/3) + 3cos(2π/3) + 2 = −1/2 − 3/2 + 2 = 0 ✓

θ = 2nπ ± 2π/3 or θ = (2n + 1)π, n ∈ ℤ; in [0, 2π] the solutions are 2π/3, π, 4π/3.

Marking split — reduction 1.5 + factorisation 1.5 + two families 2 + interval list 1 = 6
Common pitfall — Writing cosθ = −1/2 ⇒ θ = 2nπ + 2π/3 and dropping the second branch 2nπ − 2π/3.
