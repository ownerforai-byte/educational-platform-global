Quadratic equations Quadratic in range long answer

L1.Solve 2sin²x − 3sin x + 1 = 0 for x ∈ [0, 2π], and explain how the number of solutions matches the oscillation of the graph. [6]

  1. H1. Treat the equation as a quadratic in sin x and factor it.
  2. H2. sin x = 1 and sin x = 1/2 give different numbers of solutions in one revolution.
  3. H3. Count how many times each horizontal level is crossed in [0, 2π].

Given: 2sin²x − 3sinx + 1 = 0, x ∈ [0, 2π] Required: all solutions and a graph-based check 1. (2sinx − 1)(sinx − 1) = 0 ⇒ sinx = 1/2 or sinx = 1 2. sinx = 1/2 ⇒ x = π/6, 5π/6 3. sinx = 1 ⇒ x = π/2 (a single point of the wave) 4. the line y = 1/2 cuts the sine wave twice per revolution; y = 1 touches it once 5. so 2 + 1 = 3 solutions 6. check x = 5π/6: 2(1/4) − 3(1/2) + 1 = 1/2 − 3/2 + 1 = 0 ✓

x = π/6, π/2, 5π/6 — three solutions, matching two crossings for sinx = 1/2 and one touch for sinx = 1.

Marking split — factorisation 2 + solutions from 1/2 2 + solution from 1 1 + graph reasoning 1 = 6
Common pitfall — Writing x = π/6 only for sinx = 1/2, or inventing a second solution for sinx = 1.
