L1.Solve tan⁻¹(2x) + tan⁻¹(3x) = π/4, stating clearly which roots are acceptable and why. [6]

  1. H1. Apply the addition formula: tan(sum) = (2x + 3x)/(1 − 6x²).
  2. H2. Set it equal to tan(π/4) = 1 and clear the denominator.
  3. H3. For the formula to hold with a positive sum we need 6x² < 1 — test each root.

Given: tan⁻¹(2x) + tan⁻¹(3x) = π/4 Required: all admissible x, with justification 1. tan(sum) = (2x + 3x)/(1 − 6x²) = 5x/(1 − 6x²) 2. 5x/(1 − 6x²) = 1 ⇒ 5x = 1 − 6x² ⇒ 6x² + 5x − 1 = 0 3. (6x − 1)(x + 1) = 0 ⇒ x = 1/6 or x = −1 4. condition: the formula needs 1 − 6x² > 0, i.e. |x| < 1/√6 5. x = 1/6: 6x² = 1/6 < 1 ✓ ; x = −1: 1 − 6 = −5 < 0 ✗ (the sum would be negative) 6. verify x = 1/6: tan⁻¹(1/3) + tan⁻¹(1/2) = π/4 ✓

x = 1/6 only; x = −1 is rejected because it makes 1 − 6x² negative, so the sum lies outside (0, π/2).

Marking split — formula and quadratic 2.5 + both roots 1.5 + admissibility test 1.5 + check 0.5 = 6
Common pitfall — Keeping both roots. The addition formula only holds on the branch where 1 − xy > 0; always test it.
