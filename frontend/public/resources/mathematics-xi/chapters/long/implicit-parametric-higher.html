Implicit differentiation Implicit differentiation long answer

L1.The curve x² + xy + y² = 3 passes through (1, 1). (a) Find dy/dx by implicit differentiation. (b) Evaluate the slope at (1, 1). (c) Write the tangent line there. [6]

  1. H1. Differentiate term by term, remembering that y is a function of x (product rule on xy).
  2. H2. Collect the dy/dx terms on one side.
  3. H3. A tangent is y − y₁ = m(x − x₁).

Given: x² + xy + y² = 3, point (1, 1) Required: dy/dx, the slope, the tangent 1. 2x + (y + x y′) + 2y y′ = 0 2. y′(x + 2y) = −(2x + y) ⇒ y′ = −(2x + y)/(x + 2y) 3. at (1, 1): y′ = −(2 + 1)/(1 + 2) = −3/3 = −1 4. tangent: y − 1 = −1(x − 1) 5. ⇒ y = −x + 2, i.e. x + y = 2 6. check (1,1) on both the curve (1 + 1 + 1 = 3 ✓) and the tangent (2 = 2 ✓)

dy/dx = −(2x + y)/(x + 2y); slope −1 at (1, 1); tangent x + y = 2.

Marking split — differentiation 2 + solving for y′ 1.5 + slope 1 + tangent 1.5 = 6
Common pitfall — Differentiating xy as y instead of y + x y′ — the product rule is the whole point of the exercise.
