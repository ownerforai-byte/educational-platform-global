Inverse of a matrix Inverse and system long answer

L1.Let A = [[1, 2], [3, 5]]. (a) Find A⁻¹. (b) Use it to solve x + 2y = 4, 3x + 5y = 11. (c) Verify that A² − 6A − I = 0. [6]

  1. H1. det A = 1·5 − 2·3 = −1; the adjugate swaps 1 and 5 and negates 2 and 3.
  2. H2. Write the system as AX = B and multiply by A⁻¹ on the left.
  3. H3. For the verification, compute A² and 6A and subtract I.

Given: A = [[1,2],[3,5]], system x + 2y = 4, 3x + 5y = 11 Required: A⁻¹, the solution, and the Cayley–Hamilton check 1. det A = 5 − 6 = −1, adj A = [[5, −2], [−3, 1]] 2. A⁻¹ = −[[5, −2], [−3, 1]] = [[−5, 2], [3, −1]] 3. X = A⁻¹B = [[−5, 2], [3, −1]]·[[4], [11]] = [[−20 + 22], [12 − 11]] = [[2], [1]] 4. check in the original: 2 + 2 = 4 ✓ and 6 + 5 = 11 ✓ 5. A² = [[7, 12], [18, 31]], 6A = [[6, 12], [18, 30]] 6. A² − 6A = [[1, 0], [0, 1]] = I ⇒ A² − 6A − I = 0 ✓

A⁻¹ = [[−5, 2], [3, −1]]; x = 2, y = 1; and A² − 6A − I = 0 is verified.

Marking split — inverse 2 + solution 2 + verification 2 = 6
Common pitfall — Forgetting the minus sign of det A = −1, which flips every entry of the adjugate.
