Building the table Two values of h long answer

L1.Estimate ∫₀¹ dx/(1 + x²) with the trapezoidal rule using (a) h = 0.5 and (b) h = 0.25, and compare both with the exact value π/4. [6]

  1. H1. Ordinates for h = 0.5: 1, 0.8, 0.5.
  2. H2. For h = 0.25 you need five ordinates; the middle three are doubled.
  3. H3. Compare each error with the exact 0.785398.

Given: ∫₀¹ dx/(1 + x²), exact π/4 = 0.785398 Required: both trapezoidal estimates and their errors 1. h = 0.5: y = 1, 0.8, 0.5 ⇒ T = 0.25[1 + 0.5 + 2(0.8)] = 0.25(3.1) 2. T₁ = 0.7750, error = 0.01040 3. h = 0.25: y = 1, 0.94118, 0.8, 0.64, 0.5 4. middle sum = 0.94118 + 0.8 + 0.64 = 2.38118 5. T₂ = 0.125[1.5 + 4.76236] = 0.125(6.26236) = 0.78280, error = 0.00260 6. halving h cut the error by a factor of 4 — the h² behaviour of the rule

(a) 0.7750 (error 0.0104) (b) 0.7828 (error 0.0026); the error falls by a factor of 4 when h is halved.

Marking split — h = 0.5 estimate 1.5 + h = 0.25 estimate 2.5 + error comparison 2 = 6
Common pitfall — Doubling the first and last ordinates. Only the interior ordinates carry the factor 2.
