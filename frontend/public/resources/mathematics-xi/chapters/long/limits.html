L1.Evaluate with full working: (a) lim(x→0) (1 − cos 2x)/x², (b) lim(x→∞) (√(x² + 1) − x), (c) lim(x→2) (x³ − 8)/(x² − 4). [6]

  1. H1. For (a) use 1 − cos2x = 2sin²x, then the standard limit sinθ/θ → 1.
  2. H2. For (b) multiply and divide by the conjugate √(x² + 1) + x.
  3. H3. For (c) factor both the difference of cubes and the difference of squares, then cancel x − 2.

Given: three limits Required: each value with the algebra that removes the indeterminacy 1. (a) 1 − cos2x = 2sin²x, so (1 − cos2x)/x² = 2(sinx/x)² → 2(1)² = 2 2. (b) (√(x²+1) − x)(√(x²+1) + x)/(√(x²+1) + x) = 1/(√(x²+1) + x) 3. as x → ∞ the denominator → ∞, so the limit is 0 4. (c) x³ − 8 = (x − 2)(x² + 2x + 4); x² − 4 = (x − 2)(x + 2) 5. cancel x − 2: (x² + 2x + 4)/(x + 2) → (4 + 4 + 4)/4 6. = 12/4 = 3

(a) 2 (b) 0 (c) 3.

Marking split — each part 2
Common pitfall — Writing 0/0 = 1, or cancelling x − 2 without stating that x ≠ 2 in the limit process.
