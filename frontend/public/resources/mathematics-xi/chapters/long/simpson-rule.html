Odd/even strip requirement Two values of h long answer

L1.Estimate ∫₀¹ dx/(1 + x) by Simpson's rule with h = 0.5 and h = 0.25, and compare with ln 2 = 0.693147. [6]

  1. H1. Simpson needs an even number of strips: h = 0.5 gives 2 strips and h = 0.25 gives 4.
  2. H2. Weights go 1, 4, 2, 4, 1 and the multiplier is h/3.
  3. H3. For h = 0.5 the ordinates are 1, 0.66667, 0.5.

Given: ∫₀¹ dx/(1 + x) = ln 2 = 0.693147 Required: two Simpson estimates and their errors 1. h = 0.5: S = (0.5/3)[1 + 0.5 + 4(0.66667)] 2. = 0.16667 × 4.16667 = 0.69444, error 0.00130 3. h = 0.25: y = 1, 0.8, 0.66667, 0.57143, 0.5 4. S = (0.25/3)[1 + 0.5 + 4(0.8 + 0.57143) + 2(0.66667)] 5. = 0.08333 × 8.31905 = 0.69326, error 0.00011 6. the same h = 0.5 gives error 0.0013 for Simpson against 0.0026 for the trapezoidal rule, and the halving factor is about 12

(a) 0.69444 (error 0.0013) (b) 0.69326 (error 0.0001); Simpson is far more accurate than the trapezoidal rule for the same h.

Marking split — each estimate 2 + comparison 2 = 6
Common pitfall — Using an odd number of strips. Simpson's rule is undefined there — always pair the strips.
