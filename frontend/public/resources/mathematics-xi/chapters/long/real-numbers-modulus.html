Modulus and distance Modulus equation long answer

L1.Solve |x − 1| + |x + 2| = 5 by the critical-point method, and hence state the least possible value of |x − 1| + |x + 2|. [6]

  1. H1. The moduli change behaviour at x = −2 and x = 1; split the number line there.
  2. H2. On the middle piece the two distances add to exactly 3, independent of x.
  3. H3. The least value is the distance between the two critical points.

Given: |x − 1| + |x + 2| = 5, critical points −2 and 1 Required: the solution set and the minimum of the expression 1. x < −2: −(x − 1) − (x + 2) = 5 ⇒ −2x − 1 = 5 ⇒ x = −3 ✓ 2. −2 ≤ x < 1: (1 − x) + (x + 2) = 3 ≠ 5 ⇒ no solution 3. x ≥ 1: (x − 1) + (x + 2) = 5 ⇒ 2x + 1 = 5 ⇒ x = 2 ✓ 4. on [−2, 1] the expression is constantly 3 = |1 − (−2)| 5. so the least value is 3, attained for every x in [−2, 1]

x = −3 or x = 2; the least value of the expression is 3.

Marking split — case split 2 + two valid roots 2 + minimum argument 2 = 6
Common pitfall — Squaring both sides at once — it creates extraneous roots and hides the constant middle piece.
