The definition

Q1.State the derivative definition and use it to differentiate x². [4]

f′(x) = lim(h→0)[f(x + h) − f(x)]/h = lim[(x+h)² − x²]/h = lim(2x + h)

2x

Polynomials Spot the error

Q20.A student writes [(x + h)² − x²]/h = 2x and stops. What is missing? [2]

Trigonometric functions Assertion–reason

Q21.Assertion: d/dx sinx = cosx follows from first principles. Reason: lim(h→0) sinh/h = 1 and lim(h→0) cosh = 1. [2]

Both true, and the reason is the actual proof

The definition Explain

Q22.Why must h tend to zero rather than being set to zero? [2]

Setting h = 0 makes the difference quotient 0/0.

Only the limit gives the tangent slope; substitution is undefined
