Group C

  1. 20. 1. let the rhombus be OACB with OA = a and OB = b, where |a| = |b| 2. the diagonals are OC = a + b and AB = b − a 3. (a + b)·(b − a) = a·b − |a|² + |b|² − a·b 4. = |b|² − |a|² 5. since the sides are equal, this is 0 6. so the diagonals meet at a right angleAns. the diagonals of a rhombus are perpendicular
  2. 21. 1. the three edge vectors from the origin are (1, 2, 3), (2, 1, 1), (3, 2, 1) 2. determinant = 1(1 − 2) − 2(2 − 3) + 3(4 − 3) 3. = −1 + 2 + 3 = 4 4. tetrahedron volume = |determinant|/6 5. = 4/6 6. = 2/3Ans. volume = 2/3 cubic units
  3. 22. 1. |a + b|² = |a|² + 2a·b + |b|² 2. a·b ≤ |a||b|, so |a + b|² ≤ |a|² + 2|a||b| + |b|² 3. the right side is (|a| + |b|)² 4. taking square roots gives the inequality 5. equality needs a·b = |a||b| 6. that happens exactly when a and b point the same wayAns. |a + b| ≤ |a| + |b|, with equality when a and b are parallel and in the same sense
