  1. 12. 1. x ∈ (A ∪ B)′ ⇔ x ∉ (A ∪ B) 2. ⇔ x ∉ A and x ∉ B 3. ⇔ x ∈ A′ and x ∈ B′ 4. ⇔ x ∈ A′ ∩ B′ 5. each step is reversible, so the two sets contain the same elementsAns. hence (A ∪ B)′ = A′ ∩ B′
