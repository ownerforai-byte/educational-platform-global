Group B

  1. 12. 1. cos2A = cos(A + A) = cosAcosA − sinAsinA 2. = cos²A − sin²A = cos²A − (1 − cos²A) 3. = 2cos²A − 1 4. cos60° = 1/2 ⇒ cos120° = 2(1/4) − 1Ans. cos 2A = 2cos²A − 1 and cos 120° = −1/2
  2. 13. 1. 2sinθcosθ − sinθ = 0 2. sinθ(2cosθ − 1) = 0 3. sinθ = 0 ⇒ θ = 0, π 4. cosθ = 1/2 ⇒ θ = π/3 5. all three lie in [0, π]Ans. θ = 0, π/3, π
  3. 14. 1. tan(A + B) = sin(A + B)/cos(A + B) 2. = (sinAcosB + cosAsinB)/(cosAcosB − sinAsinB) 3. divide every term by cosAcosB 4. = (tanA + tanB)/(1 − tanAtanB) 5. tan75° = tan(45° + 30°) = (1 + 1/√3)/(1 − 1/√3) 6. = (√3 + 1)/(√3 − 1) = 2 + √3Ans. tan(A + B) = (tanA + tanB)/(1 − tanAtanB); tan 75° = 2 + √3
  4. 15. 1. 2(1 − sin²θ) + sinθ − 2 = 0 2. −2sin²θ + sinθ = 0 ⇒ sinθ(1 − 2sinθ) = 0 3. sinθ = 0 ⇒ θ = nπ 4. sinθ = 1/2 ⇒ θ = nπ + (−1)ⁿ π/6Ans. θ = nπ or θ = nπ + (−1)ⁿ π/6, n ∈ ℤ
  5. 16. 1. 1 + cosA = 2cos²(A/2) and sinA = 2sin(A/2)cos(A/2) 2. the quotient is [2cos²(A/2)]/[2sin(A/2)cos(A/2)] 3. cancel 2cos(A/2) 4. = cos(A/2)/sin(A/2) = cot(A/2)Ans. (1 + cos A)/sin A = cot(A/2)
  6. 17. 1. cosx = √(1 − 4/9) = √5/3 2. tan(x/2) = sinx/(1 + cosx) 3. = (2/3)/(1 + √5/3) = 2/(3 + √5) 4. rationalise: 2(3 − √5)/(9 − 5) = (3 − √5)/2Ans. tan(x/2) = (3 − √5)/2 ≈ 0.382
  7. 18. 1. take tan of both sides: 3x = tan(π/4) = 1 2. x = 1/3 3. 3x = 1 lies in the principal range, so the solution is admissibleAns. x = 1/3
  8. 19. 1. 2sin20°sin40° = cos20° − cos60° = cos20° − 1/2 2. multiply sin80°: (cos20° − 1/2)sin80°/2 3. 2sin80°cos20° = sin100° + sin60° = sin80° + √3/2 4. so the value is [sin80° + √3/2 − sin80°]/4 5. = (√3/2)/4Ans. sin 20° sin 40° sin 80° = √3/8

Group C

  1. 20. 1. write 1 − cosA = 2sin²(A/2) and 1 + cosA = 2cos²(A/2), sinA = 2sin(A/2)cos(A/2) 2. numerator = 2sin²(A/2) + 2sin(A/2)cos(A/2) 3. = 2sin(A/2)[sin(A/2) + cos(A/2)] 4. denominator = 2cos²(A/2) + 2sin(A/2)cos(A/2) 5. = 2cos(A/2)[cos(A/2) + sin(A/2)] 6. the bracket cancels, leaving sin(A/2)/cos(A/2) = tan(A/2)Ans. (1 + sinA − cosA)/(1 + sinA + cosA) = tan(A/2)
  2. 21. 1. replace sin²x by 1 − cos²x: 2 − 2cos²x − 3cosx = 0 2. 2cos²x + 3cosx − 2 = 0 3. (2cosx − 1)(cosx + 2) = 0 4. cosx = 1/2 or cosx = −2 5. the second is impossible since |cosx| ≤ 1 6. cosx = 1/2 ⇒ x = π/3, 5π/3 in [0, 2π]Ans. x = π/3 and x = 5π/3
  3. 22. 1. tan2A = tan(A + A) = (tanA + tanA)/(1 − tanA·tanA) 2. = 2tanA/(1 − tan²A) 3. tanA = 3/4 ⇒ tan2A = (3/2)/(1 − 9/16) 4. = (3/2)/(7/16) = 24/7 5. tan2A > 0 with A acute gives 2A in the first quadrant 6. check: A ≈ 36.87° ⇒ 2A ≈ 73.74°, and tan 73.74° ≈ 3.43 = 24/7 ✓Ans. tan 2A = 2tanA/(1 − tan²A); with tanA = 3/4, tan2A = 24/7 (first quadrant)
