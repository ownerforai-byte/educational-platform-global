7.3 · Trapezoidal Rule — two-mark conceptual answers

Topics The formula · Building the table · Error behaviour · Comparing with the exact value

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

The formula 2 marks

C1. What is the idea behind the trapezoidal rule? [2]

Ans. Replace the curve by straight chords over each strip, so the area is a sum of trapeziums instead of the exact curve area.

Building the table 2 marks

C2. Write the trapezoidal rule formula. [2]

Ans. T = (h/2)[y₀ + yₙ + 2(y₁ + y₂ + … + yₙ₋₁)], with the interior ordinates counted twice and the end ones once.

Building the table 2 marks

C3. When does the trapezoidal rule over-estimate the integral? [2]

Ans. When the curve is concave upward, since the chords then lie above the curve.

Error behaviour 2 marks

C4. What is the order of the error in the trapezoidal rule? [2]

Ans. It is proportional to h², so halving the strip width cuts the error to roughly one quarter.

Error behaviour 2 marks

C5. When is the trapezoidal rule exact? [2]

Ans. For linear functions, because a straight line coincides with its chords, so the trapeziums reproduce the area exactly.

Comparing with the exact value 2 marks

C6. Why must the ordinates be equally spaced? [2]

Ans. The formula uses one common width h; unequal strips would each need their own trapezium area.
