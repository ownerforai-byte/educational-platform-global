1.3 · Functions: Domain, Range, Composite and Inverse — two-mark conceptual answers

Topics Domain and range · Composite functions · Inverse functions · Graphs and extrema

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

Domain and range 2 marks

C1. What are the domain and the range of a function? [2]

Ans. The domain is the set of all inputs the function accepts; the range is the set of all outputs it actually produces.

Domain and range 2 marks

C2. When is a function one-one? [2]

Ans. When different inputs always give different outputs, i.e. f(a) = f(b) forces a = b. Its graph then meets every horizontal line at most once.

Composite functions 2 marks

C3. When is a function onto? [2]

Ans. When its range equals its codomain, so every element of the codomain is the image of at least one input.

Inverse functions 2 marks

C4. Why is f⁻¹ not the same as 1/f? [2]

Ans. f⁻¹ undoes the operation of f, so f(f⁻¹(x)) = x. The reciprocal 1/f(x) is a different function altogether.

Inverse functions 2 marks

C5. When does the inverse of a function exist? [2]

Ans. Exactly when the function is both one-one and onto (bijective), because only then can each output be traced back to one input.

Graphs and extrema 2 marks

C6. What does the graph of f⁻¹ look like compared with f? [2]

Ans. It is the reflection of the graph of f in the line y = x, since the roles of x and y are interchanged.
