2.4 · Equations Restricted to an Interval — two-mark conceptual answers

Topics Linear equations · Quadratic equations · Multiple angles · Mixed equations

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

Linear equations 2 marks

C1. Why can a quadratic in sin x give up to four solutions in [0, 2π]? [2]

Ans. Each factor gives a value of sin x, and each value inside (−1, 1) produces two angles in one full revolution.

Linear equations 2 marks

C2. Why must you reject sin x = 2 when solving in [0, 2π]? [2]

Ans. The sine of a real angle never exceeds 1, so that factor has no solution and contributes nothing to the answer.

Quadratic equations 2 marks

C3. Why does sin x = 1 give only one solution in [0, 2π]? [2]

Ans. The line y = 1 touches the sine curve only at x = π/2; the second branch would fall outside the interval.

Quadratic equations 2 marks

C4. What does a sketch of both graphs tell you about an interval equation? [2]

Ans. The number of intersections is exactly the number of solutions, which shows at once whether a root has been missed.

Multiple angles 2 marks

C5. Why must the end points 0 and 2π be checked? [2]

Ans. The interval is closed, so a solution equal to 0 or 2π counts as valid, and both give the same angle.

Mixed equations 2 marks

C6. How do you handle an equation such as 2sin²x − 3sin x + 1 = 0? [2]

Ans. Treat sin x as a single unknown, factor or use the quadratic formula, then keep only values between −1 and 1 and solve for x in the given interval.
