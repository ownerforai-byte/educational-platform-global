7.4 · Simpson's One-Third Rule — two-mark conceptual answers

Topics The formula · Odd/even strip requirement · Error order · Comparing with the trapezoidal rule

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

The formula 2 marks

C1. What is the idea behind Simpson's rule? [2]

Ans. Fit a parabola through every three consecutive ordinates instead of a chord, which follows the curvature of the graph much more closely.

Odd/even strip requirement 2 marks

C2. Write Simpson's rule formula. [2]

Ans. S = (h/3)[y₀ + yₙ + 4(odd ordinates) + 2(even interior ordinates)], with the end ordinates counted once.

Odd/even strip requirement 2 marks

C3. Why does Simpson's rule need an even number of strips? [2]

Ans. Each parabola uses three ordinates, so the strips are consumed two at a time and an odd strip would be left unpaired.

Error order 2 marks

C4. What is the order of the error in Simpson's rule? [2]

Ans. It is proportional to h⁴, so halving h reduces the error by about sixteen times — far better than the trapezoidal rule.

Error order 2 marks

C5. When is Simpson's rule exact? [2]

Ans. For polynomials up to degree three, because a cubic agrees with the parabola fit over a symmetric triple of points.

Comparing with the trapezoidal rule 2 marks

C6. Why is Simpson's rule usually preferred to the trapezoidal rule? [2]

Ans. For the same number of ordinates it is far more accurate, though it requires an even number of strips.
