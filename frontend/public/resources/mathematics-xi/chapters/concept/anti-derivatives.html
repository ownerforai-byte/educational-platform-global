6.7 · Anti-derivatives — two-mark conceptual answers

Topics Standard integrals · Substitution · By parts · Trigonometric integrals

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

Standard integrals 2 marks

C1. What is an antiderivative of f(x)? [2]

Ans. A function F(x) whose derivative is f(x). Every such F differs from any other by a constant.

Substitution 2 marks

C2. Why is the constant of integration necessary? [2]

Ans. All functions F(x) + C have the same derivative, so the antiderivative is a family of curves and dropping C loses every member but one.

Substitution 2 marks

C3. When should you use substitution? [2]

Ans. When the integrand contains a function together with (a multiple of) its derivative, so that the integral collapses into a standard power form.

By parts 2 marks

C4. When should you integrate by parts? [2]

Ans. When the integrand is a product of two different kinds of function, such as x ln x or x e^x, using ∫u dv = uv − ∫v du.

By parts 2 marks

C5. What is ∫(1/x) dx? [2]

Ans. ln|x| + C. The modulus is needed because the derivative formula holds for negative x as well.

Trigonometric integrals 2 marks

C6. Why is ∫x² dx = x³/3 + C? [2]

Ans. Because d/dx(x³/3) = x², which is exactly the power rule nn⁻¹ run backwards.
