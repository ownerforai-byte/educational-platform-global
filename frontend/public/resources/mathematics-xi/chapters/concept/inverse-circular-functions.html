2.1 · Inverse Circular Functions — two-mark conceptual answers

Topics Principal values · Inverse identities · Composition with trig functions · Simple equations

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

Principal values 2 marks

C1. Why must the domain of sin x be restricted before defining sin⁻¹? [2]

Ans. Sine is not one-one on ℝ, so it cannot be inverted there. On [−π/2, π/2] it is one-one and onto [−1, 1], which makes the inverse single-valued.

Principal values 2 marks

C2. What is the principal value range of sin⁻¹ x? [2]

Ans. sin⁻¹ x lies in [−π/2, π/2]; this is the branch chosen so that the answer is unique for each x in [−1, 1].

Inverse identities 2 marks

C3. Why is tan⁻¹ x + tan⁻¹ (1/x) = π/2 for x > 0? [2]

Ans. The two angles are complementary: if tan α = x then tan(π/2 − α) = 1/x, and both angles lie in the principal range.

Composition with trig functions 2 marks

C4. Express cos⁻¹ (−x) in terms of cos⁻¹ x. [2]

Ans. cos⁻¹(−x) = π − cos⁻¹ x, because the cosine of the supplementary angle is the negative of the cosine.

Composition with trig functions 2 marks

C5. Why can the formula tan⁻¹x + tan⁻¹y = tan⁻¹((x + y)/(1 − xy)) fail? [2]

Ans. It holds only when xy < 1. If xy > 1 the sum lies outside (−π/2, π/2), so a ±π correction must be added.

Simple equations 2 marks

C6. What is the range of cos⁻¹ x, and why? [2]

Ans. It is [0, π], the interval on which cos x decreases steadily from 1 to −1 and so is one-one.
