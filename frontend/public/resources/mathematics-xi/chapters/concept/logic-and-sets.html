1.1 · Logic and Sets — two-mark conceptual answers

Topics Statements and connectives · Truth values · Sets and Venn diagrams · Cardinality

Each question is the two-mark kind NEB asks at the start of the paper; the model answer is one or two precise sentences.

Statements and connectives 2 marks

C1. What is a statement in logic? [2]

Ans. A sentence that is either true or false, but never both. A command or a question, such as “Study mathematics”, is not a statement.

Truth values 2 marks

C2. When are two sets A and B equal? [2]

Ans. When they contain exactly the same elements, i.e. A ⊆ B and B ⊆ A. Order and repetition do not matter.

Sets and Venn diagrams 2 marks

C3. Why is the empty set a subset of every set? [2]

Ans. A ⊆ B means every element of A lies in B; the empty set has no element that could fail the test, so the condition holds vacuously.

Sets and Venn diagrams 2 marks

C4. What is the power set of a set with n elements? [2]

Ans. The set of all its subsets, written P(A). It has 2ⁿ members, because each element is either chosen or not.

Cardinality 2 marks

C5. State De Morgan's laws for sets. [2]

Ans. (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′: complementing reverses union and intersection.

Cardinality 2 marks

C6. What is the difference between A − B and B − A? [2]

Ans. A − B holds the elements of A that are not in B; B − A holds the elements of B that are not in A. They are equal only when both are empty.
