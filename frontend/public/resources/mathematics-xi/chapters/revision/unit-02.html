2. π/6, the only value in [−π/2, π/2].
3. 1, for every angle A.

5. [0, π].
6. sin 2A = 2 sin A cos A.
7. No: sin(π/6) = sin(5π/6), so two angles share one value.
8. −1/2, in the second quadrant.
9. π.
10. θ = 2nπ ± α, n ∈ ℤ.
11. Let sin⁻¹x = θ, so sin θ = x and cos(π/2 − θ) = x. Both angles lie in [0, π/2], hence cos⁻¹x = π/2 − θ and the sum is π/2.
12. tan⁻¹2 + tan⁻¹3 = π + tan⁻¹((2 + 3)/(1 − 6)) = π − π/4 = 3π/4, since xy = 6 > 1. Adding tan⁻¹1 = π/4 gives π.
13. 2 cos 4A sin A.
14. cos A = 4/5, so sin 2A = 2(3/5)(4/5) = 24/25.
15. cos(45° + 30°) = (√6 − √2)/4 ≈ 0.2588.
16. θ = π/6 and θ = 5π/6.
17. tan(45° − 30°) = (1 − 1/√3)/(1 + 1/√3) = 2 − √3.
18. The tangent of the sum is (1/2 + 1/3)/(1 − 1/6) = (5/6)/(5/6) = 1. Each angle is less than π/4, so their sum is exactly π/4.
19. sin 2A = 2tanA/(1 + tan²A) = (3/2)/(25/16) = 24/25.
20. From 4sin²18° + 2sin18° − 1 = 0, sin 18° = (√5 − 1)/4 ≈ 0.309.
21. sin 3A = sin(2A + A) = sin2A cosA + cos2A sinA = 2sinA cos²A + sinA(1 − 2sin²A). Replacing cos²A by 1 − sin²A gives 2sinA − 2sin³A + sinA − 2sin³A = 3sinA − 4sin³A.
22. (2sinθ − 1)(sinθ − 1) = 0, so sinθ = 1/2 gives θ = π/6, 5π/6 and sinθ = 1 gives θ = π/2. Three solutions.
23. tanθ = ±√3, so θ = π/3, 4π/3 (positive) and θ = 2π/3, 5π/3 (negative). Four solutions.
24. sin2θ − sinθ = 2cos(3θ/2)sin(θ/2) = 0. So sin(θ/2) = 0 ⇒ θ = 2nπ, or cos(3θ/2) = 0 ⇒ θ = (2n + 1)π/3. Hence θ = 2nπ or (2n + 1)π/3, n ∈ ℤ.
