17. R² = 100 + 100 + 2(100)(−1/2) = 100, so R = 10 N.
18. v = 0 + 4(3) = 12 m/s.
19. s = ½(4)(9) = 18 m.
20. For three concurrent forces in equilibrium, P/sin α = Q/sin β = R/sin γ, where each angle is opposite its force.
21. f(2) = −1 and f(3) = 16. x₁ = 2.5 with f = 5.625 > 0, so [2, 2.5]; x₂ = 2.25 with f ≈ 1.89 > 0, so [2, 2.25]. The root is about 2.09.
