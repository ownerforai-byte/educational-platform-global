10. 1, the volume of the unit cube.
11. Setting the dot product to zero: 2 − 2λ + 3 = 0 ⇒ λ = 5/2.
12. (i + j)·(j + k) = 1 and both lengths are √2, so cos θ = 1/2 and θ = 60°.
13. cos θ = 6/12 = 1/2, so θ = 60°.
14. Area = ½|i × j| = ½ square unit.
15. (1)/1 = 1 unit along i.
16. The second vector is exactly twice the first, so they are parallel and both start at the origin; the three points lie on one line.
17. 1, the volume of the unit cube.
18. a + b = −c gives 1 + 1 + 2a·b = 1, so a·b = −1/2.
19. ±(2/3, 1/3, −2/3), since the length is 3.
20. 5i.
21. Expanding by linearity gives six triple products. Those containing a repeated vector vanish, leaving (a, b, c), (b, c, a) and (c, a, b); each equals [a b c], so the sum is 2[a b c].
22. The determinant is 1(1·1 − 2·0) − 2(0 − 0) + 3(0 − 0) = 1, so the volume is 1 cubic unit.
23. AB = (1, 1, 1) and AC = (λ − 1, 2, 2). Collinearity needs AC = kAB, so k = 2 and λ − 1 = 2; hence λ = 3.
24. Let OA = a and OB = b. The diagonal OC has midpoint ½(a + b), and the diagonal AB has midpoint ½(a + b) as well. The two midpoints coincide, so the diagonals bisect each other.
