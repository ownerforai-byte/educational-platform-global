10. i²¹ = (i⁴)⁵ · i = i.
11. “If a number is not even, then it is not divisible by 4.” The contrapositive is logically equivalent to the original.
12. The inequality says the distance of x from 3 is less than 1, so x lies between 3 − 1 = 2 and 3 + 1 = 4.
13. y = 2x + 3 ⇒ x = (y − 3)/2, so f⁻¹(x) = (x − 3)/2.
14. x = −b/2a = 2 and y = 4 − 8 + 1 = −3, so the vertex is (2, −3), a minimum.
15. S = 20 · 21/2 = 210.
16. a = 1, r = 1/3, so S = 1/(1 − 1/3) = 3/2.
17. A² = [[7, 10], [15, 22]] and 5A = [[5, 10], [15, 20]], so the answer is [[2, 0], [0, 2]] = 2I.
18. x² = −4 ⇒ x = ±2i.
19. α² + β² = (α + β)² − 2αβ = 36 − 16 = 20 (roots 2 and 4).
20. (1 + i)² = 1 + 2i + i² = 2i, so |z| = 2.
21. Either 2x − 1 = x + 4 ⇒ x = 5, or 2x − 1 = −(x + 4) ⇒ 3x = −3 ⇒ x = −1. Both check, so x = 5, −1.
22. y = (x − 3)(x + 1) gives x-intercepts −1 and 3 and y-intercept −3; the vertex is (1, −4) and the axis is x = 1. The parabola opens upward.
23. Let the roots be m and m + 1. Then p = 2m + 1 and q = m(m + 1), so p² − 4q = 4m² + 4m + 1 − 4m² − 4m = 1.
24. D = −1 − 2 = −3, Dx = −5 − 1 = −6, Dy = 1 − 10 = −9, so x = 2 and y = 3. Check: 2 + 3 = 5 ✓, 4 − 3 = 1 ✓.
