Algebra of complex numbers Powers of i hard

H1.Simplify (1 + i)/(1 − i) and hence evaluate (1 + i)⁸. [5]

  1. H1. Multiply numerator and denominator by the conjugate 1 + i.
  2. H2. The quotient collapses to i.
  3. H3. Use (1 + i)² = 2i and raise that to the fourth power.

(1 + i)²/(1 + 1) = 2i/2 = i (1 + i)⁸ = [(1 + i)²]⁴ = (2i)⁴ = 16i⁴

(1 + i)/(1 − i) = i and (1 + i)⁸ = 16

Modulus and argument Modulus–argument hard

H2.Find the modulus and argument of z = −1 + i√3. [4]

  1. H1. |z| = √(x² + y²).
  2. H2. The point is in the second quadrant, so the argument is π minus the reference angle.
  3. H3. The reference angle satisfies tan α = √3.

|z| = √(1 + 3) = 2 α = tan⁻¹(√3) = π/3 arg z = π − π/3

|z| = 2, arg z = 2π/3

Roots and equations Square roots hard

H3.Find the square roots of 3 + 4i. [5]

  1. H1. Let √(3 + 4i) = x + iy, so x² − y² = 3 and 2xy = 4.
  2. H2. Also x² + y² = |3 + 4i| = 5.
  3. H3. Solve for x² and y², then keep the signs that make xy positive.

x² + y² = 5 and x² − y² = 3 ⇒ x² = 4, y² = 1 2xy = 4 > 0 ⇒ (x, y) = (2, 1) or (−2, −1)

√(3 + 4i) = ±(2 + i)

Polar form De Moivre hard

H4.Prove that (cos θ + i sin θ)³ = cos 3θ + i sin 3θ. [5]

  1. H1. Expand the cube with the binomial theorem.
  2. H2. Use i² = −1 and i³ = −i, then separate real and imaginary parts.
  3. H3. Apply the triple-angle identities.

cos³θ + 3i cos²θ sinθ − 3cosθ sin²θ − i sin³θ = (4cos³θ − 3cosθ) + i(3sinθ − 4sin³θ)

= cos 3θ + i sin 3θ (De Moivre's theorem for n = 3)

Modulus and argument Proof hard

H5.Prove that |z₁z₂| = |z₁||z₂| for any two complex numbers. [4]

  1. H1. Write each number in polar form r cis θ.
  2. H2. Multiply the moduli and add the arguments.
  3. H3. Read off the modulus of the product.

z₁z₂ = r₁r₂ cis(θ₁ + θ₂) modulus = r₁r₂ = |z₁||z₂|

|z₁z₂| = |z₁||z₂|; the arguments add

Polar form Polar form hard

H6.Express 1 + i in polar form and hence evaluate (1 + i)⁶. [5]

  1. H1. Compute |1 + i| = √2 and arg = tan⁻¹1.
  2. H2. Raise to the sixth power: modulus (√2)⁶, argument 6π/4.
  3. H3. Reduce 3π/2 to the standard position and write the value.

1 + i = √2 cis(π/4) (1 + i)⁶ = (√2)⁶ cis(3π/2) = 8(−i)

(1 + i)⁶ = −8i
