Polynomials Polynomial hard

H1.Differentiate y = x² + 3x − 2 from first principles. [5]

  1. H1. Write f(x + h) − f(x) and expand the square.
  2. H2. Cancel every term that is free of h.
  3. H3. Divide by h, then let h → 0.

[(x+h)² + 3(x+h) − 2 − (x² + 3x − 2)]/h = (2xh + h² + 3h)/h = 2x + 3 + h → 2x + 3

dy/dx = 2x + 3

Rational and root functions Root function hard

H2.Differentiate y = 1/√x from first principles. [5]

  1. H1. Form the difference quotient and put it over a common denominator.
  2. H2. Rationalise the numerator √x − √(x + h).
  3. H3. After cancelling h the denominator contains 2x√x.

[√x − √(x+h)]/[h√x√(x+h)] · [√x + √(x+h)]/[√x + √(x+h)] = −1/[√x√(x+h)(√x + √(x+h))] → −1/(2x√x)

dy/dx = −1/(2x^{3/2})

Trigonometric functions Trigonometric hard

H3.Differentiate y = sin 2x from first principles. [5]

  1. H1. Expand sin(2x + 2h) with the addition formula.
  2. H2. Group into sin2x(cos2h − 1) + cos2x sin2h.
  3. H3. Use (cos2h − 1)/h → 0 and sin2h/h → 2.

[sin2x(cos2h − 1) + cos2x sin2h]/h → sin2x·0 + cos2x·2

dy/dx = 2 cos 2x

Rational and root functions Root function hard

H4.Differentiate y = √(2x + 1) from first principles. [5]

  1. H1. Rationalise √(2x + 2h + 1) − √(2x + 1).
  2. H2. The numerator becomes 2h after rationalising.
  3. H3. Divide by h and let h → 0 in the surviving denominator.

2h/[h(√(2x+2h+1) + √(2x+1))] → 2/[2√(2x+1)]

dy/dx = 1/√(2x + 1)

Trigonometric functions Trigonometric hard

H5.Differentiate y = cos x from first principles. [4]

  1. H1. Expand cos(x + h) = cosx cosh − sinx sinh.
  2. H2. Separate the two standard limits (cosh − 1)/h and sinh/h.
  3. H3. The first tends to 0 and the second to 1.

[cosx(cosh − 1) − sinx sinh]/h → cosx·0 − sinx·1

dy/dx = −sin x

Polynomials Polynomial hard

H6.Differentiate y = (2x + 1)² from first principles and check the answer by expanding first. [5]

  1. H1. Treat the quotient as a difference of squares and factor.
  2. H2. One factor is 2h; divide it out.
  3. H3. Expand (2x + 1)² and differentiate term by term as a check.

[(2x + 2h + 1)² − (2x + 1)²]/h = 4(2x + 1) + 4h → 4(2x + 1) check: y = 4x² + 4x + 1 ⇒ y′ = 8x + 4

dy/dx = 8x + 4
