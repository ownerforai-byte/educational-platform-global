tan⁻¹2 + tan⁻¹3 = π + tan⁻¹(−1) = 3π/4 (since 2·3 > 1) tan⁻¹1 = π/4 sum = 3π/4 + π/4 = π

the sum is π

H2.Prove that tan⁻¹(1/2) + tan⁻¹(1/3) = π/4. [3]

  1. H1. Use the addition formula for two inverse tangents with ab < 1.
  2. H2. The numerator is 1/2 + 1/3 = 5/6 and the denominator 1 − 1/6 = 5/6.
  3. H3. Both angles are acute, so the sum stays in the principal range.

tan(sum) = (1/2 + 1/3)/(1 − 1/6) = (5/6)/(5/6) = 1 0 < sum < π/2

sum = tan⁻¹1 = π/4

H3.Solve sin⁻¹x = cos⁻¹x. [4]

  1. H1. Use sin⁻¹x + cos⁻¹x = π/2 for x in [−1, 1].
  2. H2. Replacing cos⁻¹x gives 2sin⁻¹x = π/2.
  3. H3. So sin⁻¹x = π/4 — now apply sine to both sides.

sin⁻¹x + cos⁻¹x = π/2 2sin⁻¹x = π/2 ⇒ sin⁻¹x = π/4 x = sin(π/4)

x = 1/√2

H4.Evaluate sin(2 tan⁻¹(3/4)). [4]

  1. H1. Let θ = tan⁻¹(3/4), so tan θ = 3/4 and θ is acute.
  2. H2. Use sin 2θ = 2tanθ/(1 + tan²θ).
  3. H3. 1 + tan²θ = 1 + 9/16 = 25/16.

sin2θ = 2(3/4)/(1 + 9/16) = (3/2)/(25/16) = 24/25

24/25

H5.Prove that 2tan⁻¹(1/3) + tan⁻¹(1/7) = π/4. [4]

  1. H1. First rewrite 2tan⁻¹(1/3) using 2tan⁻¹a = tan⁻¹(2a/(1 − a²)).
  2. H2. With a = 1/3 that gives tan⁻¹(3/4).
  3. H3. Then combine tan⁻¹(3/4) with tan⁻¹(1/7) and simplify.

2tan⁻¹(1/3) = tan⁻¹[(2/3)/(1 − 1/9)] = tan⁻¹(3/4) tan⁻¹(3/4) + tan⁻¹(1/7): (3/4 + 1/7)/(1 − 3/28) = (25/28)/(25/28) = 1

the sum is tan⁻¹1 = π/4

H6.Solve tan⁻¹((x − 1)/(x − 2)) + tan⁻¹((x + 1)/(x + 2)) = π/4. [5]

  1. H1. Apply the addition formula and set the tangent equal to tan(π/4) = 1.
  2. H2. The numerator becomes 2x² − 4 and the common denominator x² − 4.
  3. H3. The denominator of the formula is 1 − (x² − 1)/(x² − 4) = −3/(x² − 4).

[(x−1)(x+2) + (x+1)(x−2)]/[(x−2)(x+2)] = (2x² − 4)/(x² − 4) 1 − [(x−1)(x+1)]/[(x−2)(x+2)] = −3/(x² − 4) tan(sum) = (2x² − 4)/(−3) = 1

2x² = 1 ⇒ x = ±1/√2
