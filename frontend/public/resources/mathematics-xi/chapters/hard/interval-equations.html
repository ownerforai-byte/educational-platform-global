Quadratic equations Quadratic in range hard

H1.Solve 2sin²x + sin x − 1 = 0 for x ∈ [0, 2π]. [5]

  1. H1. Factor the quadratic in sin x.
  2. H2. (2sinx − 1)(sinx + 1) = 0 gives sinx = 1/2 or sinx = −1.
  3. H3. List only the values inside [0, 2π].

sinx = 1/2 ⇒ x = π/6, 5π/6 sinx = −1 ⇒ x = 3π/2

x = π/6, 5π/6, 3π/2

Multiple angles Multiple angles hard

H2.Solve cos 3x = 1/2 for x ∈ [0, π]. [5]

  1. H1. First solve for 3x: the principal solution is π/3, and cosine repeats every 2π.
  2. H2. So 3x = 2nπ ± π/3; with x ∈ [0, π] we need 3x ∈ [0, 3π].
  3. H3. The admissible values are 3x = π/3, 5π/3, 7π/3.

3x = π/3, 5π/3, 7π/3 (all ≤ 3π)

x = π/9, 5π/9, 7π/9

Multiple angles Multiple angles hard

H3.Solve sin 2x = cos 2x for x ∈ [0, π]. [4]

  1. H1. Divide by cos 2x where it is non-zero to get tan 2x = 1.
  2. H2. Then 2x = π/4 + nπ.
  3. H3. Keep only values with 0 ≤ x ≤ π, i.e. 0 ≤ 2x ≤ 2π.

tan2x = 1 ⇒ 2x = π/4, 5π/4

x = π/8, 5π/8

Linear equations Quadratic in range hard

H4.Solve tan²x = 3 for x ∈ [0, 2π). [4]

  1. H1. Take roots: tanx = √3 or tanx = −√3.
  2. H2. The principal solutions are π/3 and −π/3.
  3. H3. Add π repeatedly and keep the results below 2π.

tanx = √3 ⇒ x = π/3, 4π/3 tanx = −√3 ⇒ x = 2π/3, 5π/3

x = π/3, 2π/3, 4π/3, 5π/3

Quadratic equations Quadratic in range hard

H5.Solve 2cos²x + 3cos x + 1 = 0 for x ∈ [0, 2π]. [5]

  1. H1. Factor the quadratic in cos x.
  2. H2. (2cosx + 1)(cosx + 1) = 0.
  3. H3. For cosx = −1/2 take the two quadrant values; cosx = −1 gives one value.

cosx = −1/2 ⇒ x = 2π/3, 4π/3 cosx = −1 ⇒ x = π

x = 2π/3, π, 4π/3

Mixed equations Auxiliary angle hard

H6.Solve sin x + cos x = 1 for x ∈ [0, 2π]. [5]

  1. H1. Combine the left side into a single sine: √2 sin(x + π/4).
  2. H2. Then sin(x + π/4) = 1/√2.
  3. H3. x + π/4 = π/4 or 3π/4 inside the required range.

√2 sin(x + π/4) = 1 ⇒ sin(x + π/4) = 1/√2 x + π/4 = π/4, 3π/4

x = 0 or x = π/2
