H1.Estimate ∫₀¹ x³ dx with the trapezoidal rule using h = 0.25. [5]

  1. H1. Four strips mean five ordinates: 0, 0.015625, 0.125, 0.421875, 1.
  2. H2. Multiply h/2 by (first + last + 2 × the middle sum).
  3. H3. The middle sum is 0.015625 + 0.125 + 0.421875 = 0.5625.

= 0.125[0 + 1 + 2(0.5625)] = 0.125(2.125)

≈ 0.2656 (exact 0.25, error 0.0156)

H2.Estimate ∫₁² dx/x with the trapezoidal rule using h = 0.25. [5]

  1. H1. Ordinates: 1, 0.8, 0.6667, 0.5714, 0.5.
  2. H2. Middle sum = 0.8 + 0.6667 + 0.5714 = 2.0381.
  3. H3. Multiply 0.125 by (1 + 0.5 + 2 × 2.0381).

= 0.125[1.5 + 4.0762] = 0.125(5.5762)

≈ 0.6970 (exact ln 2 = 0.6931)

H3.For ∫₀¹ x² dx show numerically that halving h reduces the error by a factor of 4. [5]

  1. H1. h = 0.5 gives ordinates 0, 0.25, 1.
  2. H2. h = 0.25 gives ordinates 0, 0.0625, 0.25, 0.5625, 1.
  3. H3. Compare each error with the exact value 1/3.

h = 0.5: 0.25[0 + 1 + 2(0.25)] = 0.375, error 0.0417 h = 0.25: 0.125[1 + 2(0.875)] = 0.34375, error 0.01042

error falls from 0.0417 to 0.0104 — a factor of 4, as h² predicts

H4.Estimate ∫₀^{π/2} sin x dx with the trapezoidal rule using h = π/4. [4]

  1. H1. Ordinates are sin 0 = 0, sin(π/4) = 0.7071, sin(π/2) = 1.
  2. H2. Here h/2 = π/8.
  3. H3. = (π/8)[0 + 1 + 2(0.7071)].

= 0.3927 × 2.4142

≈ 0.9481 (exact 1, error about 0.052)

The formula Exactness hard

H5.Show that the trapezoidal rule is exact for f(x) = 2x + 1 on [0, 2] with h = 1. [4]

  1. H1. Ordinates: f(0) = 1, f(1) = 3, f(2) = 5.
  2. H2. Apply (h/2)[y₀ + yₙ + 2Σ middle].
  3. H3. Compare with the exact integral ∫₀²(2x + 1)dx.

= 0.5[1 + 5 + 2(3)] = 0.5(12) = 6 exact = [x² + x]₀² = 6

both are 6 — the rule is exact for every linear function

The formula Derivation hard

H6.Derive the trapezoidal rule from the areas of trapeziums. [4]

  1. H1. Split [a, b] into n strips of width h.
  2. H2. The i-th strip is a trapezium with parallel sides y_i and y_{i+1}.
  3. H3. Its area is (h/2)(y_i + y_{i+1}); add all strips.

Σ (h/2)(y_i + y_{i+1}) = (h/2)[y₀ + 2y₁ + 2y₂ + … + 2y_{n−1} + yₙ]

the end ordinates appear once and every interior ordinate twice
