Cardinality Venn / cardinality hard

H1.In a survey of 100 students, 60 like mathematics, 45 like physics and 20 like both. Find how many like exactly one subject and how many like neither. [4]

  1. H1. Draw two overlapping circles and write 20 in the overlap.
  2. H2. Subtract 20 from each single count to get the exclusive parts: 40 and 25.
  3. H3. Everything inside the circles is 40 + 20 + 25; subtract that from 100.

only maths = 60 − 20 = 40 only physics = 45 − 20 = 25 at least one = 40 + 20 + 25 = 85 neither = 100 − 85 = 15

exactly one = 65 students; neither = 15 students

Sets and Venn diagrams Set proof hard

H2.Prove by set laws that A − (B ∪ C) = (A − B) ∩ (A − C). [4]

  1. H1. Rewrite every set difference using intersection and complement.
  2. H2. Apply De Morgan's law to (B ∪ C)′.
  3. H3. Use idempotence to split A ∩ A into the two pieces you need.

A − (B ∪ C) = A ∩ (B ∪ C)′ = A ∩ (B′ ∩ C′) = (A ∩ B′) ∩ (A ∩ C′) = (A − B) ∩ (A − C)

proved: the two set expressions are identical for every A, B, C

Truth values Truth table hard

H3.Show that (p → q) ↔ (¬q → ¬p) is a tautology. [3]

  1. H1. Build a truth table with columns p, q, p → q, ¬q, ¬p, ¬q → ¬p.
  2. H2. Compare the two implication columns row by row.
  3. H3. A biconditional is true exactly when its two sides agree.

p q | p→q | ¬q→¬p T T | T | T T F | F | F F T | T | T F F | T | T the two columns are identical, so the biconditional is always T

tautology — the contrapositive is logically equivalent to the implication

Cardinality Counting hard

H4.A set A has 7 elements. Find (i) the number of subsets, (ii) the number containing a fixed element x, (iii) the number with exactly 3 elements. [4]

  1. H1. Every element is either in or out, so the total is a power of 2.
  2. H2. Fix x inside, then each of the other 6 elements is still free.
  3. H3. Choosing exactly 3 means choosing 3 from 7.

(i) 2⁷ = 128 (ii) 2⁶ = 64 (iii) C(7,3) = 7·6·5/3·2·1 = 35

(i) 128 (ii) 64 (iii) 35

Truth values Logic proof hard

H5.Prove that p → (q ∧ r) ≡ (p → q) ∧ (p → r). [4]

  1. H1. Replace each implication using A → B ≡ ¬A ∨ B.
  2. H2. The left side becomes ¬p ∨ (q ∧ r).
  3. H3. Distribute the disjunction over the conjunction.

p → (q ∧ r) ≡ ¬p ∨ (q ∧ r) ≡ (¬p ∨ q) ∧ (¬p ∨ r) ≡ (p → q) ∧ (p → r)

equivalent — ∨ distributes over ∧

Cardinality Word problem hard

H6.In a class of 40 students, 25 play football, 20 play cricket and 8 play neither game. How many play both? [3]

  1. H1. Students playing at least one game = 40 − 8.
  2. H2. Apply inclusion–exclusion: |F ∪ C| = |F| + |C| − |F ∩ C|.
  3. H3. Solve 32 = 25 + 20 − both.

at least one = 40 − 8 = 32 both = 25 + 20 − 32 = 13

13 students play both games
