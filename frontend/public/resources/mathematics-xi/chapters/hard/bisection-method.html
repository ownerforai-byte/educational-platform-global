Bisection steps Iteration hard

H1.Apply three bisection steps to x³ − x − 1 = 0 on [1, 2]. [5]

  1. H1. First confirm the sign change: f(1) = −1 and f(2) = 5.
  2. H2. Take midpoints 1.5, then 1.25 or 1.75 depending on the sign of f(1.5).
  3. H3. Keep the half-bracket in which the sign change survives.

f(1) = −1, f(2) = 5 x₁ = 1.5, f = 0.875 > 0 ⇒ [1, 1.5] x₂ = 1.25, f = −0.2969 < 0 ⇒ [1.25, 1.5] x₃ = 1.375, f = 0.2246 > 0 ⇒ [1.25, 1.375]

root ≈ 1.31, trapped in [1.25, 1.375]

Accuracy and error Accuracy hard

H2.An interval of width 1 is used for bisection. How many steps give an error below 0.005? [4]

  1. H1. The error bound after n steps is width/2ⁿ.
  2. H2. Solve 1/2ⁿ < 0.005, i.e. 2ⁿ > 200.
  3. H3. 2⁷ = 128 is too small; 2⁸ = 256 works.

2ⁿ > 200 ⇒ n ≥ 8

8 steps

Sign-change test Reasoning hard

H3.Why must f be continuous for the bisection method to be valid? [4]

  1. H1. The method only uses the signs of f at the ends of a bracket.
  2. H2. A sign change guarantees a root only if the graph does not jump.
  3. H3. That guarantee is the intermediate value theorem.

f(a)f(b) < 0 plus continuity ⇒ some c in (a, b) has f(c) = 0 without continuity the graph can jump over the axis

continuity is what turns a sign change into a guaranteed root

Bisection steps Iteration hard

H4.Solve x² − 5 = 0 on [2, 3] using two bisection steps. [4]

  1. H1. f(2) = −1 and f(3) = 4.
  2. H2. x₁ = 2.5 gives f = 1.25 > 0, so the bracket shrinks to [2, 2.5].
  3. H3. x₂ = 2.25 gives f = 0.0625 > 0.

x₁ = 2.5, f = 1.25 > 0 ⇒ [2, 2.5] x₂ = 2.25, f = 0.0625 > 0 ⇒ [2, 2.25]

root ≈ 2.24, inside [2, 2.25]

Iteration tables Iteration table hard

H5.Build a four-row bisection table for x² − 5 = 0 on [2, 3]. [5]

  1. H1. Each row records the bracket, its midpoint and the sign of f at the midpoint.
  2. H2. Replace the endpoint whose f has the same sign as f(midpoint).
  3. H3. Continue until four rows are filled.

x₁ = 2.5, f = +1.25 ⇒ [2, 2.5] x₂ = 2.25, f = +0.0625 ⇒ [2, 2.25] x₃ = 2.125, f = −0.4844 ⇒ [2.125, 2.25] x₄ = 2.1875, f = −0.2148 ⇒ [2.1875, 2.25]

after 4 rows the root lies in [2.1875, 2.25]

Accuracy and error Accuracy hard

H6.Compare the theoretical error after four bisection steps with the actual bracket width in the previous problem. [4]

  1. H1. The start interval has width 1.
  2. H2. Theory: error ≤ 1/2⁴.
  3. H3. Measure the final bracket 2.1875 to 2.25.

theoretical bound = 1/16 = 0.0625 actual width = 2.25 − 2.1875 = 0.0625

they agree exactly — halving the bracket each step is the whole method
