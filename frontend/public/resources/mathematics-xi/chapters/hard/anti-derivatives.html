By parts By parts hard

H1.Evaluate ∫ x e^{2x} dx. [5]

  1. H1. Integrate by parts with u = x and dv = e^{2x} dx.
  2. H2. Then v = e^{2x}/2 and du = dx.
  3. H3. The remaining integral is a simple exponential.

= x·e^{2x}/2 − (1/2)∫e^{2x}dx = x e^{2x}/2 − e^{2x}/4 + C

(e^{2x}/4)(2x − 1) + C

By parts By parts hard

H2.Evaluate ∫ x² ln x dx. [5]

  1. H1. Take u = ln x so that differentiating removes the logarithm.
  2. H2. Then dv = x² dx and v = x³/3.
  3. H3. The remaining integral is a plain power of x.

= (x³/3)lnx − ∫(x³/3)(1/x)dx = (x³/3)lnx − (1/3)(x³/3) + C

(x³/3) ln x − x³/9 + C

Trigonometric integrals Trigonometric hard

H3.Evaluate ∫ sin²x dx. [4]

  1. H1. A square of sine must be linearised first.
  2. H2. Use sin²x = (1 − cos 2x)/2.
  3. H3. Integrate term by term: ∫cos 2x dx = sin 2x/2.

= (1/2)∫(1 − cos2x)dx = x/2 − sin2x/4 + C

x/2 − sin 2x/4 + C

Substitution Substitution / partial fractions hard

H4.Evaluate ∫ dx/(x² − a²). [5]

  1. H1. Factor the denominator and split into partial fractions.
  2. H2. 1/(x² − a²) = (1/2a)[1/(x − a) − 1/(x + a)].
  3. H3. Integrate each piece to a logarithm and combine.

= (1/2a)[∫dx/(x−a) − ∫dx/(x+a)] = (1/2a)[ln|x−a| − ln|x+a|] + C

(1/2a) ln|(x − a)/(x + a)| + C

By parts Recognition hard

H5.Evaluate ∫ eˣ(sin x + cos x) dx. [4]

  1. H1. Look for a product rule in reverse: eˣ times a bracket.
  2. H2. Check d/dx(eˣ sin x).
  3. H3. If the derivative matches the integrand exactly, you are done.

d/dx(eˣ sinx) = eˣ sinx + eˣ cosx = eˣ(sinx + cosx)

eˣ sin x + C

Substitution Algebraic simplification hard

H6.Evaluate ∫ x/(x + 1) dx. [4]

  1. H1. Make the degree of the numerator match by writing x = (x + 1) − 1.
  2. H2. Split into 1 − 1/(x + 1).
  3. H3. Integrate term by term.

= ∫[1 − 1/(x+1)]dx = x − ln|x+1| + C

x − ln|x + 1| + C
