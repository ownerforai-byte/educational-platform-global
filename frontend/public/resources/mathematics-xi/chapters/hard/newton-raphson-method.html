The formula The formula hard

H1.Apply one Newton–Raphson step to x² − 7 = 0 starting at x₀ = 2.5. [4]

  1. H1. Write f(x) = x² − 7 and f′(x) = 2x.
  2. H2. x₁ = x₀ − f(x₀)/f′(x₀).
  3. H3. f(2.5) = −0.75 and f′(2.5) = 5.

x₁ = 2.5 − (−0.75)/5 = 2.5 + 0.15

x₁ = 2.65

Iteration steps Iteration hard

H2.Apply one Newton–Raphson step to x³ − 2x − 5 = 0 from x₀ = 2. [4]

  1. H1. f(2) = 8 − 4 − 5.
  2. H2. f′(x) = 3x² − 2, so f′(2) = 10.
  3. H3. Subtract f/f′ from x₀.

x₁ = 2 − (−1)/10 = 2 + 0.1

x₁ = 2.1

Iteration steps Iteration hard

H3.Use one Newton–Raphson step on cos x = x from x₀ = 0.5. [5]

  1. H1. Put f(x) = cos x − x, so f′(x) = −sin x − 1.
  2. H2. f(0.5) = 0.8776 − 0.5 = 0.3776 and f′(0.5) = −1.4794.
  3. H3. x₁ = 0.5 − 0.3776/(−1.4794).

x₁ = 0.5 + 0.2552

x₁ ≈ 0.755 (the root is near 0.739)

Convergence Proof hard

H4.Show that Newton–Raphson applied to x² − a = 0 gives x₁ = (x₀ + a/x₀)/2. [5]

  1. H1. f(x) = x² − a and f′(x) = 2x.
  2. H2. x₁ = x₀ − (x₀² − a)/(2x₀).
  3. H3. Split the fraction and simplify.

x₁ = x₀ − x₀/2 + a/(2x₀) = x₀/2 + a/(2x₀)

x₁ = (x₀ + a/x₀)/2 — the Babylonian square-root iteration

Comparison with bisection Comparison hard

H5.For √2, compare the number of steps Newton–Raphson and bisection need to reach three decimals. [5]

  1. H1. Newton from x₀ = 1.5: x₁ = (1.5 + 2/1.5)/2.
  2. H2. Continue: 1.4167, then 1.41422.
  3. H3. Bisection halves the error every step, so it needs about ten steps.

Newton: 1.5 → 1.4167 → 1.41422 → 1.414213… bisection on [1,2]: after 10 steps width = 1/1024 ≈ 0.001

Newton: 3 steps; bisection: about 10 steps

H6.Apply one Newton–Raphson step to x³ − 8 = 0 from x₀ = 2.1. [4]

  1. H1. f(2.1) = 9.261 − 8 = 1.261.
  2. H2. f′(x) = 3x², so f′(2.1) = 13.23.
  3. H3. x₁ = 2.1 − 1.261/13.23.

x₁ = 2.1 − 0.0953

x₁ ≈ 2.0047
