Distance between parallel lines Parallel lines hard

H1.Find the distance between the parallel lines 3x − 4y + 7 = 0 and 6x − 8y − 5 = 0. [4]

  1. H1. The coefficients must be identical before the formula applies.
  2. H2. Divide the second line by 2: 3x − 4y − 5/2 = 0.
  3. H3. Use |c₁ − c₂|/√(a² + b²) with √(9 + 16) = 5.

|7 − (−5/2)|/5 = (19/2)/5

distance = 19/10 = 1.9 units

H2.Find the bisector of the angle between 4x + 3y − 6 = 0 and 3x − 4y + 8 = 0 that contains the point (1, 1). [5]

  1. H1. Substitute (1, 1) into both lines to see whether the values have the same sign.
  2. H2. Both give 1/5 and 7/5, so the region corresponds to the (+) = (+) bisector.
  3. H3. Write (4x + 3y − 6)/5 = (3x − 4y + 8)/5 and simplify.

at (1,1): 1/5 > 0 and 7/5 > 0 ⇒ (4x + 3y − 6)/5 = (3x − 4y + 8)/5 4x + 3y − 6 = 3x − 4y + 8

x + 7y − 14 = 0

Perpendicular distance Perpendicular distance hard

H3.Find the foot of the perpendicular from (2, 1) to the line 3x − 4y + 5 = 0. [5]

  1. H1. A line perpendicular to 3x − 4y + 5 = 0 has direction (3, −4).
  2. H2. Write the foot as (2 + 3t, 1 − 4t).
  3. H3. Force that point to satisfy the given line and solve for t.

3(2 + 3t) − 4(1 − 4t) + 5 = 0 6 + 9t − 4 + 16t + 5 = 0 ⇒ 25t + 7 = 0 ⇒ t = −7/25 foot = (2 − 21/25, 1 + 28/25)

(29/25, 53/25)

Perpendicular distance Distance formula hard

H4.Find k so that the line 4x + 3y + k = 0 is at a distance of 2 units from (1, 1). [4]

  1. H1. Use the point–line distance formula with √(16 + 9) = 5.
  2. H2. |4 + 3 + k|/5 = 2 ⇒ |k + 7| = 10.
  3. H3. A modulus equation gives two values of k.

|k + 7| = 10 k + 7 = 10 or k + 7 = −10

k = 3 or k = −17

Bisector of a given region Locus hard

H5.A point moves so that its distance from (1, 0) equals its distance from the line x = −1. Find the locus. [5]

  1. H1. Let the moving point be P(x, y).
  2. H2. Its distance from the line x = −1 is |x + 1|.
  3. H3. Square both distances and simplify.

√((x − 1)² + y²) = |x + 1| (x − 1)² + y² = (x + 1)² x² − 2x + 1 + y² = x² + 2x + 1

y² = 4x — a parabola with focus (1, 0) and directrix x = −1

H6.Find the distance of the point of intersection of 2x + 3y = 7 and 3x − 4y = 1 from the line 5x − 12y + 5 = 0. [5]

  1. H1. Solve the two-line system first.
  2. H2. Eliminate y by multiplying the equations by 4 and 3 and adding.
  3. H3. Substitute the intersection into the distance formula with √(25 + 144) = 13.

8x + 12y = 28 and 9x − 12y = 3 ⇒ 17x = 31 ⇒ x = 31/17, y = 19/17 |5(31/17) − 12(19/17) + 5|/13 = |12/17|/13
