Homogeneous pairs Homogeneous pair hard

H1.Find the separate equations of the pair of lines x² − 5xy + 6y² = 0. [4]

  1. H1. A homogeneous quadratic in x and y factorises into two linear factors through the origin.
  2. H2. Look for two numbers whose product is 6 and whose sum is −5.
  3. H3. Factor as (x − 2y)(x − 3y) = 0.

x² − 5xy + 6y² = (x − 2y)(x − 3y) = 0

x = 2y and x = 3y

Condition for a real pair Condition for a real pair hard

H2.Find k so that x² + kxy + 4y² = 0 represents two coincident lines. [4]

  1. H1. Compare with ax² + 2hxy + by² = 0 to read a = 1, 2h = k, b = 4.
  2. H2. Coincident lines need h² = ab.
  3. H3. Solve (k/2)² = 4.

h = k/2, h² = ab = 4 k²/4 = 4 ⇒ k² = 16

k = ±4

Angle between a pair Angle between a pair hard

H3.Find the acute angle between the lines 2x² − 7xy + 3y² = 0. [5]

  1. H1. Identify a = 2, b = 3 and 2h = −7, so h = −7/2.
  2. H2. Use tanθ = 2√(h² − ab)/(a + b).
  3. H3. h² = 49/4 and ab = 6, so h² − ab = 25/4.

tanθ = 2·(5/2)/5 = 1

θ = 45°

Slopes and special cases Special cases hard

H4.Find the pair of lines through the origin perpendicular to the pair x² − 4xy + y² = 0. [5]

  1. H1. For ax² + 2hxy + by² = 0 with slopes m₁, m₂, perpendicular lines have slopes −1/m₁, −1/m₂.
  2. H2. Replacing y by x and x by −y produces the perpendicular pair.
  3. H3. That maps ax² + 2hxy + by² to bx² − 2hxy + ay².

a = 1, 2h = −4, b = 1 perpendicular pair: bx² − 2hxy + ay² = 0 = x² + 4xy + y²

x² + 4xy + y² = 0

H5.Show that x² + 2xy + y² = 0 represents coincident lines and state the angle between them. [4]

  1. H1. The expression is a perfect square.
  2. H2. (x + y)² = 0 gives x + y = 0 twice.
  3. H3. Coincident lines have no angle between them.

x² + 2xy + y² = (x + y)² = 0 h² = 1 = ab

the line x + y = 0 counted twice; angle 0°

H6.Find h so that the angle between the lines of x² + hxy + y² = 0 is 60°. [5]

  1. H1. Here a = 1, b = 1 and 2h is the coefficient of xy, so h_theory = h/2.
  2. H2. tanθ = 2√(h_theory² − ab)/(a + b) with θ = 60°.
  3. H3. √3 = √(h²/4 − 1) after simplifying the 2s.

tan60° = √3 = 2√(h²/4 − 1)/2 3 = h²/4 − 1 ⇒ h² = 16

h = ±4
