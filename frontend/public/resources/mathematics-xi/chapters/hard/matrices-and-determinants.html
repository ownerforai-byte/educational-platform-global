Solving systems Cramer's rule hard

H1.Solve 3x + 4y = 10 and 2x − y = 3 by Cramer's rule. [5]

  1. H1. Write the coefficient determinant D first.
  2. H2. Replace the x-column by the constants for Dₓ, the y-column for D_y.
  3. H3. Divide each determinant by D.

D = |3 4; 2 −1| = −3 − 8 = −11 Dₓ = |10 4; 3 −1| = −10 − 12 = −22 D_y = |3 10; 2 3| = 9 − 20 = −11 x = Dₓ/D = 2, y = D_y/D = 1

x = 2, y = 1

Inverse of a matrix Matrix inverse hard

H2.Find the inverse of A = [[2, 1], [5, 3]]. [4]

  1. H1. Check the determinant: 2·3 − 1·5.
  2. H2. For a 2×2 matrix, swap the diagonal entries and negate the other two.
  3. H3. Divide the adjugate by the determinant.

det A = 6 − 5 = 1 adj A = [[3, −1], [−5, 2]]

A⁻¹ = [[3, −1], [−5, 2]]

Inverse of a matrix Proof hard

H3.Prove that (AB)⁻¹ = B⁻¹A⁻¹ for invertible matrices A and B. [4]

  1. H1. It is enough to show that B⁻¹A⁻¹ multiplies AB to the identity.
  2. H2. Use associativity to regroup the product.
  3. H3. BB⁻¹ = I and AA⁻¹ = I finish it.

(AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AIA⁻¹ = AA⁻¹ = I (B⁻¹A⁻¹)(AB) = B⁻¹(A⁻¹A)B = B⁻¹B = I

both products equal I, so (AB)⁻¹ = B⁻¹A⁻¹ — the order reverses

Determinants Determinant hard

H4.Evaluate |1 2 3; 2 4 6; 7 8 9| and justify the answer without expanding. [3]

  1. H1. Compare the first two rows.
  2. H2. Row 2 is a multiple of row 1.
  3. H3. A determinant with proportional rows is zero.

R₂ = 2R₁ ⇒ the rows are linearly dependent ⇒ det = 0

0 — the determinant vanishes because two rows are proportional

Algebra of matrices Matrix algebra hard

H5.If A = [[1, 2], [3, 4]] verify that A² − 5A − 2I = 0. [5]

  1. H1. Compute A² by matrix multiplication.
  2. H2. Compute 5A and 2I separately.
  3. H3. Subtract entry by entry.

A² = [[7, 10], [15, 22]] 5A = [[5, 10], [15, 20]] 2I = [[2, 0], [0, 2]] A² − 5A − 2I = [[0, 0], [0, 0]]

verified: A² − 5A − 2I = 0 (Cayley–Hamilton for 2×2)

Solving systems Matrix method hard

H6.Solve x + y = 3 and 2x + 3y = 8 using a matrix inverse. [5]

  1. H1. Write the system as AX = B with A = [[1, 1], [2, 3]].
  2. H2. det A = 1, so A⁻¹ = [[3, −1], [−2, 1]].
  3. H3. Multiply A⁻¹ by B to get X.

X = A⁻¹B = [[3, −1], [−2, 1]]·[[3], [8]] = [[9 − 8], [−6 + 8]] = [[1], [2]]

x = 1, y = 2
