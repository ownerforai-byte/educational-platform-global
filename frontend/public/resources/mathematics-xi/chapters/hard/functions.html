Domain and range Domain and range hard

H1.Find the domain and range of f(x) = √(x² − 4). [4]

  1. H1. A square root needs a non-negative radicand.
  2. H2. x² ≥ 4 gives |x| ≥ 2 — two separate pieces of the line.
  3. H3. The output of a square root is never negative and is unbounded above.

x² − 4 ≥ 0 ⇒ x ≤ −2 or x ≥ 2 f(x) ≥ 0 and f(x) → ∞ as |x| → ∞

domain (−∞, −2] ∪ [2, ∞); range [0, ∞)

Composite functions Composite hard

H2.If f(x) = 2x + 3 and g(x) = x², find (g∘f)(x) and (f∘g)(x) and show they are different. [4]

  1. H1. (g∘f)(x) means g(f(x)): the inner function is f.
  2. H2. Substitute 2x + 3 into x² for one, and x² into 2x + 3 for the other.
  3. H3. Expand the first result and compare term by term.

(g∘f)(x) = (2x + 3)² = 4x² + 12x + 9 (f∘g)(x) = 2x² + 3

they differ (4x² + 12x + 9 ≠ 2x² + 3): composition is not commutative

Inverse functions Inverse function hard

H3.Show that f(x) = (x + 1)/(x − 1) is its own inverse. [4]

  1. H1. Write y = (x + 1)/(x − 1) and solve for x in terms of y.
  2. H2. Cross-multiply: y(x − 1) = x + 1.
  3. H3. Collect the x terms on one side and divide.

yx − y = x + 1 x(y − 1) = y + 1 x = (y + 1)/(y − 1)

f⁻¹(x) = (x + 1)/(x − 1) = f(x) — an involution

Domain and range Domain hard

H4.Find the domain of f(x) = log(x − 1) + √(5 − x). [4]

  1. H1. A logarithm needs a strictly positive argument.
  2. H2. A square root needs a non-negative argument.
  3. H3. The domain is the intersection of x > 1 and x ≤ 5.

x − 1 > 0 ⇒ x > 1 5 − x ≥ 0 ⇒ x ≤ 5 intersection: 1 < x ≤ 5

domain (1, 5]

Composite functions Composite hard

H5.If f(x) = x/(x + 1), find and simplify f(f(x)). [3]

  1. H1. Replace every x in the formula by x/(x + 1).
  2. H2. The new denominator is x/(x + 1) + 1.
  3. H3. Clear the compound fraction by multiplying by (x + 1).

f(f(x)) = [x/(x+1)] / [x/(x+1) + 1] = [x/(x+1)] / [(x + x + 1)/(x+1)] = x/(2x + 1)

f(f(x)) = x/(2x + 1), with x ≠ −1, −1/2

Inverse functions Bijection hard

H6.Show that f(x) = x³ is one-one and onto on ℝ, then write f⁻¹. [4]

  1. H1. One-one: suppose f(a) = f(b) and take cube roots.
  2. H2. Onto: given any real y, name an x with x³ = y.
  3. H3. For the inverse, swap x and y and solve.

a³ = b³ ⇒ a = b (one-one) for every y ∈ ℝ, f(y^{1/3}) = y (onto) y = x³ ⇒ x = y^{1/3}

bijective; f⁻¹(x) = x^{1/3}
