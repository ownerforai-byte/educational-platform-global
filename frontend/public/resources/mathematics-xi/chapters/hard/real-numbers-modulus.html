Modulus and distance Modulus equation hard

H1.Solve |x − 2| + |x + 3| = 7. [5]

  1. H1. The two moduli change behaviour at x = −3 and x = 2, so split the line into three pieces.
  2. H2. On the middle piece test any value: the left side is constant there.
  3. H3. On each outer piece you get a linear equation; keep the root only if it lies in that piece.

x < −3: −(x−2) − (x+3) = 7 ⇒ −2x − 1 = 7 ⇒ x = −4 ✓ −3 ≤ x < 2: (x−2 is negative, x+3 positive) ⇒ 5 = 7 ✗ x ≥ 2: (x−2) + (x+3) = 7 ⇒ 2x + 1 = 7 ⇒ x = 3 ✓

x = −4 or x = 3

Surds and rationalisation Proof by contradiction hard

H2.Prove that √2 is irrational. [4]

  1. H1. Assume the opposite: √2 = p/q with p, q coprime positive integers.
  2. H2. Square both sides to get p² = 2q², so p² is even.
  3. H3. Show q must also be even, contradicting coprimality.

√2 = p/q ⇒ p² = 2q² ⇒ 2 | p² ⇒ 2 | p ⇒ p = 2k 4k² = 2q² ⇒ q² = 2k² ⇒ 2 | q p and q both even contradicts gcd(p, q) = 1

√2 cannot be written as a ratio of integers — it is irrational

Intervals Modulus inequality hard

H3.Solve |2x − 1| < 5 and give the answer as an interval. [3]

  1. H1. Use |u| < a ⇔ −a < u < a.
  2. H2. Write the double inequality −5 < 2x − 1 < 5.
  3. H3. Add 1 throughout, then divide by 2.

−5 < 2x − 1 < 5 −4 < 2x < 6 −2 < x < 3

x ∈ (−2, 3)

Inequalities Inequality proof hard

H4.Prove that for a > 0 and b > 0, (a + b)/2 ≥ √(ab). [4]

  1. H1. Start from a square that cannot be negative: (√a − √b)² ≥ 0.
  2. H2. Expand it to a − 2√(ab) + b ≥ 0.
  3. H3. Rearrange and divide by 2; check when equality holds.

(√a − √b)² ≥ 0 a − 2√(ab) + b ≥ 0 a + b ≥ 2√(ab) (a + b)/2 ≥ √(ab)

AM ≥ GM, with equality exactly when a = b

Modulus and distance Modulus equation hard

H5.Solve |x|² − 5|x| + 6 = 0. [4]

  1. H1. Notice that |x|² = x², and substitute t = |x| with t ≥ 0.
  2. H2. Factor t² − 5t + 6 = (t − 2)(t − 3).
  3. H3. Each positive t gives two values of x.

t = |x| ⇒ t² − 5t + 6 = 0 ⇒ t = 2 or t = 3 t = 2 ⇒ x = ±2 t = 3 ⇒ x = ±3

x = ±2, ±3

Inequalities Greatest integer hard

H6.Find all x for which [2x − 3] = 4, where [ ] denotes the greatest integer function. [4]

  1. H1. Translate: [y] = 4 means 4 ≤ y < 5.
  2. H2. Put y = 2x − 3 into that double inequality.
  3. H3. Solve 7 ≤ 2x < 8 and keep the half-open end.

4 ≤ 2x − 3 < 5 7 ≤ 2x < 8 3.5 ≤ x < 4

x ∈ [3.5, 4)
