The formula Applied hard

H1.Evaluate ∫₀² x³ dx by Simpson's rule with h = 0.5 and compare with the exact value. [5]

  1. H1. Four strips give ordinates 0, 0.125, 1, 3.375, 8.
  2. H2. Use (h/3)[y₀ + y₄ + 4(y₁ + y₃) + 2y₂].
  3. H3. The exact value is x⁴/4 = 4 at x = 2.

= (0.5/3)[0 + 8 + 4(3.5) + 2(1)] = (1/6)(24)

4 — exact, as Simpson's rule is for every cubic

Odd/even strip requirement Odd/even strips hard

H2.Estimate ∫₀¹ dx/(1 + x) using Simpson's rule with h = 0.25. [5]

  1. H1. Ordinates: 1, 0.8, 0.6667, 0.5714, 0.5.
  2. H2. 4(0.8 + 0.5714) + 2(0.6667) + 1.5 = 8.319.
  3. H3. Multiply by h/3 = 1/12.

= (0.25/3)[1.5 + 5.4857 + 1.3334] = 0.08333 × 8.3191

≈ 0.69326 (exact ln 2 = 0.69315 — five-figure accuracy)

The formula Exactness hard

H3.Show that Simpson's rule gives ∫₀¹ x² dx exactly with two strips. [4]

  1. H1. With h = 0.5 the ordinates are 0, 0.25, 1.
  2. H2. Weights are 1, 4, 1 and the multiplier is h/3.
  3. H3. (0.5/3)(0 + 1 + 4(0.25)).

= (0.5/3)(2) = 1/3

exact — x² is a parabola and the rule fits a parabola through the three points

Comparing with the trapezoidal rule Applied hard

H4.Estimate ∫₀^{π/2} sin x dx by Simpson's rule with h = π/4. [4]

  1. H1. Ordinates 0, 0.7071, 1; the multiplier is h/3 = π/12.
  2. H2. Only the middle ordinate gets weight 4.
  3. H3. = (π/12)(0 + 1 + 4(0.7071)).

= 0.2618 × 3.8284

≈ 1.0023 (exact 1, error about 0.0023 — much better than the trapezoidal 0.052)

Error order Error order hard

H5.Explain why Simpson's rule is exact for every cubic. [4]

  1. H1. The rule replaces three consecutive points by a parabola.
  2. H2. Its error term contains the fourth derivative f⁗.
  3. H3. For a cubic the fourth derivative is zero.

error ∝ (b − a)h⁴ f⁗ and f⁗ = 0 for any cubic

the error vanishes, so cubics are integrated exactly

Comparing with the trapezoidal rule Comparison hard

H6.Estimate ∫₀¹ dx/(1 + x²) by both rules with h = 0.25 and compare with π/4. [5]

  1. H1. Ordinates: 1, 0.94118, 0.8, 0.64, 0.5.
  2. H2. Trapezoidal: 0.125[1.5 + 2(2.38118)].
  3. H3. Simpson: (0.25/3)[1.5 + 4(1.58118) + 1.6].

trapezoidal ≈ 0.78280 Simpson ≈ 0.78539 exact π/4 = 0.785398

Simpson is accurate to five decimals; the trapezoidal rule is off by about 0.0026
