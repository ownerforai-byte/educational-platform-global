Equations reducible to quadratics Quadratic form hard

H1.Solve 2cos²θ + 3sinθ = 0 completely. [5]

  1. H1. Replace cos²θ by 1 − sin²θ so only sines remain.
  2. H2. The quadratic 2sin²θ − 3sinθ − 2 = 0 factorises as (2sinθ + 1)(sinθ − 2).
  3. H3. sinθ = 2 is impossible, so only sinθ = −1/2 survives.

2 − 2sin²θ + 3sinθ = 0 ⇒ 2sin²θ − 3sinθ − 2 = 0 (2sinθ + 1)(sinθ − 2) = 0 ⇒ sinθ = −1/2

θ = nπ − (−1)ⁿ π/6, n ∈ ℤ

tan θ = k tan θ = k hard

H2.Solve tan²θ = 3 completely. [4]

  1. H1. Take square roots to get tanθ = ±√3.
  2. H2. Both values are special angles: tan(π/3) = √3 and tan(−π/3) = −√3.
  3. H3. Tangent repeats every π, so each solution becomes a family.

tanθ = ±√3 = tan(±π/3)

θ = nπ ± π/3, n ∈ ℤ

sin θ = k sin θ = k hard

H3.Solve sin 3θ = sin 2θ completely. [5]

  1. H1. For sinA = sinB write A = nπ + (−1)ⁿB.
  2. H2. For even n: 3θ = nπ + 2θ, giving θ = nπ.
  3. H3. For odd n: 3θ = nπ − 2θ, giving 5θ = nπ with n odd.

3θ = nπ + (−1)ⁿ2θ n even: θ = nπ n odd: 5θ = nπ ⇒ θ = nπ/5 (n odd)

θ = nπ or θ = (2m + 1)π/5, n, m ∈ ℤ

Equations reducible to quadratics Quadratic form hard

H4.Solve cos 2θ = sin θ completely. [5]

  1. H1. Write sinθ = cos(π/2 − θ) or convert the left side to sines.
  2. H2. Using cos2θ = 1 − 2sin²θ gives 2sin²θ + sinθ − 1 = 0.
  3. H3. Factor: (2sinθ − 1)(sinθ + 1) = 0.

1 − 2sin²θ = sinθ ⇒ (2sinθ − 1)(sinθ + 1) = 0 sinθ = 1/2 or sinθ = −1

θ = nπ + (−1)ⁿ π/6 or θ = 2nπ − π/2

H5.Solve tan θ + cot θ = 2. [5]

  1. H1. Write both ratios in sines and cosines over a common denominator.
  2. H2. (sin²θ + cos²θ)/(sinθ cosθ) = 1/(sinθ cosθ).
  3. H3. So sinθ cosθ = 1/2, i.e. sin 2θ = 1.

1/(sinθ cosθ) = 2 ⇒ sinθ cosθ = 1/2 2sinθcosθ = 1 ⇒ sin2θ = 1 2θ = 2nπ + π/2

θ = nπ + π/4, n ∈ ℤ

tan θ = k Quadratic form hard

H6.Solve sec²θ = 2 tan θ. [4]

  1. H1. Use sec²θ = 1 + tan²θ.
  2. H2. The equation becomes tan²θ − 2tanθ + 1 = 0.
  3. H3. That is (tanθ − 1)² = 0, so the two roots coincide.

1 + tan²θ = 2tanθ ⇒ (tanθ − 1)² = 0 ⇒ tanθ = 1

θ = nπ + π/4, n ∈ ℤ
