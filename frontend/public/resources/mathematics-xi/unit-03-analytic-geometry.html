Unit 3 — Analytic Geometry

Mathematics XI (Mat. 007)  •  NEB Grade 11  •  20 teaching hours  •  Exercise solutions + conceptual bank

Three examinable layers: the distance from a point to a line and the two angle bisectors; pairs of straight lines (a second-degree equation split into two factors); and 3-D coordinates with direction cosines and ratios. Every question in this unit is a formula applied with correct signs — which is why sign slips dominate the lost marks.

Marks pattern. Expect one 2-mark distance or direction-cosine item, one 4-mark bisector or pair-of-lines item, and one 4–5 mark question combining a condition (find k, prove perpendicular) with the geometry.

Keep the two normalised forms separate in your head:

  • Distance: d = |a₁x₁ + b₁y₁ + c₁| / √(a₁² + b₁²) — one line, one point.
  • Bisector: (a₁x+b₁y+c₁)/√(a₁²+b₁²) = ±(a₂x+b₂y+c₂)/√(a₂²+b₂²) — two lines, both signs.

Exercise 3.1 — Straight line: distance and bisectors

Q1. Find the length of the perpendicular from (3, 4) to the line 3x + 4y − 5 = 0.

d = |ax₁ + by₁ + c| / √(a² + b²) = |3(3) + 4(4) − 5| / √(9 + 16) = |9 + 16 − 5| / 5 = 20/5 = 4

d = 4 units

Q2. Find the distance of (−2, 3) from 4x − 3y + 5 = 0.

d = |4(−2) − 3(3) + 5| / √(16 + 9) = |−8 − 9 + 5| / 5 = 12/5

d = 12/5 = 2.4 units

Q3. Find the distance of the origin from 3x − 4y + 10 = 0.

For the origin (0,0) only the constant term survives in the numerator:

d = |0 + 0 + 10| / √(9 + 16) = 10/5 = 2

d = 2 units

Q4. Find the distance between the parallel lines 3x + 4y = 7 and 3x + 4y = 12.

Rewrite with the same left side: 3x + 4y − 7 = 0 and 3x + 4y − 12 = 0. Two parallel lines give

d = |c₁ − c₂| / √(a² + b²) = |−7 + 12| / 5 = 5/5 = 1

d = 1 unit

Q5. Find the equations of the two bisectors of the angles between 3x + 4y − 5 = 0 and 5x − 12y + 7 = 0.

Normalise each line by its own √(a²+b²): 5 for the first, 13 for the second.

(3x + 4y − 5)/5 = ± (5x − 12y + 7)/13

Taking + :

13(3x+4y−5) = 5(5x−12y+7) 39x + 52y − 65 = 25x − 60y + 35 14x + 112y − 100 = 0 ⇒ 7x + 56y − 50 = 0

Taking − :

13(3x+4y−5) = −5(5x−12y+7) 39x + 52y − 65 = −25x + 60y − 35 64x − 8y − 30 = 0 ⇒ 32x − 4y − 15 = 0

7x + 56y − 50 = 0  and  32x − 4y − 15 = 0

Q6. Find the acute angle between 2x − y + 3 = 0 and x − 3y + 2 = 0.

Slopes: m₁ = 2 (from y = 2x + 3), m₂ = 1/3 (from y = x/3 + 2/3) tanθ = |(m₁ − m₂)/(1 + m₁m₂)| = |(2 − 1/3)/(1 + 2/3)| = |(5/3)/(5/3)| = 1

θ = 45°  (acute angle)

Q7. Find k if 2x + ky = 5 is perpendicular to 3x − 4y = 7.

Slopes: −2/k and 3/4 Perpendicular ⇒ (−2/k)(3/4) = −1 ⇒ −6/(4k) = −1 ⇒ 4k = 6 ⇒ k = 3/2

k = 3/2

Q8. Find the equation of the line through (1, 2) parallel to 3x + 4y = 7.

A parallel line keeps the same normal (a,b) and changes only the constant:

3(x−1) + 4(y−2) = 0 ⇒ 3x + 4y − 11 = 0

3x + 4y − 11 = 0

Q9. Do the origin and the point (5, 0) lie on the same side of 3x + 4y − 10 = 0?

Substitute both points into the left side; the signs of the results decide the side.

At (0,0): −10 < 0 At (5,0): 15 − 10 = 5 > 0

Opposite signs ⇒ the two points lie on opposite sides of the line.

Q10. Find the length of the perpendicular from (2, −1) to 3x − 4y + 5 = 0 and state its geometric meaning.

d = |3(2) − 4(−1) + 5| / 5 = |6 + 4 + 5|/5 = 15/5 = 3

The point is 3 units from the line; the perpendicular segment has length 3 and meets the line at its foot.

d = 3 units — the shortest (perpendicular) distance from the point to the line.

Exercise 3.2 — Pair of straight lines

Q1. Separate x² − 5xy + 6y² = 0 into its two lines.

x² − 5xy + 6y² = (x − 2y)(x − 3y) = 0

The pair is x = 2y and x = 3y.

Q2. Find the angle between the pair x² − 4xy + y² = 0.

For ax² + 2hxy + by² = 0: a = 1, 2h = −4 ⇒ h = −2, b = 1.

tanθ = 2√(h² − ab)/(a + b) = 2√(4 − 1)/(1 + 1) = 2√3/2 = √3

θ = 60° (and its supplement 120° for the other pair of arms)

Q3. Show that 2x² + 3xy − 2y² = 0 represents a pair of perpendicular lines.

2x² + 3xy − 2y² = (2x − y)(x + 2y) = 0 Lines: y = 2x and y = −x/2 Product of slopes: 2 × (−1/2) = −1

The lines are perpendicular; notice a + b = 2 + (−2) = 0, which is the perpendicularity condition.

Q4. Find the condition for ax² + 2hxy + by² = 0 to represent two perpendicular lines, and prove it.

Let the lines be y = m₁x and y = m₂x. Then ax² + 2hxy + by² = b(y − m₁x)(y − m₂x) Comparing coefficients: m₁ + m₂ = −2h/b, m₁m₂ = a/b Perpendicular ⇔ m₁m₂ = −1 ⇔ a/b = −1 ⇔ a + b = 0

The pair is perpendicular ⇔ a + b = 0  (proved)

Q5. Find k so that kx² + 8xy + 4y² = 0 represents (i) real distinct lines, (ii) coincident lines.

Here a = k, h = 4, b = 4. The lines are real when h² ≥ ab:

16 ≥ 4k ⇒ k ≤ 4 Distinct and real: k < 4 Coincident: k = 4, giving 4x² + 8xy + 4y² = 4(x + y)² = 0

(i) k < 4   (ii) k = 4

Q6. Show that x² + 2xy + y² − 4 = 0 represents a pair of parallel lines and find them.

x² + 2xy + y² = (x+y)² ⇒ (x+y)² = 4 ⇒ x + y = 2 or x + y = −2

Both lines have slope −1, so they are parallel; the distance between them is |2 − (−2)|/√2 = 4/√2 = 2√2.

x + y = 2 and x + y = −2 — parallel lines.

Q7. Find the joint equation of the two lines through the origin with slopes 2 and −3.

y = 2x ⇒ (2x − y) is a factor y = −3x ⇒ (3x + y) is a factor (2x − y)(3x + y) = 6x² + 2xy − 3xy − y² = 6x² − xy − y² = 0

6x² − xy − y² = 0

Q8. Verify the condition abc + 2fgh − af² − bg² − ch² = 0 for the pair x² + 2xy + y² − 4 = 0.

Compare with ax² + by² + 2hxy + 2gx + 2fy + c = 0: a = 1, b = 1, h = 1, g = 0, f = 0, c = −4.

abc = 1·1·(−4) = −4 2fgh = 0 −af² = 0, −bg² = 0 −ch² = −(−4)(1) = 4 Sum: −4 + 0 + 0 + 0 + 4 = 0 ✓

The condition is satisfied, consistent with the pair found in Q6.

Q9. Find k if one of the lines of 3x² + kxy − 2y² = 0 is x = y.

If x = y is a line of the pair, then (x − y) is a factor, so the equation vanishes when x = y. Substitute x = y:

3x² + kx² − 2x² = (3 + k − 2)x² = (1 + k)x² = 0 ⇒ k = −1

Check: 3x² − xy − 2y² = (3x + 2y)(x − y) ⇒ lines x = y and y = −3x/2 ✓

k = −1

Q10. Find the separate equations of 6x² + 5xy − 6y² = 0.

6x² + 5xy − 6y² = (3x − 2y)(2x + 3y) = 0

Check by expansion: 6x² + 9xy − 4xy − 6y² = 6x² + 5xy − 6y² ✓. Note a + b = 6 + (−6) = 0, so the pair is perpendicular.

3x − 2y = 0 and 2x + 3y = 0

Exercise 3.3 — Coordinates in space

Q1. Find the distance between (1, 2, 3) and (4, 6, 3).

d = √[(4−1)² + (6−2)² + (3−3)²] = √(9 + 16 + 0) = 5

d = 5 units

Q2. Show that (1, 2, 3), (2, 3, 4) and (0, 1, 2) are collinear.

AB = (2−1, 3−2, 4−3) = (1, 1, 1) AC = (0−1, 1−2, 2−3) = (−1, −1, −1)

AC = −AB, so the two vectors are parallel and share the point A.

The three points are collinear.

Q3. Find the direction cosines of the line joining (1, 2, 3) and (4, 6, 3).

DRs = (4−1, 6−2, 3−3) = (3, 4, 0) |dr| = √(9 + 16 + 0) = 5 l = 3/5, m = 4/5, n = 0

Check: l² + m² + n² = 9/25 + 16/25 + 0 = 1 ✓

l = 3/5, m = 4/5, n = 0

Q4. Find the direction cosines of a line which makes equal angles with the three coordinate axes.

Equal angles ⇒ l = m = n. Using l² + m² + n² = 1:

3l² = 1 ⇒ l = ±1/√3

l = m = n = ±1/√3 (both signs allowed; the line makes equal angles with all axes)

Q5. Find the distance of (3, 4, 5) from the origin.

d = √(3² + 4² + 5²) = √50 = 5√2

d = 5√2 ≈ 7.07 units

Q6. A line has direction cosines (1/√3, 1/√3, k). Find k.

l² + m² + n² = 1 ⇒ 1/3 + 1/3 + k² = 1 ⇒ k² = 1/3 ⇒ k = ±1/√3

k = ±1/√3

Q7. Show that (1, 0, 0), (0, 1, 0) and (0, 0, 1) form an equilateral triangle.

AB = √[(0−1)² + (1−0)² + 0] = √2 BC = √[0 + (0−1)² + (1−0)²] = √2 CA = √[(1−0)² + 0 + (0−1)²] = √2

All three sides are √2, so the triangle is equilateral.

Q8. Find the centroid of the triangle with vertices (1, 2, 3), (2, 3, 4) and (3, 4, 5).

G = ((1+2+3)/3, (2+3+4)/3, (3+4+5)/3) = (2, 3, 4)

Centroid = (2, 3, 4)

Q9. Write the direction ratios and direction cosines of the X-axis.

The X-axis is the line through the origin in the direction (1, 0, 0), whose magnitude is 1.

DRs (1, 0, 0); direction cosines l = 1, m = 0, n = 0.

Q10. Find the distance between (2, −1, 3) and (−1, 3, 2).

d = √[(−1−2)² + (3+1)² + (2−3)²] = √(9 + 16 + 1) = √26

d = √26 ≈ 5.10 units

Exercise 3.4 — Topic-by-topic extension

Three topics, one level harder: distance questions that first require rearranging a line, bisector questions that ask which bisector, and pair-of-lines questions where the condition (perpendicular, coincident) drives the algebra.

Topic 1 — Straight line: distance and bisectors

Q1. Find the distance between the parallel lines 3x − 4y + 7 = 0 and 3x − 4y − 5 = 0.

The coefficients already match, so only the constants differ:

d = |c₁ − c₂|/√(a² + b²) = |7 − (−5)|/√(9 + 16) = 12/5

d = 12/5 = 2.4 units

Q2. Find k if the distance from (3, 0) to the line 4x + 3y + k = 0 is 2.

|4(3) + 3(0) + k|/√(16 + 9) = 2 |12 + k| = 10 ⇒ 12 + k = 10 or 12 + k = −10

Both branches are needed because the modulus hides the sign.

k = −2 or k = −22

Q3. Find the bisector of the angle between 3x + 4y − 5 = 0 and 5x − 12y + 3 = 0 that contains the origin.

Normalise both lines, then choose the sign that puts the origin on the same side of each.

L₁ = (3x + 4y − 5)/5, L₂ = (5x − 12y + 3)/13 At (0,0): L₁ = −1 (negative), L₂ = 3/13 (positive) — opposite signs, so the bisector containing the origin is L₁ = −L₂. 13(3x + 4y − 5) = −5(5x − 12y + 3) 39x + 52y − 65 = −25x + 60y − 15

32x − 4y − 25 = 0

Q4. Find the bisector of the angle between 2x + y + 3 = 0 and x − 2y − 4 = 0 that contains the origin.

At (0,0): (2·0 + 0 + 3)/√5 = 3/√5 > 0 (0 − 0 − 4)/√5 = −4/√5 < 0 Opposite signs ⇒ the origin's bisector is L₁ = −L₂: (2x + y + 3)/√5 = −(x − 2y − 4)/√5 2x + y + 3 = −x + 2y + 4

Bisector: 3x − y − 1 = 0

Topic 2 — Pair of straight lines

Q5. Find the separate equations of the pair 6x² + 5xy − 6y² = 0.

Treat it as a quadratic in x with y as constant, or factor directly:

6x² + 9xy − 4xy − 6y² = (3x − 2y)(2x + 3y) = 0

3x − 2y = 0 and 2x + 3y = 0

Q6. Find the angle between the lines x² − 4xy + y² = 0.

Here a = 1, 2h = −4 ⇒ h = −2, b = 1. For a homogeneous pair the angle satisfies

tanθ = 2√(h² − ab)/|a + b| = 2√(4 − 1)/2 = √3

θ = 60°

Q7. For what value of k does 2x² + kxy − 3y² = 0 represent perpendicular lines?

Perpendicular requires a + b = 0, i.e. 2 + (−3) = −1 ≠ 0. So no k can make this pair perpendicular — the coefficient of x² would have to be 3.

No such k (need a + b = 0)

Q8. Find the bisectors of the pair x² − y² = 0.

The pair is (x − y)(x + y) = 0, i.e. the two lines y = ±x, which are already perpendicular. For perpendicular lines the bisectors are the coordinate axes.

(x² − y²)/(a − b) = xy/h with a = 1, b = −1, h = 0 is degenerate; by symmetry the bisectors are x = 0 and y = 0.

x = 0 and y = 0

Topic 3 — Coordinates in space

Q9. Find the direction cosines of the line joining A(1, 2, 3) and B(3, 6, 9).

AB = (2, 4, 6), |AB| = √(4 + 16 + 36) = √56 = 2√14 l = 2/(2√14) = 1/√14, m = 2/√14, n = 3/√14

(1, 2, 3)/√14

Q10. Show that the points A(1, 2, 3), B(2, 4, 5) and C(3, 6, 7) are collinear.

AB = (1, 2, 2), BC = (1, 2, 2) Proportional with ratio 1 ⇒ parallel, with B common.

Collinear

Q11. Find the coordinates of the point dividing the join of P(1, −2, 3) and Q(4, 5, −6) in the ratio 2 : 1 internally.

R = ((2·4 + 1·1)/3, (2·5 + 1(−2))/3, (2(−6) + 1·3)/3) = (9/3, 8/3, −9/3)

R = (3, 8/3, −3)

Q12. Find the angle between the lines with direction ratios (1, 1, 0) and (0, 1, 1).

cosθ = (1·0 + 1·1 + 0·1)/(√2·√2) = 1/2

θ = 60°

Exercise 3.5 — Mixed question types, topic by topic

Four NEB shapes per topic: a direct substitution, a condition on k, a bisector or angle computation, and a combined-equation construction.

Topic 1 — Straight line: distance and bisectors

Q1. 2 marks. Find the perpendicular distance from (4, −1) to 3x − 4y + 2 = 0.

d = |12 + 4 + 2|/5 = 18/5

18/5 = 3.6 units

Q2. 4 marks. Find k so that 2x + 3y = 1 and kx + y = 2 are perpendicular.

a₁a₂ + b₁b₂ = 0 ⇒ 2k + 3 = 0

k = −3/2

Q3. 4 marks. Find both bisectors of the angle between 4x − 3y + 1 = 0 and 3x + 4y − 2 = 0.

Both normals have length 5, so the equations are already normalised:

(4x − 3y + 1)/5 = ±(3x + 4y − 2)/5 + sign: 4x − 3y + 1 = 3x + 4y − 2 ⇒ x − 7y + 3 = 0 − sign: 4x − 3y + 1 = −3x − 4y + 2 ⇒ 7x + y − 1 = 0

x − 7y + 3 = 0 and 7x + y − 1 = 0

Q4. 5 marks. Find the distance between 2x + 3y = 5 and 4x + 6y = 11.

The coefficients must match first; divide the second by 2:

2x + 3y = 5.5 d = |5 − 5.5|/√(4 + 9) = 0.5/√13

d = 1/(2√13) = √13/26 units

Topic 2 — Pair of straight lines

Q5. 2 marks. Write the separate equations of x² − 5xy + 6y² = 0.

x² − 5xy + 6y² = (x − 2y)(x − 3y) = 0

x = 2y and x = 3y

Q6. 4 marks. Find the angle between the lines 2x² − 3xy − 2y² = 0.

Here a = 2, b = −2, so a + b = 0 ⇒ the lines are perpendicular without any computation.

90°

Q7. 4 marks. For what k are the lines of 3x² + kxy − 3y² = 0 perpendicular?

Perpendicularity needs a + b = 0, and here 3 + (−3) = 0 for every k.

Every real k

Q8. 5 marks. Find the combined equation of the two lines through the origin with slopes 2 and −1/2.

(y − 2x)(y + x/2) = 0 = y² + xy/2 − 2xy − x² = 2y² − 3xy − 2x² = 0

Check perpendicularity: a = −2, b = 2 ⇒ a + b = 0 ✓

2y² − 3xy − 2x² = 0

Topic 3 — Coordinates in space

Q9. 2 marks. Find the distance of (1, 2, 3) from the origin.

OP = √(1 + 4 + 9) = √14

√14 units

Q10. 4 marks. A line makes equal angles with all three axes. Find its direction cosines.

l = m = n and l² + m² + n² = 1 ⇒ 3l² = 1 ⇒ l = ±1/√3

(1, 1, 1)/√3 (or the negative of it)

Q11. 4 marks. Find the ratio in which (2, 3, 4) divides the join of (1, 1, 1) and (3, 5, 7).

(1 + 2t, 1 + 4t, 1 + 6t) = (2, 3, 4) ⇒ t = 1/2 Midpoint check: t = 1/2 does give (2, 3, 4)

1 : 1 — the point is the midpoint

Q12. 5 marks. Find the angle between the lines with direction ratios (2, −1, 2) and (1, 2, 2).

a₁a₂ + b₁b₂ + c₁c₂ = 2 − 2 + 4 = 4 |both| = 3 each ⇒ cosθ = 4/9

θ = cos⁻¹(4/9) ≈ 63.6°

Concept drills — why, what, where

Analytic geometry is the most sign-sensitive unit in the paper. These drills train the decisions — which sign, which bisector, which form — that decide the answer.

D1. Spot the error. A student writes the distance from (1, 2) to 3x + 4y + 5 = 0 as (3 + 8 + 5)/5 = 16/5. What is missing?

The absolute value — distance is a magnitude. Here the expression is positive so the number is right, but with the point on the other side of the line the same formula would return a negative “distance”.

Why it works: the numerator is a signed quantity; |·| converts it to a length. Where you use it: every distance item — write the modulus before substituting.

D2. Method choice. Two lines are given as x + y = 3 and 2x + 2y = 7. How do you see instantly that they are parallel, and what does that imply about a solution?

The coefficients are proportional (1/2 = 1/2) but the constants are not (3/2 ≠ 7/2), so the lines are parallel and distinct — no intersection, so no common solution.

Why it works: proportional coefficients give the same normal direction. Where you use it: check the ratio pattern first; it saves solving anything.

D3. Why two answers? Why does “the bisector” of two lines really mean two lines?

Two intersecting lines create four angles, paired into two equal-angle sets. Equating the normalised forms with + and − produces the bisector of each pair, and the two bisectors are perpendicular.

Why it works: the ± sign corresponds to “same side” and “opposite side”. Where you use it: when a question asks for the bisector containing a given point, test the sign that point satisfies.

D4. What does it claim? What does a + b = 0 assert about the pair ax² + 2hxy + by² = 0?

That the two lines are perpendicular. The sum of the coefficients of x² and y² vanishes exactly when the product of the slopes is −1.

Why it works: with slopes m₁m₂ = a/b, perpendicularity is a/b = −1. Where you use it: “find k so the lines are perpendicular” — set a + b = 0, do not factor.

D5. Counterexample hunt. Is a second-degree equation in x and y always a pair of straight lines?

No. x² + y² + 1 = 0 has no real points at all, and x² + y² = 0 is a single point. It represents a real pair of lines only when the discriminant condition h² ≥ ab holds together with the appropriate condition on the general form.

Why it works: “degree two” is necessary but not sufficient. Where you use it: before quoting a pair-of-lines formula, verify the equation really factors.

D6. Why the normalisation? Why can't you equate ax + by + c₁ and a′x + b′y + c₂ directly?

Because those expressions are not distances — they are scaled by different factors. Only after dividing by each √(a² + b²) do both sides mean the same thing, so only then does “equal” mean “equidistant”.

Why it works: the ratio c/√(a² + b²) is the distance to the origin. Where you use it: every bisector question begins with normalising both lines.

D7. Where to use it. You are asked for the area of the triangle formed by a line and the coordinate axes. Which quantities do you need?

The two intercepts: set y = 0 for the x-intercept and x = 0 for the y-intercept. Then area = ½|x-intercept| × |y-intercept| — no distance formula required.

Why it works: the axes are perpendicular, so the intercepts are the legs. Where you use it: any “area of the triangle with the axes” item.

D8. Read the numbers. A line has direction cosines (0, 1/2, √3/2). Describe its direction without drawing.

l = 0 means it is perpendicular to the x-axis, so the line lies in a plane parallel to the yz-plane. The remaining two cosines show 60° with the y-axis and 30° with the z-axis.

Why it works: each cosine is the projection of the unit direction on an axis. Where you use it: quick interpretation questions worth 2 marks.

D9. Necessity check. Why must l² + m² + n² = 1 hold, and what does it let you compute?

The direction cosines are the components of a unit vector along the line, so their squares sum to 1 by Pythagoras. It lets you find the third cosine once two are known — a standard one-line question.

Why it works: direction cosines are a unit vector in disguise. Where you use it: “a line makes 45° with two axes, find the third angle”.

D10. Predict the geometry. In a pair ax² + 2hxy + by² = 0 with h = 0 and a = b, what figure do you get?

a(x² + y²) = 0 forces x = 0 and y = 0 — the two coordinate axes. With h = 0 the pair is always the axes when a = b, and reduces to a single line when a ≠ b.

Why it works: the cross term is what tilts the lines. Where you use it: sanity-check a factorisation by looking at h.

D11. Where the sign bites. Why does the section formula require the ratio to be written as m : n in a fixed order?

Because the weights are attached to the opposite endpoint: mx₂ + nx₁. Swapping m and n silently swaps the point with its complement on the line, giving the external-style location instead of the intended one.

Why it works: the segment is divided in a stated direction, from the first point to the second. Where you use it: internal/external division questions — state the order before substituting.

D12. Where to stop. After finding a candidate value of k that makes two lines perpendicular, what must you still check?

That both lines are real and distinct with that k — the pair must factor into two real lines. Otherwise the “perpendicular” answer describes something that does not exist geometrically.

Why it works: the algebra can hold while the geometry degenerates. Where you use it: any constructed-constant question — one verification line protects the final mark.

Conceptual bank — 2-mark questions with model answers

C1. Why is the distance formula written with a modulus?

Because a₁x₁ + b₁y₁ + c₁ can be negative depending on which side of the line the point lies, whereas length cannot. The modulus keeps d ≥ 0, so d measures distance, not signed displacement.

C2. Why does the bisector formula have a ± sign?

Two lines form four angles, and the bisectors of the two pairs are distinct lines. Taking + gives one bisector and − gives the other; the ± records the fact that a point can be equidistant from the lines in two different directions.

C3. What does the equation ax² + 2hxy + by² = 0 represent geometrically?

Two straight lines through the origin (real when h² ≥ ab), because every term is of degree two, so (0,0) satisfies it for all coefficients.

C4. State the condition for ax² + 2hxy + by² = 0 to give two real distinct lines, and for two perpendicular lines.

Real and distinct: h² − ab > 0. Perpendicular: a + b = 0 (since m₁m₂ = a/b must equal −1). Coincident lines occur when h² = ab with the equation a perfect square.

C5. State the condition for the general second-degree equation to represent a pair of straight lines.

abc + 2fgh − af² − bg² − ch² = 0, together with h² ≥ ab. This is the determinant condition on the 3×3 symmetric coefficient matrix.

C6. Distinguish direction ratios from direction cosines.

Direction ratios are any three numbers proportional to the direction of the line; direction cosines are the unique cosines of the angles the line makes with the positive axes, obtained by dividing the ratios by their magnitude, so l² + m² + n² = 1.

C7. Why must l² + m² + n² = 1 for direction cosines?

The point (l, m, n) lies on the unit sphere (the line direction is a unit vector), so its distance from the origin is 1. Equivalently cos²α + cos²β + cos²γ = 1.

C8. Give the distance between two parallel lines ax + by + c₁ = 0 and ax + by + c₂ = 0.

d = |c₁ − c₂|/√(a² + b²). The coefficients of x and y must be made identical first, otherwise the formula does not apply.

C9. How do you decide whether two points lie on the same side of a line?

Substitute each point into the left side. If the two values have the same sign, the points are on the same side; opposite signs mean opposite sides; zero means the point is on the line.

C10. Find the angle between the X-axis and the line joining (0,0,0) to (1,1,0).

Direction cosines of the line: (1/√2, 1/√2, 0). The X-axis has l = 1. Then cosθ = l = 1/√2, so θ = 45°.

C11. What does the pair of lines 4x² − y² = 0 look like, and what is the angle between them?

4x² − y² = (2x − y)(2x + y) = 0, i.e. y = 2x and y = −2x. Here a = 4, b = −1, h = 0, so tanθ = 2√(0 + 4)/(4 − 1) = 4/3, giving θ ≈ 53.13°.

C12. Can a second-degree equation in x and y represent a circle and a pair of lines at the same time?

No. A circle needs a = b and h = 0 with a non-zero constant term; a pair of lines through the origin needs no linear or constant terms at all (unless the lines are translated). The two conditions cannot both hold, so the classification is exclusive.

C13. Write the slope of the line ax + by + c = 0.

m = −a/b (b ≠ 0). A vertical line has b = 0 and no finite slope.

C14. State the conditions for two lines to be parallel and perpendicular, in terms of a, b and slope.

Slopes: m₁ = m₂ for parallel, m₁m₂ = −1 for perpendicular. Coefficients: a₁b₂ = a₂b₁ for parallel, a₁a₂ + b₁b₂ = 0 for perpendicular.

C15. Write the equation of the line through (x₁, y₁) and (x₂, y₂).

Two-point form: (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁), with slope m = (y₂ − y₁)/(x₂ − x₁).

C16. What is the normal form of a straight line?

x cos α + y sin α = p, where p is the perpendicular distance from the origin and α is the angle that perpendicular makes with the positive x-axis.

C17. Why does the perpendicular-distance formula use √(a² + b²) in the denominator?

Because √(a² + b²) is the length of the normal vector (a, b). Dividing by it converts the line to normal form, so the constant term becomes the actual distance.

C18. What is the locus of points equidistant from two lines?

Two straight lines through the point of intersection — the bisectors of the two angles formed. Their equations come from equating the two normalised distances.

C19. What does a homogeneous second-degree equation a x² + 2hxy + b y² = 0 represent?

A pair of straight lines through the origin. Every term has the same total degree, so (0, 0) satisfies it and the two lines pass through the origin.

C20. Why does the general second-degree pair-of-lines equation have no constant term?

Because the two lines meet at the origin. If a constant were present the lines would still cross, but at some non-zero point, which is obtained by shifting the origin.

C21. What does h² = ab mean for ax² + 2hxy + by² = 0?

h² = ab makes the equation a perfect square, so the two lines coincide — the equation represents a single line counted twice.

C22. Write the distance between two parallel lines.

For ax + by + c₁ = 0 and ax + by + c₂ = 0, the distance is |c₁ − c₂|/√(a² + b²). The coefficients must be made identical first.

C23. Write the direction cosines of the x-, y- and z-axes.

x-axis: (1, 0, 0); y-axis: (0, 1, 0); z-axis: (0, 0, 1). Each satisfies l² + m² + n² = 1.

C24. Can a direction cosine equal 2? Why?

No. Direction cosines are the cosines of the angles made with the axes, so each lies in [−1, 1], and l² + m² + n² = 1 forces every |l| ≤ 1.

C25. A line makes 90° with the x-axis and 45° with the y-axis. Find its angle with the z-axis.

l² + m² + n² = 1 ⇒ 0 + 1/2 + n² = 1 ⇒ n = ±1/√2, so the angle is 45° or 135°.

C26. Give the formula for the angle between two lines in terms of direction ratios.

cos θ = (l₁l₂ + m₁m₂ + n₁n₂) after normalising, or a₁a₂ + b₁b₂ + c₁c₂ over the product of the two vector lengths when using direction ratios.

C27. What is the section formula for a point dividing a segment internally in 3D?

If P divides A(x₁, y₁, z₁) and B(x₂, y₂, z₂) in ratio m : n, then P = ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n), (mz₂ + nz₁)/(m+n)).

C28. How do you test whether three points in space are collinear?

Find the direction ratios of AB and BC; the points are collinear exactly when these ratios are proportional, i.e. one vector is a scalar multiple of the other.

C29. What is the equation of the XY-plane, and what does z = 0 mean?

z = 0 is the XY-plane; every point on it has zero height above (or below) that plane. Similarly y = 0 is the ZX-plane and x = 0 the YZ-plane.

C30. Why must both sides of a distance equation be divided by the same normalising factor?

Because the distance formula only works for a line written in normalised form; scaling only one side changes the equality and therefore gives wrong bisectors and distances.

C31. Give the equations of the angle bisectors of the pair ax² + 2hxy + by² = 0.

The bisectors are (x² − y²)/(a − b) = xy/h. They are always perpendicular to each other and pass through the point where the two given lines meet.

C32. What does it mean for two lines to be concurrent?

All three lines pass through one common point. For a₁x + b₁y + c₁ = 0 (i = 1, 2, 3) the condition is that the 3×3 determinant of coefficients vanishes.

C33. State the general equation of a circle and the meaning of its centre and radius.

x² + y² + 2gx + 2fy + c = 0 has centre (−g, −f) and radius √(g² + f² − c), real only when g² + f² − c > 0.

Long-answer set — 4 to 6 marks

L1. [4] Find the distance between the parallel lines 3x − 4y + 7 = 0 and 6x − 8y = 21.

The coefficient sets must match before the formula can be used. Divide the second line by 2:

6x − 8y − 21 = 0 ⇒ 3x − 4y − 21/2 = 0

d = |c₁ − c₂|/√(a²+b²) = |7 − (−21/2)| / 5 = (7 + 10.5)/5 = 17.5/5 = 3.5

d = 7/2 = 3.5 units

L2. [5] Find the bisector of the acute angle between 3x + 4y − 5 = 0 and 5x − 12y + 7 = 0.

From Exercise 3.1 Q5 the two bisectors are

7x + 56y − 50 = 0 and 32x − 4y − 15 = 0

To pick the acute-angle bisector, test the origin in each numerator: for the first line the origin gives −5 (inside), for the second +7. The origin lies in the obtuse region, so its bisector 7x + 56y − 50 = 0 bisects the obtuse angle, and the other one bisects the acute angle.

Acute-angle bisector: 32x − 4y − 15 = 0

L3. [5] Show that 2x² − 5xy − 3y² = 0 represents two lines through the origin, find both, and find the angle between them.

2x² − 5xy − 3y² = (2x + y)(x − 3y) = 0 ⇒ y = −2x and y = x/3

a = 2, 2h = −5 ⇒ h = −5/2, b = −3 tanθ = 2√(h² − ab)/(a + b) = 2√(25/4 + 6)/(−1) = 2(7/2)/(−1) = −7

The negative sign means the obtuse angle is 180° − tan⁻¹7; the acute angle is tan⁻¹7 ≈ 81.87°.

Lines: 2x + y = 0 and x − 3y = 0; acute angle ≈ 81.9°

L4. [5] Find the value of k for which the equation 2x² + kxy − 3y² = 0 represents a pair of perpendicular lines; is such a k possible?

Perpendicularity for a homogeneous pair requires a + b = 0. Here a = 2 and b = −3, so

a + b = 2 − 3 = −1 ≠ 0 regardless of k

Hence no value of k makes this particular pair perpendicular — k only controls the angle, not the a + b sum.

For reference, real distinct lines need h² − ab > 0: k²/4 + 6 > 0, true for all k, so every k gives a real pair.

No such k exists; the pair is perpendicular only when a + b = 0, which here fails identically.

L5. [5] Find the direction cosines of the line joining A(2, −1, 3) and B(−1, 3, 2), and find the distance AB.

DRs of AB = (−1−2, 3+1, 2−3) = (−3, 4, −1) |AB| = √(9 + 16 + 1) = √26 l = −3/√26, m = 4/√26, n = −1/√26

Check: (9 + 16 + 1)/26 = 26/26 = 1 ✓

d = √26; direction cosines (−3/√26, 4/√26, −1/√26)

L6. [6] Find the equations of the lines represented by x² − 4xy + y² = 0 and their angle bisectors.

Solving for y/x = m from x² − 4xy + y² = 0 (divide by x²):

m² − 4m + 1 = 0 ⇒ m = (4 ± √12)/2 = 2 ± √3 Lines: y = (2 + √3)x and y = (2 − √3)x

For the bisectors of a homogeneous pair, use (x² − y²)/(a − b) = xy/h:

a = 1, b = 1, h = −2 a − b = 0 ⇒ x² − y² = 0 ⇒ x = ±y

The bisectors are x = y and x = −y — perpendicular to each other, as bisectors of a perpendicular-free pair always are (here the lines are symmetric about y = x).

Lines: y = (2 ± √3)x; bisectors: x = y and x = −y

Trap 1 — unnormalised bisectors. Dividing the differentials without dividing by √(a²+b²) gives a wrong bisector. Normalise both lines first.

Trap 2 — mismatched parallel coefficients. 3x − 4y + 7 = 0 and 6x − 8y = 21 are not yet in comparable form; scale one until the x and y coefficients agree.

Trap 3 — losing one bisector. A 4-mark bisector question expects two equations. Dropping the − branch loses half the marks.

Trap 4 — treating direction ratios as cosines. DRs may be any proportional triple; only after dividing by the magnitude do you get cosines, and only then does l² + m² + n² = 1.

Trap 5 — forgetting the ± in oblique-pair angles. tanθ from a pair of lines can come out negative; report the acute angle as tan⁻¹|value| and note the obtuse supplement.
