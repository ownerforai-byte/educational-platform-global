Unit 2 — Trigonometry

Mathematics XI (Mat. 007)  •  NEB Grade 11  •  12 teaching hours  •  Exercise solutions + conceptual bank

Two examinable ideas only: the inverse circular functions (principal values, ranges, combination formulae) and trigonometric equations (general values, counting roots in an interval). Everything in this unit is short — which is exactly why it is marked harshly on precision.

Where the marks live. Trigonometry is a small unit but it appears in every paper:

  • A 2-mark principal-value or evaluation item (sin⁻¹(sin 5π/6), tan⁻¹(1/2)+tan⁻¹(1/3)).
  • A 4-mark proof of a combination identity (tan⁻¹x ± tan⁻¹y, sin⁻¹x + cos⁻¹x = π/2).
  • A 4–5-mark general-solution question, often with a restriction to [0, 2π].

The single rule that protects most marks: always state the principal-value range of the inverse function you are using, and always write "n ∈ ℤ" in a general solution.

Exercise 2.1 — Principal values

Q1. Evaluate sin⁻¹(√3/2).

sin⁻¹ has principal range [−π/2, π/2]. The angle in that range with sine √3/2 is π/3.

sin⁻¹(√3/2) = π/3

Q2. Evaluate cos⁻¹(−1/2).

cos⁻¹ has principal range [0, π]. The cosine is negative in the second quadrant, and cos(2π/3) = −1/2.

cos⁻¹(−1/2) = 2π/3

Q3. Evaluate tan⁻¹(1) + tan⁻¹(−1).

tan⁻¹(1) = π/4, tan⁻¹(−1) = −π/4

Sum = 0

Q4. Evaluate sin⁻¹(−1/2) + cos⁻¹(−1/2).

sin⁻¹(−1/2) = −π/6 (range [−π/2, π/2]) cos⁻¹(−1/2) = 2π/3 (range [0, π]) Sum = −π/6 + 4π/6 = 3π/6 = π/2

π/2   — the identity sin⁻¹x + cos⁻¹x = π/2 holds for every x in [−1, 1]

Q5. Evaluate sin(cos⁻¹(3/5)).

Let θ = cos⁻¹(3/5), so cos θ = 3/5 with θ ∈ [0, π/2]. Build the right triangle: adjacent 3, hypotenuse 5, so opposite = √(25−9) = 4.

sin θ = 4/5

sin(cos⁻¹(3/5)) = 4/5

Q6. Evaluate sin⁻¹(sin 5π/6) and explain why it is not 5π/6.

sin(5π/6) = 1/2 sin⁻¹(1/2) = π/6 because π/6 ∈ [−π/2, π/2]

5π/6 is outside the principal range, so it cannot be the output of sin⁻¹.

sin⁻¹(sin 5π/6) = π/6 ≠ 5π/6

Q7. Evaluate cos(2 cos⁻¹(1/2)).

cos⁻¹(1/2) = π/3 ⇒ 2cos⁻¹(1/2) = 2π/3 cos(2π/3) = −1/2

−1/2

Q8. Evaluate tan⁻¹(√3) − cot⁻¹(−√3).

tan⁻¹(√3) = π/3 For the negative argument in cot⁻¹ (principal range (0, π)): cot(5π/6) = −√3 ⇒ cot⁻¹(−√3) = 5π/6 π/3 − 5π/6 = 2π/6 − 5π/6 = −3π/6 = −π/2

−π/2

Q9. Write tan⁻¹(2x/(1 − x²)) as a multiple of tan⁻¹x, stating the condition.

Using tan 2θ = 2 tan θ/(1 − tan²θ) with θ = tan⁻¹x:

2tan⁻¹x = tan⁻¹( 2x/(1 − x²) ) provided 1 − x² > 0 and |x| < 1

tan⁻¹(2x/(1−x²)) = 2tan⁻¹x for |x| < 1

Q10. Find the domain of sin⁻¹(2x) and of tan⁻¹(x²).

  1. sin⁻¹ is defined only on [−1, 1]: −1 ≤ 2x ≤ 1 ⇒ −1/2 ≤ x ≤ 1/2.
  2. tan⁻¹ is defined on all of ℝ, and x² is always real, so the domain is ℝ.

Domain of sin⁻¹(2x) = [−1/2, 1/2]; domain of tan⁻¹(x²) = ℝ

Exercise 2.2 — Combination formulae

Q1. Prove sin⁻¹x + cos⁻¹x = π/2 for x ∈ [−1, 1].

Let sin⁻¹x = θ, so sin θ = x and θ ∈ [−π/2, π/2].

cos(π/2 − θ) = sin θ = x

Now π/2 − θ ∈ [0, π] (because θ ∈ [−π/2, π/2]), which is exactly the principal range of cos⁻¹. Since cos⁻¹ is one–one on [0, π],

cos⁻¹x = π/2 − θ = π/2 − sin⁻¹x ⇒ sin⁻¹x + cos⁻¹x = π/2

Proved for all x ∈ [−1, 1].

Q2. Evaluate tan⁻¹(1/2) + tan⁻¹(1/3).

Both arguments are positive and their product 1/6 < 1, so the sum lies in (0, π/2) and the standard formula applies:

tan(A+B) = (1/2 + 1/3) / (1 − 1/6) = (5/6)/(5/6) = 1 ⇒ tan⁻¹(1) = π/4

π/4

Q3. Prove tan⁻¹(1/2) + tan⁻¹(2/11) = tan⁻¹(3/4).

(1/2 + 2/11) / (1 − (1/2)(2/11)) = (11/22 + 4/22) / (1 − 1/11) = (15/22) / (10/11) = (15/22)(11/10) = 15/20 = 3/4

All quantities are positive and the product is 1/11 < 1, so no π needs to be added.

tan⁻¹(1/2) + tan⁻¹(2/11) = tan⁻¹(3/4)  (proved)

Q4. Show that 2tan⁻¹(1/3) = tan⁻¹(3/4).

Using tan 2θ = 2tanθ/(1 − tan²θ) with tanθ = 1/3:

tan(2θ) = (2/3) / (1 − 1/9) = (2/3)/(8/9) = (2/3)(9/8) = 3/4

2tan⁻¹(1/3) = tan⁻¹(3/4)  (proved)

Q5. Prove cos⁻¹(4/5) + cos⁻¹(12/13) = cos⁻¹(33/65).

Let A = cos⁻¹(4/5) and B = cos⁻¹(12/13). Then cos A = 4/5, sin A = 3/5; cos B = 12/13, sin B = 5/13.

cos(A+B) = cosA cosB − sinA sinB = (4/5)(12/13) − (3/5)(5/13) = 48/65 − 15/65 = 33/65

A + B lies in [0, π], which is the range of cos⁻¹, so taking cos⁻¹ of both sides is legitimate.

cos⁻¹(4/5) + cos⁻¹(12/13) = cos⁻¹(33/65)  (proved)

Q6. Prove tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) for xy < 1.

Let A = tan⁻¹x, B = tan⁻¹y so that tan A = x, tan B = y, and A, B ∈ (−π/2, π/2). Then

tan(A+B) = (tanA + tanB)/(1 − tanA tanB) = (x+y)/(1−xy)

If xy < 1 the denominator is positive, A + B ∈ (−π/2, π/2), which is the range of tan⁻¹, so

tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)), xy < 1  (proved)

Q7. Prove tan⁻¹(1/3) + tan⁻¹(1/5) + tan⁻¹(1/7) + tan⁻¹(1/8) = π/4.

Pair the terms so each product is below 1:

tan⁻¹(1/3) + tan⁻¹(1/5) = tan⁻¹[ (1/3+1/5)/(1 − 1/15) ] = tan⁻¹[ (8/15)/(14/15) ] = tan⁻¹(4/7) tan⁻¹(1/7) + tan⁻¹(1/8) = tan⁻¹[ (1/7+1/8)/(1 − 1/56) ] = tan⁻¹[ (15/56)/(55/56) ] = tan⁻¹(3/11)

Now combine the two results:

tan⁻¹[ (4/7 + 3/11)/(1 − (4/7)(3/11)) ] = tan⁻¹[ (44/77 + 21/77)/(1 − 12/77) ] = tan⁻¹[ (65/77)/(65/77) ] = tan⁻¹(1) = π/4

Every partial sum stayed in (0, π/2), so no π correction is needed at any stage.

Sum = π/4  (proved)

Q8. Evaluate tan⁻¹(1) + tan⁻¹(2) + tan⁻¹(3).

tan⁻¹(1) = π/4 tan⁻¹(2) + tan⁻¹(3): xy = 6 > 1, so the sum is π + tan⁻¹((2+3)/(1−6)) = π + tan⁻¹(−1) = π − π/4 = 3π/4 Total = π/4 + 3π/4 = π

tan⁻¹(1) + tan⁻¹(2) + tan⁻¹(3) = π

Q9. Solve tan⁻¹(2x) + tan⁻¹(3x) = π/4.

tan⁻¹[(2x + 3x)/(1 − 6x²)] = π/4 ⇒ 5x/(1 − 6x²) = 1 ⇒ 5x = 1 − 6x² ⇒ 6x² + 5x − 1 = 0 ⇒ (6x − 1)(x + 1) = 0 ⇒ x = 1/6 or x = −1

Reject x = −1: then 2x = −2, 3x = −3, both inverse tangents negative while the sum π/4 is positive. (Equivalently 1 − 6x² < 0 there, so the value moves by π.)

x = 1/6

Q10. Prove 2tan⁻¹(1/2) = tan⁻¹(4/3) and hence evaluate 2tan⁻¹(1/2) − tan⁻¹(1/7)?

2tan⁻¹(1/2) = tan⁻¹[ 2(1/2)/(1 − 1/4) ] = tan⁻¹[1/(3/4)] = tan⁻¹(4/3)

tan⁻¹(4/3) − tan⁻¹(1/7) = tan⁻¹[ (4/3 − 1/7)/(1 + (4/21)) ] = tan⁻¹[ (25/21)/(25/21) ] = tan⁻¹(1) = π/4

2tan⁻¹(1/2) − tan⁻¹(1/7) = π/4

Exercise 2.3 — Trigonometric equations: general values

The four general solutions to memorise.
  • sinθ = k, |k| ≤ 1 ⇒ θ = nπ + (−1)ⁿ α, where α = sin⁻¹k.
  • cosθ = k ⇒ θ = 2nπ ± α, where α = cos⁻¹k.
  • tanθ = k ⇒ θ = nπ + α, where α = tan⁻¹k.
  • If sinθ = 0 ⇒ θ = nπ; if cosθ = 0 ⇒ θ = (2n+1)π/2.
Always state α inside its principal range first, then apply the pattern.

Q1. Solve sin θ = 1/2 for the general value.

α = sin⁻¹(1/2) = π/6 (principal value) sinθ = 1/2 ⇒ θ = nπ + (−1)ⁿ(π/6)

θ = nπ + (−1)ⁿ π/6, n ∈ ℤ

Q2. Solve cos θ = −1/2.

α = cos⁻¹(−1/2) = 2π/3 cosθ = −1/2 ⇒ θ = 2nπ ± 2π/3

θ = 2nπ ± 2π/3, n ∈ ℤ

Q3. Solve tan θ = √3.

α = tan⁻¹(√3) = π/3 ⇒ θ = nπ + π/3

θ = nπ + π/3, n ∈ ℤ

Q4. Solve 2sin²θ − 3sinθ + 1 = 0.

Let u = sinθ: 2u² − 3u + 1 = 0 ⇒ (2u − 1)(u − 1) = 0 ⇒ sinθ = 1/2 or sinθ = 1

sinθ = 1/2 ⇒ θ = nπ + (−1)ⁿ π/6 sinθ = 1 ⇒ θ = (4n+1)π/2

θ = nπ + (−1)ⁿ π/6  or  θ = (4n+1)π/2, n ∈ ℤ

Q5. Solve cos 2θ = cos θ.

For cos X = cos Y: X = 2nπ ± Y.

2θ = 2nπ + θ ⇒ θ = 2nπ 2θ = 2nπ − θ ⇒ 3θ = 2nπ ⇒ θ = 2nπ/3

θ = 2nπ or θ = 2nπ/3, n ∈ ℤ

Q6. Solve sin θ + cos θ = √2.

Divide throughout by √2 = √(1²+1²):

(1/√2)sinθ + (1/√2)cosθ = 1 sin(θ + π/4) = 1 θ + π/4 = (4n+1)π/2 θ = (4n+1)π/2 − π/4 = 2nπ + π/4

θ = 2nπ + π/4, n ∈ ℤ

Q7. Solve tan²θ = 3.

tanθ = ±√3 tanθ = √3 ⇒ θ = nπ + π/3 tanθ = −√3 ⇒ θ = nπ − π/3

θ = nπ ± π/3, n ∈ ℤ

Q8. Solve 2cos²θ + 3sinθ = 0.

2(1 − sin²θ) + 3sinθ = 0 2 − 2sin²θ + 3sinθ = 0 2sin²θ − 3sinθ − 2 = 0 (2sinθ + 1)(sinθ − 2) = 0

sinθ = 2 is impossible; so sinθ = −1/2, with α = sin⁻¹(−1/2) = −π/6.

θ = nπ + (−1)ⁿ(−π/6) = nπ − (−1)ⁿ π/6, n ∈ ℤ

Q9. Solve sin²θ = 1/4.

sinθ = ±1/2 ⇒ θ = nπ ± π/6

Both signs collapse into the single ± pattern, because sinθ = 1/2 has solutions nπ + (−1)ⁿπ/6 and sinθ = −1/2 adds nπ − (−1)ⁿπ/6.

θ = nπ ± π/6, n ∈ ℤ

Q10. Solve 4 sinθ cosθ = √3.

2(2sinθcosθ) = √3 ⇒ 2sin2θ = √3 ⇒ sin2θ = √3/2 2θ = nπ + (−1)ⁿ π/3 θ = nπ/2 + (−1)ⁿ π/6

θ = nπ/2 + (−1)ⁿ π/6, n ∈ ℤ

Q11. Solve cot θ = −1.

tanθ = −1 ⇒ α = tan⁻¹(−1) = −π/4 θ = nπ − π/4

θ = nπ − π/4 (equivalently θ = nπ + 3π/4), n ∈ ℤ

Q12. Solve sec²θ = 4.

1/cos²θ = 4 ⇒ cos²θ = 1/4 ⇒ cosθ = ±1/2 cosθ = 1/2 ⇒ θ = 2nπ ± π/3 cosθ = −1/2 ⇒ θ = 2nπ ± 2π/3 Combined: θ = nπ ± π/3

θ = nπ ± π/3, n ∈ ℤ

Exercise 2.4 — Equations restricted to an interval

Q1. Solve 2sin²θ − sinθ − 1 = 0 for θ ∈ [0, 2π].

(2sinθ + 1)(sinθ − 1) = 0 ⇒ sinθ = −1/2 or sinθ = 1

sinθ = 1 ⇒ θ = π/2. sinθ = −1/2 in [0, 2π] ⇒ θ = π + π/6 = 7π/6 and θ = 2π − π/6 = 11π/6.

θ = π/2, 7π/6, 11π/6   (three solutions)

Q2. Solve sin 2θ = 1/2 for θ ∈ [0, π].

θ ∈ [0, π] ⇒ 2θ ∈ [0, 2π].

sin 2θ = 1/2 ⇒ 2θ = π/6, 5π/6 ⇒ θ = π/12, 5π/12

θ = π/12, 5π/12

Q3. Solve cos²θ − cosθ = 0 for θ ∈ [0, 2π].

cosθ(cosθ − 1) = 0 ⇒ cosθ = 0 or cosθ = 1 cosθ = 0 ⇒ θ = π/2, 3π/2 cosθ = 1 ⇒ θ = 0, 2π

θ = 0, π/2, 3π/2, 2π

Q4. How many solutions does tan θ = 2 have in [0, 2π]? Find them.

tan has period π, so in an interval of length 2π there are exactly two solutions.

α = tan⁻¹2 ≈ 63.4° ≈ 1.107 rad θ = α and θ = α + π ≈ 4.249 rad

Two solutions: θ ≈ 1.11 rad and θ ≈ 4.25 rad

Q5. Solve 3tan²θ = 1 for θ ∈ (0, π).

tan²θ = 1/3 ⇒ tanθ = ±1/√3 Both values are non-zero, so θ = π/6, 5π/6 (the negative branch in (0, π) is 5π/6)

θ = π/6, 5π/6

Q6. Solve sin 3θ = 0 for θ ∈ [0, π].

3θ = nπ ⇒ θ = nπ/3, n ∈ ℤ θ ∈ [0, π] ⇒ n = 0, 1, 2, 3 ⇒ θ = 0, π/3, 2π/3, π

θ = 0, π/3, 2π/3, π

Conceptual bank — 2-mark questions with model answers

C1. State the principal value ranges of sin⁻¹, cos⁻¹ and tan⁻¹.

sin⁻¹x ∈ [−π/2, π/2]; cos⁻¹x ∈ [0, π]; tan⁻¹x ∈ (−π/2, π/2). These ranges are what make each inverse a single-valued function.

C2. Why is sin⁻¹(sin 5π/6) not equal to 5π/6?

Because 5π/6 does not lie in the principal range [−π/2, π/2] of sin⁻¹. Since sin(5π/6) = 1/2 and sin⁻¹(1/2) = π/6, the value is π/6.

C3. What are the domains of sin⁻¹x, cos⁻¹x and tan⁻¹x?

sin⁻¹ and cos⁻¹ are defined for x ∈ [−1, 1] (the range of sine and cosine); tan⁻¹ is defined for all real x.

C4. Distinguish a particular solution from a general solution.

A particular solution is one value satisfying the equation (e.g. θ = π/6); the general solution is the complete family containing all solutions (e.g. θ = nπ + (−1)ⁿπ/6, n ∈ ℤ). Every particular solution is obtained by choosing n.

C5. Why does the sine general solution carry (−1)ⁿ?

Because sinα = sin(π − α): two distinct angles share each sine value. The factor (−1)ⁿ alternates which of the two branches is taken as n increases, so one formula records both.

C6. Does sin θ = 2 have a solution? Justify.

No. |sinθ| ≤ 1 for all real θ, and 2 > 1, so the equation has no solution in ℝ.

C7. Show that sin⁻¹(−x) = −sin⁻¹x but cos⁻¹(−x) ≠ −cos⁻¹x.

sin is odd, so if sinθ = −x then sin(−θ) = x, and both −θ and θ fall in the principal range: sin⁻¹(−x) = −sin⁻¹x. But cos is even: cos⁻¹(−x) = π − cos⁻¹x, e.g. cos⁻¹(−1/2) = 2π/3 while −cos⁻¹(−1/2) = −2π/3, which is outside [0, π].

C8. How many solutions does cos θ = 0 have in [0, 2π]?

Two: θ = π/2 and θ = 3π/2. In general cosθ = 0 gives θ = (2n+1)π/2.

C9. Why can we write tan⁻¹(1/2) + tan⁻¹(1/3) = π/4 without adding π?

Both angles are positive and their product 1/6 is less than 1, so the sum lies inside (−π/2, π/2), the principal range of tan⁻¹. If the product exceeded 1, the sum would cross π/2 and a π correction would be necessary.

C10. If tan⁻¹x = π/4, what is x?

x = tan(π/4) = 1, since π/4 lies in the principal range.

C11. State the general solution of tanθ = k and explain why it has period π.

θ = nπ + tan⁻¹k. The tangent function repeats every π (tan(θ+π) = tanθ), so one solution generates all others by adding multiples of π.

C12. Evaluate sin⁻¹(1/2) + cos⁻¹(1/2) and name the identity used.

By sin⁻¹x + cos⁻¹x = π/2 for x ∈ [−1,1], the sum is π/2 — no separate evaluation of each term is needed.

C13. Solve sinθ = −√3/2 giving the principal value of α first.

α = sin⁻¹(−√3/2) = −π/3, so θ = nπ + (−1)ⁿ(−π/3) = nπ − (−1)ⁿπ/3.

C14. What is the period of sin 2θ and how does it affect the number of solutions in [0, 2π]?

Period = 2π/2 = π. So the pattern of solutions repeats twice in [0, 2π], typically doubling the count of roots found in one period.

C15. Define sin⁻¹ and state its domain and range.

sin⁻¹ : [−1, 1] → [−π/2, π/2] is the inverse of the sine function restricted to [−π/2, π/2], chosen so that it is one–one.

C16. Is sin⁻¹x the same as 1/sin x?

No. sin⁻¹x is the inverse function (an angle); 1/sin x = cosec x is the reciprocal. The superscript −1 means "inverse", not "reciprocal".

C17. What is a principal value?

The unique value of an inverse circular function that lies inside its stated principal range — e.g. sin⁻¹(1/2) = π/6, not 5π/6.

C18. Why is sin⁻¹x defined only for x ∈ [−1, 1]?

Because it is the inverse of sin, whose output never leaves [−1, 1]. Outside that interval no angle has the given sine.

C19. Evaluate sin⁻¹(1), cos⁻¹(0) and tan⁻¹(0).

sin⁻¹1 = π/2, cos⁻¹0 = π/2 (both inside their principal ranges), and tan⁻¹0 = 0.

C20. State the principal range of cot⁻¹ and explain why it differs from tan⁻¹.

cot⁻¹ has range (0, π), while tan⁻¹ has (−π/2, π/2). The intervals are chosen so each inverse is continuous and single-valued; cot⁻¹ must avoid the point where cot blows up at 0 and π.

C21. Evaluate sin⁻¹(1/2) + cos⁻¹(1/2).

By sin⁻¹x + cos⁻¹x = π/2, the sum is π/2 directly: π/6 + π/3 = π/2.

C22. Explain why cos⁻¹(−1/2) = 2π/3 and not −2π/3.

cos⁻¹ has principal range [0, π], so a negative output is impossible. In the second quadrant cos(2π/3) = −1/2, and 2π/3 lies in [0, π].

C23. Why does a trigonometric equation need a general solution rather than one answer?

Trigonometric functions are periodic, so one value repeats infinitely often. The general solution records every repetition through an integer n; a single value would answer only within one period.

C24. Give the general solution of sin θ = 0.

θ = nπ, n ∈ ℤ — the sine vanishes at every integer multiple of π.

C25. Give the general solution of cos θ = 1 and of cos θ = 0.

cosθ = 1 ⇒ θ = 2nπ. cosθ = 0 ⇒ θ = (2n + 1)π/2 — the odd multiples of π/2.

C26. Give the general solution of tan θ = 0.

θ = nπ. The tangent has period π, so one solution generates all of them by adding multiples of π.

C27. Give the general solution of sin θ = −1.

θ = (4n − 1)π/2, equivalently θ = 2nπ − π/2. Only the bottom of the unit circle has sine −1.

C28. How many solutions does sin θ = 1/2 have in [0, 2π]?

Two: θ = π/6 and θ = 5π/6 — one in each of the first and second quadrants where sine is positive.

C29. How many solutions does tan 3θ = 1 have in [0, π]?

Three. 3θ = nπ + π/4 gives θ = nπ/3 + π/12; n = 0, 1, 2 give π/12, 5π/12, 3π/4, all inside [0, π].

C30. Solve sin θ = cos θ for the general value.

Divide by cosθ (cosθ = 0 is not a solution, since then sinθ = ±1): tanθ = 1 ⇒ θ = nπ + π/4.

C31. Express a sin θ + b cos θ as a single sine.

a sinθ + b cosθ = R sin(θ + φ) with R = √(a² + b²) and tanφ = b/a. This converts the sum into one wave whose amplitude and phase are read off directly.

C32. What is the maximum value of 3 sin θ + 4 cos θ?

R = √(9 + 16) = 5, and R sin(θ + φ) ranges over [−5, 5], so the maximum is 5.

C33. Why is sin²θ + cos²θ = 1 so useful in equations?

It lets a quadratic in sinθ be rewritten in cosθ (or vice versa), reducing a mixed equation to a single-variable one — e.g. 2cos²θ + 3sinθ = 0 becomes a quadratic in sinθ.

C34. Convert 150° to radians.

Multiply by π/180: 150π/180 = 5π/6 radians.

C35. What is the period of |sin θ|?

π. The absolute value folds the negative half-wave upward, so the pattern repeats twice as often as sinθ itself.

C36. What is the period of tan 2θ?

π/2, since the period of tan(kθ) is π/|k|.

C37. What happens when solving sin θ = k with |k| > 1?

There is no solution, because |sinθ| ≤ 1 for every real θ. The equation should be rejected at that point, not solved.

C38. Evaluate sin⁻¹(sin 3π/4).

sin(3π/4) = 1/√2 = sin(π/4), and π/4 lies in the principal range, so the value is π/4 (not 3π/4).

C39. Evaluate cos⁻¹(cos 5π/3).

cos(5π/3) = 1/2, and cos⁻¹(1/2) = π/3 because 5π/3 lies outside the principal range [0, π].

C40. Evaluate tan⁻¹(tan 3π/4).

tan(3π/4) = −1, so tan⁻¹(−1) = −π/4 — inside (−π/2, π/2), as required.

C41. Why does cos 2θ = cos θ produce two families of solutions?

For cos X = cos Y the general rule is X = 2nπ ± Y. The two signs give 2θ = 2nπ + θ and 2θ = 2nπ − θ, so θ = 2nπ and θ = 2nπ/3 — two distinct infinite families.

C42. State the general solution of sin²θ = sin²α.

θ = nπ ± α, n ∈ ℤ. Both signs are needed because squaring records two possible sines, ±sinα.

C43. Does tan θ = k always have a solution?

Yes, for every real k — the range of tan is all of ℝ. The general solution θ = nπ + tan⁻¹k always exists.

C44. If tan⁻¹x + tan⁻¹y = π/2, what relation connects x and y?

Then tan⁻¹y = π/2 − tan⁻¹x = cot⁻¹x = tan⁻¹(1/x), so y = 1/x, i.e. xy = 1.

C45. If tan⁻¹x + tan⁻¹y = π/4, show x + y + xy = 1.

Taking tan of both sides: (x + y)/(1 − xy) = 1 ⇒ x + y = 1 − xy ⇒ x + y + xy = 1.

C46. Why must a candidate solution obtained by squaring be checked?

Squaring is not reversible: it can turn a false statement into a true one, so values that satisfy the squared equation may not satisfy the original. Substituting back removes these extraneous roots.

Long-answer set — 4 to 6 marks

L1. [5] Prove that tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) when xy < 1, and evaluate tan⁻¹(1/2) + tan⁻¹(1/3).

Let A = tan⁻¹x, B = tan⁻¹y, so tanA = x, tanB = y with A, B ∈ (−π/2, π/2). Then

tan(A+B) = (tanA + tanB)/(1 − tanA tanB) = (x+y)/(1−xy)

Given xy < 1, 1 − xy > 0, so A + B ∈ (0, π) and indeed in (−π/2, π/2) for x, y of small magnitude. Applying tan⁻¹ (which is one–one there):

A + B = tan⁻¹((x+y)/(1−xy))

Application: x = 1/2, y = 1/3, xy = 1/6 < 1:

(1/2 + 1/3)/(1 − 1/6) = (5/6)/(5/6) = 1 ⇒ sum = tan⁻¹1 = π/4

Formula proved; tan⁻¹(1/2) + tan⁻¹(1/3) = π/4

L2. [5] Prove sin⁻¹(4/5) + sin⁻¹(5/13) = sin⁻¹(63/65).

Let A = sin⁻¹(4/5) so cosA = 3/5, and B = sin⁻¹(5/13) so cosB = 12/13 (both angles acute).

sin(A+B) = sinA cosB + cosA sinB = (4/5)(12/13) + (3/5)(5/13) = 48/65 + 15/65 = 63/65

A + B ∈ (0, π) because both are acute, and sin⁻¹(63/65) is acute too since 63/65 < 1; the value 63/65 lies in (0,1), so no π correction is needed.

sin⁻¹(4/5) + sin⁻¹(5/13) = sin⁻¹(63/65)  (proved)

L3. [5] Prove sin⁻¹(3/5) − sin⁻¹(8/17) = cos⁻¹(84/85).

Let A = sin⁻¹(3/5) so cosA = 4/5, and B = sin⁻¹(8/17) so cosB = 15/17.

cos(A − B) = cosA cosB + sinA sinB = (4/5)(15/17) + (3/5)(8/17) = 60/85 + 24/85 = 84/85

Since A, B ∈ (0, π/2) and A > B, the difference A − B ∈ (0, π/2) ⊂ [0, π], so cos⁻¹ may be applied directly.

cos(A−B) = 84/85 ⇒ sin⁻¹(3/5) − sin⁻¹(8/17) = cos⁻¹(84/85)  (proved)

L4. [4] Solve sin 2θ + cos θ = 0 for the general value.

2 sinθ cosθ + cosθ = 0 cosθ (2sinθ + 1) = 0 ⇒ cosθ = 0 or 2sinθ + 1 = 0

cosθ = 0 ⇒ θ = (2n+1)π/2 sinθ = −1/2 ⇒ θ = nπ + (−1)ⁿ(−π/6) = nπ − (−1)ⁿπ/6

θ = (2n+1)π/2  or  θ = nπ − (−1)ⁿπ/6, n ∈ ℤ

L5. [4] Solve 3tanθ − cotθ = 2.

Put t = tanθ (t ≠ 0), so cotθ = 1/t:

3t − 1/t = 2 ⇒ 3t² − 2t − 1 = 0 ⇒ (3t + 1)(t − 1) = 0 ⇒ tanθ = 1 or tanθ = −1/3

tanθ = 1 ⇒ θ = nπ + π/4 tanθ = −1/3 ⇒ θ = nπ − tan⁻¹(1/3)

θ = nπ + π/4  or  θ = nπ − tan⁻¹(1/3), n ∈ ℤ

L6. [5] Solve 2cos²θ = 3sinθ for θ ∈ [0, 2π].

2(1 − sin²θ) = 3sinθ 2sin²θ + 3sinθ − 2 = 0 (2sinθ − 1)(sinθ + 2) = 0 ⇒ sinθ = 1/2 (sinθ = −2 rejected)

θ = π/6, 5π/6 in [0, 2π]

Check at θ = π/6: 2cos²(π/6) = 2(3/4) = 3/2 and 3sin(π/6) = 3/2 ✓

θ = π/6, 5π/6

L7. [6] Solve tan⁻¹(x+1) + tan⁻¹(x−1) = tan⁻¹(8/31).

Argument of the left side: ((x+1)+(x−1)) / (1 − (x+1)(x−1)) = 2x / (1 − (x²−1)) = 2x/(2 − x²)

So 2x/(2 − x²) = 8/31 ⇒ 62x = 16 − 8x² ⇒ 8x² + 62x − 16 = 0 ⇒ 4x² + 31x − 8 = 0.

x = [−31 ± √(961 + 128)]/8 = [−31 ± 33]/8 x = 1/4 or x = −8

Reject x = −8: then (x+1)(x−1) = 63 > 1, so the left side exceeds π/2 while tan⁻¹(8/31) is acute.

x = 1/4

Trap 1 — forgetting the range check. Writing tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)) when xy > 1 is a sign error of π. State xy < 1 or add/subtract π explicitly.

Trap 2 — dropping n ∈ ℤ. A general solution without "n ∈ ℤ" is an incomplete answer and loses the final mark.

Trap 3 — dividing by sinθ. From sin2θ + cosθ = 0, dividing by cosθ loses the cosθ = 0 family. Always factor, never divide by a quantity that can vanish.

Trap 4 — keeping an impossible root. sinθ = 2 or cosθ = −3 must be rejected explicitly with the reason |sinθ| ≤ 1.

Speed habit. For every trigonometric equation, write three lines before solving: the identity you will use, the substitution or factorisation, and the range of the unknown (especially when the angle is 2θ or 3θ). This is what distinguishes a 4-mark answer from a 2-mark attempt.
