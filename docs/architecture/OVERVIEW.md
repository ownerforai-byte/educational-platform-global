# Architecture — Ravikisan's Platform

## System overview

```
Browser / PWA
    │
    ├─ Next.js 16 (Vercel)  ──  frontend/
    │     App Router · React 19 · TypeScript
    │     150+ routes · ISR on corpus pages
    │
    │   POST /api/*  (proxy rewrites → backend)
    │
    └─ Express API (Render)  ──  backend/
          Supabase (PostgreSQL) · Agnes LLM chain
```

## Frontend layers

```
frontend/app/
  (app)/          Authenticated shell — all study pages
  (app)/layout.tsx
    └─ AppShell
         └─ RequireApproval   (auth wall)
              └─ RouteCreditGate  (spark gate)
                   └─ SectionTierGate  (tier gate)
                        └─ {page}

  auth/           Login, signup, OAuth callback, welcome
  legal/          Privacy, Terms, Cookies …
  api/            Next.js route handlers (thin proxies to backend)
  page.tsx        Root → TierHomeRouter → /home/{tier}
```

## The 5-tier access ladder

```
visitor  → public home, blog, help only
member   → signed in; 15 Veer AI chats/day; no notes yet
plus     → class notes, labs, formula sheets, Veer studio
pro      → every index: derivations, PDF library, graph banks
owner    → everything + admin console (allowlist emails only)
```

Enforced in three places:
1. **`SectionTierGate`** — client-side muted card for wrong-tier pages
2. **`RouteCreditGate`** — client-side spark overlay (UI only)
3. **`POST /api/content/reveal`** — server-side auth + tier + spark-window check

## AI provider chain

```
Agnes (primary)  →  Groq  →  Cerebras  →  Gemini  →  Cloudflare
     ↓ (any fail)
Free-tier pool (10 providers, inserted before "internal"):
  LLM7 (keyless) → OVHcloud (keyless) → OpenRouter → Mistral
  → NVIDIA → DeepSeek → SambaNova → ModelScope → SiliconFlow → HF
     ↓
Internal keyword engine (always last)
```

Work-type lanes (one key per lane, no cross-lane queueing):
- `chat` → Agnes
- `quiz-generate` → Cerebras
- `evaluate` → Gemini
- `math` → Cerebras
- `deep-dive` → Gemini
- `image-gen` → Agnes
- `figure` → Gemini

## Content gating (CDN leak fix)

Before: note/PYQ bodies served from `public/data/` — CDN-accessible to anyone.

After: bodies moved off public static. Auth chain on `POST /api/content/reveal`:

```
requireAuth (401) → tier check (403 before spark) → spark window check (403)
    → fs.readFile from server-side corpus → 200 + body
```

Spark windows are persisted to `profiles.credits_unlock` (JSONB) so the
server can verify them without trusting the client.

## Database

Supabase (PostgreSQL). Key tables:
- `profiles` — user tiers, credits, coin gate, spark windows
- `premium_requests` — upgrade request queue
- `progress` — topic completion per user
- `ai_quiz_history` — quiz answers and accuracy
- `chat_history` — saved Veer conversations

## PWA

- Manifest: `/frontend/public/manifest.json`
- Service worker: generated by `next-pwa`
- Play Store: Android TWA in `android-twa/`

## File classification

Every file is either **[IMPORTANT CORE FILE]** or **[CONTENT FILE]** (see `AGENTS.md`).
Core files drive behaviour. Content files are data payloads — never bulk-read them.
