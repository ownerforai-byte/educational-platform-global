## 1. Topic Introduction — The Repairable Break

A **removable discontinuity** is a break the limit ignores: the two-sided limit exists but f(a) is missing or mismatched. The repair is always the same — define or redefine f(a) to equal the limit.

%%%
## 2. Fundamental Concepts

### 2.1 Definition and detection

- **Removable at a** ⟺ lim_{x→a} f(x) = L exists (finite) but f(a) ≠ L or f(a) is undefined.
- **Detection protocol:** substitute (get 0/0 or undefined), compute the limit by transformation, compare with f(a).

### 2.2 The two species

- **Hole:** f(a) undefined, limit exists — (x²−4)/(x−2) at 2 with limit 4.
- **Mismatch:** f(a) defined but ≠ limit — the redefined-point case (f(1) = 3 vs limit 2).

### 2.3 The repair theorem

- **Theorem:** defining (or redefining) **f(a) = L** makes f continuous at a — the discontinuity was removable precisely because one value fixes it.
- After repair, the function is continuous; before repair, the graph shows an isolated open dot (hole) or a detached dot (mismatch).

### 2.4 Common sources

- Rational functions with cancelled common factors: (x²−9)/(x−3) → hole at 3 with limit 6.
- Piecewise definitions with a deliberately wrong middle value.
- Roots of numerators shared with denominators — the factor-and-cancel signature.

%%%
## 3. Scientific Definitions

| Term | Scientific meaning | Example |
|---|---|---|
| **Removable discontinuity** | Limit exists, value missing/mismatched | hole at (2, 4) |
| **Hole** | f(a) undefined, limit exists | open dot on graph |
| **Repair** | Set f(a) = lim | one redefinition |
| **Factor-and-cancel** | Common factor exposes the hole | (x²−9)/(x−3) |

%%%
## 4. Detailed Explanation

### 4.1 Why "removable"

- The defect lives at a single point and the limit already knows the correct value: plugging it in removes the break entirely. Jumps and blow-ups need infinitely many point-changes or none works — they are not removable.

### 4.2 The graph signature

- A hole is an **open dot** on an otherwise continuous curve; a mismatch adds a **closed dot** floating elsewhere. Both are single-point defects — the visual fingerprint of removability.

### 4.3 Simplification caution

- Cancelling (x − a) changes the domain: the simplified expression is continuous at a but the **original** is not — always state the x ≠ a licence and report the hole.

## 5. Comparison Tables

**Discontinuity triage**

| Type | Limit exists? | Repair |
|---|---|---|
| removable (hole/mismatch) | yes | define f(a) = L |
| jump | no (finite sides differ) | none |
| infinite | no (blow-up) | none |

%%%
## 6. Common Confusions

**Cancelled ≠ continuous:** the cancellation proves the limit, not the original function's continuity — the domain shrank.
%%%
**Removable needs a finite limit:** an infinite limit at a is an infinite discontinuity, never removable.
%%%
**Hole location:** the hole sits at (a, **L**) — at the limit's height, not at f(a)'s (which doesn't exist).

## 7. Exam Application

**NEB-style (3m): Find the point of discontinuity of f(x) = (x² − 9)/(x − 3), classify it, and state the repair.** — Domain: x ≠ 3. **Limit:** factor (x−3)(x+3)/(x−3) = x + 3 (x ≠ 3) ⟹ lim_{x→3} = **6**. **Classification:** f(3) undefined with the limit existing ⟹ **removable discontinuity (hole)** at (3, 6). **Repair:** define f(3) = 6; the repaired f equals x + 3 everywhere and is continuous on ℝ.
%%%
**NEB-style (2m): For f(x) = (x² + x − 6)/(x − 2), find lim_{x→2} f(x) and the removable break.** — Factor: (x + 3)(x − 2)/(x − 2) = x + 3 (x ≠ 2) ⟹ limit **5**. f(2) undefined ⟹ **removable hole at (2, 5)**; repair f(2) = 5.
%%%
**NEB-style (2m): f(x) = (x + 2)/(x² − 4) at x = −2: removable or not?** — Factor denominator: (x + 2)/[(x−2)(x+2)] = 1/(x − 2) for x ≠ −2, ±... for x ≠ ±2. **Limit as x → −2:** 1/(−2 − 2) = **−1/4** — finite! So x = −2 is **removable** (hole at (−2, −1/4)); repair f(−2) = −1/4. But at x = 2 the simplified 1/(x−2) **blows up** ⟹ x = 2 is an **infinite** (non-removable) discontinuity. One function, two species — triage each point separately.

@@practiceQuestions@@
**NEB-style (3m): Find and classify the discontinuity of f(x) = (x² − 9)/(x − 3), then state the repair.** — **Domain:** x ≠ 3 (the denominator ban). **Limit:** factor the numerator: (x − 3)(x + 3)/(x − 3) = **x + 3 for x ≠ 3** — the cancellation is licensed by the punctured neighbourhood. Hence lim_{x→3} f(x) = 3 + 3 = **6**. **Classification:** f(3) is undefined while the limit exists ⟹ a **removable discontinuity** — specifically a **hole** at the point **(3, 6)** (open dot at the limit's height). **Repair:** define f(3) = 6; the repaired function agrees with x + 3 on all of ℝ and is continuous everywhere. **Caution stated:** the cancellation changed the domain — the original f, not x + 3, is the function under discussion, and the hole is part of its graph.
%%%
**NEB-style (2m): Find lim_{x→2} (x² + x − 6)/(x − 2) and describe the removable break.** — **Substitution:** (4 + 2 − 6)/0 = **0/0** ⟹ transform. **Factor:** x² + x − 6 = (x + 3)(x − 2), so the expression = (x + 3)(x − 2)/(x − 2) = **x + 3 for x ≠ 2**. **Limit:** 2 + 3 = **5**. **Break:** f(2) undefined with limit 5 ⟹ **removable hole at (2, 5)**; the repair f(2) = 5 restores continuity. The factor-and-cancel signature — a shared linear factor — is the universal birthplace of removable rational breaks.
%%%
**NEB-style (3m): Triage f(x) = (x + 2)/(x² − 4) at each point of discontinuity.** — **Suspicious points:** zeros of x² − 4 = (x − 2)(x + 2), i.e. x = 2 and x = −2 — triage each separately. **At x = −2:** cancel the common factor: f(x) = 1/(x − 2) for x ≠ ±2; lim_{x→−2} f(x) = 1/(−4) = **−1/4** — finite ⟹ **removable** (hole at (−2, −1/4)); repair f(−2) = −1/4. **At x = 2:** the simplified form 1/(x − 2) has numerator 1 ≠ 0 with denominator → 0 ⟹ **blow-up**: lim_{x→2⁺} = +∞, lim_{x→2⁻} = −∞ ⟹ **infinite discontinuity** — not removable. **Verdict:** one function, two species — the cancelled factor's zero is always the removable candidate; the surviving denominator's zero is always the infinite one.
@@summary@@
A **removable discontinuity** is the repairable break: the two-sided limit **exists finitely** while f(a) is missing (a **hole**) or wrong (a **mismatch**). Detection is the standard loop — substitute, transform (factor-and-cancel is the signature: (x²−9)/(x−3) → x + 3 with hole at **(3, 6)**), compare — and the **repair theorem** is one line: set f(a) = L. The graph shows an open dot at (a, L) (plus a detached dot for mismatches), and the caution stands: cancelling a factor **shrinks the domain**, so the simplified expression's continuity doesn't transfer back automatically. Triage is per-point: (x+2)/(x²−4) is **removable at −2** (limit −1/4) and **infinite at 2** — the cancelled factor's zero is the cure-able candidate, the surviving denominator's zero is not. Limit exists, one value to fix: removability in a sentence.
