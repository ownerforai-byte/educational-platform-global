## 1. Topic Introduction — The Companion Doorway to Inverse Trig, Exp and Log Derivatives

This canonical is the **short-form doorway** to derivatives of inverse trigonometric, exponential and logarithmic functions: the inverse-engine rule and the base-e story in one page. The parent canonical carries the full treatment; this companion mirrors the table, adds the deep readings, and drills four heavy-mark problems.

%%%
## 2. Theorem Mirror

- **Inverse-engine rule:** if f is invertible and differentiable with f′ ≠ 0, then (f⁻¹)′(f(x)) = 1/f′(x) — differentiate the identity f⁻¹(f(x)) = x by the chain rule.
- **Inverse trig table:** (sin⁻¹x)′ = 1/√(1−x²); (cos⁻¹x)′ = −1/√(1−x²); (tan⁻¹x)′ = 1/(1+x²); (cot⁻¹x)′ = −1/(1+x²); (sec⁻¹x)′ = 1/(|x|√(x²−1)); (cosec⁻¹x)′ = −1/(|x|√(x²−1)).
- **Exp/log table:** (eˣ)′ = eˣ; (aˣ)′ = aˣ ln a; (ln x)′ = 1/x; (log_a x)′ = 1/(x ln a).
- **Domains:** inverse trig entries valid on their interiors (|x| < 1 for sin/cos⁻¹; |x| > 1 for sec/cosec⁻¹).

%%%
## 3. Deep Conceptual — One Engine, Six Derivatives

- The inverse-engine rule derives the **entire inverse trig table**: sin⁻¹ via 1/cos y = 1/√(1−x²) (the positive root forced by the principal branch); tan⁻¹ via 1/sec²y = cos²y = 1/(1+x²). One theorem plus branch discipline replaces six memorisations.
- **Every inverse singularity is a horizontal tangent:** sin⁻¹x's derivative blows up at x = ±1 exactly where sin y has f′ = 0 (y = ±π/2). The f′ ≠ 0 hypothesis is where the rule's licence expires — and the blow-up points are visible on the original graph.
- **e is the unique self-replicating base:** (aˣ)′ = aˣ ln a, so self-replication forces ln a = 1. The natural base pays no tax; every other base is e wearing a constant — which is why natural logs are natural.

%%%
## 4. Deep Conceptual — Branches Supply the Signs

- The inverse trig derivatives' signs come from the **principal branches**: on y ∈ [−π/2, π/2], cos y ≥ 0, so the square root in (sin⁻¹)′ is positive; the co-function minus signs are the branch's mirror. Sign errors in this table are almost always branch errors.
- **The log's two tables:** (ln x)′ = 1/x on (0, ∞); the f′/f pattern ∫ later extends it to ln|f| — the absolute value is the domain repair that lets one formula serve both signs.

%%%
## 5. Worked Example Types

- **Type A — engine derivation:** derive one inverse trig entry from the rule, stating the branch.
- **Type B — base conversions:** (aˣ)′ and (log_a x)′ with the ln a tax made explicit.
- **Type C — chain-wrapped entries:** sin⁻¹(u), ln(u), eᵘ with the inner derivative attached.
- **Type D — singularity reading:** locate where an inverse derivative blows up and match to the original's horizontal tangents.

## 6. Common Confusions

**"1/√(1−x²) needs a ±":** the branch decides — principal branches make it positive. **"(aˣ)′ = aˣ":** only for a = e; the ln a tax is otherwise mandatory.

@@practiceQuestions@@
**NEB-style (6m): Derive (tan⁻¹x)′ = 1/(1 + x²) using the inverse-engine rule, stating the branch.** — **Setup:** y = tan⁻¹x ⟹ x = tan y with y ∈ (−π/2, π/2) — the principal branch, on which tan is one-to-one and sec y > 0. **Engine:** (tan⁻¹)′(x) = 1/(tan)′(y) = 1/sec²y. **Express in x:** sec²y = 1 + tan²y = **1 + x²** (the Pythagorean identity). **Result: 1/(1 + x²)** — valid for all real x (the branch covers ℝ). **Deep point:** the Pythagorean identities are the engine's translation dictionary — each inverse trig derivative is 1/(the partner's derivative), rewritten in x by the matching identity; no memorisation survives the derivation.
%%%
**NEB-style (5m): Differentiate y = 5ˣ and y = log₃x, making each base tax explicit.** — **Exponential:** (5ˣ)′ = 5ˣ·ln 5 — the general-base tax ln 5 ≈ 1.609; only e pays none. **Logarithm:** (log₃x)′ = 1/(x·ln 3) — the same tax in the denominator; equivalently log₃x = ln x/ln 3 and the constant multiple rule delivers it. **Cross-check:** the two taxes are reciprocals' mirrors — each is ln of the base, because aˣ = e^{x ln a} and log_a x = ln x/ln a are the same conversion worn outside-in. **Deep point:** base conversions are e's algebra in disguise: rewrite in base e, differentiate with the natural rules, and the ln a factors appear mechanically.
%%%
**NEB-style (5m): Differentiate y = sin⁻¹(3x) and state the domain of the answer.** — **Chain rule (outer table, inner derivative):** (sin⁻¹)′(u) = 1/√(1 − u²) with u = 3x, u′ = 3 ⟹ y′ = 3/√(1 − 9x²). **Domain:** the outer table needs |u| < 1 ⟹ |3x| < 1 ⟹ **|x| < 1/3**; at x = ±1/3 the derivative blows up (the original's horizontal tangents at y = ±π/2). **Deep point:** the chain rule wraps every table entry — write both factors (outer evaluated at u, inner derivative) explicitly and the composition can never be forgotten; the domain shrinks with the inner function's range.
%%%
**NEB-style (6m): Using the inverse-engine rule, derive (sec⁻¹x)′ = 1/(|x|√(x² − 1)) and explain the absolute value.** — **Setup:** y = sec⁻¹x ⟹ x = sec y, y ∈ [0, π] \\ {π/2} (the principal branch). **Engine:** (sec⁻¹)′(x) = 1/(sec)′(y) = 1/(sec y·tan y) = 1/(x·tan y). **Express tan y:** sec²y − 1 = tan²y ⟹ |tan y| = √(x² − 1) (x = sec y satisfies |x| ≥ 1). **The absolute value:** on the branch, tan y is positive for y ∈ [0, π/2) and negative for y ∈ (π/2, π] — so x·tan y = |x|·√(x²−1) in both halves (the signs of x and tan y match on the branch) ⟹ **(sec⁻¹x)′ = 1/(|x|√(x² − 1))**, valid for |x| > 1. **Deep point:** the absolute value is not decoration — it is the branch's sign bookkeeping compressed into one symbol; dropping it halves the table's correctness on the negative side.
@@summary@@
Inverse trigonometric, exponential and logarithmic derivatives come from one engine — (f⁻¹)′ = 1/f′ — plus branch discipline and the Pythagorean dictionary; every singularity of an inverse derivative is the original's horizontal tangent made visible. The exponential family orbits e: the self-replicating base pays no ln a tax, every other base wears one, and the log's reciprocal rule completes the inverse pair. Derive rather than recall, and state the domain with every answer.
