## 1. Topic Introduction — The Arithmetic of Chance

Probability measures uncertainty on a 0–1 scale. The theorem set: the **classical (Laplace) definition** m/n, the **addition law** with the mutually-exclusive special case, the **conditional probability** P(A|B), the **multiplication law**, **independence**, and **Bayes' theorem**.

%%%
## 2. Fundamental Concepts

### 2.1 Classical definition and its axioms

- **P(A) = m/n**: m favourable outcomes among n equally likely ones.
- **Axioms:** 0 ≤ P(A) ≤ 1; P(φ) = 0; P(S) = 1; and P(A) + P(A′) = **1** (the complement law — the "at least one" workhorse: P(at least one) = 1 − P(none)).

### 2.2 Addition law

- **Theorem:** P(A∪B) = P(A) + P(B) − P(A∩B) — the overlap counted twice must be subtracted once.
- **Mutually exclusive special case:** A∩B = φ ⟹ P(A∪B) = P(A) + P(B).

### 2.3 Conditional probability and multiplication

- **Definition:** P(A|B) = P(A∩B)/P(B), P(B) > 0 — probability of A given B happened.
- **Multiplication law:** P(A∩B) = P(A)·P(B|A) = P(B)·P(A|B).

### 2.4 Independence and Bayes

- **Independent events:** P(A∩B) = P(A)·P(B) — knowledge of one changes nothing about the other. (Do not confuse with mutually exclusive: exclusive events with positive probabilities are **dependent** — one excludes the other.)
- **Bayes' theorem:** P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / Σⱼ P(Aⱼ)P(B|Aⱼ) — inverting conditional probabilities from effect back to cause.
- **Theorem (total probability):** if A₁, A₂ partition S, P(B) = P(A₁)P(B|A₁) + P(A₂)P(B|A₂).

## 3. Scientific Definitions

| Term | Scientific meaning | Example |
|---|---|---|

| **Mutually exclusive** | A∩B = φ | head and tail on one toss |
| **Conditional probability** | P(A|B) = P(A∩B)/P(B) | draw given a red came first |
| **Independent events** | P(A∩B) = P(A)P(B) | two separate coins |

%%%
## 4. Detailed Explanation

### 4.1 The complement trick

- "At least one success" is the complement of "no successes". Counting at-least-one directly is error-prone; 1 − P(none) is one line. The single most useful probability shortcut.

### 4.2 With and without replacement

- Without replacement, the second draw's probability is **conditional** — the deck remembers. With replacement, draws are independent — the deck forgets. Naming which case you are in is half the answer.

### 4.3 Bayes in words

- Prior (before the evidence) × likelihood (evidence given cause) ∝ posterior (cause given evidence). The theorem re-weights beliefs by the data.

## 6. Common Confusions

**Mutually exclusive ≠ independent:** if A and B are exclusive and P(A), P(B) > 0, then P(A∩B) = 0 ≠ P(A)P(B) — exclusive events are maximally dependent.
%%%
**Addition law needs the overlap:** forgetting −P(A∩B) overcounts; only the exclusive case drops it.
%%%
**P(A|B) ≠ P(B|A):** the probability of disease given a positive test is not the test's accuracy — Bayes exists because these differ.

## 7. Exam Application

**NEB 2022 (verified PYQ): If P(A) = 0.6, P(B) = 0.5 and P(A∩B) = 0.3, then P(A∪B) = ? (1m)** — Addition law: P(A∪B) = 0.6 + 0.5 − 0.3 = **0.8**. Note P(A∩B) = 0.3 ≠ P(A)P(B) = 0.30... here they coincide, so A and B happen to be independent as well — but the union answer needs only the addition law.
%%%
**NEB-style (3m): A bag contains 4 red and 6 black balls. Two balls are drawn one after the other without replacement. Find the probability that both are red.** — **Conditional multiplication:** P(1st red) = 4/10; P(2nd red | 1st red) = 3/9. P(both red) = (4/10)(3/9) = **12/90 = 2/15**. Without replacement the deck remembers — the second factor is conditional.
%%%
**NEB-style (2m): A card is drawn from a pack of 52. Find the probability that it is a king or a heart.** — P(king) = 4/52; P(heart) = 13/52; P(king ∩ heart) = 1/52 (the king of hearts is counted twice otherwise). Addition law: 4/52 + 13/52 − 1/52 = **16/52 = 4/13**.
%%%
**NEB-style (3m): In a factory, machine A produces 60% of items with 2% defectives, machine B 40% with 5% defectives. An item is found defective. Find the probability it came from A. (Bayes)** — P(defective) = (0.6)(0.02) + (0.4)(0.05) = 0.012 + 0.020 = 0.032 (total probability). **Bayes:** P(A | defective) = (0.6)(0.02)/0.032 = 0.012/0.032 = **3/8 = 0.375**.

@@practiceQuestions@@
**NEB 2022 (verified PYQ): If P(A) = 0.6, P(B) = 0.5 and P(A∩B) = 0.3, then P(A∪B) is: (1m)** — **Addition law:** P(A∪B) = P(A) + P(B) − P(A∩B) — the intersection must be subtracted because the individual probabilities count it twice. **Substitute:** P(A∪B) = 0.6 + 0.5 − 0.3 = **0.8**. **Bonus observation:** P(A∩B) = 0.3 = P(A)P(B) = (0.6)(0.5), so A and B are in fact independent here — but the union computation itself needs only the addition law, and the overlap term cannot be dropped (the events are not mutually exclusive).
%%%
**NEB-style (3m): A bag contains 4 red and 6 black balls. Two balls are drawn one after the other without replacement. Find the probability that both are red.** — **Case named:** without replacement ⟹ conditional (the deck remembers). **Step 1:** P(first red) = 4/10 = 2/5. **Step 2:** after one red leaves, 3 red among 9 remain: P(second red | first red) = 3/9 = 1/3. **Multiplication law:** P(both red) = (2/5)(1/3) = **2/15 ≈ 0.133**. (With replacement the answer would be (4/10)² = 4/25 = 0.16 — larger, because the red count is never depleted.)
%%%
**NEB-style (2m): One card is drawn from a well-shuffled pack of 52. Find the probability that it is a king or a heart.** — **Sets:** kings (4 cards), hearts (13 cards), and their intersection (king of hearts, 1 card). **Addition law:** P(king ∪ heart) = 4/52 + 13/52 − 1/52 = 16/52 = **4/13**. The subtraction is essential: without it, the king of hearts would be counted in both sets and the probability overcounted — this is exactly the non-exclusive case of the addition theorem.
%%%
**NEB-style (3m): Machine A produces 60% of a factory's items with 2% defective rate; machine B produces 40% with 5% defective rate. An item chosen at random is found defective. Find the probability that it was produced by machine A.** — **Total probability:** P(D) = P(A)P(D|A) + P(B)P(D|B) = (0.6)(0.02) + (0.4)(0.05) = 0.012 + 0.020 = **0.032**. **Bayes' theorem:** P(A|D) = P(A)P(D|A)/P(D) = 0.012/0.032 = **3/8 = 0.375**. **Reading:** although A makes more items and has fewer defects, the evidence "defective" shifts the probability toward B — the posterior 0.375 is below the prior 0.6, exactly the re-weighting Bayes formalises.
@@summary@@
Probability quantifies chance: **P(A) = m/n** on equally likely outcomes, bounded by the axioms with the **complement law** P(A) + P(A′) = 1 powering the "at least one = 1 − none" shortcut. The **addition law** P(A∪B) = P(A) + P(B) − P(A∩B) subtracts the double-counted overlap (NEB 2022: 0.6 + 0.5 − 0.3 = **0.8**), collapsing to a sum only for mutually exclusive events — which are emphatically **not** independent. **Conditional probability** P(A|B) = P(A∩B)/P(B) and the **multiplication law** handle dependent sequences: without replacement, the deck remembers (both red from 4R/6B: 2/5 × 1/3 = 2/15). **Independence** is P(A∩B) = P(A)P(B); **Bayes' theorem** inverts conditionals — prior × likelihood over total probability — turning "defective ⟹ machine A" into 3/8. Exclusive, independent, conditional: name the case, then compute.
