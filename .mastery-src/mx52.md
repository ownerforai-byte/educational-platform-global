## 1. Topic Introduction — The Companion Doorway to the Limit System

This canonical is the **short-form doorway** to the limit system: the neighbourhood definition, the indeterminate forms, and the evaluation ladder in one page. The full theorem-grade treatment lives in the parent canonical (limits of a function, indeterminate forms, algebraic properties); this companion mirrors its theorems, adds the deep-conceptual readings, and drills four heavy-mark problems.

%%%
## 2. Theorem Mirror

- **Definition:** lim_{x→a} f(x) = L ⟺ for every ε > 0 there is δ > 0 with 0 < |x − a| < δ ⟹ |f(x) − L| < ε. The **0 < |x − a|** encodes "the point itself is excluded" — holes and wrong values cannot block a limit.
- **One-sided versions:** LHL (x → a⁻) and RHL (x → a⁺) exist independently; **the two-sided limit exists iff both exist and are equal.**
- **Indeterminate forms:** 0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰ — shapes needing transformation, never verdicts.
- **Evaluation ladder:** substitute → factor/conjugate → degree comparison → standard limits → squeeze → L'Hôpital.

%%%
## 3. Deep Conceptual — The Limit as a Prediction, Not a Report

- The limit answers "where is the curve *heading*," not "what is there." That is why f(2) can be 100 while lim_{x→2} f(x) = 4: the destination sign and the road are independent quantities, and continuity is precisely their agreement.
- **Every transformation preserves the destination:** factoring, conjugates, and standard-limit steering rewrite the expression for x ≠ a only — the punctured neighbourhood the limit reads is untouched, so existence and value carry over.
- **Failure is diagnostic:** 0/0 says "shared root — factor"; c/0 says "wall — read signs by side"; oscillation says "no approach — damp or squeeze." Each failure mode names its own cure.

%%%
## 4. Deep Conceptual — Why Both Sides Must Agree

- The real line offers two directions of arrival, so a single approaching value exists only if both directions report the same one. The existence theorem is not a convention — it is the only way two independent one-sided stories can name one number.
- **Disagreement is data:** LHL = 3, RHL = 7 measures a jump of size 4 and locates the gap. "Does not exist" is a complete answer *when evidenced by both sides* — the error is claiming existence without the two-sided audit.

%%%
## 5. Worked Example Types

- **Type A — clean substitution:** polynomials, roots, |x| at interior points; cite continuity, then evaluate.
- **Type B — 0/0:** factor (double factoring when both die), cancel with the x ≠ a licence, substitute again.
- **Type C — piecewise joints:** compute LHL and RHL from the governing pieces, compare, then compare with f(a).
- **Type D — squeeze:** bound the oscillator between converging rails; the middle follows.

%%%
## 6. Common Confusions

**"0/0 = 1" or "= 0":** an indeterminate form has no value — it is a work order. **"Discontinuous ⟹ no limit":** removable breaks leave limits fully intact; only the point is sick.

@@practiceQuestions@@
**NEB-style (5m): Evaluate lim_{x→4} (x² − 16)/(x − 4) and describe the graph at x = 4.** — **Form:** (16 − 16)/0 = **0/0** ⟹ transform. **Factor:** x² − 16 = (x − 4)(x + 4) ⟹ the expression = x + 4 for x ≠ 4. **Value:** lim = **8**. **Graph:** the line y = x + 4 with a **hole** at (4, 8) — both branches approach the missing point. **Deep point:** the 0/0 diagnosis guaranteed the shared root; the cancellation licence (x ≠ 4) is what makes the simplified form limit-equivalent to the original.
%%%
**NEB-style (6m): For f(x) = 2x + 1 for x < 3, f(x) = 10 − x for x > 3, f(3) = 5: compute LHL, RHL, the limit if it exists, and the continuity verdict.** — **LHL (x → 3⁻):** 2(3) + 1 = **7**. **RHL (x → 3⁺):** 10 − 3 = **7**. **Existence:** both sides exist and agree ⟹ **lim_{x→3} f(x) = 7**. **Value:** f(3) = **5**. **Verdict:** limit exists, value differs ⟹ **removable discontinuity** — repair by f(3) = 7. **Deep point:** the two-gate audit ran in order — sides first (existence), then the value comparison (classification); the assigned value 5 is a third independent quantity that neither gate consulted.
%%%
**NEB-style (5m): Evaluate lim_{x→0} x²·cos(1/x), naming the theorem used.** — **The obstacle:** cos(1/x) oscillates without settling — no side limit exists for it alone. **Squeeze setup:** −1 ≤ cos(1/x) ≤ 1 ⟹ multiplying by x² ≥ 0: **−x² ≤ x²cos(1/x) ≤ x²**. **Rails converge:** both −x² and x² → 0. **Squeeze verdict:** **lim = 0**. **Deep point:** the squeeze theorem converts bounded chaos into a limit — the oscillation never settles but its amplitude collapses; this is the same engine that later makes x·sin(1/x) continuous at 0.
%%%
**NEB-style (6m): Evaluate lim_{x→−2} (x³ + 8)/(x + 2) and state what single value at x = −2 makes the extended function continuous.** — **Form:** (−8 + 8)/0 = **0/0** ⟹ shared root. **Factor (sum of cubes):** x³ + 8 = (x + 2)(x² − 2x + 4) ⟹ the expression = x² − 2x + 4 for x ≠ −2. **Value:** 4 + 4 + 4 = **12**. **Repair:** defining **f(−2) = 12** makes value = limit ⟹ continuous. **Deep point:** the sum-of-cubes identity is the transformation tool when the shared root is negative — every power's difference/sum identity exists to expose the factor (x − a) or (x + a) that the 0/0 form promises.
@@summary@@
The limit is the value approached as x nears a — with the point itself excluded, so holes and wrong values never block it. One-sided limits exist independently; the two-sided limit demands both exist **and** agree. Indeterminate forms are work orders routed through the ladder: substitute, factor or conjugate, compare degrees, invoke the stars, squeeze, or differentiate. The deep reading: a limit is a prediction from the neighbourhood, f(a) is a report from the point, and continuity is their coincidence — the single architectural idea every later calculus definition reuses.
