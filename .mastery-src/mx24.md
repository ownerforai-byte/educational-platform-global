## 2. Fundamental Concepts

### 2.1 Function: domain and range (companion)

- **Domain bans:** denominator ≠ 0, even-root radicand ≥ 0, log argument > 0; combinations intersect.
- **Range by inversion:** solve y = f(x) for x; the feasible y's are the range.
- **Inverse theorem:** f⁻¹ exists ⟺ one-to-one; construct y = f(x) → solve → swap; graph reflects in y = x.

### 2.2 Sequence and series (companion)

- **AP:** aₙ = a + (n−1)d, Sₙ = n/2(a + l). **GP:** aₙ = arⁿ⁻¹, Sₙ = a(rⁿ−1)/(r−1), S∞ = a/(1−r) iff |r| < 1.
- **Means:** AM ≥ GM ≥ HM, equality iff a = b. **Special sums:** Σi = n(n+1)/2, Σi² = n(n+1)(2n+1)/6, Σi³ = [n(n+1)/2]².

### 2.3 Minors, cofactors, determinants (companion)

- **Cᵢⱼ = (−1)^(i+j)Mᵢⱼ**; Laplace expansion along any row/column.
- **Adjoint identity:** A·adj A = |A|I ⟹ A⁻¹ = adj A/|A| for |A| ≠ 0; |AB| = |A||B|.

## 7. Exam Application

**NEB-style (2m): Find the domain of f(x) = 1/√(4 − x²).** — Two bans: radicand 4 − x² ≥ 0 ⟹ −2 ≤ x ≤ 2; **denominator ≠ 0** ⟹ √(4 − x²) ≠ 0 ⟹ x ≠ ±2. Intersection: **−2 < x < 2**, the open interval (−2, 2) — the endpoints die not by the root rule but by the denominator rule.
%%%
**NEB-style (2m): How many terms of the GP 3 + 6 + 12 + ⋯ give a sum of 765?** — Sₙ = 3(2ⁿ − 1)/(2 − 1) = 3(2ⁿ − 1) = 765 ⟹ 2ⁿ − 1 = 255 ⟹ 2ⁿ = 256 ⟹ **n = 8**. Check: 3(1 + 2 + ⋯ + 128) = 3·255 = 765 ✓.
%%%
**NEB-style (2m): For A = [[1, 2], [3, 4]], find adj A and A⁻¹.** — Cofactors: C₁₁ = 4, C₁₂ = −3, C₂₁ = −2, C₂₂ = 1 ⟹ **adj A = [[4, −2], [−3, 1]]**; |A| = 4 − 6 = −2. **A⁻¹ = (1/−2)[[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]].** Check AA⁻¹ = I ✓.

@@practiceQuestions@@
**NEB-style (2m): Find the domain of f(x) = 1/√(4 − x²).** — **Ban 1 (even root):** the radicand must be non-negative: 4 − x² ≥ 0 ⟹ x² ≤ 4 ⟹ −2 ≤ x ≤ 2. **Ban 2 (denominator):** 1/√(4 − x²) requires √(4 − x²) ≠ 0 ⟹ x ≠ ±2 — the endpoints are **forbidden**, not merely allowed. **Intersection of the bans:** **−2 < x < 2**, i.e. the open interval **(−2, 2)**. The lesson: when a root sits in a denominator, the root's ≥ becomes a strict > — the two rules interact, and the intersection is the whole answer.
%%%
**NEB-style (2m): How many terms of the geometric progression 3 + 6 + 12 + ⋯ must be added to give a sum of 765?** — **Setup:** a = 3, r = 6/3 = 2, Sₙ = a(rⁿ − 1)/(r − 1) = 3(2ⁿ − 1). **Equation:** 3(2ⁿ − 1) = 765 ⟹ 2ⁿ − 1 = 255 ⟹ 2ⁿ = 256 = 2⁸ ⟹ **n = 8 terms**. **Verification:** the terms are 3, 6, 12, 24, 48, 96, 192, 384; their sum = 3(2⁸ − 1) = 3 × 255 = 765 ✓. (No S∞ licence is needed here — r = 2 ≥ 1, so the series diverges and only finite sums exist, which is exactly why the question asks for a partial sum.)
%%%
**NEB-style (2m): For A = [[1, 2], [3, 4]], find adj A and A⁻¹, and verify AA⁻¹ = I.** — **Cofactors:** C₁₁ = +4, C₁₂ = −3, C₂₁ = −2, C₂₂ = +1 ⟹ cofactor matrix [[4, −3], [−2, 1]] ⟹ **adj A = transpose = [[4, −2], [−3, 1]]**. **Determinant:** |A| = 1·4 − 2·3 = −2 ≠ 0. **Inverse:** A⁻¹ = adj A/|A| = **(1/−2)[[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]]**. **Verification:** AA⁻¹ = [[1(−2) + 2(3/2), 1(1) + 2(−1/2)], [3(−2) + 4(3/2), 3(1) + 4(−1/2)]] = [[−2 + 3, 1 − 1], [−6 + 6, 3 − 2]] = [[1, 0], [0, 1]] = **I** ✓ — the adjoint identity doing its job.
