%%%
## 2. Theorem Mirror

- **Definition:** lim_{x→a} f(x) = L via 0 < |x − a| < δ ⟹ |f(x) − L| < ε — the neighbourhood, point excluded.
- **Existence:** LHL and RHL must both exist and agree; domain edges truncate the theorem to one side.
- **Forms:** determinate (c/0 → ±∞ by side, 0/c → 0, ∞/c → ∞) vs indeterminate (0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰).
- **Strategy:** diagnose by substitution ⟹ transform by the failure mode's cure ⟹ substitute again ⟹ cross-check.

%%%
## 3. Deep Conceptual — Limits as the Subject's Universal Joint

- Derivatives, integrals, continuity, asymptotes: each is a limit wearing different clothes. The neighbourhood idea (approach, exclude the point, demand agreement) is the single pattern; learning it once equips the whole subject.
- **The two-gate structure recurs:** derivatives need one-sided slopes to exist and agree (|x| fails gate two); continuity needs the limit to exist and match the value (gate three). Calculus iterates one architecture at every level — value, slope, curvature.
- **Existence before value:** establish *that* the limit exists (sides, squeeze, theorem), *then* compute what it is. Reversing the order manufactures false answers.

%%%
## 4. Deep Conceptual — The Determinate Forms Carry Information Too

- **c/0⁺ → +∞, c/0⁻ → −∞:** the sign of c and the side jointly decide the wall's direction — these are *answers*, not failures.
- **0/c → 0:** the numerator dies, the denominator stands — a genuine limit of 0.
- **∞/c → ∞:** unbounded growth, read by side when c carries a sign. The determinate forms classify behaviour; only the seven indeterminate shapes demand work.

%%%
## 5. Worked Example Types

- **Type A — two-gate audit:** piecewise or rational suspects ⟹ LHL, RHL, compare, then compare with f(a).
- **Type B — transform chain:** 0/0 ⟹ factor/conjugate/steer ⟹ substitute ⟹ verify by a second route.
- **Type C — wall reading:** c/0 forms ⟹ side-by-side signs, splitting vs unifying by parity.
- **Type D — squeeze:** bounded oscillator between converging rails.

%%%
## 6. Common Confusions

**"∞ is a limit":** ∞ describes behaviour; the limit still does not exist as a real number — report both. **"Transform changes the limit":** licensed transforms agree off the excluded point, so the limit is untouched.

@@practiceQuestions@@
**NEB-style (5m): Evaluate lim_{x→5} (x² − 25)/(x − 5) with the full four-line rhythm.** — **Form:** (25 − 25)/0 = **0/0**. **Transform:** x² − 25 = (x − 5)(x + 5) ⟹ expression = x + 5 for x ≠ 5. **Licence:** cancellation valid off x = 5. **Value:** **10**. **Cross-check:** the star (xⁿ − aⁿ)/(x − a) → naⁿ⁻¹ gives 2·5 = 10 ✓. **Deep point:** the rhythm's four lines are four theorems — form diagnosis, transformation identity, cancellation licence, continuity-licensed substitution; naming each is the working.
%%%
**NEB-style (6m): Evaluate the one-sided limits of f(x) = (x + 2)/(x − 1) at x = 1 and classify the discontinuity.** — **Numerator at 1:** 3 ≠ 0 ⟹ a genuine wall. **RHL (x → 1⁺):** denominator small positive, numerator positive ⟹ → **+∞**. **LHL (x → 1⁻):** denominator small negative ⟹ → **−∞**. **Classification:** **infinite discontinuity**, splitting wall (odd power of (x − 1)); the limit does not exist; non-removable. **Deep point:** the numerator's nonzero value at the root certified the wall before signs were read; the odd parity predicted the split — three facts from one factorisation glance.
%%%
**NEB-style (5m): Evaluate lim_{x→0} (√(1 + x) − 1)/x.** — **Form:** 0/0 ✓. **Transform (conjugate):** (√(1+x) − 1)(√(1+x) + 1) = x ⟹ the expression = 1/(√(1+x) + 1) for x ≠ 0. **Value:** 1/(1 + 1) = **1/2**. **Cross-check:** the radical star √(1+u) − 1 ~ u/2 gives 1/2 ✓. **Deep point:** the conjugate converted a radical 0/0 into a plain substitution — every transformation's job is to hand the problem to continuity; the answer 1/2 is the square root's slope at 1, the derivative in embryo.
%%%
**NEB-style (6m): For f(x) = (x² − 3x + 2)/(x − 1) for x ≠ 1, f(1) = 0: run the complete limit-and-continuity audit at x = 1.** — **Form:** (1 − 3 + 2)/0 = 0/0 ⟹ factor: (x − 1)(x − 2)/(x − 1) = x − 2 for x ≠ 1. **Limit:** lim = **−1** (both sides agree — the simplified form is continuous). **Value:** f(1) = 0 ≠ −1. **Classification:** removable (mismatch) — detached dot at (1, 0) over the hole at (1, −1). **Repair:** f(1) = −1 ⟹ continuous. **Deep point:** the audit's order — limit via transformation, then value comparison, then classification and repair — is the universal template; every continuity question is this audit with different algebra feeding step one.
