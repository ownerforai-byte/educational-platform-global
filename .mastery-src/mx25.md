## 1. Topic Introduction — The Idea of Approaching

A **limit** asks what value f(x) approaches as x nears a — not what it reaches. This opening topic installs the intuition, the notation, and the one-sided/existence scaffolding the whole calculus unit stands on.

%%%
## 2. Fundamental Concepts

### 2.1 The limit idea

- **lim_{x→a} f(x) = L** means f(x) can be made arbitrarily close to L by taking x sufficiently close to a (from either side), **x ≠ a**.
- The value at a is irrelevant: f may be undefined at a (the hole case) or take a different value — the limit reads the *neighbourhood*, not the point.

### 2.1b Notation and reading

- x → a⁺ (from the right), x → a⁻ (from the left); the two-sided limit exists only if both one-sided limits agree (row 32's theorem).
- **Indeterminate forms** 0/0, ∞/∞, 0·∞ signal *work needed*, not an answer: factor, rationalise, or use standard limits.

### 2.2 Continuity preview

- A function is **continuous at a** when three things line up: f(a) exists, lim_{x→a} f(x) exists, and the two are **equal**. Graphically: pen never lifts.

### 2.3 Why limits matter

- Derivatives are limits of difference quotients; integrals are limits of sums; asymptotes are limits at infinity. Limits are calculus's atomic operation.

%%%
## 3. Scientific Definitions

| Term | Scientific meaning | Example |
|---|---|---|
| **Limit** | Value approached, not attained | lim_{x→2} (x²−4)/(x−2) = 4 |
| **One-sided limit** | Approach from one direction only | x → a⁺, x → a⁻ |
| **Indeterminate form** | 0/0 etc. — needs transformation | (x²−4)/(x−2) at 2 |
| **Continuity** | f(a) = lim_{x→a} f(x) | pen never lifts |

%%%
## 4. Detailed Explanation

### 4.1 The hole is the point

- (x² − 4)/(x − 2) is undefined at x = 2 yet approaches 4: factoring to x + 2 (valid since x ≠ 2) exposes the approach value. Limits see through holes.

### 4.2 Indeterminate ≠ undefined

- 0/0 is *indeterminate*: many values possible, decided only by transforming the expression. 5/0 is not indeterminate — it signals blow-up (infinite limit or DNE).

### 4.3 The three-part continuity test

- Memorise as a checklist: exists at a; limit exists; they match. Each can fail independently — and each failure mode is a named discontinuity (rows 36–38).

## 5. Comparison Tables

**Limit vs value**

| Situation | f(a) | lim_{x→a} f(x) | Verdict |
|---|---|---|---|
| continuous | 4 | 4 | continuous |
| removable hole | undefined | 4 | limit exists |
| redefined point | 7 | 4 | discontinuous |
| blow-up | undefined | ±∞ | discontinuous |

%%%
## 6. Common Confusions

**Limit ≠ value:** lim can exist where f(a) doesn't — the neighbourhood decides, not the point.
%%%
**0/0 is not 1 or 0:** it is a request for transformation, never an answer.
%%%
**x ≠ a is part of the definition:** the approach excludes the destination by design.

%%%
## 7. Exam Application

**NEB-style (2m): Evaluate lim_{x→2} (x² − 4)/(x − 2).** — Direct substitution gives **0/0** (indeterminate — transform, don't conclude). Factor: (x−2)(x+2)/(x−2) = **x + 2 for x ≠ 2**. Limit: 2 + 2 = **4**. The cancellation is licensed precisely because x ≠ 2 in the limiting process.
%%%
**NEB-style (2m): Evaluate lim_{x→3} (2x + 1).** — Polynomials are **continuous everywhere**: the limit equals the value by direct substitution — 2(3) + 1 = **7**. The general theorem: for any polynomial P, lim_{x→a} P(x) = P(a); the same holds for |x| and roots at interior points.
%%%
**NEB-style (2m): The function f(x) = (x² − 1)/(x − 1) for x ≠ 1, f(1) = 3. Discuss continuity at x = 1.** — **Limit:** factoring gives x + 1 for x ≠ 1, so lim_{x→1} f(x) = 2. **Value:** f(1) = 3. **Test:** limit exists (2) but ≠ value (3) ⟹ **discontinuous at x = 1** — a *removable* discontinuity: redefining f(1) = 2 would repair it (row 36's theme).

@@practiceQuestions@@
**NEB-style (2m): Evaluate lim_{x→2} (x² − 4)/(x − 2).** — **Step 1 — substitute:** (4 − 4)/(2 − 2) = **0/0** — an indeterminate form, which demands transformation rather than a verdict. **Step 2 — factor:** x² − 4 = (x − 2)(x + 2), so the expression is (x − 2)(x + 2)/(x − 2) = **x + 2 for x ≠ 2** — the cancellation is licensed because the limiting process never uses x = 2 itself. **Step 3 — substitute again:** lim = 2 + 2 = **4**. The function has a hole at (2, 4): the limit exists even though f(2) does not — the neighbourhood, not the point, decides.
%%%
**NEB-style (2m): Evaluate lim_{x→3} (2x + 1), citing the relevant theorem.** — **Theorem:** every polynomial P is continuous on all of ℝ, so **lim_{x→a} P(x) = P(a)** — direct substitution is licensed. **Compute:** P(3) = 2(3) + 1 = **7**. The same theorem covers roots and |x| at interior points of their domains; substitution fails only at the special spots (denominator zeros, radicand boundaries, piecewise joints) where the machinery of indeterminate forms and one-sided limits takes over.
%%%
**NEB-style (2m): The function f is given by f(x) = (x² − 1)/(x − 1) for x ≠ 1 and f(1) = 3. Discuss the continuity of f at x = 1.** — **Three-part test.** **Part 1:** f(1) = 3 exists ✓. **Part 2:** the limit — factoring (x² − 1)/(x − 1) = x + 1 for x ≠ 1 gives lim_{x→1} f(x) = 2 ✓. **Part 3:** f(1) = 3 ≠ 2 = limit ✗ — the test fails at the third step, so **f is discontinuous at x = 1**. **Classification:** since the limit exists, the failure is purely at the point's value — a **removable discontinuity**: redefining f(1) = 2 would make f continuous there (the "pen lift" is a single detached dot, easily re-attached).
@@summary@@
The **limit** lim_{x→a} f(x) = L is the value f(x) approaches as x nears a from both sides — with **x ≠ a built into the definition**, so holes and redefinitions at a don't block the approach: (x²−4)/(x−2) limits to 4 through its hole, and (x²−1)/(x−1) with f(1) = 3 fails continuity only because value 3 ≠ limit 2 (a **removable** break). One-sided notation x → a⁺, a⁻ sets up the existence theorem (both sides must agree). **Indeterminate forms** — 0/0 chief among them — are *work orders*, not answers: factor, rationalise, or invoke standard limits, then substitute. **Continuity at a** is the three-part checklist: f(a) exists, the limit exists, they're equal — the pen never lifts. Polynomials pass everywhere (lim P(x) = P(a)), making substitution the default and transformation the exception that proves the rule. Limits are calculus's atom: derivatives, integrals and asymptotes are all limits in costume.
