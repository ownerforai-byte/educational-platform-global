## 1. Topic Introduction — Limits as a System

This canonical consolidates the **limit of a function**, the **indeterminate forms**, and the **algebraic properties of limits** — the operating system every later technique runs on.

%%%
## 2. Fundamental Concepts

### 2.1 The definition, restated

- **lim_{x→a} f(x) = L** ⟺ f(x) can be made arbitrarily close to L by taking x sufficiently close to a (x ≠ a). The limit is about the **neighbourhood**, not the point.

### 2.2 The indeterminate forms

- **0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰** — seven forms where substitution fails and transformation is mandatory. Each is a *shape*, not a value: 0/0 candidates can converge to anything (x/x → 1; x²/x² → 1; x·0 forms vary).
- **Determinate outcomes:** c/0⁺ → +∞, c/0⁻ → −∞ (c ≠ 0), 0/∞ → 0, ∞/c → ∞ — these need no transformation.

### 2.3 The algebraic properties (theorems)

- If lim f = L and lim g = M (both finite): **sum:** lim (f+g) = L + M; **product:** lim fg = LM; **quotient:** lim f/g = L/M (M ≠ 0); **constant multiple:** lim cf = cL; **power:** lim fⁿ = Lⁿ.
- **Root property:** lim ⁿ√f = ⁿ√L (L ≥ 0 for even n).
- **Sandwich (squeeze) theorem:** g ≤ f ≤ h with lim g = lim h = L ⟹ lim f = L.
- **Composition:** lim_{x→a} f(g(x)) = f(lim_{x→a} g(x)) when f is continuous at the inner limit.

### 2.4 The method ladder

- Substitution → factor/conjugate (0/0) → degree comparison (∞/∞) → standard limits → squeeze. Properties justify every step: splitting a fraction into factors is the product theorem; steering through u is the composition theorem.

## 4. Detailed Explanation

### 4.1 Why indeterminate ≠ undefined

- 0/0 is *undetermined*, not *nonexistent*: the neighbourhood values may conspire toward any number, ∞, or nothing. The form is a flag to investigate, not a verdict.

### 4.2 The theorems as a licence system

- Splitting (x²−4)/(x−2) into (x+2)·(x−2)/(x−2) uses the product theorem — but only after each factor's limit exists. The theorems have hypotheses; the licence metaphor keeps them visible.

### 4.3 Squeeze as the endgame

- When algebra cannot isolate the value (oscillating factors), bounding does. The squeeze theorem is the only property that works without an explicit formula for f.

## 6. Common Confusions

**lim f = L does not need f(a) = L:** the point is excluded — that is why 0/0 limits exist at all.
%%%
**Splitting without existence:** the product theorem fails if a factor's limit DNE — regroup before splitting.
%%%
**c/0 is not indeterminate:** it is determinately infinite (with sign from the side); only 0/0 needs work.

## 7. Exam Application

**NEB 2023 (verified PYQ): Find lim_{x→2} (x² − 4)/(x − 2). (2m)** — **Substitute:** (4 − 4)/0 = **0/0** ⟹ transform. **Factor:** x² − 4 = (x − 2)(x + 2); cancel (x ≠ 2 licensed): x + 2. **Substitute:** 2 + 2 = **4**. (Cross-check via the star (xⁿ − aⁿ)/(x − a) → naⁿ⁻¹: 2·2 = 4 ✓.)
%%%
**NEB-style (2m): State the seven indeterminate forms and show that 0/0 has no fixed value.** — The forms: **0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰**. **No fixed value:** (x² − 4)/(x − 2) → 4; (x³ − 8)/(x − 2) → 12; (x − 2)²/(x − 2) → 0; (x − 2)/(x − 2)² → ∞ — all are 0/0 at x = 2 yet converge differently ⟹ the form alone determines nothing; the specific functions decide.
%%%
**NEB-style (3m): Prove the product rule for limits: if lim_{x→a} f = L and lim_{x→a} g = M (finite), then lim_{x→a} f·g = LM.** — Write f = L + α, g = M + β where α, β → 0 (this is what the limits mean). Then fg = LM + Lβ + Mα + αβ, so |fg − LM| ≤ |L||β| + |M||α| + |α||β|. Given ε > 0, choose δ so that |α|, |β| < min(1, ε/(3(|L|+1)), ε/(3(|M|+1))); then |fg − LM| < ε. Hence lim fg = LM ∎ — the decomposition f = L + (f − L) is the standard trick that turns limit theorems into algebra.

**NEB 2023 (verified PYQ): Find lim_{x→2} (x² − 4)/(x − 2). (2m)** — **Substitute:** (2² − 4)/(2 − 2) = 0/0 — **indeterminate** ⟹ transform. **Factor:** x² − 4 = (x − 2)(x + 2) (difference of squares), so (x² − 4)/(x − 2) = **x + 2 for x ≠ 2** — the cancellation is licensed on the punctured neighbourhood. **Substitute:** 2 + 2 = **4**. **Cross-check:** the algebraic star lim_{x→a} (xⁿ − aⁿ)/(x − a) = naⁿ⁻¹ with n = 2, a = 2 gives 2·2¹ = 4 ✓. The two routes agree — the star *is* the factoring method compressed.
%%%
**NEB-style (2m): State the seven indeterminate forms and demonstrate that the 0/0 form has no fixed value.** — **The seven forms:** 0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰ — each names a *shape* of failure, not a value. **Demonstration:** at x = 2, all four of these are 0/0: (x² − 4)/(x − 2) → **4**; (x³ − 8)/(x − 2) → **12**; (x − 2)²/(x − 2) → **0**; (x − 2)/(x − 2)² → **∞**. Same form, four different outcomes ⟹ the form is a *flag to transform*, never an answer. **Contrast:** c/0 (c ≠ 0) is **determinate** — the quotient grows without bound, sign depending on the side — and needs no transformation, only a sign analysis.
%%%
**NEB-style (3m): Prove the product rule: if lim_{x→a} f(x) = L and lim_{x→a} g(x) = M (both finite), then lim_{x→a} f(x)g(x) = LM.** — **Decomposition:** write f = L + α and g = M + β, where α = f − L → 0 and β = g − M → 0 as x → a — this is precisely what the two limits assert. **Expand:** fg = (L + α)(M + β) = **LM + Lβ + Mα + αβ**, so |fg − LM| ≤ |L|·|β| + |M|·|α| + |α|·|β|. **Epsilon bookkeeping:** given ε > 0, choose δ so that for |x − a| < δ: |α| < 1 and |α| < ε/(3(|M|+1)), and |β| < ε/(3(|L|+1)). Then |fg − LM| ≤ |L|·ε/(3(|L|+1)) + |M|·ε/(3(|M|+1)) + 1·ε/3 < ε/3 + ε/3 + ε/3 = ε. **Conclusion:** lim fg = LM ∎. The decomposition f = L + (f − L) — "the limit plus a vanishing error" — is the master trick behind every limit theorem.
@@summary@@
Limits form a **system**. The **definition** is neighbourhoodal — x approaches, never arrives — which is exactly why 0/0 limits can exist. The **seven indeterminate forms** (0/0, ∞/∞, 0·∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰) are flags for transformation, provably value-free: four 0/0 examples at x = 2 land on 4, 12, 0, ∞. The **algebraic properties** — sum, product, quotient, constant multiple, power, root — are theorems with hypotheses (finite limits, non-zero denominators), proved by the master decomposition f = L + (f − L); the **squeeze theorem** handles what algebra cannot (oscillation), and the **composition theorem** licenses u-substitution. The **method ladder** — substitute, factor/conjugate, degree comparison, standard limits, squeeze — turns every limit into a diagnosis: classify the form, cite the licence, transform, answer. NEB 2023's (x²−4)/(x−2) → 4 is the ladder's first rung in action.
