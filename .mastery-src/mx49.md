## 1. Topic Introduction — Differentiation in Reverse

**Anti-derivatives and integration**: the basic integral table, **integration by substitution**, and **integration by parts** — running the derivative machinery backwards.

%%%
## 2. Fundamental Concepts

### 2.1 Anti-derivative and the indefinite integral

- **F is an anti-derivative of f** ⟺ F′ = f. **∫f(x)dx = F(x) + C** — the whole family, since constants differentiate to 0. **Uniqueness theorem:** two anti-derivatives of the same f differ by a constant.
- **Basic table (reverse of the derivative table):** ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1); ∫dx/x = ln|x| + C; ∫eˣdx = eˣ + C; ∫aˣdx = aˣ/ln a + C; ∫sin x dx = −cos x + C; ∫cos x dx = sin x + C; ∫sec²x dx = tan x + C; ∫1/(1+x²)dx = tan⁻¹x + C; ∫1/√(1−x²)dx = sin⁻¹x + C.

### 2.2 Linearity

- ∫(af + bg)dx = a∫f dx + b∫g dx — term-by-term integration with constants carried.

### 2.3 Integration by substitution

- **Theorem:** ∫f(g(x))g′(x)dx = ∫f(u)du with u = g(x) — the chain rule reversed. Procedure: spot the inner function, let u = g(x), compute du = g′(x)dx, transform, integrate, substitute back.
- **Workhorses:** ∫f(ax+b)dx = (1/a)F(ax+b) + C; ∫f′/f dx = ln|f| + C; ∫fⁿf′dx = fⁿ⁺¹/(n+1) + C.

### 2.4 Integration by parts

- **Theorem:** ∫u·v dx = u·v − ∫u′·v dx (from the product rule integrated). **LIATE ordering** for choosing u: Log, Inverse trig, Algebraic, Trig, Exponential — differentiate the earlier class.
- **Classic cycles:** ∫x·eˣdx = xeˣ − eˣ + C; ∫ln x dx = x ln x − x + C; ∫x·sin x dx = −x cos x + sin x + C; repeated parts for ∫eˣ sin x dx (two cycles then solve linearly).

## 4. Detailed Explanation

### 4.1 Why + C is not decoration

- Differentiation destroys constants; integration must restore the whole family. Initial conditions (a point the curve passes through) pin C — the constant is where physical initial data enters calculus.

### 4.2 Substitution as pattern recognition

- The integrand must contain the inner function's derivative (up to a constant): ∫2x·e^{x²}dx has g = x², g′ = 2x present ⟹ u = x² gives ∫eᵘdu = e^{x²} + C. When g′ is absent, rescale constants; when absent entirely, substitution fails.

### 4.3 Parts as rearrangement

- Parts trades one integral for another: choose u so that u′ simplifies (LIATE) and dv so that ∫v dx is doable. Cyclic integrands (eˣ sin x) return to themselves after two applications — solve the resulting linear equation.

## 5. Comparison Tables

**Method selector**

| f′(x)/f(x) | u = f: ln\|f\| |
| fⁿ·f′ | power substitution |
| xⁿ·(exp/trig) | parts (u = xⁿ) |
| ln x, tan⁻¹x alone | parts (u = the function) |
| eˣ·sin x | parts twice + solve |

## 6. Common Confusions

**Forgetting + C:** the indefinite integral is a family; omitting C loses a mark every time.
**∫dx/x = ln|x|:** the absolute value is part of the answer (domain symmetry).
**Parts u-choice:** differentiate the LIATE-earlier factor — choosing u = eˣ in ∫xeˣdx loops forever.

## 7. Exam Application

**NEB 2023 (verified PYQ): Evaluate ∫(3x² + 2x − 1)dx. (3m)** — **Linearity + power rule reversed:** ∫3x²dx = x³; ∫2x dx = x²; ∫(−1)dx = −x. **Result: x³ + x² − x + C.** (Check: d/dx(x³ + x² − x + C) = 3x² + 2x − 1 ✓.)
%%%
**NEB-style (3m): Evaluate ∫2x·e^{x²}dx.** — **Substitution:** u = x², du = 2x dx ⟹ ∫eᵘdu = eᵘ + C ⟹ **e^{x²} + C**. The integrand contains the inner function's derivative exactly — the substitution licence is complete.
%%%
**NEB-style (3m): Evaluate ∫x·ln x dx.** — **Parts** (LIATE: Log before Algebraic ⟹ u = ln x, dv = x dx): du = dx/x, v = x²/2. ∫x ln x dx = (x²/2)ln x − ∫(x²/2)(1/x)dx = (x²/2)ln x − (1/2)∫x dx = **(x²/2)ln x − x²/4 + C**.

@@practiceQuestions@@
**NEB 2023 (verified PYQ): Evaluate ∫(3x² + 2x − 1)dx. (3m)** — **Linearity:** split into three integrals with constants carried: ∫3x²dx + ∫2x dx + ∫(−1)dx. **Power rule reversed term by term:** ∫3x²dx = 3·x³/3 = **x³**; ∫2x dx = 2·x²/2 = **x²**; ∫(−1)dx = **−x**. **Result: x³ + x² − x + C** — the constant C is mandatory (the anti-derivative is a family). **Verification:** d/dx(x³ + x² − x + C) = 3x² + 2x − 1 ✓ — differentiation returns the integrand exactly.
%%%
**NEB-style (3m): Evaluate ∫2x·e^{x²}dx.** — **Spot the composite:** e^{x²} is e^u with u = x², and the integrand contains u′ = 2x as a factor — the substitution licence is complete. **Transform:** let u = x², du = 2x dx; the integral becomes ∫eᵘdu. **Integrate:** eᵘ + C. **Substitute back: e^{x²} + C.** **Verify:** d/dx e^{x²} = e^{x²}·2x ✓ (chain rule) — the answer differentiates back to the integrand. This is the chain rule reversed in its purest recognisable form: inner function present, inner derivative attached.
%%%
**NEB-style (3m): Evaluate ∫x·ln x dx.** — **Method selection:** a product of unlike types (algebraic × logarithmic) ⟹ **integration by parts**. **LIATE ordering:** Log ranks before Algebraic ⟹ choose **u = ln x** (differentiate the logarithm) and **dv = x dx** (integrate the power). **Compute pieces:** du = dx/x; v = ∫x dx = x²/2. **Apply the formula** ∫u dv = uv − ∫v du: ∫x ln x dx = (x²/2)·ln x − ∫(x²/2)·(1/x)dx = (x²/2)ln x − (1/2)∫x dx = **(x²/2)ln x − x²/4 + C**. **Verify:** d/dx[(x²/2)ln x − x²/4] = x ln x + x/2 − x/2 = x ln x ✓. The LIATE choice is what made the new integral *simpler* — the whole art of parts.
@@summary@@
**Integration** runs differentiation backwards. An **anti-derivative** satisfies F′ = f, and ∫f dx = F + C — the **+C** restores the family constants destroyed by differentiation (two anti-derivatives differ by a constant). The **basic table** mirrors the derivative table (power rule reversed, ln|x|, eˣ, −cos x, tan⁻¹x, sin⁻¹x), and **linearity** integrates term by term (NEB 2023: 3x² + 2x − 1 → x³ + x² − x + C). **Substitution** reverses the chain rule: spot the inner function with its derivative attached (2x·e^{x²} → e^{x²} + C), with the workhorses f(ax+b), f′/f → ln|f|, fⁿf′. **Parts** reverses the product rule — ∫u dv = uv − ∫v du — with **LIATE** choosing u so the new integral simplifies (∫x ln x dx → (x²/2)ln x − x²/4 + C); cyclic integrands like eˣ sin x need two passes and a linear solve. Method selection is the exam skill: spot f′, or multiply unlike types, or differentiate the LIATE-earlier factor — then verify by differentiating back.
