## 1. Topic Introduction — Machines With Rules

A **function** is a machine assigning exactly one output to each input. The theorems: **domain conventions** (denominators, even roots, logarithms), **composition** f∘g, and the **inverse theorem** — f⁻¹ exists exactly when f is one-to-one, and y = f(x) ⟺ x = f⁻¹(y).

%%%
## 2. Fundamental Concepts

### 2.1 Definition and testing

- **Function f: A → B:** every a ∈ A has **exactly one** image f(a) ∈ B. Vertical-line test: any vertical line cuts the graph at most once.
- **Domain** = allowed inputs; **range** = actual outputs {f(x) : x ∈ D}.

### 2.2 Domain theorems

- **Polynomials:** all of ℝ. **Rational:** denominator ≠ 0. **Even roots:** radicand ≥ 0. **log:** argument > 0. Combinations take the **intersection** of the conditions.

### 2.3 Composite functions

- **(f∘g)(x) = f(g(x))** — apply g first, then f; domain = {x ∈ D_g : g(x) ∈ D_f}. Composition is associative but **not commutative**: f∘g ≠ g∘f in general.
- Example: f(x) = √x, g(x) = 1 − x² ⟹ f∘g(x) = √(1 − x²) with domain [−1, 1] — g's output must survive f's radicand rule.

### 2.4 Inverse functions (the theorem)

- **Theorem:** f has an inverse ⟺ f is **one-to-one** (injective): f(a) = f(b) ⟹ a = b. Geometric test: horizontal lines cut the graph at most once.
- **Construction:** set y = f(x), solve for x, interchange: **f⁻¹(f(x)) = x** and f(f⁻¹(y)) = y.
- **Graph theorem:** the graph of f⁻¹ is the reflection of f's graph in the line **y = x**.
- **Domain–range swap:** domain of f⁻¹ = range of f and vice versa.
- Monotone functions (strictly increasing or decreasing) are automatically one-to-one — hence invertible on their domains.

%%%
## 4. Detailed Explanation

### 4.1 Why inverses need one-to-one

- An inverse must send each output back to a **unique** input. If f(a) = f(b) with a ≠ b, the inverse cannot decide where to send the common value — ambiguity kills invertibility.

### 4.2 Range by inversion

- The fastest way to find a range: solve y = f(x) for x and ask which y permit a real solution — the permissible y's are exactly the range.

### 4.3 The reflection picture

- Swapping x and y in the equation mirrors the graph across y = x: inputs become outputs. This is why (a, b) on f ⟺ (b, a) on f⁻¹.

## 6. Common Confusions

**f⁻¹ means inverse, not reciprocal:** 1/f is a new function; f⁻¹ undoes f — different objects entirely.
%%%
**Composition order:** (f∘g)(x) = f(g(x)) — g acts **first**; reading left-to-right as "f then g" is the classic error.
%%%
**Domain of f∘g is an intersection:** g's output must be a legal input for f — not just g's own domain.

## 7. Exam Application

**NEB-style (3m): Find the inverse of f(x) = (2x + 3)/(x − 1), x ≠ 1, and state its domain.** — Set y = (2x + 3)/(x − 1): y(x − 1) = 2x + 3 ⟹ yx − y = 2x + 3 ⟹ x(y − 2) = y + 3 ⟹ **x = (y + 3)/(y − 2)**. Hence **f⁻¹(x) = (x + 3)/(x − 2)**, x ≠ 2. **Domain of f⁻¹:** x ≠ 2 — which is exactly the **range** of f (the horizontal asymptote y = 2 that f never attains): domain–range swap in action.
%%%
**NEB-style (2m): If f(x) = 2x + 1 and g(x) = x², find f∘g and g∘f and show they differ.** — f∘g(x) = f(x²) = **2x² + 1**; g∘f(x) = g(2x + 1) = **(2x + 1)² = 4x² + 4x + 1**. They differ (e.g. x = 1 gives 3 vs 9) — composition is not commutative.
%%%
**NEB-style (2m): Find the domain of f(x) = √(x − 2) / (x² − 9).** — Two conditions: radicand x − 2 ≥ 0 ⟹ x ≥ 2; denominator x² − 9 ≠ 0 ⟹ x ≠ ±3. **Intersection:** x ≥ 2 and x ≠ 3 ⟹ **domain = [2, 3) ∪ (3, ∞)** — note −3 is irrelevant since it already fails x ≥ 2.

@@practiceQuestions@@
**NEB-style (3m): Find the inverse of f(x) = (2x + 3)/(x − 1), x ≠ 1, and state the domain of f⁻¹.** — **Construction:** write y = (2x + 3)/(x − 1) and solve for x: y(x − 1) = 2x + 3 ⟹ yx − y = 2x + 3 ⟹ yx − 2x = y + 3 ⟹ x(y − 2) = y + 3 ⟹ **x = (y + 3)/(y − 2)**. Swapping names: **f⁻¹(x) = (x + 3)/(x − 2)**, defined for x ≠ 2. **Verification:** f(f⁻¹(x)) = [2(x+3)/(x−2) + 3] / [(x+3)/(x−2) − 1] = [(2x + 6 + 3x − 6)/(x−2)] / [(x + 3 − x + 2)/(x−2)] = (5x)/(5) = x ✓. **Domain of f⁻¹ = (−∞, 2) ∪ (2, ∞)** — exactly the **range** of f, since y = 2 is the horizontal asymptote f never reaches: the domain–range swap theorem made visible.
%%%
**NEB-style (2m): If f(x) = 2x + 1 and g(x) = x², find (f∘g)(x) and (g∘f)(x) and deduce that composition is not commutative.** — **(f∘g)(x) = f(g(x))** — apply g first: f(x²) = 2x² + 1. **(g∘f)(x) = g(f(x))** — apply f first: g(2x + 1) = (2x + 1)² = 4x² + 4x + 1. **Comparison:** 2x² + 1 ≠ 4x² + 4x + 1 (at x = 1: 3 vs 9), so **f∘g ≠ g∘f** — composition is associative, (f∘g)∘h = f∘(g∘h), but the order of machines matters and commutativity fails in general.
%%%
**NEB-style (2m): Find the domain of f(x) = √(x − 2)/(x² − 9).** — **Condition 1 (even root):** x − 2 ≥ 0 ⟹ x ≥ 2. **Condition 2 (denominator):** x² − 9 ≠ 0 ⟹ x ≠ 3 and x ≠ −3. **Intersection of the conditions:** x ≥ 2 excludes −3 already, so only x ≠ 3 further restricts: **domain = [2, 3) ∪ (3, ∞)**. Note the method: the domain of a combination is the **intersection** of each piece's legality — both bans must be honoured simultaneously, and conditions that are vacuous (−3) drop out automatically.
@@summary@@
A **function** assigns exactly one output to each input — the vertical-line test — with a **domain** fixed by the bans: denominator ≠ 0, even-root radicand ≥ 0, log argument > 0, combined by intersection (√(x−2)/(x²−9) lives on [2, 3) ∪ (3, ∞)). The **range** is fastest found by inversion: solve y = f(x) for x and keep feasible y. **Composition** (f∘g)(x) = f(g(x)) runs the inner machine first, with domain {x ∈ D_g : g(x) ∈ D_f}; it is associative but never commutative (2x² + 1 vs 4x² + 4x + 1). The **inverse theorem**: f⁻¹ exists ⟺ f is one-to-one (horizontal-line test; monotone ⟹ injective); construct by y = f(x) → solve → swap, verify f⁻¹(f(x)) = x, and read the graph as a **reflection in y = x** with domain and range exchanged — f(x) = (2x+3)/(x−1) inverts to (x+3)/(x−2) whose domain x ≠ 2 is f's asymptote-range. One-to-one is uniqueness backwards; everything else is bookkeeping.
