1.

Concept

Text

कक्षा १२ को लेखन व्यावसायिक हुन्छ: प्रतिवेदन (घटना/तथ्य — शीर्षक, प्रतिवेदक, ५W नेतृत्व, अवरोही क्रममा विवरण, निष्पक्ष स्वर), समीक्षा (कृति परिचय + शिल्प विश्लेषण + निर्णय), सारांश (मूलको एक तिहाइ, आफ्नै शब्द, क्रम कायम), व्यावसायिक पत्र (विषय-स्पष्ट, बुँदागत माग)। निबन्ध, चिठी, कथा-कविता-संवाद कक्षा ११ कै सीप उच्च परिष्कारसहित।

2.
Label

Formula

Kind

formula

Text

प्रतिवेदन: शीर्षक + प्रतिवेदक + नेतृत्व (को/के/कहिले/कहाँ) + विवरण (किन/कसरी, अवरोही) · समीक्षा: परिचय + शिल्प (कथानक/भाषा/पात्र) + निर्णय · सारांश: पढ → रेखाङ्कन → आफ्नै शब्द (~१/३) → जाँच · व्यावसायिक पत्र: विषय + सन्दर्भ + माग (बुँदागत) + विनीत

3.
Label

Conditions

Text

प्रतिवेदन वस्तुनिष्ठ हुनुपर्छ (प्रत्यक्षदर्शी स्वर, भूतकाल, उद्धरण श्रेयसहित)। सारांशमा मूलक्रम र अनुपात कायम; उदाहरण/मत हटाउने। समीक्षामा निर्णयलाई प्रमाण चाहिन्छ (दृश्य/प्रविधि उद्धृत)। व्यावसायिक पत्रमा एक विषय, छोटा अनुच्छेद।

4.
Label

Special cases

Text

सम्पादकीय/सम्पादन लेखनमा संस्थागत स्वर (व्यक्तिगत मत होइन)। पुस्तक समीक्षामा कथावस्तु संक्षेप + शिल्प + सिफारिस। चलचित्र समीक्षामा अभिनय/निर्देशन/छायाङ्कन छुट्टै मूल्याङ्कन। सारांशमा शीर्षक हुँदैन, आफ्नै शब्द अनिवार्य।

5.
Label

Solved

Text

विद्यालय कार्यक्रमको प्रतिवेदन: शीर्षक ('विज्ञान प्रदर्शनी सम्पन्न') + प्रतिवेदक/मिति → नेतृत्व (के, कहिले, कहाँ, को) → विवरण अवरोही क्रममा (उद्घाटन → प्रदर्शनी → पुरस्कार → समापन) → प्रत्यक्ष उद्धरण एक। पाँच W नेतृत्वमै, बाँकी तल — सम्पादकले तलबाट काटे पनि समाचार बाँच्छ।

6.
Label

Limitation

Text

ढाँचाले विषयवस्तु जन्माउँदैन — तथ्यहीन प्रतिवेदन आकारले बच्दैन। अति-संक्षेपणले योग्यता/सन्दर्भ मार्छ (सारांशको झूट)। समीक्षामा मापदण्ड नखुलाउँदा निर्णय स्वेच्छाचारी देखिन्छ।

7.
Label

Derivation

Text

अङ्क-योजनाबाट पछाडि: विषयवस्तु (तथ्य पूर्णता) + सङ्गठन (नेतृत्व-पहिलो, सुसङ्गत) + भाषा (संक्षिप्त, शुद्ध) → नेतृत्वमा पाँचै W किनभने सम्पादक तलबाट काट्छन्; सारांशमा अनुपात किनभने परीक्षक मूल-अनुच्छेदअनुसार जाँच्छन्।

8.
Label

Shortcut

Text

प्रतिवेदन: ५W नेतृत्वमा, विवरण अवरोही। सारांश: आफ्नै शब्द, एक तिहाइ, उदाहरण-मत हटाऊ। समीक्षा: निर्णयलाई दुई प्रमाण चाहिन्छ। व्यावसायिक पत्र: विषय-लाइनमै माग झल्कियोस्।

9.
Label

Board question

Text

NEB-style: कार्यक्रम प्रतिवेदन (शीर्षक + नेतृत्वसहित); अनुच्छेद सारांश निश्‍चित सीमामा; पुस्तक/चलचित्र समीक्षा निर्णयसहित; व्यावसायिक पत्र माग-बुँदासहित।
