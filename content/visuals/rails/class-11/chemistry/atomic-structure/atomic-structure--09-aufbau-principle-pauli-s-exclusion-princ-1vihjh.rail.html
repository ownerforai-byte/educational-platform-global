Label

Conditions

Text

4s before 3d — but also 4s out first: filling order and removal order are different questions. Ions strip the highest-n shell first. · Pairing needs a partner orbital, not the same orbital: Hund's rule forbids pairing while a degenerate orbital is still empty — O (2p⁴) pairs only because all three p orbitals already hold one electron.

"No two electrons in an atom can have identical values of all four quantum numbers." — Pauli; the reason matter occupies space at all.

5.
Label

Solved

Text

K (Z = 19) = [Ar] 4s¹ — the (n + l) rule at work: 4s (4+0 = 4) beats 3d (3+2 = 5), so the 19th electron of potassium enters 4s, not 3d — the single clearest demonstration of Aufbau.

Hund's rule scope: it applies only within a degenerate set (p³, d⁵…); it never overrides Aufbau's energy ordering across different subshells. · Exceptions are ground-state facts: Cr and Cu configurations apply to the neutral ground-state atoms; their ions follow the normal removal order (Cu⁺ = 3d¹⁰). · ## 7. Fe³⁺ has an exactly half-filled 3d⁵ — maximum exchange energy and spherical symmetry — so it is extra stable.
