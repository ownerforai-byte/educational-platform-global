Quick concepts

Text

Validity checking order: l against n−1 → mₗ against ±l → mₛ against ±1/2. Run the checks in this order and every "which set is impossible" question resolves mechanically.

12.
Label

Key points

Text

n = shell (1, 2, 3…; 2n² electrons); l = subshell shape (0 to n−1: s, p, d, f); mₗ = orientation (−l to +l, 2l+1 orbitals); mₛ = spin (±1/2). Na valence electron (NEB 2024): n = 3, l = 0, mₗ = 0, mₛ = +1/2. Impossible-set test (NEB 2023): check l ≤ n−1 first, then |mₗ| ≤ l, then mₛ = ±1/2.

6. Common Confusions l range vs mₗ range: l runs 0 to n − 1; mₗ runs −l to +l. For n = 3, l = 2 is legal (3d) but mₗ = 2 with l = 1 is not — the two ranges are different rules. · "n = 3, l = 3" trap: l can never equal n; the highest l in shell n is n − 1 (3f does not exist). · mₛ values: only ±1/2 — never ±1. Spin "up/down" is shorthand for the two signs, not a literal direction.
