1.
Label

Concept

Text

Unsolvable-by-formula equations surrender to iteration: bisection halves a bracketing interval (slow, certain), Newton-Raphson slides down the tangent (fast, needs a good start): xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). Numerical integration does the same for areas: trapezoidal averages heights into trapezoids, Simpson fits parabolas through triplets (needs even strips). The mechanics option mirrors physics: parallelogram of forces, inclined-plane motion.

2.
Label

Formula

Kind

formula

Text

Newton–Raphson: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) · bisection: halve [a,b] keeping f(a)·f(b) < 0 · trapezoidal: h/2·[y₀ + 2Σyᵢ + yₙ] · Simpson 1/3: h/3·[y₀ + 4Σodd + 2Σeven + yₙ] (n EVEN) · forward-difference tables extrapolate from the top (NEB 2022 MCQ)

3.
Label

Conditions

Text

Newton needs f′ ≠ 0 near the root and a close x₀ — bad starts cycle or flee. Bisection needs a sign change on [a,b] (continuity assumed). Simpson demands an EVEN number of strips; trapezoidal accepts any n. Forward differences assume EQUAL x-intervals.

4.
Label

Special cases

Text

x³ − 2x − 5 = 0 from x₀ = 2: f = −1, f′ = 3x²−2 = 10 → x₁ = 2.1; iterate to 2.0946 (three decimals, NEB 2023). Multiple roots slow Newton to linear crawl. Simpson beats trapezoidal on smooth curves (exact for cubics); rough data favours trapezoidal's humility.

5.
Label

Solved

Text

x³ − 2x − 5 = 0, x₀ = 2: f(2) = −1, f′(x) = 3x² − 2 → f′(2) = 10 → x₁ = 2 − (−1)/10 = 2.1. Next: f(2.1) = 0.061, f′ = 11.23 → x₂ ≈ 2.0946; one more pass stabilises 2.095 (NEB 2023, 3 marks). Always show f, f′, and each iterate.

6.
Label

Limitation

Text

Newton can diverge, oscillate (x²+1 = 0 has no real root to find) or stall at stationary points. Bisection converges surely but slowly (one binary digit per step). Simpson on odd strips is undefined — miscounting n is the classic lost mark.

7.
Label

Derivation

Text

Newton from Taylor: f(x) ≈ f(xₙ) + f′(xₙ)(x−xₙ) = 0 → x = xₙ − f/f′ — each step solves the LINEARISATION, converging quadratically near simple roots (correct digits roughly double). Trapezoidal from piecewise-linear area; Simpson from integrating the parabola through each (x₀,x₁,x₂) triplet, giving the 1–4–2–4…–1 weights.

8.
Label

Shortcut

Text

Root questions: write f, f′, x₀, then iterate in a table — examiners award step marks per row. 'Three decimal places' means iterate until the 3rd decimal freezes. Integration: even strips + smooth → Simpson; else trapezoidal. Forward differences → top-of-table extrapolation (NEB 2022 MCQ).

9.
Label

Board question

Text

NEB 2023 (3): x³ − 2x − 5 = 0 by Newton-Raphson from x₀ = 2 (3 d.p.). NEB 2022 (1): forward differences extrapolate from the table's beginning (MCQ). Bisection steps and trapezoidal/Simpson area numericals rotate yearly.
