6. Common Confusions Degrees vs radians: the general-value theorems are stated in radians — convert the interval before filtering. · (−1)ⁿ belongs to sine only: writing θ = nπ + (−1)ⁿα for cosine is a signature error; cosine uses 2nπ ± α. · Interval endpoints: "0 ≤ θ ≤ 2π" includes both ends — test n values that land exactly on 0 or 2π.
