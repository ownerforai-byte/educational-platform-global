Inverse circular functions exist only because the trig functions are restricted to principal branches: sin⁻¹ on [−1,1] → [−π/2, π/2], cos⁻¹ on [−1,1] → [0, π], tan⁻¹ on ℝ → (−π/2, π/2). Inside the branch, f⁻¹(f(θ)) = θ; outside it, the answer is the branch-representative (sin⁻¹(sin 2π/3) = π/3).…

Limitation

Text

The branch is a choice that buys uniqueness: restrict the periodic function until it is one-to-one, and only then does the inverse exist. · Principal branches: sin^-1 on [-1,1] -> [-pi/2, pi/2]; cos^-1 on [-1,1] -> [0, pi]; tan^-1 on R -> (-pi/2, pi/2); cot^-1 -> (0, pi); sec^-1, cosec^-1 on R minus (-1,1). Compositions: sin(sin^-1 x) = x on [-1,1]; sin^-1(sin th) = th only inside the branch (sin^-1(sin 2pi/3) = pi/3). Complement theorems: sin^-1 x + cos^-1 x = pi/2; tan^-1 x + cot^-1 x = pi/2; sec^-1 x + cosec^-1 x = pi/2.…

1. Topic Introduction — Undoing Periodic Functions sin, cos, tan are many-to-one; their inverse circular functions pick the principal branch — a restricted domain where each function is one-to-one — so the inverse is a genuine function. The theorems: principal value branches, inverse compositions, and the addition formulas for sin⁻¹ ± cos⁻¹/tan⁻¹. · ## 2. Fundamental Concepts ### 2.1 Principal value branches (the core theorem) - sin⁻¹: domain [−1, 1], range [−π/2, π/2]. - cos⁻¹: domain [−1, 1], range [0, π]. - tan⁻¹: domain ℝ, range (−π/2, π/2). - Proof idea: on these intervals each function is bijective (strictly monotone), so the inverse exists; the branch is chosen to make it so.…
