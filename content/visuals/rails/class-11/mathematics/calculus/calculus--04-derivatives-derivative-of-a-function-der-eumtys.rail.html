Special cases

Text

Five derivatives are worth memorising as a block: d/dx(sin x) = cos x, d/dx(cos x) = -sin x, d/dx(e^x) = e^x, d/dx(ln x) = 1/x and d/dx(x) = 1. · d/dx(a^x) = a^x ln a, so a constant multiple of x in the exponent is handled by the chain rule as d/dx(a^(kx)) = k a^(kx) ln a.

11.
Label

Quick concepts

Text

Derivative at a point: the limit of the difference quotient, equal to the slope of the tangent line and the instantaneous rate of change. · First principles versus rules: the rules are shortcuts proved from f'(x) = lim(h->0)[f(x+h) - f(x)]/h, and both routes must give the same answer. · Power, constant and sum rules: d/dx(c) = 0, d/dx(x^n) = n x^(n-1), d/dx[cf] = cf' and d/dx[f ± g] = f' ± g'. · Product rule (fg)' = f'g + fg' and quotient rule (f/g)' = (f'g - fg')/g^2, the latter valid only where g != 0.

12.
Label

Key points

Text

The derivative is the slope of the tangent, not of the secant; the secant slope becomes the tangent slope only in the limit h -> 0. · d/dx(sin x) = cos x says the slope equals cos x at that point, not that the slope is constant or always positive. · Every product needs (fg)' = f'g + fg'; the tempting 'differentiate each factor and multiply' is wrong. · In the chain rule, differentiate the outer function leaving the inner one untouched, then multiply by the derivative of the inner function.

1. Derivative Definition · The derivative of f(x) at x is: f'(x) = lim(h->0) [f(x+h) - f(x)]/h · Represents the instantaneous rate of change or slope of the tangent line.

17.
Label

More ideas

Text

Chain rule d/dx[f(g(x))] = f'(g(x)) x g'(x), needed whenever one function is composed with another. · Exponential and logarithmic derivatives: d/dx(e^x) = e^x, d/dx(a^x) = a^x ln a, d/dx(ln x) = 1/x and d/dx(sqrt x) = 1/(2 sqrt x). · d/dx(sqrt x) follows from the power rule with n = 1/2, giving 1/(2 sqrt x) for x > 0.

18.
Label

More ideas

Text

The power rule needs no restriction on the exponent, but a^(kx) with a <= 0 and a non-integer k is not a real function and has no real derivative. · d/dx(ln|x|) = 1/x holds for x != 0, which pairs with d/dx(sqrt x) = 1/(2 sqrt x) being defined only for x > 0. · Every rule assumes the expression is defined at the point in question, so a derivative also requires the original function to exist there.

19.
Label

More ideas

Text

The derivative of f at x is f'(x) = lim(h->0) [f(x+h) - f(x)]/h, the limit of the slope of the secant from x to x+h as h tends to 0. · The power rule d/dx(x^n) = n x^(n-1) holds for every real exponent n, and is used with d/dx(c) = 0 and d/dx[f ± g] = f' ± g'. · d/dx(sin x) = cos x, d/dx(cos x) = -sin x, d/dx(tan x) = sec^2 x, d/dx(cot x) = -csc^2 x, d/dx(sec x) = sec x tan x and d/dx(csc x) = -csc x cot x.

20.
Label

More ideas

Text

The product rule is (fg)' = f'g + fg' and the quotient rule is (f/g)' = (f'g - fg')/g^2 for g != 0. · The chain rule gives d/dx[f(g(x))] = f'(g(x)) x g'(x), so d/dx(sin^2 x) = 2 sin x cos x and d/dx(e^(3x)) = 3e^(3x). · Count the layers of a composite function, as each layer contributes its own derivative factor, so d/dx(sin^2 x) = 2 sin x cos x has two factors.
