Pair of straight lines — one equation, two lines

1.
Label

Concept

Text

The general second-degree equation ax² + 2hxy + by² + 2gx + 2fy + c = 0 represents a PAIR of straight lines exactly when its discriminant Δ vanishes — otherwise it is a circle, parabola, ellipse or hyperbola. The homogeneous part (ax² + 2hxy + by² = 0) gives two lines through the origin parallel to the pair, and tanθ = 2√(h²−ab)/|a+b| measures their angle. Perpendicular distance, angle bisectors and 3D direction cosines complete the toolkit.

2.
Label

Formula

Kind

formula

Text

pair condition: Δ = abc + 2fgh − af² − bg² − ch² = 0 · homogeneous ax²+2hxy+by²=0 → lines through origin · tanθ = 2√(h²−ab)/|a+b| (a+b=0 → perpendicular) · distance point→line: |ax₁+by₁+c|/√(a²+b²) · latus rectum of y²=4ax is 4a (y²=12x → 12)

3.
Label

Conditions

Text

Δ = 0 is necessary AND sufficient for a genuine line-pair (degenerate cases like a point need care). The angle formula needs h² ≥ ab for real lines. Bisector equations come in a ± pair (acute + obtuse). Direction cosines satisfy l²+m²+n² = 1; ratios scale freely.

4.
Label

Special cases

Text

Circle through (0,−2), (−4,0), (3,0) (NEB 2024, 3 marks): general form x²+y²+2gx+2fy+c = 0 → three substitutions, solve for g, f, c → centre (−g,−f), radius √(g²+f²−c). Parabola y² = 12x = 4·3·x → latus rectum 4a = 12 (NEB 2023 MCQ).

5.
Label

Solved

Text

Circle through (0,−2), (−4,0), (3,0): substitute each into x²+y²+2gx+2fy+c = 0 → (0,4,−4f+c=0… solving gives g, f, c) → centre (−g,−f), r = √(g²+f²−c) (NEB 2024, 3 marks). Parabola check: y² = 12x matches y² = 4ax with a = 3 → latus rectum = 4a = 12, option (c) (NEB 2023).

6.
Label

Limitation

Text

Δ = 0 also covers degenerate non-line cases (single point, coincident lines need the homogeneous part's discriminant too). The pair formulas assume non-degenerate, real lines. 3D direction-cosine methods here cover lines only — planes belong to higher study.

7.
Label

Derivation

Text

Factor the homogeneous part: ax²+2hxy+by² = a(x−m₁y)(x−m₂y) → slopes m₁+m₂ = −2h/b, m₁m₂ = a/b; tanθ = |(m₁−m₂)/(1+m₁m₂)| simplifies to 2√(h²−ab)/|a+b|. The full Δ emerges from eliminating the translation (completing squares in x and y) — vanishing constant term after shifting to the centre means lines through the shifted origin.

8.
Label

Shortcut

Text

'Does it represent a pair of lines?' → compute Δ, answer yes/no with the value. Perpendicular pair? Check a+b = 0 instantly. Circle through points: general form + three substitutions, never geometry. Latus rectum: read 4a off y² = 4ax.
