11.
Label

Quick concepts

Text

Domain: the set of all inputs x for which f is defined; range: the set of all output values f actually produces. · The codomain is the declared target B, while the range is only the subset of B that is actually hit by f. · Injective (one-to-one): different inputs give different outputs, tested by the horizontal line test on the graph. · Surjective (onto): every element of the codomain is the image of at least one input.

12.
Label

Key points

Text

f^-1 denotes the inverse function, never the reciprocal 1/f(x). · Domain and range are generally different sets; the range of f is the domain of f^-1. · An inverse exists only for a bijective function, so a restriction is often needed first, as with x^2 on x >= 0. · Composition does not commute, since f o g and g o f are different functions in general.

Text

A function f from set A to set B assigns to each element of A exactly one element of B, and is written f: A -> B with domain A and codomain B. · For f(x) = sqrt(x-2) the domain is x >= 2 and the range is y >= 0, because a square root is never negative. · If f: A -> B is bijective then f^-1 exists with f^-1(f(x)) = x and f(f^-1(y)) = y, so (f o f^-1)(x) = (f^-1 o f)(x) = x.
