1.

Concept

Text

Seventeen lessons, one recurring weapon: unknown words surrender to three attacks — synonym/antonym pairing (abundant↔plentiful/scarce), contextual guessing (surrounding sentence defines the word), and word-formation (prefix/root/suffix dissection). NEB tests vocabulary as choice (economical vs economic), completion (attach/ensure/collate) and production (one synonym + one antonym each).

2.
Label

Formula

Kind

formula

Text

attack order: context sentence → word parts → synonym/antonym · abundant = plentiful (syn) / scarce (ant) · brave = courageous / cowardly · ancient = old/antique / modern · economical (thrifty) ≠ economic (financial) ≠ economics (subject)

3.
Label

Conditions

Text

Contextual guessing needs the FULL sentence — half a clause misleads. Synonym answers must match part of speech and register ('attach' fits 'submit your assignment … files', not 'join'). Antonyms pair by the tested sense (ancient–modern for age, not ancient–new for objects).

4.
Label

Special cases

Text

False friends: 'economical report' is wrong — governments produce ECONOMIC reports (NEB 2024). Collocations decide ('keep promises', 'make promises' never 'do promises'). Same word, two senses: 'honest girl' takes 'an' (vowel sound, not vowel letter) — the NEB 2021 article trap.

5.
Label

Solved

Text

Synonym + antonym for 'abundant', 'brave', 'ancient' (NEB 2023, 3 marks): abundant → plentiful/scarce; brave → courageous/cowardly; ancient → antique/modern. Method: fix the meaning from a known context first ('abundant harvest'), then pair both sides — never invent pairs for an unguessed word.

6.
Label

Limitation

Text

No synonym is exact — connotation and collocation differ (slim vs skinny vs thin). Context clues fail on deliberately low-context test sentences; word-part analysis fails on non-compositional words (butterfly ≠ butter + fly). Dictionaries confirm; guesses propose.

7.
Label

Derivation

Text

Take any lesson word through the full drill: (1) sentence context → rough sense; (2) prefix/root/suffix split (un+happi+ness); (3) synonym chain and antonym mirror; (4) fresh sentence using it. Four passes move a word from recognition to production — the actual NEB demand, since answers must be WRITTEN, not ticked.

8.
Label

Shortcut

Text

MCQ options: eliminate by part of speech first, collocation second. 'Economic/economical' pairs: money-word → economic, thrifty-word → economical. Articles: sound, not spelling (an honest, a university). Learn words in synonym–antonym PAIRS, never alone.

9.
Label

Board question

Text

NEB 2024 (2): vocabulary MCQ — 'economical/economic' report; 'attach/ensure' the files. NEB 2023 (3): one synonym + one antonym each for 'abundant', 'brave', 'ancient'. NEB 2021 (2): articles — 'an honest girl … the promises she made'.
