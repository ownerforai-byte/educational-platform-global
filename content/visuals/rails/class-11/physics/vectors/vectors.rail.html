Cross product — area, torque and the right-hand rule

1.
Label

Concept

Text

The vector product C=A×B of two vectors is a third vector: magnitude ABsinθ, direction perpendicular to the plane of A and B by the right-hand rule (fingers along A, curl toward B, thumb gives C). Dot product measures sameness (projection); cross product measures perpendicularity (area).

2.
Label

Formula

Kind

formula

Text

|A × B| = AB sinθ, 0° ≤ θ ≤ 180° · A × B = AB sinθ n̂ · cyclic: î×ĵ=k̂, ĵ×k̂=î, k̂×î=ĵ · î×î = ĵ×ĵ = k̂×k̂ = 0

3.
Label

Conditions

Text

Defined for exactly two vectors in 3D space only (no A×B×C without brackets). θ is the smaller angle between them, 0° to 180°, so sinθ ≥ 0 and the magnitude is never negative.

4.
Label

Special cases

Text

Parallel (θ = 0°/180°) → A×B = 0, the test for parallelism. Perpendicular (θ = 90°) → |A×B| = AB, the maximum. Anti-commutative: B×A = −(A×B). Distributive over addition: A×(B+C) = A×B + A×C.

5.
Label

Solved

Text

Torque τ = r × F with r = 2î + 3ĵ m, F = 4î − 5ĵ N: τ = |î ĵ k̂; 2 3 0; 4 −5 0| = k̂(−10 − 12) = −22k̂ N·m — 22 N·m clockwise (into the page).

6.
Label

Limitation

Text

A×B = 0 does NOT mean a zero vector — parallel vectors qualify too. Not associative: A×(B×C) ≠ (A×B)×C in general. No true cross product in 2D (only a scalar pseudo-product AxBy − AyBx).

7.
Label

Derivation

Text

Expand by components: A×B = (Axî+Ayĵ+Azk̂)×(Bxî+Byĵ+Bzk̂). Self-products vanish, anti-cyclic pairs flip sign, leaving (AyBz−AzBy)î + (AzBx−AxBz)ĵ + (AxBy−AyBx)k̂ — exactly the determinant, with |A×B| = AB sinθ following from |A|²|B|² − (A·B)² = A²B²sin²θ.

8.
Label

Shortcut

Text

Memorise the cyclic order î→ĵ→k̂→î: forward = +, backward = −. Parallel → 0, perpendicular → max. |A×B| = parallelogram area, half of it = triangle area. Torque, magnetic force qv×B and angular momentum r×p are all the same product.
