1.

Evaluate: lim(x→0) (sin 3x)/x

Marks

2

Year

2024

Source

NEB Model

Solution

Using standard limit: lim(x→0) (sin x)/x = 1

lim(x→0) (sin 3x)/x = lim(x→0) [3·(sin 3x)/(3x)] = 3 × 1 = 3

Knowledge Note

Standard limits: lim(x→0) sin(ax)/x = a; lim(x→0) (1-cos x)/x² = 1/2; lim(x→0) tan x/x = 1

2.

Find lim(x→2) (x²-4)/(x-2)

Marks

2

Year

2023

Source

NEB Past

Solution

lim(x→2) (x²-4)/(x-2) = lim(x→2) (x+2)(x-2)/(x-2) = lim(x→2) (x+2) = 4

Knowledge Note

This is a 0/0 indeterminate form. Factorize and cancel common factors.

Practice
  • Evaluate: lim(x→0) (√(1+x)-1)/x — Answer: 1/2 (multiply by conjugate)
  • Evaluate: lim(x→∞) (3x²+2x+1)/(2x²-x+3) — Answer: 3/2 (divide by highest power)
  • Evaluate: lim(x→0) (1-cos 2x)/x² — Answer: 2
Examples
  • lim(x→0) sin(5x)/x = 5 — using sin(ax)/x = a
  • lim(x→0) (e^x-1)/x = 1 — exponential limit
Practice Questions
  • Evaluate: lim(x→0) (tan x)/x
  • Evaluate: lim(x→∞) (5x³+2x)/(3x³-x²+1)
  • Evaluate: lim(x→1) (x³-1)/(x-1)

Find dy/dx if y = x³ + 2x² - 5x + 3

Marks

2

Year

2024

Source

NEB Model

Solution

dy/dx = 3x² + 4x - 5

Using power rule: d/dx(x^n) = nx^(n-1)

Knowledge Note

Sum rule: d/dx(f+g) = f'+g'. Constant rule: d/dx(c) = 0.

2.

Find the derivative of y = sin x · cos x using product rule.

Marks

3

Year

2023

Source

NEB Model

Solution

Using product rule: (uv)' = u'v + uv' u = sin x, v = cos x u' = cos x, v' = -sin x

dy/dx = cos x · cos x + sin x · (-sin x) = cos²x - sin²x = cos 2x

Knowledge Note

Note: sin x cos x = ½sin 2x, so dy/dx = cos 2x directly.

3.

Find dy/dx for y = ln(sin x).

Marks

3

Year

2022

Source

NEB Past

Solution

Using chain rule: d/dx[ln(u)] = (1/u)·du/dx

Here u = sin x, du/dx = cos x

dy/dx = (1/sin x) · cos x = cot x

Knowledge Note

Chain rule: d/dx[f(g(x))] = f'(g(x)) · g'(x)

Practice
  • Find dy/dx if y = 3x⁴ - 2x³ + x - 7 — Answer: 12x³ - 6x² + 1
  • Find dy/dx if y = √x — Answer: 1/(2√x)
  • Find dy/dx if y = e^(2x) — Answer: 2e^(2x)
Examples
  • d/dx(x³) = 3x² — power rule application
  • d/dx(sin x) = cos x — standard derivative
Practice Questions
  • Find dy/dx if y = x⁵ - 3x³ + 2x
  • Find dy/dx if y = cos 3x
  • Find dy/dx if y = x² · e^x

Solution

∫(3x² + 2x - 1) dx = 3·(x³/3) + 2·(x²/2) - x + C = x³ + x² - x + C

Knowledge Note

Integration is the reverse of differentiation. Don't forget +C (constant of integration).

Solution

∫₀¹ x² dx = [x³/3]₀¹ = (1/3) - 0 = 1/3

Knowledge Note

Definite integral gives area under curve from a to b.

1.

What does it mean for a function to be continuous at x = a? Check if f(x) = x² is continuous at x = 1.

Marks

3

Year

2024

Source

NEB Model

Solution

Continuous at x=a if: (i) f(a) is defined, (ii) lim(x→a)f(x) exists, (iii) lim(x→a)f(x) = f(a).

For f(x) = x² at x=1: f(1) = 1 ✓ lim(x→1)x² = 1 ✓ 1 = 1 ✓ → continuous

Knowledge Note

Polynomials, sin x, cos x, e^x are continuous everywhere.
