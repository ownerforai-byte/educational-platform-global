Questions

1.

Find the direction cosines of the line joining the points A(1, 2, 3) and B(4, 5, 6), and write the equation of the line.

Marks

4

Year

2024

Source

NEB Model

Solution

Direction ratios: AB = (4 − 1, 5 − 2, 6 − 3) = (3, 3, 3).

Magnitude = √(9 + 9 + 9) = 3√3, so the direction cosines are (3, 3, 3)/(3√3) = (1/√3, 1/√3, 1/√3), and they satisfy l² + m² + n² = 1.

Equation of the line: (x − 1)/3 = (y − 2)/3 = (z − 3)/3, i.e. x − 1 = y − 2 = z − 3, or in vector form r = (i + 2j + 3k) + λ(i + j + k).

Knowledge Note

Direction ratios need not be unit vectors; direction cosines are the normalised ratios, and only for these does l² + m² + n² = 1 hold.

2.

Find the angle between the lines (x − 1)/2 = (y + 3)/−1 = z/3 and (x − 2)/1 = (y − 1)/2 = (z + 1)/−2.

Marks

5

Year

2024

Source

NEB Model

Solution

The direction ratios are d₁ = (2, −1, 3) and d₂ = (1, 2, −2).

cosθ = |d₁·d₂|/(|d₁||d₂|) = |2(1) + (−1)(2) + 3(−2)| / (√14 × 3) = |2 − 2 − 6|/(3√14) = 6/(3√14) = 2/√14 ≈ 0.535 → θ ≈ 57.7°.

Taking the absolute value gives the acute angle between the lines.

Knowledge Note

Use the absolute value in the numerator, otherwise the formula returns the obtuse supplement — a very frequent marking deduction.

3.

Find the equation of the plane passing through the point (2, 3, −1) with normal vector n = 2i − j + 3k.

Marks

3

Year

2024

Source

NEB Model

Solution

The plane through r₀ with normal n satisfies n·(r − r₀) = 0:

2(x − 2) − 1(y − 3) + 3(z + 1) = 0 2x − 4 − y + 3 + 3z + 3 = 0

2x − y + 3z + 2 = 0, i.e. 2x − y + 3z = −2.

In vector form: r·(2i − j + 3k) = 3 (since 2(2) − 3 + 3(−1) = −2... check: the constant equals n·r₀ = 4 − 3 − 3 = −2).

Knowledge Note

The plane's cartesian coefficients are exactly the normal's components — read the normal straight off the equation ax + by + cz + d = 0.
