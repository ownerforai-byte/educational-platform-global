Questions

1.

Explain the bisection method. One root of x³ − x − 2 = 0 lies between 1 and 2 — perform one iteration and give the refined interval.

Marks

3

Year

2024

Source

NEB Model

Solution

Bisection: bracket the root in [a, b] (f(a)·f(b) < 0), halve at m = (a+b)/2, keep the half where the sign changes.

f(1) = −2, f(2) = 4. Midpoint 1.5: f(1.5) = 3.375 − 1.5 − 2 = −0.125 < 0 — same sign as f(1).

Refined interval: (1.5, 2).

Knowledge Note

Bisection always converges (halving the error each step) but slowly — reliability is its selling point.

2.

Write the Newton-Raphson formula. Use one iteration starting from x₀ = 3.5 to approximate √12.

Marks

3

Year

2024

Source

NEB Model

Solution

Formula: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). For √12 use f(x) = x² − 12, f′ = 2x.

x₁ = 3.5 − (12.25 − 12)/7 = 3.5 − 0.0357 ≈ 3.464 (true √12 ≈ 3.4641 — one step is already accurate to 3 decimals).

Knowledge Note

Newton-Raphson converges quadratically near simple roots but fails if f′(x) ≈ 0 or the start is poor.

3.

State the trapezoidal rule. Use it with n = 2 to approximate ∫₀¹ x² dx.

Marks

3

Year

2024

Source

NEB Model

Solution

Trapezoidal rule: ∫ = h/2·[f(x₀) + 2Σinterior + f(xₙ)], h = (b−a)/n.

h = 0.5: integral ≈ (0.5/2)[0 + 2(0.25) + 1] = 0.25 × 1.5 = 0.375 (exact: 1/3 ≈ 0.333).

Knowledge Note

Trapezoidal overestimates convex-up curves — the error sign is predictable from curvature.

4.

State Simpson's 1/3 rule. Use it with n = 2 to evaluate ∫₀¹ x² dx and compare with the exact value.

Marks

3

Year

2024

Source

NEB Model

Solution

Simpson's 1/3: ∫ = h/3·[f(x₀) + 4Σodd + 2Σeven + f(xₙ)] (n even).

h = 0.5: integral ≈ (0.5/3)[0 + 4(0.25) + 1] = (0.5/3)(2) = 1/3 — exactly the true value, since Simpson's is exact for polynomials up to cubic.

Knowledge Note

Simpson's beats trapezoidal for smooth curves — exact through degree 3 with the same evaluations.

5.

A measurement is recorded as 2.54 cm against a true value of 2.50 cm. Find the absolute and relative errors.

Marks

2

Year

2024

Source

NEB Model

Solution

Absolute error = |measured − true| = |2.54 − 2.50| = 0.04 cm.

Relative error = 0.04/2.50 = 0.016 (1.6%).

Knowledge Note

Absolute error carries units; relative error is unit-free — always divide by the TRUE value.

6.

Distinguish between an algorithm and a flowchart. Write an algorithm to find the sum of the first n natural numbers.

Marks

3

Year

2024

Source

NEB Model

Solution

Algorithm: step-by-step procedure in words/pseudocode. Flowchart: the same logic drawn with symbols (ovals, diamonds, arrows).

Sum 1..n: (1) read n; (2) set sum = 0, i = 1; (3) repeat: sum += i, i += 1 until i > n; (4) print sum. (Closed form: n(n+1)/2.)

Knowledge Note

Every algorithm needs input, finite steps, and output — the three checkpoints of any 'write an algorithm' answer.
