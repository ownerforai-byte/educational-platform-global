1.

Q4(a). Prove that 2cos-1x = cos-1(2x^2-1).

Knowledge Note

Double-angle backwards: 2x^2-1 is cos2t in disguise; the principal range forces x >= 0.

Marks

3

Solution

Put t = cos-1x in [0, pi], so x = cost. Then 2x^2-1 = 2cos^2t-1 = cos2t. For 2t to be the principal value we need 2t in [0, pi], i.e. t in [0, pi/2], i.e. x >= 0; then cos-1(2x^2-1) = 2t = 2cos-1x. Proved (valid for 0 <= x <= 1; the book states it without the hypothesis).

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(a); book pp167-168 = PDF pp194-195

2.

Q4(b). Prove that 3cos-1x = cos-1(4x^3-3x).

Knowledge Note

Triple-angle backwards: 4x^3-3x is cos3t; needs 3t inside [0, pi], i.e. x >= 1/2.

Marks

3

Solution

Put t = cos-1x in [0, pi], so x = cost. Then 4x^3-3x = 4cos^3t-3cost = cos3t. For 3t to be the principal value we need 3t in [0, pi], i.e. t in [0, pi/3], i.e. x in [1/2, 1]; then cos-1(4x^3-3x) = 3t = 3cos-1x. Proved (valid for 1/2 <= x <= 1).

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(b); book pp167-168 = PDF pp194-195

3.

Q4(c). Prove that 3tan-1x = tan-1((3x-x^3)/(1-3x^2)).

Knowledge Note

tan3t expansion with tant = x; needs 3t inside (-pi/2, pi/2), i.e. |x| < 1/sqrt(3).

Marks

3

Solution

Put t = tan-1x in (-pi/2, pi/2), so x = tant. Then tan3t = (3tant-tan^3t)/(1-3tan^2t) = (3x-x^3)/(1-3x^2). For 3t to be the principal value we need 3t in (-pi/2, pi/2), i.e. |x| < 1/sqrt(3); then tan-1 of the fraction is 3t = 3tan-1x. Proved (valid for |x| < 1/sqrt(3)).

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(c); book pp167-168 = PDF pp194-195

4.

Q4(d). Prove that sin(arccos t) = cos(arcsin t).

Knowledge Note

Both sides equal sqrt(1-t^2): each cofunction lands on the non-negative branch.

Marks

2

Solution

arccos t lies in [0, pi] where sine is non-negative, so sin(arccos t) = +sqrt(1-t^2). arcsin t lies in [-pi/2, pi/2] where cosine is non-negative, so cos(arcsin t) = +sqrt(1-t^2). Both equal sqrt(1-t^2). Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(d); book pp167-168 = PDF pp194-195

Q4(e). Prove that cos(2arccost) = 2t^2-1.

2

Solution

Put u = arccost, so cosu = t. Then cos2u = 2cos^2u-1 = 2t^2-1. Proved.

Q4(g). Prove that cos(sin-1u+cos-1v) = v.sqrt(1-u^2)-u.sqrt(1-v^2). (T.U. 2049)

Knowledge Note

cos(A+B) = cosAcosB-sinAsinB with cosA = sqrt(1-u^2), sinB = sqrt(1-v^2): test u = v = 0 gives cos(pi/2) = 0. (T.U. 2049)

3

Solution

Put A = sin-1u (sinA = u, cosA = +sqrt(1-u^2)) and B = cos-1v (cosB = v, sinB = +sqrt(1-v^2)). Then cos(A+B) = cosAcosB-sinAsinB = v.sqrt(1-u^2)-u.sqrt(1-v^2). Check u = v = 0: LHS = cos(0+pi/2) = 0, RHS = 0. Proved.

8.

Q4(h). Prove that tan-1(1/5)+tan-1(1/7) = tan-1(6/17).

Knowledge Note

Sum formula with positive denominator 1-1/35: the sum stays acute.

Marks

2

Solution

(1/5+1/7)/(1-(1/5)(1/7)) = (12/35)/(34/35) = 12/34 = 6/17. Both angles are acute and their product 1/35 < 1, so the sum is the acute angle tan-1(6/17). Proved.

9.

Q4(i). Prove that tan-1a-tan-1c = tan-1((a-b)/(1+ab))+tan-1((b-c)/(1+bc)).

Knowledge Note

Telescoping in disguise: each RHS term is a difference of two tan-1, and the middle terms cancel.

Marks

3

Solution

Where defined (ab, bc > -1), tan-1((a-b)/(1+ab)) = tan-1a-tan-1b and tan-1((b-c)/(1+bc)) = tan-1b-tan-1c by the difference formula. Adding: the tan-1b terms cancel, leaving tan-1a-tan-1c. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(i); book pp167-168 = PDF pp194-195

10.

Q4(j). Prove that tan(arctanu-arctanv) = (u-v)/(1+uv).

Knowledge Note

tan(A-B) with tanA = u, tanB = v: one line.

Marks

2

Solution

Put A = arctanu, B = arctanv, so tanA = u and tanB = v. Then tan(A-B) = (tanA-tanB)/(1+tanAtanB) = (u-v)/(1+uv). Proved.

Q4(k). Prove that tan(2tan-1x) = 2tan(tan-1x+tan-1x^3). (HSEB 2052)

Knowledge Note

(x+x^3)/(1-x^4) simplifies by cancelling (1+x^2): the x^3 term is there to make this happen. (HSEB 2052)

Solution

tan(tan-1x+tan-1x^3) = (x+x^3)/(1-x.x^3) = x(1+x^2)/((1-x^2)(1+x^2)) = x/(1-x^2). Doubling: 2x/(1-x^2) = tan(2tan-1x). Proved.

12.

Q4(l). Prove that tan-1x+tan-1y+tan-1z = tan-1((x+y+z-xyz)/(1-xy-yz-zx)). (HSEB 2055)

Knowledge Note

tan(A+B+C) = (s1-xyz)/(1-s2): expand once, quote forever. (HSEB 2055)

Marks

3

Solution

Put A = tan-1x, B = tan-1y, C = tan-1z. Then tan(A+B+C) = (tanA+tanB+tanC-tanAtanBtanC)/(1-(tanAtanB+tanBtanC+tanCtanA)) = (x+y+z-xyz)/(1-xy-yz-zx). Taking tan-1 (principal branch where defined) gives the formula. Proved. (Statement via image read of the cut-off line.)

13.

Q4(m). Prove that sin-1(4/5)+sin-1(5/13)+sin-1(16/65) = pi/2. (HSEB 2053)

Knowledge Note

First two angles combine to cos-1(16/65); the third is its complement. (HSEB 2053)

Marks

3

Solution

sin of the first two summed: (4/5)(12/13)+(3/5)(5/13) = 48/65+15/65 = 63/65; cos: (3/5)(12/13)-(4/5)(5/13) = 36/65-20/65 = 16/65 > 0. So their sum is the acute angle with cosine 16/65, i.e. cos-1(16/65). Adding sin-1(16/65) gives pi/2. Proved.

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q4(m) (HSEB 2053); book p167 = PDF p194 (image read)

14.

Q4(n). Prove that tan-1(sqrt(x)) = (1/2)cos-1((1-x)/(1+x)) = (1/2)sin-1(2sqrt(x)/(1+x)). (T.U. 2055 S, HSEB 2054)

Knowledge Note

Put sqrt(x) = tant: both fractions become cos2t and sin2t with 2t in [0, pi/2]. (T.U. 2055 S, HSEB 2054)

Marks

3

Solution

For 0 <= x < 1 put sqrt(x) = tant with t in [0, pi/4). Then (1-tan^2t)/(1+tan^2t) = cos2t with 2t in [0, pi/2), so cos-1 of it is 2t; and 2tant/(1+tan^2t) = sin2t, so sin-1 of it is 2t. Halving gives t = tan-1(sqrt(x)) in both cases. Proved.

Q6(i). Solve tan-1((x-1)/(x-2))+tan-1((x+1)/(x+2)) = tan-1(1).

Knowledge Note

Sum formula: A+B and 1-AB turn out equal (both 6/7 at the roots), so the sum is genuinely pi/4.

Marks

3

Solution

With A = (x-1)/(x-2), B = (x+1)/(x+2): A+B = (2x^2-4)/(x^2-4), 1-AB = -3/(x^2-4). A+B = 1-AB gives 2x^2-4 = -3, i.e. x^2 = 1/2, x = +-1/sqrt(2). At both roots A+B = 6/7 > 0 and 1-AB = 6/7 > 0, so the sum is genuinely pi/4. Both valid. Matches the printed Answers key (p169): x = +-1/sqrt(2).
