Questions

1.

Q1(i). The angles of a triangle are 105° and 15°; find the ratio of its sides.

Knowledge Note

Name the two given angles A and C so the computed third angle sits in the middle: a:b:c then reads straight off as sin105:sin60:sin15.

Marks

3

Solution

The third angle is 180° - (105° + 15°) = 60°. Call the given angles A = 105° and C = 15°, so B = 60°. By the sine rule a:b:c = sinA:sinB:sinC = sin105°:sin60°:sin15°. Now sin105° = sin(60°+45°) = sin60°cos45° + cos60°sin45° = (√6+√2)/4, sin60° = √3/2 = 2√3/4, sin15° = sin(60°-45°) = (√6-√2)/4. Hence a:b:c = (√6+√2):2√3:(√6-√2). Since √6+√2 = √2(√3+1), √6-√2 = √2(√3-1) and 2√3 = √2·√6, dividing by √2 gives a:b:c = (√3+1):√6:(√3-1). Check: largest angle 105° faces the largest side √3+1 ≈ 2.73, smallest angle 15° faces √3-1 ≈ 0.73.

2.

Q1(ii). If A = 45°, B = 60°, show that a:c = 2:(√3+1).

Knowledge Note

sin75°/sin45° collapses to (√3+1)/2: expand sin75° = sin(45°+30°) rather than reaching for a calculator.

Marks

3

Solution

C = 180° - (45° + 60°) = 75°. By the sine rule a/c = sinA/sinC = sin45°/sin75°. Now sin75° = sin(45°+30°) = sin45°cos30° + cos45°sin30° = (1/√2)(√3/2) + (1/√2)(1/2) = (√3+1)/(2√2). So a/c = (1/√2) / ((√3+1)/(2√2)) = 2/(√3+1), i.e. a:c = 2:(√3+1). Verified: sin75° ≈ 0.966 and 2/(√3+1) = 2/2.732 ≈ 0.732 = sin45°/sin75° ≈ 0.707/0.966. ✓

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q1(ii); book p196 = PDF p223 (vision read)

3.

Q1(iii). If one angle of a triangle is 60° and the ratio of the other two is 1:3, find all the angles and the ratio of the sides.

Knowledge Note

Angles in ratio 1:3 with A = 60° give B = 30°, C = 90° at once: assign the 60° to the middle angle so a:b:c reads 1:√3:2.

Marks

3

Solution

Let the other two angles be x and 3x. Then x + 3x = 180° - 60° = 120°, so x = 30°. The three angles are 30°, 60°, 90°. Put B = 60° (the given angle), A = 30°, C = 90°. By the sine rule a:b:c = sin30°:sin60°:sin90° = (1/2):(√3/2):1 = 1:√3:2. Check: hypotenuse c = 2 opposite 90° is the longest side. ✓

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q1(iii); book p196 = PDF p223 (vision read)

4.

Q1(iv). The angles of a triangle are in the ratio 2:3:7. Prove that the sides are in the ratio √2:2:(√3+1).

Knowledge Note

2+3+7 = 12 parts, so one part is 15°: the angles are 30°, 45°, 105° and the sine ratio simplifies with a factor of √2.

Marks

4

Solution

2 + 3 + 7 = 12 parts = 180°, so one part is 15° and the angles are 30°, 45°, 105°. By the sine rule a:b:c = sin30°:sin45°:sin105° = (1/2):(1/√2):((√6+√2)/4). Multiplying by 4 gives 2:2√2:(√6+√2); dividing by √2 gives √2:2:(√3+1). Largest angle 105° faces √3+1 ≈ 2.73, the longest side. ✓

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q1(iv); book p196 = PDF p223 (vision read)

5.

Q1(v). If cosA = 4/5 and cosB = 3/5, find a:b:c.

Knowledge Note

cosA = 4/5, cosB = 3/5 is the 3-4-5 triangle in disguise: cos(A+B) = 0 forces C = 90°.

Marks

3

Solution

sinA = 3/5 and sinB = 4/5 (A, B acute). cos(A+B) = cosAcosB - sinAsinB = (4/5)(3/5) - (3/5)(4/5) = 0, so A+B = 90° and C = 90°, sinC = 1. By the sine rule a:b:c = sinA:sinB:sinC = (3/5):(4/5):1 = 3:4:5. Check: 3² + 4² = 5², consistent with C = 90°. ✓

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q1(v); book p196 = PDF p223 (vision read)

6.

Q2(i). Given a = 2, b = √2, c = √3+1, solve the triangle. (HSEB 2058)

Knowledge Note

c = √3+1 is the longest side, so expect C obtuse: cosine gives C = 105° directly, then sine for A and angle-sum for B.

Marks

4

Solution

c² = (√3+1)² = 4+2√3 ≈ 7.46 > a²+b² = 6, so C is obtuse. cosC = (a²+b²-c²)/(2ab) = (4+2-4-2√3)/(2·2·√2) = (2-2√3)/(4√2) = -(√3-1)/(2√2) = -sin15° = cos105°, so C = 105°. Then sinA = a·sinC/c = 2·sin105°/(√3+1) = 2(√6+√2)/(4(√3+1)) = √2(√3+1)/(2(√3+1)) = √2/2, and since a < c, A is acute: A = 45°. B = 180° - (105°+45°) = 30°. Answer: A = 45°, B = 30°, C = 105° (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q2(i) (HSEB 2058); book p196 = PDF p223 (vision read)

7.

Q2(ii). If a = 3+√3, b = 2√3, c = √6, solve the triangle.

Knowledge Note

a = 3+√3 is the longest side: cosine gives A = 105° at once; factor √3 out of (3+√3) when simplifying sinB.

Marks

4

Solution

cosA = (b²+c²-a²)/(2bc) = (12+6-(9+3+6√3))/(2·2√3·√6) = (6-6√3)/(4√18) = (1-√3)/(2√2) = -sin15° = cos105°, so A = 105°. Then sinB = b·sinA/a = 2√3·sin105°/(3+√3). Since 3+√3 = √3(√3+1) and sin105° = (√6+√2)/4 = √2(√3+1)/4, sinB = 2√3·√2(√3+1)/(4√3(√3+1)) = √2/2; with b < a, B is acute: B = 45°. C = 180° - (105°+45°) = 30°. Answer: A = 105°, B = 45°, C = 30° (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q2(ii); book p196-197 = PDF p223-224 (vision read)

8.

Q2(iii). If three sides of a triangle are proportional to 2:√6:√3+1, find all the angles. (HSEB 2056)

Knowledge Note

Same 45°-60°-75° triangle as the worked Example 5: c = √3+1 is longest, so cosine for C first, then sine for A.

Marks

4

Solution

Put a = 2k, b = √6·k, c = (√3+1)k. c² = (4+2√3)k² ≈ 7.46k² is the largest, so C is the largest angle. cosC = (a²+b²-c²)/(2ab) = (4+6-4-2√3)/(2·2·√6)·(1/k² cancels) = (6-2√3)/(4√6) = (3-√3)/(2√6) = √3(√3-1)/(2√6) = (√3-1)/(2√2) = sin15° = cos75°, so C = 75°. Then sinA = a·sinC/c = 2·sin75°/(√3+1) = √2/2 (as in Q2(i)); with a < c, A = 45°. B = 180° - (45°+75°) = 60°. Answer: 45°, 60°, 75° (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q2(iii) (HSEB 2056); book p197 = PDF p224 (vision read)

9.

Q3(i). If C = 30°, B = 45°, c = 6√2, solve the triangle.

Knowledge Note

Two angles given: the third is 105° and both unknown sides scale off c/sinC = 12√2; keep sin105° in surd form until the last step.

Marks

3

Solution

A = 180° - (30°+45°) = 105°. By the sine rule with c/sinC = 6√2/(1/2) = 12√2: b = 12√2·sin45° = 12√2·(1/√2) = 12; a = 12√2·sin105° = 12√2·(√6+√2)/4 = 3√2(√6+√2) = 3(2√3+2) = 6(√3+1). Answer: A = 105°, b = 12, a = 6(√3+1) (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q3(i); book p197 = PDF p224 (vision read)

10.

Q3(ii). If A = 60°, B = 75°, a = 2√3, solve the triangle.

Knowledge Note

A = 60° makes a/sinA simplify to 4: b and c then drop out as (√6+√2) and 2√2 with no calculator.

Marks

3

Solution

C = 180° - (60°+75°) = 45°. a/sinA = 2√3/(√3/2) = 4. So b = 4·sin75° = 4(√6+√2)/4 = √6+√2, and c = 4·sin45° = 4/√2 = 2√2. Answer: C = 45°, b = √6+√2, c = 2√2 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q3(ii); book p197 = PDF p224 (vision read)

11.

Q3(iii). If A = 30°, B = 45°, b = 2, solve the triangle.

Knowledge Note

Mirror of Q3(i) with the known side b = 2: the common factor b/sinB = 2√2 clears both denominators.

Marks

3

Solution

C = 180° - (30°+45°) = 105°. b/sinB = 2/(1/√2) = 2√2. So a = 2√2·sin30° = 2√2·(1/2) = √2, and c = 2√2·sin105° = 2√2(√6+√2)/4 = (√12+2)/2 = (2√3+2)/2 = √3+1. Answer: C = 105°, a = √2, c = √3+1 (matches the printed key).

12.

Q4(i). If a = 2, b = 4, C = 60°, find A and B.

Knowledge Note

SAS with a:b = 1:2 and included 60°: c = 2√3 first, then sinA = 1/2 with A < C forces the acute value A = 30°.

Marks

4

Solution

c² = a²+b²-2ab·cosC = 4+16-2·2·4·(1/2) = 20-8 = 12, so c = 2√3. Then sinA = a·sinC/c = 2(√3/2)/(2√3) = 1/2, giving A = 30° or 150°; A = 150° is impossible with C = 60° (sum > 180°), and a < c confirms A acute: A = 30°. B = 180° - (30°+60°) = 90°. Answer: A = 30°, B = 90° (matches the printed key; indeed 2²+(2√3)² = 4²).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q4(i); book p197 = PDF p224 (vision read)

13.

Q4(ii). Two sides of a triangle are √3+1 and √3-1 and the included angle is 60°; solve the triangle.

Knowledge Note

The sine rule alone gives sinA ≈ 0.966 (75° or 105°): the cosine rule breaks the tie — a is the longest side, so A = 105°. Classic exam trap.

Marks

5

Solution

Put a = √3+1, b = √3-1, C = 60°. c² = a²+b²-2ab·cos60° = (4+2√3)+(4-2√3)-(3-1) = 8-2 = 6, so c = √6 (matches the key). By the sine rule sinA = a·sinC/c = (√3+1)(√3/2)/√6 = (√3+1)/(2√2) ≈ 0.966, so A = 75° or 105°. Tie-break with cosine: a² = 4+2√3 ≈ 7.46 > b²+c² = (4-2√3)+6 ≈ 6.54, so A is obtuse: A = 105°. Then B = 180° - (105°+60°) = 15°. Answer: c = √6, A = 105°, B = 15° (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q4(ii); book p197 = PDF p224 (vision read)

14.

Q4(iii). Given a = √57, A = 60° and area Δ = 2√3, find b and c.

Knowledge Note

Area + cosine rule give bc = 8 and b²+c² = 65: (b+c)² = 81 turns it into the quadratic t²-9t+8 = 0.

Marks

4

Solution

Δ = (1/2)bc·sinA gives 2√3 = (1/2)bc(√3/2), so bc = 8. From the cosine rule a² = b²+c²-2bc·cosA: 57 = b²+c²-2·8·(1/2) = b²+c²-8, so b²+c² = 65. Then (b+c)² = 65+2·8 = 81, so b+c = 9. b, c are the roots of t²-9t+8 = 0, i.e. {8, 1}. Answer: b, c are 8 and 1 in some order (matches the printed key). Check: (1/2)·8·1·sin60° = 2√3. ✓

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q4(iii); book p197 = PDF p224 (vision read)

15.

Q5(i). Given a = 3, b = 3√3, A = 30°, solve the triangle. In which case is the solution ambiguous?

Knowledge Note

SSA with a < b but a > b·sinA: two triangles. B = 60° gives the right-angled one (c = 6); B = 120° gives C = 30° and c = a = 3.

Marks

5

Solution

sinB = b·sinA/a = 3√3·(1/2)/3 = √3/2, so B = 60° or 120°; both satisfy A+B < 180°, so this case is AMBIGUOUS with two solutions. If B = 60°: C = 90° and c = a/sinA = 3/(1/2) = 6. If B = 120°: C = 30° and c = a·sinC/sinA = 3 (equal angles give equal sides). Answer: B = 60°, C = 90°, c = 6; or B = 120°, C = 30°, c = 3 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q5(i) (ambiguous case); book p197 = PDF p224 (vision read)

16.

Q5(ii). Given a = 2, b = √3+1, A = 45°, solve the triangle. In which case is the solution ambiguous?

Knowledge Note

Same ambiguous pattern with surds: sinB = (√3+1)/(2√2) ≈ 0.966 gives B = 75°/105°. The printed key writes 'a = √6 / √2' but a = 2 is given — it means c (flag filed).

Marks

5

Solution

sinB = b·sinA/a = (√3+1)(1/√2)/2 = (√3+1)/(2√2) ≈ 0.966, so B = 75° or 105°; A+B = 120° or 150°, both below 180°, so this case is AMBIGUOUS with two solutions. If B = 75°: C = 60° and c = a·sinC/sinA = 2(√3/2)/(1/√2) = √6. If B = 105°: C = 30° and c = 2(1/2)/(1/√2) = √2. Answer: B = 75°, C = 60°, c = √6; or B = 105°, C = 30°, c = √2 (the printed Answers line writes 'a' for these, a label slip since a = 2 is given — verified by substitution: 2·sin60°/sin45° = √6. ✓).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q5(ii) (ambiguous case); book p197 = PDF p224 (vision read)

17.

Q5(iii). Given A = 30°, a = 6, b = 4 (take sin19°30′ = 1/3 and sin49°30′ = 3/4), solve the triangle. Is the solution ambiguous?

Knowledge Note

b < a kills the second value: B is acute (19°30′), C = 130°30′, and sinC = sin49°30′ = 3/4 makes c = 9 exactly.

Marks

4

Solution

sinB = b·sinA/a = 4(1/2)/6 = 1/3, so B = 19°30′ (taking the given value). Since b < a, B < A = 30°, so B must be acute — only ONE solution. C = 180° - (30°+19°30′) = 130°30′. Then c = a·sinC/sinA = 6·sin130°30′/(1/2) = 12·sin49°30′ = 12·(3/4) = 9. Answer: B = 19°30′, C = 130°30′, c = 9, unique (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.7 Ex 7.1 Q5(iii); book p197 = PDF p224 (vision read)
