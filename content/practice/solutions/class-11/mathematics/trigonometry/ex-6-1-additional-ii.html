1.

AQ7(i). If the angles of a triangle are to one another as 1:2:3, prove that the corresponding sides are 1:sqrt(3):2.

Knowledge Note

Angles 1:2:3 of 180 deg are 30/60/90: sides go as sin30:sin60:sin90 = 1:sqrt(3):2.

Marks

3

Solution

Let the angles be k, 2k, 3k with k + 2k + 3k = 180 deg, so k = 30 deg: angles 30, 60, 90 deg. By the sine rule a:b:c = sin30:sin60:sin90 = (1/2):(sqrt(3)/2):1 = 1:sqrt(3):2.

2.

AQ7(ii). If the sides of a triangle are 7 cms, 4*sqrt(3) cms, sqrt(13) cms, prove that the smallest angle is 30 deg.

Knowledge Note

Smallest side sqrt(13) is opposite the smallest angle: cosine rule gives cos = sqrt(3)/2.

Marks

3

Solution

The smallest angle is opposite the smallest side sqrt(13). By the cosine rule, cos = [7^2 + (4sqrt(3))^2 - (sqrt(13))^2]/[274sqrt(3)] = (49 + 48 - 13)/(56sqrt(3)) = 84/(56sqrt(3)) = 3/(2*sqrt(3)) = sqrt(3)/2. Hence the smallest angle is 30 deg.

3.

AQ7(iii). The angles of a triangle ABC are in A.P., and it is given that b:c = sqrt(3):sqrt(2). Find angle A. (Printed Answers line reads '7.(ii) 75 deg' - a label slip for 7.(iii); 7.(ii) is a proof with no numeric answer.)

Knowledge Note

Angles in A.P. force the middle to 60 deg; then b:c = sinB:sinC pins C = 45 deg.

Marks

3

Solution

Angles in A.P.: 2B = A + C with A + B + C = 180 deg gives 3B = 180, so B = 60 deg. Then b:c = sinB:sinC gives sqrt(3):sqrt(2) = (sqrt(3)/2):sinC, so sinC = sqrt(2)/2 and C = 45 deg (C = 135 deg impossible with B = 60). Hence A = 180 - 60 - 45 = 75 deg. (Filed: the printed answer '75 deg' belongs to this part (iii), not (ii).)

Source

Answer

A = 75 deg

4.

AQ7(iv). In triangle ABC, if angle A = 30 deg and b:c = 2:sqrt(3), find angle B.

Knowledge Note

Try B = 90 deg first: sinB:sinC = 1:sin60 = 2:sqrt(3) matches instantly.

Marks

3

Solution

B + C = 150 deg and sinB:sinC = 2:sqrt(3). With B = 90 deg, C = 60 deg: sinB:sinC = 1:(sqrt(3)/2) = 2:sqrt(3). This satisfies the ratio, and monotonicity of sinB/sin(150 deg - B) on (0, 150 deg) makes it unique. So B = 90 deg. Matches the printed Answers: 90 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q7(iv); book p189 = PDF p216-217 (vision read); matches key

Answer

B = 90 deg

5.

AQ7(v). If a = 2b and A = 3B, find the angles of the triangle.

Knowledge Note

sin3B = 2sinB gives sinB*(1 - 4sin^2B) = 0: with B under 60 deg, sinB = 1/2.

Marks

4

Solution

a:b = sinA:sinB gives 2:1 = sin3B:sinB, so sin3B = 2sinB. With sin3B = 3sinB - 4sin^3B: 3sinB - 4sin^3B = 2sinB, i.e. sinB*(1 - 4sin^2B) = 0. Since B is a triangle angle with 3B < 180 deg, sinB != 0, so sin^2B = 1/4 and (B acute) sinB = 1/2: B = 30 deg. Then A = 90 deg, C = 60 deg. Matches the printed Answers: 90, 30, 60 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q7(v); book p189 = PDF p216-217 (vision read); matches key

Answer

A = 90 deg, B = 30 deg, C = 60 deg

6.

AQ8. If 1/(a+b) + 1/(b+c) = 3/(a+b+c), show that angle B = 60 deg.

Knowledge Note

Mirror of Ex Q8 with a, b swapped: (a+c)^2 - b^2 = 3ca factors to cosB = 1/2.

Marks

4

Solution

[(b+c) + (a+b)]/[(a+b)(b+c)] = 3/(a+b+c), i.e. (a+2b+c)(a+b+c) = 3(a+b)(b+c). Put s1 = a+c: (s1+2b)(s1+b) = 3[b^2 + bs1 + ac], i.e. s1^2 + 3bs1 + 2b^2 = 3b^2 + 3b*s1 + 3ac, so s1^2 = b^2 + 3ac. Hence (a+c)^2 = b^2 + 3ac, i.e. a^2 + c^2 - b^2 = ac, so cosB = 1/2 and B = 60 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q8; book p189 = PDF p216-217 (vision read)

7.

AQ9(i). If in a triangle ABC, A = 60 deg, show that b + c = 2a*cos((B-C)/2).

Knowledge Note

b + c = 2R(sinB + sinC) = 4Rcos(A/2)*cos((B-C)/2): with A = 60 deg, cos(A/2) = a/(2R).

Marks

4

Solution

b + c = 2R(sinB + sinC) = 4Rsin((B+C)/2)cos((B-C)/2) = 4Rcos(A/2)cos((B-C)/2). With A = 60 deg, cos(A/2) = cos30 = sqrt(3)/2 and a = 2Rsin60 = 2Rsqrt(3)/2 = Rsqrt(3), so 4Rcos(A/2) = 4Rsqrt(3)/2 = 2Rsqrt(3) = 2a. Hence b + c = 2a*cos((B-C)/2).

Source

8.

AQ9(ii). In a triangle ABC, if angle B = 60 deg, prove that (a+b+c)*(a-b+c) = 3ca.

Knowledge Note

(a+c)^2 - b^2 = 3ca rearranges to a^2 + c^2 - b^2 = ca: read off cosB.

Marks

4

Solution

(a+b+c)*(a-b+c) = (a+c)^2 - b^2 = a^2 + c^2 + 2ac - b^2. With B = 60 deg, cosB = (a^2+c^2-b^2)/(2ac) = 1/2 gives a^2 + c^2 - b^2 = ac. Substituting: ac + 2ac = 3ca.

Source

AQ10(i). If in any triangle a:b:c = 2:3:4 and s = 27, find the area of the triangle.

Knowledge Note

a:b:c = 2:3:4 with s = 27 forces a = 12, b = 18, c = 24: Heron gives sqrt(271593) = 27sqrt(15).

Marks

3

Solution

2k + 3k + 4k = 2s = 54 gives k = 6: a = 12, b = 18, c = 24. Delta = sqrt[27(27-12)(27-18)(27-24)] = sqrt(271593) = sqrt(10935) = sqrt(72915) = 27sqrt(15) sq. units. Matches the printed Answers: 27*sqrt(15) sq. units.

AQ10(ii). In a triangle ABC, a = 5, b = 6 and C = 30 deg; show that its area is 7.5 sq. units.

Knowledge Note

Delta = (1/2)absinC: (1/2)56sin30 = 7.5 directly.

2

Solution

Delta = (1/2)absinC = (1/2)56sin30 = 15*(1/2) = 7.5 sq. units.

11.

AQ10(iii). In a triangle ABC, if a = sqrt(2), b = sqrt(3) and c = sqrt(5), show that its area is (1/2)*sqrt(6) sq. units.

Knowledge Note

2^2 + 3^2 ... (sqrt(2))^2 + (sqrt(3))^2 = (sqrt(5))^2: right triangle, legs sqrt(2), sqrt(3).

Marks

3

Solution

a^2 + b^2 = 2 + 3 = 5 = c^2, so the triangle is right angled at C. Delta = (1/2)ab = (1/2)sqrt(2)sqrt(3) = (1/2)*sqrt(6) sq. units.

12.

AQ11. In any triangle ABC, if a = 13 cms, b = 14 cms, c = 15 cms, find sin(A/2), cos(A/2), sinA, cosA and tan(A/2).

Knowledge Note

s = 21: sin(A/2) = sqrt[(s-b)(s-c)/(bc)] = sqrt(1/5); everything else follows by doubling.

Marks

5

Solution

s = (13+14+15)/2 = 21. sin(A/2) = sqrt[(s-b)(s-c)/(bc)] = sqrt[(76)/(1415)] = sqrt(42/210) = 1/sqrt(5). cos(A/2) = sqrt[s(s-a)/(bc)] = sqrt[(218)/210] = sqrt(4/5) = 2/sqrt(5). sinA = 2sin(A/2)cos(A/2) = 2(1/sqrt(5))(2/sqrt(5)) = 4/5. cosA = (b^2+c^2-a^2)/(2bc) = (196+225-169)/(214*15) = 252/420 = 3/5. tan(A/2) = sin(A/2)/cos(A/2) = 1/2.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q11; book p190 = PDF p217 (vision read)

Answer

sin(A/2) = 1/sqrt(5), cos(A/2) = 2/sqrt(5), sinA = 4/5, cosA = 3/5, tan(A/2) = 1/2

13.

AQ12(i). If a, b, c are in A.P., prove that 3tan(A/2)tan(C/2) = 1.

Knowledge Note

a, b, c in A.P. means 2sinB = sinA + sinC: divide by 2cos(B/2) to get 2sin(B/2) = cos((A-C)/2), then use tan product formula.

Marks

4

Solution

2b = a + c gives 2sinB = sinA + sinC, i.e. 4sin(B/2)cos(B/2) = 2sin((A+C)/2)cos((A-C)/2) = 2cos(B/2)cos((A-C)/2), so 2sin(B/2) = cos((A-C)/2). Now tan(A/2)tan(C/2) = [cos((A-C)/2) - cos((A+C)/2)]/[cos((A-C)/2) + cos((A+C)/2)]. Since cos((A+C)/2) = sin(B/2), this is [2sin(B/2) - sin(B/2)]/[2sin(B/2) + sin(B/2)] = sin(B/2)/[3sin(B/2)] = 1/3. Hence 3tan(A/2)*tan(C/2) = 1.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q12(i); book p190 = PDF p217 (vision read)

14.

AQ12(ii). If b, a, c are in A.P., prove that cos((B-C)/2) = 2*sin(A/2).

Knowledge Note

2a = b + c becomes 2sinA = 2cos(A/2)*cos((B-C)/2): cancel cos(A/2).

Marks

4

Solution

2a = b + c gives 2sinA = sinB + sinC = 2sin((B+C)/2)cos((B-C)/2) = 2cos(A/2)cos((B-C)/2). Since 2sinA = 4sin(A/2)cos(A/2), dividing by 2cos(A/2) gives 2sin(A/2) = cos((B-C)/2).

15.

AQ13. If b - a = mc, prove that cot((B-A)/2) = (1 + mcosB)/(msinB).

Knowledge Note

c + (b-a)cosB = b(cosA + cosB) = 2bcos((A+B)/2)cos((A-B)/2): the sine-rule ratio collapses to cot((B-A)/2).

Marks

5

Solution

m = (b-a)/c. Then (1 + mcosB)/(msinB) = [c + (b-a)cosB]/[(b-a)sinB]. Numerator: c + (b-a)cosB = (acosB + bcosA) + (b-a)cosB (projection law) = b(cosA + cosB) = 2bcos((A+B)/2)cos((A-B)/2) = 2bsin(C/2)cos((B-A)/2). Denominator: (b-a)sinB = 2R(sinB - sinA)sinB = 2R2cos((A+B)/2)sin((B-A)/2)sinB = 4Rsin(C/2)sin((B-A)/2)sinB. Ratio: [2bsin(C/2)cos((B-A)/2)]/[4Rsin(C/2)sin((B-A)/2)sinB] = [22RsinBcos((B-A)/2)]/[4Rsin((B-A)/2)*sinB] = cos((B-A)/2)/sin((B-A)/2) = cot((B-A)/2).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q13; book p190 = PDF p217 (vision read)
