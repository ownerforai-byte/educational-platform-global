1.

Q6. If a^4 + b^4 + c^4 = 2c^2*(a^2+b^2), prove that C = 45 deg or 135 deg. (T.U. 2051) (HSEB 2056)

Knowledge Note

Move everything left: (a^2+b^2-c^2)^2 = 2a^2b^2, then cosC = +-1/sqrt(2).

Marks

5

Solution

a^4 + b^4 + c^4 - 2a^2c^2 - 2b^2c^2 = 0. Add 2a^2b^2 to both sides: (a^4 + b^4 + c^4 + 2a^2b^2 - 2a^2c^2 - 2b^2c^2) = 2a^2b^2, i.e. (a^2+b^2-c^2)^2 = 2a^2b^2. So a^2+b^2-c^2 = +-sqrt(2)*ab, and cosC = (a^2+b^2-c^2)/(2ab) = +-sqrt(2)/2. With 0 < C < pi, C = 45 deg or 135 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q6 (T.U. 2051) (HSEB 2056); book pp187-188 = PDF p215 (vision read)

2.

Q7. If (a+b+c)*(b+c-a) = 3bc, show that A = 60 deg.

Knowledge Note

(b+c)^2 - a^2 = 3bc factors to b^2+c^2-a^2 = bc: read off cosA = 1/2.

Marks

3

Solution

(a+b+c)*(b+c-a) = (b+c)^2 - a^2 = b^2 + c^2 + 2bc - a^2. Setting this equal to 3bc gives b^2 + c^2 - a^2 = bc, so cosA = (b^2+c^2-a^2)/(2bc) = 1/2. With 0 < A < pi, A = 60 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q7; book p188 = PDF p215 (vision read)

3.

Q8. If 1/(a+c) + 1/(b+c) = 3/(a+b+c), show that C = 60 deg. (T.U. 2054, HSEB 2053)

Knowledge Note

Clear denominators: (a+c)+(b+c) over product form collapses to (a+b)^2 = c^2 + 3ab.

Marks

4

Solution

Combining: [(b+c) + (a+c)]/[(a+c)(b+c)] = 3/(a+b+c), i.e. (a+b+2c)(a+b+c) = 3[(a+c)(b+c)]. Put s1 = a+b: (s1+2c)(s1+c) = 3[c^2 + cs1 + ab], i.e. s1^2 + 3cs1 + 2c^2 = 3c^2 + 3c*s1 + 3ab, so s1^2 = c^2 + 3ab. Hence (a+b)^2 = c^2 + 3ab, i.e. a^2 + b^2 - c^2 = ab, so cosC = 1/2 and C = 60 deg.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q8 (T.U. 2054, HSEB 2053); book p188 = PDF p215 (vision read)

4.

Q9. If the cosines of two of the angles of a triangle are proportional to the opposite sides, prove that the triangle is isosceles.

Knowledge Note

cosA/a = cosB/b becomes sinBcosA = sinAcosB, i.e. sin(B-A) = 0.

Marks

4

Solution

Suppose cosA/a = cosB/b (the same argument works for any pair). Then bcosA = acosB, i.e. 2RsinBcosA = 2RsinAcosB, so sinBcosA - sinAcosB = sin(B-A) = 0. With angles in (0, pi), B - A = 0, so A = B and the triangle is isosceles.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q9; book p188 = PDF p215 (vision read)

5.

Q10. If (cosA + 2cosC):(cosA + 2cosB) = sinB:sinC, prove that the triangle is either isosceles or right-angled.

Knowledge Note

Either cosA = 0 (right-angled) or the sine factors force B = C: factor, never divide blindly.

Marks

5

Solution

Cross-multiplying: (cosA + 2cosC)sinC = (cosA + 2cosB)sinB, i.e. cosA(sinC - sinB) = 2(sinBcosB - sinCcosC) = sin2B - sin2C. Now sin2B - sin2C = 2cos(B+C)sin(B-C) = -2cosAsin(B-C), and sinC - sinB = 2cos((B+C)/2)sin((C-B)/2) = 2sin(A/2)sin((C-B)/2). So 2cosAsin(A/2)sin((C-B)/2) = -2cosAsin(B-C) = 4cosAsin((C-B)/2)cos((C-B)/2). If cosA = 0 then A = 90 deg (right-angled). Otherwise divide by 2cosAsin((C-B)/2) (zero only if B = C, isosceles): sin(A/2) = 2cos((C-B)/2). But |(C-B)/2| < (B+C)/2 = (pi-A)/2 gives cos((C-B)/2) > cos((pi-A)/2) = sin(A/2), so 2cos((C-B)/2) > sin(A/2) always and this case never occurs. Hence B = C (isosceles) or A = 90 deg (right-angled).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q10; book p188 = PDF p215 (vision read)

6.

Q11. If 2cosA = sinB/sinC, show that the triangle is isosceles.

Knowledge Note

2sinCcosA = sinB expands to sin(C-A) = 0 via sinB = sin(A+C).

Marks

4

Solution

2sinCcosA = sinB = sin(A+C) = sinAcosC + cosAsinC. Subtracting cosAsinC: sinCcosA = sinAcosC, i.e. sinCcosA - sinA*cosC = sin(C-A) = 0. With angles in (0, pi), C = A, so the triangle is isosceles.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q11; book p188 = PDF p215 (vision read)

7.

Q12. Prove that a^2, b^2, c^2 are in A.P. if sinA:sinC = sin(A-B):sin(B-C).

Knowledge Note

Translate both sides to cos2: the condition becomes cos2A + cos2C = 2cos2B, the AP condition.

Marks

5

Solution

a^2, b^2, c^2 in A.P. means 2sin^2B = sin^2A + sin^2C (dividing by 4R^2), i.e. (1-cos2B) = (1-cos2A)/2 + (1-cos2C)/2, i.e. cos2A + cos2C = 2cos2B. The given condition: sinAsin(B-C) = sinC*sin(A-B). Left: [cos(A-B+C) - cos(A+B-C)]/2 = [cos(pi-2B) - cos(pi-2C)]/2 = (cos2C - cos2B)/2. Right: [cos(C-A+B) - cos(C+A-B)]/2 = [cos(pi-2A) - cos(pi-2B)]/2 = (cos2B - cos2A)/2. Equality gives cos2C - cos2B = cos2B - cos2A, i.e. cos2A + cos2C = 2cos2B, exactly the A.P. condition.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q12 (condition continues on book p188); book p188 = PDF pp215-216 (vision read)

8.

Q14. If 8R^2 = a^2 + b^2 + c^2, prove that the triangle is right angled. (T.U. 2057S)

Knowledge Note

a^2+b^2+c^2 = 4R^2(sum sin^2) = 8R^2(1 + cosAcosBcosC): the 8R^2 forces a zero cosine.

Marks

4

Solution

a^2 + b^2 + c^2 = 4R^2(sin^2A + sin^2B + sin^2C). Since sin^2A + sin^2B + sin^2C = 2 + 2cosAcosBcosC (standard identity), this equals 8R^2(1 + cosAcosBcosC). Setting it equal to 8R^2 gives cosAcosB*cosC = 0, so one angle is 90 deg: the triangle is right angled.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q14 (T.U. 2057S); book p188 = PDF p215-216 (vision read)

9.

Q15. If a = 10, b = 8, c = 6, find s, Delta, R and sin(B/2).

Knowledge Note

6-8-10 is the scaled 3-4-5 right triangle: s = 12, Delta = 24, R = 5 fall out immediately.

Marks

4

Solution

s = (10+8+6)/2 = 12. Delta = sqrt[s(s-a)(s-b)(s-c)] = sqrt[12246] = sqrt(576) = 24. R = abc/(4Delta) = 480/96 = 5. sin(B/2) = sqrt[(s-a)(s-c)/(ac)] = sqrt[(12-10)(12-6)/(10*6)] = sqrt(12/60) = sqrt(1/5) = 1/sqrt(5). Matches the printed Answers (p190): 15. 12, 24, 5, 1/sqrt(5).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q15; book p188 = PDF p216 (vision read); matches key

Answer

s = 12, Delta = 24, R = 5, sin(B/2) = 1/sqrt(5)
