Questions

1.

Q3(a). In any triangle, prove that (b+c)cosA + (c+a)cosB + (a+b)*cosC = a + b + c.

Knowledge Note

Regroup into the three projection pairs: (bcosA + acosB) = c and friends.

Marks

4

Solution

Regroup the left side as (bcosA + acosB) + (ccosB + bcosC) + (acosC + ccosA). By the projection law bcosA + acosB = c, ccosB + bcosC = a, and acosC + ccosA = b. Adding gives c + a + b = a + b + c.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q3(a); book p186 = PDF p213-214 (vision read)

2.

Q3(b). In any triangle, prove that b^2sin2C + c^2sin2B = 2ab*sinC. (T.U. 2051H)

Knowledge Note

Write everything with a = 2RsinA: both sides become 8R^2sinAsinBsinC.

Marks

4

Solution

Left side: b^22sinCcosC + c^22sinBcosB = 8R^2sin^2BsinCcosC + 8R^2sin^2CsinBcosB = 8R^2sinBsinC(sinBcosC + cosBsinC) = 8R^2sinBsinCsin(B+C) = 8R^2sinAsinBsinC. Right side: 2(2RsinA)(2RsinB)sinC = 8R^2sinAsinB*sinC. Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q3(b) (T.U. 2051H); book p186 = PDF p214 (vision read)

3.

Q3(c). In any triangle, prove that c^2cos^2B + b^2cos^2C + bc*cos(B-C) = (a^2 + b^2 + c^2)/2. (T.U. 2058S)

Knowledge Note

The trick is (bcosC + ccosB)^2 = a^2: expand it to isolate c^2cos^2B + b^2cos^2C.

Marks

5

Solution

From the projection law a = bcosC + ccosB, squaring gives a^2 = b^2cos^2C + c^2cos^2B + 2bccosBcosC, so c^2cos^2B + b^2cos^2C = a^2 - 2bccosBcosC. Substituting: left side = a^2 - 2bccosBcosC + bccos(B-C) = a^2 - 2bccosBcosC + bc(cosBcosC + sinBsinC) = a^2 - bc(cosBcosC - sinBsinC) = a^2 - bccos(B+C) = a^2 + bccosA. Since bccosA = (b^2+c^2-a^2)/2, this is a^2 + (b^2+c^2-a^2)/2 = (a^2+b^2+c^2)/2.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q3(c) (T.U. 2058S); book p186 = PDF p214 (vision read; the 1/2 on the right confirmed in print)

4.

Q3(d). In any triangle, prove that (c - bcosA)/(b - ccosA) = cosB/cosC. (HSEB 2064)

Knowledge Note

c - bcosA = 2RsinA*cosB: the sinA factor cancels in the ratio.

Marks

4

Solution

c - bcosA = 2RsinC - 2RsinBcosA = 2R[sin(A+B) - sinBcosA] = 2RsinAcosB. Likewise b - ccosA = 2RsinB - 2RsinCcosA = 2R[sin(A+C) - sinCcosA] = 2RsinAcosC. Dividing (cosA != 0; if cosA = 0 both numerator and denominator reduce via the projection law) gives cosB/cosC.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q3(d) (HSEB 2064); book pp186-187 = PDF pp213-214 (vision read)

5.

Q3(e). In any triangle, prove that (a - bcosC)/(c - bcosA) = sinC/sinA.

Knowledge Note

Same 2R expansion as Q3(d): a - bcosC = 2RsinC*cosB, and the cosB cancels.

Marks

4

Solution

a - bcosC = 2RsinA - 2RsinBcosC = 2R[sin(B+C) - sinBcosC] = 2RcosBsinC. From Q3(d), c - bcosA = 2RsinAcosB. Dividing gives (2RsinCcosB)/(2RsinA*cosB) = sinC/sinA.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q3(e); book p187 = PDF p214 (vision read)

6.

Q4(a). In any triangle, prove that a^3sin(B-C) + b^3sin(C-A) + c^3*sin(A-B) = 0.

Knowledge Note

Use cosB = (a^2+c^2-b^2)/(2ac): each product a^3bcosC collapses to a^2*(a^2+b^2-c^2)/2.

Marks

4

Solution

Write sin(B-C) = sinBcosC - cosBsinC = (bcosC - ccosB)/(2R), so a^3sin(B-C) = a^3(bcosC - ccosB)/(2R). Summing cyclically and multiplying by 2R gives [a^3bcosC + b^3ccosA + c^3acosB] - [a^3ccosB + b^3acosC + c^3bcosA]. Now a^3bcosC = a^3b(a^2+b^2-c^2)/(2ab) = a^2(a^2+b^2-c^2)/2, and cyclically; their sum is (1/2)[sum a^4 + sum a^2b^2 - sum a^2c^2] = (1/2)sum a^4 since the two mixed sums are equal. Likewise a^3ccosB = a^2(a^2+c^2-b^2)/2, summing to the same (1/2)*sum a^4. Their difference is 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q4(a); book p187 = PDF p214 (vision read; cubes confirmed: a^3, b^3, c^3)

7.

Q4(b). In any triangle, prove that [(b^2-c^2)/a^2]sin2A + [(c^2-a^2)/b^2]sin2B + [(a^2-b^2)/c^2]*sin2C = 0.

Knowledge Note

[(b^2-c^2)/a^2]sin2A reduces to 2sin(B-C)cosA; then sin(B-C)cosA = (sin2C - sin2B)/2 telescopes.

Marks

5

Solution

(b^2-c^2)/a^2 = 4R^2sin(B-C)sinA/(4R^2sin^2A) = sin(B-C)/sinA, so the first term is [sin(B-C)/sinA]2sinAcosA = 2sin(B-C)cosA (and cyclically). Now 2sin(B-C)cosA = 2*[sin(B-C+A) + sin(B-C-A)]/2 = sin(pi-2C) + sin(-(pi-2B)) = sin2C - sin2B. Summing cyclically: (sin2C - sin2B) + (sin2A - sin2C) + (sin2B - sin2A) = 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q4(b); book p187 = PDF p214 (vision read; denominators a^2, b^2, c^2 confirmed)

8.

Q4(c). In any triangle, prove that (a^2-b^2+c^2)tanB = (a^2+b^2-c^2)tanC = (b^2+c^2-a^2)*tanA.

Knowledge Note

Each leg equals abc/R: (a^2-b^2+c^2)tanB = 2acsinB.

Marks

4

Solution

a^2 - b^2 + c^2 = 2accosB by the cosine rule, so the first expression is 2accosBtanB = 2acsinB = 2ac(b/2R) = abc/R. Cyclically the second is 2absinC = abc/R and the third is 2bc*sinA = abc/R. All three equal abc/R, hence are equal.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q4(c); book p187 = PDF pp214-215 (vision read)

9.

Q4(d). In any triangle, prove that (cosB - cosC)/(cosA + 1) = (c - b)/a.

Knowledge Note

Sum-to-product on top and bottom: cosB - cosC = -2cos(A/2)sin((B-C)/2), cosA + 1 = 2*cos^2(A/2).

Marks

4

Solution

cosB - cosC = -2sin((B+C)/2)sin((B-C)/2) = -2cos(A/2)sin((B-C)/2), and cosA + 1 = 2cos^2(A/2). So the left side is -sin((B-C)/2)/cos(A/2). Meanwhile (c-b)/a = (sinC - sinB)/sinA = [2cos((B+C)/2)sin((C-B)/2)]/[2sin(A/2)cos(A/2)] = [2sin(A/2)(-sin((B-C)/2))]/[2sin(A/2)*cos(A/2)] = -sin((B-C)/2)/cos(A/2). Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q4(d); book p187 = PDF p215 (vision read)

10.

Q4(e). In any triangle, prove that (asinA + bsinB + csinC)/(acosA + bcosB + ccosC) = R*(a^2+b^2+c^2)/(abc).

Knowledge Note

Numerator = 2Rsum sin^2, denominator = abc/(2R^2): their ratio is exactly R(a^2+b^2+c^2)/(abc).

Marks

5

Solution

Numerator: asinA + bsinB + csinC = 2R(sin^2A + sin^2B + sin^2C) = 2R(a^2+b^2+c^2)/(4R^2) = (a^2+b^2+c^2)/(2R). Denominator: acosA + bcosB + ccosC = 2R(sinAcosA + sinBcosB + sinCcosC) = R(sin2A + sin2B + sin2C) = R4sinAsinBsinC = 4R(a/2R)(b/2R)(c/2R) = abc/(2R^2). Dividing: [(a^2+b^2+c^2)/(2R)]/[abc/(2R^2)] = R*(a^2+b^2+c^2)/(abc).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q4(e); book p187 = PDF p215 (vision read)
