1.

Q7(a). If tan-1x+tan-1y+tan-1z = pi, prove that x+y+z = xyz. (T.U. 2050)

Knowledge Note

tan of the sum is tan(pi) = 0: the numerator x+y+z-xyz must vanish. (T.U. 2050)

Marks

3

Solution

Take tan of both sides: tan(tan-1x+tan-1y+tan-1z) = tan(pi) = 0. The left side is (x+y+z-xyz)/(1-xy-yz-zx), so its numerator is 0 (denominator nonzero): x+y+z = xyz. Proved.

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q7(a) (T.U. 2050); book p168 = PDF p195 (image read)

2.

Q7(b). If tan-1x+tan-1y+tan-1z = pi/2, prove that xy+yz+zx = 1. (T.U. 2048, 2050)

Knowledge Note

tan of pi/2 is undefined: the denominator 1-(xy+yz+zx) must vanish. (T.U. 2048, 2050)

Marks

3

Solution

tan of the sum is tan(pi/2), undefined, while the expansion is (x+y+z-xyz)/(1-xy-yz-zx). Hence the denominator is 0: 1-(xy+yz+zx) = 0, i.e. xy+yz+zx = 1. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q7(b) (T.U. 2048, 2050); book p168 = PDF p195 (image read)

3.

Q8. If cos-1x+cos-1y+cos-1z = pi, show that x^2+y^2+z^2+2xyz = 1. (T.U. 2056 S)

Knowledge Note

cos(A+B) = -cosC, then one squaring: the cross term 2xyz appears. (T.U. 2056 S)

Marks

3

Solution

Put A = cos-1x, B = cos-1y, C = cos-1z with A+B = pi-C. Then cos(A+B) = -cosC, i.e. xy-sqrt((1-x^2)(1-y^2)) = -z, i.e. xy+z = +sqrt((1-x^2)(1-y^2)) (non-negative here). Squaring: x^2y^2+2xyz+z^2 = 1-x^2-y^2+x^2y^2, i.e. x^2+y^2+z^2+2xyz = 1. Shown.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q8 (T.U. 2056 S); book pp168-169 = PDF pp195-196 (image read)

4.

Q9(i). Prove that tan-1(3/5)+sin-1(3/5) = tan-1(27/11).

Knowledge Note

tanA = 3/5 with tanB = 3/4: (27/20)/(11/20) = 27/11, and the sum stays under 90deg.

Marks

3

Solution

tanA = 3/5 for A = tan-1(3/5); sinB = 3/5 gives cosB = 4/5 and tanB = 3/4 for B = sin-1(3/5). tan(A+B) = (3/5+3/4)/(1-(3/5)(3/4)) = (27/20)/(11/20) = 27/11. A ~ 30.96deg and B ~ 36.87deg are acute with sum ~ 67.8deg < 90deg, so A+B = tan-1(27/11). Proved. (Confirmed against an independent NEB-video statement of the same question.)

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q9(i); book p169 = PDF p196 (image read)

5.

Q9(ii). Prove that tan-1(1/3)+tan-1(1/5)+tan-1(1/7)+tan-1(1/8) = pi/4.

Knowledge Note

Pair them: (1/3,1/5) -> 4/7 and (1/7,1/8) -> 3/11, then (65/77)/(65/77) = 1.

Marks

3

Solution

tan-1(1/3)+tan-1(1/5) = tan-1((8/15)/(14/15)) = tan-1(4/7); tan-1(1/7)+tan-1(1/8) = tan-1((15/56)/(55/56)) = tan-1(3/11). Then tan-1(4/7)+tan-1(3/11) = tan-1((65/77)/(65/77)) = tan-1(1) = pi/4, all sums acute with positive denominators. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q9(ii); book p169 = PDF p196 (image read)

6.

Q9(iii). Prove that 2tan-1(1/3)+tan-1(1/7) = pi/4. (HSEB 2051)

Knowledge Note

Double 1/3 to 3/4 first (2.(1/3)/(1-1/9) = 3/4), then add 1/7 to reach exactly 1. (HSEB 2051)

Marks

3

Solution

2tan-1(1/3) = tan-1(2.(1/3)/(1-1/9)) = tan-1((2/3)/(8/9)) = tan-1(3/4). Then tan-1(3/4)+tan-1(1/7) = tan-1((3/4+1/7)/(1-3/28)) = tan-1((25/28)/(25/28)) = tan-1(1) = pi/4. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q9(iii) (HSEB 2051); book p169 = PDF p196 (image read)

7.

Q9(iv). Prove that 4(cot-13+cosec-1(sqrt(5))) = pi. (HSEB 2058)

Knowledge Note

cot-13 = tan-1(1/3) and cosec-1(sqrt(5)) = tan-1(1/2): sum to tan-1(1) = pi/4, times 4. (HSEB 2058)

Marks

3

Solution

cot-13 = tan-1(1/3). cosec-1(sqrt(5)) = sin-1(1/sqrt(5)); with sin = 1/sqrt(5), tan = (1/sqrt(5))/(2/sqrt(5)) = 1/2, so it equals tan-1(1/2). Sum: tan-1(1/3)+tan-1(1/2) = tan-1((5/6)/(5/6)) = tan-1(1) = pi/4. Times 4: pi. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q9(iv) (HSEB 2058); book p169 = PDF p196 (image read)

8.

Q9(v). Prove that tan-11+tan-12+tan-13 = pi = 2(tan-11+tan-1(1/2)+tan-1(1/3)). (T.U. 2051, 54)

Knowledge Note

tan-12+tan-13 = 3pi/4 (ratio -1 with sum past pi/2); the half-weight inner sum is pi/2. (T.U. 2051, 54)

Marks

3

Solution

tan-12+tan-13: (2+3)/(1-6) = -1 with both acute and sum in (pi/2, pi), so 3pi/4; plus tan-11 = pi/4 gives pi. Inner: tan-1(1/2)+tan-1(1/3) = tan-1((5/6)/(5/6)) = tan-1(1) = pi/4; plus tan-11 = pi/2; doubled = pi. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q9(v) (T.U. 2051, 54); book p169 = PDF p196 (image read)

9.

Q10(i). Prove that sin-1(sqrt((x-b)/(a-b))) = cos-1(sqrt((a-x)/(a-b))) = tan-1(sqrt((x-b)/(a-x))). (T.U. 2057 S)

Knowledge Note

One parameter t = sin^2 of the first form: cos and tan drop out of 1-t. (T.U. 2057 S)

Marks

3

Solution

For b <= x <= a put t = sin-1(sqrt((x-b)/(a-b))) =: u. Then cosu = +sqrt(1-(x-b)/(a-b)) = sqrt((a-x)/(a-b)), so u = cos-1(sqrt((a-x)/(a-b))); and tanu = sinu/cosu = sqrt((x-b)/(a-x)), so u = tan-1(sqrt((x-b)/(a-x))). All three equal u. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q10(i) (T.U. 2057 S); book p169 = PDF p196 (image read)

10.

Q10(ii). Prove that cos-1x = 2sin-1(sqrt((1-x)/2)) = 2cos-1(sqrt((1+x)/2)).

Knowledge Note

Half-angle in sin^2/cos^2 form with t = cos-1x.

Marks

2

Solution

Put t = cos-1x, so x = cost. Then sqrt((1-x)/2) = sqrt((1-cost)/2) = sin(t/2) (t/2 in [0, pi/2], non-negative), so 2sin-1 of it is t. Likewise sqrt((1+x)/2) = cos(t/2), so 2cos-1 of it is t. Both equal cos-1x. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q10(ii); book p169 = PDF p196 (image read)

Q11. If sin-1x+sin-1y+sin-1z = pi, prove that x.sqrt(1-x^2)+y.sqrt(1-y^2)+z.sqrt(1-z^2) = 2xyz. (T.U. 2052)

Knowledge Note

sin2A+sin2B+sin2C = 4sinAsinBsinC (proved in Ch.4 Ex 4.1 Q12(b)): halve it. (T.U. 2052)

Marks

3

Solution

Put A = sin-1x, B = sin-1y, C = sin-1z with A+B+C = pi. Then sin2A+sin2B+sin2C = 4sinAsinBsinC (Ch.4 Ex 4.1 Q12(b)), i.e. 2(x.sqrt(1-x^2)+y.sqrt(1-y^2)+z.sqrt(1-z^2)) = 4xyz since sinA = x and cosA = +sqrt(1-x^2) on the sin-1 range. Halving gives the result. Proved.

12.

Q12. If sin-1x+sin-1y+sin-1z = pi/2, prove that x^2+y^2+z^2+2xyz = 1.

Knowledge Note

sinC = cos(A+B): move xy over, then square once.

Marks

3

Solution

Put A = sin-1x, B = sin-1y, C = sin-1z with C = pi/2-(A+B). Then sinC = cos(A+B), i.e. z = sqrt((1-x^2)(1-y^2))-xy, i.e. z+xy = +sqrt((1-x^2)(1-y^2)) (non-negative). Squaring: z^2+2xyz+x^2y^2 = 1-x^2-y^2+x^2y^2, i.e. x^2+y^2+z^2+2xyz = 1. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Ex 5.1 Q12; book p169 = PDF p196 (image read)

15.

AQ1(iii). Prove that sin-1x = tan-1(x/sqrt(1-x^2)). (HSEB 2050)

Knowledge Note

tan of sin-1x is opposite-over-adjacent: x over sqrt(1-x^2). (HSEB 2050)

Marks

2

Solution

Put t = sin-1x in [-pi/2, pi/2] with x in (-1, 1), so sint = x and cost = +sqrt(1-x^2) != 0. Then tant = sint/cost = x/sqrt(1-x^2) with t in (-pi/2, pi/2), so t = tan-1(x/sqrt(1-x^2)). Proved.

16.

AQ2. Explain what the inverse circular function is. What are the domains and ranges of sin-1x, cos-1x and tan-1x so that they are functions of x?

Knowledge Note

Restrict sin to [-pi/2, pi/2], cos to [0, pi], tan to (-pi/2, pi/2): one y per x.

Marks

2

Solution

y = sinx (and cosx, tanx) is many-to-one, so its x-y swap is not a function. Restricting to one monotone branch gives a function: sin-1x has domain [-1, 1], range [-pi/2, pi/2]; cos-1x has domain [-1, 1], range [0, pi]; tan-1x has domain (-inf, inf), range (-pi/2, pi/2). (The printed Answers, p171, confirm all three domain-range lines.)

17.

AQ3. Prove that tan-1((a-b)/(1+ab))+tan-1((b-c)/(1+bc))+tan-1((c-a)/(1+ca)) = tan-1((a^2-b^2)/(1+a^2b^2))+tan-1((b^2-c^2)/(1+b^2c^2))+tan-1((c^2-a^2)/(1+c^2a^2)).

Knowledge Note

Both sides telescope to zero: each sum is three differences that cancel.

Marks

3

Solution

LHS = (tan-1a-tan-1b)+(tan-1b-tan-1c)+(tan-1c-tan-1a) = 0 and RHS = (tan-1a^2-tan-1b^2)+(tan-1b^2-tan-1c^2)+(tan-1c^2-tan-1a^2) = 0 by the difference formula (where all pairwise products exceed -1). Both sides are 0. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.5 Additional Q3; book p170 = PDF p197 (image read)

18.

AQ4(i). [Print says = 0: DISPROVED.] cot-1((ab+1)/(a-b))+cot-1((bc+1)/(b-c))+cot-1((ca+1)/(c-a)) = 0.

Knowledge Note

PRINT ERROR with counterexample: a = 3, b = 2, c = 1 gives pi, not 0. The correct identity equals pi.

Marks

3

Solution

Counterexample a = 3, b = 2, c = 1: arccot(7/1)+arccot(3/1)+arccot(4/(-2)) = arccot7+arccot3+arccot(-2) ~ 8.13deg+18.43deg+153.43deg = 180deg = pi, not 0. So the printed = 0 is false. Correct identity: for a > b > c with ab, bc, ca > -1 the sum is pi, since cot-1(1/t) = tan-1t for t > 0 and = pi+tan-1t for t < 0, and tan-1((a-b)/(1+ab))+tan-1((b-c)/(1+bc))+tan-1((c-a)/(1+ca)) telescopes to 0. Filed as a print error with correction.

19.

AQ4(ii). Prove that cot-11+cot-12+cot-13 = pi/2.

Knowledge Note

Each cot-1 is pi/2 minus a tan-1; the three tan-1 sum to pi by Q9(v).

2

Solution

cot-1x = pi/2-tan-1x for every nonzero x. So the sum is 3pi/2-(tan-11+tan-12+tan-13) = 3pi/2-pi = pi/2, using Q9(v) (tan-11+tan-12+tan-13 = pi). Proved.

21.

AQ4(iv). Prove that tan((1/2)sin-1(2x/(1+x^2))+(1/2)cos-1((1-y^2)/(1+y^2))) = (x+y)/(1-xy).

Knowledge Note

Both halves are double-angle masks: (1/2)sin-1(2x/(1+x^2)) = tan-1x and (1/2)cos-1((1-y^2)/(1+y^2)) = tan-1y.

Marks

3

Solution

sin-1(2x/(1+x^2)) = 2tan-1x and cos-1((1-y^2)/(1+y^2)) = 2tan-1y (the standard t-substitution masks). Halving gives tan-1x+tan-1y, and tan of that sum is (x+y)/(1-xy). Proved.
