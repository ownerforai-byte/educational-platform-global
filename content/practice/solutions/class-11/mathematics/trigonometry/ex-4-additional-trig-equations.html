Questions

1.

AQ1(a). What does the trigonometrical equation mean?

Knowledge Note

An equation true for ALL values is an identity; one true for SOME values is a (conditional) equation.

Marks

1

Solution

An equation involving trigonometric functions of an unknown angle (variable) is a trigonometrical equation. It is 'conditional': unlike an identity (true for every admissible value), it holds only for specific values - e.g. sin x = 1/2 is satisfied by x = 30deg but not by x = 45deg (book Section 4.2).

2.

AQ1(b). What is the solution (root) of a trigonometrical equation?

Knowledge Note

Roots are the specific angles that satisfy the equation.

Marks

1

Solution

Any particular value of the unknown angle that satisfies the equation is a solution (root) - e.g. x = 30deg and x = 150deg are roots of sin x = 1/2, since both satisfy it (book Section 4.2).

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Additional Q1; book p155 = PDF p182; answer from Section 4.2 text

3.

AQ1(c). What is the general value (general solution) of a trigonometrical equation?

Knowledge Note

Periodicity makes roots infinite: the general solution packages them all with an integer n.

Marks

1

Solution

Because trig functions repeat every 360deg, an equation has infinitely many roots (e.g. sin x = 1/2 holds at 30deg, 150deg and every coterminal angle). The set of ALL solutions, written with an arbitrary integer n, is the general solution - e.g. x = n.360deg+30deg or n.360deg+150deg (book Section 4.2).

4.

AQ2(i). Solve sin2x + sin4x + sin6x = 0.

Knowledge Note

sin2x+sin6x = 2sin4xcos2x: the whole row collapses on sin4x.

Marks

2

Solution

(sin2x+sin6x)+sin4x = 2sin4xcos2x+sin4x = sin4x(2cos2x+1) = 0. sin4x = 0: x = n.pi/4. cos2x = -1/2: x = n.pi +- pi/3. Verified: x = pi/4 gives 1+0-1 = 0; x = pi/3 gives 0. (Key's 'n.pi/4' fraction partially legible; both families verified.)

5.

AQ2(ii). Solve 2sin^2x + sin^2 2x = 2.

Knowledge Note

Half the equation, then everything in cos2x: -cos2x(cos2x+1) = 0.

Marks

2

Solution

sin^2x(1+2cos^2x) = 1; with sin^2x = (1-cos2x)/2 and 2sin^2xcos^2x = sin^2 2x/2: 1-cos2x+sin^2 2x = 2 gives -cos2x(cos2x+1) = 0. cos2x = 0: x = n.pi+pi/2... i.e. odd multiples: x = (2n+1).pi/4? No: cos2x = 0 gives 2x = (2n+1).pi/2, x = (2n+1).pi/4 (odd pi/4s). cos2x = -1: x = (2n+1).pi/2. Union: x = (2n+1).pi/4 or (2n+1).pi/2 - equivalently n.pi+pi/2 or n.pi+-pi/4. Matches the key: 'n.pi+pi/2, n.pi+-pi/4'.

6.

AQ2(iii). Solve 2sin^2x + 3cosx = 0 (0 < x < 2pi).

Knowledge Note

2(1-cos^2)+3cos = 0: (2cosx+1)(cosx-2) = 0 - discard cosx = 2.

Marks

2

Solution

2cos^2x-3cosx-2 = (2cosx+1)(cosx-2) = 0. cosx = 2 impossible. cosx = -1/2: in (0, 2pi): x = 2pi/3, 4pi/3. Verified: x = 2pi/3 gives 2(3/4)+3(-1/2) = 0. (Key's '2pi/3, 4pi/3' fragments match.)

7.

AQ2(iv). Solve sin^2theta - costheta = 1/4 (0 <= theta <= 2pi).

Knowledge Note

cos^2+cos-3/4 = 0: cos = 1/2 or -3/2 - keep only 1/2.

Marks

2

Solution

1-cos^2-cos-1/4 = 0 gives cos^2+cos-3/4 = 0: costheta = 1/2 (other root -3/2 rejected). In [0, 2pi]: theta = pi/3, 5pi/3. Verified: sin^2(pi/3)-cos(pi/3) = 3/4-1/2 = 1/4.

8.

Q2(v). Solve 2tantheta - cottheta = -1.

Knowledge Note

Multiply by tantheta: 2tan^2+tan-1 = (2tan-1)(tan+1) = 0.

Marks

2

Solution

2tan^2theta+tantheta-1 = (2tantheta-1)(tantheta+1) = 0 (tantheta != 0 throughout). tantheta = 1/2: theta = n.pi+alpha (alpha = tan^(-1)(1/2)). tantheta = -1: theta = n.pi-pi/4. Both verified. (Key's 'n.pi+alpha' fragment matches.)

9.

AQ2(vi). Solve tan^2theta + (1-sqrt(3))tantheta - sqrt(3) = 0.

(tan+1)(tan-sqrt(3)) = 0: -pi/4 and +pi/3 families.

2

Solution

(tantheta+1)(tantheta-sqrt(3)) = 0. tantheta = -1: theta = n.pi-pi/4. tantheta = sqrt(3): theta = n.pi+pi/3. Verified: theta = pi/3 gives 3+(1-sqrt(3))sqrt(3)-sqrt(3) = 3+sqrt(3)-3-sqrt(3) = 0.

12.

AQ3(iii). Solve tantheta + sectheta = sqrt(3) [T.U. 2050].

Knowledge Note

(sin+1)/cos = sqrt(3): 2sin(theta-pi/3) = -1 - and 3pi/2 must be thrown out (tan/sec undefined).

Marks

2

Solution

sin+1 = sqrt(3)cos gives 2sin(theta-pi/3) = -1: sin(theta-pi/3) = -1/2, theta = 2n.pi+pi/6 or 2n.pi+3pi/2. theta = 3pi/2 (mod 2pi) makes tan/sec undefined - rejected. So theta = 2n.pi+pi/6. Verified: tan(pi/6)+sec(pi/6) = 1/sqrt(3)+2/sqrt(3) = sqrt(3).
