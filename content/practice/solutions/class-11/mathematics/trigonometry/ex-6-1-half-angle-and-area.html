Questions

1.

Q5(a). In any triangle, prove that [(b-c)/a]*cos(A/2) = sin((B-C)/2).

Knowledge Note

(b-c)/a = sin((B-C)/2)/cos(A/2): sum-to-product on both differences.

Marks

3

Solution

(b-c)/a = (sinB - sinC)/sinA = [2cos((B+C)/2)sin((B-C)/2)]/[2sin(A/2)cos(A/2)] = [2sin(A/2)sin((B-C)/2)]/[2sin(A/2)cos(A/2)] = sin((B-C)/2)/cos(A/2). Multiplying by cos(A/2) gives sin((B-C)/2).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(a); book p187 = PDF p215 (vision read)

2.

Q5(b). In any triangle, prove that bcos^2(A/2) + acos^2(B/2) = (a+b+c)/2.

Knowledge Note

cos^2(A/2) = (1+cosA)/2, then the projection law finishes it: bcosA + acosB = c.

Marks

3

Solution

bcos^2(A/2) + acos^2(B/2) = b(1+cosA)/2 + a(1+cosB)/2 = [(a+b) + (bcosA + acosB)]/2. By the projection law bcosA + acosB = c, so this equals (a+b+c)/2.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(b); book p187 = PDF p215 (vision read; s written as (a+b+c)/2 in print)

3.

Q5(c). In any triangle, prove that a(cosB - cosC) = 2(c-b)*cos^2(A/2).

Knowledge Note

cosB - cosC = -2cos(A/2)sin((B-C)/2) and c - b = -4Rsin(A/2)sin((B-C)/2): the sine factors cancel.

Marks

4

Solution

Left: a(cosB - cosC) = 2RsinA[-2sin((B+C)/2)sin((B-C)/2)] = 2R2sin(A/2)cos(A/2)[-2cos(A/2)sin((B-C)/2)] = -8Rsin(A/2)cos^2(A/2)sin((B-C)/2). Right: 2(c-b)cos^2(A/2) = 4R(sinC - sinB)cos^2(A/2) = 4R2cos((B+C)/2)sin((C-B)/2)cos^2(A/2) = 8Rsin(A/2)[-sin((B-C)/2)]*cos^2(A/2). Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(c); book p187 = PDF p215 (vision read)

4.

Q5(d). In any triangle, prove that [(b-c)/a]cos^2(A/2) + [(c-a)/b]cos^2(B/2) + [(a-b)/c]*cos^2(C/2) = 0.

Knowledge Note

Each weighted term becomes (cosC - cosB)/2: the three differences telescope to zero.

Marks

5

Solution

From Q5(a), (b-c)/a = sin((B-C)/2)/cos(A/2), so the first term is sin((B-C)/2)*cos(A/2) = [sin((B-C+A)/2) + sin((B-C-A)/2)]/2 = [sin((pi-2C)/2) + sin((-(pi-2B))/2)]/2 = (cosC - cosB)/2. Cyclically the second is (cosA - cosC)/2 and the third is (cosB - cosA)/2. Adding: [(cosC - cosB) + (cosA - cosC) + (cosB - cosA)]/2 = 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(d); book p187 = PDF p215 (vision read)

5.

Q5(e). In any triangle, prove that bccos^2(A/2) + cacos^2(B/2) + ab*cos^2(C/2) = s^2, where 2s = a+b+c.

Knowledge Note

Halve with (1+cosA)/2, then use bccosA + cacosB + ab*cosC = (a^2+b^2+c^2)/2.

Marks

4

Solution

The left side is [bc(1+cosA) + ca(1+cosB) + ab(1+cosC)]/2 = [(ab+bc+ca) + (bccosA + cacosB + abcosC)]/2. Now bc*cosA = (b^2+c^2-a^2)/2 and cyclically, so the bracket sum is (a^2+b^2+c^2)/2. Hence the left side is [(ab+bc+ca) + (a^2+b^2+c^2)/2]/2 = (a+b+c)^2/4 = s^2.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(e); book p187 = PDF p215 (vision read)

6.

Q5(f). In any triangle, prove that tan^2(A/2)tan^2(B/2)tan^2(C/2) = [(s-a)/s][(s-b)/s][(s-c)/s], where 2s = a+b+c.

Knowledge Note

tan^2(A/2) = (s-b)(s-c)/[s(s-a)]: multiply the three and one factor cancels.

Marks

3

Solution

By the half-angle formula tan^2(A/2) = (s-b)(s-c)/[s(s-a)], and cyclically for B and C. Multiplying: numerator (s-b)(s-c)(s-c)(s-a)(s-a)(s-b) = [(s-a)(s-b)(s-c)]^2; denominator s^3(s-a)(s-b)(s-c). Cancelling one factor (s-a)(s-b)(s-c) gives (s-a)(s-b)(s-c)/s^3 = [(s-a)/s][(s-b)/s]*[(s-c)/s].

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(f); book p187 = PDF p215 (vision read)

7.

Q5(g). In any triangle, prove that (b+c-a)[cot(B/2) + cot(C/2)] = 2acot(A/2).

Knowledge Note

cot(B/2) + cot(C/2) = sinA/[sin(B/2)*sin(C/2)]: half-angles are compulsory (full angles fail: test the 3-4-5 triangle).

Marks

4

Solution

cot(B/2) + cot(C/2) = sin((B+C)/2)/[sin(B/2)sin(C/2)] = cos(A/2)/[sin(B/2)sin(C/2)], so the left side is 2(s-a)cos(A/2)/[sin(B/2)sin(C/2)]. Now (s-a) = 4Rcos(A/2)sin(B/2)sin(C/2) (from r = 4Rsin(A/2)sin(B/2)sin(C/2) and tan(A/2) = r/(s-a)). Substituting: 24Rcos(A/2)sin(B/2)sin(C/2)cos(A/2)/[sin(B/2)sin(C/2)] = 8Rcos^2(A/2). The right side is 2acot(A/2) = 4RsinAcos(A/2)/sin(A/2) = 8Rcos^2(A/2). Both sides agree. (Check on 3-4-5 with A = 90 deg: left = 2(cot(B/2)+cot(C/2)) = 2(2.414+0.414) = 5.657 = 25*cot45.)

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q5(g); book p187 = PDF p215 (vision read; half-angles confirmed in print)

8.

Q13(a). In any triangle, prove that a^2cotA + b^2cotB + c^2cotC = 4Delta.

Knowledge Note

a^2cotA = Ra(b^2+c^2-a^2)/(bc): summing gives R(2sum a^2b^2 - sum a^4)/(abc) = 4Delta by Heron.

Marks

5

Solution

a^2cotA = a^2cosA/sinA = a^2[(b^2+c^2-a^2)/(2bc)]/(a/2R) = Ra(b^2+c^2-a^2)/(bc) = Ra^2(b^2+c^2-a^2)/(abc). Summing cyclically gives R/(abc)[sum a^2(b^2+c^2-a^2)] = R/(abc)[2(a^2b^2+b^2c^2+c^2a^2) - (a^4+b^4+c^4)]. By Heron's form 16Delta^2 = 2sum a^2b^2 - sum a^4, so this is R16Delta^2/(abc) = 16RDelta^2/(4RDelta) = 4Delta (using abc = 4RDelta).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q13(a); book p188 = PDF p215 (vision read)

9.

Q13(b). In any triangle, prove that (asinA + bsinB + csinC)^2 = (a^2+b^2+c^2)(sin^2A + sin^2B + sin^2C).

Knowledge Note

Equality holds because a/sinA = 2R is constant: both sides equal 4R^2*(sum sin^2)^2.

Marks

4

Solution

Since a = 2RsinA (and cyclically), the left side is [2R(sin^2A + sin^2B + sin^2C)]^2 = 4R^2(sin^2A + sin^2B + sin^2C)^2. The right side is [4R^2(sin^2A + sin^2B + sin^2C)]*(sin^2A + sin^2B + sin^2C), which is the same. (This is Cauchy-Schwarz with equality, because (a, b, c) is proportional to (sinA, sinB, sinC).)

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q13(b); book p188 = PDF p215 (vision read)

10.

Q13(c). In any triangle, prove that sinA + sinB + sinC = s/R, where 2s = a+b+c.

Knowledge Note

sinA + sinB + sinC = (a+b+c)/(2R) = s/R: just add the three sine-rule fractions.

Marks

3

Solution

sinA + sinB + sinC = a/(2R) + b/(2R) + c/(2R) = (a+b+c)/(2R) = 2s/(2R) = s/R.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q13(c); book p188 = PDF p215 (vision read)

11.

Q13(d). In any triangle, prove that acosBcosC + bcosCcosA + ccosAcosB = Delta/R.

Knowledge Note

Expand acosBcosC with a = y+z style substitution: sum = [sum a^2 - sum(b-c)^2 ... ]/(4R) = Delta/R.

Marks

5

Solution

acosBcosC = 2RsinAcosBcosC, so the left side is 2R[sinAcosBcosC + sinBcosCcosA + sinCcosAcosB]. Dividing the bracket by cosAcosBcosC gives tanA + tanB + tanC, which equals tanAtanBtanC (standard A+B+C = pi identity). Hence the bracket is cosAcosBcosCtanAtanBtanC = sinAsinBsinC, and the sum is 2RsinAsinBsinC = 2R(abc/8R^3) = abc/(4R^2) = Delta/R (using abc = 4RDelta).

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Ex 6.1 Q13(d); book p188 = PDF p215 (vision read)
