Questions

1.

Q1(a). Prove that (tanA - secA + 1)/(tanA + secA - 1) = cosA/(1 + sinA).

Knowledge Note

Divide top and bottom by cosA, then cross-multiply: both sides become cosA times (sinA - cosA + 1).

Marks

2

Solution

Divide numerator and denominator by cosA: LHS = (sinA - 1 + cosA)/(sinA + 1 - cosA). Cross-check: (sinA+cosA-1)(1+sinA) = sinA+sin^2A+cosA+sinAcosA-1-sinA = sin^2A+cosA+sinAcosA-1 = -cos^2A+cosA+sinAcosA = cosA(1-cosA+sinA) = cosA(sinA-cosA+1) = RHS numerator times denominator. Hence equal. Proved. (Statement via 200-dpi image read; OCR had merged the fraction bars.)

2.

Q1(b). Prove that 1/cosA - 1/(secA+tanA) = 1/(secA-tanA) - 1/cosA.

Knowledge Note

sec^2 - tan^2 = 1 makes the two unit fractions sum to exactly 2secA.

Marks

2

Solution

Rearranged: 2secA = 1/(secA-tanA) + 1/(secA+tanA). RHS = ((secA+tanA)+(secA-tanA))/((secA-tanA)(secA+tanA)) = 2secA/(sec^2A-tan^2A) = 2secA/1 = 2secA = LHS. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q1(b); book p142 = PDF p169 (200-dpi image read)

3.

Q2. If cosA + sinA = sqrt(2)cosA, show that cosA - sinA = sqrt(2)sinA.

Knowledge Note

Read sinA straight off the hypothesis: sinA = (sqrt(2)-1)cosA - then both target sides are the same multiple of cosA.

Marks

2

Solution

From the hypothesis sinA = (sqrt(2)-1)cosA (cosA != 0, else 1 = 0). Then cosA - sinA = cosA-(sqrt(2)-1)cosA = (2-sqrt(2))cosA; and sqrt(2)sinA = sqrt(2)(sqrt(2)-1)cosA = (2-sqrt(2))cosA. Equal. Shown. (No squaring, so no sign ambiguity.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q2; book p142 = PDF p169 (image read)

4.

Q3(a). Show that sin(B-C)/(sinB sinC) + sin(C-A)/(sinC sinA) + sin(A-B)/(sinA sinB) = 0.

Knowledge Note

sin(B-C)/(sinB sinC) = cotC - cotB: the three terms telescope to zero.

Marks

3

Solution

sin(B-C)/(sinB sinC) = (sinBcosC-cosBsinC)/(sinBsinC) = cotC-cotB. Cyclically the others give cotA-cotC and cotB-cotA. Sum = 0. Shown.

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q3(a); book p142 = PDF p169 (image read)

Q3(b). Show that cosA + cos(120deg+A) + cos(120deg-A) = 0.

Knowledge Note

cos(120+A)+cos(120-A) = 2cos120 cosA = -cosA: the pair eats the leading cosA.

Marks

2

Solution

cos(120+A)+cos(120-A) = 2cos120deg.cosA = 2(-1/2)cosA = -cosA. Adding cosA gives 0. Shown.

6.

Q4(a). If tanx = k.tany, show that (k-1)sin(x+y) = (k+1)sin(x-y).

Knowledge Note

Componendo in disguise: write k = sinxcosy/(cosxsiny) and expand both sides to (k^2-1)cosxsiny.

Marks

3

Solution

tanx = k.tany gives sinxcosy = k.cosxsiny. LHS = (k-1)(sinxcosy+cosxsiny) = (k-1)(k+1)cosxsiny. RHS = (k+1)(sinxcosy-cosxsiny) = (k+1)(k-1)cosxsiny. Equal. Shown.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q4(a); book p142 = PDF p169 (image read)

7.

Q4(b). If sin(A+B) = k.sin(A-B), prove that (k-1)cotB = (k+1)cotA.

Knowledge Note

Solve for (k-1) and (k+1) from the hypothesis: both equal twice a product over the same denominator.

Marks

3

Solution

k = (sinAcosB+cosAsinB)/(sinAcosB-cosAsinB) =: N/D. Then k-1 = 2cosAsinB/D and k+1 = 2sinAcosB/D. So (k-1)cotB = 2cosAcosB/D = (k+1)cotA. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q4(b); book p142 = PDF p169 (image read)

8.

Q5(a). Prove that cos2A = (1-tan^2A)/(1+tan^2A).

Knowledge Note

Divide top and bottom by cos^2A: tan^2A appears and cos2A = cos^2 - sin^2 drops out.

Marks

2

Solution

(1-tan^2A)/(1+tan^2A) = ((cos^2A-sin^2A)/cos^2A)/((cos^2A+sin^2A)/cos^2A) = (cos^2A-sin^2A)/1 = cos2A. Proved.

Q5(b). Prove that (1+cos2B)/sin2B = cotB.

Knowledge Note

Double-angle both parts: 2cos^2B over 2sinBcosB.

Marks

1

Solution

(1+cos2B)/sin2B = 2cos^2B/(2sinBcosB) = cosB/sinB = cotB. Proved.

10.

Q5(c). Prove that cos^2(A-120deg) + cos^2A + cos^2(A+120deg) = 3/2.

Knowledge Note

Average of three 120-degree-shifted squares is 3/2: the cross terms cancel in pairs. (OCR misread '= 2'; the image confirms 3/2.)

Marks

3

Solution

cos(A+-120) = -cosA/2 -/+ sqrt(3)sinA/2. Squaring: each = cos^2A/4 + 3sin^2A/4 -/+ cross term; the two cross terms (+sqrt(3)sinAcosA/2 and its negative) cancel. Sum = cos^2A + 2(cos^2A/4+3sin^2A/4) = (3/2)(cos^2A+sin^2A) = 3/2. Proved. (Book prints 3/2 - confirmed by image; OCR's '= 2' was a misread.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q5(c); book p142 = PDF p169 (200-dpi image read: '= 3/2')

11.

Q6. If theta and phi are acute angles and cos2theta = (3cos2phi-1)/(3-cos2phi), show that tantheta = sqrt(2).tanphi.

Knowledge Note

Write cos2phi with t = tan^2phi, simplify to (1-2t)/(1+2t), then read tan^2theta = 2t off the half-angle form.

Marks

3

Solution

Put t = tan^2phi, so cos2phi = (1-t)/(1+t). RHS = (3(1-t)/(1+t)-1)/(3-(1-t)/(1+t)) = (2-4t)/(2+4t) = (1-2t)/(1+2t). Hence cos2theta = (1-2t)/(1+2t), and tan^2theta = (1-cos2theta)/(1+cos2theta) = 4t/2 = 2t. Acute angles give positive roots: tantheta = sqrt(2).tanphi. Shown.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q6; book p143 = PDF p170 (200-dpi image read)

12.

Q7. If 2tanA = 3tanB, prove that tan(A-B) = sin2B/(5-cos2B).

Knowledge Note

tan(A-B) with tanA = 3tanB/2 on top; on the bottom write everything with tanB via sin2B and cos2B.

Marks

3

Solution

LHS = (tanA-tanB)/(1+tanAtanB) = (tanB/2)/((2+3tan^2B)/2) = tanB/(2+3tan^2B). RHS = (2tanB/(1+tan^2B))/(5-(1-tan^2B)/(1+tan^2B)) = 2tanB/(4+6tan^2B) = tanB/(2+3tan^2B). Equal. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q7; book p143 = PDF p170 (200-dpi image read)

13.

Q8. If tan(theta/2) = sqrt((1-e)/(1+e)).tan(phi/2), prove that cosphi = (costheta-e)/(1-e.costheta).

Knowledge Note

Half-angle t-substitution plus k^2(1+e) = 1-e: numerator and denominator share the factor (1-e).

Marks

3

Solution

Put t = tan(phi/2), T = tan(theta/2) = k.t with k^2 = (1-e)/(1+e). Then (costheta-e)/(1-e.costheta) with costheta = (1-k^2t^2)/(1+k^2t^2): numerator = ((1-e)-k^2t^2(1+e))/(1+k^2t^2) = (1-e)(1-t^2)/(1+k^2t^2) since k^2(1+e) = 1-e; denominator = ((1-e)+k^2t^2(1+e))/(1+k^2t^2) = (1-e)(1+t^2)/(1+k^2t^2). Ratio = (1-t^2)/(1+t^2) = cosphi. Proved. (The orbital true-anomaly relation.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q8; book p143 = PDF p170 (200-dpi image read)

Q9(a). Prove that 8.sin20deg.sin40deg.sin80deg = sqrt(3).

Knowledge Note

sin20.sin40.sin80 = sin60/4: the triple-angle product identity with theta = 20.

sin(theta)sin(60-theta)sin(60+theta) = sin3theta/4 with theta = 20deg gives sin20sin40sin80 = sin60/4 = sqrt(3)/8. Times 8: sqrt(3). Proved.

15.

Q9(b). Prove that 16.cos20deg.cos40deg.cos60deg.cos80deg = 1.

Knowledge Note

cos20cos40cos80 = sin160/(8sin20) = 1/8; the cos60 factor halves it once more.

Marks

2

Solution

cos60 = 1/2. cos20cos40cos80 = sin(8x20)/(8sin20) = sin160/sin... = sin20/(8sin20) = 1/8 (using costheta.cos2theta.cos4theta = sin8theta/(8sintheta)). Product = (1/8)(1/2) = 1/16; times 16 = 1. Proved.

16.

Q9(c). Prove that tan6deg.tan42deg.tan66deg.tan78deg = 1.

Knowledge Note

Pair them as (sqrt(5)-2)(sqrt(5)+2) = 1: exact surd values at 6/66 and 42/78 degrees.

Marks

3

Solution

tan6tan66 = (cos60-cos72)/(cos60+cos72) = (1/2-sin18)/(1/2+sin18) = sqrt(5)-2 (with sin18 = (sqrt(5)-1)/4). tan42tan78 = (cos36-cos120)/(cos36+cos120) = (sin54+1/2)/(sin54-1/2) = sqrt(5)+2 (with sin54 = (sqrt(5)+1)/4). Product = (sqrt(5)-2)(sqrt(5)+2) = 5-4 = 1. Proved.

17.

Q10. If sin2x = 3.sin2y, prove that 2.tan(x-y) = tan(x+y).

Knowledge Note

Componendo-dividendo on sin2x/sin2y = 3/1 turns the ratio into tan(x+y)/tan(x-y) = 2.

Marks

2

Solution

(sin2x+sin2y)/(sin2x-sin2y) = (3+1)/(3-1) = 2. LHS = (2sin(x+y)cos(x-y))/(2cos(x+y)sin(x-y)) = tan(x+y)/tan(x-y). So tan(x+y)/tan(x-y) = 2, i.e. tan(x+y) = 2tan(x-y). Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q10; book p143 = PDF p170

18.

Q11. Prove that ((cosA+cosB)/(sinA-sinB))^n + ((sinA+sinB)/(cosA-cosB))^n = 2cot^n((A-B)/2) or 0 according as n is even or odd.

Knowledge Note

Each bracket is +-cot((A-B)/2): same sign (even n) doubles, opposite signs (odd n) cancel.

Marks

3

Solution

(cosA+cosB)/(sinA-sinB) = (2cos((A+B)/2)cos((A-B)/2))/(2cos((A+B)/2)sin((A-B)/2)) = cot((A-B)/2). (sinA+sinB)/(cosA-cosB) = (2sin((A+B)/2)cos((A-B)/2))/(-2sin((A+B)/2)sin((A-B)/2)) = -cot((A-B)/2). Sum = cot^n + (-cot)^n = 2cot^n((A-B)/2) for even n, 0 for odd n. Proved. (Statement via 200-dpi image read; OCR had scrambled the denominators.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q11; book p143 = PDF p170 (200-dpi image read)

19.

Q12(a). If A+B+C = pi, prove that tan(B/2)tan(C/2) + tan(C/2)tan(A/2) + tan(A/2)tan(B/2) = 1.

Knowledge Note

(A+B)/2 and C/2 are complementary: tan((A+B)/2) = cot(C/2) rearranges straight into the result.

Marks

2

Solution

(A+B)/2 = pi/2 - C/2, so (tan(A/2)+tan(B/2))/(1-tan(A/2)tan(B/2)) = tan((A+B)/2) = cot(C/2) = 1/tan(C/2). Cross-multiplying: tan(A/2)tan(C/2)+tan(B/2)tan(C/2) = 1-tan(A/2)tan(B/2). Rearranged: sum = 1. Proved. (Statement via 200-dpi image read; OCR had dropped the half-angles.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q12(a); book p143 = PDF p170 (200-dpi image read)

20.

Q12(b). If A+B+C = pi, prove that sin2A + sin2B + sin2C = 4.sinA.sinB.sinC.

Knowledge Note

Pair the first two sines, then fold sin2C in: cosC = -cos(A+B) makes the last step click.

Marks

2

Solution

sin2A+sin2B = 2sin(A+B)cos(A-B) = 2sinC.cos(A-B). Add sin2C = 2sinCcosC: total = 2sinC(cos(A-B)+cosC) = 2sinC(cos(A-B)-cos(A+B)) = 2sinC.2sinAsinB = 4sinAsinBsinC. Proved.

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q12(b); book p143 = PDF p170 (image read)

21.

Q13(a). If A+B+C = pi, prove that cos^2A + cos^2B + cos^2C = 1 - 2cosAcosBcosC.

Knowledge Note

Group cos^2A+cos^2B with the half-angle form, then let cosC = -cos(A+B) finish it - the book's own worked example uses this.

Marks

2

Solution

cos^2A+cos^2B = 1+(cos2A+cos2B)/2 = 1+cos(A+B)cos(A-B) = 1-cosC.cos(A-B). Add cos^2C: 1-cosC.cos(A-B)+cos^2C = 1-cosC(cos(A-B)-cosC) = 1-cosC(cos(A-B)+cos(A+B)) = 1-2cosAcosBcosC. Proved. (Same proof as the book's worked example above Ex 4.1.)

Source

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q13(a); book p143 = PDF p170 (image read)

22.

Q13(b). If A+B+C = pi, prove that sin^2(A/2) + sin^2(B/2) + sin^2(C/2) = 1 - 2sin(A/2)sin(B/2)sin(C/2).

Knowledge Note

Apply the Q13(a) pattern to the half-angles X = A/2 etc. (X+Y+Z = pi/2): the cofunction flips cos into sin exactly where needed.

Marks

2

Solution

Put X = A/2, Y = B/2, Z = C/2 with X+Y+Z = pi/2. sin^2X+sin^2Y = 1-(cos2X+cos2Y)/2 = 1-cos(X+Y)cos(X-Y) = 1-sinZ.cos(X-Y). Add sin^2Z: 1-sinZ.cos(X-Y)+sin^2Z = 1-sinZ(cos(X-Y)-sinZ) = 1-sinZ(cos(X-Y)-cos(X+Y)) = 1-2sinXsinYsinZ. Proved. (Statement via 200-dpi image read; OCR had dropped the half-angles.)

Sukunda Basic Mathematics Grade XI, Ch.4 Ex 4.1 Q13(b); book p143 = PDF p170 (200-dpi image read)
