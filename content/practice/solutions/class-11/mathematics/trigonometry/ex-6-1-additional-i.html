Questions

1.

AQ1(i). State and establish the sine law. (T.U. 2055S)

Knowledge Note

Draw the circumdiameter through C: angle CBD is 90 deg, so sinA = a/(2R).

Marks

5

Solution

Statement: in any triangle ABC, a/sinA = b/sinB = c/sinC = 2R where R is the circumradius. Proof: let O be the circumcentre and extend CO to meet the circumcircle at D, so CD = 2R is a diameter and angle CBD = 90 deg (angle in a semicircle). Angles CAD... angle CDB equals angle CAB = A (angles in the same segment subtend CB). In right triangle CBD, sin(angle CDB) = BC/CD = a/(2R), so sinA = a/(2R), i.e. a/sinA = 2R. The same construction at the other vertices gives b/sinB = c/sinC = 2R.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q1(i) (T.U. 2055S); book p188 = PDF p216 (vision read)

2.

AQ1(ii). State the sine law. Use this law to prove the projection law a = bcosC + ccosB and the tangent law tan((B-C)/2) = [(b-c)/(b+c)]cot(A/2) (with cyclic form tan((A-B)/2) = [(a-b)/(a+b)]cot(C/2)). (T.U. 2057S) (HSEB 2050; cyclic form HSEB 2058)

Knowledge Note

Projection is sine law + sin(B+C) expansion; tangent law is (sinB - sinC)/(sinB + sinC) plus sum-to-product.

Marks

5

Solution

Sine law: a/sinA = b/sinB = c/sinC = 2R. Projection: bcosC + ccosB = 2RsinBcosC + 2RsinCcosB = 2Rsin(B+C) = 2RsinA = a. Tangent law: (b-c)/(b+c) = (sinB - sinC)/(sinB + sinC) = [2cos((B+C)/2)sin((B-C)/2)]/[2sin((B+C)/2)cos((B-C)/2)] = tan((B-C)/2)cot((B+C)/2) = tan((B-C)/2)tan(A/2) (since (B+C)/2 = (pi-A)/2). Hence tan((B-C)/2) = [(b-c)/(b+c)]cot(A/2). The cyclic form tan((A-B)/2) = [(a-b)/(a+b)]cot(C/2) (top of book p189, tags T.U. 2057S, HSEB 2058) follows by the same steps with permuted letters.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q1(ii) (T.U. 2057S) (HSEB 2050); book p188 = PDF p216, cyclic form top of book p189 = PDF p216 (vision read)

3.

AQ2. In any triangle ABC, prove that a/sinA = b/sinB = c/sinC. (HSEB 2058)

Knowledge Note

a/sinA = b/sinB = c/sinC is the sine law restated as a continued proportion.

Marks

2

Solution

By the sine law each of a/sinA, b/sinB, c/sinC equals 2R, so all three are equal.

4.

AQ3. In any triangle, prove that a/sinA = b/sinB = c/sinC = 2R, where R is the radius of the circumcircle. (HSEB 2051, 2052, 2055)

Knowledge Note

The common value 2R is the circumdiameter: each side is a chord subtending its angle at the centre.

Marks

3

Solution

From AQ1(i), a/sinA = 2R where 2R is the diameter of the circumcircle through the construction with diameter CD = 2R. Repeating at each vertex, b/sinB = c/sinC = 2R as well, so all four expressions are equal.

5.

AQ4. In any triangle ABC, prove that cos(C/2) = sqrt[s(s-c)/(ab)], and write the similar results for sin(B/2) and tan(B/2). (HSEB 2054)

Knowledge Note

cos(C/2) = sqrt[s(s-c)/(ab)]; the B-forms follow by cyclic permutation: sin(B/2) = sqrt[(s-a)(s-c)/(ac)], tan(B/2) = sqrt[(s-a)(s-c)/(s(s-b))].

Marks

4

Solution

cos^2(C/2) = (1+cosC)/2 = [1 + (a^2+b^2-c^2)/(2ab)]/2 = [(a+b)^2 - c^2]/(4ab) = [(a+b-c)(a+b+c)]/(4ab) = [2(s-c)*2s]/(4ab) = s(s-c)/(ab). Since C/2 is acute, cos(C/2) = sqrt[s(s-c)/(ab)]. Similarly sin(B/2) = sqrt[(s-a)(s-c)/(ac)] (from sin^2(B/2) = (1-cosB)/2) and tan(B/2) = sin(B/2)/cos(B/2) = sqrt[(s-a)(s-c)/(s(s-b))].

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q4 (HSEB 2054); book p189 = PDF p216 (vision read)

6.

AQ5. Prove that cos(A/2) = sqrt[s(s-a)/(bc)]. (T.U. 2056S) (HSEB 2057)

Knowledge Note

cos^2(A/2) = (1+cosA)/2 = [(b+c)^2 - a^2]/(4bc) = s(s-a)/(bc).

Marks

3

Solution

cos^2(A/2) = (1+cosA)/2 = [1 + (b^2+c^2-a^2)/(2bc)]/2 = [(b+c)^2 - a^2]/(4bc) = [(b+c-a)(b+c+a)]/(4bc) = [2(s-a)*2s]/(4bc) = s(s-a)/(bc). Since A/2 is acute, cos(A/2) = sqrt[s(s-a)/(bc)].

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q5 (T.U. 2056S) (HSEB 2057); book p189 = PDF p216 (vision read)

7.

AQ6(i). In any triangle ABC, prove that (c - acosB)/(b - acosC) = sinB/sinC.

Knowledge Note

c - acosB = 2RsinCcosB: expand sinC = sin(A+B) and watch sinBcosB cancel.

Marks

4

Solution

c - acosB = 2RsinC - 2RsinAcosB = 2R[sin(A+B) - sinAcosB] = 2RcosAsinB. Likewise b - acosC = 2RsinB - 2RsinAcosC = 2R[sin(A+C) - sinAcosC] = 2RcosAsinC. Dividing gives sinB/sinC.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(i); book p189 = PDF p216 (vision read)

8.

AQ6(ii). Prove that [(cos^2B - cos^2C)/(b+c)] + [(cos^2C - cos^2A)/(c+a)] + [(cos^2A - cos^2B)/(a+b)] = 0.

Knowledge Note

cos^2B - cos^2C = sin^2C - sin^2B = (c-b)(c+b)/(4R^2): each fraction leaves (c-b)/(4R^2).

Marks

5

Solution

cos^2B - cos^2C = (1 - sin^2B) - (1 - sin^2C) = sin^2C - sin^2B = (c^2-b^2)/(4R^2). Dividing by (b+c) gives (c-b)/(4R^2). Cyclically the second term is (a-c)/(4R^2) and the third is (b-a)/(4R^2). Adding: [(c-b) + (a-c) + (b-a)]/(4R^2) = 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(ii); book p189 = PDF p216 (vision read)

9.

AQ6(iii). Prove that [a^2sin(B-C)/(sinB + sinC)] + [b^2sin(C-A)/(sinC + sinA)] + [c^2*sin(A-B)/(sinA + sinB)] = 0.

Knowledge Note

sinB + sinC = 2cos(A/2)cos((B-C)/2) cancels the cosine, leaving 16R^2sin^2(A/2)cos(A/2)*sin((B-C)/2); the sum telescopes via (cosC - cosB)/2.

Marks

5

Solution

a^2sin(B-C) = 4R^2sin^2A2sin((B-C)/2)cos((B-C)/2) and sinB + sinC = 2cos(A/2)cos((B-C)/2), so the first term is 16R^2sin^2(A/2)cos(A/2)sin((B-C)/2). Since cos(A/2)sin((B-C)/2) = [cosC - cosB]/2 (from Q5(d) working), the first term equals 8R^2sin^2(A/2)(cosC - cosB). Cyclically summing: 8R^2[sin^2(A/2)(cosC - cosB) + sin^2(B/2)(cosA - cosC) + sin^2(C/2)(cosB - cosA)]. With sin^2(A/2) = (1-cosA)/2 this is 4R^2[(1-cosA)(cosC - cosB) + (1-cosB)(cosA - cosC) + (1-cosC)(cosB - cosA)] = 4R^2[(cosC - cosB + cosA - cosC + cosB - cosA) - (cosAcosC - cosAcosB + cosBcosA - cosBcosC + cosCcosB - cosCcosA)] = 4R^2[0 - 0] = 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(iii); book p189 = PDF p216 (vision read)

10.

AQ6(iv). Prove that tan(A/2)*tan(B/2) = (a+b-c)/(a+b+c).

Knowledge Note

tan(A/2)tan(B/2) = r/(s-c)... no: use Delta: tan(A/2)tan(B/2) = Delta^2/[(s(s-a))(s(s-b))]... simplest is (s-c)/s via r^2 = (s-a)(s-b)(s-c)/s.

Marks

3

Solution

tan(A/2)tan(B/2) = sqrt[(s-b)(s-c)/(s(s-a))] sqrt[(s-a)(s-c)/(s(s-b))] = (s-c)/s. And (a+b-c)/(a+b+c) = 2(s-c)/(2s) = (s-c)/s. Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(iv); book p189 = PDF p216 (vision read)

11.

AQ6(v). Prove that (b-c)cot(A/2) + (c-a)cot(B/2) + (a-b)*cot(C/2) = 0.

Knowledge Note

(b-c)cot(A/2) = 4Rcos(A/2)sin((B-C)/2) = 2R(cosC - cosB): cyclic sum vanishes.

Marks

4

Solution

(b-c)cot(A/2) = 2R(sinB - sinC)cos(A/2)/sin(A/2) = 2R2cos((B+C)/2)sin((B-C)/2)cos(A/2)/sin(A/2) = 4Rsin((B-C)/2)cos(A/2) = 2R[cosC - cosB] (using 2sin((B-C)/2)cos(A/2) = cosC - cosB from Q5(d) working). Cyclically the others are 2R(cosA - cosC) and 2R(cosB - cosA). Adding: 2R*[(cosC - cosB) + (cosA - cosC) + (cosB - cosA)] = 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(v); book p189 = PDF p216 (vision read)

12.

AQ6(vi). Prove that (a-b)^2cos^2(C/2) + (a+b)^2sin^2(C/2) = c^2.

Knowledge Note

Expand with cos^2(C/2) = (s(s-c))/(ab) style halves, or collect: LHS - c^2 = (a-b)^2 - 4ab*sin^2(C/2) - ... = 0 by the cosine rule.

Marks

4

Solution

With cos^2(C/2) = (1+cosC)/2 and sin^2(C/2) = (1-cosC)/2, the left side is [(a-b)^2(1+cosC) + (a+b)^2(1-cosC)]/2 = [(a-b)^2 + (a+b)^2]/2 + cosC[(a-b)^2 - (a+b)^2]/2 = (2a^2+2b^2)/2 + cosC(-4ab)/2 = (a^2+b^2) - 2ab*cosC = c^2 by the cosine rule.

Source

Sukunda Basic Mathematics Grade XI, Ch.6 Additional Questions (I) Q6(vi); book p189 = PDF p216 (vision read)
