Q5. Reduce 2x-√3y+5 = 0 to normal form.

Knowledge Note

Marks

4

Solution

Divide by -√(4+3) = -√7 (p > 0 forces negative divisor): x(-2/√7)+y(√3/√7) = 5/√7. Boxed x cos α+y sin α = 5/√7 with cos α = -2/√7, sin α = √3/√7 (matches the printed key form).

F = midpoint of AB = (2,-1): median CF through (1,2),(2,-1): slope -3: 3x+y-5 = 0. (Each verified by substitution; consistent with the key family.)

Q10. Prove triplets concurrent: (i) 9x-13y-90 = 0, 2x+11y-20 = 0, 7x+y-70 = 0; (ii) 3x-2y-7 = 0, 2x+3y+4 = 0, x-y-3 = 0.

Knowledge Note

Solve pairwise; each intersection lies on the third.

Marks

5

Solution

(i) First two: D = 99+26 = 125; Dx = 990+260 = 1250, x = 10; Dy = 180-180 = 0, y = 0. Third: 70+0-70 = 0 ✓. (ii) First two: D = 9+4 = 13; Dx = -28+21 = -7? Dx = (-7)(3)-(−2)(4) = -21+8 = -13, x = -1; Dy = 3(4)-(-7)(2) = 12+14 = 26, y = 2. Third: -1-2-3 = -6 ≠ 0? Recompute: lines 3x-2y = 7, 2x+3y = -4: D = 9+4 = 13. Dx = 7(3)-(-2)(-4) = 21-8 = 13, x = 1. Dy = 3(-4)-7(2) = -12-14 = -26, y = -2. Third: 1-(-2)-3 = 0 ✓. Concurrent ∎ (verified by substitution).

Source

Sukunda Basic Mathematics Grade XI, Ch.13 Ex 13.1 Q10; book p386 = PDF p413 (vision read)
