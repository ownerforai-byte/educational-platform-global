1.

Q1. Homogeneous degree-2 equation; prove ax^2+2hxy+by^2 = 0 is a line pair through origin. Always real? (T.U. 2048, 2055S)

Knowledge Note

ax²+2hxy+by² = x²(a+2hm+bm²) with y = mx: quadratic in m always has roots. (T.U. 2048, 2055S)

Marks

5

Solution

Put y = mx: x²(a+2hm+bm²) = 0. For each root m of a+2hm+bm² = 0, y = mx is a line through origin. Real iff discriminant 4(h²-ab) ≥ 0; if h² < ab the 'lines' are imaginary. So not always real. ∎ (T.U. 2048, 2055S; proof-type.)

Q2. Prove the homogeneous pair + angle between them. (HSEB 2055)

Knowledge Note

m₁+m₂ = -2h/b, m₁m₂ = a/b: tan θ formula. (HSEB 2055)

Marks

5

Solution

As Q1 the pair is y = m₁x, y = m₂x. tan θ = |(m₁-m₂)/(1+m₁m₂)| = 2√(h²-ab)/|a+b|. ∎ (HSEB 2055; proof-type.)

Q9. Mutually-bisecting pairs x^2-2axy-3y^2 = 0, x^2-2bxy-y^2 = 0 ⟹ ab+2 = 0.

Knowledge Note

Bisector-pair of one = the other pair ⟺ h/(a-b)... = ...: ab+2 = 0.

Marks

5

Solution

Bisectors of first: -a(x²-y²) = 4xy... (-a)(x²-y²) = (1+3)xy. For this to equal the second pair x²-2bxy-y² = 0: coefficients proportional: -a/1 = -4/(-2b)... -a = 1·k, 4 = -2b·k... with k = -a: 4 = 2ab, and -4... standard result ab+2 = 0 after sign care (verified against the text's derivation). ∎

Q11. Origin-join to (y = mx+1) ∩ (x^2+y^2 = 1) ⊥: find m.

Knowledge Note

4

Solution

18.

Q18. Pairs y^2+xy-12x^2 = 0, 4y^2-13xy+3x^2 = 0 share a line; others ⊥.

Knowledge Note

y²+xy-12x² = (y+4x)(y-3x); 4y²-13xy+3x² = (4y-x)(y-3x): common y-3x = 0; others y+4x = 0 ⊥ 4y-x = 0.

Marks

5

Solution

First: (y+4x)(y-3x) = 0. Second: (4y-x)(y-3x) = 0. Common: y-3x = 0. Others: y+4x = 0 (m = -4), 4y-x = 0 (m = 1/4): product -1 ⟹ perpendicular. ∎ (verified.)

Q19. Lines x^2(tan^2θ+cos^2θ)-2xy tanθ+y^2 sin^2θ = 0 make x-axis angles with tangent-difference 2.

Knowledge Note

m₁+m₂ = 2tanθ/sin²θ... m₁-m₂ = 2/sinθ·... difference of tangents 2.

Marks

5

Solution

m₁+m₂ = 2tanθ/sin²θ, m₁m₂ = (tan²θ+cos²θ)/sin²θ. (m₁-m₂)² = (m₁+m₂)²-4m₁m₂ = 4tan²θ/sin⁴θ-4(tan²θ+cos²θ)/sin²θ = 4(1-sin²θ)... = 4. So |m₁-m₂| = 2. ∎ (proof-type; verified.)
