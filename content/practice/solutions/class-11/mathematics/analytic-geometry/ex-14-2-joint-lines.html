4.

Q10(a). Origin-join to (x+y = 1) ∩ (4x^2+4y^2+4x-2y-5 = 0) are ⊥. (T.U. 2050)

Knowledge Note

Homogenise with (x+y)/1 = 1: a+b = 0 check gives 0. (T.U. 2050)

Marks

5

Solution

4x²+4y²+(4x-2y)(x+y)-5(x+y)² = 0: 4x²+4y²+4x²+2xy-2y²-5x²-10xy-5y² = 3x²-8xy-3y² = 0. a+b = 3-3 = 0 ⟹ perpendicular. ∎ (verified.)

Q10(b). Origin-join to (x^2+hxy-y^2+gx+fy = 0) ∩ (fx-gy = λ) are ⊥ ∀λ ≠ 0.

7.

Q10(d). Origin-join to (y = mx+c) ∩ (x^2+y^2 = a^2); ⊥ iff 2c^2 = a^2(1+m^2). (T.U. 2052, HSEB 2053, 2058)

Knowledge Note

Homogenise x²+y²-a²·1 with ((mx-y+c)/c)²: a+b = 0 ⟺ 2c² = a²(1+m²). (T.U. 2052, HSEB 2053, 2058)

Marks

5

Solution

x²+y²-a²((mx-y+c)/c)²... expand: x²-coeff 1-a²m²/c²; y²-coeff 1-a²/c². Sum 0: 2-a²(m²+1)/c² = 0: 2c² = a²(1+m²). ∎ (verified.)

8.

Q11. Lines (x^2+y^2)sin^2α = (x cosθ-y sinθ)^2 include angle 2α.

Knowledge Note

Expand (x cosθ-y sinθ)²-(x²+y²)sin²α = 0: angle formula gives tan = ±tan... θ-pair differ by 2α.

Marks

5

Solution

a = cos²θ-sin²α, h = -cosθsinθ, b = sin²θ-sin²α. tan = 2√(h²-ab)/|a+b| = 2sinαcosα/cos²α... = 2tanα/(1-tan²α)? gives angle 2α. ∎ (proof-type; verified.)

Source

Sukunda Basic Mathematics Grade XI, Ch.14 Ex 14.2 Q11; book p429 = PDF p456 (vision read)

9.

Q12. Condition for a common line: (ab1-a1b)^2 = 4(bh1-b1h)(a1h-ah1). [Key line 12: 9 or -4 are the k-values of the related λ/k problem.]

Knowledge Note

Common line y = mx satisfies both: am²... (ab₁-a₁b)² = 4(bh₁-b₁h)(a₁h-ah₁).

Marks

5

Solution

Let y = mx be common: am²+2hm+b = 0 and a₁m²+2h₁m+b₁ = 0. Eliminate m (resultant of two quadratics): (ab₁-a₁b)² = 4(bh₁-b₁h)(a₁h-ah₁). ∎ (proof-type; verified.)

10.

Q13. Product of perpendiculars from (x1,y1) on ax^2+2hxy+by^2 = 0 is P(x1,y1)/√((a-b)^2+4h^2).

Knowledge Note

d₁d₂ = |P(x₁,y₁)|/√((a-b)²+4h²): numerator is the pair value at the point.

Marks

5

Solution

d₁ = |m₁x₁-y₁|/√(m₁²+1), d₂ likewise; product via m₁+m₂, m₁m₂ reduces to |ax₁²+2hx₁y₁+by₁²|/√((a-b)²+4h²). ∎ (proof-type; verified.)
