Q9. p, p' from origin to x secθ+y cosecθ = a and x cosθ-y sinθ = a cos2θ: prove 4p^2+p'^2 = a^2. (T.U. 2051, 2055S)

Knowledge Note

p = |−a|/√(sec²+cosec²)... 4p²+p'² with p' = |−a cos2θ|/1.

Marks

5

Solution

p = a/√(sec²θ+cosec²θ) = a sinθcosθ... 1/sec²+... p = a sinθcosθ/1? √(sec²+cosec²) = 1/(sinθcosθ): p = a sinθcosθ. p' = |−a cos2θ|/√(cos²+sin²) = a|cos2θ|... a cos2θ (signed). 4p²+p'² = 4a²sin²θcos²θ+a²cos²2θ = a²sin²2θ+a²cos²2θ = a². ∎ (proof-type; no key answer needed).
