1.

Q1(a). Find the equation of the circle with centre at (4, 5) and radius 3.

Knowledge Note

(x-h)²+(y-k)²=r²: expand once, then compare with x²+y²+2gx+2fy+c=0.

Marks

3

Solution

Standard form: (x-4)²+(y-5)² = 3². Expand: x²-8x+16+y²-10y+25 = 9, so x²+y²-8x-10y+32 = 0. Boxed x²+y²-8x-10y+32 = 0 (matches the printed key, book p442).

Source

2.

Q1(b). Find the equation of the circle with centre at (0, 0) and diameter 8.

Knowledge Note

Centre at the origin and diameter 8 means radius 4; the general form collapses to x²+y²=r².

Marks

2

Solution

Radius = 8/2 = 4, centre (0,0): x²+y² = 4². Boxed x²+y² = 16 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(b); book p441 = PDF p468 (vision read)

3.

Q1(c). Find the equation of the circle with centre at (p, q) and radius √(p²+q²).

Knowledge Note

When r² = p²+q² the constant term cancels exactly to zero — the circle passes through the origin.

Marks

3

Solution

(x-p)²+(y-q)² = p²+q² → x²-2px+p²+y²-2qy+q² = p²+q², so x²+y²-2px-2qy = 0. Boxed x²+y²-2px-2qy = 0 (matches the printed key); note it passes through (0,0), as the radius equals the distance of the centre from the origin.

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(c); book p441 = PDF p468 (vision read)

4.

Q1(d). Find the equation of the circle with centre at (4, -1) and through the origin.

Knowledge Note

"Through the origin" means r² = h²+k², so the constant term again vanishes.

Marks

3

Solution

r² = (4-0)²+(-1-0)² = 17. (x-4)²+(y+1)² = 17 → x²+y²-8x+2y+17 = 17. Boxed x²+y²-8x+2y = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(d); book p441 = PDF p468 (vision read)

5.

Q1(e). Find the equation of the circle whose two diameters are x + y = 6 and x + 2y = 8 and radius 10.

Knowledge Note

Two diameters of a circle meet at its centre, so the centre is the intersection of the given lines.

Marks

4

Solution

Centre = intersection of x+y = 6 and x+2y = 8: subtract → y = 2, then x = 4, so centre (4, 2). With r = 10: (x-4)²+(y-2)² = 100 → x²+y²-8x-4y+20 = 100. Boxed x²+y²-8x-4y-80 = 0. FLAG (print/key mismatch): the printed Answers, book p442, give x²+y²-16x+4y-32 = 0, i.e. centre (8,-2), radius 10. That centre lies on x+y = 6 but NOT on the printed x+2y = 8 (8-4 = 4 ≠ 8), so one printed line and the key disagree. Both forms are filed: as-printed x²+y²-8x-4y-80 = 0 (centre (4,2)) and key form x²+y²-16x+4y-32 = 0 (centre (8,-2), which would follow if the second diameter read x-2y = 12, since 8-2(-2) = 12).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(e); book p441 = PDF p468 (vision read); key book p442 = PDF p469 (350-dpi zoom)

6.

Q1(f). Find the equation of the circle with centre at (1, 5) and through the point of intersection of the lines 2x - y = 5 and 3x + y = 10.

Knowledge Note

Centre is given; the "point of intersection" supplies the radius.

Marks

4

Solution

Solve 2x-y = 5, 3x+y = 10: adding gives 5x = 15, x = 3, y = 1. So P(3,1) and r² = (3-1)²+(1-5)² = 4+16 = 20. (x-1)²+(y-5)² = 20 → x²+y²-2x-10y+26 = 20. Boxed x²+y²-2x-10y+6 = 0. FLAG (print/key mismatch): the printed key, book p442, reads x²+y²+2x-10y-6 = 0, which is the circle of centre (-1, 5) through the same point P (r² = 16+16 = 32). The printed centre "(+1, 5)" appears to be a sign slip; the key form is filed alongside.

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(f); book p441 = PDF p468 (300-dpi zoom read); key book p442 = PDF p469

7.

Q1(g). Find the equation of the circle with (0, 0) and (4, 7) as the ends of a diameter.

Knowledge Note

Diameter form: (x-x₁)(x-x₂)+(y-y₁)(y-y₂) = 0.

Marks

3

Solution

(x-0)(x-4)+(y-0)(y-7) = 0 → x²-4x+y²-7y = 0. Boxed x²+y²-4x-7y = 0 (matches the printed key); centre (2, 7/2), r = √(4+49/4) = √65/2.

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(g); book p441 = PDF p468 (vision read)

8.

Q1(h). Find the equation of the circle concentric with x² + y² + 8x - 6y + 1 = 0 and radius 3.

Knowledge Note

Concentric circles share g and f; only the constant term changes.

Marks

3

Solution

g = 4, f = -3 → centre (-4, 3). With r = 3: x²+y²+8x-6y+(16+9-9) = 0 → x²+y²+8x-6y+16 = 0. Boxed x²+y²+8x-6y+16 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(h); book p441 = PDF p468 (vision read)

9.

Q1(i). Find the equation of the circle concentric with x² + y² - 8x + 12y + 15 = 0 and passing through (5, 4).

Knowledge Note

Same centre, radius = distance from the centre to the given point.

Marks

3

Solution

Centre (4, -6). r² = (5-4)²+(4+6)² = 1+100 = 101. x²+y²-8x+12y+(16+36-101) = 0 → x²+y²-8x+12y-49 = 0. Boxed x²+y²-8x+12y-49 = 0 (matches the printed key).

10.

Q1(j). Find the equation of the circle passing through the origin and making intercepts equal to 3 and 4 from the positive x and y-axes respectively.

Knowledge Note

Intercepts a and b on the axes through the origin give the circle x²+y²-ax-by = 0 (Thales: the origin sees the segment AB at a right angle).

Marks

3

Solution

Points: (0,0), (3,0), (0,4). General form with c = 0: 9+6g = 0 → g = -3/2; 16+8f = 0 → f = -2. Equation x²+y²-3x-4y = 0. Boxed x²+y²-3x-4y = 0 (matches the printed key); centre (3/2, 2), r = 5/2 (the hypotenuse of the 3-4-5 triangle is the diameter).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(j); book p441 = PDF p468 (vision read)

11.

Q1(k). Find the equation of the circle whose centre lies on x + 3y + 1 = 0 and which passes through (5, 3) and (-2, 2).

Knowledge Note

Centre on a line + two points on the circle: the centre is equidistant from both points, giving a second linear equation.

Marks

4

Solution

Let the centre be (h,k) with h = -3k-1. Equidistance: (h-5)²+(k-3)² = (h+2)²+(k-2)² → -10h-6k+34 = 4h-4k+8 → 14h+2k = 26 → 7h+k = 13. Substituting h = -3k-1: -21k-7+k = 13 → k = -1, h = 2. Centre (2,-1), r² = (2-5)²+(-1-3)² = 25. x²+y²-4x+2y+(4+1-25) = 0. Boxed x²+y²-4x+2y-20 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q1(k); book p441 = PDF p468 (vision read)

12.

Q2(a). Find the equation of the circle with centre (3, 4) touching the x-axis.

Knowledge Note

Touching the x-axis means the radius equals |k|, the distance from the centre to y = 0.

Marks

3

Solution

Distance from (3,4) to the x-axis = 4, so r = 4. (x-3)²+(y-4)² = 16 → x²+y²-6x-8y+9 = 0. Boxed x²+y²-6x-8y+9 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(a); book p441 = PDF p468 (vision read)

13.

Q2(b). Find the equation of the circle with centre (a, b) touching the y-axis.

Knowledge Note

Touching the y-axis means r = |h|; keeping r as a symbol keeps the a² term in the constant.

Marks

3

Solution

Distance from (a,b) to the y-axis = |a|, so r = a. (x-a)²+(y-b)² = a² → x²+y²-2ax-2by+b² = 0. Boxed x²+y²-2ax-2by+b² = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(b); book p441 = PDF p468 (vision read)

14.

Q2(c). Find the equation of the circle with centre (4, 5) touching the line 3x - 4y + 18 = 0.

Knowledge Note

Distance from a point to a line: |ax₀+by₀+c|/√(a²+b²) — this is the radius when the line is a tangent.

Marks

4

Solution

r = |3(4)-4(5)+18|/√(9+16) = |12-20+18|/5 = 10/5 = 2. (x-4)²+(y-5)² = 4 → x²+y²-8x-10y+37 = 0. Boxed x²+y²-8x-10y+37 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(c); book p441 = PDF p468 (vision read)

15.

Q2(d). Find the equation of the circle whose centre lies on 3x - 5y = 4 and which touches both the axes.

Knowledge Note

Touching both axes forces |h| = |k| = r; the given line then fixes the sign and the size.

Marks

4

Solution

Touching both axes → centre (±r, ±r) with radius r. Put (h,k) = (t,t): 3t-5t = 4 → t = -2. Centre (-2,-2), r = 2: x²+y²+4x+4y+(4+4-4) = 0. Boxed x²+y²+4x+4y+4 = 0 (matches the printed key). (The other sign choices contradict 3h-5k = 4.)

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(d); book p441 = PDF p468 (vision read)

16.

Q2(e). Find the equation of the circle which touches each axis and passes through (2, 1).

Knowledge Note

Two circles satisfy "touches both axes through (2,1)": a small one in the first quadrant near the point and a large one outside it.

Marks

5

Solution

Centre (t,t), radius |t|; through (2,1): (2-t)²+(1-t)² = t² → 5-6t+t² = 0 → t = 1 or t = 5. t = 1: x²+y²-2x-2y+1 = 0. t = 5: x²+y²-10x-10y+25 = 0. Boxed x²+y²-2x-2y+1 = 0 and x²+y²-10x-10y+25 = 0 (both match the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(e); book p441 = PDF p468 (vision read)

17.

Q2(f). Find the equation of the circle which touches the coordinate axes at (a, 0) and (0, a).

Knowledge Note

Tangency at (a,0) and (0,a) pins the centre to (a,a) and the radius to a.

Marks

3

Solution

The radius to (a,0) is perpendicular to the x-axis, so the centre is (a,a) and r = a: (x-a)²+(y-a)² = a² → x²+y²-2ax-2ay+a² = 0. Boxed x²+y²-2ax-2ay+a² = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(f); book p441 = PDF p468 (vision read)

18.

Q2(g). Find the equation of the circle with radius 4 and centre on 13x + 4y = 32 which touches the line 3x + 4y = 12.

Knowledge Note

Centre on a given line + fixed radius + tangent to a line: solve |distance| = 4 for the free parameter.

Marks

5

Solution

Let the centre be (h,k) with 13h+4k = 32 → k = (32-13h)/4. Tangency: |3h+4k-12|/5 = 4 → |3h+32-13h-12| = 20 → |20-10h| = 20 → h = 0 or h = 4. h = 0 → k = 8, centre (0,8): x²+y²-16y+48 = 0. h = 4 → k = -5, centre (4,-5): x²+y²-8x+10y+25 = 0. Boxed x²+y²-16y+48 = 0, x²+y²-8x+10y+25 = 0 (both match the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q2(g); book p441 = PDF p468 (vision read)

Q3(a). Find the centre and radius of the circle x² + y² - 12x - 4y = 9.

Knowledge Note

Given x²+y²+2gx+2fy+c=0: centre (-g,-f), radius √(g²+f²-c).

Marks

3

Solution

g = -6, f = -2, c = -9 → centre (6,2); r = √(36+4+9) = 7. Boxed centre (6, 2), radius 7 (matches the printed key).

20.

Q3(b). Find the centre and radius of the circle x² + y² - 3x + 2y - 3/4 = 0.

Knowledge Note

Fractional coefficients are fine — read g and f straight off the halved coefficients.

Marks

3

Solution

g = -3/2, f = 1, c = -3/4 → centre (3/2, -1); r = √(9/4+1+3/4) = √4 = 2. Boxed centre (3/2, -1), radius 2 (matches the printed key).

21.

Q3(c). Find the centre and radius of the circle 4(x² + y²) + 12ax - 6ay - a² = 0.

Knowledge Note

First divide by the leading coefficient 4 so that x² and y² have coefficient 1.

Marks

4

Solution

Divide by 4: x²+y²+3ax-(3/2)ay-a²/4 = 0, so g = 3a/2, f = -3a/4, c = -a²/4. Centre (-3a/2, 3a/4); r = √(9a²/4+9a²/16+a²/4) = √(49a²/16) = 7a/4. Boxed centre (-3a/2, 3a/4), radius 7a/4 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q3(c); book p441 = PDF p468 (vision read)

22.

Q4(a). Find the equation of the circle passing through (0, 0), (a, 0) and (0, b).

Knowledge Note

Three points determine a circle; the intercept form is the fastest route when two points are on the axes.

Marks

4

Solution

c = 0 from (0,0); a²+2ga = 0 → g = -a/2; b²+2fb = 0 → f = -b/2. Equation x²+y²-ax-by = 0. Boxed x²+y²-ax-by = 0. FLAG: the printed key, book p442, reads x²+y²-ax-bx = 0 — the second variable is a print slip (the point is (0,b), so the term must be -by; AB is a diameter, centre (a/2, b/2)).

23.

Q4(b). Find the equation of the circle passing through (1, 2), (3, 1) and (-3, -1).

Knowledge Note

General form through three points: three linear equations in g, f, c.

Marks

4

Solution

x²+y²+2gx+2fy+c = 0 at the three points: 2g+4f+c = -5; 6g+2f+c = -10; -6g-2f+c = -10. The last two give c = -10 and 12g+4f = 0 → f = -3g; then 2g-12g = 5 → g = -1/2, f = 3/2. Boxed x²+y²-x+3y-10 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q4(b); book p441 = PDF p468 (vision read)

24.

Q4(c). Find the equation of the circle circumscribing the triangle whose sides are x + y = 6, 2x + y = 4 and x + 2y = 5.

Knowledge Note

Circumcircle of a triangle: find the three vertices as line intersections, then solve for g, f, c.

Marks

5

Solution

Vertices: x+y = 6 with 2x+y = 4 → (-2, 8); x+y = 6 with x+2y = 5 → (7, -1); 2x+y = 4 with x+2y = 5 → (1, 2). At the three points: -4g+16f+c = -68; 14g-2f+c = -50; 2g+4f+c = -5. Subtracting: 6g-12f = 63 and 12g-6f = -45 → g = -17/2, f = -19/2, c = 50. Boxed x²+y²-17x-19y+50 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q4(c); book p441 = PDF p468 (vision read)

25.

Q5. Show that the points (3, 3), (6, 4), (7, 1) and (4, 0) are concyclic. Find the centre and radius of the circle.

Knowledge Note

Four points are concyclic iff one circle passes through all of them — find the circle from three, then test the fourth.

Marks

4

Solution

Fit x²+y²+2gx+2fy+c = 0 through (3,3), (6,4), (7,1): 6g+6f+c = -18; 12g+8f+c = -52; 14g+2f+c = -50. Subtracting: 6g+2f = -34 → 3g+f = -17, and 2g-6f = 2 → g-3f = 1. With g = 1+3f: 3+9f+f = -17 → f = -2, g = -5, then c = -18+30+12 = 24. Circle: x²+y²-10x-4y+24 = 0, centre (5,2), r = √(25+4-24) = √5. Test the fourth point (4,0): 16+0-40-0+24 = 0 ✓, so all four are concyclic. Cross-check by perpendicular bisectors: of (3,3)-(7,1) is y = 2x-8 and of (6,4)-(4,0) is 2y = -x+9, meeting at (5,2) ✓. Boxed centre (5, 2), radius √5 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q5; book p442 = PDF p469 (vision read)

26.

Q6. If y - x = 2 is the equation of a chord of the circle x² + y² + 2x = 0, find the equation of the circle of which this chord is a diameter.

Knowledge Note

Intersect the chord line with the circle to get the diameter's endpoints, then use the diameter form.

Marks

5

Solution

Substitute y = x+2: x²+(x+2)²+2x = 0 → 2x²+6x+4 = 0 → x²+3x+2 = 0 → x = -1, -2. Endpoints (-1,1) and (-2,0). Circle on this diameter: (x+1)(x+2)+(y-1)(y-0) = 0 → x²+3x+2+y²-y = 0. Boxed x²+y²+3x-y+2 = 0 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.1 Q6; book p442 = PDF p469 (vision read); key book p442 = PDF p469
