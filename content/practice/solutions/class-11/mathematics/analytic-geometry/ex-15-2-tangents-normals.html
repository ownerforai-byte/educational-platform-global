Q1(a). Find the equations of the tangent and normal to x² + y² = 8 at (2, 2).

Knowledge Note

Tangent at (x₁,y₁) on x²+y²=a²: xx₁+yy₁ = a²; the normal joins the point to the centre.

Marks

3

Solution

Tangent: 2x+2y = 8 → x+y = 4. Normal passes through (0,0) and (2,2): y = x, i.e. x-y = 0. Boxed x+y = 4, x-y = 0 (matches the printed key, book p453).

4.

Q2(a). Show that the line 3x - 4y = 25 and the circle x² + y² = 25 intersect in two coincident points.

Knowledge Note

A line meets a circle in two coincident points exactly when the perpendicular distance from the centre equals the radius.

Marks

4

Solution

Distance of 3x-4y-25 = 0 from the centre (0,0): |−25|/√(9+16) = 25/5 = 5 = radius. A line at distance = radius meets the circle at two coincident points (the tangent), so the intersection is the single point of contact (3,-4). ∎

Source

Q2(c). Prove that the tangent to the circle x² + y² = 5 at the point (1, -2) also touches the circle x² + y² - 8x + 6y + 20 = 0 and find the point of contact.

Knowledge Note

Tangency is preserved by a common chord line: show the line is at distance r from the second centre, then drop a perpendicular for the contact.

Marks

5

Solution

Check (1,-2) on the first circle: 1+4 = 5 ✓. Tangent there: x-2y = 5. Second circle: centre (4,-3), r = √(16+9-20) = √5. Distance from (4,-3) to x-2y-5 = 0 is |4+6-5|/√5 = 5/√5 = √5 = r, so the line is tangent to it. Contact = foot of the perpendicular from (4,-3): (4+t, -3-2t) with 4+t+6+4t-5 = 0 → t = -1 → (3,-1). Boxed point of contact (3, -1) (matches the printed key).

13.

Q5(a). Find the condition that the line px + qy = r is tangent to the circle x² + y² = a².

Knowledge Note

Tangent condition by distance: |r|/√(p²+q²) = a, since the line px+qy = r passes at distance |r| from the origin.

Marks

4

Solution

Distance from the centre (0,0) to px+qy-r = 0 is |r|/√(p²+q²). Tangency: |r|/√(p²+q²) = a → r² = a²(p²+q²). Boxed a²(p²+q²) = r² (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q5(a); book p452 = PDF p479 (vision read)

14.

Q5(b). Deduce the condition that lx + my + n = 0 may be a tangent to the circle x² + y² + 2gx + 2fy + c = 0.

Knowledge Note

Centre (-g,-f), radius √(g²+f²-c): square the distance equation.

Marks

5

Solution

Distance from (-g,-f) to lx+my+n = 0 is |-gl-mf+n|/√(l²+m²); set it equal to √(g²+f²-c) and square: (lg+mf-n)² = (l²+m²)(g²+f²-c). Boxed (lg+mf-n)² = (l²+m²)(g²+f²-c), printed in the key as (g²+f²-c)(l²+m²) = (ln-lg-mf)² — the same statement.

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q5(b); book p452 = PDF p479 (vision read)

16.

Q6(a). Show that the tangents to x² + y² = 100 at (6, 8) and (8, -6) are perpendicular to each other.

Knowledge Note

Slope of the tangent at (x₁,y₁) on x²+y²=a² is -x₁/y₁.

Marks

3

Solution

At (6,8): 6x+8y = 100 → 3x+4y = 50, slope -3/4. At (8,-6): 8x-6y = 100 → 4x-3y = 50, slope 4/3. Product of slopes = (-3/4)(4/3) = -1, hence perpendicular. ∎

18.

Q7. Find the equation of the circle whose centre is (h, k) and which passes through the origin, and prove that the tangent at the origin is hx + ky = 0.

Knowledge Note

Circle through the origin with centre (h,k) has no constant term; its tangent at the origin is the line perpendicular to the radius.

Marks

4

Solution

r² = h²+k²: (x-h)²+(y-k)² = h²+k² → x²+y²-2hx-2ky = 0. Boxed x²+y²-2hx-2ky = 0. Tangent at (0,0) via xx₁+yy₁-g(x+x₁)-f(y+y₁) with the centre written as (-g,-f) = (h,k): 0+0-hx-ky = 0, i.e. hx+ky = 0 — the line perpendicular to the radius from (0,0) to (h,k), whose slope is k/h. ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q7; book p452 = PDF p479 (vision read)

Q8. If the line lx + my = 1 touches the circle x² + y² = a², prove that the point (l, m) lies on a circle whose radius is 1/a.

Knowledge Note

Tangency gives l²+m² = 1/a²; the required locus is read straight off that relation.

Marks

5

Solution

Distance from (0,0) to lx+my-1 = 0 is 1/√(l²+m²); tangency: 1/√(l²+m²) = a → l²+m² = 1/a². So (l,m) satisfies x²+y² = 1/a², a circle centred at the origin with radius 1/a. ∎

20.

Q9(a). Find the conditions for the two circles x² + y² = a² and (x - c)² + y² = b² to touch (i) externally, (ii) internally.

Knowledge Note

External contact: distance between centres = r₁+r₂; internal contact: = |r₁-r₂|.

Marks

4

Solution

Centres (0,0) and (c,0), radii a and b; distance between centres = |c|. (i) External: |c| = a+b. (ii) Internal: |c| = |a-b|. Boxed a+b = c and a ~ b = c (printed key uses the a ≥ b convention, so |a-b| = c).

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q9(a); book p452 = PDF p479 (vision read)

21.

Q9(b). Prove that the two circles x² + y² + 2ax + c² = 0 and x² + y² + 2by + c² = 0 touch if 1/a² + 1/b² = 1/c².

Knowledge Note

Write both circles in standard form, then impose the tangency condition; the c⁴ terms cancel and factor.

Marks

5

Solution

Centres (-a,0) and (0,-b), radii √(a²-c²) and √(b²-c²); distance² between centres = a²+b². Tangency: a²+b² = (r₁±r₂)² = a²-c²+b²-c²+2r₁r₂ → c² = r₁r₂ → c⁴ = (a²-c²)(b²-c²) = a²b²-a²c²-b²c²+c⁴ → a²b² = c²(a²+b²) → divide by a²b²c²: 1/c² = 1/a²+1/b². ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q9(b); book p452 = PDF p479 (vision read)

Q11. Find the points of intersection of the line x + y - 3 = 0 and the circle x² + y² - 2x - 3 = 0. Also find the length of the intercept made by the line with the circle.

Knowledge Note

Chord endpoints from the intersection; the intercept length is the distance between them.

Marks

4

Solution

y = 3-x: x²+(3-x)²-2x-3 = 0 → 2x²-8x+6 = 0 → x²-4x+3 = 0 → x = 1, 3 → points (1,2) and (3,0). Length = √((3-1)²+(0-2)²) = √8 = 2√2. Boxed (1, 2), (3, 0); 2√2 (matches the printed key).

Q12. A circle touches the parallel lines 3x - 4y = 7 and 3x - 4y + 43 = 0 and has its centre on 2x - 3y + 13 = 0. Find its equation.

Knowledge Note

Between two parallel tangents the centre lies on the mid-parallel; the radius is half the separation.

Marks

5

Solution

Separation = |7-(-43)|/√(9+16) = 50/5 = 10 → r = 5. Centre lies on the mid-line 3x-4y = (7-43)/2 = -18, i.e. 3x-4y+18 = 0. Solve with 2x-3y+13 = 0: from these, 6x-8y = -36 and 6x-9y = -39 → y = 3, x = -2. Centre (-2,3): x²+y²+4x-6y+(4+9-25) = 0. Boxed x²+y²+4x-6y-12 = 0 (matches the printed key).

Knowledge Note

y = x + c touches x²+y² = a² iff c = ±a√2 — here c = a√2, the '+' branch.

4

Solution

Rewrite as x-y+a√2 = 0; distance from (0,0) = a√2/√2 = a = r, so the line is a tangent. Contact = foot of the perpendicular from (0,0): (t,-t) with t+t+a√2 = 0 → t = -a/√2 → (-a/√2, a/√2). Boxed (-a/√2, a/√2) (matches the printed key).

Q14. Tangents are drawn from the origin to the circle x² + y² + 10x + 10y + 40 = 0. Find their equations.

Knowledge Note

The power of the origin is +40 > 0, so the origin lies outside the circle and two real tangents pass through it — write y = mx and impose distance = r.

Marks

5

Solution

Centre (-5,-5), r² = 25+25-40 = 10. Line y = mx → mx-y = 0; distance |-5m+5|/√(1+m²) = √10 → 25(m-1)² = 10(1+m²) → 15m²-50m+15 = 0 → 3m²-10m+3 = 0 → m = 3 or 1/3. Boxed 3x-y = 0 and x-3y = 0 (both match the printed key).

30.

Q17. Show that the length of the tangent drawn from any point on the circle x² + y² + 2gx + 2fy + c = 0 to the circle x² + y² + 2gx + 2fy + c₁ = 0 is √(c₁ - c).

Knowledge Note

On the first circle the power of every point is -c, so the tangent to the second circle telescopes.

Marks

5

Solution

Let P(x₁,y₁) lie on the first circle: x₁²+y₁²+2gx₁+2fy₁+c = 0, i.e. x₁²+y₁²+2gx₁+2fy₁ = -c. Length of tangent from P to the second circle = √(x₁²+y₁²+2gx₁+2fy₁+c₁) = √(c₁-c). This is independent of P, so all such tangents are equal. ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.15 Ex 15.2 Q17; book p453 = PDF p480 (vision read)

Q18 (hand-written in this copy). Find the equation of the line through the point (1, -1) which cuts off a chord of length 4√3 m from the circle x² + y² - 6x + 4y - 3 = 0.

Knowledge Note

Chord length 2√(r²-d²) ties the distance d from the centre to the desired slope; here the parameter cancels to a single slope.

Marks

5

Solution

Centre (3,-2), r = √(9+4+3) = 4. Chord length 2√(r²-d²) = 4√3 → r²-d² = 12 → d² = 4, d = 2. Line through (1,-1): y+1 = m(x-1) → mx-y-m-1 = 0. Distance from (3,-2): |3m+2-m-1|/√(1+m²) = |2m+1|/√(1+m²) = 2 → (2m+1)² = 4(1+m²) → 4m²+4m+1 = 4+4m² → m = 3/4. Line: 4y+4 = 3x-3 → 3x-4y-7 = 0. Boxed 3x-4y-7 = 0 (matches the answer written beside the question in this copy, book p453). With chord length 2√3 no real line exists (d² = 13 > 20), which fixes the reading 4√3.
