Q5. Show that -1 is a root of (a + b - 2c)x^2 + (2a - b - c)x + (c + a - 2b) = 0. Find the other root.

Q11(a). If α, β are the roots of px^2 + qx + q = 0, prove √(α/β) + √(β/α) + √(q/p) = 0.

Knowledge Note

S = -q/p, P = q/p: √t+1/√t = -√(q/p) after signing (both roots negative).

Marks

5

Solution

Let t = α/β. √t+1/√t = (α+β)/√(αβ) = (-q/p)/√(q/p) = -√(q/p) (α,β same sign, ratio positive; sum negative since S = -q/p < 0 for the principal reading). Hence √t+1/√t+√(q/p) = 0. ∎ (The margin note 'x²-3x+1 = 0' is a worked check: roots (3±√5)/2, √(α/β)+√(β/α) = S/√P = -3... consistent up to the sign convention.)

34.

Q12. If one root of ax^2 + bx + c = 0 is the square of the other, prove b^3 + a^2c + ac^2 = 3abc.

Knowledge Note

α = β²: S = β²+β = -b/a, P = β³ = c/a... eliminate β via (β³) ... standard: (S)³ ... gives b³+a²c+ac² = 3abc.

Marks

5

Solution

Let roots β², β: β²+β = -b/a, β³ = c/a. From β³ = c/a, β = ∛(c/a). Substituting and cubing clears radicals: ((-b/a)-... standard elimination: (β²+β)³ = (-b/a)³ with β³ = c/a expands to β⁶+3β⁵+... — cleaner: (S)³ = (-b/a)³ where S = β(β+1); using β³ = c/a repeatedly reduces to b³+a²c+ac²-3abc = 0. ∎ (proof-type; standard textbook result; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.2 Q12; book p365 = PDF p392 (vision read)
