1.

Q1(a). Prove that log_a(xy^3/z^2) = log_a x + 3log_a y - 2log_a z (x, y, z > 0, a > 0, a != 1).

Knowledge Note

Quotient first, then product, then power: peel the log apart layer by layer. The web index drops the '+' and '3' (prints 'log_a x log_a y'); the identity needs + 3log_a y.

Marks

2

Solution

LHS = log_a(xy^3/z^2). Quotient rule: = log_a(xy^3) - log_a(z^2). Product rule: = log_a x + log_a(y^3) - log_a(z^2). Power rule: = log_a x + 3log_a y - 2log_a z = RHS. Proved. (The web index prints this without the '+' and '3'; restored here since log_a(xy^3) = log_a x + 3log_a y. Book OCR p112 confirms '+ 3'.)

2.

Q1(b). Prove that log_a 2x + 3(log_a x - log_a y) = log_a(2x^4/y^3).

Knowledge Note

A sum of logs is the log of a product: 3(log x - log y) folds into one cube.

Marks

2

Solution

LHS = log_a 2x + 3(log_a x - log_a y). Quotient rule inside: = log_a 2x + 3log_a(x/y). Power rule: = log_a 2x + log_a(x/y)^3 = log_a 2x + log_a(x^3/y^3). Product rule: = log_a(2x . x^3/y^3) = log_a(2x^4/y^3) = RHS. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(b); book p112 = PDF p137 + SciPiPupil Ex-4 typed page

3.

Q1(c). Prove that log_a x^2 - 2log_a sqrt(x) = log_a x (x > 0).

Knowledge Note

sqrt(x) is x^(1/2): the power rule turns 2log sqrt(x) into exactly log x.

Marks

2

Solution

LHS = log_a x^2 - 2log_a sqrt(x) = log_a x^2 - 2log_a(x^(1/2)). Power rule on each: = 2log_a x - 2.(1/2)log_a x = 2log_a x - log_a x = log_a x = RHS. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(c); book p112 = PDF p137 + SciPiPupil Ex-4 typed page

4.

Q1(d). Prove that a^{log_a x} = x (a > 0, a != 1, x > 0). [Printed flat as 'a log_a x = x'; the exponent position is restored.]

Knowledge Note

a^{log_a x} = x is the definition of a logarithm undone: log_a x is the exponent that turns a into x.

Marks

2

Solution

Let t = log_a x. By definition of logarithm, a^t = x. Substituting t back: a^{log_a x} = x. Proved. (The web index prints this flat without the superscript; the exponent form is the standard inverse property.)

5.

Q1(e). Prove that log_a a^x = x.

Knowledge Note

log_a a = 1 pulls the exponent down untouched.

Marks

2

Solution

LHS = log_a(a^x). Power rule: = x.log_a a = x . 1 = x = RHS. Proved.

6.

Q1(f). Prove that (log a)^2 - (log b)^2 = log(ab) . log(a/b) (a, b > 0).

Knowledge Note

Difference of two squares works on logs too: U^2 - V^2 = (U+V)(U-V), then product/quotient rules.

Marks

2

Solution

LHS = (log a)^2 - (log b)^2 = (log a + log b)(log a - log b) by a^2 - b^2 = (a+b)(a-b). Product rule: log a + log b = log(ab). Quotient rule: log a - log b = log(a/b). So LHS = log(ab).log(a/b) = RHS. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(f); book p112 = PDF p137 + SciPiPupil Ex-4 typed page

7.

Q1(g). Verify that log(1 + 2 + 3) = log 1 + log 2 + log 3, and state why this does not make log(x+y) = log x + log y.

Knowledge Note

A numerical coincidence, NOT a rule: 1+2+3 and 1x2x3 both equal 6. Never split log of a sum in general.

Marks

2

Solution

LHS = log(6). RHS = log 1 + log 2 + log 3 = 0 + log(2.3) = log 6 (product rule + log 1 = 0). So LHS = RHS = log 6. Verified. Caution: this works only because 1+2+3 = 6 = 1x2x3; in general log(x+y) != log x + log y.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(g); book p112 = PDF p137; coincidence flagged

8.

Q1(h). Prove that x^{log y - log z} . y^{log z - log x} . z^{log x - log y} = 1 (x, y, z > 0).

Knowledge Note

Take log of both sides: each exponent drops down and the six terms cancel in pairs.

Marks

3

Solution

Let P = LHS. Take log (any base): log P = (log y - log z)log x + (log z - log x)log y + (log x - log y)log z. Expanding: = log x.log y - log x.log z + log y.log z - log y.log x + log z.log x - log z.log y = 0. So log P = 0 = log 1, hence P = 1. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(h); book p112 = PDF p137; standard cyclic-exponent proof

9.

Q1(i). Prove that (yz)^{log y - log z} . (zx)^{log z - log x} . (xy)^{log x - log y} = 1 (x, y, z > 0).

Knowledge Note

Same trick as (h), one level up: each factor log-splits into a difference of SQUARES, and the squares telescope to zero.

Marks

3

Solution

Let P = LHS. Take log: log P = (log y - log z).log(yz) + (log z - log x).log(zx) + (log x - log y).log(xy). Since log(yz) = log y + log z: first term = (log y - log z)(log y + log z) = (log y)^2 - (log z)^2. Likewise the others give (log z)^2 - (log x)^2 and (log x)^2 - (log y)^2. Sum = 0. So log P = 0, P = 1. Proved. (Recovered from book p112 = PDF p137 OCR; the web index skips from (h) to (j).)

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(i); book p112 = PDF p137 OCR conf 0.93 (web index omits it)

10.

Q1(j). Prove that log_a sqrt(a sqrt(a sqrt(a^2))) = 1 (a > 0, a != 1).

Knowledge Note

Work from the inside out: sqrt(a^2) = a (a > 0), so each nested root collapses one layer until only log_a a = 1 is left.

Marks

2

Solution

Innermost: sqrt(a^2) = a. Then a.sqrt(a^2) = a.a = a^2, and sqrt(a^2) = a. Then a.(that) = a.a = a^2, and the outer sqrt gives a. So the whole radicand is a, and log_a a = 1. Proved. (Radicand cross-checked against book p112 OCR 'a/a/a^2' fragments and the web typed page.)

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q1(j); book p112 = PDF p137 + SciPiPupil Ex-4 typed page

11.

Q2. If f(x) = log((1+x)/(1-x)) (-1 < x < 1), show that f(2ab/(1+a^2b^2)) = 2f(ab), where |ab| < 1. (The print orders the fraction as (1-x)/(1+x); the identity holds for either sign - both sides only change sign.)

Knowledge Note

Set t = ab: the fraction 2t/(1+t^2) is built so its (1+t)/(1-t) form becomes a perfect square - the log doubles.

Marks

3

Solution

Put t = ab (|t| < 1, so f is defined). LHS = f(2t/(1+t^2)) = log((1 + 2t/(1+t^2))/(1 - 2t/(1+t^2))) = log(((1+t^2+2t)/(1+t^2))/((1+t^2-2t)/(1+t^2))) = log((1+t)^2/(1-t)^2) = 2log((1+t)/(1-t)) = 2f(t) = 2f(ab). Shown. (Statement decoded from a 220-dpi band crop of PDF p137: 'f(x) = log(1-x/1+x), show ... = 2f(ab), 2ab/1+a^2b^2, |ab|<1'. Proved for the (1+x)/(1-x) form; with the flipped fraction both sides negate.)

12.

Q3. If x = log_{2a} a, y = log_{3a} 2a and z = log_{4a} 3a, prove that xyz + 1 = 2yz.

Knowledge Note

Write each log in one base (natural log): xyz collapses to a single ratio and the claim becomes ordinary algebra.

Marks

3

Solution

Write all three in natural logs: x = ln a/ln 2a, y = ln 2a/ln 3a, z = ln 3a/ln 4a. Then xyz = ln a/ln 4a and yz = ln 2a/ln 4a. Claim xyz + 1 = 2yz becomes (ln a + ln 4a)/ln 4a = 2ln 2a/ln 4a, i.e. ln(4a^2)... check: ln a + ln 4a = ln(4a^2)? No: ln a + ln 4a = ln(4a^2) is wrong; ln a + ln 4a = ln(4a^2/a)... recompute: need ln a + ln 4a = 2ln 2a = ln(4a^2). LHS = ln(a.4a) = ln(4a^2). RHS = ln((2a)^2) = ln(4a^2). Equal. Proved. (Valid for a > 0 with all bases positive and != 1.)

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q3; book p112 = PDF p137 OCR; change-of-base chain

13.

Q4. If (log x)/(y-z) = (log y)/(z-x) = (log z)/(x-y), prove that x^x . y^y . z^z = 1.

Knowledge Note

One common value k ties the three logs together; the weighted sum x.logx + y.logy + z.logz then telescopes to zero.

Marks

3

Solution

Put each ratio = k: log x = k(y-z), log y = k(z-x), log z = k(x-y). Take log of P = x^x.y^y.z^z: log P = x.log x + y.log y + z.log z = k[x(y-z) + y(z-x) + z(x-y)] = k[xy - xz + yz - yx + zx - zy] = 0. So log P = 0 = log 1, hence P = 1. Proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Book Ex 2.4 Q4; book p112 = PDF p137 OCR '(logx)/(y-z)...prove x^x.y^y.z^z = 1'

14.

A1 (printing variant). If a^2 + b^2 = 2ab (a, b > 0), show that log((a+b)/2) = (log a + log b)/2.

Knowledge Note

a^2 + b^2 = 2ab rearranges to (a-b)^2 = 0, forcing a = b; both sides then collapse to log a. APPENDIX: this is the guide-edition's Ex 2.4 Q2 (SciPiPupil typed page) - it does NOT occur in the 2075-print Ex 2.4 (book p112 = PDF p137); kept here so no web-indexed question is ever dropped.

Marks

3

Solution

Given a^2 + b^2 = 2ab, so a^2 - 2ab + b^2 = 0, i.e. (a-b)^2 = 0, hence a = b. LHS = log((a+a)/2) = log(2a/2) = log a. RHS = (log a + log a)/2 = log a. LHS = RHS. Shown.

Source

Guide-edition Ex 2.4 Q2 (SciPiPupil typed page; absent from 2075-print p112); proof via (a-b)^2 = 0
