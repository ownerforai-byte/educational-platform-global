1.

Q1(a). Solve by both addition method and row-equivalent matrices: 5x - 2y = -2; 2x + 5y = -24.

Knowledge Note

Elimination first: multiply to align one variable, add to kill it, back-substitute; the row operations mirror exactly these steps.

Marks

4

Solution

Addition: 5×(first)+2×(second): 25x-10y+4x+10y = -10-48, so 29x = -58, x = -2. In 5x-2y = -2: -10-2y = -2, y = -4. Row-equivalent: [5 -2 : -2; 2 5 : -24] → R1↔R2 → R2→R2-(5/2)R1 → R2→(-2/29)R2 → R1→R1+R2 gives [1 0 : -2; 0 1 : -4]. Boxed (-2,-4). Verify: 5(-2)-2(-4) = -10+8 = -2 ✓; 2(-2)+5(-4) = -4-20 = -24 ✓ (matches the printed key).

2.

Q1(b). Solve by both addition method and row-equivalent matrices: x - y = 2; 2x + 3y = 9.

Knowledge Note

From x - y = 2 read x = 2+y and substitute, or eliminate directly; both give the same single step.

Marks

4

Solution

Addition: 2×(first)-(second): 2x-2y-2x-3y = 4-9, so -5y = -5, y = 1; then x = 2+1 = 3. Row-equivalent: [1 -1 : 2; 2 3 : 9] → R2→R2-2R1 = [1 -1 : 2; 0 5 : 5] → R2→R2/5 → R1→R1+R2 gives [1 0 : 3; 0 1 : 1]. Boxed (3,1). Verify: 3-1 = 2 ✓; 6+3 = 9 ✓ (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.10 Ex 10.2 Q1(b); book p298 = PDF p325 (vision read)

3.

Q1(c). Solve by both addition method and row-equivalent matrices: x + y - 2z = 7; 2x - 3y - 2z = 0; x - 2y - 3z = 3.

Knowledge Note

Kill x first from two pairs, leaving a 2×2 in y,z; solve it, then back-substitute up the chain.

Marks

5

Solution

Addition: 2×(first)-(second): 5y-2z = 14. (first)-(third): 3y+z = 4, so z = 4-3y; then 5y-2(4-3y) = 14 gives 11y = 22, y = 2, z = -2, x = 7-2-4 = 1. Row-equivalent: reduce [1 1 -2 : 7; 2 -3 -2 : 0; 1 -2 -3 : 3] by R2→R2-2R1, R3→R3-R1, then R3→R3-(3/5)R2, scale and back-eliminate to [I : 1; 2; -2]. Boxed (1,2,-2). Verify in second: 2-6+4 = 0 ✓; third: 1-4+6 = 3 ✓ (matches the printed key).

Sukunda Basic Mathematics Grade XI, Ch.10 Ex 10.2 Q1(c); book p298 = PDF p325 (vision read)

4.

Q2(a). Solve by row-equivalent matrices: 8x - 3y = -31; 2x + 6y = 26.

Knowledge Note

2×2 row-reduction: get a leading 1, kill below it, scale the second row, kill above it.

Marks

3

Solution

[8 -3 : -31; 2 6 : 26] → R1↔R2 → R2→R2-4R1 = [2 6 : 26; 0 -27 : -135] → R2→R2/(-27) = [2 6 : 26; 0 1 : 5] → R1→R1-6R2, R1→R1/2 gives [1 0 : -2; 0 1 : 5]. Boxed (-2,5). Verify: 8(-2)-3(5) = -16-15 = -31 ✓; 2(-2)+6(5) = -4+30 = 26 ✓ (matches the printed key).

5.

Q2(b). Solve by row-equivalent matrices: 3x - 3y = 11; 9x - 2y = 5.

Knowledge Note

Fractions are fine mid-way: the (-1/3) survives because 3×(-1/3)-3×(-4) = -1+12 = 11.

Marks

3

Solution

[3 -3 : 11; 9 -2 : 5] → R1→R1/3 → R2→R2-9R1 = [1 -1 : 11/3; 0 7 : -28] → R2→R2/7 → R1→R1+R2 gives [1 0 : -1/3; 0 1 : -4]. Boxed (-1/3,-4). Verify: 3(-1/3)-3(-4) = -1+12 = 11 ✓; 9(-1/3)-2(-4) = -3+8 = 5 ✓ (matches the printed key).

6.

Q2(c). Solve by row-equivalent matrices: x = 2y + 3; 3x - 5y = 8.

Knowledge Note

Rewrite x = 2y+3 as x-2y = 3 first so the augmented matrix has constant right sides.

Marks

3

Solution

Rewrite as x-2y = 3; 3x-5y = 8. [1 -2 : 3; 3 -5 : 8] → R2→R2-3R1 = [1 -2 : 3; 0 1 : -1] → R1→R1+2R2 gives [1 0 : 1; 0 1 : -1]. Boxed (1,-1). Verify: 1 = 2(-1)+3 ✓; 3(1)-5(-1) = 8 ✓ (matches the printed key).

7.

Q2(d). Solve by row-equivalent matrices: 3x - 2y = 8; 5x + 3y = 7.

Knowledge Note

Determinant 3·3-(-2)·5 = 19 ≠ 0, so a unique solution; row ops divide by 19 once.

Marks

3

Solution

[3 -2 : 8; 5 3 : 7] → R1→R1/3 → R2→R2-5R1 = [1 -2/3 : 8/3; 0 19/3 : -19/3] → R2→(3/19)R2 → R1→R1+(2/3)R2 gives [1 0 : 2; 0 1 : -1]. Boxed (2,-1). Verify: 6+2 = 8 ✓; 10-3 = 7 ✓ (matches the printed key).

Q2(h). Solve by row-equivalent matrices: 5x - 3y = 20; 2x + 3y = 8.

14.

Q3(a). Use row-equivalent matrices to solve: x - y + 2z = 0; x - 2y + 3z = -1; 2x - 2y + z = -3.

Knowledge Note

3×3 plan: column 1 → ones and zeros, column 2 → ones and zeros, scale column 3, back-eliminate.

Marks

5

Solution

[1 -1 2 : 0; 1 -2 3 : -1; 2 -2 1 : -3] → R2→R2-R1, R3→R3-2R1 = [1 -1 2 : 0; 0 -1 1 : -1; 0 0 -3 : -3] → R2→-R2, R3→R3/(-3) = [1 -1 2 : 0; 0 1 -1 : 1; 0 0 1 : 1] → R2→R2+R3, R1→R1-2R3, R1→R1+R2 gives [I : 0; 2; 1]. Boxed (0,2,1). Verify in second: 0-4+3 = -1 ✓; third: 0-4+1 = -3 ✓ (matches the printed key, book p299).

16.

Q3(c). Use row-equivalent matrices to solve: x + y + z = 1; x + 2y + 3z = 4; x + 3y + 7z = 13. (T.U. 2051)

Knowledge Note

T.U. 2051: the coefficient matrix is Vandermonde-like; successive differences expose z = 3 first.

Marks

5

Solution

R2→R2-R1: y+2z = 3. R3→R3-R1: 2y+6z = 12, i.e. y+3z = 6. Subtracting: z = 3; then y = 3-6 = -3; x = 1-(-3)-3 = 1. Row-equivalent: same steps on [1 1 1 : 1; 1 2 3 : 4; 1 3 7 : 13] reach [I : 1; -3; 3]. Boxed (1,-3,3). Verify in third: 1-9+21 = 13 ✓ (matches the printed key).

17.

Q3(d). Use row-equivalent matrices to solve: 3x - 5z = -7; 3x + 5y = 3; 3z - 3y = 2.

Knowledge Note

Missing variables are zero coefficients: write 3x+0y-5z = -7 so no column is skipped.

Marks

5

Solution

Augmented [3 0 -5 : -7; 3 5 0 : 3; 0 -3 3 : 2] → R2→R2-R1 = [3 0 -5 : -7; 0 5 5 : 10; 0 -3 3 : 2] → R2→R2/5: y+z = 2; with -3y+3z = 2: substituting y = 2-z gives -3(2-z)+3z = 2, 6z = 8, z = 4/3, y = 2/3; then 3x = -7+20/3 = -1/3, x = -1/9. Boxed (-1/9,2/3,4/3). Verify in third: 4-2 = 2 ✓ (matches the printed key).

18.

Q3(e). Use row-equivalent matrices to solve: 9y - 5x = 3; x + z = 1; z + 2y = 2.

Knowledge Note

Reorder as -5x+9y+0z = 3; x+0y+z = 1; 0x+2y+z = 2, then eliminate x with R2 → 5R2+R1.

Marks

5

Solution

From x+z = 1, x = 1-z; from z+2y = 2, z = 2-2y, so x = 2y-1. In -5x+9y = 3: -5(2y-1)+9y = 3 gives -y+5 = 3, y = 2; then z = -2, x = 3. Row ops on [-5 9 0 : 3; 1 0 1 : 1; 0 2 1 : 2] reach [I : 3; 2; -2]. Boxed (3,2,-2). Verify: 18-15 = 3 ✓; 3-2 = 1 ✓; -2+4 = 2 ✓ (matches the printed key).

19.

Q3(f). Use row-equivalent matrices to solve: x + 4y + 3z = 6; 3x + 9y = 18; -5x - 6y + 2z = -5.

Knowledge Note

Row 2 has z = 0, so 3x+9y = 18 gives x = 6-3y first; feed it into the other two.

20.

Q3(g). Use row-equivalent matrices to solve: x - y + z = -3; x + y + z = 1; 3x - 4y - z = 1.

Knowledge Note

Adding the first two rows kills y and z at once: 2x = 4.

Marks

5

Solution

Adding first+second gives 2x+2z = -2, i.e. x+z = -1. Subtracting first from second: 2y = 4, y = 2. Then x+z = -1 and 3x-z = 1+4y = 9, so 3x-z = 9; with z = -1-x: 3x+1+x = 9, 4x = 8, x = 2, z = -3. Boxed (2,2,-3). Verify in third: 6-8+3 = 1 ✓ (matches the printed key).

21.

Q3(h). Use row-equivalent matrices to solve: x - y - z = -2; 5x + 10z = 20; 10y - 20z = 10.

Knowledge Note

Rows 2 and 3 are multiples of 5 and 10: divide them first to get x+2z = 4 and y-2z = 1.

Marks

5

Solution

Row 2 ÷ 5: x+2z = 4. Row 3 ÷ 10: y-2z = 1, y = 1+2z. Row 1: x-y-z = -2 gives (4-2z)-(1+2z)-z = -2, 3-5z = -2, z = 1; then x = 2, y = 3. Boxed (2,3,1). Verify: 2-3-1 = -2 ✓; 10+10 = 20 ✓; 30-20 = 10 ✓ (matches the printed key).

23.

Q3(j). Use row-equivalent matrices to solve: x + 4y + z = 18; 3x + 3y - 2z = 2; -4y + z = -7.

Knowledge Note

Row 3 gives z = 4y-7; eliminate z from the first two, then solve the 2×2 in x,y.

Marks

5

Solution

z = 4y-7. Row 1: x+4y+4y-7 = 18, x+8y = 25. Row 2: 3x+3y-2(4y-7) = 2, 3x-5y = -12. From first: x = 25-8y; then 3(25-8y)-5y = -12 gives 75-29y = -12, y = 3; x = 1; z = 5. Boxed (1,3,5). Verify in row 2: 3+9-10 = 2 ✓ (matches the printed key).
