Questions

1.

Q1. Evaluate: | 1 2 -3; 2 0 4; 3 2 1 |.

Knowledge Note

Expand along row 1 with the (-1)^{r+c} checkerboard: -2(2-12)-(4-0)-3(4-0).

Marks

4

Solution

Expanding along row 1: 1(0·1-4·2)-2(2·1-4·3)+(-3)(2·2-0·3) = 1(0-8)-2(2-12)-3(4-0) = -8+20-12 = 0 (matches the printed key).

2.

Q2. By the rule of Sarrus, find the value of | 1 -2 2; 1 3 2; 0 1 1 |.

Knowledge Note

Sarrus: write the first two columns again and sum the three down-diagonals minus the three up-diagonals.

Marks

4

Solution

Down-diagonals: 1·3·1 + (-2)·2·0 + 2·1·1 = 3+0+2 = 5. Up-diagonals: 0·3·2 + 1·2·1 + 1·1×(-2) = 0+2-2 = 0. Value = 5-0 = 5 (matches the printed key; consistent with the worked Sarrus example on p255).

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.2 Q2; book p264 = PDF p291 (vision read)

3.

Q3. Show that | a b c; aω^2 bω^2 cω^2; aω bω cω | = 0 where ω is an imaginary cube root of unity.

Knowledge Note

ω^3 = 1 and 1+ω+ω^2 = 0: column operations expose the ω^3-1 factor.

Marks

4

Solution

Factor a, b, c from columns 1, 2, 3: abc·| 1 1 1; ω^2 ω^2 ω^2; ω ω ω |. Rows 2 and 3 are multiples of row 1 (ω^2 and ω times), so two rows are proportional and the determinant is 0.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.2 Q3; book p264 = PDF p291 (vision read)

4.

Q4. Show that | b+c a a; b c+a b; c c a+b | = 4abc.

Knowledge Note

R1 -> R1+R2+R3 makes every entry (a+b+c): factor it out, then C1 -> C1-C2, C2 -> C2-C3 triangles the rest.

Marks

4

Solution

Sarrus check: down-diagonals give (b+c)(c+a)(a+b)+abc+abc; up-diagonals give ac(c+a)+bc(b+c)+ab(a+b). With P = (b+c)(c+a)(a+b) = a^2(b+c)+a(b+c)^2+bc(b+c), the difference P+2abc-ac(c+a)-bc(b+c)-ab(a+b) collapses: a^2 terms cancel, a terms give a(4bc), bc terms cancel, leaving 4abc. So the determinant equals 4abc (twin of Additional-Determinants Q1 on p283).

5.

Q5. Show that | 1 a bc; 1 b ca; 1 c ab | = (a-b)(b-c)(c-a). [Print note: the book shows a minus sign; numeric check at a=1,b=2,c=3 gives det = 2 = +(a-b)(b-c)(c-a), so the printed minus is a sign slip.]

Knowledge Note

Numeric check at (1,2,3) gives +2: the correct sign is +(a-b)(b-c)(c-a); the printed minus is a sign slip.

Marks

4

Solution

R2 -> R2-R1, R3 -> R3-R1: rows become (0, b-a, c(a-b)) and (0, c-a, b(a-c)). Expanding along C1: det = (b-a)b(a-c) - c(a-b)(c-a). With u = b-a, v = c-a (so a-c = -v, a-b = -u): det = u(-bv) - (-cu)v = -buv + cuv = uv(c-b) = (b-a)(c-a)(c-b) = (a-b)(b-c)(c-a) (three sign flips). Numeric check (1,2,3): Sarrus 25-23 = 2 = (-1)(-1)(2).
