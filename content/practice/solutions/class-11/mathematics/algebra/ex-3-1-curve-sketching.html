1.

Q1(a). Examine whether f(x) = x sin x + cos x is even, odd or neither.

Knowledge Note

Even x even = even: (-x)sin(-x) = (-x)(-sinx) = x sinx, and cos(-x) = cosx.

Marks

1

Solution

f(-x) = (-x)sin(-x) + cos(-x) = (-x)(-sin x) + cos x = x sin x + cos x = f(x). Even. Matches the printed Answers key (p129): 'a) Even'.

2.

Q1(b). Examine whether f(x) = 5x^2 + sin x is even, odd or neither.

Knowledge Note

Even + odd (both present, neither zero) can never be purely even or purely odd.

Marks

1

Solution

f(-x) = 5x^2 - sin x. This equals neither f(x) (= 5x^2 + sin x) nor -f(x) (= -5x^2 - sin x) (e.g. at x = pi/2: f = 5pi^2/4+1 vs f(-pi/2) = 5pi^2/4-1). Neither. Matches the printed Answers key: 'b) Neither'.

Source

Q1(c). Examine whether f(x) = sqrt(1+x^2) - sqrt(1-x^2) is even, odd or neither.

Knowledge Note

Marks

1

Solution

f(-x) = sqrt(1+(-x)^2) - sqrt(1-(-x)^2) = sqrt(1+x^2) - sqrt(1-x^2) = f(x). Even. Matches the printed Answers key: 'c) Even'. (The scan merges Q1(d)'s fraction bar into this line; (c) is the numerator alone - confirmed by 200-dpi image read.)

11.

Q3(a). Test the periodicity of f(x) = sin 2x and find its period.

Knowledge Note

sin(2(x+pi)) = sin(2x+2pi) = sin 2x: doubling the speed halves the period.

Marks

1

Solution

f(x+pi) = sin(2x+2pi) = sin 2x = f(x), and no smaller positive shift works (2x must advance by a full 2pi). Periodic with period pi. Matches the printed Answers key: 'a) Periodic, pi'.

Q3(b). Test the periodicity of f(x) = cos(pi x) and find its period.

Knowledge Note

cos(u+2pi) = cos u: set u = pi.x and solve pi(x+T) = pi.x+2pi for T.

1

Solution

f(x+2) = cos(pi x + 2pi) = cos(pi x) = f(x), and 2 is minimal (needs pi.T = 2pi). Periodic with period 2. Matches the printed Answers key: 'b) Periodic, 2'. (The bare '2' in the key is complete - not truncated.)

Q3(c). Test the periodicity of f(x) = tan(x/4) and find its period.

Solution

14.

Q3(d). Test the periodicity of f(x) = sin(ax+b) (a > 0) and find its period.

Knowledge Note

a > 0 stretches/compresses the wave: the argument must still advance by 2pi, so T = 2pi/a.

Marks

1

Solution

f(x+T) = sin(a(x+T)+b) = sin(ax+b+aT); this equals sin(ax+b) for all x iff aT = 2pi, i.e. T = 2pi/a (minimal positive). Periodic with period 2pi/a. 16.

Q4(a). Prove that f(x) = 3 + 5x is increasing for all x in R.

Knowledge Note

Positive slope preserves order: x1 > x2 implies 5x1 > 5x2.

Marks

2

Solution

Let x1 > x2. Then 5x1 > 5x2 (multiplying by positive 5), so 3+5x1 > 3+5x2, i.e. f(x1) > f(x2). Hence f is (strictly) increasing on R.

Source

Sukunda Basic Mathematics Grade XI, Ch.3 Ex 3.1 Q4(a); book p128 = PDF p155

17.

Q4(b). Prove that f(x) = 5 - 4x is decreasing for all x in R.

Knowledge Note

Negative slope reverses order: multiplying by -4 flips the inequality.

Marks

2

Solution

Let x1 > x2. Then -4x1 < -4x2 (multiplying by negative -4 flips), so 5-4x1 < 5-4x2, i.e. f(x1) < f(x2). Hence f is (strictly) decreasing on R.

Sukunda Basic Mathematics Grade XI, Ch.3 Ex 3.1 Q4(b); book p128 = PDF p155
