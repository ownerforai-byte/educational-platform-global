3.

Q5(c). Sum to infinity: 3/5+4/5^2+3/5^3+4/5^4+3/5^5+4/5^6+...

Knowledge Note

Interlaced 3/5^r and 4/5^r: sum each GP separately, common denominator 24.

Marks

3

Solution

Odd positions: 3/5+3/5^3+... = (3/5)/(1-1/25) = (3/5)/(24/25) = 15/24. Even positions: 4/25+4/5^4+... = (4/25)/(24/25) = 4/24. Total = 19/24 (matches the printed key).

4.

Q5(d). Sum to infinity (|x| > 1): a/x+b/x^2+a/x^3+b/x^4+...

Knowledge Note

Pair a/x^{2k-1}+b/x^{2k} = (ax+b)/x^{2k}: one GP with ratio 1/x^2.

Marks

3

Solution

Group pairs: (ax+b)/x^2+(ax+b)/x^4+... with first term (ax+b)/x^2 and ratio 1/x^2 (|x| > 1 so it converges). S = ((ax+b)/x^2)/(1-1/x^2) = (ax+b)/(x^2-1) (matches the printed key).

5.

Q5(e). Sum to infinity: 1+3/4+7/16+15/64+...

Knowledge Note

T_r = (2^r-1)/2^{2r-2}: split into 4·(1/2)^r minus (1/4)^{r-1}.

Marks

4

Solution

T_r = (2^r-1)/2^{2r-2} = 4(1/2)^r-(1/4)^{r-1} (check r = 3: 4/8-1/16 = 7/16). S = 4·(1/2)/(1/2)-1/(1-1/4) = 4-4/3 = 8/3 (matches the printed key).

6.

Q6(a). Sum to infinity (-1 < x < 1): 1+3x+5x^2+7x^3+...

Knowledge Note

(1-x)S shifts the arithmetico-geometric series into a plain GP: S = (1+x)/(1-x)^2.

Marks

4

Solution

S = 1+3x+5x^2+...; xS = x+3x^2+5x^3+.... Subtracting: (1-x)S = 1+2x+2x^2+... = 1+2x/(1-x) = (1+x)/(1-x). So S = (1+x)/(1-x)^2 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.3 Q6(a); book p230 = PDF p257 (vision read)

7.

Q6(b). Sum to infinity (-1 < a < 1): 1-5a+9a^2-13a^3+...

Knowledge Note

Same shift trick with ratio -a: (1+a)S = 1-4a/(1+a).

Marks

4

Solution

S = 1-5a+9a^2-...; -aS = -a+5a^2-9a^3+.... Adding: (1+a)S = 1-4a+4a^2-4a^3+... = 1-4a/(1+a) = (1-3a)/(1+a). So S = (1-3a)/(1+a)^2 (matches the printed key).

8.

Q7(a). Sum to n terms: 1+2/2+3/2^2+4/2^3+...

Knowledge Note

Same shift with x = 1/2: S = 4-(n+2)/2^{n-1}; check n = 1 gives 1.

Marks

4

Solution

Arithmetico-geometric with x = 1/2: S = (1-(n+1)/2^n+n/2^{n+1})/(1/2)^2 = 4-(n+1)/2^{n-2}+n/2^{n-1} = 4-n/2^{n-1}-1/2^{n-2} (matches the printed key; n = 1 gives 4-2-1 = 1).

Source

9.

Q7(b). Sum to n terms: 1+4/5+7/5^2+10/5^3+...

Knowledge Note

x = 1/5 version: constant 3·(25/16)-2·(5/4) = 35/16; check n = 1 gives 1.

Marks

5

Solution

T_r = (3r-2)/5^{r-1}. S = 3(1+2x+3x^2+...+nx^{n-1})-2(1+x+...+x^{n-1}) with x = 1/5. Using the finite AG and GP sums: S = 35/16-(12n+7)/(16·5^{n-1}) (matches the printed key; n = 1 gives (35-19)/16 = 1; n = 2 gives 1.8 = 1+4/5).

10.

Q8. If a, b, c are in A.P. and x, y, z are in G.P., prove that x^{b-c}·y^{c-a}·z^{a-b} = 1.

Knowledge Note

Take logs: the lny coefficient telescopes to zero and the lnr coefficient is a+c-2b = 0.

Marks

4

Solution

Put x = y/r, z = yr (common ratio r). log LHS = (b-c)(lny-lnr)+(c-a)lny+(a-b)(lny+lnr) = lny(b-c+c-a+a-b)+lnr(-b+c+a-b) = (a+c-2b)lnr = 0 since a, b, c are in A.P. Hence LHS = 1.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.3 Q8; book p231 = PDF p258 (vision read)

11.

Q9. If p, q, r are in A.P., prove that the qth term is the G.M. between the pth and rth terms of the same G.P.

Knowledge Note

(p+r)/2 = q makes the GM of the pth and rth terms exactly the qth term.

Marks

4

Solution

G.P.: first term A, ratio R. pth term = AR^{p-1}, rth = AR^{r-1}; their GM = AR^{(p+r-2)/2}. Since p, q, r in A.P., (p+r)/2 = q, so the GM is AR^{q-1}, the qth term.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.3 Q9; book p231 = PDF p258 (vision read)

12.

AQ1. If a, b, c are in H.P., prove that a/(a-b) = (a+c)/(a-c).

Knowledge Note

a/(a-b) vs (a+c)/(a-c): cross-multiplying reduces to ab+bc = 2ac, the HP condition.

Marks

4

Solution

Cross-multiplying: a(a-c) = (a+c)(a-b) iff a^2-ac = a^2-ab+ac-bc iff ab+bc = 2ac iff 1/c+1/a = 2/b, which is exactly the H.P. condition (1/a, 1/b, 1/c in A.P.).

Sukunda Basic Mathematics Grade XI, Ch.8 Additional Q1; book p231 = PDF p258 (vision read)

13.

AQ2. If a, b, c are in A.P., x is the G.M. between a and b, and y is the G.M. between b and c, prove that b^2 is the A.M. between x^2 and y^2.

Knowledge Note

AM of x^2, y^2 is b(a+c)/2 = b·b: the AP relation a+c = 2b does the whole job.

Marks

4

Solution

x^2 = ab, y^2 = bc. Their AM is (ab+bc)/2 = b(a+c)/2 = b·2b/2 = b^2 (using a+c = 2b).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Additional Q2; book p231 = PDF p258 (vision read)

14.

AQ3. If the A.M. of two positive numbers a and b is twice their G.M., show that a:b = (2+sqrt(3)):(2-sqrt(3)).

Knowledge Note

t+1/t = 4 with t = sqrt(a/b) gives t = 2±sqrt(3); squaring preserves the ratio form.

Marks

4

Solution

(a+b)/2 = 2sqrt(ab), so a+b = 4sqrt(ab). Put t = sqrt(a/b) > 1: t+1/t = 4, so t^2-4t+1 = 0, t = 2+sqrt(3). Then a:b = t^2:1 = (2+sqrt(3))^2:1 = (2+sqrt(3)):(2-sqrt(3)) since (2+sqrt(3))(2-sqrt(3)) = 1.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Additional Q3; book p231 = PDF p258 (vision read)

15.

AQ4. A rubber ball is dropped from 16 ft; each rebound rises to 3/4 of the previous height. Total distance before rest?

Knowledge Note

16 down + 2×(up GP with a = 12, r = 3/4): 16+2·48 = 112 ft.

Marks

4

Solution

Down: 16. Up-and-down bounces: 2(16·3/4+16·(3/4)^2+...) = 2·12/(1-3/4) = 2·48 = 96. Total = 16+96 = 112 ft (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Additional Q4; book p231 = PDF p258 (vision read)

16.

AQ5. Square side 16 cm; successive squares join midpoints indefinitely. Sum of all perimeters?

Knowledge Note

Midpoint joining halves the area, so sides shrink by 1/sqrt(2): perimeters form a GP with r = 1/sqrt(2).

Marks

4

Solution

Sides: 16, 16/sqrt(2), ... (area halves each time). Perimeters: 64, 64/sqrt(2), ... with r = 1/sqrt(2). Sum = 64/(1-1/sqrt(2)) = 64sqrt(2)/(sqrt(2)-1) = 64(2+sqrt(2)) cm (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Additional Q5; book p231 = PDF p258 (vision read)

18.

AQ6(b). Find the nth term and sum of 1^2.2+2^2.3+3^2.4+...

Knowledge Note

r^2(r+1) = r^3+r^2: cube-sum plus square-sum factor into n(n+1)(n+2)(3n+1)/12.

4

Solution

T_r = r^2(r+1) = r^3+r^2. S_n = [n(n+1)/2]^2+n(n+1)(2n+1)/6 = n(n+1)(3n^2+7n+2)/12 = n(n+1)(n+2)(3n+1)/12 (matches the printed key).
