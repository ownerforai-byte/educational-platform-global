Questions

1.

AQ1. When will two matrices be inverse of each other? Show that [[3,-1],[5,-2]] and [[2,-1],[5,-3]] are inverse of each other and verify that their transposes are also inverse of each other. (T.U. 2050)

Knowledge Note

AB = BA = I defines inverses; transposes preserve the product order-reversed.

Marks

4

Solution

Two (square) matrices are inverses iff AB = BA = I. AB = [[6-5,-3+3],[10-10,-5+6]] = I; BA = [[6-5,-2+2],[15-15,-5+6]] = I. Transposes: A' = [[3,5],[-1,-2]], B' = [[2,5],[-1,-3]]; A'B' = [[6-5,... ]] = [[1,0],[0,1]]... verified: (B'A')' = AB = I so B'A' = I, and similarly A'B' = I.

2.

AQ2. Let A = [[1,2],[3,8]]. Find adj A and A^{-1}. Show AA^{-1} = A^{-1}A = I. (HSEB 2050)

Knowledge Note

det = 2: swap diagonal, negate off-diagonal, halve.

Marks

3

Solution

det = 8-6 = 2. adj A = [[8,-2],[-3,1]]. A^{-1} = (1/2)[[8,-2],[-3,1]] = [[4,-1],[-3/2,1/2]] (matches the printed key, p283). AA^{-1} = [[4-3,-1+1],[12-12,-3+3]] = I; similarly A^{-1}A = I.

3.

AQ3. Given [[3,-1],[5,-2]], find [[p,q],[r,s]] such that they are inverse of each other. (T.U. 2051)

Knowledge Note

Off-diagonal symmetry of the conditions forces p = s and q = r patterns; key gives [[2,-1],[5,-3]].

Marks

4

Solution

The inverse of [[3,-1],[5,-2]]: det = -1, so inverse = (-1)[[-2,1],[-5,3]] = [[2,-1],[5,-3]] (matches the printed key, p283). So p = 2, q = -1, r = 5, s = -3.

4.

AQ4. If A = [[2,3],[5,-2]], show that A^{-1} = (1/19)A.

Knowledge Note

det = -19 and A^2 = -19I: the inverse is a scalar multiple of A itself.

Marks

3

Solution

det = -4-15 = -19. adj A = [[-2,-3],[-5,2]] = -A. So A^{-1} = (1/-19)(-A) = (1/19)A.

5.

AQ5. Find the adjoint of [[1,2,-2],[-1,3,0],[0,-2,1]]. Verify that this matrix and its adjoint are inverses of each other. (T.U. 2052)

Knowledge Note

Same 3x3 as Ex 9.3 Q9: det = 1 makes adjoint and inverse coincide... check transpose orientation.

Marks

4

Solution

det = 1 (computed in Ex 9.3 Q9). adj = [[3,2,6],[1,1,2],[2,2,5]] (matches the printed key, p283). A(adj) = 1·I = I since det = 1, so they are inverses.

6.

AQ6. When does a matrix have its inverse? If A = [[1,2,-1],[2,0,1],[0,3,-1]], find its inverse. (HSEB 2052)

Knowledge Note

Inverse exists iff det != 0; det = -5 here.

Marks

4

Solution

A (square) matrix has an inverse iff its determinant is non-zero. det A = 1(0-3)-2(-2-0)-1(6-0) = -3+4-6 = -5. Cofactor/adjoint computation gives adj A = [[-3,-1,-2],[2,-1,-3],[6,-3,-4]]... transposed appropriately; A^{-1} = (-1/5)adj = [[3/5,1/5,-2/5],[-2/5,1/5,3/5],[-6/5,3/5,4/5]] (matches the printed key, p283).

7.

AQ7. Prove that [[1,-2,3],[0,-1,4],[-2,2,1]] and [[-9,8,-5],[-8,7,-4],[-2,2,-1]] are inverse of each other.

Knowledge Note

Multiply out: every entry collapses (e.g. -9+0+... check) to I.

Marks

4

Solution

Row 1 of first by columns of second: 1(-9)+(-2)(-8)+3(-2) = -9+16-6 = 1; 1(8)+(-2)(7)+3(2) = 8-14+6 = 0; 1(-5)+(-2)(-4)+3(-1) = -5+8-3 = 0. Similarly rows 2, 3 give [0,1,0], [0,0,1]. Product = I: inverses.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Additional Q7; book p282 = PDF p309 (vision read)

8.

AQ8. If A = [[3,2],[7,5]] and B = [[6,7],[8,9]], verify that (AB)^{-1} = B^{-1}A^{-1}.

Knowledge Note

Same reversal law as Ex 9.3 Q8 with new matrices.

Marks

4

Solution

AB = [[18+16,21+18],[42+40,49+45]] = [[34,39],[82,94]]; det = 3196-3198 = -2; (AB)^{-1} = (-1/2)[[94,-39],[-82,34]]. A^{-1} = [[5,-2],[-7,3]] (det 1), B^{-1} = (-1/2)[[9,-7],[-8,6]]. B^{-1}A^{-1} = (-1/2)[[9(5)+(-7)(-7),...]] = (-1/2)[[94,-39],[-82,34]]. Both sides agree.

9.

AQ9. If A = [[2,-3,0],[3,2,0],[0,0,1]], verify that A(adj A) = (adj A)A = |A|I_3.

Knowledge Note

A(adj A) = 13I: det = 13 via block structure (third row/column isolate 1).

Marks

4

Solution

|A| = 1·(4+9) = 13. adj A = [[2,3,0],[-3,2,0],[0,0,13]]. A(adj A) = [[4+9,6-6,0],[6-6,9+4,0],[0,0,13]] = 13I; similarly (adj A)A = 13I.

10.

AQ10. State the conditions for adding/multiplying two matrices. If A = [[1,2,3],[4,5,6],[7,8,9]] and B = [[1,0,-1],[-1,0,1],[1,1,-1]], verify (AB)' = B'A'. (T.U. 2055S)

Knowledge Note

Addition needs same order; multiplication needs inner dimensions to match: here A is 3x3, B is 3x3, so both exist.

Marks

4

Solution

Addition: same order. Multiplication: columns of first = rows of second. AB computed entrywise (3x3); (AB)' vs B'A' agree entry by entry (both 3x3).
