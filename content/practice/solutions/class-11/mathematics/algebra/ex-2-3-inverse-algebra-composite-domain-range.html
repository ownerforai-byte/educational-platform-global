Q9. Show f:R→R, f(x) = cx + d (c ≠ 0) is one-one and onto. Find f⁻¹. Also show f(f⁻¹(x)) = f⁻¹(f(x)) = x.

Knowledge Note

c ≠ 0 is the whole engine: it lets you divide when proving one-one and when solving for onto.

Marks

3

Solution

One-one: cx₁+d = cx₂+d ⟹ c(x₁−x₂) = 0 ⟹ x₁ = x₂ (c ≠ 0). Onto: for any y, x = (y−d)/c ∈ R gives f(x) = y. So f⁻¹(x) = (x−d)/c (matches key). f(f⁻¹(x)) = c·((x−d)/c)+d = x; f⁻¹(f(x)) = (cx+d−d)/c = x. ✅

Source

Q10. f:R−{2}→R−{3}, f(x) = 3x/(x−2). Show f is bijective and find f⁻¹.

Knowledge Note

Cross-multiply to prove one-one; solve y = 3x/(x−2) for x to prove onto and read off the inverse.

Marks

4

Solution

One-one: 3x₁/(x₁−2) = 3x₂/(x₂−2) ⟹ x₁(x₂−2) = x₂(x₁−2) ⟹ −2x₁ = −2x₂ ⟹ x₁ = x₂. Onto: y = 3x/(x−2) ⟹ yx−2y = 3x ⟹ x(y−3) = 2y ⟹ x = 2y/(y−3) ∈ R−{2} for y ≠ 3. So ✅ f⁻¹(x) = 2x/(x−3) (matches key) and f is bijective.
