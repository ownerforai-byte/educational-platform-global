Questions

1.

Q1(a). Let X = {a,b,c}, Y = {p,r,s}. Is R1 = {(a,p),(a,r),(b,r),(c,s)} a function from X to Y? Give reason.

Knowledge Note

A relation X→Y is a function iff every element of X has exactly one image in Y — one output each, no element left without an image.

Marks

1

Solution

Check each element of X: a appears twice — (a,p) and (a,r), i.e. a has two images p and r. A function allows exactly one image per domain element. ✅ NOT a function (a violates uniqueness).

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q1(a)

2.

Q1(b). With X, Y as above, is R2 = {(a,p),(b,r)} a function? Give reason.

Knowledge Note

Totality matters too: every domain element must appear at least once as a first component.

Marks

1

Solution

List first components: {a, b} — element c ∈ X has no pair, so no image for c. A function from X to Y must cover all of X. ✅ NOT a function (c has no image).

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q1(b)

3.

Q1(c). With X, Y as above, is R3 = {(a,s),(b,s),(c,s)} a function? Give reason.

Knowledge Note

Many-to-one is allowed: distinct domain elements may share one image; only one-image-per-element and full coverage are required.

Marks

1

Solution

First components: a→s, b→s, c→s. Every element of X appears exactly once as a first component. ✅ IS a function (constant function; many-to-one is legal).

Q1(d). With X, Y as above, is R4 = {(a,p),(b,p),(c,s)} a function? Give reason.

Knowledge Note

Same test: each of a, b, c used exactly once ⇒ function, even though a and b share image p.

Marks

1

Solution

a→p, b→p, c→s — all three domain elements covered exactly once. ✅ IS a function.

Q1(e). With X, Y as above, is R5 = {(a,p),(b,r),(c,s)} a function? Give reason.

One-to-one onto a 3-element codomain subset: each domain element used once ⇒ function (bijective onto {p,r,s}).

Q2(a). If f: A→B with f(x) = 1−x, find the image of 1.

Knowledge Note

Image = function value at a point: substitute and simplify, watching fraction arithmetic.

Marks

1

Solution

f(1) = 1 − 1 = 0. ✅ Image of 1 is 0.

Q2(b). With f(x) = 1−x as above, find the image of 3/2.

Knowledge Note

With fractions, keep a common denominator: 1 − 3/2 = (2−3)/2 = −1/2.

Marks

1

Solution

f(3/2) = 1 − 3/2 = (2 − 3)/2 = −1/2. ✅ Image of 3/2 is −1/2.

10.

Q3(a). Find a formula for the inverse function f⁻¹ if f: R→R, f(x) = x + 1.

Knowledge Note

Inverse by interchange: set y = f(x), swap to x = …, then solve for y.

Marks

2

Solution

Step 1 — Let y = x + 1. Step 2 — Interchange: x = y + 1. Step 3 — Solve: y = x − 1. ✅ f⁻¹(x) = x − 1. (Check: f(f⁻¹(x)) = (x−1)+1 = x ✔)

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q3(a)

11.

Q3(b). Find f⁻¹ if f: R→R, f(x) = 2x + 3.

Knowledge Note

Linear inverse: after swapping, isolate y by undoing ×2 then −3.

Marks

2

Solution

Step 1 — y = 2x + 3. Step 2 — x = 2y + 3. Step 3 — 2y = x − 3, so y = (x−3)/2. ✅ f⁻¹(x) = (x−3)/2. (Check: 2·((x−3)/2)+3 = x ✔)

Q3(d). Find f⁻¹ if f: R→R, f(x) = x³ + 5.

Knowledge Note

Cubic inverse uses the real cube root: x = y³+5 ⇒ y = ∛(x−5).

2

Solution

Step 1 — y = x³ + 5. Step 2 — x = y³ + 5. Step 3 — y³ = x − 5, so y = ∛(x−5). ✅ f⁻¹(x) = ∛(x−5). (Check: (∛(x−5))³+5 = x ✔)

Q3(e). Find f⁻¹ if f: R→R, f(x) = 3x − 2.

Knowledge Note

Undo 3x−2 in reverse: add 2, divide by 3.

2

Solution

15.

Q4(a-i). Let f(x) = 2x + 1 and g(x) = 3x − 1. Find gof(x).

Knowledge Note

gof means apply f first: g(f(x)) = 3(2x+1)−1.

Marks

2

Solution

gof(x) = g[f(x)] = g(2x+1) = 3(2x+1) − 1 = 6x + 3 − 1. ✅ gof(x) = 6x + 2.

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q4(a) gof

16.

Q4(a-ii). With f, g as above, find fog(x).

Knowledge Note

fog reverses the order: f(g(x)) = 2(3x−1)+1. Order matters — compare with gof.

Marks

2

Solution

fog(x) = f[g(x)] = f(3x−1) = 2(3x−1) + 1 = 6x − 2 + 1. ✅ fog(x) = 6x − 1. (Note gof ≠ fog here.)

Q4(b-i). Let f(x) = 3x² − 4 and g(x) = 2x − 5. Find gof(x).

Knowledge Note

Substitute the whole quadratic into the linear outer function, then expand.

Marks

2

Solution

gof(x) = g(3x²−4) = 2(3x²−4) − 5 = 6x² − 8 − 5. ✅ gof(x) = 6x² − 13.

18.

Q4(b-ii). With f, g as above, find fog(x).

Knowledge Note

Squaring a binomial: (2x−5)² = 4x² − 20x + 25 — middle term is 2·(2x)(−5).

Marks

3

Solution

fog(x) = f(2x−5) = 3(2x−5)² − 4 = 3(4x² − 20x + 25) − 4 = 12x² − 60x + 75 − 4. ✅ fog(x) = 12x² − 60x + 71. (Check at x = 0: f(g(0)) = f(−5) = 3·25−4 = 71 ✔)

Q4(c-i). Let f(x) = x³ − 1 and g(x) = x². Find gof(x).

Knowledge Note

Marks

2

Solution

gof(x) = (x³−1)². ✅ gof(x) = (x³ − 1)² (= x⁶ − 2x³ + 1 expanded).
