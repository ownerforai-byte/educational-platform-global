Knowledge Note

3

Solution

Q8. Using the properties of real numbers, prove: (a) a + c = c + a; (b) a·c = b·c ⇒ a = b (c≠0); (c) a<b ⇒ a+c<b+c; (d) a < b and c < d ⇒ a + c < b + d; (e) a > b and c < 0 ⇒ a·c < b·c; (f) a > b and c > 0 ⇒ a·c > b·c. (Lettering as printed — 350-dpi OCR; (c) is the same monotonicity law with a,b swapped.)

Knowledge Note

These are the field/order axioms of R (section 1.7–1.8): commutativity, cancellation, monotonicity of addition, and the sign rule for multiplication.

Marks

6

Solution

(a) Commutative axiom of addition: for all a,c∈R, a+c = c+a. ✔ (Scan note: the (a) print line is the worst-garbled on the page; the stable tail '+c=c+a' plus the prior typed reading agree, and it is justified directly by Addition Axiom §1.7(ii).) (b) Cancellation: ac=bc → ac−bc=0 → c(a−b)=0 → since c≠0, a−b=0, so a=b. ✔ (c) Addition axiom (monotonicity): if a<b then a+c<b+c (add c to both sides). ✔ (d) Add the two inequalities (transitivity of order): a<b and c<d → a+c < b+c < b+d, hence a+c < b+d. ✔ (e),(f) Multiplication axiom: multiplying an inequality by a positive c preserves the sign (a>b, c>0 → ac>bc); multiplying by a negative c reverses it (a>b, c<0 → ac<bc). ✔ All six follow directly from the field + order axioms stated in §1.7–1.8.

Sukunda Basic Mathematics XI, Ch.1 Ex 1.3 (pp 40-41); axioms from §1.7 Field Axioms & §1.8 Order Axioms
