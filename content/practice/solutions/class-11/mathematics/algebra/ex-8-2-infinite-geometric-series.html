Q1(a). Does 1+2+2^2+2^3+... have a sum?

Knowledge Note

r = 2, |r| > 1: partial sums 2^n-1 diverge, no sum.

Marks

1

Solution

r = 2 with |r| > 1: the partial sums S_n = 2^n-1 grow without bound, so the series has no sum.

Q3. The sum to infinity of a geometric series is 15, and the first term is 3. Find the common ratio.

Knowledge Note

15 = 3/(1-r) gives 1-r = 1/5 at once.

Marks

3

Solution

3/(1-r) = 15, so 1-r = 3/15 = 1/5, giving r = 4/5 (matches the printed key; |r| < 1 so the sum is valid).

12.

Q4. The sum of an infinite number of terms in G.P. is 15, and the sum of their squares is 45; find the series.

Knowledge Note

Divide the square-sum equation by the sum equation: (1-r)/(1+r) = 1/5 forces r = 2/3, a = 5.

Marks

4

Solution

a/(1-r) = 15 and a^2/(1-r^2) = 45. Since 1-r^2 = (1-r)(1+r), the second gives a^2/((1-r)(1+r)) = 45. With a = 15(1-r): 225(1-r)^2/((1-r)(1+r)) = 225(1-r)/(1+r) = 45, so (1-r)/(1+r) = 1/5, giving 5-5r = 1+r, r = 2/3. Then a = 15(1/3) = 5. The series is 5+10/3+20/9+... (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.2 Q4; book p221 = PDF p248 (vision read)

13.

Q5. Prove that 3^(1/3)·3^(1/9)·3^(1/27)·... = √3.

Knowledge Note

The exponents 1/3+1/9+... sum to 1/2, so the product is 3^(1/2).

Marks

3

Solution

The product equals 3^(1/3+1/9+1/27+...). The exponent is a geometric series with a = 1/3, r = 1/3: sum = (1/3)/(1-1/3) = 1/2. So the product is 3^(1/2) = √3.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.2 Q5; book p221 = PDF p248 (vision read)

14.

Q6. If x = 1/(1+y) with y > 0, prove that x+x^2+x^3+... to infinity = 1/y.

Knowledge Note

y > 0 gives 0 < x < 1, so x/(1-x) applies; x = 1/(1+y) turns 1-x into y/(1+y).

Marks

3

Solution

Since y > 0, 0 < x = 1/(1+y) < 1, so the infinite sum is x/(1-x). Now 1-x = 1-1/(1+y) = y/(1+y) = xy, so x/(1-x) = x/(xy) = 1/y.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.2 Q6; book p221 = PDF p248 (vision read)
