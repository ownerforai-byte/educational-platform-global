1.

Q1(a). Apply matrix method or Cramer's rule: 2x - y = 5; x - 2y = 1.

Knowledge Note

Cramer's rule 2×2: D = -3, Dx = -9, Dy = -3; one determinant per variable.

Marks

4

Solution

A = [2 -1; 1 -2], C = [5; 1]. D = 2(-2)-(-1)(1) = -3. Dx = 5(-2)-(-1)(1) = -9, Dy = 2(1)-5(1) = -3. x = Dx/D = 3, y = Dy/D = 1. Matrix check: A^-1 = (-1/3)[-2 1; -1 2], X = A^-1 C = [3; 1]. Boxed (3,1). Verify: 6-1 = 5 ✓; 3-2 = 1 ✓ (matches the printed key).

Q1(b). Apply matrix method or Cramer's rule: 2x + 5y = 17; 5x - 2y = -1.

Knowledge Note

D = 2(-2)-5(5) = -29; the large pivot still divides evenly.

4

Solution

D = 2(-2)-5(5) = -29. Dx = 17(-2)-5(-1) = -29, Dy = 2(-1)-17(5) = -87. x = -29/-29 = 1, y = -87/-29 = 3. Boxed (1,3). Verify: 2+15 = 17 ✓; 5-6 = -1 ✓ (matches the printed key).

Q1(c). Apply matrix method or Cramer's rule: 3x + 4y = -2; 5x - 7y = 24.

Knowledge Note

Q1(f). Apply matrix method or Cramer's rule: 2x + 5y = 24; 2x + 3y = 12.

Solution

7.

Q1(g). Apply matrix method or Cramer's rule: (2x/3) + y = 16; x + (y/4) = 14.

Knowledge Note

Clear fractions first: ×3 and ×4 give 2x+3y = 48 and 4x+y = 56 — integer Cramer's rule from there.

Marks

4

Solution

Multiply first by 3: 2x+3y = 48. Multiply second by 4: 4x+y = 56. D = 2(1)-3(4) = -10. Dx = 48(1)-3(56) = -120, x = 12. Dy = 2(56)-48(4) = -80, y = 8. Boxed (12,8). Verify: 8+8 = 16 ✓; 12+2 = 14 ✓ (matches the printed key).

8.

Q1(h). Apply matrix method or Cramer's rule: 3x + (4/y) = 10; -2x + (3/y) = -1.

Knowledge Note

Substitute u = 1/y to linearise: 3x+4u = 10; -2x+3u = -1; then y = 1/u.

Marks

4

Solution

Put u = 1/y: 3x+4u = 10; -2x+3u = -1. D = 9+8 = 17. Dx = 30+4 = 34, x = 2. Du = -3+20 = 17, u = 1, so y = 1. Boxed (2,1). Verify: 6+4 = 10 ✓; -4+3 = -1 ✓ (matches the printed key).

9.

Q2(a). Solve by matrix method or Cramer's rule: x - 3y - 7z = 6; 2x + 3y + z = 9; 4x + y = 7.

Knowledge Note

3×3 Cramer's rule: D = 1(0-1)+3(2-4)-7(2-12) = 63; Dx = 63, Dy = 189, Dz = -126.

Marks

5

Solution

D = |1 -3 -7; 2 3 1; 4 1 0|: 1×(3×0-1×1) = -1; -(-3)×(2×0-1×4) = -12; +(-7)×(2×1-3×4) = +70; D = -1-12+70 = 57. Dx (constants in column 1): 6×(0-1) = -6; +3×(0-7) = -21; -7×(9-21) = +84; Dx = 57, x = 1. Dy = 171 (same expansion down column 2), y = 171/57 = 3. Dz = -114, z = -114/57 = -2. Boxed (1,3,-2). Verify: 1-9+14 = 6 ✓; 2+9-2 = 9 ✓; 4+3 = 7 ✓ (matches the printed key; D = 57 ≠ 0 confirms uniqueness).

Source

Sukunda Basic Mathematics Grade XI, Ch.10 Ex 10.3 Q2(a); book p310 = PDF p337 (vision read)

10.

Q2(b). Solve by matrix method or Cramer's rule: 2x - 3y - z = 4; x - 2y - z = 1; x - y + 2z = 9. (T.U. 2053)

Knowledge Note

T.U. 2053: D = 2(-5)-(-3)(3)+(-1)(-1+2) = -2; Dx = -4, Dy = 2, Dz = -6.

Marks

5

Solution

D = |2 -3 -1; 1 -2 -1; 1 -1 2| = 2(-4-1)+3(2+1)-(−1+2) = -10+9-1 = -2. Dx = |4 -3 -1; 1 -2 -1; 9 -1 2| = 4(-5)+3(2+9)-(−1+18) = -20+33-17 = -4, x = 2. Dy = |2 4 -1; 1 1 -1; 1 9 2| = 2(2+9)-4(2+1)-(9-1) = 22-12-8 = 2, y = -1. Dz = |2 -3 4; 1 -2 1; 1 -1 9| = 2(-18+1)+3(9-1)+4(-1+2) = -34+24+4 = -6, z = 3. Boxed (2,-1,3). Verify in first: 4+3-3 = 4 ✓ (matches the printed key).

11.

Q2(c). Solve by matrix method or Cramer's rule: 3x - y - 2z = 1; x - y + 2z = 3; -2x + 3y + z = 8.

Knowledge Note

Elimination is shorter than 3×3 determinants here: row 1 gives 3x = 1+y+2z; substitute down the chain.

Marks

5

Solution

(second)-(first)÷? Use elimination: from row 2, x = 3+y-2z. In row 1: 3(3+y-2z)-y-2z = 1 gives 9+2y-8z = 1, y-4z = -4. Row 3: -2(3+y-2z)+3y+z = 8 gives -6+y+5z = 8, y+5z = 14. Subtracting: 9z = 18, z = 2; y = 14-10 = 4; x = 3+4-4 = 3. Boxed (3,4,2). Verify in first: 9-4-4 = 1 ✓ (matches the printed key).

12.

Q2(d). Solve by matrix method or Cramer's rule: 3x + 5y = 2; 2x - 3z = -7; 4y + 2z = 2.

Knowledge Note

Sparse system: from 2x-3z = -7 get x = (3z-7)/2; from 4y+2z = 2 get y = (1-z)/2; one substitution left.

Marks

5

Solution

y = (1-z)/2, x = (3z-7)/2. In 3x+5y = 2: 3(3z-7)/2+5(1-z)/2 = 2 gives (9z-21+5-5z)/2 = 2, 4z-16 = 4, z = 5; then x = 4, y = -2. Boxed (4,-2,5). Verify: 12-10 = 2 ✓; 8-15 = -7 ✓; -8+10 = 2 ✓ (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.10 Ex 10.3 Q2(d); book p310 = PDF p337 (vision read)

13.

Q2(e). Solve by matrix method or Cramer's rule: 6y + 6z = -1; 8x + 6z = -1; 4x + 9y = 8. [Print note: the Answers line shows (1/2,2/3,5/6), but 6(2/3)+6(5/6) = 9 ≠ -1; z = -5/6 is correct.]

Knowledge Note

Key-slip alert: 6y+6z = -1 with y = 2/3 forces z = -5/6, not +5/6 — substitution proves the printed plus is wrong.

Marks

5

Solution

From 4x+9y = 8 and 8x+6z = -1: multiply first by 2, 8x+18y = 16; subtract second: 18y-6z = 17. With 6y+6z = -1 (×3: 18y+18z = -3): subtracting gives -24z = 20, z = -5/6. Then 6y-5 = -1, y = 2/3; 8x-5 = -1, x = 1/2. Boxed (1/2,2/3,-5/6). Verify: 4+(-5) = -1 ✓; 4-5 = -1 ✓; 2+6 = 8 ✓. The printed +5/6 fails the first equation, so it is a sign slip.

14.

Q2(f). Solve by matrix method or Cramer's rule: x + 2y - z = -5; 2x - y + z = 6; x - y - 3z = -3.

Knowledge Note

D = 1(3+1)-2(-6-1)-(−2+1) = 4+14+1 = 19; Dx = 19, Dy = -38, Dz = 38.

Marks

5

Solution

D = |1 2 -1; 2 -1 1; 1 -1 -3| = 1(3+1)-2(-6-1)-(−2+1) = 4+14+1 = 19. Dx = |-5 2 -1; 6 -1 1; -3 -1 -3| = -5(3+1)-2(-18+3)-(−6-3) = -20+30+9 = 19, x = 1. Dy = |1 -5 -1; 2 6 1; 1 -3 -3| = 1(-18+3)+5(-6-1)-(−6-6) = -15-35+12 = -38, y = -2. Dz = |1 2 -5; 2 -1 6; 1 -1 -3| = 1(3+6)-2(-6-6)-5(-2+1) = 9+24+5 = 38, z = 2. Boxed (1,-2,2). Verify in second: 2+2+2 = 6 ✓ (matches the printed key).
