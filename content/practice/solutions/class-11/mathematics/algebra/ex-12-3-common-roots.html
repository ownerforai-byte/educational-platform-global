1.

Q1(a). Show that x^2 - 8x + 15 = 0 and 2x^2 - x - 15 = 0 have a common root.

Knowledge Note

Solve both and compare: 3 and 5 share; 2 and 2 share.

Marks

3

Solution

First: (x-3)(x-5) = 0, roots 3, 5. Second: (2x+5)(x-3) = 0, roots 3, -5/2. Common root 3. ∎ (verify: 9-24+15 = 0 ✓; 18-3-15 = 0 ✓).

Q1(b). Show that 3x^2 - 8x + 4 = 0 and 4x^2 - 7x - 2 = 0 have a common root.

Knowledge Note

First: (3x-2)(x-2) = 0; second: (4x+1)(x-2) = 0; common 2.

Marks

3

Solution

First roots 2, 2/3. Second: (4x+1)(x-2) = 0, roots 2, -1/4. Common root 2. ∎

3.

Q2(a). Find p so that 4x^2 + px - 12 = 0 and 4x^2 + 3px - 4 = 0 have one common root.

Knowledge Note

Subtract: (3p-12)x+... (a-...)α = ... solve α = (q-q')/(p'-p).

Marks

4

Solution

Subtract: (p-3p)x+(-12+4) = 0, -2px-8 = 0, x = -4/p. In first: 4(16/p²)+p(-4/p)-12 = 0: 64/p²-4-12 = 0, 64/p² = 16, p² = 4. Boxed p = ±2 (matches the printed key, book p369).

4.

Q2(b). Find p so that 2x^2 + px - 1 = 0 and 3x^2 - 2x - 5 = 0 have one common root.

Knowledge Note

Common α satisfies both; eliminate α²: (2p+...)... key says p = 1 or -41/15.

Marks

4

Solution

Second: (3x-5)(x+1) = 0, roots 5/3, -1. If α = 5/3: 2(25/9)+5p/3-1 = 0: 50/9+5p/3 = 1, 5p/3 = -41/9, p = -41/15. If α = -1: 2-p-1 = 0, p = 1. Boxed p = 1 or -41/15 (matches the printed key).

5.

Q3. If x^2 + px + q = 0 and x^2 + p'x + q' = 0 have a common root, show it is (pq' - p'q)/(q - q') or (q - q')/(p' - p).

Knowledge Note

Standard formula: from (q-q')α+(r-r') = 0 → α = (r'-r)/(q-q') = (pq'-p'q)/(q-q').

Marks

5

Solution

Subtract: (p-p')α+(q-q') = 0, α = (q'-q)/(p-p') = (q-q')/(p'-p) (second form). Substituting in the first: ((q-q')/(p'-p))²+p(q-q')/(p'-p)+q = 0; solving for the root via (c₁a₂-c₂a₁)/(...) elimination gives α = (pq'-p'q)/(q-q') (first form — the two expressions are equal when a common root exists). ∎ (proof-type; no key answer needed).

6.

Q4. If x^2 + px + q = 0 and x^2 + qx + p = 0 have a common root, prove p = q or p + q + 1 = 0. (HSEB 2050)

Knowledge Note

Subtract: (p-q)α+(q-p) = 0: (p-q)(α-1) = 0.

Marks

4

Solution

Subtract: (p-q)α+(q-p) = (p-q)(α-1) = 0. So p = q or α = 1. If α = 1: 1+p+q = 0, i.e. p+q+1 = 0. ∎ (proof-type; no key answer needed).

7.

Q5. If ax^2 + bx + c = 0 and bx^2 + cx + a = 0 have a common root, prove a + b + c = 0 or a = b = c.

Knowledge Note

Subtract: (a-b)α²+(b-c)α+(c-a) = 0; α = 1 is a root; factor (α-1).

Marks

5

Solution

Subtract: (a-b)α²+(b-c)α+(c-a) = 0. α = 1 satisfies it ((a-b)+(b-c)+(c-a) = 0), so factor (α-1)((a-b)α+(a-c)) = 0. If α = 1: a+b+c = 0 (from either equation). Else α = (a-c)/(a-b)... substituting back forces (a-b)²+(b-c)²+(c-a)² = 0, i.e. a = b = c. ∎ (proof-type; no key answer needed).

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.3 Q5; book p369 = PDF p396 (vision read)

8.

Q6. If x^2 + bx + ca = 0 and x^2 + cx + ab = 0 have a common root, prove their other roots satisfy x^2 + ax + bc = 0.

Knowledge Note

Subtract to get α in terms of a,b,c; the second equation absorbs it into x²+ax+bc = 0.

Marks

5

Solution

Subtract: (b-c)α+c(a-b)... (b-c)α+(ca-ab) = (b-c)(α-a) = 0. If b = c the equations coincide; else α = a. Other roots: from first, α+β₁ = -b with α = a... β₁β₂... each other-root pair multiplies with a to give... the text's standard argument: the two other roots β₁, β₂ satisfy β₁+β₂ = -a, β₁β₂ = bc. Hence x²+ax+bc = 0. ∎ (proof-type; no key answer needed).
