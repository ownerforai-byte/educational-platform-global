1.

Q1. What are the roots of a quadratic equation? Can a real-coefficient quadratic have one real and one imaginary root? (T.U. 2053)

Knowledge Note

Quadratic ⟺ degree 2 with a ≠ 0; real coefficients ⟹ complex roots pair up (conjugate-root theorem).

Marks

4

Solution

Roots are the x-values making ax²+bx+c = 0. No: if a+ib (b ≠ 0) is a root of a real-coefficient quadratic, its conjugate a-ib is also a root — imaginary roots occur in pairs. One real + one imaginary is impossible. ∎ (T.U. 2053; proof-type.)

Q2. For ax^2 + bx + c = 0 state root conditions. Find the equation with reciprocal roots of 3x^2 - 5x - 3 = 0. (HSEB 2051)

Knowledge Note

D > 0 / = 0 / < 0; reciprocal equation 3x²-5x-3 = 0 → 3x²+5x-1 = 0... check: 1/α+1/β = S/P, 1/P. (HSEB 2051)

Marks

5

Solution

Real unequal ⟺ D > 0; equal ⟺ D = 0; imaginary ⟺ D < 0. Reciprocals of 3x²-5x-3 = 0: S = 5/3, P = -1. New S = S/P = -5/3... 1/α+1/β = (α+β)/αβ = (5/3)/(-1) = -5/3; new P = 1/P = -1. x²+(5/3)x-1 = 0. Boxed 3x²+5x-3 = 0 (matches the printed key, book p371).

3.

Q3. Distinguish identity vs equation. What are the roots of ax^2 + bx + c = 0? Prove a quadratic has at most two roots. (T.U. 2049)

Knowledge Note

Identity holds for all x; equation for some x; n+1 points force degree-n equality — a quadratic has ≤ 2 roots. (T.U. 2049)

Marks

5

Solution

Identity: true for every x (e.g. (x+1)² = x²+2x+1). Equation: true only for specific x (its roots: x = (-b±√D)/2a). At most two: if α,β,γ were three distinct roots, ax²+bx+c = a(x-α)(x-β) vanishes at γ only if... a(γ-α)(γ-β) = 0 with a ≠ 0 and distinct factors nonzero — contradiction. ∎ (T.U. 2049; proof-type.)

4.

Q4. Conditions for ax^2 + bx + c = 0 to have (i) reciprocal roots, (ii) equal-magnitude opposite-sign roots, (iii) both roots positive, (iv) both roots negative.

Knowledge Note

Reciprocal ⟺ c = a; opposite-in-sign ⟺ b = 0; both positive ⟺ S > 0, P > 0, D ≥ 0; both negative ⟺ S < 0, P > 0, D ≥ 0.

Marks

5

Solution

(i) c = a (P = 1). (ii) b = 0 (S = 0). (iii) a,c same sign, b opposite sign, D ≥ 0 (S = -b/a > 0, P = c/a > 0). (iv) a,b,c same sign, D ≥ 0 (S < 0, P > 0). (Matches the printed key: i) c = a; ii) b = 0; iii/iv sign rules + positive discriminant, book p371.)

Sukunda Basic Mathematics Grade XI, Ch.12 Additional Q4; book p369 = PDF p396 (vision read)

Q5. Prove the roots of x^2 + (2k - 1)x + k^2 = 0 are real if k ≤ 1/4.

Knowledge Note

D = (2k-1)²-4k² = 1-4k ≥ 0 ⟺ k ≤ 1/4.

Marks

4

Solution

D = (2k-1)²-4k² = 4k²-4k+1-4k² = 1-4k. Real ⟺ D ≥ 0 ⟺ k ≤ 1/4. ∎ (proof-type; no key answer needed).

Q6. Show the roots of 2(a^2 + b^2)x^2 + 2(a + b)x + 1 = 0 are never real unless a = b.

Knowledge Note

D/4 = (a+b)²-2(a²+b²) = -(a-b)² ≤ 0; real only at a = b.

Marks

4

Solution

D/4 = (a+b)²-2(a²+b²) = a²+2ab+b²-2a²-2b² = -(a²-2ab+b²) = -(a-b)² ≤ 0. D = 0 (real, equal) only when a = b; else D < 0 (imaginary). ∎ (proof-type; no key answer needed).

Sukunda Basic Mathematics Grade XI, Ch.12 Additional Q6; book p369 = PDF p396 (vision read)

7.

Q7. Show the roots of (b - c)x^2 + 2(c - a)x + (a - b) = 0 are always real.

Knowledge Note

D = 4(c-a)²-4(b-c)(a-b) = 4[(a-b)²+(b-c)²+(c-a)²]/2 ≥ 0 always.

Marks

4

Solution

D/4 = (c-a)²-(b-c)(a-b). Expand: c²-2ca+a²-(ab-b²-ca+bc) = a²+b²+c²-ab-bc-ca = ½[(a-b)²+(b-c)²+(c-a)²] ≥ 0. Hence always real. ∎ (proof-type; no key answer needed).

Q8. Prove the roots of (a^2 + b^2)x^2 + 2(bc + ad)x + (c^2 + d^2) = 0 are imaginary; real only when a/b = d/c.

Knowledge Note

D/4 = (bc+ad)²-(a²+b²)(c²+d²) = -(ad-bc)² ≤ 0; zero ⟺ ad = bc ⟺ a/b = d/c.

Marks

5

Solution

Q9. Find m so that 3x^2 + 4mx + 2 = 0 and 2x^2 + 3x - 2 = 0 have a common root.

Knowledge Note

Second equation: (2x-1)(x+2) = 0, roots 1/2, -2; test each in the first.

Marks

4

Solution

Second roots: x = [-3±√(9+16)]/4 = (-3±5)/4: 1/2, -2. If 1/2: 3/4+2m+2 = 0, 2m = -11/4, m = -11/8. If -2: 12-8m+2 = 0, 8m = 14, m = 7/4. Boxed m = 7/4 or -11/8 (matches the printed key, book p371).

Q10. If the root-ratios of ax^2 + bx + c = 0 and a'x^2 + b'x + c' = 0 are equal, prove b^2/b'^2 = ac/a'c'.

Knowledge Note

Ratio r: roots of first kr₁,kr₂... b²/ac is ratio-invariant: b²/ac = (r+1)²/r = b'²/a'c'.

Marks

5

Solution

Let ratio be r:1, roots k·r, k·1: S = k(r+1) = -b/a, P = kr²... k²r = c/a. b²/ac = k²(r+1)²/(k²r) = (r+1)²/r — depends only on r. Same r for both equations gives b²/ac = b'²/a'c'. Rearranged: b²/b'² = ac/a'c'. ∎ (proof-type; no key answer needed).

Q12. For what k is one root of x^2 + 3x - 6 = k(x - 1)^2 double the other?

Knowledge Note

x²+3x-6 = k(x-1)²: (1-k)x²+(3+2k)x-(6+k) = 0 with roots α,2α: 3α = S, 2α² = P.

Marks

5

Solution

(1-k)x²+(3+2k)x-(6+k) = 0. Roots α, 2α: 3α = -(3+2k)/(1-k), 2α² = -(6+k)/(1-k). From first α = -(3+2k)/(3(1-k)); substitute: 2(3+2k)²/(9(1-k)²) = -(6+k)/(1-k). Solve: 2(3+2k)² = -9(6+k)(1-k). Expand: 2(9+12k+4k²) = -9(6-6k+k-k²) = -9(6-5k-k²): 18+24k+8k² = -54+45k+9k²: 0 = -72+21k+k² = k²+21k-72 = (k+24)(k-3). Boxed k = -24 or 3 (matches the printed key).

Q13. For what k are the roots of 3x^2 - 2kx + k = 0 in ratio 3:1?

Knowledge Note

Ratio 3:1: 4t = 2k/3... S = 2k/3, P = k/3: 16t²... solve: k = 4.

Marks

4

Solution

Roots 3t, t: S = 4t = 2k/3, P = 3t² = k/3. From first t = k/6; 3k²/36 = k/3: k²/12 = k/3: k² = 4k. k ≠ 0 (else P = 0 = S... degenerate), so k = 4. Boxed 4 (matches the printed key).

14.

Q14. If the root-sum of 1/(x + a) + 1/(x + b) = 1/c is zero, prove the root-product is -(a^2 + b^2)/2.

Knowledge Note

1/(x+a)+1/(x+b) = 1/c: (2x+a+b)c = x²+(a+b)x+ab; S = 0 gives c = (a+b)/2... then P = ab-(a+b)c = ... -(a²+b²)/2.

Marks

5

Solution

(x+b+x+a)c = (x+a)(x+b): 2cx+(a+b)c = x²+(a+b)x+ab. x²+((a+b)-2c)x+(ab-(a+b)c) = 0. S = 0: (a+b)-2c = 0, c = (a+b)/2. P = ab-(a+b)c = ab-(a+b)²/2 = (2ab-a²-2ab-b²)/2 = -(a²+b²)/2. ∎ (proof-type; no key answer needed).

Q17. If α, β are the roots of ax^2 + bx + c = 0, find equations with roots (i) (aα + b)^-1, (aβ + b)^-1 and (ii) √(α/β), √(β/α).

Knowledge Note

aα+b = -c/α: (aα+b)⁻¹ = -α/c; sum -S/c = b/ac... new equation acx²-bx+1 = 0.

Marks

5

Solution

(i) aα+b = -c/α (since aα²+bα+c = 0), so (aα+b)⁻¹ = -α/c. New S = -(α+β)/c = b/ac; new P = αβ/c² = (c/a)/c² = 1/ac. x²-(b/ac)x+1/ac = 0. Boxed acx²-bx+1 = 0 (matches). (ii) t = √(α/β): t+1/t = S/√P; t satisfies √P·t²-S·t+√P... with S = -b/a, P = c/a: √(c/a)t²+(b/a)t+√(c/a) = 0. Boxed √ac·x²+bx+√ac = 0 (matches the printed key).

19.

Q19. If the root-differences of x^2 + 2px + q = 0 and x^2 + 2qx + p = 0 are equal, prove p + q + 1 = 0.

Knowledge Note

Difference 2√(p²-q) = 2√(q²-p): square: p²-q = q²-p, (p-q)(p+q+1) = 0 with... p,q... the differences equal with p ≠ q gives p+q+1 = 0.

Marks

5

Solution

Δ₁ = 2√(p²-q), Δ₂ = 2√(q²-p). Equal: p²-q = q²-p: p²-q²+p-q = (p-q)(p+q)+(p-q)... (p-q)(p+q+1) = 0. For distinct pairings (non-identical equations) p ≠ q... the text's conclusion: p+q+1 = 0. ∎ (proof-type; the header problem on book p371).

Sukunda Basic Mathematics Grade XI, Ch.12 Additional Q19 (header problem); book p371 = PDF p398 (vision read)
