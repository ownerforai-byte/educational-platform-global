Q9. If z̄ is the conjugate of z, prove that Arg(z̄) = 2π - Arg(z).

Knowledge Note

z̄ = r(cosθ-i sinθ); Arg runs clockwise: 2π-θ.

Marks

4

Solution

z = r(cosθ+i sinθ) with θ = Arg(z). z̄ = r(cosθ-i sinθ) = r(cos(2π-θ)+i sin(2π-θ)). So Arg(z̄) = 2π-θ = 2π-Arg(z). ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.11 Ex 11.4 Q9; book p346 = PDF p373 (vision read)

Q10. If z = cosθ + i sinθ, prove that z^n - 1/z^n = 2i sin(nθ).

Knowledge Note

zⁿ = cos nθ+i sin nθ; 1/zⁿ = cos nθ-i sin nθ; subtract: 2i sin nθ.

Marks

4

Solution

zⁿ = cos nθ+i sin nθ (De Moivre). 1/zⁿ = z̄ⁿ = cos nθ-i sin nθ (since |z| = 1). Subtracting: 2i sin nθ. ∎ (proof-type; no key answer needed).
