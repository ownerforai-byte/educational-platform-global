Questions

1.

Q1(a). If A = [[1,2],[3,5]] and B = [[4,-1],[2,3]], compute A+B, A-B and 2A+3B.

Knowledge Note

Add entrywise; matching shapes is the validity condition for +/-.

Marks

4

Solution

A+B = [[5,1],[5,8]]. A-B = [[-3,3],[1,2]]. 2A = [[2,4],[6,10]], 3B = [[12,-3],[6,9]], so 2A+3B = [[14,1],[12,19]].

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q1(a); book p248 = PDF p275 (vision read)

2.

Q1(b). If A = [[1,2],[3,5]], B = [[4,-1],[2,3]] and C = [[1,2,3],[0,1,4]], compute the following, if possible: (i) A+B (ii) A-B (iii) A+C.

Knowledge Note

Addition needs identical order: B is 2x2, C is 2x3, so only A+B and A-B exist.

Marks

3

Solution

(i) A+B = [[5,1],[5,8]]. (ii) A-B = [[-3,3],[1,2]]. (iii) A+C is NOT possible: A is 2x2 while C is 2x3, and addition requires identical order.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q1(b); book p248 = PDF p275 (vision read)

3.

Q2. Compute: (i) 2[[1,4],[2,5]] (ii) (1/2)[[1,4],[2,5]] (iii) 3[[4,0],[2,-3]].

Knowledge Note

Scalar multiple acts on every entry; check each entry against the key.

Marks

3

Solution

(i) [[2,8],[4,10]]. (ii) [[1/2,2],[1,5/2]]. (iii) [[12,0],[6,-9]].

4.

Q3. If A = [[1,3],[2,5]] and B = [[-2,0],[1,4]], show that AB != BA.

Knowledge Note

AB multiplies rows of A by columns of B; BA has different entries: the classic non-commutativity example.

Marks

4

Solution

AB = [[1(-2)+3(1), 1(0)+3(4)],[2(-2)+5(1), 2(0)+5(4)]] = [[1,12],[1,20]]. BA = [[-2(1)+0(2), -2(3)+0(5)],[(1)+4(2), 3+20]] = [[-2,-6],[9,23]]. Since [[1,12],[1,20]] != [[-2,-6],[9,23]], AB != BA.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q3; book p248 = PDF p275 (vision read)

5.

Q4. If A = [[1,0,-1],[3,2,1]] and C = [[1,2],[0,3],[-2,5]], show that AC != CA (one side may fail to exist).

Knowledge Note

AC is 2x2 via inner dimension 3; CA is blocked (3-wide times 2-tall).

Marks

4

Solution

AC = [[1(1)+0(0)+(-1)(-2), 1(2)+0(3)+(-1)(5)],[3(1)+2(0)+1(-2), 3(2)+2(3)+1(5)]] = [[3,-3],[1,17]] (2x2). CA is 3x2 times 2x3 = 3x3: CA = [[7,4,1],[9,6,3],[13,10,7]]. Since AC is 2x2 and CA is 3x3, AC != CA.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q4; book p248-249 = PDF pp275-276 (vision read)

6.

Q5. If A = [[1,2],[0,3]] and C = [[0,2],[0,-1]], show that AC = O although A != O and C != O.

Knowledge Note

Zero divisors exist for matrices: both factors non-zero, product zero.

Marks

3

Solution

AC = [[1(0)+2(0), 1(2)+2(-1)],[0(0)+3(0), 0(2)+3(-1)]] = [[0,0],[0,0]] = O, while A != O and C != O.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q5; book p249 = PDF p276 (vision read)

7.

Q6. If A = [[1,4],[3,6]], B = [[1,2],[0,-2]] and C = [[2,1],[0,3]], show that A(B+C) = AB+AC.

Knowledge Note

Distributivity A(B+C) = AB+AC holds entry by entry.

Marks

4

Solution

B+C = [[3,3],[0,1]]. A(B+C) = [[1(3)+4(0), 1(3)+4(1)],[3(3)+6(0), 3(3)+6(1)]] = [[3,7],[9,15]]. AB = [[1,2-8],[3,6-12]] = [[1,-6],[3,-6]]; AC = [[2,1+12],[6,3+18]] = [[2,13],[6,21]]. AB+AC = [[3,7],[9,15]]. Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q6; book p249 = PDF p276 (vision read)

8.

Q7. If A = [[4,3],[-5,6]], B = [[2,-1],[3,-2]] and C = [[1,2],[3,4]], show that (AB)C = A(BC).

Knowledge Note

Associativity (AB)C = A(BC): compute both bracketings.

Marks

4

Solution

AB = [[8+9,-4-6],[-10+18,5-12]] = [[17,-10],[8,-7]]. (AB)C = [[17+(-30),34-40],[8-21,16-28]] = [[-13,-6],[-13,-12]]. BC = [[2-3,4-4],[3-6,6-8]] = [[-1,0],[-3,-2]]. A(BC) = [[-4-9,0-6],[5-18,0-12]] = [[-13,-6],[-13,-12]]. Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q7; book p249 = PDF p276 (vision read)

9.

Q8. If A = [[3,-1],[5,-2]] and B = [[2,-1],[5,-3]], compute A^2B (= A(AB)).

Knowledge Note

First compute AB, then multiply by A on the left again.

Marks

4

Solution

AB = [[6-5,-3+3],[10-10,-5+6]] = [[1,0],[0,1]] = I. So A^2B = A(AB) = AI = A = [[3,-1],[5,-2]] (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.1 Q8; book p249 = PDF p276 (vision read)
