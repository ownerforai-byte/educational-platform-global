1.

Q1(a). If A = [[4,3],[-5,6]] and C = [[2,-1],[3,-2]], compute A', C', (AC)' and C'A'.

Knowledge Note

Transpose swaps rows and columns; B'A' multiplies in reverse order.

Marks

4

Solution

A' = [[4,-5],[3,6]], C' = [[2,3],[-1,-2]]. AC = [[8+9,-4-6],[-10+18,5-12]] = [[17,-10],[8,-7]], so (AC)' = [[17,8],[-10,-7]]. C'A' = [[2(4)+3(3)... ]] = [[8+9, -10-6],[... ]] = [[17,8],[-10,-7]] = (AC)' (matches the printed key).

Q1(b). If A = [[1,2,3],[0,1,4],[2,3,0]] and B = [[-1,2,1],[3,0,-1],[2,1,0]], find A', B', (AB)' and B'A'.

Knowledge Note

(AB)' multiplies 3x3 by 3x3: check each of the 9 entries.

4

3.

Q2(a). If A = [[1,2],[-3,6],[0,1]], B = [[0,3],[5,7],[1,-4]] and k = 3, compute A', B' and verify (i) (A')' = A (ii) (A+B)' = A'+B' (iii) (kA)' = kA'.

Knowledge Note

(A')' restores the original; (A+B)' splits entrywise; (kA)' scales every entry.

Marks

4

Solution

A' = [[1,-3,0],[2,6,1]], B' = [[0,5,1],[3,7,-4]]. (i) (A')' = A by double swap. (ii) A+B = [[1,5],[2,13],[1,-3]], (A+B)' = [[1,2,1],[5,13,-3]] = A'+B'. (iii) (3A)' = 3A'. All verified.

4.

Q2(b). If A = (1/3)[[1,2,2],[2,1,-2],[-2,2,-1]], verify that AA' = A'A = I.

Knowledge Note

Orthogonal test: rows are unit vectors and pairwise orthogonal (dot products 0).

Marks

4

Solution

Row dots: r1·r1 = (1+4+4)/9 = 1; r1·r2 = (2+2-4)/9 = 0; r1·r3 = (-2+4-2)/9 = 0; r2·r2 = (4+1+4)/9 = 1; r2·r3 = (-4+2+2)/9 = 0; r3·r3 = (4+4+1)/9 = 1. So AA' = I; symmetric argument gives A'A = I.

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.3 Q2(b); book p280 = PDF p307 (vision read)

5.

Q3. If A = [[2,4,3],[2,3,4],[5,2,6]], find A'. (a) Show that the sum of the given matrix and its transpose is a symmetric matrix. (b) Show that the difference is a skew-symmetric matrix.

Knowledge Note

S = (M+M')/2 is symmetric, K = (M-M')/2 is skew: the decomposition is unique.

Marks

4

Solution

A' = [[2,2,5],[4,3,2],[3,4,6]]. (a) S = A+A' = [[4,6,8],[6,6,6],[8,6,12]], and S' = S: symmetric. (b) K = A-A' = [[0,2,-2],[-2,0,2],[2,-2,0]], and K' = -K with zero diagonal: skew-symmetric.

Source

Sukunda Basic Mathematics Grade XI, Ch.9 Ex 9.3 Q3; book p280 = PDF p307 (vision read)

6.

Q4. Find the adjoints and inverses of the following matrices, if possible: (i) [[2,1],[4,6]] (ii) [[2,4],[1,3]] (iii) [[3,2],[1,1]] (iv) [[1,0,1],[0,1,1],[1,1,0]] (v) [[1,2,4],[0,1,6],[1,3,2]] (vi) [[1,-1,1],[2,1,-3],[1,1,1]].

Knowledge Note

adjoint = transpose of cofactor matrix; inverse = adjoint/det; singular iff det = 0.

Marks

5

Solution

(i) det = 8; adj = [[6,-1],[-4,2]]; inv = [[3/4,-1/8],[-1/2,1/4]]. (ii) det = 2; adj = [[3,-4],[-1,2]]; inv = [[3/2,-2],[-1/2,1]]. (iii) det = 1; adj = inv = [[1,-2],[-1,3]]. (iv) det = -2; adj = [[-1,1,-1],[1,-1,-1],[-1,-1,1]]; inv = (-1/2)adj. (v) det = -8; adj = [[-16,8,8],[6,-2,-6],[-1,-1,1]]; inv = [[2,-1,-1],[-3/4,1/4,3/4],[1/8,1/8,-1/8]]. (vi) det = 10; adj = [[4,2,2],[-5,0,5],[1,-2,3]]; inv = (1/10)adj. All match the printed key, p281.

7.

Q5. If A = [[7,-3],[6,2]], prove that A^{-1} = (1/32)[[2,3],[-6,7]].

Knowledge Note

det = 32: swap the diagonal, negate the off-diagonal, divide by 32.

Marks

3

Solution

det A = 14+18 = 32. Adj A = [[2,3],[-6,7]]. So A^{-1} = (1/32)[[2,3],[-6,7]].

8.

Q6. Prove that [[-3,-2],[5,3]] and [[3,2],[-5,-3]] are inverses of each other.

Knowledge Note

Two matrices are inverses iff their product (both ways for square matrices) is I.

Marks

3

Solution

Product: [[-9+10,-6+6],[15-15,10-9]] = [[1,0],[0,1]] = I. So each is the inverse of the other.

9.

Q7. If A = [[5,3],[4,2]], verify that A(adj A) = (adj A)A = |A|I.

Knowledge Note

A(adj A) = (det A)I holds for every square matrix: verify entry by entry.

Marks

4

Solution

|A| = 10-12 = -2. adj A = [[2,-3],[-4,5]]. A(adj A) = [[10-12,-15+15],[8-8,-12+10]] = [[-2,0],[0,-2]] = -2I. Similarly (adj A)A = -2I.

Source

10.

Q8. If A = [[2,3],[4,5]] and B = [[6,0],[-5,2]], verify that (AB)^{-1} = B^{-1}A^{-1}.

Knowledge Note

Compute AB, invert it, and compare against B^{-1}A^{-1} (order reverses).

Marks

4

Solution

AB = [[12-15,0+6],[24-25,0+10]] = [[-3,6],[-1,10]]; det = -30+6 = -24; (AB)^{-1} = (-1/24)[[10,-6],[1,-3]]. A^{-1} = (-1/2)[[5,-3],[-4,2]], B^{-1} = (1/12)[[2,0],[5,6]]. B^{-1}A^{-1} = (-1/24)[[2,0],[5,6]][[5,-3],[-4,2]] = (-1/24)[[10,-6],[25-24,-15+12]] = (-1/24)[[10,-6],[1,-3]]. Both sides agree.

11.

Q9. If A = [[1,2,-2],[-1,3,0],[0,-2,1]], find A^{-1} and verify that AA^{-1} = I.

Knowledge Note

det = 1 here, so the inverse equals the adjoint: AA^{-1} = I checks 9 entries.

Marks

4

Solution

det A = 1(3-0)-2(-1-0)-2(2-0) = 3+2-4 = 1. Cofactors give adj A = [[3,2,6],[1,1,2],[2,2,5]]. Since det = 1, A^{-1} = adj A (matches the printed key, p281). AA^{-1} = I verified entry by entry.
