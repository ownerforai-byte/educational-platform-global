Questions

1.

Q1(a). Prove that x, y, z are in A.P., G.P. or H.P. according as (x-y)/(y-z) = x/x or x/y or x/z respectively.

Knowledge Note

AP gives ratio 1 (written x/x), GP gives x/y via y^2 = xz, HP gives x/z via y = 2xz/(x+z): one computation, three readings.

Marks

3

Solution

A.P.: (x-y)/(y-z) = x/x = 1 gives x-y = y-z, i.e. 2y = x+z, the A.P. condition. G.P.: (x-y)/(y-z) = x/y gives xy-y^2 = xy-xz, i.e. y^2 = xz, the G.P. condition. H.P.: (x-y)/(y-z) = x/z gives xz-yz = xy-xz, i.e. 2xz = y(x+z), so y = 2xz/(x+z), the H.P. condition. Each step reverses, so the three cases are proved.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q1(a); book p214 = PDF p241 (vision read)

2.

Q1(b). If (x+y)/2, y and (y+z)/2 are in H.P., show that x, y, z are in G.P.

Knowledge Note

Clear the HP condition 2/y = 2/(x+y) + 2/(y+z): everything cancels except xz = y^2.

Marks

3

Solution

The three means are in H.P., so 2/y = 1/((x+y)/2) + 1/((y+z)/2) = 2/(x+y) + 2/(y+z). Dividing by 2: 1/y = (y+z+x+y)/((x+y)(y+z)) = (x+z+2y)/((x+y)(y+z)). Cross-multiplying: (x+y)(y+z) = y(x+z+2y), i.e. xy+xz+y^2+yz = xy+xz+2y^2, so y^2 = xz. Hence x, y, z are in G.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q1(b); book p214 = PDF p241 (vision read)

3.

Q1(c). If G is the geometric mean between a and b, show that 1/(G^2-a^2) + 1/(G^2-b^2) = 1/G^2.

Knowledge Note

Substitute G^2 = ab first: the two fractions combine over ab(b-a) and the (b-a) cancels.

Marks

3

Solution

G^2 = ab. Then 1/(G^2-a^2) + 1/(G^2-b^2) = 1/(ab-a^2) + 1/(ab-b^2) = 1/(a(b-a)) + 1/(b(a-b)) = (b-a)/(ab(b-a)) = 1/(ab) = 1/G^2 (for a not equal to b).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q1(c); book p214 = PDF p241 (vision read)

4.

Q2(a). If H is the harmonic mean between a and b, prove that 1/(H-a) + 1/(H-b) = 1/a + 1/b.

Knowledge Note

Write H = 2ab/(a+b), then 2H-(a+b) = -(a-b)^2/(a+b): the square cancels against the denominator.

Marks

4

Solution

H = 2ab/(a+b). Now 1/(H-a) + 1/(H-b) = (2H-a-b)/((H-a)(H-b)). The numerator: 2H-(a+b) = 4ab/(a+b)-(a+b) = (4ab-(a+b)^2)/(a+b) = -(a-b)^2/(a+b). The denominator: (H-a)(H-b) = H^2-H(a+b)+ab = 4a^2b^2/(a+b)^2-2ab+ab = -ab(a-b)^2/(a+b)^2. Dividing: (-(a-b)^2/(a+b))/(-ab(a-b)^2/(a+b)^2) = (a+b)/ab = 1/a+1/b.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q2(a); book p215 = PDF p242 (vision read)

5.

Q2(b). If A and H are the arithmetic and harmonic means between a and b respectively, prove that (a-A)(b-A)/((a-H)(b-H)) = A/H.

Knowledge Note

a-A = (a-b)/2 but a-H = a(a-b)/(a+b): each ratio keeps one factor (a+b), and their product is A/H.

Marks

4

Solution

A = (a+b)/2, H = 2ab/(a+b). a-A = a-(a+b)/2 = (a-b)/2; a-H = a-2ab/(a+b) = a(a-b)/(a+b). So (a-A)/(a-H) = ((a-b)/2)/(a(a-b)/(a+b)) = (a+b)/(2a). Likewise (b-A)/(b-H) = (a+b)/(2b). Multiplying: (a+b)^2/(4ab). And A/H = ((a+b)/2)/(2ab/(a+b)) = (a+b)^2/(4ab). Both sides agree.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q2(b); book p215 = PDF p242 (vision read)

6.

Q3(a). If x is the A.M. between y and z, and y is the G.M. between z and x, prove that z will be the H.M. between x and y.

Knowledge Note

These conditions force x = y = z (then the HM claim is trivial): derive 2x^2-xy-y^2 = 0, i.e. (x-y)(2x+y) = 0.

Marks

4

Solution

x = (y+z)/2 and y^2 = zx, so z = 2x-y. Then y^2 = x(2x-y) = 2x^2-xy, i.e. 2x^2-xy-y^2 = 0, so (x-y)(2x+y) = 0. For positive quantities x = y, hence z = 2x-y = x. So x = y = z, for which 2/z = 1/x+1/y holds (2/x = 2/x): z is indeed the H.M. between x and y.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q3(a); book p215 = PDF p242 (vision read)

7.

Q3(b). If a, b, c are in A.P., and b, c, a are in H.P., prove that c, a, b are in G.P.

Knowledge Note

AP gives c = 2b-a; HP of b,c,a gives 2ab = c(a+b): substituting forces (a+2b)(a-b) = 0, so a = b = c.

Marks

4

Solution

From the A.P., 2b = a+c, so c = 2b-a. From the H.P., 2/c = 1/b+1/a = (a+b)/ab, so 2ab = c(a+b). Substituting c: 2ab = (2b-a)(a+b) = 2ab+2b^2-a^2-ab, giving 0 = 2b^2-a^2-ab = -(a+2b)(a-b). For positive quantities a = b, so c = 2b-a = b. Thus a = b = c, and equal numbers are trivially in G.P.: c, a, b are in G.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q3(b); book p215 = PDF p242 (vision read)

8.

Q3(c). If a, b, c are in A.P., b, c, d are in G.P. and c, d, e are in H.P., then prove that a, c, e are in G.P.

Knowledge Note

Chain the three means: c^2 = bd with d = 2ce/(c+e) and b = (a+c)/2 collapses to c^2 = ae.

Marks

4

Solution

b = (a+c)/2, c^2 = bd, and 2/d = 1/c+1/e gives d = 2ce/(c+e). Then c^2 = b·2ce/(c+e) = (a+c)ce/(c+e). So c^2(c+e) = ce(a+c), i.e. c^3+c^2e = ace+c^2e, giving c^3 = ace, so c^2 = ae. Hence a, c, e are in G.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q3(c); book p215 = PDF p242 (vision read)

9.

Q4. If a, b, c are in A.P., G.P. or H.P., show that b^2 is >, = or < ac respectively.

Knowledge Note

The AP case is (a-c)^2/4 >= 0; the HP case follows by applying the AP case to the reciprocals.

Marks

3

Solution

A.P.: b = (a+c)/2, so b^2-ac = (a+c)^2/4-ac = (a-c)^2/4 >= 0, i.e. b^2 >= ac (> unless a = c). G.P.: b^2 = ac by definition. H.P.: 1/a, 1/b, 1/c are in A.P., so by the A.P. case (1/b)^2 >= (1/a)(1/c), i.e. 1/b^2 >= 1/ac, so b^2 <= ac (< unless a = c).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q4; book p215 = PDF p242 (vision read)

10.

Q5(a). The A.M. of two numbers is 25 and their G.M. is 20. Find the numbers.

Knowledge Note

Sum-product with AM = 25, GM = 20: t^2-50t+400 = 0 splits as (t-10)(t-40).

Marks

4

Solution

Let the numbers be a, b. Then a+b = 50 and ab = 20^2 = 400. They are the roots of t^2-50t+400 = 0: t = (50±sqrt(2500-1600))/2 = (50±30)/2, so t = 40 or 10. The numbers are 40 and 10 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q5(a); book p215 = PDF p242 (vision read)

11.

Q5(b). The difference between the A.M. and G.M. of two numbers is 2, and the difference between the G.M. and the H.M. is 1.6. Find the numbers.

Knowledge Note

From A-G = 2 and G-H = 1.6 with H = G^2/A: 2G = 1.6(G+2) forces G = 8, A = 10.

Marks

5

Solution

Let G be the G.M.; then A = G+2 and ab = G^2. H = ab/A = G^2/(G+2). G-H = 1.6 gives G-G^2/(G+2) = 1.6, i.e. 2G/(G+2) = 1.6, so 2G = 1.6G+3.2, giving G = 8. Then A = 10, a+b = 20, ab = 64: t^2-20t+64 = 0 gives t = (20±sqrt(400-256))/2 = (20±12)/2, so t = 16 or 4. The numbers are 16 and 4 (matches the printed key).

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q5(b); book p215 = PDF p242 (vision read)

12.

Q6. The sum of three numbers in A.P. is 36. Adding 1, 4 and 43 to them respectively, the resulting numbers are in G.P. Find the numbers.

Knowledge Note

AP sum 36 makes the middle term 12; the GP condition 16^2 = (13-d)(55+d) is a quadratic with roots d = 9, -51.

Marks

5

Solution

Let the numbers be 12-d, 12, 12+d (sum 36 forces middle term 12). After adding: 13-d, 16, 55+d in G.P., so 16^2 = (13-d)(55+d) = 715-42d-d^2. Hence d^2+42d-459 = 0, so d = (-42±sqrt(1764+1836))/2 = (-42±60)/2, giving d = 9 or d = -51. For d = 9: 3, 12, 21. For d = -51: 63, 12, -39. (Matches the printed key, whose '6. a)' line has no 6(b) — filed as a label slip.)

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q6; book p215 = PDF p242 (vision read)

13.

Q7(a). If a^x = b^y = c^z and a, b, c are in G.P., prove that x, y, z are in H.P.

Knowledge Note

Take logs with x = G/r: the lny terms sum to zero and the lnr coefficient is a+c-2b = 0.

Marks

4

Solution

Put a^x = b^y = c^z = k. Then x = lnk/lna, y = lnk/lnb, z = lnk/lnc. Since a, b, c are in G.P., lnb-lna = lnc-lnb. Now 1/x+1/z-2/y = (lna+lnc-2lnb)/lnk = 0, so 2/y = 1/x+1/z: x, y, z are in H.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q7(a); book p215 = PDF p242 (vision read)

14.

Q7(b). If one G.M. G and two A.M.s p and q are inserted between two given positive numbers, prove that G^2 = (2p-q)(2q-p).

Knowledge Note

Two AMs split [a,b] in thirds: 2p-q = a and 2q-p = b recover the endpoints, whose product is G^2.

Marks

4

Solution

Let the numbers be a, b. Then G^2 = ab, p = a+(b-a)/3 = (2a+b)/3, q = a+2(b-a)/3 = (a+2b)/3. Now 2p-q = (4a+2b-a-2b)/3 = a and 2q-p = (2a+4b-2a-b)/3 = b. So (2p-q)(2q-p) = ab = G^2.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q7(b); book p215 = PDF p242 (vision read)

15.

Q8(i). If a, b, c are in H.P., prove that bc/(b+c), ca/(c+a), ab/(a+b) are in H.P.

Knowledge Note

Reciprocate: (b+c)/bc = 1/b+1/c; with 1/a,1/b,1/c as u,u+d,u+2d the three sums are 2u+3d,2u+2d,2u+d.

Marks

4

Solution

(i) The reciprocals are (b+c)/bc = 1/b+1/c, 1/c+1/a, 1/a+1/b. Since 1/a, 1/b, 1/c are in A.P. (say u, u+d, u+2d), these sums are 2u+3d, 2u+2d, 2u+d — in A.P. — so the originals are in H.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q8(i); book p215 = PDF p242 (vision read)

16.

Q8(ii). If a, b, c are in H.P., prove that 2a-b, b, 2c-b are in G.P.

Knowledge Note

Expand (2a-b)(2c-b) and use 2ac = b(a+c) from the HP condition: everything cancels to b^2.

Marks

4

Solution

(2a-b)(2c-b) = 4ac-2b(a+c)+b^2. From the H.P. condition 1/a+1/c = 2/b we get 2ac = b(a+c). Substituting: 4ac-4ac+b^2 = b^2. So (2a-b)(2c-b) = b^2: the three are in G.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q8(ii); book p215 = PDF p242 (vision read)

17.

Q8(iii). If a, b, c are in H.P., prove that a(b+c), b(c+a), c(a+b) are in A.P.

Knowledge Note

Successive differences are c(b-a) and a(c-b): equal iff ab+bc = 2ac, the HP condition.

Marks

4

Solution

Second minus first: b(c+a)-a(b+c) = c(b-a). Third minus second: c(a+b)-b(c+a) = a(c-b). Equality needs c(b-a) = a(c-b), i.e. ab+bc = 2ac, i.e. 1/c+1/a = 2/b, exactly the H.P. condition. So the three are in A.P.

Source

Sukunda Basic Mathematics Grade XI, Ch.8 Ex 8.1 Q8(iii); book p215 = PDF p242 (vision read)
