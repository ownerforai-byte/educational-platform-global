1.

Q1(a). Identify whether (1,3) and (3,1) are equal.

Knowledge Note

Ordered pairs are equal iff first components match AND second components match — order matters, unlike sets.

Marks

1

Solution

First components: 1 ≠ 3, so the pairs differ already. ✅ NOT equal. (Never swap-check sets here — (1,3) ≠ (3,1) is the canonical example.)

Q1(b). Identify whether (a,b) and (a,b) are equal.

Knowledge Note

Identical pairs are trivially equal — the reflexive case examiners include to test the definition.

Q1(d). Identify whether (x,x) and (y,y) are equal.

5.

Q2(a). Find x and y if (x+y, 3) = (1, x−y).

Knowledge Note

Equate components to get a 2×2 linear system; add the equations to kill y.

Marks

2

Solution

Step 1 — Equate: x+y = 1 …(i); 3 = x−y, i.e. x−y = 3 …(ii). Step 2 — Add (i)+(ii): 2x = 4 → x = 2. Step 3 — y = 1−x = −1. ✅ x = 2, y = −1. (Check: (2+(−1), 3) = (1, 3) and (1, 2−(−1)) = (1, 3) ✔)

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.1 Q2(a)

6.

Q2(b). Find x and y if (x+2y, 3) = (−1, 2x−y).

Knowledge Note

Same method with messier coefficients — substitute y from the simpler equation.

Marks

2

Solution

Step 1 — x+2y = −1 …(i); 3 = 2x−y, i.e. y = 2x−3 …(ii). Step 2 — Sub (ii) in (i): x+2(2x−3) = −1 → 5x−6 = −1 → x = 1. Step 3 — y = 2(1)−3 = −1. ✅ x = 1, y = −1. (Check: (1−2, 3) = (−1, 3); (−1, 2+1) = (−1, 3) ✔)

Q2(c). Find x and y if (x−2, y+1) = (1, 0).

Knowledge Note

Decoupled equations — read each variable straight off.

Marks

2

Solution

x−2 = 1 → x = 3; y+1 = 0 → y = −1. ✅ x = 3, y = −1.

Q3(a). If A = {1,2,3} and B = {a,b}, find A × A.

Knowledge Note

A×A lists every first-set element against every first-set element: n(A)² pairs.

Marks

2

Solution

A × A = {(1,1),(1,2),(1,3),(2,1),(2,2),(2,3),(3,1),(3,2),(3,3)} — 9 pairs. ✅

Q4(a). Let A = {a,b}, B = {b,c}, C = {c,d}. Find A × (B ∪ C).

Knowledge Note

Union first, then cross: B∪C = {b,c,d}, and A supplies the first components.

Marks

2

Solution

B∪C = {b,c,d}. A×(B∪C) = {(a,b),(a,c),(a,d),(b,b),(b,c),(b,d)} — 6 pairs. ✅ (Web-index typo fixed: it prints (b,a), but a ∉ B∪C, so (b,a) is impossible; the correct pair is (b,b).)

16.

Q5(a). Let A = {a,b}, B = {c,d}, C = {d,e}. Verify A × (B ∪ C) = (A × B) ∪ (A × C).

Knowledge Note

LHS–RHS verification: compute both sides fully, then compare as sets.

Marks

3

Solution

LHS: B∪C = {c,d,e}; A×that = {(a,c),(a,d),(a,e),(b,c),(b,d),(b,e)}. RHS: (A×B)∪(A×C) = {(a,c),(a,d),(b,c),(b,d)} ∪ {(a,d),(a,e),(b,d),(b,e)} = {(a,c),(a,d),(a,e),(b,c),(b,d),(b,e)}. LHS = RHS. ✅ Verified.

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.1 Q5(a)

17.

Q5(b). With A, B, C as above, verify A × (B ∩ C) = (A × B) ∩ (A × C).

Knowledge Note

Same drill for ∩: B∩C = {d} collapses the LHS to 2 pairs.

Marks

3

Solution

LHS: B∩C = {d}; A×{d} = {(a,d),(b,d)}. RHS: {(a,c),(a,d),(b,c),(b,d)} ∩ {(a,d),(a,e),(b,d),(b,e)} = {(a,d),(b,d)}. LHS = RHS. ✅ Verified.

18.

Q6(a). Find the Cartesian product A × B where A = {x : x = 1,2,3} and B = {y : y = 3−x}.

Knowledge Note

Build B by evaluating the rule at each x in A — B's order follows x = 1, 2, 3.

Marks

2

Solution

A = {1,2,3}. y = 3−x gives: x=1→2, x=2→1, x=3→0, so B = {2,1,0}. A×B = {(1,2),(1,1),(1,0),(2,2),(2,1),(2,0),(3,2),(3,1),(3,0)} — 9 pairs. ✅

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.1 Q6(a)

19.

Q6(b). Find A × B where A = {x : x = 0,1,2} and B = {y : y = x²}.

Knowledge Note

Squares grow fast: x = 2 gives y = 4, so B is not {0,1,2}.

Marks

2

Solution

A = {0,1,2}. y = x² gives 0, 1, 4, so B = {0,1,4}. A×B = {(0,0),(0,1),(0,4),(1,0),(1,1),(1,4),(2,0),(2,1),(2,4)} — 9 pairs. ✅
