Questions

1.

AQ9(a). Show that f:[-2,0]->R defined by f(x) = x^2 is one-one but not onto.

Knowledge Note

On [-2,0] every number is non-positive, so x1^2 = x2^2 forces x1 = x2 - the sign ambiguity of squares disappears.

Marks

3

Solution

One-one: let x1, x2 in [-2,0] with x1^2 = x2^2. Then |x1| = |x2|; since both are <= 0, x1 = -|x1| = -|x2| = x2. So f is one-one. Not onto: f(x) = x^2 >= 0 always (range is [0,4]), so e.g. -1 in R has no pre-image. Hence one-one but not onto.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q9(a); book p114 = PDF p141 OCR conf 0.94

2.

AQ9(b). Let f:[0,inf)->R be defined by f(x) = |x|. The print asks to 'show it is one-one and onto' - assess honestly.

Knowledge Note

Read the codomain carefully: |x| on [0,inf) never goes negative, so 'onto R' as printed is FALSE - the intended codomain is [0,inf).

Marks

3

Solution

One-one: on [0,inf), |x| = x, so f(x1) = f(x2) gives x1 = x2 - one-one holds. Onto R FAILS: range is [0,inf), so e.g. -1 in R has no pre-image. VERDICT: one-one yes, onto R no (print overstates). With the corrected codomain [0,inf), f(x) = x is bijective. FLAGGED as a print tension.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q9(b); book p114 = PDF p141 OCR; onto-R disproved, corrected codomain given

3.

AQ10. Let R0 be the set of non-zero real numbers and f:R0->R0 be defined by f(x) = 1/x. Show that f is one-one and onto.

Knowledge Note

f(f(x)) = x makes a function its own inverse - bijectivity follows for free.

Marks

2

Solution

One-one: 1/x1 = 1/x2 gives x1 = x2 (multiply by x1.x2 != 0). Onto: for each y in R0, x = 1/y is in R0 and f(x) = y. So f is one-one and onto (indeed f(f(x)) = x).

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q10; book p114 = PDF p141 OCR conf 0.94

4.

AQ11. Define an inverse of a function. What condition makes a function have its inverse? Let f:R->R be defined by f(x) = 2x - 4. Find f^-1 and show that f(f^-1(x)) = f^-1(f(x)) = x.

Knowledge Note

Swap x and y, solve for y: the inverse undoes each operation in reverse order.

Marks

3

Solution

A function has an inverse iff it is one-one and onto (bijective); f^-1 reverses every arrow. Here y = 2x - 4; swapping roles x = 2y - 4 gives y = (x+4)/2, so f^-1(x) = (x+4)/2 (the book prints this hint). Check: f(f^-1(x)) = 2.(x+4)/2 - 4 = x; f^-1(f(x)) = ((2x-4)+4)/2 = x.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q11; book p114 = PDF p141 OCR (hint printed in book)

5.

AQ12 (T.U. 2053). Let f:R->R be defined by f(x) = x^3. Show that f is one-one and onto. Hence find f^-1.

Knowledge Note

Odd powers preserve order: cubes keep distinct numbers distinct and hit every real.

Marks

3

Solution

One-one: x1^3 = x2^3 gives (taking real cube roots) x1 = x2. Onto: for each y in R, x = cubert(y) is real with f(x) = y. Hence bijective; f^-1(x) = cubert(x).

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q12 (T.U. 2053); book p114 = PDF p141 OCR

6.

AQ13. Let f:R->R be defined by f(x) = ax + b (a, b real). Find f^-1 and show that f(f^-1(x)) = f^-1(f(x)) = x.

Knowledge Note

The inverse exists only if a != 0 (a = 0 makes f constant) - the book's 'a, b real' needs this hypothesis added.

Marks

3

Solution

Requires a != 0 (else f is constant, not bijective - hypothesis added). y = ax + b gives x = ay + b, so y = (x-b)/a: f^-1(x) = (x-b)/a. Check: f(f^-1(x)) = a.(x-b)/a + b = x; f^-1(f(x)) = ((ax+b)-b)/a = x.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q13; book p114 = PDF p141 OCR; a != 0 hypothesis added

7.

AQ14 (HSEB 2054). Let f:R->R be defined by f(x) = 2x and g:R->R by g(x) = x + 1. Find (fog)(x) and (gof)(x). Are they one-one?

Knowledge Note

Order matters in composition: doubling after adding 1 differs from adding 1 after doubling.

Marks

3

Solution

(fog)(x) = f(x+1) = 2x + 2. (gof)(x) = g(2x) = 2x + 1. Both are non-zero-slope linears, hence one-one: yes and yes. Matches the printed Answers key (p115): '2x+2, 2x+1; yes'.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q14 (HSEB 2054); book p114 = PDF p141 OCR; matches printed Answers key p115 (PDF p142)

8.

AQ15. With f(x) = 2x^2 - 3 and g(x) = 3x + 2 determine (i) (fog)(x), (ii) (gof)(x), (iii) (fof)(x), (iv) (gog)(x). (f is cut off in the scan; 2x^2-3 is forced by the printed answers.)

Knowledge Note

Four compositions, one pair: expand each and match against the key - the key itself pins down f.

Marks

3

Solution

(i) (fog)(x) = 2(3x+2)^2 - 3 = 2(9x^2+12x+4) - 3 = 18x^2+24x+5. (ii) (gof)(x) = 3(2x^2-3) + 2 = 6x^2-7. (iii) (fof)(x) = 2(2x^2-3)^2 - 3 = 2(4x^4-12x^2+9) - 3 = 8x^4-24x^2+15. (iv) (gog)(x) = 3(3x+2) + 2 = 9x+8. All four match the printed Answers key (p115) exactly.

9.

AQ16(a). Prove that ~(p ^ (~p)) is a tautology.

Knowledge Note

p AND (NOT p) is always false - negating it is always true. That is the whole proof.

Marks

2

Solution

Truth table: p=T: ~p=F, p^(~p)=F, ~(F)=T. p=F: ~p=T, p^(~p)=F, ~(F)=T. All-true column: tautology. Matches the printed key table (p115-116).

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q16(a); book pp114-115 = PDF pp141-142; matches printed key table

11.

AQ16(c). Prove that (p v q) v (~p) is a tautology.

Knowledge Note

If p is false, ~p is true and already makes the big OR true; if p is true, p itself does.

Marks

2

Solution

Truth table over p,q: whenever p=T, (p v q)=T so the whole is T; whenever p=F, ~p=T so the whole is T. All four rows true: tautology. Matches the printed key table.

(~q) AND q can never both hold - the whole conjunction dies whatever p is.

13.

AQ17. If f:R-{1}->R-{2} is defined by f(x) = 2x/(x-1), prove that f is one-one and onto.

Knowledge Note

Solve y = 2x/(x-1) for x: the forbidden denominator x = 1 maps exactly to the forbidden value y = 2.

Marks

3

Solution

One-one: 2x1/(x1-1) = 2x2/(x2-1) gives x1(x2-1) = x2(x1-1), i.e. x1 = x2. Onto: for y != 2, y = 2x/(x-1) gives x(y-2) = y... solve: yx - y = 2x, x(y-2) = y, x = y/(y-2) (defined since y != 2); and x != 1 since y/(y-2) = 1 would give y = y-2, impossible. So every y in R-{2} has pre-image y/(y-2) in R-{1}: onto.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q17; book p115 = PDF p142 OCR (two consistent reads)

14.

AQ18. Is the following argument valid? All natural numbers are integers. x is not an integer. Therefore, x is not a natural number.

Knowledge Note

Modus tollens: being an integer is necessary for being a natural number, so failing it rules out the conclusion.

Marks

2

Solution

Valid (modus tollens). Form: P -> Q (natural -> integer); ~Q (x not integer); therefore ~P (x not natural). Denying the consequent necessarily denies the antecedent.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q18; book p115 = PDF p142 OCR

15.

AQ19. Is the following argument valid? Some students of class XI are smart. Prakash is a student of class XI. Therefore, Prakash is smart.

Knowledge Note

'Some' does not cover all: Prakash may sit in the non-smart part of the class.

Marks

2

Solution

Invalid. 'Some students are smart' only guarantees a smart subset; Prakash may belong to the complementary (non-smart) subset. The middle term is undistributed - no conclusion about Prakash follows.

16.

AQ20. Prove that f:R->R defined by f(x) = 2x^3 - 1 is one-one and onto. Also find f^-1.

Knowledge Note

Strictly increasing (derivative 6x^2 >= 0, zero only at a point) means injective; odd-degree means surjective.

Marks

3

Solution

One-one: 2x1^3-1 = 2x2^3-1 gives x1^3 = x2^3, so x1 = x2 (real cube roots unique). Onto: for each y, x = cubert((y+1)/2) is real with f(x) = y. Inverse: y = 2x^3-1 gives x = ((y+1)/2)^(1/3), so f^-1(x) = ((x+1)/2)^(1/3). Matches the printed Answers key (p116): '((x+1)/2)^1/3'.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q20; book p115 = PDF p142 OCR; matches printed Answers key p116 (PDF p143, root glyph confirmed)

17.

AQ21 [HSEB 2065]. If f,g:R->R are defined by f(x) = x^3 + 2 and g(x) = 4x - 1, find (fog)(x) and (gof)(x) and show that the composite functions are not commutative.

Knowledge Note

Compute both orders and compare: (4x-1)^3+2 versus 4x^3+7 are nowhere equal.

Marks

3

Solution

(fog)(x) = f(4x-1) = (4x-1)^3 + 2 = 64x^3-48x^2+12x+1. (gof)(x) = g(x^3+2) = 4(x^3+2)-1 = 4x^3+7. They differ (e.g. at x=0: 1 vs 7), so fog != gof: not commutative. Matches the printed Answers key (p116): 'No'.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q21 [HSEB 2065]; book p115 = PDF pp141-142 (ask confirmed by 350-dpi crop); matches key

18.

AQ22 [HSEB 2061]. From f(x) = 2x^3 - 3 and g(x) = 3x + 2 (x in R), determine (fog)(x) and (gof)(x). Are they one-one?

Knowledge Note

Cubes preserve order, so both composites inherit one-one-ness from f and g.

Marks

3

Solution

(fog)(x) = 2(3x+2)^3 - 3 = 54x^3+108x^2+72x+13. (gof)(x) = 3(2x^3-3) + 2 = 6x^3-7. One-one: (fog)'(x) = 18(3x+2)^2 >= 0 with equality only at x = -2/3, so strictly increasing: yes. (gof)'(x) = 18x^2 >= 0 with equality only at 0, so strictly increasing: yes.

Source

Sukunda Basic Mathematics Grade XI, Ch.2 Additional Q22 [HSEB 2061]; book p115 = PDF p141 (statement confirmed by 350-dpi line image)

AQ23. If f(x) = x^3 - 1 and g(x) = 2x - 3, compute (f^-1 o g)(2) and (f o g^-1)(1). (Notation read from a 350-dpi line image; OCR alone merges the -1s.)

Knowledge Note

Read the tiny -1s: the first ask inverts f, the second inverts g. Each answer checks by direct substitution.

Marks

3

Solution

f^-1(x) = cubert(x+1); g^-1(x) = (x+3)/2. (f^-1 o g)(2) = f^-1(g(2)) = f^-1(1) = cubert(2) (since (cubert2)^3-1 = 1: verified). (f o g^-1)(1) = f(g^-1(1)) = f(2) = 7 (verified). Exact answers: cubert(2) and 7. NOTE: the printed key (p116) shows '23. 2, 7' - the '2' is almost certainly a dropped cube-root sign (cubert(2)), since the key's Q20 line proves the compositor prints ^{1/3}; pending physical-book confirmation.

20.

AQ24. If f,g,h:R->R are defined by f(x) = x + 1, g(x) = e^x and h(x) = log x, find the value of (h o (g o f))(1).

Knowledge Note

Evaluate inside-out: +1, then exponential, then log - the natural log exactly undoes e^.

Marks

2

Solution

f(1) = 2; g(2) = e^2; h(e^2) = log(e^2) = 2 (natural log). So (h o (g o f))(1) = 2. Matches the printed Answers key (p116): '24. 2'.
