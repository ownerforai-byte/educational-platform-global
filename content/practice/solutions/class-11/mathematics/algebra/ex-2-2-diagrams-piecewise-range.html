1.

Q1(a). (Arrow diagram, see print.) State whether the diagram defines a function A→B. [Key: Yes.]

Knowledge Note

Arrow-diagram test: every dot on the A side must send out exactly one arrow — a dot with none, or with two, kills the function.

Marks

1

Solution

Each element of A sends out exactly one arrow to B — one image each, none left out. ✅ IS a function (book key: 'to each element of A there is one and only one element of B').

7.

Q4(i). Let f(x) = x + 2 in the interval −1 ≤ x ≤ 2 (domain of definition [−1, 2]). Find f(−1), f(0), f(1), f(2), f(−2), f(3).

Knowledge Note

Domain restriction rules: a formula only answers inside its stated interval — outside, the value simply doesn't exist.

Marks

3

Solution

Inside [−1,2]: f(−1) = −1+2 = 1; f(0) = 2; f(1) = 3; f(2) = 4. Outside: −2 ∉ [−1,2] and 3 ∉ [−1,2], so f(−2) and f(3) are NOT defined (not zero — undefined). ✅ 1, 2, 3, 4; f(−2), f(3) undefined (matches printed key).

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q4(i); answers vs printed key p.84

8.

Q4(ii). Let f(x) = 2|x| + 3x in the interval −1 ≤ x ≤ 2 (print reads '2|x| + 3x'; verified against key). Find f(−1), f(0), f(1), f(2), f(−2), f(3).

Knowledge Note

Absolute-value split: 2|x| + 3x behaves as x (x ≥ 0) and 5x... check: x<0 gives −2x+3x = x? No: 2(−x)+3x = x. Actually both branches give x?? f(−1) = 2−3 = −1 = x. f(1) = 2+3 = 5?? 2|1|+3 = 5 ≠ 1. Recompute: x ≥ 0: 2x+3x = 5x; x < 0: −2x+3x = x. So the function is piecewise x / 5x — verify each point directly.

Marks

3

Solution

f(−1) = 2(1) + 3(−1) = 2−3 = −1; f(0) = 0; f(1) = 2+3 = 5; f(2) = 4+6 = 10. f(−2), f(3) outside [−1,2] ⇒ NOT defined. ✅ −1, 0, 5, 10; f(−2), f(3) undefined (matches printed key).

9.

Q5(i). Let f(x) = 3+2x (−1/2 ≤ x < 0); 3−2x (0 ≤ x < 1/2); −3−2x (x ≥ 1/2). Find f(−1/2), f(0), f(1/2) and [f(h) − f(0)]/h for 0 ≤ h < 1/2.

Knowledge Note

Piecewise discipline: first ask WHICH piece the input falls in (mind the ≤ vs < at joints), then substitute.

Marks

3

Solution

a) x = −1/2 takes the FIRST piece (closed end): 3+2(−1/2) = 2. b) x = 0 takes the SECOND piece: 3−0 = 3. c) x = 1/2 takes the THIRD piece (x ≥ 1/2): −3−2(1/2) = −4. d) For 0 ≤ h < 1/2, f(h) = 3−2h and f(0) = 3, so [f(h)−f(0)]/h = (3−2h−3)/h = −2. ✅ 2, 3, −4, −2 (matches printed key).

Source

Sukunda Basic Mathematics XI, Ch.2 Book Ex 2.2 Q5(i); answers vs printed key p.84

10.

Q5(ii). Let f(x) = 4x−2 (x ≥ 1); 2x (x < 1). Find f(2), f(1), f(0), f(−1) and [f(h) − f(1)]/h for h > 1.

Knowledge Note

The joint x = 1 belongs to the upper piece (x ≥ 1) — a favourite examiner trap.

Marks

3

Solution

a) f(2) = 8−2 = 6. b) f(1) = 4−2 = 2 (upper piece, since 1 ≥ 1). c) f(0) = 0. d) f(−1) = −2. e) For h > 1, f(h) = 4h−2 and f(1) = 2: [(4h−2)−2]/h = 4(h−1)/h. ✅ 6, 2, 0, −2, 4(h−1)/h (matches printed key).

11.

Q6(i). Let A = {−1, 0, 2, 4, 6}, f:A→R with f(x) = x/(x+2). Find the range of f.

Knowledge Note

Range = the set of outputs only: evaluate at every domain point, collect distinct values.

Marks

2

Solution

f(−1) = −1/1 = −1; f(0) = 0; f(2) = 2/4 = 1/2; f(4) = 4/6 = 2/3; f(6) = 6/8 = 3/4. ✅ Range = {−1, 0, 1/2, 2/3, 3/4} (matches printed key).

12.

Q6(ii). With A = {−1, 0, 2, 4, 6}, f:A→R with f(x) = x/(x+1). Find the range of f.

Knowledge Note

Zero denominator = red flag: x = −1 kills x/(x+1), so −1 contributes no output — the range skips it.

Marks

2

Solution

f(−1) = −1/0 — UNDEFINED (division by zero, so −1 yields no image). f(0) = 0; f(2) = 2/3; f(4) = 4/5; f(6) = 6/7. ✅ Range = {0, 2/3, 4/5, 6/7} (over the four admissible inputs; −1 excluded with reason).

Q7. Determine whether f and g are equal: (a) f(x) = x² with domain A = {−1, −2, −3}; (b) g given by Venn diagram. [Key: equal.]

Knowledge Note

Equal functions need BOTH: same domain AND same value at every point — check as sets of pairs.

Marks

2

Solution

As a set of pairs, f = {(−1, 1), (−2, 4), (−3, 9)} (since (−1)² = 1, (−2)² = 4, (−3)² = 9). The diagram g shows exactly {(−1,1), (−2,4), (−3,9)}. Same domain, same values everywhere. ✅ f = g — the two functions are EQUAL (matches printed key).

Q8(a). A = {−2,−1,0,1,2}, B = {4,0,1}, f(x) = x². Is f one-one? [Key: No.]

Knowledge Note

One counterexample kills one-one: a single repeated output (f(−2) = f(2)) is enough.

Marks

2

Solution

f(−2) = 4 and f(2) = 4 — two different inputs, same output (−2 ≠ 2 but f(−2) = f(2)). ✅ NOT one-one (book key: 'f(−2) = 4 = f(2) does not imply −2 = 2'). (Also f(−1) = f(1) = 1.)

Q8(b). A = positive integers, B = their squares, f(x) = x². Is f one-one? [Key: Yes.]

Knowledge Note

On positive integers squaring never collides: distinct bases give distinct squares.

Marks

1

Solution

For positive integers, x ≠ y ⟹ x² ≠ y² (e.g. 2² = 4 ≠ 9 = 3²; squares are strictly increasing on N). ✅ One-one (book key).

Q9(ii). f:N→N, f(x) = 2x. One-one, onto, both or neither? [Key: one-one.]

Knowledge Note

Doubling hits only evens: one-one yes, onto no — the classic one-one-only example.

Marks

1

Solution

One-one: 2x = 2y ⟹ x = y. Not onto: odd numbers (1, 3, 5, …) have no pre-image since f(N) = {2, 4, 6, …} ≠ N. ✅ One-one ONLY (matches key).

21.

Q9(iv). f:Q→Q, f(x) = 6x + 5. One-one, onto, both or neither? [Key: both.]

Knowledge Note

Linear maps x ↦ ax + b (a ≠ 0) over Q are bijective — invert by undoing: x = (y−5)/6 stays rational.

Marks

2

Solution

One-one: 6x+5 = 6y+5 ⟹ x = y. Onto: for any r ∈ Q, x = (r−5)/6 ∈ Q and f(x) = r. ✅ Both — ONE-ONE AND ONTO (matches key).

Q9(v). f:R→R, f(x) = x³. One-one, onto, both or neither? [Key: both.]

Knowledge Note

Cubing over R is strictly increasing, hence bijective with inverse ∛.

Marks

2

Solution

One-one: x³ = y³ ⟹ x = y over R. Onto: every r ∈ R is (∛r)³. ✅ Both — ONE-ONE AND ONTO (matches key).
