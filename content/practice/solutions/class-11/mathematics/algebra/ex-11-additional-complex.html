1.

Q1(i). If z = (2 + i)/(3 - i), find the real and imaginary parts of (1 + z)/(1 - z).

Knowledge Note

(1+z)/(1-z) with z = (2+i)/(3-i) = (1+i)/2: gives 1+2i.

Marks

4

Solution

z = (2+i)(3+i)/10 = (6+2i+3i-1)/10 = (5+5i)/10 = (1+i)/2. (1+z)/(1-z) = ((3+i)/2)/((1-i)/2) = (3+i)/(1-i) = (3+i)(1+i)/2 = (3+3i+i-1)/2 = (2+4i)/2 = 1+2i. Boxed Re = 1, Im = 2 (matches the printed key, book p348).

Q1(ii). If z = (2 + i)/(3 - i), find z + 1/z.

Knowledge Note

1/(a+bi) = (a-bi)/(a²+b²): z+1/z telescopes to (3-i)/2.

Marks

4

Solution

z = (1+i)/2 (above). 1/z = 2/(1+i) = 1-i. z+1/z = (1+i)/2+(1-i) = (3-i)/2. Boxed 3/2-i/2 (matches the printed key).

Q2. If z1 = 3 - 2i and z2 = 4 + 3i, find (i) 1/z1, (ii) 1/z2, (iii) z1/z2 and z2/z1.

Knowledge Note

1/(3-2i) = (3+2i)/13; 1/(4+3i) = (4-3i)/25.

Marks

3

Solution

(i) (3+2i)/13. (ii) (4-3i)/25. (iii) z1/z2 = (3-2i)(4-3i)/25 = (12-9i-8i-6)/25 = (6-17i)/25; z2/z1 = (4+3i)(3+2i)/13 = (12+8i+9i-6)/13 = (6+17i)/13. (All match the printed key.)

6.

Q4. If a + ib = 1/(1 + i) + 1/(1 - i), prove that a^2 + b^2 = 1.

Knowledge Note

|a+ib|² = a²+b²: conjugate pairs kill the cross terms.

Marks

4

Solution

1/(1+i)+1/(1-i) = ((1-i)+(1+i))/2 = 1. So a+ib = 1, a = 1, b = 0, a²+b² = 1. ∎ (proof-type; no key answer needed).

7.

Q5. If √(x + iy) = a + ib, prove that √(x - iy) = a - ib.

Knowledge Note

Take conjugates: √(x-iy) = a-ib follows from uniqueness of the square root pair.

Marks

4

Solution

Squaring: x+iy = (a+ib)² = (a²-b²)+2abi. Conjugating: x-iy = (a²-b²)-2abi = (a-ib)². Taking square roots (same branch): √(x-iy) = a-ib. ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.11 Additional Q5; book p347 = PDF p374 (vision read)

8.

Q6. If z = a + ib and w = c + id, prove that (zw̄)-bar = z̄·w.

Knowledge Note

Conjugate of a product is the product of conjugates — apply twice.

Marks

4

Solution

zw̄ = (a+ib)(c-id) = (ac+bd)+i(bc-ad). Conjugating: (ac+bd)-i(bc-ad). z̄·w = (a-ib)(c+id) = (ac+bd)+i(ad-bc) = (ac+bd)-i(bc-ad). Equal ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.11 Additional Q6; book p347 = PDF p374 (vision read)

9.

Q7. If z and w are complex numbers, prove that ||z| - |w|| ≤ |z + w| ≤ |z| + |w|.

Knowledge Note

|z|² = zz̄ ≥ 0: the cross term 2Re(zw̄) is bounded by ±2|z||w|.

Marks

5

Solution

|z+w|² = |z|²+|w|²+2Re(zw̄) (Ex 11.2 Q7). Since -|zw̄| ≤ Re(zw̄) ≤ |zw̄| = |z||w|: |z|²+|w|²-2|z||w| ≤ |z+w|² ≤ |z|²+|w|²+2|z||w|, i.e. (|z|-|w|)² ≤ |z+w|² ≤ (|z|+|w|)². Square roots give the result. ∎

Q10. If ω is one of the complex cube roots of unity, prove that (i) ω^3 = 1 and (ii) 1 + ω + ω^2 = 0.

Knowledge Note

Write z = x+iy, expand (x+iy)²+2(x+iy)+2 = 0, split real/imaginary.

Marks

5

Solution

ω = (-1+i√3)/2. (i) ω² = (1-2i√3-3)/4 = (-1-i√3)/2; ω³ = ω²·ω = (1+3)/4 = 1 ✓. (ii) 1+ω+ω² = 1+(-1+i√3)/2+(-1-i√3)/2 = 0 ✓. ∎ (proof-type; no key answer needed).

15.

Q11. Prove that each complex cube root of unity is the reciprocal of the other.

Knowledge Note

Discriminant (2i)²-4·2·(-1-4i) = 28+32i = (6+... ) — cleaner: complete the square or factor with the known root.

Marks

5

Solution

Roots: 1, ω = (-1+i√3)/2, ω² = (-1-i√3)/2. 1/1 = 1; 1/ω = ω² and 1/ω² = ω (since ω·ω² = ω³ = 1). So each root's reciprocal is another cube root of unity. ∎ (proof-type; no key answer needed).

Q12. Express a complex number in polar form. State De Moivre's theorem. Using De Moivre find the cube roots of unity. If ω = (-1 + √3 i)/2, prove that ω^2 = (-1 - √3 i)/2.

Knowledge Note

Equate: x-1 = -3, y+2 = 1 from (-3+i).

Marks

3

Solution

Polar: z = r(cosθ+i sinθ), r = √(x²+y²), tanθ = y/x. De Moivre: (cosθ+i sinθ)ⁿ = cos nθ+i sin nθ. Unity = cos(k·360°)+i sin(k·360°); cube roots at 0°, 120°, 240°: 1, (-1+i√3)/2, (-1-i√3)/2. Squaring ω: ((-1+i√3)/2)² = (1-2i√3-3)/4 = (-1-i√3)/2. ∎

17.

Q13. What is a complex number? Express it in polar form. Find the square root of (2 - 36i)/(2 + 3i). (T.U. 2053)

Knowledge Note

Simplify the fraction first: it equals -8-6i; roots ±(1-3i).

Marks

5

Solution

A complex number is an ordered pair (x,y) written x+iy with i² = -1; polar form x+iy = r(cosθ+i sinθ), r = √(x²+y²), tanθ = y/x. Fraction: (2-36i)(2-3i)/13 = (4-6i-72i+108i²)/13 = (-104-78i)/13 = -8-6i. Roots: x²-y² = -8, 2xy = -6, norm 10, so x = ±1, y = ∓3. Check (1-3i)² = 1-6i-9 = -8-6i ✓. Boxed ±(1-3i) = ±(3i-1) (matches the printed key).

Q14. Prove that (i) ((-1 + √-3)/2)^6 + ((-1 - √-3)/2)^9 = 2 and (ii) ((-1 + √-3)/2)^5 + ((-1 - √-3)/2)^5 = -1.

Knowledge Note

x+iy = (1+2i)(2-i)/5 = (4+3i)/5: read off x, y.

Marks

4

Solution

Let ω = (-1+i√3)/2, so ω̄ = ω², ω³ = 1, ω+ω² = -1. (i) ω⁶+ω̄⁹ = (ω³)²+(ω³)³ = 1+1 = 2 ✓. (ii) ω⁵+ω̄⁵ = ω²+ω = -1 ✓. ∎ (proof-type; no key answer needed).

Q15. Show that (a + ib)/(c + id) is real if ad = bc. [The text prints the full working on book p348.]

Knowledge Note

Set z = x+iy; the equation forces (x²+y²)² = ... take moduli: |x+iy| = |...|.

Marks

5

Solution

(a+ib)/(c+id) = (a+ib)(c-id)/(c²+d²) = ((ac+bd)+i(bc-ad))/(c²+d²). Real iff the imaginary part vanishes iff bc-ad = 0 iff ad = bc. ∎ (as worked in the text, book p348 = PDF p375).

Q16. If z and w are two complex numbers, prove that (a) |z - w| ≤ |z| + |w| and (b) |z + w| ≥ |z| - |w|.

Knowledge Note

Square both sides of |z-w| ≤ |z|+|w| and use Re(zw̄) ≤ |zw̄|.

Marks

5

Solution

(a) |z-w|² = |z|²+|w|²-2Re(zw̄) ≤ |z|²+|w|²+2|z||w| = (|z|+|w|)². (b) |z+w|² = |z|²+|w|²+2Re(zw̄) ≥ |z|²+|w|²-2|z||w| = (|z|-|w|)². Square roots give both. ∎ (The text proves (a) in full on book p349; (b) is the same argument with w → -w.)

21.

Q17. Prove that ((-1 + √-3)/2)^n + ((-1 - √-3)/2)^n = 2 if n is a multiple of 3, and -1 if n is any other integer.

Knowledge Note

ω = e^{2πi/3}: 1+ω+ω² = 0 and ω³ = 1 give the two values 2 and -1.

Marks

4

Solution

ωⁿ+ω̄ⁿ with ω³ = 1. If n = 3k: 1+1 = 2. If n = 3k+1: ω+ω̄ = ω+ω² = -1. If n = 3k+2: ω²+ω̄² = ω²+ω = -1. ∎ (proof-type; no key answer needed).

Sukunda Basic Mathematics Grade XI, Ch.11 Additional Q17 (worked in text); book p349 = PDF p376 (vision read)
