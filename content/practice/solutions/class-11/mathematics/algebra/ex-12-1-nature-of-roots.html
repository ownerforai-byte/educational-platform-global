Q1(a). Determine the nature of the roots of x^2 - 6x + 5 = 0.

Knowledge Note

D = b²-4ac: x²-6x+5 gives 36-20 = 16 > 0, perfect square → rational unequal.

Marks

3

Solution

D = (-6)²-4(1)(5) = 36-20 = 16 > 0 and a perfect square. Roots real, rational, unequal: x = (6±4)/2 = 5, 1. Boxed real, rational, unequal (matches the printed key, book p357).

Q3. If x^2 + 2(k + 2)x + 9k = 0 has equal roots, find k.

Knowledge Note

D = 4(k+2)²-36k = 4(k²-5k+4) = 4(k-1)(k-4); zero at k = 1, 4.

Marks

4

Solution

D = 4(k+2)²-36k = 4(k²+4k+4-9k) = 4(k²-5k+4) = 4(k-1)(k-4) = 0. Boxed k = 1 or 4 (matches the printed key).

10.

Q5. If the roots of (a^2 + b^2)x^2 - 2(ac + bd)x + (c^2 + d^2) = 0 are equal, show that a/b = c/d.

Knowledge Note

D = 4(ac+bd)²-4(a²+b²)(c²+d²) = -4(ad-bc)² ≤ 0; equal ⟺ ad = bc.

Marks

5

Solution

D/4 = (ac+bd)²-(a²+b²)(c²+d²) = a²c²+2acbd+b²d²-a²c²-a²d²-b²c²-b²d² = -(a²d²-2acbd+b²c²) = -(ad-bc)². Equal roots ⟺ D = 0 ⟺ ad = bc ⟺ a/b = c/d (b,d ≠ 0). ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.1 Q5; book p357 = PDF p384 (vision read)

Q6. Show the roots of (a^2 - bc)x^2 + 2(b^2 - ca)x + (c^2 - ab) = 0 are equal if b = 0 or a^3 + b^3 + c^3 - 3abc = 0.

Knowledge Note

D/4 = (b²-ca)²-(a²-bc)(c²-ab) = b⁴-... = A(a³+b³+c³-3abc) with b = 0 as the other factor.

Marks

5

Solution

D/4 = (b²-ca)²-(a²-bc)(c²-ab) = b⁴-2b²ca+c²a²-(a²c²-a³b-bc³+ab²c) = b⁴-3b²ca+a³b+bc³ = b(b³-3bca+a³+c³) = b(a³+b³+c³-3abc). D = 0 ⟺ b = 0 or a³+b³+c³-3abc = 0. ∎ (proof-type; no key answer needed).

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.1 Q6; book p357 = PDF p384 (vision read)

12.

Q7. If a, b, c are rational and a + b + c = 0, show the roots of (b + c - a)x^2 + (c + a - b)x + (a + b - c) = 0 are rational.

Knowledge Note

With s = a+b+c = 0: coefficient ratio (2s-3a):(2s-3b):(2s-3c) = -3a:-3b:-3c, so D = 9(b²-4... ) — actually substitute c = -a-b and check D is a non-negative square of a rational.

Marks

5

Solution

b+c-a = -2a, c+a-b = -2b, a+b-c = -2c (using s = 0). Equation: -2ax²-2bx-2c = 0, i.e. ax²+bx+c = 0 with c = -a-b. D = b²-4a(-a-b) = b²+4a²+4ab = (2a+b)², a perfect square of a rational. Roots (-b±(2a+b))/2a are rational. ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.1 Q7; book p357 = PDF p384 (vision read)

13.

Q8. Prove the roots of (x - a)(x - b) = k^2 are real for all k.

Knowledge Note

(x-a)(x-b) = k² expands to x²-(a+b)x+ab-k² = 0 with D = (a-b)²+4k² ≥ 0 always.

Marks

4

Solution

x²-(a+b)x+ab-k² = 0. D = (a+b)²-4(ab-k²) = (a-b)²+4k² ≥ 0 for all real a,b,k. Hence real roots. ∎ (proof-type; no key answer needed).

14.

Q9. Show the roots of x^2 - 4abx + (a^2 + 2b^2)^2 = 0 are imaginary.

Knowledge Note

D = 16a²b²-4(a²+2b²)² = -4(a²-2b²)²-16b⁴ < 0 unless degenerate.

Solution

D = (4ab)²-4(a²+2b²)² = 16a²b²-4a⁴-16a²b²-16b⁴ = -4a⁴-16b⁴ = -4(a⁴+4b⁴) < 0 (for (a,b) ≠ (0,0)). Hence imaginary roots. ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.1 Q9; book p357 = PDF p384 (vision read)

15.

Q10. If the roots of qx^2 + 2px + 2q = 0 are real and unequal, prove the roots of (p + q)x^2 + 2qx + (p - q) = 0 are imaginary.

Knowledge Note

First D₁ = 4(p²-2q²) > 0 gives p² > 2q²; second D₂ = 4q²-4(p²-q²) = 8q²-4p² < 0.

Marks

5

Solution

D₁ = 4p²-8q² = 4(p²-2q²) > 0, so p² > 2q². D₂ = 4q²-4(p+q)(p-q) = 4q²-4(p²-q²) = 8q²-4p² = 4(2q²-p²) < 0 (from p² > 2q²). Hence the second equation has imaginary roots. ∎ (proof-type; no key answer needed).

Source

Sukunda Basic Mathematics Grade XI, Ch.12 Ex 12.1 Q10; book p357 = PDF p384 (vision read)
