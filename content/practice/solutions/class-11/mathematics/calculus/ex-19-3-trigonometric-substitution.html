1.

Q1(i). Find the indefinite integral: integral of dx / sqrt(1 - x^2).

Knowledge Note

Standard inverse-sine form: the derivative of sin^-1 x is exactly 1/sqrt(1-x^2).

Marks

1

Solution

Recognise d/dx (sin^-1 x) = 1/sqrt(1-x^2), so integral dx/sqrt(1-x^2) = sin^-1 x + c. Derivation by substitution: put x = sin theta, dx = cos theta d theta, sqrt(1-x^2) = cos theta, giving integral d theta = theta + c = sin^-1 x + c. Boxed (printed key p583).

2.

Q1(ii). Find the indefinite integral: integral of dx / [x^2 sqrt(9 - x^2)].

Knowledge Note

For sqrt(a^2 - x^2) put x = a sin theta; here a = 3. The surviving cosec^2 theta integrates to -cot theta.

Marks

3

Solution

Let x = 3 sin theta, dx = 3 cos theta d theta, sqrt(9-x^2) = 3 cos theta. Then x^2 sqrt(9-x^2) = 9 sin^2 theta 3 cos theta = 27 sin^2 theta cos theta, so the integral is integral 3 cos theta d theta/(27 sin^2 theta cos theta) = (1/9) integral cosec^2 theta d theta = -(1/9) cot theta + c = -(1/9) sqrt(9-x^2)/x + c = -sqrt(9-x^2)/(9x) + c. Check: d/dx[-sqrt(9-x^2)/(9x)] = -1/9 [(-x/sqrt(9-x^2))x - sqrt(9-x^2)]/x^2 = -1/9[(-x^2 - (9-x^2))/sqrt(9-x^2)]/x^2 = 1/(x^2 sqrt(9-x^2)). Boxed (printed key p583).

3.

Q1(iii). Find the indefinite integral: integral of dx / (a^2 - x^2)^(3/2).

Knowledge Note

x = a sin theta collapses the 3/2 power to a cos^3 theta, leaving integral sec^2 theta d theta = tan theta.

Marks

3

Solution

Let x = a sin theta, dx = a cos theta d theta, (a^2 - x^2)^(3/2) = (a^2 cos^2 theta)^(3/2) = a^3 cos^3 theta. Then the integral = integral a cos theta d theta/(a^3 cos^3 theta) = (1/a^2) integral sec^2 theta d theta = (1/a^2) tan theta + c = (1/a^2) * x/sqrt(a^2-x^2) + c = x/(a^2 sqrt(a^2-x^2)) + c. Check: d/dx[x/(a^2 sqrt(a^2-x^2))] = (1/a^2)[sqrt(a^2-x^2) + x^2/sqrt(a^2-x^2)]/(a^2-x^2) = (1/a^2)(a^2)/(a^2-x^2)^(3/2) = 1/(a^2-x^2)^(3/2). Boxed (printed key p583).

4.

Q1(iv). Find the indefinite integral: integral of x^2 dx / sqrt(a^2 - x^2).

Knowledge Note

Same substitution, then the half-angle identity sin^2 theta = (1 - cos 2 theta)/2 turns it into two elementary integrals.

Marks

4

Solution

Let x = a sin theta, dx = a cos theta d theta, sqrt(a^2-x^2) = a cos theta. Then integral x^2 dx/sqrt(a^2-x^2) = integral a^2 sin^2 theta * a cos theta d theta/(a cos theta) = a^2 integral sin^2 theta d theta = a^2 integral (1 - cos 2 theta)/2 d theta = (a^2/2)[theta - (sin 2 theta)/2] + c = (a^2/2)(theta - sin theta cos theta) + c = (a^2/2) sin^-1(x/a) - (1/2) x sqrt(a^2-x^2) + c (since a^2 sin theta cos theta = x sqrt(a^2-x^2)). Boxed (printed key p583).

5.

Q2(i). Find the indefinite integral: integral of sqrt(x^2 - 9) dx / x.

Knowledge Note

x = 3 sec theta turns sqrt(x^2-9) into 3 tan theta; the leftover sec theta tan^2 theta splits into sec theta sec^2 theta - sec theta.

Marks

4

Solution

Let x = 3 sec theta, dx = 3 sec theta tan theta d theta, sqrt(x^2-9) = 3 tan theta. Then integral sqrt(x^2-9) dx/x = integral 3 tan theta 3 sec theta tan theta d theta/(3 sec theta) = 3 integral tan^2 theta d theta = 3 integral (sec^2 theta - 1) d theta = 3(tan theta - theta) + c = sqrt(x^2-9) - 3 sec^-1(x/3) + c. Check: d/dx[sqrt(x^2-9)] = x/sqrt(x^2-9) and d/dx[-3 sec^-1(x/3)] = -3 (1/3)/((x/3)sqrt(x^2/9-1)) = -3/x ... = -(33)/(x sqrt(x^2-9)) = -9/(x sqrt(x^2-9)); the sum is (x^2-9)/(x sqrt(x^2-9)) = sqrt(x^2-9)/x. Boxed (printed key p583).

6.

Q2(ii). Find the indefinite integral: integral of dx / [x^2 sqrt(x^2 - a^2)].

Knowledge Note

x = a sec theta: the sec/tan factors cancel completely and leave a plain cosine.

Marks

3

Solution

Let x = a sec theta, dx = a sec theta tan theta d theta, sqrt(x^2-a^2) = a tan theta. Then x^2 sqrt(x^2-a^2) = a^3 sec^2 theta tan theta, so the integral = integral a sec theta tan theta d theta/(a^3 sec^2 theta tan theta) = (1/a^2) integral cos theta d theta = (1/a^2) sin theta + c = (1/a^2) sqrt(x^2-a^2)/x + c = sqrt(x^2-a^2)/(a^2 x) + c. Boxed (printed key p583).

7.

Q2(iii). Find the indefinite integral: integral of dx / (x^2 - a^2)^(3/2).

Knowledge Note

After x = a sec theta the integrand becomes sec theta/tan^2 theta = cosec theta cot theta, whose integral is -cosec theta.

Marks

3

Solution

Let x = a sec theta, dx = a sec theta tan theta d theta, (x^2-a^2)^(3/2) = a^3 tan^3 theta. Then the integral = integral a sec theta tan theta d theta/(a^3 tan^3 theta) = (1/a^2) integral sec theta/tan^2 theta d theta = (1/a^2) integral cosec theta cot theta d theta = -(1/a^2) cosec theta + c = -(1/a^2) * x/sqrt(x^2-a^2) + c = -x/(a^2 sqrt(x^2-a^2)) + c. Boxed (printed key p583).

8.

Q2(iv). Find the indefinite integral: integral of dx / sqrt(x^2 - 4).

Knowledge Note

Standard logarithmic form integral dx/sqrt(x^2 - a^2) = log|x + sqrt(x^2-a^2)|, here a = 2.

Marks

2

Solution

Use the standard result (obtained by x = 2 sec theta, or by rationalising with u = x + sqrt(x^2-4)): integral dx/sqrt(x^2-4) = log|x + sqrt(x^2-4)| + c. Check: d/dx log|x + sqrt(x^2-4)| = [1 + x/sqrt(x^2-4)]/[x + sqrt(x^2-4)] = [sqrt(x^2-4) + x]/[sqrt(x^2-4)(x + sqrt(x^2-4))] = 1/sqrt(x^2-4). Boxed (printed key p583).

9.

Q2(v). Find the indefinite integral: integral of x^3 dx / (x^2 - a^2)^(3/2).

Knowledge Note

The substitution x = a sec theta turns the whole thing into 4a integral cosec^2(2 theta) d theta; then cot 2 theta is converted back to x.

Marks

5

Solution

Let x = a sec theta, dx = a sec theta tan theta d theta, x^3 = a^3 sec^3 theta, (x^2-a^2)^(3/2) = a^3 tan^3 theta. Then the integral = integral a^3 sec^3 theta * a sec theta tan theta d theta/(a^3 tan^3 theta) = a integral sec^4 theta/tan^2 theta d theta = a integral d theta/(sin^2 theta cos^2 theta) = 4a integral cosec^2(2 theta) d theta = -2a cot 2 theta + c. Now cot theta = a/sqrt(x^2-a^2), so cot 2 theta = (cot^2 theta - 1)/(2 cot theta) = (2a^2 - x^2)/(2a sqrt(x^2-a^2)). Hence -2a cot 2 theta = (x^2 - 2a^2)/sqrt(x^2-a^2) + c. Boxed (printed key p583).

10.

Q3(i). Find the indefinite integral: integral of dx / (x^2 + a^2).

Knowledge Note

Standard inverse-tangent form; the a in the denominator comes out of the substitution x = a tan theta.

Marks

2

Solution

Let x = a tan theta, dx = a sec^2 theta d theta, x^2 + a^2 = a^2 sec^2 theta. Then the integral = integral a sec^2 theta d theta/(a^2 sec^2 theta) = (1/a) integral d theta = (1/a) theta + c = (1/a) tan^-1(x/a) + c. Boxed (printed key p583).

11.

Q3(ii). Find the indefinite integral: integral of dx / [x^2 sqrt(x^2 + 1)].

Knowledge Note

x = tan theta gives integral sec theta/tan^2 theta d theta = -cosec theta, and cosec theta = sqrt(x^2+1)/x.

Marks

3

Solution

Let x = tan theta, dx = sec^2 theta d theta, sqrt(x^2+1) = sec theta. Then x^2 sqrt(x^2+1) = tan^2 theta sec theta, so the integral = integral sec^2 theta d theta/(tan^2 theta sec theta) = integral sec theta/tan^2 theta d theta = integral (1/cos theta)(cos^2 theta/sin^2 theta) d theta = integral cos theta/sin^2 theta d theta = -1/sin theta + c = -cosec theta + c = -sqrt(x^2+1)/x + c. Boxed (printed key p583).

12.

Q3(iii). Find the indefinite integral: integral of x^2 dx / (1 + x^2)^2.

Knowledge Note

x = tan theta makes the integrand sin^2 theta; the half-angle identity then gives two terms.

Marks

4

Solution

Let x = tan theta, dx = sec^2 theta d theta, (1+x^2)^2 = sec^4 theta. Then integral x^2 dx/(1+x^2)^2 = integral tan^2 theta sec^2 theta d theta/sec^4 theta = integral sin^2 theta d theta = (1/2) integral (1 - cos 2 theta) d theta = (1/2)(theta - (sin 2 theta)/2) + c = (1/2)(theta - sin theta cos theta) + c = (1/2) tan^-1 x - (1/2) * x/(1+x^2) + c. Boxed (printed key p583 prints (1/2)tan^-1 x - (1/2) x/(x^2+1) + c).

Q3(iv). Find the indefinite integral: integral of dx / sqrt(a^2 + x^2).

Knowledge Note

Standard logarithmic form integral dx/sqrt(a^2+x^2) = log|x + sqrt(a^2+x^2)|.

Marks

2

Solution

Substitute x = a tan theta: dx = a sec^2 theta d theta, sqrt(a^2+x^2) = a sec theta, so the integral = integral sec theta d theta = log|sec theta + tan theta| + c = log|sqrt(a^2+x^2)/a + x/a| + c = log|x + sqrt(a^2+x^2)| + c (the -log a is absorbed into c). Boxed (printed key p583).

14.

Q3(v). Find the indefinite integral: integral of dx / [x sqrt(x^2 + 1)].

Knowledge Note

x = tan theta turns it into integral cosec theta d theta = log|tan(theta/2)|, then tan(theta/2) = (sec theta - 1)/tan theta is converted back.

Marks

3

Solution

Let x = tan theta, dx = sec^2 theta d theta, sqrt(x^2+1) = sec theta. Then the integral = integral sec^2 theta d theta/(tan theta sec theta) = integral sec theta/tan theta d theta = integral cosec theta d theta = log|tan(theta/2)| + c. Using tan(theta/2) = (sec theta - 1)/tan theta = (sqrt(x^2+1) - 1)/x, the answer is log|(sqrt(x^2+1) - 1)/x| + c. Boxed (printed key p583). Equivalently -log|(sqrt(x^2+1)+1)/x| + c = -log|cosec theta + cot theta| + c, the same family.

Q3(vi). Find the indefinite integral: integral of (tan^-1 x)/(1 + x^2) dx.

Knowledge Note

The denominator is the derivative of tan^-1 x, so the whole integrand is u du with u = tan^-1 x.

Solution

Let u = tan^-1 x, du = dx/(1+x^2). Then integral u du = u^2/2 + c = (1/2)(tan^-1 x)^2 + c. Check: d/dx = tan^-1 x * 1/(1+x^2). Boxed (printed key p583).

16.

Q4(i). Find the indefinite integral: integral of sqrt((a + x)/(a - x)) dx.

Knowledge Note

Rationalise the numerator first: sqrt((a+x)/(a-x)) = (a+x)/sqrt(a^2-x^2), which splits into two standard forms.

Marks

3

Solution

Multiply numerator and denominator of the radicand's fraction by (a+x): sqrt((a+x)/(a-x)) = sqrt((a+x)^2/(a^2-x^2)) = (a+x)/sqrt(a^2-x^2) for a+x > 0. So the integral = integral a dx/sqrt(a^2-x^2) + integral x dx/sqrt(a^2-x^2) = a sin^-1(x/a) - sqrt(a^2-x^2) + c. Check: d/dx = a/sqrt(a^2-x^2) + x/sqrt(a^2-x^2) = (a+x)/sqrt(a^2-x^2) = sqrt((a+x)/(a-x)). Boxed (printed key p583).

Sukunda Basic Mathematics Grade XI, Ch.19 Exercise 19.3 Q4(i); book p582-583 = PDF p609-610; key book p583 = PDF p610

17.

Q4(ii). Find the indefinite integral: integral of sqrt(x/(a - x)) dx.

Knowledge Note

Substitute x = a sin^2 phi so that the radical becomes tan of a half-angle, leaving 2a integral sin^2 phi d phi.

Marks

4

Solution

Let x = a sin^2 phi, so dx = 2a sin phi cos phi d phi and sqrt(x/(a-x)) = sin phi/cos phi. Then the integral = integral (sin phi/cos phi)(2a sin phi cos phi) d phi = 2a integral sin^2 phi d phi = a integral (1 - cos 2 phi) d phi = a(phi - sin phi cos phi) + c. Since phi = sin^-1 sqrt(x/a) and sin phi cos phi = sqrt(x/a) * sqrt((a-x)/a) = sqrt(x(a-x))/a, the answer is a sin^-1 sqrt(x/a) - sqrt(x(a-x)) + c. Boxed (printed key p583).
