1.

Q1(i). Test the continuity of f(x) = x² at x = 4 by computing the left limit, the right limit and the value of the function.

Knowledge Note

Continuity test at x = a: LHL = RHL = f(a). A polynomial passes automatically.

Marks

2

Solution

lim (x→4⁻) x² = 16; lim (x→4⁺) x² = 16; f(4) = 16. All three are equal, so f is continuous at x = 4. Boxed continuous (matches the printed key, book p483).

Q1(ii). Test the continuity of f(x) = 2 − 3x² at x = 0.

Knowledge Note

A polynomial is continuous at every real point: all three quantities coincide.

Q1(iii). Test the continuity of f(x) = 3x² − 2x + 4 at x = 1.

Knowledge Note

Same polynomial rule for a quadratic at the specified point.

Marks

2

Solution

f(1) = 3 − 2 + 4 = 5. Both one-sided limits use the same expression and give 5. LHL = RHL = f(1) = 5, so f is continuous at x = 1. Boxed continuous (matches the key).

4.

Q1(iv). Test the continuity of f(x) = 1/(2x) at x = 0.

Knowledge Note

A finite limit cannot exist where the function blows up: 1/(2x) has no value at x = 0.

Marks

2

Solution

f(0) is not defined (division by zero), and lim (x→0) 1/(2x) fails to be finite (→ +∞ from the right, → −∞ from the left). Since f(0) does not exist, f is discontinuous at x = 0. Boxed discontinuous (matches the key).

A rational function is continuous at every point of its domain — only poles break continuity.

7.

Q1(vii). Test the continuity of f(x) = 1/(1 − x) at x = 1. [T.U. 2048]

Knowledge Note

At a pole the one-sided limits are infinite and the value is undefined: an infinite discontinuity.

Marks

2

Solution

f(1) = 1/0 is undefined; lim (x→1⁻) 1/(1 − x) → +∞ and lim (x→1⁺) 1/(1 − x) → −∞. No finite limit and no value, so f is discontinuous at x = 1. Boxed discontinuous (matches the key).

9.

Q1(ix). Test the continuity of f(x) = (x² − 9)/(x − 3) at x = 3.

Knowledge Note

0/0 with a cancelling factor: the limit exists but the value does not — a removable discontinuity.

Marks

3

Solution

(x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3) = x + 3 for x ≠ 3, so lim (x→3⁻) f = 6 = lim (x→3⁺) f. But f(3) = 0/0 is not defined. Since the limit exists while the value does not, f is discontinuous at x = 3 — a removable discontinuity, removed by defining f(3) = 6. Boxed discontinuous (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.4 Q1(ix); book p482 = PDF p509; key book p483

10.

Q1(x). Test the continuity of f(x) = (x² − 16)/(x − 4) at x = 4.

Knowledge Note

Identical removable pattern: the hole at x = 4 can be filled with the limit 8.

Marks

3

Solution

For x ≠ 4, (x² − 16)/(x − 4) = x + 4, so both one-sided limits equal 8. But f(4) is undefined (0/0), so f is discontinuous at x = 4 (removable; redefine f(4) = 8 to make it continuous). Boxed discontinuous (matches the key).

11.

Q1(xi). Test the continuity of f(x) = |x − 2|/(x − 2) at x = 2.

Knowledge Note

|x − a|/(x − a) is the sign function shifted: a jump discontinuity with limits +1 and −1.

Marks

3

Solution

For x > 2: |x − 2|/(x − 2) = 1, so the right limit is 1. For x < 2: |x − 2|/(x − 2) = −1, so the left limit is −1. Also f(2) is undefined. Since the one-sided limits differ, f is discontinuous at x = 2 (jump discontinuity). Boxed discontinuous (matches the key).

12.

Q2(i). Discuss the continuity of f(x) = 2 − x² for x ≤ 2 and f(x) = x − 4 for x > 2 at x = 2. [T.U. 2053 H]

Knowledge Note

For a piecewise function, continuity at the join needs LHL = RHL = f(a).

Marks

3

Solution

f(2) = 2 − 4 = −2. Left limit (x ≤ 2 rule): 2 − 4 = −2. Right limit (x > 2 rule): 2 − 4 = −2. Since LHL = RHL = f(2) = −2, f is continuous at x = 2. Boxed continuous (matches the key).

15.

Q2(iv). Discuss the continuity of f(x) = 2x + 1 for x < 1, f(x) = 2 for x = 1, f(x) = 3x for x > 1 at x = 1. (HSEB 2052, 2057, 2058) [T.U. 2051 H, 2056 S]

Knowledge Note

When the printed value differs from the common limit, the discontinuity is removable: redefine f(a) as the limit.

Marks

4

Solution

LHL: 2(1) + 1 = 3 from the x < 1 rule; RHL: 3(1) = 3. The limit exists and equals 3, but f(1) = 2 ≠ 3. Hence f is discontinuous at x = 1 (removable discontinuity); it becomes continuous if f(1) is redefined as 3. Boxed discontinuous (matches the key).

16.

Q3(i). f(x) = x² + 2 for x < 5, 20 for x = 5, 3x + 12 for x > 5. Show that f has a removable discontinuity at x = 5.

Knowledge Note

Removable discontinuity: the limit exists (27) but the printed value (20) sits off the curve.

Marks

4

Solution

LHL: 5² + 2 = 27. RHL: 3(5) + 12 = 15 + 12 = 27. The limit exists and equals 27, while f(5) = 20 ≠ 27. Because the two-sided limit exists but differs from the value, the discontinuity is removable (put f(5) = 27 to repair it). ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.4 Q3(i); book p483 = PDF p510

17.

Q3(ii). f(x) = 2x − 3 for x < 2, 2 for x = 2, 3x − 5 for x > 2. Is f continuous at x = 2? If not, how can it be made continuous there?

Knowledge Note

Same test: common limit 1 vs printed value 2 → removable, and the repair value is the limit.

Marks

4

Solution

LHL: 2(2) − 3 = 1. RHL: 3(2) − 5 = 1. Limit = 1, but f(2) = 2. Since limit ≠ value, f is not continuous at x = 2; it is a removable discontinuity. Define f(x) = 2x − 3 for x < 2, f(2) = 1, f(x) = 3x − 5 for x > 2 to make it continuous. Boxed No; redefine f(2) = 1 (matches the key).

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.4 Q3(ii); book p483 = PDF p510; key book p483

18.

Q4(i). f(x) = kx + 3 for x ≥ 2 and f(x) = 3x − 1 for x < 2. Find k so that f is continuous at x = 2.

Knowledge Note

Find k by equating the two branches at the join (and with the value).

Marks

3

Solution

Left limit (x < 2 rule): 3(2) − 1 = 5. Right limit and value: 2k + 3. Continuity requires 2k + 3 = 5, so 2k = 2 and k = 1. Boxed k = 1 (matches the key).

19.

Q4(ii). f(x) = (2x² − 18)/(x − 3) for x ≠ 3 and f(x) = k for x = 3. Find k so that f is continuous at x = 3.

Knowledge Note

The constant must equal the removable limit: factor 2x² − 18 = 2(x − 3)(x + 3).

Marks

3

Solution

For x ≠ 3: (2x² − 18)/(x − 3) = 2(x² − 9)/(x − 3) = 2(x + 3). Hence the limit at x = 3 is 2(3 + 3) = 12. Continuity needs f(3) = limit, so k = 12. Boxed k = 12 (matches the key).
