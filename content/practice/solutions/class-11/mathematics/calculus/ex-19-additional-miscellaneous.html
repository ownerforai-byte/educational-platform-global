1.

AQ1. What is an antiderivative? Is it true that there are a number of antiderivatives of a function which differ from one another only by a constant? Show this relation by taking an example.

Knowledge Note

Antiderivative = any function whose derivative returns the given function; the +c family is the whole answer set of an indefinite integral.

Marks

4

Solution

An antiderivative (primitive) of f on an interval is a function F with F'(x) = f(x) for every x in the interval. Yes, the statement is true: if F is one antiderivative then F + c is another for every constant c, and conversely any two antiderivatives of the same f on an interval differ by a constant - because (F - G)' = f - f = 0, and a function with zero derivative on an interval is constant (mean value theorem). Example: for f(x) = 3x^2, the functions x^3, x^3 + 5, x^3 - 7 and in general x^3 + c all differentiate to 3x^2, and any two of them differ only by a constant. That is exactly why the indefinite integral is written integral 3x^2 dx = x^3 + c. Boxed (printed book p605, theory).

2.

AQ2. What does an indefinite integral mean? How does it differ from a definite integral? What does integral from a to b of f(x) dx represent?

Knowledge Note

Indefinite integral = a family of functions (the antiderivatives); definite integral = one number, the signed area, and the two are linked by the fundamental theorem.

Marks

4

Solution

The indefinite integral integral f(x) dx denotes the whole family of antiderivatives of f, i.e. F(x) + c where F' = f; its value is a function (plus an arbitrary constant). The definite integral integral from a to b of f(x) dx is a single real number computed as F(b) - F(a) for any antiderivative F; the arbitrary constant cancels, so the answer does not depend on which antiderivative is chosen. Geometrically, integral from a to b of f(x) dx represents the signed area between the graph of y = f(x), the x-axis, and the vertical lines x = a and x = b: area above the axis counts positive, area below counts negative, and the two cancel where the curve changes sign. The link between the two notions is the fundamental theorem of calculus: d/dx integral from a to x of f(t) dt = f(x). Boxed (printed book p605, theory).

AQ3(iv). Evaluate: integral of (cos 2x - cos 2alpha)/(cos x - cos alpha) dx.

Knowledge Note

Marks

4

Solution

Hence the integral = 2(sin x + x cos alpha) + c. Boxed (printed key p607).

AQ6(ii). Evaluate: integral of (sin x - x)/(1 - cos x) dx.

Knowledge Note

Differentiate the answer to see the structure: log(1 - cos x) supplies sin x/(1 - cos x) and x cot(x/2) supplies the -x/(1 - cos x) part.

Marks

5

Solution

Write the integrand as sin x/(1 - cos x) - x/(1 - cos x). The first part integrates to log(1 - cos x) because d(1 - cos x) = sin x dx. For the second, 1 - cos x = 2 sin^2(x/2), so x/(1 - cos x) = (x/2) cosec^2(x/2); by parts with u = x, dv = (1/2)cosec^2(x/2)dx, v = -cot(x/2): integral = -x cot(x/2) + integral cot(x/2) dx = -x cot(x/2) + 2 log|sin(x/2)|. Subtracting gives log(1 - cos x) + x cot(x/2) - 2 log sin(x/2) + c. Boxed (printed key p608).

AQ7(v). Evaluate: integral from 0 to pi/2 of sin theta cos theta sqrt(a^2 sin^2 theta + b^2 cos^2 theta) d theta.

Knowledge Note

u = a^2 sin^2 + b^2 cos^2 has derivative 2(a^2 - b^2) sin cos, and the limits map to b^2 and a^2; the result factors as (a^2 + ab + b^2)/(3(a+b)).

Marks

5

Solution

Let u = a^2 sin^2 theta + b^2 cos^2 theta; du = 2(a^2 - b^2) sin theta cos theta d theta, with u = b^2 at theta = 0 and u = a^2 at theta = pi/2. Boxed (printed key p608).
