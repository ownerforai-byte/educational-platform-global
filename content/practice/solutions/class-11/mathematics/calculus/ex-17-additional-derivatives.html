Q1. Define differential coefficient of a function at a given point. Find, from first principles, the derivative of x + sqrt(x) with respect to x. (T.U. 2051)

Knowledge Note

f'(a) = lim(h->0)[f(a+h)-f(a)]/h. For x + sqrt(x) rationalise the surd: the quotient is 1 + 1/[sqrt(x+h)+sqrt(x)] -> 1 + 1/(2 sqrt x).

Marks

5

Solution

Definition. The differential coefficient (derivative) of f at the point x = a is f'(a) = lim(h->0) [f(a+h) - f(a)]/h, when this limit exists; it is the instantaneous rate of change of f at a and, geometrically, the slope of the tangent to y = f(x) at (a, f(a)). Step 1 (difference quotient). With f(x) = x + sqrt(x): [f(x+h) - f(x)]/h = {h + [sqrt(x+h) - sqrt(x)]}/h = 1 + [sqrt(x+h) - sqrt(x)]/h. Step 2 (rationalise the surd). sqrt(x+h) - sqrt(x) = [(x+h) - x]/[sqrt(x+h) + sqrt(x)] = h/[sqrt(x+h) + sqrt(x)], so the quotient = 1 + 1/[sqrt(x+h) + sqrt(x)]. Step 3 (h -> 0). sqrt(x+h) -> sqrt(x), giving 1 + 1/(2 sqrt(x)). Boxed d/dx [x + sqrt(x)] = 1 + 1/(2 sqrt(x)), x > 0 (printed key p533: 1 + 1/(2 sqrt(x))).

Source

2.

Q2. Define the differential coefficient of a function at a given point. What are its physical meanings? Find from definition the differential coefficient of sin x with respect to x. (T.U. 2052)

Knowledge Note

sin(x+h) - sin x = 2 cos(x + h/2) sin(h/2); sin u/u -> 1 gives cos x. Physical readings: velocity, acceleration, general instantaneous rate.

Marks

5

Solution

Definition. f'(a) = lim(h->0) [f(a+h) - f(a)]/h is the differential coefficient of f at x = a, the limit of the average rate of change over a shrinking interval [a, a+h]. Physical meanings. (i) If s = f(t) is the distance moved in time t, then f'(t) is the instantaneous velocity. (ii) If v = f(t) is velocity, then f'(t) is the instantaneous acceleration. (iii) In general f'(a) is the instantaneous rate of change of f with respect to x at x = a (rate of cooling, rate of growth, marginal cost, ...). Derivative of sin x. [sin(x+h) - sin x]/h = [2 cos(x + h/2) sin(h/2)]/h (sum-to-product) = cos(x + h/2) * [sin(h/2)/(h/2)]. As h -> 0, sin(h/2)/(h/2) -> 1 and cos(x + h/2) -> cos x, so the limit is cos x. Boxed d/dx (sin x) = cos x (printed key p533: cos x).

Q3. Define the differential coefficient of a function f(x) at a point and interpret it geometrically. Find from first principles the derivative of sqrt(2x + 3) with respect to x. (T.U. 2053)

Knowledge Note

d/dx sqrt(u) = u'/(2 sqrt u) with u = 2x+3 gives 2/(2 sqrt(2x+3)) = 1/sqrt(2x+3). Geometric meaning: slope of the tangent.

Marks

4

Solution

Definition and geometry. f'(a) = lim(h->0) [f(a+h) - f(a)]/h. Geometrically the quotient is the slope of the chord joining P(a, f(a)) to Q(a+h, f(a+h)); as h -> 0 the chord turns into the tangent at P, so f'(a) is the slope of the tangent to y = f(x) at x = a, i.e. f'(a) = tan(psi) where psi is the angle the tangent makes with the positive x-axis. Step 1. f(x+h) - f(x) = sqrt(2x + 2h + 3) - sqrt(2x + 3) = [(2x + 2h + 3) - (2x + 3)]/[sqrt(2x + 2h + 3) + sqrt(2x + 3)] = 2h/[sqrt(2x + 2h + 3) + sqrt(2x + 3)]. Step 2. Divide by h: quotient = 2/[sqrt(2x + 2h + 3) + sqrt(2x + 3)]. Step 3. h -> 0: limit = 2/[2 sqrt(2x + 3)] = 1/sqrt(2x + 3). Boxed d/dx sqrt(2x + 3) = 1/sqrt(2x + 3), x > -3/2 (printed key p533: 1/sqrt(2x + 3)).

Q4(ii). Find from first principles the derivative of sqrt(ax + b) and define dy/dx as a slope. (T.U. 2052 H)

Knowledge Note

General surd rule by first principles: d/dx sqrt(ax+b) = a/(2 sqrt(ax+b)); dy/dx is the tangent gradient tan(theta).

Marks

5

Solution

Step 1. f(x+h) - f(x) = sqrt(ax + ah + b) - sqrt(ax + b) = [(ax + ah + b) - (ax + b)]/[sqrt(ax + ah + b) + sqrt(ax + b)] = ah/[sqrt(ax + ah + b) + sqrt(ax + b)]. Step 2. Divide by h: quotient = a/[sqrt(ax + ah + b) + sqrt(ax + b)]. Step 3. h -> 0: derivative = a/[2 sqrt(ax + b)]. Boxed d/dx sqrt(ax + b) = a/(2 sqrt(ax + b)), ax + b > 0 (printed key p533: a/(2 sqrt(ax+b))). dy/dx as a slope. For the curve y = f(x), dy/dx at a point is the gradient of the tangent there: dy/dx = tan(theta) = rise/run measured along the tangent; a positive value means the curve rises, a negative value means it falls, and dy/dx = 0 marks a horizontal tangent (stationary point).

Q5(i). Define the derivative of a function at any point. Prove that d/dx [f(x) + g(x)] = d/dx f(x) + d/dx g(x). (T.U. 2054)

Knowledge Note

Write the difference quotient of f+g as the sum of the two difference quotients and take limits term by term.

Marks

5

Solution

Definition. If f is defined on an interval containing x, then f'(x) = lim(h->0) [f(x+h) - f(x)]/h whenever the limit exists; the function x -> f'(x) so obtained is the derivative of f. Proof (sum rule). Let y = f(x) + g(x). Then [y(x+h) - y(x)]/h = {[f(x+h) - f(x)] + [g(x+h) - g(x)]}/h = [f(x+h) - f(x)]/h + [g(x+h) - g(x)]/h. Because the limit of a sum is the sum of the limits (both exist by hypothesis), letting h -> 0 gives y' = f'(x) + g'(x). Boxed d/dx[f + g] = f' + g'. (The printed key carries this as a proof, p533.)

Q5(ii). Prove that d/dx [f(x) g(x)] = f(x) d/dx g(x) + g(x) d/dx f(x). (T.U. 2054)

Knowledge Note

The standard trick: insert f(x+h)g(x) - f(x+h)g(x) so that both difference quotients appear; the leftover f(x+h) -> f(x).

Marks

5

Solution

Proof (product rule). Let y = f(x) g(x). The difference quotient is [f(x+h)g(x+h) - f(x)g(x)]/h. Add and subtract f(x+h) g(x): = [f(x+h)g(x+h) - f(x+h)g(x) + f(x+h)g(x) - f(x)g(x)]/h = f(x+h)[g(x+h) - g(x)]/h + g(x)[f(x+h) - f(x)]/h. As h -> 0, f(x+h) -> f(x) (f is differentiable, hence continuous) and the two brackets tend to g'(x) and f'(x). Hence y' = f(x) g'(x) + g(x) f'(x). Boxed (the printed key carries this as a proof, p533).

Q6(ii). Find from first principles the derivative of x^(3/4).

Knowledge Note

General power rule by first principles: factor out x^n and use (1 + u)^n = 1 + nu + ...; answer (3/4)x^(-1/4).

Marks

5

Solution

Write x + h = x(1 + h/x). Then [(x+h)^(3/4) - x^(3/4)]/h = x^(3/4)[(1 + h/x)^(3/4) - 1]/h. Put u = h/x -> 0 and use (1 + u)^n = 1 + nu + O(u^2): the quotient = x^(3/4)[(3/4)u + O(u^2)]/(x u) = (3/4)x^(-1/4) + O(u). Hence the derivative is (3/4)x^(-1/4) = 3/(4 x^(1/4)). Boxed (printed key p533: (3/4)x^(-1/4), i.e. 3/(4 x^(1/4))).

Q10(a). If sin y = x sin(a + y), prove that dy/dx = sin^2(a + y)/sin a.

Knowledge Note

Implicit differentiation, then replace x by sin y/sin(a+y); the bracket collapses to sin a/sin(a+y).

Marks

5

Solution

Differentiate implicitly with respect to x: cos y y' = sin(a + y) + x cos(a + y) y'. Collect y': y'[cos y - x cos(a + y)] = sin(a + y). Eliminate x using the given relation x = sin y/sin(a + y): cos y - x cos(a + y) = [cos y sin(a + y) - sin y cos(a + y)]/sin(a + y) = sin[(a + y) - y]/sin(a + y) = sin a/sin(a + y). Therefore y' = sin(a + y) * sin(a + y)/sin a = sin^2(a + y)/sin a. Boxed (printed key, book p534).

Q11. If y = sqrt((1 + x)/(1 - x)), prove that dy/dx = y/(1 - x^2).

Knowledge Note

Squaring makes the quotient differentiation trivial; the identity (1-x)^2 y^2 = 1-x^2 converts the result to y/(1-x^2).

Marks

4

Solution

Square: y^2 = (1 + x)/(1 - x). Differentiate implicitly: 2y y' = [(1 - x) + (1 + x)]/(1 - x)^2 = 2/(1 - x)^2, so y' = 1/[(1 - x)^2 y]. Now (1 - x)^2 y^2 = (1 - x)(1 + x) = 1 - x^2, hence (1 - x)^2 y = (1 - x^2)/y and y' = y/(1 - x^2). Boxed (printed key, book p534).

Q13(iii). Find dy/dx when x^m y^n = (x + y)^(m+n).

Knowledge Note

Homogeneous-type relation: the common factor (my - nx) cancels, leaving the symmetric answer y/x.

Marks

5

Solution

Take logs: m log x + n log y = (m + n)log(x + y). Differentiate: m/x + n y'/y = (m + n)(1 + y')/(x + y). Collect y': y'[(m + n)/(x + y) - n/y] = m/x - (m + n)/(x + y). Left bracket = [(m + n)y - n(x + y)]/[y(x + y)] = (my - nx)/[y(x + y)]; right side = [m(x + y) - (m + n)x]/[x(x + y)] = (my - nx)/[x(x + y)]. Hence y' = y/x (for my != nx). Boxed y/x (printed key p534).

Solution
