1.

Q1(i). Find, from first principles, the differential coefficient of sin 4x.

Knowledge Note

First principles for sin: [sin(A+h) − sin A] = 2cos(A+h/2)sin(h/2), and sin(ku)/u → k.

Marks

3

Solution

[sin(4x+4h) − sin4x]/h = 2cos(4x+2h)sin(2h)/h. As h→0: sin(2h)/h → 2 and cos(4x+2h) → cos4x, so the limit is 2·2cos4x = 4cos4x. Boxed 4cos4x (matches the printed key, book p522).

Q1(ii). Find, from first principles, the differential coefficient of cos(ax − b).

Knowledge Note

cos A − cos B = −2sin((A+B)/2)sin((A−B)/2); the inner derivative a comes out.

Marks

4

Solution

[cos(ax−b+ah) − cos(ax−b)]/h = −2sin(ax−b+ah/2)sin(ah/2)/h. As h→0: sin(ah/2)/h → a/2 and the sine factor → sin(ax−b), so the limit is −2·sin(ax−b)·(a/2) = −a sin(ax−b). Boxed −a sin(ax−b) (matches the printed key, book p522).

Q1(vi). Find, from first principles, the differential coefficient of cos²x. (T.U. 057S, 058S)

Knowledge Note

cos²x = (1+cos2x)/2, so its derivative is −sin2x — the classic double-angle result. (T.U. 057S, 058S)

Marks

4

Solution

cos²x = (1 + cos2x)/2. First principles on cos2x gives its derivative −2sin2x, so d/dx[(1+cos2x)/2] = (−2sin2x)/2 = −sin2x. Alternatively [cos²(x+h) − cos²x]/h = [cos(x+h)−cosx][cos(x+h)+cosx]/h → (−sinx)(2cosx) = −sin2x. Boxed −sin2x (matches the printed key, book p522).
