1.

Q1. Evaluate: lim (x→0) sin(ax)/x.

Knowledge Note

Standard result lim(θ→0) sinθ/θ = 1; rescale the angle to use it.

Marks

2

Solution

Multiply and divide by a: sin(ax)/x = a·sin(ax)/(ax). As x → 0, ax → 0 and sin(ax)/(ax) → 1, so the limit is a·1 = a. Boxed a (matches the printed key, book p474).

tan u/u → 1 as u → 0.

tan(bx)/x = b·tan(bx)/(bx) → b·1 = b. Boxed b (matches the key).

Q3. Evaluate: lim (x→0) sin(mx)/sin(nx).

Knowledge Note

Divide numerator and denominator by x; both become standard sine quotients.

Marks

2

Solution

sin(mx)/sin(nx) = [m·sin(mx)/(mx)]/[n·sin(nx)/(nx)] → m·1/(n·1) = m/n. Boxed m/n (matches the key).

Q5. Evaluate: lim (x→0) sin(px)/tan(qx).

Knowledge Note

Convert tan(qx) to sin(qx)/cos(qx); cos(qx) → 1.

Marks

2

Solution

sin(px)/tan(qx) = sin(px)·cos(qx)/sin(qx) = [sin(px)/(px)]·cos(qx)·(px)/[ (qx)·sin(qx)/(qx) ] = (p/q)·[sin(px)/(px)]/[(sin qx)/(qx)]·cos(qx) → (p/q)·1·1 = p/q. Boxed p/q (matches the key).

6.

Q6. Evaluate: lim (x→a) sin(x − a)/(x² − a²).

Knowledge Note

Factor x² − a² = (x − a)(x + a) and use sin(x − a)/(x − a) → 1.

Marks

3

Solution

x² − a² = (x − a)(x + a). So the quotient = [sin(x − a)/(x − a)]·1/(x + a). As x → a the bracket → 1 and 1/(x + a) → 1/(2a). Boxed 1/(2a) (matches the key).

7.

Q7. Evaluate: lim (x→p) (x² − p²)/tan(x − p).

Knowledge Note

(x² − p²) = (x − p)(x + p) and tan(x − p)/(x − p) → 1.

Marks

3

Solution

Write the quotient as (x + p)·(x − p)/tan(x − p). Since tan(x − p)/(x − p) → 1, its reciprocal (x − p)/tan(x − p) → 1. Hence the limit is (p + p)·1 = 2p. Boxed 2p (matches the key).

Group: [sin(ax)/sin(cx)]·cos(bx) → (a/c)·1 = a/c. Boxed a/c (matches the key).

Q9. Evaluate: lim (x→0) (1 − cos x)/x².

Knowledge Note

Multiply by (1 + cos x) to turn 1 − cos x into sin²x.

Marks

3

Solution

(1 − cos x)/x² = (1 − cos x)(1 + cos x)/[x²(1 + cos x)] = sin²x/[x²(1 + cos x)] = [sin x/x]²·1/(1 + cos x) → 1²·1/2 = 1/2. Boxed 1/2 (matches the key).

Q10. Evaluate: lim (x→0) (1 − cos 6x)/x².

Solution

1 − cos 6x = 2 sin²(3x). Quotient = 2 sin²(3x)/x² = 18·[sin 3x/(3x)]² → 18·1 = 18. Boxed 18 (matches the key).

Q11. Evaluate: lim (x→0) (1 − cos 9x)/x².

General pattern: (1 − cos kx)/x² → k²/2.

Solution

1 − cos 9x = 2 sin²(4.5x) = 2 sin²(9x/2). Quotient = 2·(9/2)²·[sin(9x/2)/(9x/2)]² = (81/2)·1 = 81/2. Boxed 81/2 (matches the key).

12.

Q12. Evaluate: lim (x→0) (cos ax − cos bx)/x².

Knowledge Note

cos A − cos B = −2 sin((A+B)/2) sin((A−B)/2); each sine quotient contributes its coefficient.

Marks

4

Solution

cos ax − cos bx = 2 sin((a+b)x/2) sin((b−a)x/2). Divide by x²: 2·[(a+b)/2]·[(b−a)/2]·[sin((a+b)x/2)/((a+b)x/2)]·[sin((b−a)x/2)/((b−a)x/2)] → 2·(a+b)(b−a)/4 = (b² − a²)/2. Boxed ½(b² − a²) (matches the key).

13.

Q13. Evaluate: lim (x→0) (sin ax − sin bx)/x.

Knowledge Note

sin A − sin B = 2 cos((A+B)/2) sin((A−B)/2); one factor cancels x.

Marks

4

Solution

sin ax − sin bx = 2 cos((a+b)x/2) sin((a−b)x/2). Divide by x: 2·[(a−b)/2]·cos((a+b)x/2)·[sin((a−b)x/2)/((a−b)x/2)] → (a − b)·1·1 = a − b. Boxed a − b (matches the key).

14.

Q14. Evaluate: lim (x→0) (1 − cos px)/(1 − cos qx).

Knowledge Note

Ratio of two 1 − cos forms: the squared coefficients give p²/q².

Marks

4

Solution

1 − cos px = 2 sin²(px/2), 1 − cos qx = 2 sin²(qx/2). Ratio = [sin(px/2)/(px/2)]²(p²x²/4) ÷ {[sin(qx/2)/(qx/2)]²(q²x²/4)} → p²/q². Boxed p²/q² (matches the key).

15.

Q15. Evaluate: lim (x→0) (tan x − sin x)/x³.

Knowledge Note

tan x − sin x = sin x(1 − cos x)/cos x: use the two standard limits together.

Marks

4

Solution

tan x − sin x = sin x(1/cos x − 1) = sin x(1 − cos x)/cos x. Divide by x³: [sin x/x]·[(1 − cos x)/x²]·1/cos x → 1·(1/2)·1 = 1/2. Boxed 1/2 (matches the key).

16.

Q16. Evaluate: lim (x→0) (tan 2x − sin 2x)/x³.

Knowledge Note

Same identity with 2x: each factor contributes its coefficient, giving 2³ = 8 times the x-case.

Marks

4

Solution

tan 2x − sin 2x = sin 2x(1 − cos 2x)/cos 2x. Divide by x³: [sin 2x/x]·[(1 − cos 2x)/x²]·1/cos 2x. Now sin 2x/x → 2 and (1 − cos 2x)/x² = 2 sin²x/x² = 2 → 2. Product: 2·2·1 = 4. Boxed 4 (matches the key).

17.

Q17. Evaluate: lim (x→π/2) (sec x − tan x).

Knowledge Note

sec x − tan x = (1 − sin x)/cos x; multiply by (1 + sin x) to remove the 0/0.

Marks

3

Solution

sec x − tan x = (1 − sin x)/cos x = (1 − sin²x)/[cos x(1 + sin x)] = cos²x/[cos x(1 + sin x)] = cos x/(1 + sin x). As x → π/2: 0/(1 + 1) = 0. Boxed 0 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q17; book p473 = PDF p500; key book p474

18.

Q18. Evaluate: lim (x→π/4) (sec²x − 2)/(tan x − 1).

Knowledge Note

sec²x − 2 = tan²x − 1 = (tan x − 1)(tan x + 1): cancel the vanishing factor.

Marks

3

Solution

Use sec²x = 1 + tan²x: sec²x − 2 = tan²x − 1 = (tan x − 1)(tan x + 1). Cancel (tan x − 1) (non-zero for x ≠ π/4 near π/4): limit = tan(π/4) + 1 = 1 + 1 = 2. Boxed 2 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q18; book p473 = PDF p500; key book p474

Q19. Evaluate: lim (x→π/4) (2 − cosec²x)/(1 − cot x).

cosec²x = 1 + cot²x, so the numerator factors against (1 − cot x).

Marks

3

Solution

2 − cosec²x = 2 − (1 + cot²x) = 1 − cot²x = (1 − cot x)(1 + cot x). Cancel (1 − cot x): limit = 1 + cot(π/4) = 1 + 1 = 2. Boxed 2 (matches the key).

20.

Q20. Evaluate: lim (x→y) (tan x − tan y)/(x − y).

Knowledge Note

y is a constant here: tan x − tan y = sin(x − y)/(cos x cos y), so the (x − y) cancels.

Marks

4

Solution

tan x − tan y = sin x/cos x − sin y/cos y = (sin x cos y − cos x sin y)/(cos x cos y) = sin(x − y)/(cos x cos y). Divide by (x − y): [sin(x − y)/(x − y)]·1/(cos x cos y) → 1/(cos y·cos y) = sec²y. Boxed sec²y (matches the key).

23.

Q23. Evaluate: lim (x→θ) (x cot θ − θ cot x)/(x − θ). [T.U. 2049, HSEB 2055]

Knowledge Note

Add and subtract θ cot θ, then use cot θ − cot x = sin(x − θ)/(sin θ sin x).

Marks

5

Solution

x cot θ − θ cot x = (x − θ)cot θ + θ(cot θ − cot x). Also cot θ − cot x = cos θ/sin θ − cos x/sin x = (cos θ sin x − cos x sin θ)/(sin θ sin x) = sin(x − θ)/(sin θ sin x). So the quotient = cot θ + θ·sin(x − θ)/[sin θ sin x (x − θ)] = cot θ + θ/[sin θ sin x]·[sin(x − θ)/(x − θ)] → cot θ + θ/(sin θ sin θ) = cot θ + θ/sin²θ. Boxed cot θ + θ/sin²θ (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q23; book p473 = PDF p500; key book p474

24.

Q24. Evaluate: lim (x→θ) (x cos θ − θ cos x)/(x − θ). [T.U. 2052 H, 2057 S]

Knowledge Note

Add and subtract θ cos θ, then use cos θ − cos x = 2 sin((θ+x)/2) sin((x−θ)/2).

Marks

5

Solution

x cos θ − θ cos x = (x − θ)cos θ + θ(cos θ − cos x). And cos θ − cos x = 2 sin((θ+x)/2) sin((x−θ)/2). Quotient = cos θ + θ·2 sin((θ+x)/2)·[sin((x−θ)/2)/(x − θ)] = cos θ + θ·sin((θ+x)/2)·[sin((x−θ)/2)/((x−θ)/2)] → cos θ + θ·sin θ·1 = cos θ + θ sin θ. Boxed cos θ + θ sin θ (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q24; book p473 = PDF p500; key book p474

25.

Q25. Evaluate: lim (x→1) (1 + cos πx)/tan²(πx).

Knowledge Note

Shift the origin: t = x − 1; then 1 + cos πx = 1 − cos πt and tan²πx = tan²πt.

Marks

4

Solution

Put t = x − 1 → 0, so πx = π + πt. Then cos πx = −cos πt and tan(πx) = tan(πt). Numerator: 1 − cos πt = 2 sin²(πt/2). Denominator: tan²(πt) = sin²(πt)/cos²(πt). Quotient = 2 sin²(πt/2)·cos²(πt)/sin²(πt) = 2 sin²(πt/2)cos²(πt)/[4 sin²(πt/2)cos²(πt/2)] = 1/[2 cos²(πt/2)] → 1/2 (cos 0 = 1). Boxed 1/2 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q25; book p473 = PDF p500; key book p474

26.

Q26. Evaluate: lim (x→θ) (x tan θ − θ tan x)/(x − θ). [T.U. 2050 H]

Knowledge Note

Add and subtract θ tan θ; tan θ − tan x = −sin(x − θ)/(cos θ cos x).

Marks

5

Solution

x tan θ − θ tan x = (x − θ)tan θ + θ(tan θ − tan x). And tan θ − tan x = sin(θ − x)/(cos θ cos x) = −sin(x − θ)/(cos θ cos x). Quotient = tan θ − θ·[sin(x − θ)/(x − θ)]/(cos θ cos x) → tan θ − θ/(cos θ cos θ) = tan θ − θ sec²θ. Boxed tan θ − θ sec²θ (matches the key).

27.

Q27. Evaluate: lim (θ→π/4) (cos θ − sin θ)/(θ − π/4).

Knowledge Note

Shift to π/4: with h = θ − π/4 both cosine and sine expand to the same √2/2 base.

Marks

4

Solution

Put h = θ − π/4 → 0. cos θ = cos(π/4 + h) = (cos h − sin h)/√2; sin θ = (cos h + sin h)/√2. Difference = −2 sin h/√2 = −√2 sin h. Divide by h: −√2·(sin h/h) → −√2. Boxed −√2 (matches the key).

28.

Q28. Evaluate: lim (x→c) (√x − √c)/(sin x − sin c).

Knowledge Note

Two 0/0 parts: rationalise the root and use (sin x − sin c)/(x − c) → cos c.

Marks

5

Solution

Rationalise: √x − √c = (x − c)/(√x + √c). The quotient = (x − c)/[(√x + √c)(sin x − sin c)] = 1/(√x + √c) · (x − c)/(sin x − sin c). Since (sin x − sin c)/(x − c) → cos c, the reciprocal → 1/cos c. Hence the limit = 1/(2√c)·1/cos c = sec c/(2√c). Boxed sec c/(2√c) (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.2 Q28; book p473 = PDF p500; key book p474

34.

Q30(b). Evaluate: lim (x→π/2) cos x/log(x − π/2 + 1).

Knowledge Note

Put t = x − π/2; cos x = −sin t and log(1 + t) ~ t, so the two leading terms cancel with a minus sign.

Marks

4

Solution

Let t = x − π/2 → 0. Then cos x = cos(π/2 + t) = −sin t and log(x − π/2 + 1) = log(1 + t). Quotient = −sin t/log(1 + t) = −[sin t/t]·[t/log(1 + t)] → −1·1 = −1. Boxed −1 (matches the key).
