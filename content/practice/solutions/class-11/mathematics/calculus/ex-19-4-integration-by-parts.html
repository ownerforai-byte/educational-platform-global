Questions

1.

Q1(a). Calculate the integral: integral of x log x dx.

Knowledge Note

LIATE rule: the logarithm is the u, the algebraic part is dv, so differentiating removes the log entirely.

Marks

2

Solution

By parts with u = log x, dv = x dx, so du = dx/x, v = x^2/2: integral u dv = uv - integral v du gives integral x log x dx = (x^2/2) log x - integral (x^2/2)(dx/x) = (x^2/2) log x - (1/2) integral x dx = (x^2/2) log x - x^2/4 + c = (1/4)x^2 (2 log x - 1) + c. Boxed (printed key p588).

Source

Sukunda Basic Mathematics Grade XI, Ch.19 Exercise 19.4 Q1(a); book p587 = PDF p614; key book p588 = PDF p615

2.

Q1(b). Calculate the integral: integral of (5x - 2) log x dx.

Knowledge Note

Same LIATE split with a linear factor: u = log x, dv = (5x - 2) dx, v = 5x^2/2 - 2x.

Marks

3

Solution

By parts with u = log x, dv = (5x-2)dx, du = dx/x, v = 5x^2/2 - 2x: integral = (5x^2/2 - 2x) log x - integral (5x^2/2 - 2x)(dx/x) = (5x^2/2 - 2x) log x - integral (5x/2 - 2) dx = (5x^2/2 - 2x) log x - 5x^2/4 + 2x + c = (1/2)x(5x - 4) log x - 5x^2/4 + 2x + c. Boxed (printed key p588).

3.

Q1(c). Calculate the integral: integral of x^n log x dx. (T.U. 2051 H).

Knowledge Note

The general log-times-power case: v = x^(n+1)/(n+1) and the leftover integral is again a pure power.

Marks

3

Solution

By parts with u = log x, dv = x^n dx, du = dx/x, v = x^(n+1)/(n+1): integral = x^(n+1)/(n+1) log x - (1/(n+1)) integral x^n dx = x^(n+1)/(n+1) log x - x^(n+1)/(n+1)^2 + c = x^(n+1)/(n+1)^2 [(n+1) log x - 1] + c. Boxed (printed key p588). Note n = -1 is excluded because log x itself would then be the integrand's square.

4.

Q1(d). Calculate the integral: integral of (log x)^2 dx.

Knowledge Note

Take u = (log x)^2 with dv = dx; one round of by parts leaves integral log x dx, which is a known standard form.

Marks

3

Solution

By parts with u = (log x)^2, dv = dx, du = 2 log x dx/x, v = x: integral (log x)^2 dx = x(log x)^2 - 2 integral log x dx = x(log x)^2 - 2(x log x - x) + c = x(log x)^2 - 2x log x + 2x + c. (The inner integral is itself by parts: integral log x dx = x log x - x.) Boxed (printed key p588).

5.

Q1(e). Calculate the integral: integral of x log(x - 1) dx. (T.U. 049 H).

Knowledge Note

u = log(x - 1), dv = x dx; the leftover integral is an improper fraction, so divide x^2 by (x - 1) first.

Marks

4

Solution

By parts with u = log(x-1), dv = x dx, du = dx/(x-1), v = x^2/2: integral = (x^2/2) log(x-1) - (1/2) integral x^2 dx/(x-1). Polynomial division: x^2/(x-1) = x + 1 + 1/(x-1), so the leftover is (1/2)[x^2/2 + x + log(x-1)]. Hence integral = (x^2/2) log(x-1) - x^2/4 - x/2 - (1/2) log(x-1) + c = (1/2)(x^2 - 1) log(x-1) - x^2/4 - x/2 + c. Boxed (printed key p588).

Source

Sukunda Basic Mathematics Grade XI, Ch.19 Exercise 19.4 Q1(e); book p587 = PDF p614; key book p588 = PDF p615

6.

Q1(f). Calculate the integral: integral of x^2 e^(ax) dx. (HSEB 2058).

Knowledge Note

Exponential beats polynomial in LIATE, so u = x^2 and by parts runs twice, the power dropping 2 -> 1 -> 0.

Marks

4

Solution

By parts with u = x^2, dv = e^(ax) dx, du = 2x dx, v = e^(ax)/a: integral x^2 e^(ax) dx = x^2 e^(ax)/a - (2/a) integral x e^(ax) dx. Apply by parts again to integral x e^(ax) dx = x e^(ax)/a - e^(ax)/a^2. Therefore the integral = x^2 e^(ax)/a - (2/a)[x e^(ax)/a - e^(ax)/a^2] + c = x^2 e^(ax)/a - 2x e^(ax)/a^2 + 2 e^(ax)/a^3 + c. Boxed (printed key p588).

8.

Q1(h). Calculate the integral: integral of (2x - 1) e^(2x) dx. (T.U. 048).

Knowledge Note

With a linear factor one round of by parts is enough, and the answer collapses to (x - 1)e^(2x).

Marks

2

Solution

By parts with u = 2x - 1, dv = e^(2x) dx, du = 2 dx, v = e^(2x)/2: integral = (2x-1) e^(2x)/2 - integral e^(2x) dx = (2x-1) e^(2x)/2 - e^(2x)/2 + c = (2x - 2) e^(2x)/2 + c = (x - 1) e^(2x) + c. Boxed (printed key p588).

9.

Q1(i). Calculate the integral: integral of x sin x dx. (T.U. 2053 H, HSEB 2057).

Knowledge Note

u = x, dv = sin x dx with v = -cos x; the sign is the usual trap in this classic.

Marks

2

Solution

By parts with u = x, dv = sin x dx, du = dx, v = -cos x: integral x sin x dx = -x cos x + integral cos x dx = -x cos x + sin x + c = sin x - x cos x + c. Check: d/dx = cos x - cos x + x sin x = x sin x. Boxed (printed key p588).

10.

Q1(j). Calculate the integral: integral of x sec^2 x dx. (T.U. 048 H).

Knowledge Note

dv = sec^2 x dx integrates straight to tan x, and the leftover integral of tan x gives log cos x.

Marks

2

Solution

By parts with u = x, dv = sec^2 x dx, du = dx, v = tan x: integral x sec^2 x dx = x tan x - integral tan x dx = x tan x - log|sec x| + c = x tan x + log|cos x| + c. Boxed (printed key p588 prints x tan x + log cos x + c).

11.

Q1(k). Calculate the integral: integral of x sec x tan x dx.

Knowledge Note

sec x tan x is the derivative of sec x, so it is the dv; the remaining integral is the standard integral of sec x.

Marks

3

Solution

By parts with u = x, dv = sec x tan x dx, du = dx, v = sec x: integral x sec x tan x dx = x sec x - integral sec x dx = x sec x - log|sec x + tan x| + c. Boxed (printed key p588).

12.

Q1(l). Calculate the integral: integral of x cos(nx) dx.

Knowledge Note

Linear times cosine: u = x, dv = cos nx dx, and the chain factor 1/n appears twice.

Marks

3

Solution

By parts with u = x, dv = cos nx dx, du = dx, v = sin nx/n: integral x cos nx dx = x sin nx/n - (1/n) integral sin nx dx = x sin nx/n + cos nx/n^2 + c = (1/n) x sin nx + (1/n^2) cos nx + c. Boxed (printed key p588).

13.

Q1(m). Calculate the integral: integral of x sin(ax) dx.

Knowledge Note

The general-frequency version of Q1(i); keep the two 1/a factors straight.

Marks

3

Solution

By parts with u = x, dv = sin(ax) dx, du = dx, v = -cos(ax)/a: integral = -x cos(ax)/a + (1/a) integral cos(ax) dx = -x cos(ax)/a + sin(ax)/a^2 + c = (1/a^2) sin ax - (1/a) x cos ax + c. Boxed (printed key p588).

15.

Q1(o). Calculate the integral: integral of x^2 sin x dx. (T.U. 2049, HSEB 2057).

Knowledge Note

Two rounds of by parts; the first leaves integral x cos x dx, which Q1(i)-style by parts finishes.

Marks

3

Solution

By parts with u = x^2, dv = sin x dx, du = 2x dx, v = -cos x: integral = -x^2 cos x + 2 integral x cos x dx. For integral x cos x dx take u = x, dv = cos x dx: = x sin x - integral sin x dx = x sin x + cos x. Hence integral x^2 sin x dx = -x^2 cos x + 2x sin x + 2 cos x + c. Check: d/dx = -2x cos x + x^2 sin x + 2 sin x + 2x cos x - 2 sin x = x^2 sin x. Boxed (printed key p588).

16.

Q1(p). Calculate the integral: integral of x^2 cos(nx) dx.

Knowledge Note

Same double by-parts as Q1(o) with frequency n: two factors of 1/n and one of 1/n^2 appear.

Marks

4

Solution

By parts with u = x^2, dv = cos nx dx, du = 2x dx, v = sin nx/n: integral = x^2 sin nx/n - (2/n) integral x sin nx dx. Then integral x sin nx dx = -x cos nx/n + sin nx/n^2. So the integral = x^2 sin nx/n + (2/n)(x cos nx/n - sin nx/n^2) + c = (1/n)x^2 sin nx + (2/n^2)x cos nx - (2/n^3) sin nx + c. Boxed (printed key p588).

17.

Q1(q). Calculate the integral: integral of x^2 sin(3x - 2) dx.

Knowledge Note

Phase-shifted double by-parts: v = -cos(3x-2)/3, then the linear remainder integrates twice more with factors 1/3 and 1/9.

Marks

4

Solution

By parts with u = x^2, dv = sin(3x-2)dx, du = 2x dx, v = -cos(3x-2)/3: integral = -(x^2/3) cos(3x-2) + (2/3) integral x cos(3x-2) dx. Now by parts with u = x, dv = cos(3x-2)dx: integral x cos(3x-2) dx = (x/3) sin(3x-2) + (1/9) cos(3x-2). Therefore integral = -(1/3)x^2 cos(3x-2) + (2/9)x sin(3x-2) + (2/27) cos(3x-2) + c. Boxed (printed key p588).

18.

Q1(r). Calculate the integral: integral of x sin^2 x dx. (T.U. 2050 H).

Knowledge Note

Linearise first: sin^2 x = (1 - cos 2x)/2 turns the integrand into x/2 minus x cos 2x/2, and only the second piece needs by parts.

Marks

3

Solution

sin^2 x = (1 - cos 2x)/2, so integral x sin^2 x dx = (1/2) integral x dx - (1/2) integral x cos 2x dx = x^2/4 - (1/2)[x sin 2x/2 + cos 2x/4] + c (by parts with u = x, dv = cos 2x dx) = (1/4)x^2 - (1/4)x sin 2x - (1/8) cos 2x + c. Boxed (printed key p588).

20.

Q1(t). Calculate the integral: integral of x sin^2(nx) dx.

Knowledge Note

General-frequency linearisation: sin^2 nx = (1 - cos 2nx)/2, and every frequency is doubled in the by-parts piece.

21.

Q1(u). Calculate the integral: integral of x tan^2(nx) dx.

Knowledge Note

tan^2 = sec^2 - 1: the x sec^2 nx piece is by parts, and integral tan nx dx supplies the logarithm.

Marks

4

Solution

tan^2(nx) = sec^2(nx) - 1. So integral x tan^2 nx dx = integral x sec^2(nx) dx - integral x dx. By parts with u = x, dv = sec^2(nx)dx, v = tan(nx)/n: integral x sec^2(nx) dx = x tan(nx)/n - (1/n) integral tan(nx) dx = x tan(nx)/n + log|cos nx|/n^2. Hence the answer = (1/n) x tan nx + (1/n^2) log|cos nx| - (1/2) x^2 + c. Boxed (printed key p588 prints log cos nx without modulus).

22.

Q1(v). Calculate the integral: integral of sec^3 x dx. (T.U. 057) (HSEB 051).

Knowledge Note

The classic cyclic by-parts: u = sec x, dv = sec^2 x dx brings back integral sec^3 x, which is then solved algebraically.

Marks

4

Solution

Write I = integral sec^3 x dx = integral sec x sec^2 x dx. By parts with u = sec x, dv = sec^2 x dx, du = sec x tan x dx, v = tan x: I = sec x tan x - integral sec x tan^2 x dx = sec x tan x - integral sec x (sec^2 x - 1) dx = sec x tan x - I + integral sec x dx. So 2I = sec x tan x + log|sec x + tan x|, giving I = (1/2) sec x tan x + (1/2) log|sec x + tan x| + c. Boxed (printed key p588).

23.

Q1(w). Calculate the integral: integral of cosec^3 x dx.

Knowledge Note

Same cyclic trick with the co-function; d(cot x) = -cosec^2 x dx puts a minus sign into the recurrence.

Marks

4

Solution

Write I = integral cosec^3 x dx = integral cosec x cosec^2 x dx. By parts with u = cosec x, dv = cosec^2 x dx, du = -cosec x cot x dx, v = -cot x: I = -cosec x cot x - integral cosec x cot^2 x dx = -cosec x cot x - integral cosec x (cosec^2 x - 1) dx = -cosec x cot x - I + integral cosec x dx. So 2I = -cosec x cot x + log|cosec x - cot x|, giving I = -(1/2) cosec x cot x + (1/2) log|cosec x - cot x| + c. Boxed (printed key p588).

24.

Q1(x). Calculate the integral: integral of e^x sin x dx. (T.U. 2050).

Knowledge Note

Cyclic by parts: two rounds return the original integral with a minus sign, so it is solved as an equation.

Marks

4

Solution

Let I = integral e^x sin x dx. By parts with u = sin x, dv = e^x dx: I = e^x sin x - integral e^x cos x dx; apply by parts again to integral e^x cos x dx = e^x cos x + integral e^x sin x dx = e^x cos x + I. Therefore I = e^x sin x - e^x cos x - I, so 2I = e^x(sin x - cos x) and I = (1/2) e^x (sin x - cos x) + c. Boxed (printed key p588).

Source

Sukunda Basic Mathematics Grade XI, Ch.19 Exercise 19.4 Q1(x); book p587 = PDF p614; key book p588 = PDF p615

25.

Q1(y). Calculate the integral: integral of e^(ax) sin(bx) dx. (T.U. 051, 056).

Knowledge Note

General cyclic case: dividing by (a^2 + b^2) after two rounds is the standard result to memorise.

Marks

5

Solution

Let I = integral e^(ax) sin(bx) dx. By parts with u = sin bx, dv = e^(ax)dx, v = e^(ax)/a: I = e^(ax) sin(bx)/a - (b/a) integral e^(ax) cos(bx) dx. By parts again on the cosine integral (u = cos bx, dv = e^(ax)dx): integral e^(ax) cos(bx) dx = e^(ax) cos(bx)/a + (b/a) I. Substituting: I = e^(ax) sin(bx)/a - (b/a)[e^(ax) cos(bx)/a + (b/a) I] = e^(ax)(a sin bx - b cos bx)/a^2 - (b^2/a^2) I. Hence I(1 + b^2/a^2) = e^(ax)(a sin bx - b cos bx)/a^2, so I = e^(ax)(a sin bx - b cos bx)/(a^2 + b^2) + c. Boxed (printed key p588).

Source

Sukunda Basic Mathematics Grade XI, Ch.19 Exercise 19.4 Q1(y); book p587 = PDF p614; key book p588 = PDF p615

26.

Q1(z). Calculate the integral: integral of e^(ax) cos(bx) dx. (T.U. 2053).

Knowledge Note

Companion of Q1(y): the sign pattern flips in the numerator (b sin bx + a cos bx).

Marks

5

Solution

Let I = integral e^(ax) cos(bx) dx. By parts with u = cos bx, dv = e^(ax)dx: I = e^(ax) cos(bx)/a + (b/a) integral e^(ax) sin(bx) dx. Using integral e^(ax) sin(bx) dx = e^(ax)(a sin bx - b cos bx)/(a^2+b^2) from Q1(y): I = e^(ax) cos(bx)/a + (b/a) * e^(ax)(a sin bx - b cos bx)/(a^2+b^2) = e^(ax)[(a^2+b^2) cos bx + ab sin bx - b^2 cos bx]/[a(a^2+b^2)] = e^(ax)(a cos bx + b sin bx)/(a^2 + b^2) + c. Boxed (printed key p588 prints e^(ax)(b sin bx + a cos bx)/(a^2+b^2) + c - same expression).
