1.

Q1(i). Find the indefinite integral: integral of 3x^2 (x^3 + 1)^3 dx. (T.U. 052 H)

Knowledge Note

Substitution rule: if the derivative of the inner function appears as a factor, set u = inner function and the integral collapses to integral of u^n du.

Marks

2

Solution

Let u = x^3 + 1, du = 3x^2 dx - exactly the factor present. Then integral 3x^2(x^3+1)^3 dx = integral u^3 du = u^4/4 + c = (1/4)(x^3+1)^4 + c. Check: d/dx[(1/4)(x^3+1)^4] = (1/4)4(x^3+1)^33x^2 = 3x^2(x^3+1)^3. Boxed (printed key p578).

Q1(ii). Find the indefinite integral: integral of x (a^2 + x^2)^(3/2) dx.

Knowledge Note

Constant-factor adjustment: du carries a constant multiple of x dx, so divide by that constant - never by x itself.

Marks

2

Solution

Let u = a^2 + x^2, du = 2x dx, so x dx = du/2. Then integral x(a^2+x^2)^(3/2) dx = (1/2) integral u^(3/2) du = (1/2) u^(5/2)/(5/2) = (1/5)(a^2+x^2)^(5/2) + c. Check: d/dx = (1/5)(5/2)(a^2+x^2)^(3/2)2x = x(a^2+x^2)^(3/2). Boxed (printed key p578).

3.

Q1(iii). Find the indefinite integral: integral of x dx / (3x^2 - 4).

Knowledge Note

When the numerator is a constant multiple of the inner derivative the result is a logarithm: integral du/u = log|u|.

Marks

2

Solution

Let u = 3x^2 - 4, du = 6x dx, so x dx = du/6. Then integral x dx/(3x^2-4) = (1/6) integral du/u = (1/6) log|3x^2 - 4| + c. Check: d/dx = (1/6)*6x/(3x^2-4) = x/(3x^2-4). Boxed (printed key prints log(3x^2-4) without the modulus; the modulus is the correct domain-safe form).

Q1(iv). Find the indefinite integral: integral of x^(n-1) dx / sqrt(a^n + x^n).

Knowledge Note

The exponent n-1 is deliberately one less than n so that d(a^n + x^n) = n x^(n-1) dx: a textbook substitution.

Marks

3

Solution

Let u = a^n + x^n, du = n x^(n-1) dx, so x^(n-1) dx = du/n. Then integral x^(n-1) dx/sqrt(a^n+x^n) = (1/n) integral u^(-1/2) du = (1/n)2 sqrt(u) = (2/n) sqrt(a^n + x^n) + c. Check: d/dx[(2/n)(a^n+x^n)^(1/2)] = (2/n)(1/2)(a^n+x^n)^(-1/2)*n x^(n-1) = x^(n-1)/sqrt(a^n+x^n). Boxed (printed key p578).

5.

Q1(v). Find the indefinite integral: integral of (2x + 3) dx / (3x^2 + 9x + 5)^3.

Knowledge Note

Match the numerator to the inner derivative up to a constant: (3x^2+9x+5)' = 6x+9 = 3(2x+3).

Marks

3

Solution

Let u = 3x^2 + 9x + 5, du = (6x+9) dx = 3(2x+3) dx, so (2x+3) dx = du/3. Then integral (2x+3)u^(-3) dx = (1/3) integral u^(-3) du = (1/3)*u^(-2)/(-2) = -1/(6u^2) + c = -1/[6(3x^2+9x+5)^2] + c. Check: d/dx[-1/(6u^2)] = (1/(3))u^(-3)u' = (2x+3)/u^3. Boxed (printed key p578).

Q2(v). Find the indefinite integral: integral of sin^2 x cos^3 x dx. (T.U. 2049 H)

Knowledge Note

Marks

3

Solution

Check: d/dx = sin^2 x cos x - sin^4 x cos x = sin^2 x cos x (1 - sin^2 x) = sin^2 x cos^3 x. Boxed (printed key p578).

Q2(viii). Find the indefinite integral: integral of sin x dx / (1 - cos x)^m. (HSEB 2054)

Knowledge Note

d(1 - cos x) = sin x dx, so a power of a cosine-shifted denominator integrates by the power rule (m = 1 is the separate logarithmic case).

Solution

Let u = 1 - cos x, du = sin x dx. Then integral u^(-m) du = u^(1-m)/(1-m) + c for m /= 1, i.e. (1/(1-m))(1 - cos x)^(1-m) + c. Check: d/dx = (1/(1-m))(1-m)(1-cos x)^(-m)sin x = sin x/(1-cos x)^m. For m = 1 the answer would be log|1 - cos x| + c instead. Boxed (printed key p578, m /= 1).
