1.

Q1(a). Find the limit: lim (x→2) (2x² + 3x − 14).

Knowledge Note

A polynomial is continuous everywhere, so the limit is just the value: substitute x = a.

Marks

2

Solution

2x² + 3x − 14 is a polynomial, hence continuous at x = 2. Substitute: 2(2)² + 3(2) − 14 = 8 + 6 − 14 = 0. Boxed 0 (matches the printed key, book p466).

5.

Q2(a). Compute: lim (x→0) (4x³ − x² + 2x)/(3x² + 4x).

Knowledge Note

0/0 form: cancel the common factor x (x ≠ 0 on the approach).

Marks

3

Solution

At x = 0 both numerator and denominator vanish (0/0 form). Factor: numerator = x(4x² − x + 2), denominator = x(3x + 4). For x ≠ 0 cancel x: (4x² − x + 2)/(3x + 4). Now substitute x = 0: 2/4 = 1/2. Boxed 1/2 (matches the key).

6.

Q2(b). Compute: lim (x→4) (x³ − 64)/(x² − 16).

Knowledge Note

x³ − a³ = (x − a)(x² + ax + a²) and x² − a² = (x − a)(x + a): cancel (x − 4).

Marks

3

Solution

0/0 at x = 4. Factor: x³ − 64 = (x − 4)(x² + 4x + 16); x² − 16 = (x − 4)(x + 4). For x ≠ 4 cancel (x − 4): (x² + 4x + 16)/(x + 4). Substitute x = 4: (16 + 16 + 16)/8 = 48/8 = 6. Boxed 6 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q2(b); book p465 = PDF p492; key book p466

7.

Q2(c). Compute: lim (x→a) (x^(2/3) − a^(2/3))/(x − a).

Knowledge Note

Treat x^(2/3) as (x^(1/3))², difference of squares, then x − a = (x^(1/3))³ − (a^(1/3))³.

Marks

4

Solution

Put u = x^(1/3), c = a^(1/3) (so u³ = x, c³ = a). The quotient becomes (u² − c²)/(u³ − c³) = (u − c)(u + c)/[(u − c)(u² + uc + c²)] = (u + c)/(u² + uc + c²) for u ≠ c. As x → a, u → c: (c + c)/(3c²) = 2c/(3c²) = 2/(3c) = (2/3)a^(−1/3). Boxed (2/3)a^(−1/3) (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q2(c); book p465 = PDF p492; key book p466

8.

Q2(d). Compute: lim (x→1) (x² + 3x − 4)/(x − 1).

Knowledge Note

x² + 3x − 4 = (x + 4)(x − 1): cancel the vanishing factor.

Marks

3

Solution

Numerator at x = 1 is 0, denominator 0. Factor: x² + 3x − 4 = (x + 4)(x − 1). Cancel (x − 1) for x ≠ 1: limit = lim (x + 4) = 5. Boxed 5 (matches the key).

9.

Q2(e). Compute: lim (x→2) (x² − 5x + 6)/(x² − x − 2).

Knowledge Note

Factorise top and bottom; the (x − 2) factor cancels.

Marks

3

Solution

0/0 at x = 2. x² − 5x + 6 = (x − 2)(x − 3); x² − x − 2 = (x − 2)(x + 1). Cancel (x − 2): (x − 3)/(x + 1) → (2 − 3)/(2 + 1) = −1/3. Boxed −1/3 (matches the key).

10.

Q2(f). Compute: lim (x→2) (x² − 4x + 4)/(x² − 7x + 10).

Knowledge Note

If the numerator vanishes to a higher order, the limit is 0 — but only after cancelling the common factor.

Marks

3

Solution

x² − 4x + 4 = (x − 2)²; x² − 7x + 10 = (x − 2)(x − 5). Cancel one (x − 2): (x − 2)/(x − 5) → 0/(2 − 5) = 0. Boxed 0 (matches the key).

11.

Q2(g). Compute: lim (x→a) (√(3x) − √(2x + a))/(2(x − a)).

Knowledge Note

√A − √B forms: multiply by the conjugate (√A + √B); the difference of squares frees the (x − a) factor.

Marks

4

Solution

At x = a: √(3a) − √(3a) = 0 (0/0 form). Rationalise the numerator: √(3x) − √(2x + a) = [3x − (2x + a)]/[√(3x) + √(2x + a)] = (x − a)/[√(3x) + √(2x + a)]. Therefore the quotient = 1/{2[√(3x) + √(2x + a)]} (for x ≠ a). As x → a: 1/[2(√(3a) + √(3a))] = 1/(4√(3a)). Boxed 1/(4√(3a)) (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q2(g); book p465 = PDF p492; key book p466

12.

Q2(h). Compute: lim (x→a) (√(2x) − √(3x − a))/(√x − √a). [T.U. 2053 H]

Knowledge Note

Rationalise BOTH square-root differences; the (x − a) factors cancel and a minus sign survives.

Marks

5

Solution

Numerator: √(2x) − √(3x − a) = [2x − (3x − a)]/[√(2x) + √(3x − a)] = (a − x)/[√(2x) + √(3x − a)]. Denominator: √x − √a = (x − a)/[√x + √a]. Ratio = (a − x)(√x + √a)/[(x − a)(√(2x) + √(3x − a))] = −(√x + √a)/[√(2x) + √(3x − a)] (x ≠ a). As x → a: −(2√a)/(2√(2a)) = −√a/(√2·√a) = −1/√2. Boxed −1/√2 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q2(h); book p465 = PDF p492; key book p466

13.

Q2(i). Compute: lim (x→1) (√(2x) − √(3 − x²))/(x − 1).

Knowledge Note

After rationalising, x² + 2x − 3 = (x − 1)(x + 3) supplies the cancelling factor.

Marks

4

Solution

At x = 1: √2 − √2 = 0, and the denominator is 0 (0/0 form). Rationalise: √(2x) − √(3 − x²) = [2x − (3 − x²)]/[√(2x) + √(3 − x²)] = (x² + 2x − 3)/[√(2x) + √(3 − x²)] = (x − 1)(x + 3)/[√(2x) + √(3 − x²)]. Cancel (x − 1): limit = (1 + 3)/(√2 + √2) = 4/(2√2) = √2. Boxed √2 (matches the key).

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q2(i); book p465 = PDF p492; key book p466

Q2(j). Compute: lim (x→2) (√x − √(6 − x²))/(x − 2).

Knowledge Note

x − (6 − x²) = (x − 2)(x + 3): the conjugate frees a factor (x − 2).

Marks

4

Solution

0/0 at x = 2. Rationalise: √x − √(6 − x²) = [x − (6 − x²)]/[√x + √(6 − x²)] = (x² + x − 6)/[√x + √(6 − x²)] = (x − 2)(x + 3)/[√x + √(6 − x²)]. Cancel (x − 2): limit = (2 + 3)/(√2 + √2) = 5/(2√2). Boxed 5/(2√2) (matches the key).

15.

Q2(k). Compute: lim (x→64) (⁶√x − 2)/(³√x − 4).

Knowledge Note

Two different roots of the same x: substitute u = x^(1/6) to turn both into powers of one variable.

Marks

4

Solution

Put u = x^(1/6), so x = u⁶, ⁶√x = u and ³√x = x^(1/3) = u². As x → 64, u → 2. Quotient = (u − 2)/(u² − 4) = (u − 2)/[(u − 2)(u + 2)] = 1/(u + 2) (u ≠ 2) → 1/4. Boxed 1/4 (matches the key).

16.

Q2(l). Compute: lim (x→a) (√(3a − x) − √(x + a))/(4(x − a)).

Knowledge Note

The conjugate gives (3a − x) − (x + a) = −2(x − a), which cancels the (x − a) in the denominator.

Marks

4

Solution

At x = a the numerator is √(2a) − √(2a) = 0. Rationalise: [ (3a − x) − (x + a) ]/[√(3a − x) + √(x + a)] = (2a − 2x)/[√(3a − x) + √(x + a)] = −2(x − a)/[√(3a − x) + √(x + a)]. Divide by 4(x − a): −1/{2[√(3a − x) + √(x + a)]} → −1/[2(√(2a) + √(2a))] = −1/(4√(2a)). Boxed −1/(4√(2a)) (matches the key).

17.

Q3(a). Calculate: lim (x→∞) 2x²/(3x² + 2).

Knowledge Note

Limit at infinity of a rational function: divide by the highest power of x; only the leading coefficients survive.

Marks

2

Solution

Divide numerator and denominator by x²: 2/(3 + 2/x²). As x → ∞, 2/x² → 0, so the limit is 2/3. Boxed 2/3 (matches the key).

21.

Q4(a). Calculate: lim (x→∞) (√x − √(x − 3)).

Knowledge Note

∞ − ∞ form: rationalise. A fixed difference inside the roots gives 0 because the conjugate grows like 2√x.

Marks

3

Solution

Multiply by the conjugate: (x − (x − 3))/(√x + √(x − 3)) = 3/[√x + √(x − 3)]. As x → ∞ the denominator → ∞, so the quotient → 0. Boxed 0 (matches the key).

22.

Q4(b). Calculate: lim (x→∞) (√(x − a) − √(x − b)). [T.U. 2048 H]

Knowledge Note

Same argument for constants a, b: the numerator becomes the constant (b − a).

Marks

3

Solution

Conjugate: [(x − a) − (x − b)]/[√(x − a) + √(x − b)] = (b − a)/[√(x − a) + √(x − b)] → (b − a)/∞ = 0. Boxed 0 (matches the key).

23.

Q4(c). Calculate: lim (x→∞) (√(3x) − √(x − 5)).

Knowledge Note

Here the two square-root terms have different growth (√(3x) vs √x), so the difference diverges.

Marks

3

Solution

Conjugate: [(3x) − (x − 5)]/[√(3x) + √(x − 5)] = (2x + 5)/[√(3x) + √(x − 5)]. Divide top and bottom by √x: (2√x + 5/√x)/(√3 + √(1 − 5/x)) → (2√x)/√3 → ∞. Equivalently √(3x) − √x = (√3 − 1)√x → ∞. Boxed ∞ (matches the key; the printed note adds that an infinite limit means the limit does not exist).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q4(c); book p466 = PDF p493; key book p466

24.

Q4(d). Calculate: lim (x→∞) √x(√x − √(x − a)). [T.U. 2052]

Knowledge Note

√x·(√x − √(x − a)) = a√x/(√x + √(x − a)): divide by √x to see the a/2.

Marks

4

Solution

Inside: √x − √(x − a) = [x − (x − a)]/[√x + √(x − a)] = a/[√x + √(x − a)]. Multiply by √x: a√x/[√x + √(x − a)]. Divide numerator and denominator by √x: a/[1 + √(1 − a/x)] → a/(1 + 1) = a/2. Boxed a/2 (matches the key).

25.

Q4(e). Calculate: lim (x→∞) (√(x − a) − √(bx)).

Knowledge Note

With a coefficient b on the second root the growth rates differ: equality b = 1 is the only case that cancels.

Marks

4

Solution

Conjugate: [(x − a) − bx]/[√(x − a) + √(bx)] = [(1 − b)x − a]/[√(x − a) + √(bx)]. For b = 1 the numerator is the constant −a, so the quotient → 0. For b ≠ 1 divide by √x: [(1 − b)√x − a/√x]/[√(1 − a/x) + √b] → (1 − b)√x/(1 + √b). This is +∞ when 0 < b < 1, and −∞ when b > 1 (the printed key states ∞ for b ≠ 1 and reminds that an infinite limit means the limit does not exist). Boxed 0 if b = 1; ∞ (i.e. no finite limit) if b ≠ 1 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q4(e); book p466 = PDF p493; key book p466

26.

Q5(a). Evaluate: lim (x→2) (x − √(8 − x²))/(√(x² + 12) − 4).

Knowledge Note

Double rationalisation: each 0/0 difference of squares yields the same (x² − 4), which cancels.

Marks

5

Solution

At x = 2: (2 − 2)/(4 − 4) — 0/0 form. Numerator: x − √(8 − x²) = [x² − (8 − x²)]/[x + √(8 − x²)] = (2x² − 8)/[x + √(8 − x²)] = 2(x² − 4)/[x + √(8 − x²)]. Denominator: √(x² + 12) − 4 = [x² + 12 − 16]/[√(x² + 12) + 4] = (x² − 4)/[√(x² + 12) + 4]. Ratio = 2(x² − 4)/[x + √(8 − x²)] · [√(x² + 12) + 4]/(x² − 4) = 2[√(x² + 12) + 4]/[x + √(8 − x²)]. At x = 2: 2(4 + 4)/(2 + 2) = 16/4 = 4. Boxed 4 (matches the key).

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Ex 16.1 Q5(a); book p466 = PDF p493; key book p466

27.

Q5(b). Evaluate: lim (x→1) (x − √(2 − x²))/(2x − √(2 + 2x²)).

Knowledge Note

Both conjugates reduce to 2(x² − 1), so the factors cancel and the limit is the ratio of the remaining sums.

Marks

5

Solution

At x = 1: (1 − 1)/(2 − 2) — 0/0 form. Numerator: x − √(2 − x²) = [x² − (2 − x²)]/[x + √(2 − x²)] = (2x² − 2)/[x + √(2 − x²)] = 2(x² − 1)/[x + √(2 − x²)]. Denominator: 2x − √(2 + 2x²) = [4x² − (2 + 2x²)]/[2x + √(2 + 2x²)] = (2x² − 2)/[2x + √(2 + 2x²)] = 2(x² − 1)/[2x + √(2 + 2x²)]. Ratio = [2(x² − 1)/(x + √(2 − x²))] · [(2x + √(2 + 2x²))/(2(x² − 1))] = (2x + √(2 + 2x²))/(x + √(2 − x²)). At x = 1: (2 + 2)/(1 + 1) = 4/2 = 2. Boxed 2 (matches the key).
