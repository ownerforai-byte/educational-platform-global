1.

Q1(i). Find, from definition, the derivative of 3x².

Knowledge Note

Definition of the derivative: f'(x) = lim(h→0) [f(x+h) − f(x)]/h. Expand, cancel the h, then let h→0.

Marks

3

Solution

f(x+h) − f(x) = 3(x+h)² − 3x² = 3(x²+2xh+h²) − 3x² = 6xh + 3h². Divide by h: 6x + 3h. Let h→0: f'(x) = 6x. Boxed 6x (matches the printed key, book p510).

Q1(vi). Find, from definition, the derivative of 3/(2x²).

Knowledge Note

Q8(ix). Use implicit differentiation to obtain dy/dx for x²y² = x² + y². (T.U. 2049)

Knowledge Note

x²y² = x² + y²: 2xy² + 2x²yy' = 2x + 2yy'; factor x(1−y²) over y(x²−1).

Marks

4

Solution

2xy² + 2x²yy' = 2x + 2yy' → y'(2x²y − 2y) = 2x − 2xy² → y' = (x − xy²)/(x²y − y) = x(1 − y²)/[y(x² − 1)]. Boxed x(1−y²)/(y(x²−1)) (matches the printed key, book p511).

Q9(i). Differentiate x⁶ w.r.t. x².

Knowledge Note

d(u)/d(v) = (du/dx)/(dv/dx) — differentiate both w.r.t. x, then divide.

Solution

d(x⁶)/dx = 6x⁵; d(x²)/dx = 2x. Ratio = 6x⁵/(2x) = 3x⁴. Boxed 3x⁴ (matches the printed key, book p511).

77.

Q9(iv). Differentiate (5x − 1)⁶ w.r.t. (x + 1)².

Knowledge Note

d(x+1)²/dx = 2(x+1) gives the denominator; 30(5x−1)⁵/2(x+1) reduces to 15(5x−1)⁵/(x+1).

3

Solution

d(5x−1)⁶/dx = 30(5x−1)⁵; d(x+1)²/dx = 2(x+1). Ratio = 30(5x−1)⁵/[2(x+1)] = 15(5x−1)⁵/(x+1). Boxed 15(5x−1)⁵/(x+1) (matches the printed key, book p511).
