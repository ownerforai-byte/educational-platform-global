1.

Q1(i). Examine whether the function f(x) = 15x^2 - 14x + 1 is increasing or decreasing at x = 2/5 and x = 5/2.

Knowledge Note

Sign of f' at the point decides it: f' = 30x - 14 is negative at x = 2/5 and positive at x = 5/2.

Marks

3

Solution

A differentiable function increases at a point when f'(x) > 0 there and decreases when f'(x) < 0. f'(x) = 30x - 14. At x = 2/5: f'(2/5) = 30(2/5) - 14 = 12 - 14 = -2 < 0, so f is decreasing at x = 2/5. At x = 5/2: f'(5/2) = 30(5/2) - 14 = 75 - 14 = 61 > 0, so f is increasing at x = 5/2. Boxed decreasing at 2/5, increasing at 5/2 (printed key p551: 'Decreasing at x = 2/5 and increasing at x = 5/2').

Knowledge Note

f' = 4(x-1) has a single zero at x = 1; to the right of it the parabola 2x^2-4x+3 rises.

Q2(ii). Examine whether the function f(x) = 16x - (4/3)x^3 is increasing or decreasing on the interval (-infinity, -2).

Knowledge Note

f' = 4(4 - x^2) is negative exactly when |x| > 2; the interval (-inf, -2) lies in that region.

Marks

3

Solution

f'(x) = 16 - 4x^2 = 4(4 - x^2) = 4(2 - x)(2 + x). For x < -2 both factors (2 - x) and (2 + x) are positive and negative respectively: 2 - x > 0 and 2 + x < 0, so f'(x) < 0 throughout (-infinity, -2). Hence f is decreasing there. Boxed decreasing (printed key p551: 'Decreasing').

Q2(iii). Show that the function f(x) = -x^3 + 6x^2 - 13x + 20 is decreasing for all x in R.

Knowledge Note

Complete the square inside the bracket: 3x^2-12x+13 = 3(x-2)^2+1 > 0 always, so f' < 0 identically.

Solution

f'(x) = -3x^2 + 12x - 13 = -[3x^2 - 12x + 13] = -[3(x - 2)^2 + 1]. The bracket is at least 1 for every real x, so f'(x) <= -1 < 0 for all x. Hence f is strictly decreasing on R. Boxed (no separate key entry: 'show that').

Q2(iv). Show that the function f(x) = 4x - 9/x + 6 is increasing for all x in R except at x = 0.

Knowledge Note

f' = 4 + 9/x^2 is always positive; the excluded point x = 0 is simply outside the domain, not a sign change.

Marks

3

Solution

The function is defined only for x != 0. f'(x) = 4 + 9/x^2. Since 9/x^2 > 0 for every x != 0, f'(x) > 4 > 0 on each of the intervals (-infinity, 0) and (0, infinity). Hence f is increasing on both branches; at x = 0 the function has no value (vertical asymptote). Boxed (no separate key entry: 'show that').

Q5(i). Find the local maxima and minima and points of inflection of f(x) = 3x^2 - 6x + 3.

Knowledge Note

Quadratic: f'' is a nonzero constant, so the single stationary point is a minimum and no inflection exists.

Marks

5

Solution

f'(x) = 6x - 6 = 0 gives x = 1. f''(x) = 6 > 0 at every point, so x = 1 is a local minimum, and the value there is f(1) = 3 - 6 + 3 = 0. A point of inflection needs f''(x) = 0 with a sign change of f''; here f'' = 6 never vanishes, so there is no point of inflection. Boxed minimum value 0 at x = 1, no point of inflection (printed key p551).

Let the sides be x and y with 2(x + y) = 144, so x + y = 72 and y = 72 - x. The area is A(x) = x(72 - x) = 72x - x^2, 0 < x < 72. A'(x) = 72 - 2x = 0 gives x = 36, and A''(x) = -2 < 0, so this is a maximum. Then y = 36 and A = 36 * 36 = 1296. Boxed maximum area 1296 sq. m (printed key p552).

Q9. Show that the rectangle of largest possible area, for a given perimeter, is a square. (HSEB 2058)

Q10. A window is in the form of a rectangle surmounted by a semi-circle. If the total perimeter is 9 metres, find the radius of the semi-circle for the greatest window area. (HSEB 2055)

Knowledge Note

Perimeter 2h + 2r + pi r = 9; substituting h turns A into a quadratic in r, and A' = 9 - (4 + pi)r gives r = 9/(4+pi).

Marks

5

Solution

Let the semi-circle have radius r, so the rectangle has width 2r and height h. The perimeter is the two vertical sides, the base, and the semi-circular arc: 2h + 2r + pi r = 9, so h = (9 - 2r - pi r)/2. Area = rectangle + semi-circle = 2rh + (1/2)pi r^2 = 2r (9 - 2r - pi r)/2 + (1/2)pi r^2 = 9r - (2 + pi)r^2 + (pi/2)r^2 = 9r - (2 + pi/2)r^2. Then A'(r) = 9 - (4 + pi)r = 0, giving r = 9/(4 + pi). A''(r) = -(4 + pi) < 0, so this is a maximum (h = (9 - (2 + pi) 9/(4 + pi))/2 > 0, so the window is geometrically possible). Boxed r = 9/(4 + pi) metres (printed key p552: 9/(4 + pi) metres).

Q11. A closed cylindrical can is to be made so that its volume is 52 cm^3. Find its dimensions if the surface is to be a minimum.

Knowledge Note

S = 2 pi r^2 + 104/r; S' = 0 gives r^3 = 26/pi and the volume condition then forces h = 2r.

Marks

5

Solution

Let the radius be r and height h. Volume: pi r^2 h = 52, so h = 52/(pi r^2). The total surface of a closed can is S = 2 pi r^2 + 2 pi r h = 2 pi r^2 + 104/r. Then S'(r) = 4 pi r - 104/r^2 = 0 gives 4 pi r^3 = 104, i.e. r^3 = 26/pi, so r = (26/pi)^(1/3). S''(r) = 4 pi + 208/r^3 > 0, so this is a minimum. The height is h = 52/(pi r^2); using pi r^3 = 26 we get pi r^2 = 26/r, hence h = 52/(26/r) = 2r. Boxed radius (26/pi)^(1/3) cm with height = 2 radius (printed key p552: 'height = 2 radius where radius = (26/pi)^(1/3)').

Q12. A gardener having 120 m of fencing wishes to enclose a rectangular plot of land and also to erect a fence across the land parallel to two of the sides. Find the maximum area he can enclose.

Knowledge Note

Three parallel fences of length y plus two of length x: 2x + 3y = 120; maximising xy gives x = 30, y = 20.

Marks

5

Solution

Let the plot be x by y with the dividing fence parallel to the sides of length y. The fencing used is 2x + 3y = 120, so y = (120 - 2x)/3. Area A(x) = xy = x(120 - 2x)/3 = (120x - 2x^2)/3. A'(x) = (120 - 4x)/3 = 0 gives x = 30, hence y = (120 - 60)/3 = 20. A''(x) = -4/3 < 0, so it is a maximum. A = 30 * 20 = 600. Boxed 600 sq. m (printed key p552: 600 m^2).

Q13. Find two numbers whose sum is 10 and the sum of whose squares is minimum.

S = x^2 + (10-x)^2 is a convex quadratic with vertex at x = 5; equal halves minimise the sum of squares.

Solution
