1.

Q1. Define the continuity of a function at a point, give an example of a continuous function at a point, and say whether f(x) = 1/(1 − x) is continuous at x = 1. [T.U. 2048]

Knowledge Note

A rational function is continuous wherever its denominator is non-zero; a pole always breaks continuity.

Marks

3

Solution

Definition. f is continuous at x = a if (i) f(a) is defined, (ii) lim (x→a) f(x) exists, and (iii) lim (x→a) f(x) = f(a). Example. f(x) = x² at a = 2: f(2) = 4, the limit is 4, and the two agree, so f is continuous there. For f(x) = 1/(1 − x) at x = 1: f(1) = 1/0 is not defined and the one-sided limits are +∞ (from the left) and −∞ (from the right), so f is not continuous at x = 1. Boxed No (matches the printed key, book p486).

Q2. When is f(x) said to be continuous at x = a? Discuss the continuity of f(x) = x² + 2 for x ≤ 5 and f(x) = 3x + 12 for x > 5 at x = 5. (HSEB 2054)

Knowledge Note

Two branches meeting at the same value = continuity, even if the formula changes.

Marks

3

Solution

Condition: f is continuous at x = a iff f(a) is defined, lim (x→a) f(x) exists, and the two are equal. Here f(5) = 25 + 2 = 27; left limit 27; right limit 3(5) + 12 = 27. All equal, so f is continuous at x = 5. Boxed continuous (matches the key).

Q3(i). At what points is f(x) = (x + 1)/[(x − 2)(x − 3)] discontinuous?

Knowledge Note

Discontinuities of a rational function are exactly the zeros of its denominator (where the numerator stays finite).

Marks

3

Solution

The denominator vanishes when x − 2 = 0 or x − 3 = 0, i.e. x = 2 and x = 3. At each of these the numerator is non-zero (3 and 4), so the function has a vertical asymptote and no finite value. Hence f is discontinuous at x = 2 and x = 3. Boxed 2 and 3 (matches the key).

4.

Q3(ii). At what points is f(x) = (x + 1)/[(x − 2)(x − 3)] continuous?

Knowledge Note

Everywhere else the denominator is non-zero, so the quotient of continuous functions is continuous.

Marks

2

Solution

For every x other than 2 and 3 the denominator is non-zero; a quotient of continuous functions with non-zero denominator is continuous. Hence f is continuous at all real x except x = 2 and x = 3. Boxed continuous at all points except x = 2 and x = 3 (matches the key).

5.

Q4. Discuss the continuity of f(x) at x = 0, where f(x) = x for x > 0, f(x) = 1 for x = 0 and f(x) = −x for x < 0.

Knowledge Note

A V-shaped function with the apex value moved off the limit: common limit 0 but value 1.

Marks

3

Solution

Right limit: x → 0. Left limit: −x → 0. So lim (x→0) f(x) = 0, but f(0) = 1. Since limit ≠ value, f is discontinuous at x = 0 (a removable discontinuity; f becomes continuous if f(0) is redefined as 0). Boxed discontinuous (matches the key).

Q5. f(x) = 2x + 1 for x < 1, 2 for x = 1, 3x for x > 1. Calculate the left-hand and right-hand limits at x = 1. Is f continuous at x = 1? (HSEB 2051)

Knowledge Note

Compute both one-sided limits first, then compare with the printed value — the answer needs all three numbers.

Marks

3

Solution

LHL: 2(1) + 1 = 3. RHL: 3(1) = 3. The limit is 3, but f(1) = 2 ≠ 3, so f is not continuous at x = 1. Boxed 3, 3, No (matches the key).

Q6. f(x) = 2 − x² for x < 2, 3 for x = 2, x − 4 for x > 2. Verify that the limit exists at x = 2. Is f continuous there? If not, how can it be made continuous? (T.U. 2050)

Knowledge Note

Here the branches agree (limit −2) but the printed value is 3: removable, repaired by setting f(2) = −2.

Marks

4

Solution

LHL: 2 − 4 = −2. RHL: 2 − 4 = −2. The limit exists and equals −2, but f(2) = 3 ≠ −2, so f is not continuous at x = 2. It becomes continuous on redefining f(2) = −2. Boxed No, because lim (x→2) f(x) ≠ f(2); redefine f(2) = −2 (matches the key).

Q7. f(x) = (x² − x − 6)/(x² − 2x − 3) for x ≠ 3, f(x) = 5/3 at x = 3. Prove that f is discontinuous at x = 3. Can the definition at x = 3 be modified to make it continuous?

Knowledge Note

A 0/0 rational function: factor top and bottom, cancel, then compare the limit with the assigned value.

Marks

4

Solution

Factor: x² − x − 6 = (x − 3)(x + 2) and x² − 2x − 3 = (x − 3)(x + 1). For x ≠ 3, f(x) = (x + 2)/(x + 1), so lim (x→3) f(x) = 5/4. But f(3) = 5/3 ≠ 5/4, so f is discontinuous at x = 3. Since the limit exists, the discontinuity is removable: defining f(3) = 5/4 makes f continuous there. Boxed Yes, by defining f(3) = 5/4 (matches the key).

Q8(i). f(x) = 1/2 + x for 0 < x < 1/2, 1/2 at x = 1/2, 3/2 − x for 1/2 < x < 1. Show that f has a removable discontinuity at x = 1/2.

Knowledge Note

Removable discontinuity: both branches meet (limit 1) but the assigned value 1/2 sits below the gap.

Marks

4

Solution

LHL: 1/2 + 1/2 = 1. RHL: 3/2 − 1/2 = 1. The limit is 1, but f(1/2) = 1/2 ≠ 1. A discontinuity whose two-sided limit exists is removable (fill the point with 1). ∎

10.

Q8(ii). f(x) = x² for 0 < x < 1, x for 1 ≤ x < 2, (1/4)x³ for 2 ≤ x < 3. Show that f is continuous at x = 1 and x = 2.

Knowledge Note

Piecewise continuity at a join: match the two formulas at the junction point.

Marks

5

Solution

At x = 1: f(1) = 1 (middle branch); left limit x² → 1; right limit x → 1. All equal → continuous. At x = 2: f(2) = (1/4)(2)³ = 2 (third branch); left limit x → 2; right limit (1/4)x³ → 2. All equal → continuous. ∎

11.

Q8(iii). f(x) = 3 + 2x for −3/2 ≤ x < 0, 3 − 2x for 0 ≤ x < 3/2, −3 − 2x for x ≥ 3/2. Show that f is continuous at x = 0 but discontinuous at x = 3/2. (HSEB 2056)

Knowledge Note

One branch continuous, the other jumping: check each join independently.

Marks

5

Solution

At x = 0: f(0) = 3 − 0 = 3; left limit 3 + 0 = 3; right limit 3 − 0 = 3 → continuous. At x = 3/2: f(3/2) = −3 − 3 = −6 (third branch); left limit 3 − 2(3/2) = 0; right limit −3 − 2(3/2) = −6. Since the left limit 0 ≠ f(3/2) = −6, the limit does not exist and f is discontinuous at x = 3/2. ∎

12.

Q8(iv). f(x) = 1 for x > 0, 0 for x = 0, −1 for x < 0. Show that f is discontinuous at x = 0.

Knowledge Note

The sign function: a jump discontinuity with one-sided limits +1 and −1.

Marks

3

Solution

Right limit: 1. Left limit: −1. Since the one-sided limits differ, lim (x→0) f(x) does not exist, so f cannot be continuous at x = 0. ∎

Q10. Let f(x) = 2x (x < 2), 2 (x = 2), x² (x > 2). Show that f has a removable discontinuity at x = 2. [Hint: removable iff lim (x→2⁻) f = lim (x→2⁺) f ≠ f(2).]

Knowledge Note

The hint is the definition: equal one-sided limits that differ from the value = removable.

Marks

4

Solution

Left limit: 2(2) = 4. Right limit: 2² = 4. So lim (x→2) f(x) = 4, while f(2) = 2. The one-sided limits are equal but differ from the value, hence the discontinuity at x = 2 is removable (repair by setting f(2) = 4). ∎

18.

Q11. What condition is necessary for f(x) to be continuous at x = a? Under what conditions is f discontinuous at x = a?

Knowledge Note

Continuity needs three things at once; failing any one of them produces a discontinuity type.

Marks

5

Solution

Necessary and sufficient conditions: (i) f(a) is defined; (ii) lim (x→a) f(x) exists, i.e. lim (x→a⁻) f(x) = lim (x→a⁺) f(x) = L; (iii) L = f(a). f is discontinuous at x = a when any one fails: (a) f(a) undefined — e.g. 1/(x − 1) at x = 1 (infinite discontinuity); (b) the one-sided limits differ — e.g. |x|/x at 0 (jump discontinuity); (c) the limit exists but differs from f(a) — e.g. Q10 above (removable discontinuity).

Q12. f(x) = 1 when x ≠ 0, f(x) = 2 when x = 0. Find lim (x→0) f(x) if it exists. Is f continuous at x = 0?

Knowledge Note

Constant function with one moved point: the limit is 1 everywhere, the value at 0 is 2.

Marks

3

Solution

For x ≠ 0 the function equals 1, so both one-sided limits are 1 and lim (x→0) f(x) = 1. But f(0) = 2 ≠ 1, so f is not continuous at x = 0 (removable discontinuity). Boxed 1 (matches the key).

21.

Q13(ii). Find the points of discontinuity of f(x) = (3x − 1)/(x³ − 5x² + 6x).

Knowledge Note

Factor the cubic denominator into its three linear roots.

Marks

3

Solution

Factor: x³ − 5x² + 6x = x(x² − 5x + 6) = x(x − 2)(x − 3). The denominator vanishes at x = 0, 2, 3, and at each the numerator 3x − 1 is non-zero (−1, 5, 8). Hence f is discontinuous at x = 0, 2, 3. Boxed x = 0, 2, 3 (matches the key).
