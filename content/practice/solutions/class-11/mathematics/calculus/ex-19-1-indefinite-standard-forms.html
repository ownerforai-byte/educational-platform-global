1.

Q1(i). Find the indefinite integral: integral of 5x^3 dx.

Knowledge Note

Power rule plus constant multiple: 5x^3 integrates to (5/4)x^4; the +c records the family of antiderivatives.

Marks

2

Solution

Use the power rule integral of x^n dx = x^(n+1)/(n+1) + c for n = 3, then the constant multiple rule: integral 5x^3 dx = 5 * x^4/4 + c = (5/4)x^4 + c. Check by differentiating: d/dx[(5/4)x^4] = (5/4)(4x^3) = 5x^3. Boxed (5/4)x^4 + c (printed key p571).

2.

Q1(ii). Find the indefinite integral: integral of 7x^(5/2) dx.

Knowledge Note

n + 1 = 7/2, so the reciprocal factor is 2/7 and the 7 cancels it exactly.

Marks

2

Solution

Power rule with n = 5/2: integral x^(5/2) dx = x^(7/2)/(7/2) = (2/7)x^(7/2). Multiplying by 7: 7 (2/7)x^(7/2) + c = 2x^(7/2) + c. Check: d/dx[2x^(7/2)] = 2 (7/2)x^(5/2) = 7x^(5/2). Boxed (printed key p571: 2x^(7/2) + c).

3.

Q1(iii). Find the indefinite integral: integral of 2x^(-7/2) dx.

Knowledge Note

Negative exponent: divide by -5/2, i.e. multiply by -2/5, then by the coefficient 2.

Marks

2

Solution

Here n = -7/2, so n + 1 = -5/2 and integral x^(-7/2) dx = x^(-5/2)/(-5/2) = -(2/5)x^(-5/2). Hence 2 * (-(2/5))x^(-5/2) + c = -(4/5)x^(-5/2) + c. Check: d/dx[-(4/5)x^(-5/2)] = -(4/5)(-5/2)x^(-7/2) = 2x^(-7/2). Boxed (printed key p571).

Q2(v). Find the indefinite integral: integral of (x^2 - 1/x^2) dx.

Knowledge Note
