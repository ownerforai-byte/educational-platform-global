1.

Q1. Prove that lim (x→−2/3) 2/(2 + 3x) does not exist.

Knowledge Note

For a finite limit at a the function must stay bounded near a; 2/(2 + 3x) blows up as x → −2/3.

Marks

4

Solution

At x = −2/3 the denominator 2 + 3x = 0, so the expression is undefined there. Approach from the right: x = −2/3 + h with h → 0⁺ gives 2 + 3x = 3h → 0⁺, so 2/(3h) → +∞. Approach from the left: x = −2/3 − h gives 2 + 3x = −3h → 0⁻, so 2/(−3h) → −∞. The one-sided limits are not finite and not equal, hence the limit does not exist. ∎

Source

4.

Q3. What is meant by the left-hand and right-hand limit of a function? State the condition for the limit to exist at a point. Prove that lim (x→0) |x| = 0 but lim (x→0) |x|/x does not exist.

Knowledge Note

LHL is the value approached through x < a, RHL through x > a; the limit exists iff both exist and are equal.

Marks

5

Solution

Definitions. lim (x→a⁻) f(x) = L means f(x) can be made arbitrarily close to L by taking x < a close enough to a; lim (x→a⁺) f(x) = M is the same with x > a. The two-sided limit exists iff both one-sided limits exist and are equal: lim (x→a) f(x) = L ⇔ lim (x→a⁻) f(x) = lim (x→a⁺) f(x) = L. Proof 1: for x > 0, |x| = x → 0; for x < 0, |x| = −x → 0. Both one-sided limits are 0, so lim (x→0) |x| = 0. Proof 2: for x > 0, |x|/x = 1, so the right limit is 1; for x < 0, |x|/x = −1, so the left limit is −1. Since 1 ≠ −1, the limit does not exist. ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Additional Questions (Limits) Q3; book p484 = PDF p511

5.

Q4. Distinguish between the limit and the value of a function at a point. Given f(x) = (ax + b)/(x + 1), lim (x→0) f(x) = 2 and lim (x→∞) f(x) = 1, prove that f(−2) = 0.

Knowledge Note

The value f(a) is what the function assigns at a; the limit is what it approaches. They can differ (removable discontinuity).

Marks

5

Solution

Distinction. lim (x→a) f(x) describes the behaviour of f near a and ignores f(a) itself (f need not even be defined at a); f(a) is the single assigned value. A function is continuous at a exactly when the two coincide. Now lim (x→0) (ax + b)/(x + 1) = (0 + b)/(0 + 1) = b = 2, so b = 2. And lim (x→∞) (ax + b)/(x + 1) = a (ratio of the leading coefficients) = 1, so a = 1. Then f(x) = (x + 2)/(x + 1) and f(−2) = (−2 + 2)/(−2 + 1) = 0/(−1) = 0. ∎

Source

Sukunda Basic Mathematics Grade XI, Ch.16 Additional Questions (Limits) Q4; book p484 = PDF p511

Q5. Define the limit of a function at a point. Given f(x) = (x + 6)/(cx − d), lim (x→0) f(x) = −6 and lim (x→∞) f(x) = 1/3, prove that f(13) = 1/2.

Knowledge Note

Two limits pin the two constants: the limit at 0 gives one equation, the limit at infinity the other.

Marks

5

Solution

Definition. L = lim (x→a) f(x) if for every ε > 0 there is δ > 0 such that 0 < |x − a| < δ ⇒ |f(x) − L| < ε. At x → 0: (x + 6)/(cx − d) → 6/(−d) = −6/d, so −6/d = −6 ⇒ d = 1. At x → ∞ the quotient tends to the ratio of leading coefficients, 1/c, so 1/c = 1/3 ⇒ c = 3. Hence f(x) = (x + 6)/(3x − 1) and f(13) = (13 + 6)/(39 − 1) = 19/38 = 1/2. ∎

Source

7.

Q6. What is an indeterminate form? State their different forms. Evaluate lim (x→∞) √x(√x − √(x − a)). [T.U. 2052]

Knowledge Note

Indeterminate forms 0/0, ∞/∞, ∞−∞, 0·∞, 0⁰, 1^∞, ∞⁰ need algebraic rewriting; here a conjugate removes ∞−∞.

Marks

4

Solution

An indeterminate form is an expression whose limiting value cannot be read off from the limits of its parts — the answer depends on how the parts approach their limits. The seven standard forms are 0/0, ∞/∞, 0·∞, ∞ − ∞, 0⁰, 1^∞ and ∞⁰. Evaluation: √x − √(x − a) = [(x) − (x − a)]/[√x + √(x − a)] = a/[√x + √(x − a)], an ∞ − ∞ form removed by the conjugate. Multiply by √x: a√x/[√x + √(x − a)]. Divide top and bottom by √x: a/[1 + √(1 − a/x)] → a/(1 + 1) = a/2. Boxed a/2 (matches the key).

Q7. Let f: R → R be defined by f(x) = x if x is an integer, f(x) = 0 if x is not an integer. Find lim (x→1) f(x). Is it the same as f(1)?

Knowledge Note

A function can be continuous nowhere yet still have a limit at a point where the nearby non-integer values all give 0.

Marks

4

Solution

Approach x = 1 through non-integers: then f(x) = 0 for every such x, so the limit along that path is 0. Approach through integers: the only integer arbitrarily close to 1 is 1 itself, so this does not produce other values and the two-sided limit is 0. Hence lim (x→1) f(x) = 0. But f(1) = 1 (1 is an integer). Since 0 ≠ 1, the limit is not the same as the value — f is discontinuous at x = 1. Boxed 0, No (matches the key).

Source

Solution

Since log e = 1, write log x − 1 = log(x/e). Put x = e(1 + h), so x − e = eh and h → 0. Then log(x/e) = log(1 + h), and the quotient = log(1 + h)/(eh) = (1/e)·[log(1 + h)/h] → (1/e)·1 = 1/e. Boxed 1/e (matches the key).
