Notes

  • The applications are the reason the law is taught. You invent an Amperian path that follows the suspected field, write B times the length if B is constant, and set that equal to μ0 I_enclosed.
  • Outside a long straight wire the path is a circle and the whole current is enclosed. Inside a uniform cylindrical wire, at radius r smaller than the wire, only the current in the inner cross-section is enclosed, so I_enc = I (r^2/R^2).
  • That inner result makes B proportional to r inside the wire and proportional to 1/r outside. The two formulas meet at the surface.
  • A toroid uses a circular path inside the doughnut. The enclosed current is N I if the path threads all N turns. The circumference 2π r then gives B = μ0 N I /(2π r).
  • A path that threads no current, such as a circle outside a toroid, gives zero line integral. With the symmetry, B itself is zero there in the ideal case.
  • This is a different use from the solenoid card: here the worked case is the inside of a thick wire, not the solenoid interior.

Key Points

  • Same law, applied.
  • The path is chosen, not measured.
  • A thick wire needs the current inside radius r only.
  • The toroid is the curved solenoid.

Summary

Ampere's law is applied by a path that matches the symmetry. Inside a uniform wire only the inner share of the current counts and B grows with r. A toroid's field is μ0 N I over the circular circumference, and an ideal toroid has no field on a path that encloses nothing.

Exercises

1.

A uniform long wire of radius 2.0 mm carries 8.0 A. Find B at 1.0 mm from the axis. Use μ0 / 2π = 2.0 × 10^−7.

Steps
  • The point is inside, so I_enc = I (r^2/R^2).
  • r/R = 1/2, so (r/R)^2 = 1/4 and I_enc = 2.0 A.
  • B = (μ0 / 2π) I_enc / r.
  • r = 1.0 × 10^−3 m.
  • B = 2.0 × 10^−7 × 2.0 / 1.0 × 10^−3 = 4.0 × 10^−4 T.
Answer

4.0 × 10^−4 T.
