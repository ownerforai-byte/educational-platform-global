Notes

  • 1. Topic Introduction — The Repairable Break

    A removable discontinuity is a break the limit ignores: the two-sided limit exists but f(a) is missing or mismatched. The repair is always the same — define or redefine f(a) to equal the limit.

  • 2. Fundamental Concepts

    2.1 Definition and detection

    • Removable at a ⟺ lim_{x→a} f(x) = L exists (finite) but f(a) ≠ L or f(a) is undefined.
    • Detection protocol: substitute (get 0/0 or undefined), compute the limit by transformation, compare with f(a).

    2.2 The two species

    • Hole: f(a) undefined, limit exists — (x²−4)/(x−2) at 2 with limit 4.
    • Mismatch: f(a) defined but ≠ limit — the redefined-point case (f(1) = 3 vs limit 2).

    2.3 The repair theorem

    • Theorem: defining (or redefining) f(a) = L makes f continuous at a — the discontinuity was removable precisely because one value fixes it.
    • After repair, the function is continuous; before repair, the graph shows an isolated open dot (hole) or a detached dot (mismatch).

    2.4 Common sources

    • Rational functions with cancelled common factors: (x²−9)/(x−3) → hole at 3 with limit 6.
    • Piecewise definitions with a deliberately wrong middle value.
    • Roots of numerators shared with denominators — the factor-and-cancel signature.

  • 4. Detailed Explanation

    4.1 Why "removable"

    • The defect lives at a single point and the limit already knows the correct value: plugging it in removes the break entirely. Jumps and blow-ups need infinitely many point-changes or none works — they are not removable.

    4.2 The graph signature

    • A hole is an open dot on an otherwise continuous curve; a mismatch adds a closed dot floating elsewhere. Both are single-point defects — the visual fingerprint of removability.

    4.3 Simplification caution

    • Cancelling (x − a) changes the domain: the simplified expression is continuous at a but the original is not — always state the x ≠ a licence and report the hole.

  • 6. Common Confusions

    Cancelled ≠ continuous: the cancellation proves the limit, not the original function's continuity — the domain shrank.

  • Removable needs a finite limit: an infinite limit at a is an infinite discontinuity, never removable.
  • Hole location: the hole sits at (a, L) — at the limit's height, not at f(a)'s (which doesn't exist).

  • 7. Exam Application

    NEB-style (3m): Find the point of discontinuity of f(x) = (x² − 9)/(x − 3), classify it, and state the repair. — Domain: x ≠ 3. Limit: factor (x−3)(x+3)/(x−3) = x + 3 (x ≠ 3) ⟹ lim_{x→3} = 6. Classification: f(3) undefined with the limit existing ⟹ removable discontinuity (hole) at (3, 6). Repair: define f(3) = 6; the repaired f equals x + 3 everywhere and is continuous on ℝ.

  • NEB-style (2m): For f(x) = (x² + x − 6)/(x − 2), find lim_{x→2} f(x) and the removable break. — Factor: (x + 3)(x − 2)/(x − 2) = x + 3 (x ≠ 2) ⟹ limit 5. f(2) undefined ⟹ removable hole at (2, 5); repair f(2) = 5.
  • NEB-style (2m): f(x) = (x + 2)/(x² − 4) at x = −2: removable or not? — Factor denominator: (x + 2)/[(x−2)(x+2)] = 1/(x − 2) for x ≠ −2, ±... for x ≠ ±2. Limit as x → −2: 1/(−2 − 2) = −1/4 — finite! So x = −2 is removable (hole at (−2, −1/4)); repair f(−2) = −1/4. But at x = 2 the simplified 1/(x−2) blows up ⟹ x = 2 is an infinite (non-removable) discontinuity. One function, two species — triage each point separately.

  • 8. Deep Conceptual — Removability Is a Statement About the Neighbourhood

    • A removable break means the neighbourhood is healthy — both sides approach one value — and only the point itself is sick (missing or wrong). The graph is a curve with a hole (or a relocated dot), not a torn curve.
    • Why the repair is legitimate: redefining f(a) = L changes the function at exactly one point, and limits are blind to single points — so the limit is untouched, and the new value matches it. The repair costs nothing dynamically; every limit, and later every derivative, is unchanged.
    • The two sub-species: the hole (f(a) undefined — the formula excludes a) and the mismatch (f(a) defined but ≠ L — an assigned value disagreeing with the approach). Same cure, different pictures: open dot vs detached dot.

  • 9. Deep Conceptual — Removable Breaks as Simplification Shadows

    • Most removable breaks are created by cancellation: f(x) = (x−2)·g(x)/(x−2) is really g(x) wearing a disguise that breaks at 2. The 0/0 form at a is the signature of this hidden common factor.
    • The limit sees through the disguise: because the definition ignores x = a, the cancelled and uncancelled forms have identical limits — the removable break is invisible to every limit question and visible only to continuity and value questions.
    • Design lesson: when a problem assigns a value at a formula's excluded point, it is usually asking you to either diagnose the mismatch (continuity) or supply the matching value (repair). The assigned value is the exam's handle on an otherwise invisible point.

  • 10. Deep Conceptual — Removable vs Non-Removable: The Repair Test as Classification

    • The single diagnostic question — can redefining finitely many point-values make f continuous? — splits all discontinuities into removable (yes) and non-removable (no). It is the cleanest classification boundary in the taxonomy.
    • Why jumps fail the test: a jump's sickness is in the neighbourhood (sides disagree), which no point-value edit touches — you would need to change the function on an entire side. Infinite and oscillatory breaks fail even more thoroughly.
    • The repair test foreshadows derivatives: |x| at 0 is continuous but non-differentiable, and no value edit fixes the corner — the analogous "removability" question for slopes. Calculus iterates the same architecture one level up: neighbourhood agreement, then point agreement.

Universal Facts

  • Sensor dropouts are removable glitches: the trend (limit) is known, the missing sample (value) is interpolated - repair by redefinition.

Examples

Practice Questions

  • NEB-style (3m): Find and classify the discontinuity of f(x) = (x² − 9)/(x − 3), then state the repair. — Domain: x ≠ 3 (the denominator ban). Limit: factor the numerator: (x − 3)(x + 3)/(x − 3) = x + 3 for x ≠ 3 — the cancellation is licensed by the punctured neighbourhood. Hence lim_{x→3} f(x) = 3 + 3 = 6. Classification: f(3) is undefined while the limit exists ⟹ a removable discontinuity — specifically a hole at the point (3, 6) (open dot at the limit's height). Repair: define f(3) = 6; the repaired function agrees with x + 3 on all of ℝ and is continuous everywhere. Caution stated: the cancellation changed the domain — the original f, not x + 3, is the function under discussion, and the hole is part of its graph.
  • NEB-style (2m): Find lim_{x→2} (x² + x − 6)/(x − 2) and describe the removable break. — Substitution: (4 + 2 − 6)/0 = 0/0 ⟹ transform. Factor: x² + x − 6 = (x + 3)(x − 2), so the expression = (x + 3)(x − 2)/(x − 2) = x + 3 for x ≠ 2. Limit: 2 + 3 = 5. Break: f(2) undefined with limit 5 ⟹ removable hole at (2, 5); the repair f(2) = 5 restores continuity. The factor-and-cancel signature — a shared linear factor — is the universal birthplace of removable rational breaks.
  • NEB-style (3m): Triage f(x) = (x + 2)/(x² − 4) at each point of discontinuity. — Suspicious points: zeros of x² − 4 = (x − 2)(x + 2), i.e. x = 2 and x = −2 — triage each separately. At x = −2: cancel the common factor: f(x) = 1/(x − 2) for x ≠ ±2; lim_{x→−2} f(x) = 1/(−4) = −1/4 — finite ⟹ removable (hole at (−2, −1/4)); repair f(−2) = −1/4. At x = 2: the simplified form 1/(x − 2) has numerator 1 ≠ 0 with denominator → 0 ⟹ blow-up: lim_{x→2⁺} = +∞, lim_{x→2⁻} = −∞ ⟹ infinite discontinuity — not removable. Verdict: one function, two species — the cancelled factor's zero is always the removable candidate; the surviving denominator's zero is always the infinite one.
  • NEB-style (6m): For f(x) = (x² − 5x + 6)/(x − 2) for x ≠ 2, f(2) = 1: find the limit at 2, classify the discontinuity, and state the repair value. — Diagnose: substitute x = 2: (4 − 10 + 6)/0 = 0/0 ⟹ a shared root exists. Factor: x² − 5x + 6 = (x − 2)(x − 3) ⟹ f(x) = x − 3 for x ≠ 2. Limit: lim_{x→2} f(x) = −1. Classification: the limit exists; f(2) = 1 ≠ −1 ⟹ the failure is only at the point's value ⟹ removable discontinuity (a detached dot at (2, 1) hovering over the hole at (2, −1)). Repair: redefine f(2) = −1 ⟹ value = limit ⟹ continuous at 2. Deep point: the 0/0 diagnosis guaranteed removability before the factoring — a shared root means the neighbourhood's approach is governed by the cancelled quotient, so the break lives at the point, not in the road leading to it.
  • NEB-style (5m): For f(x) = (x³ − 27)/(x − 3) for x ≠ 3, determine the value f(3) must have for f to be continuous at 3. — Diagnose: at x = 3: (27 − 27)/0 = 0/0 ⟹ shared root. Factor (difference of cubes): x³ − 27 = (x − 3)(x² + 3x + 9) ⟹ f(x) = x² + 3x + 9 for x ≠ 3. Limit: 9 + 9 + 9 = 27. Required value: continuity needs f(3) = limit ⟹ f(3) = 27. Check the shape: the graph is the parabola y = x² + 3x + 9 with a hole at (3, 27); assigning f(3) = 27 fills it exactly. Deep point: "the value that makes it continuous" is always the limit — the question is the three-part test inverted: instead of checking Part 3, you engineer Part 3 to pass by setting the value to what Parts 1 and 2 already produced.
  • NEB-style (6m): For f(x) = (x + 2)(x² − 9)/(x² + x − 6) for x ≠ 2 and x ≠ −3: find all removable breaks, the limit at each, and the repaired values. — Factor everything: x² − 9 = (x−3)(x+3); x² + x − 6 = (x+3)(x−2). So f(x) = (x+2)(x−3)(x+3)/[(x+3)(x−2)] = (x+2)(x−3)/(x−2) after cancelling (x+3) — licensed for x ≠ −3. Break at x = −3: the cancelled factor's root ⟹ removable. Limit: (−1)(−6)/(−5) = 6/(−5) = −6/5 ⟹ repair f(−3) = −6/5. Break at x = 2: the surviving denominator's root — check the numerator at 2: (4)(−1) = −4 ≠ 0 ⟹ no cancellation possible ⟹ non-removable (infinite): as x → 2, denominator → 0 with numerator → −4 ⟹ the sides blow up (a wall). Summary: one removable break at −3 (limit −6/5, repair value −6/5) and one non-removable wall at 2. Deep point: after full factorisation, cancelled roots are removable and surviving denominator roots are not — the factorisation is simultaneously the limit computation and the discontinuity classification.
  • NEB-style (5m): A student says f(x) = (x² − 1)/(x − 1) is discontinuous at x = 1 and therefore lim_{x→1} f(x) does not exist. Assess the claim. — The discontinuity claim: correct in classification — f(1) is undefined (0/0), so f is not continuous at 1. The limit claim: wrong — the limit and the value are independent; the limit reads the neighbourhood, which is healthy. Compute: (x²−1)/(x−1) = x + 1 for x ≠ 1 ⟹ lim_{x→1} f(x) = 2. Correct statement: f has a removable discontinuity at 1 — the limit exists (2) while the value does not; defining f(1) = 2 repairs continuity. Deep point: the student treated "discontinuous" as "limit fails," conflating the point with its neighbourhood — the removable/jump/infinite taxonomy exists precisely because discontinuities differ in where they live, and only the point-local kind leaves limits intact.

Summary

A removable discontinuity is the repairable break: the two-sided limit exists finitely while f(a) is missing (a hole) or wrong (a mismatch). Detection is the standard loop — substitute, transform (factor-and-cancel is the signature: (x²−9)/(x−3) → x + 3 with hole at (3, 6)), compare — and the repair theorem is one line: set f(a) = L. The graph shows an open dot at (a, L) (plus a detached dot for mismatches), and the caution stands: cancelling a factor shrinks the domain, so the simplified expression's continuity doesn't transfer back automatically. Triage is per-point: (x+2)/(x²−4) is removable at −2 (limit −1/4) and infinite at 2 — the cancelled factor's zero is the cure-able candidate, the surviving denominator's zero is not. Limit exists, one value to fix: removability in a sentence.

Check the shape: the graph is the parabola y = x² + 3x + 9 with a hole at (3, 27); assigning f(3) = 27 fills it exactly. Deep point: "the value that makes it continuous" is always the limit — the question is the three-part test inverted: instead of checking Part 3, you engineer Part 3 to pass by setting the value to what Parts 1 and 2 already produced.
  • NEB-style (6m): For f(x) = (x + 2)(x² − 9)/(x² + x − 6) for x ≠ 2 and x ≠ −3: find all removable breaks, the limit at each, and the repaired values. — Factor everything: x² − 9 = (x−3)(x+3); x² + x − 6 = (x+3)(x−2). So f(x) = (x+2)(x−3)(x+3)/[(x+3)(x−2)] = (x+2)(x−3)/(x−2) after cancelling (x+3) — licensed for x ≠ −3. Break at x = −3: the cancelled factor's root ⟹ removable. Limit: (−1)(−6)/(−5) = 6/(−5) = −6/5 ⟹ repair f(−3) = −6/5. Break at x = 2: the surviving denominator's root — check the numerator at 2: (4)(−1) = −4 ≠ 0 ⟹ no cancellation possible ⟹ non-removable (infinite): as x → 2, denominator → 0 with numerator → −4 ⟹ the sides blow up (a wall). Summary: one removable break at −3 (limit −6/5, repair value −6/5) and one non-removable wall at 2. Deep point: after full factorisation, cancelled roots are removable and surviving denominator roots are not — the factorisation is simultaneously the limit computation and the discontinuity classification.
  • NEB-style (5m): A student says f(x) = (x² − 1)/(x − 1) is discontinuous at x = 1 and therefore lim_{x→1} f(x) does not exist. Assess the claim. — The discontinuity claim: correct in classification — f(1) is undefined (0/0), so f is not continuous at 1. The limit claim: wrong — the limit and the value are independent; the limit reads the neighbourhood, which is healthy. Compute: (x²−1)/(x−1) = x + 1 for x ≠ 1 ⟹ lim_{x→1} f(x) = 2. Correct statement: f has a removable discontinuity at 1 — the limit exists (2) while the value does not; defining f(1) = 2 repairs continuity. Deep point: the student treated "discontinuous" as "limit fails," conflating the point with its neighbourhood — the removable/jump/infinite taxonomy exists precisely because discontinuities differ in where they live, and only the point-local kind leaves limits intact.
