Notes

  • 1. Topic Introduction — Notation Before Limits

    Functions, their notation and their evaluation are the raw material limits will act on. This topic fixes the vocabulary: f: A → B, image, natural domain, evaluation at points, and the difference between an expression and a function.

  • 2. Fundamental Concepts

    2.1 Definition and notation

    • f: A → B assigns to each x ∈ A exactly one y ∈ B; x is the independent variable, y = f(x) the dependent one.
    • Image f(a); pre-image of y are the x's with f(x) = y; range = set of all images.
    • f and g are equal only when domains match and f(x) = g(x) on the whole domain.

    2.2 Evaluation mechanics

    • f(a) means "substitute a for x everywhere" — including inside absolute values, roots and piecewise branches.
    • Difference quotient: [f(x + h) − f(x)]/h — the object whose limit (row 44+) becomes the derivative; computing it is evaluation discipline.

    2.3 Natural domain

    • The largest set of real inputs where the formula is defined: the bans (denominator, even root, log) from the function topic apply unchanged.

    2.4 Piecewise functions

    • Different formulas on different intervals; evaluation picks the branch containing the input — the skill one-sided limits will formalise.

  • 3. Scientific Definitions

  • 4. Detailed Explanation

    4.1 Notation is a contract

    • f: A → B declares domain and codomain; the range may be smaller. Writing f(x) without a domain invites the domain question — always ask it.

    4.2 The difference quotient as rehearsal

    • [f(x+h) − f(x)]/h requires composing f at x + h correctly — the algebraic fluency that derivatives will assume. Practice it here, before limits raise the stakes.

    4.3 Piecewise evaluation = one-sided thinking

    • |x| evaluated at negative inputs uses the −x branch; the same branch-selection reappears as left-hand limits. The habit starts here.

  • 6. Common Confusions

    f(x + h) ≠ f(x) + h: substitute the whole expression x + h into f — the classic expansion error.

  • Range ≠ codomain: the codomain is declared; the range is earned by the formula.
  • Piecewise boundaries: at a joint, both branches' formulas may be candidates — evaluation needs the interval containing the point.

  • 7. Exam Application

    NEB-style (3m): If f(x) = x² − 3x + 2, find f(0), f(2), f(x + h) − f(x) and simplify the difference quotient. — f(0) = 2; f(2) = 4 − 6 + 2 = 0. f(x + h) = (x+h)² − 3(x+h) + 2 = x² + 2xh + h² − 3x − 3h + 2, so f(x+h) − f(x) = 2xh + h² − 3h = h(2x + h − 3). Difference quotient: h(2x + h − 3)/h = 2x + h − 3 — note the h cancels (h ≠ 0 licensed); its limit as h → 0 will be 2x − 3, the derivative.

  • NEB-style (2m): Find the natural domain of f(x) = (x + 1)/(x² − 4) and evaluate f(3). — Ban: x² − 4 ≠ 0 ⟹ x ≠ ±2; domain = ℝ \ {−2, 2}. f(3) = 4/5.
  • NEB-style (2m): For f(x) = { x + 1 if x < 2; x² − 1 if x ≥ 2 }, evaluate f(1), f(2), f(3). — f(1): 1 < 2 ⟹ first branch ⟹ 2. f(2): 2 ≥ 2 ⟹ second branch ⟹ 3. f(3): second branch ⟹ 8. The branch boundary x = 2 belongs to the second piece (≥) — boundary ownership is part of the definition.

  • 8. Deep Conceptual — Notation as a Precision Instrument

    • f: A → B states three things at once: the input set (domain), the output set (codomain), and the rule. The range (actual outputs) can be smaller than the codomain — f: ℝ → ℝ, f(x) = x² has range [0, ∞). Conflating codomain and range is a notation error, not a maths error.
    • f(a) is a number; f is a machine. Writing "f(x²)" means feed x² into the machine; it does not mean (f(x))². The parenthesis after f is input delivery, not multiplication — the notation encodes the composition idea that the chain rule later formalises.
    • Why notation discipline matters for limits: lim_{x→a} f(x) is read "the value f delivers as input approaches a" — every symbol carries a role. Sloppy reading of notation produces sloppy limit reasoning; precise reading is half the work.

  • 9. Deep Conceptual — Domain as the First Question

    • Before any limit or continuity claim, ask where the rule is defined: denominators ≠ 0, even roots need radicand ≥ 0, logs need argument > 0, and piecewise rules carry their own boundaries. The domain is the set of inputs the machine accepts.
    • Natural vs assigned domain: a formula implies a natural domain (1/(x−2) excludes 2); a definition can extend it (declaring f(2) = 5 adds a point). Continuity questions live exactly at these seams — the formula's edge and the assigned value must agree.
    • Domain reading decides limit strategy: points inside the domain's open regions allow substitution; points on the boundary or excluded demand transformation or one-sided analysis. Triage begins with the domain, not with algebra.

  • 10. Deep Conceptual — Piecewise Functions as Conditional Machines

    • A piecewise definition is a routing table: the condition column decides which formula runs. Evaluating f(2.5) means checking which condition captures 2.5, not averaging formulas or guessing.
    • The joints are where mathematics happens: at a boundary point c shared by two pieces, the function's behaviour (limit, continuity, later differentiability) is decided by comparing the pieces' one-sided behaviour. A piecewise function is really several functions glued at seams.
    • Consistency check as a design tool: to make a piecewise function continuous at a joint, set the pieces' limits equal and solve for the unknown constant — the same three-part test run in reverse, from "is it continuous" to "what value would make it so."

Practice Questions

  • NEB-style (3m): If f(x) = x² − 3x + 2, find f(0), f(2), and simplify the difference quotient [f(x + h) − f(x)]/h. — Evaluations: f(0) = 0 − 0 + 2 = 2; f(2) = 4 − 6 + 2 = 0. Difference quotient: first expand f(x + h) = (x + h)² − 3(x + h) + 2 = x² + 2xh + h² − 3x − 3h + 2 — substituting the whole input, not adding h to the output. Then f(x+h) − f(x) = 2xh + h² − 3h = h(2x + h − 3) — h factors out cleanly. Quotient: h(2x + h − 3)/h = 2x + h − 3, the cancellation licensed because h ≠ 0 in the difference quotient. (Preview: letting h → 0 gives 2x − 3 — the derivative this quotient is rehearsing.)
  • NEB-style (2m): Find the natural domain of f(x) = (x + 1)/(x² − 4) and evaluate f(3). — Domain: the single ban is the denominator: x² − 4 ≠ 0 ⟹ (x−2)(x+2) ≠ 0 ⟹ x ≠ 2 and x ≠ −2. Domain = ℝ \ {−2, 2} = (−∞, −2) ∪ (−2, 2) ∪ (2, ∞). No root or log bans apply. Evaluation: f(3) = (3 + 1)/(9 − 4) = 4/5 — a legal input since 3 ∉ {±2}.
  • NEB-style (2m): Let f(x) = x + 1 for x < 2 and f(x) = x² − 1 for x ≥ 2. Evaluate f(1), f(2) and f(3). — f(1): 1 < 2 ⟹ first branch: 1 + 1 = 2. f(2): 2 ≥ 2 ⟹ second branch (the boundary belongs to the ≥ piece by the definition): 4 − 1 = 3. f(3): second branch: 9 − 1 = 8. Note: boundary ownership is part of the function's definition — here x = 2 is claimed by the second branch, which also means the two branches disagree at the joint (2 vs 3), a jump the one-sided limits of later rows will measure precisely.
  • NEB-style (5m): For f(x) = (x+1)/(x² − 1), state the domain, simplify where licensed, and evaluate lim_{x→1} f(x). — Domain: denominator x² − 1 = 0 at x = ±1 ⟹ domain is ℝ \ {−1, 1}. Simplify: x² − 1 = (x−1)(x+1), so f(x) = (x+1)/[(x−1)(x+1)] = 1/(x−1) for x ≠ −1 (cancelling x+1 is licensed only off the domain). Limit at x = 1: 1 is in neither the original nor the simplified domain; as x → 1, 1/(x−1) blows up — from the right +∞, from the left −∞ ⟹ the limit does not exist (the sides disagree at infinity). Deep point: the cancellation at x = −1 removed a hole (limit exists there: 1/(−2) = −1/2), but x = 1 remains a genuine vertical wall — simplification can erase removable breaks, never infinite ones; knowing which root survived cancellation tells you which discontinuity type remains.
  • NEB-style (6m): A piecewise function is defined by f(x) = x + 3 for x < 2, f(x) = ax² for x ≥ 2. Find a so that lim_{x→2} f(x) exists, and give the limit. — Two-sided requirement: the limit at the joint x = 2 exists only if the two one-sided limits agree. Left side (x → 2⁻, first piece): lim (x + 3) = 2 + 3 = 5 (polynomial ⟹ substitution licensed). Right side (x → 2⁺, second piece): lim ax² = a·4 = 4a (polynomial ⟹ substitution licensed). Set equal: 4a = 5 ⟹ a = 5/4. The limit: with a = 5/4, both sides give 5, so lim_{x→2} f(x) = 5. Bonus check: f(2) = a·4 = 5 = limit ⟹ f is also continuous at the joint — matching the one-sided limits automatically made the value match, because the second piece's formula was used to define f(2). Deep point: a piecewise joint is a conditional machine's seam; the existence theorem (LHL = RHL) is the tool that welds it, and solving for the constant is the three-part test run in reverse.
  • NEB-style (4m): Given f(x) = √(x − 2), state the domain and evaluate lim_{x→2⁺} f(x), explaining why the two-sided limit at 2 is not asked. — Domain: even root needs radicand ≥ 0 ⟹ x − 2 ≥ 0 ⟹ x ≥ 2, i.e. [2, ∞). Right-hand limit: as x → 2 from inside the domain, √(x−2) → √0 = 0. Why one-sided only: the left side x < 2 is outside the domain — the function has no values there to approach through, so a left-hand limit is not merely different, it is undefined; the two-sided limit at 2 does not exist because one side has no data. Deep point: the domain's boundary converts a limit question into a one-sided question automatically — endpoints of domains always truncate the existence theorem to the side that exists, which is why continuity on a closed interval is defined with one-sided tests at the endpoints.
  • NEB-style (5m): For f(x) = x² and g(x) = 2x + 1, compute (f∘g)(x) and (g∘f)(x), and evaluate lim_{x→1} (f∘g)(x) using the composition theorem. — (f∘g)(x) = f(g(x)) = (2x + 1)² = 4x² + 4x + 1. (g∘f)(x) = g(f(x)) = 2x² + 1 — different results, confirming composition is not commutative: the machines run in the order written, inside-out. Limit via the composition theorem: g is a polynomial, continuous everywhere; f is a polynomial, continuous everywhere. The theorem: if g is continuous at a and f is continuous at g(a), then lim_{x→a} f(g(x)) = f(lim_{x→a} g(x)). Apply: lim_{x→1} g(x) = 3 (substitution), then f(3) = 9 ⟹ lim = 9. Direct check: (f∘g)(x) = 4x² + 4x + 1 at x = 1 gives 4 + 4 + 1 = 9 ✓. Deep point: the composition theorem is the licence to push a limit through a continuous machine — evaluate the inner limit first, then feed the result to the outer function; it fails exactly when the outer function is discontinuous at the inner limit, which is the seam where continuity genuinely does work.

Key Points

  • f: A -> B assigns exactly one image to each input; range = set of images, may be smaller than codomain. Equality of functions: same domain AND same values. Evaluation: substitute the whole input, including inside roots and piecewise branches. Difference quotient [f(x+h) - f(x)]/h: expand f(x+h) fully, factor out h, cancel (h != 0 licensed) - the derivative's seed. Natural domain: the usual bans. Piecewise: pick the branch whose interval contains the input; boundary ownership is declared by the definition.

Summary

Before limits, the vocabulary: a function f: A → B assigns exactly one image to each input, with range = the images actually achieved (possibly smaller than the codomain) and equality of functions requiring matching domains and values. Evaluation is wholesale substitution — including inside roots and piecewise branches, where the branch whose interval contains the input decides (boundary ownership is declared, not guessed). The difference quotient [f(x+h) − f(x)]/h is the topic's real protagonist: expanding f(x+h) fully (x² − 3x + 2 gives h(2x + h − 3)/h = 2x + h − 3) and cancelling h — licensed by h ≠ 0 — is the exact muscle the derivative will demand. The natural domain follows the standing bans; piecewise joints preview one-sided limits. Functions are expressions plus contracts: domain declared, branch chosen, h cancelled.

Why one-sided only: the left side x < 2 is outside the domain — the function has no values there to approach through, so a left-hand limit is not merely different, it is undefined; the two-sided limit at 2 does not exist because one side has no data. Deep point: the domain's boundary converts a limit question into a one-sided question automatically — endpoints of domains always truncate the existence theorem to the side that exists, which is why continuity on a closed interval is defined with one-sided tests at the endpoints.
  • NEB-style (5m): For f(x) = x² and g(x) = 2x + 1, compute (f∘g)(x) and (g∘f)(x), and evaluate lim_{x→1} (f∘g)(x) using the composition theorem. — (f∘g)(x) = f(g(x)) = (2x + 1)² = 4x² + 4x + 1. (g∘f)(x) = g(f(x)) = 2x² + 1 — different results, confirming composition is not commutative: the machines run in the order written, inside-out. Limit via the composition theorem: g is a polynomial, continuous everywhere; f is a polynomial, continuous everywhere. The theorem: if g is continuous at a and f is continuous at g(a), then lim_{x→a} f(g(x)) = f(lim_{x→a} g(x)). Apply: lim_{x→1} g(x) = 3 (substitution), then f(3) = 9 ⟹ lim = 9. Direct check: (f∘g)(x) = 4x² + 4x + 1 at x = 1 gives 4 + 4 + 1 = 9 ✓. Deep point: the composition theorem is the licence to push a limit through a continuous machine — evaluate the inner limit first, then feed the result to the outer function; it fails exactly when the outer function is discontinuous at the inner limit, which is the seam where continuity genuinely does work.
