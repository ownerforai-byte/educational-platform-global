Practice Questions

  • Q1. NEB-style (6m): Using the bisection method, find the root of f(x) = x3 - 4 correct to two iterations on [1, 2]. Solution. f(1) = -3 < 0, f(2) = 4 > 0 ⟹ a root lies in [1, 2] (sign change). Iteration 1: midpoint x = 1.5; f(1.5) = 3.375 - 4 = -0.625 < 0 ⟹ root in [1.5, 2]. Iteration 2: midpoint x = 1.75; f(1.75) = 5.359 - 4 = 1.359 > 0 ⟹ root in [1.5, 1.75]. Approximation: midpoint of the final interval, x ≈ 1.625 (true root ∛4 ≈ 1.5874). Deep point: each iteration halves the bracket and the sign of f at the midpoint tells you which half to keep - the algorithm is the intermediate value theorem turned into a loop.
  • Q2. NEB-style (6m): Use Newton-Raphson with x0​ = 2 to find √5 and verify against the true value. Solution. f(x) = x2 - 5, f'(x) = 2x. x1​ = 2 - (4 - 5)/4 = 2 + 0.25 = 2.25. x2​ = 2.25 - (5.0625 - 5)/(4.5) = 2.25 - 0.013889 = 2.236111. True value: √5 = 2.2360680... - x2​ is already correct to 4 decimal places. Deep point: near a simple root the error roughly squares each step (quadratic convergence): the initial error 0.236 became 0.014 then 0.00004 - three steps bought twelve digits of progress.

  • Q4. NEB-style (5m): Show that the equation x = cos x has a root between 0 and 1, and state the condition that guarantees bisection applies. Solution. Define f(x) = x - cos x. f(0) = 0 - 1 = -1 < 0; f(1) = 1 - cos 1 ≈ 1 - 0.5403 = 0.4597 > 0. Since f is continuous and the signs differ, the intermediate value theorem gives a root in (0, 1). Bisection's licence: exactly this - f continuous on [a, b] with f(a)·f(b) < 0. Deep point: the sign-change check is not a formality but the theorem being invoked; without continuity (or the sign change) the bracket is worthless - bisection inherits its guarantee from the IVT alone.
  • Q5. NEB-style (6m): Derive the Newton-Raphson formula from the tangent line and interpret it geometrically. Solution. At (x0​, f(x0​)) the tangent is y - f(x0​) = f'(x0​)(x - x0​). Setting y = 0 (where the tangent meets the x-axis): x = x0​ - f(x0​)/f'(x0​) ⟹ xn+1​ = xn​ - f(xn​)/f'(xn​). Geometric meaning: slide along the tangent until it crosses the axis; the crossing point is the next approximation. Deep point: the method replaces the curve by its tangent at each step - linearisation iterated; it converges when the tangents keep pointing home, and fails when they point away (see Q7).
  • Q6. NEB-style (5m): After n bisection iterations on [1, 2], what is the error bound? Find the least n making the error less than 0.01. Solution. Each iteration halves the interval: width after n steps is (b - a)/2n = 1/2n, and the midpoint is within half that of the root ⟹ error ≤ 1/2n+1. Requirement: 1/2n+1 < 0.01 ⟹ 2n+1 > 100 ⟹ n + 1 ≥ 7 ⟹ n = 6. Deep point: bisection's convergence is slow but guaranteed - the error bound is known in advance (linear halving), which is exactly what Newton-Raphson trades away for its much faster, conditional convergence.
  • Q7. NEB-style (6m): Apply Newton-Raphson to f(x) = (x - 1)2 from x0​ = 3 and explain what the iteration reveals about repeated roots. Solution. f' = 2(x - 1). x1​ = 3 - (2)2/4 = 3 - 1 = 2. x2​ = 2 - (1)/2 = 1.5. x3​ = 1.5 - (0.25)/1 = 1.25. Each step: xn+1​ = xn​ - (xn​ - 1)2/(2(xn​ - 1)) = (xn​ + 1)/2 - the error halves each step. Diagnosis: the root x = 1 is a double root (f and f' vanish together), so convergence is merely linear - the error halves instead of squaring. Deep point: Newton-Raphson's quadratic convergence is certified only at simple roots; at repeated roots the derivative's own smallness throttles the correction - the method still arrives, but at a walk instead of a sprint.

Exam Short Tricks

  • Trick 1: Bisection protocol: find a, b with f(a)f(b) < 0 → midpoint c = (a+b)/2 → keep the subinterval with the sign change → repeat; each step halves the interval (error after n steps ≤ (b−a)/2^n).
  • Trick 2: Newton–Raphson one formula: x_{n+1} = x_n − f(x_n)/f′(x_n) — choose the initial guess near the root; a wrong start (f′ ≈ 0) diverges.
  • Trick 3: Speed comparison: NR converges quadratically (doubles correct digits), bisection linearly — quote when asked to compare.
  • Trick 4: For transcendental equations (e.g. x = cos x), first isolate f(x) = x − cos x and bracket the root by testing integer values.
