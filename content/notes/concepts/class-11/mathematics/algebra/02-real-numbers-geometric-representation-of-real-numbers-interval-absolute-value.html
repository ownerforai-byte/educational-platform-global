Practice Questions

  • NEB-style (3m): Solve |2x − 3| < 5 and express the solution set as an interval. — Rule: |u| < a ⟺ −a < u < a (a > 0). Apply with u = 2x − 3: −5 < 2x − 3 < 5. Add 3 throughout: −2 < 2x < 8. Divide by 2: −1 < x < 4, so x ∈ (−1, 4) — an open interval. Geometric check: dividing by |2| rewrites the inequality as |x − 3/2| < 5/2 — the points within distance 2.5 of 1.5, whose window (−1, 4) has centre (−1+4)/2 = 1.5 ✓ and half-width 2.5 ✓. Every absolute-value inequality is a centre-and-radius statement in disguise.
  • NEB-style (2m): Solve |x + 1| = |2x − 1|. — Rule: |u| = |v| ⟺ u² = v² ⟺ u = ±v (squaring is safe here because both sides are non-negative). Case 1 (u = v): x + 1 = 2x − 1 ⟹ x = 2. Case 2 (u = −v): x + 1 = −2x + 1 ⟹ 3x = 0 ⟹ x = 0. Verification: x = 2: |3| = |3| ✓; x = 0: |1| = |−1| ✓. Solutions: {0, 2} — geometrically, the two points equidistant from −1 and 1/2 on the line.
  • NEB-style (2m): Prove the triangle inequality |x + y| ≤ |x| + |y| for real numbers, and state when equality holds. — Proof: both sides are non-negative, so it suffices to compare squares. |x + y|² = (x + y)² = x² + 2xy + y². Since xy ≤ |xy| for all reals, x² + 2xy + y² ≤ x² + 2|xy| + y² = |x|² + 2|x||y| + |y|² = (|x| + |y|)². Taking square roots of the non-negative sides preserves order: |x + y| ≤ |x| + |y|. ∎ Equality analysis: the chain tightened only at 2xy ≤ 2|xy|, which is equality exactly when xy ≥ 0 — same sign (or one is zero). So equality holds iff x and y have the same sign (or either is 0): the "detour" |x| + |y| is wasted only when the two legs point the same way.

Summary

Real numbers complete the line — no gaps, unlike ℚ — and intervals name its pieces: open (a, b) excludes endpoints, closed [a, b] includes them, and intersections of intervals remain intervals. Absolute value is distance: |x| from 0, |x − a| between x and a. Its theorems: |xy| = |x||y|, the triangle inequality |x+y| ≤ |x|+|y| (proved by squaring and xy ≤ |xy|, equality exactly when the signs agree), and the reverse form |x−y| ≥ ||x|−|y||. Solving follows three rules: |x| = a ⟺ x = ±a; |x| < a ⟺ −a < x < a (the sandwich — |2x−3| < 5 gives (−1, 4)); |x| > a ⟺ x < −a or x > a (a union of rays, the classic trap); and the δ-window |x − a| < δ ⟺ a − δ < x < a + δ — the picture that limits will reuse. Isolate, split by cases, verify: extraneous roots live in the signs.

Notes

  • 1. Topic Introduction — The Number Line and Its Distances

    Real numbers fill the line without gaps; intervals name its pieces; absolute value measures distance, deaf to direction. The theorems: interval unions/intersections, the triangle inequality, and the |x − a| < δ "distance window" that later powers limits.

  • 2. Fundamental Concepts

    2.1 Real numbers and the line

    • ℝ = rationals ∪ irrationals; every point of the line is a real number and every real number is a point — completeness is the property that leaves no gaps (unlike ℚ, which misses √2).
    • Decimal character: rationals terminate or repeat; irrationals do neither.

    2.2 Intervals

    • Open (a, b): a < x < b — endpoints excluded. Closed [a, b]: a ≤ x ≤ b — endpoints included. Half-open mixes. Unbounded: (a, ∞), (−∞, b], ℝ = (−∞, ∞).
    • Theorem: the intersection of intervals is an interval (possibly empty); unions of overlapping intervals are intervals; disjoint unions generally are not.

    2.3 Absolute value theorems

    • Definition: |x| = x if x ≥ 0, −x if x < 0; geometrically the distance from 0.
    • Theorems: |xy| = |x||y|; |x/y| = |x|/|y|; triangle inequality |x + y| ≤ |x| + |y| (equality iff xy ≥ 0); reverse triangle |x − y| ≥ ||x| − |y||.
    • Distance form: |x − a| = distance between x and a on the line.

    2.4 Equations and inequalities with |·|

    • |x| = a ⟺ x = ±a (a ≥ 0); |x| < a ⟺ −a < x < a (a > 0); |x| > a ⟺ x < −a or x > a.
    • |x − a| < δ ⟺ a − δ < x < a + δ — the δ-window about a.

  • 4. Detailed Explanation

    4.1 Why |x| is distance

    • |x − a| answers "how far from a" with no direction. Every absolute-value equation/inequality is a distance statement: |x − 2| < 3 means "within 3 of 2", i.e. −1 < x < 5.

    4.2 Open vs closed matters later

    • Limits care about approach, so open intervals (no endpoint to bump into) are the natural habitat; closed intervals carry max/min theorems. The notation choice encodes real mathematics.

    4.3 Solving strategy

    • Isolate the absolute value; split into cases by the definition; solve each case; check against the original — extraneous roots appear when both sides' signs are ignored.

  • 6. Common Confusions

    |x| > a splits into a union: "farther than a" is two rays, not one interval — the classic sign error.

  • Squaring both sides needs checking: |x − 1| = −2 has no solution; |x|=|y| allows x = ±y, not just x = y.
  • √(x²) = |x|: not x — the square root returns the non-negative root, so the absolute value is mandatory.

  • 7. Exam Application

    NEB-style (3m): Solve |2x − 3| < 5 and express the solution as an interval. — Window form: |u| < a ⟺ −a < u < a: −5 < 2x − 3 < 5 ⟹ add 3: −2 < 2x < 8 ⟹ divide by 2: −1 < x < 4, i.e. x ∈ (−1, 4). Geometric reading: the solutions are exactly the points within distance 5 of 3/2 — and indeed (−1 + 4)/2 = 3/2 with half-width 5/2 = 5/2... half-width (4 − (−1))/2 = 2.5 ✓ matches |2x−3| < 5 ⟺ |x − 3/2| < 5/2.

  • NEB-style (2m): Solve |x + 1| = |2x − 1|. — Squaring route: |u| = |v| ⟺ u² = v² ⟺ u = ±v. Case 1: x + 1 = 2x − 1 ⟹ x = 2. Case 2: x + 1 = −(2x − 1) ⟹ x + 1 = −2x + 1 ⟹ 3x = 0 ⟹ x = 0. Solutions: x = 0, 2. Check: x = 0: |1| = |−1| ✓; x = 2: |3| = |3| ✓.
  • NEB-style (2m): Prove the triangle inequality |x + y| ≤ |x| + |y|. — Both sides are non-negative, so square: |x+y|² = (x+y)² = x² + 2xy + y² ≤ x² + 2|xy| + y² = (|x| + |y|)², since 2xy ≤ 2|xy| always. Taking square roots (both sides non-negative) gives |x + y| ≤ |x| + |y|. ∎ Equality case: xy ≥ 0 — same sign or zero, i.e. x and y point the same way on the line.
