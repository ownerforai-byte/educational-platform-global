Notes

  • 1. Topic Introduction — Rectangular Arrays With Algebra

    A matrix is a rectangular array; its algebra (transpose, sums, products) and the determinant machinery turn linear systems into single computations. The theorems: transpose laws, matrix multiplication's non-commutativity, invertibility via |A| ≠ 0, and A⁻¹ = adj A/|A|.

  • 2. Fundamental Concepts

    2.1 Matrix basics and algebra

    • Order m × n; equality needs equal orders and matching entries. Addition entrywise (same orders only); scalar multiplication distributes.
    • Transpose: Aᵀ swaps rows and columns. Theorems: (Aᵀ)ᵀ = A; (A + B)ᵀ = Aᵀ + Bᵀ; (AB)ᵀ = BᵀAᵀ (reversal law); (kA)ᵀ = kAᵀ.

    2.2 Multiplication and its laws

    • (AB)ᵢⱼ = Σₖ aᵢₖbₖⱼ — row of A dotted into column of B; defined only when cols(A) = rows(B).
    • Associative: (AB)C = A(BC); distributive: A(B + C) = AB + AC; not commutative: AB ≠ BA in general (even when both are defined).
    • Identity I and zero matrix O act as neutral/absorbing elements; AB = O does not imply A = O or B = O (zero divisors exist).

    2.3 Determinants

    • 2×2: |A| = ad − bc. 3×3: cofactor expansion along any row or column.
    • Theorems: |Aᵀ| = |A|; |AB| = |A||B|; swapping two rows flips the sign; a zero row ⟹ |A| = 0; identical rows ⟹ |A| = 0.

    2.4 Inverse (the theorem)

    • A is invertible ⟺ |A| ≠ 0 (non-singular). A⁻¹ = adj A/|A|, where adj A is the transpose of the cofactor matrix.
    • Theorems: AA⁻¹ = A⁻¹A = I; (AB)⁻¹ = B⁻¹A⁻¹ (reversal); (A⁻¹)⁻¹ = A; (Aᵀ)⁻¹ = (A⁻¹)ᵀ; |A⁻¹| = 1/|A|.
    • Solving AX = B: X = A⁻¹B — unique exactly when |A| ≠ 0.

  • 4. Detailed Explanation

    4.1 Why multiplication reverses order

    • (AB)ᵀ = BᵀAᵀ and (AB)⁻¹ = B⁻¹A⁻¹ both reflect the same fact: to undo "apply A then B" you must undo B first, then A — socks before shoes, shoes off before socks.

    4.2 The determinant as an area/volume scale

    • |A| scales areas (2D) or volumes (3D) under the map x ↦ Ax; |A| = 0 collapses space — which is exactly why no inverse can restore it.

    4.3 AB = O with A, B ≠ O

    • Multiplication by a singular matrix can annihilate information: non-zero factors with zero product exist, so matrix algebra has no cancellation law.

  • 6. Common Confusions

    Multiplication order: AB needs cols(A) = rows(B); reversing kills the definition, not just the value.

  • (AB)⁻¹ = B⁻¹A⁻¹, not A⁻¹B⁻¹: the reversal law — the transpose version (AB)ᵀ = BᵀAᵀ is its twin.
  • adj A is the transpose of cofactors: forgetting the transpose is the classic inverse-computation error.

  • 7. Exam Application

    NEB 2023 (verified PYQ): If A = [[2, 1], [3, 4]], find det(A) and A⁻¹. (3m) — Determinant: |A| = (2)(4) − (1)(3) = 8 − 3 = 5 ≠ 0 ⟹ invertible. Cofactors: C₁₁ = 4, C₁₂ = −3, C₂₁ = −1, C₂₂ = 2; cofactor matrix [[4, −3], [−1, 2]]; adj A = transpose = [[4, −1], [−3, 2]]. A⁻¹ = adj A/|A| = (1/5)[[4, −1], [−3, 2]]. Check: A·A⁻¹ = (1/5)[[8−3, −2+2], [12−12, −3+8]] = (1/5)[[5, 0], [0, 5]] = I ✓.

  • NEB-style (2m): Show that (AB)ᵀ = BᵀAᵀ for A = [[1, 2], [0, 1]], B = [[1, 0], [3, 1]]. — AB = [[1+6, 0+2], [3, 1]] = [[7, 2], [3, 1]] ⟹ (AB)ᵀ = [[7, 3], [2, 1]]. BᵀAᵀ = [[1, 3], [0, 1]]·[[1, 0], [2, 1]] = [[1+6, 3], [2, 1]] = [[7, 3], [2, 1]] ✓ — equal, as the reversal law demands.
  • NEB-style (3m): Solve the system x + y = 5, 2x − y = 1 by the inverse-matrix method. — AX = B with A = [[1, 1], [2, −1]], X = [x, y]ᵀ, B = [5, 1]ᵀ. |A| = (1)(−1) − (1)(2) = −3 ≠ 0. adj A = [[−1, −1], [−2, 1]]. X = A⁻¹B = (1/−3)[[−1, −1], [−2, 1]]·[5, 1]ᵀ = (1/−3)[−6, −9]ᵀ = [2, 3]ᵀ ⟹ x = 2, y = 3. Check: 2 + 3 = 5 ✓, 4 − 3 = 1 ✓.

Confusion

  • x (AB)^T = A^T B^T. x (AB)^T = B^T A^T (order reverses!).
  • x Every matrix has an inverse. x Only square, non-singular matrices.
  • x AB = BA always. x Matrix multiplication is NOT commutative.

  • Verify (AB)ᵀ = BᵀAᵀ for 2×2 matrices A, B of your choice.
  • Solve x + y = 5, 2x − y = 1 by the inverse-matrix method.

Formulas

    • (AB)ᵀ = BᵀAᵀ; (AB)⁻¹ = B⁻¹A⁻¹; |AB| = |A||B|
    • 2×2: A⁻¹ = (1/(ad−bc))[[d, −b], [−c, a]]
    • A⁻¹ = adj A/|A|; AA⁻¹ = I; |A⁻¹| = 1/|A|; AX = B ⟹ X = A⁻¹B

Summary

Matrices bring algebra to arrays. Transpose swaps rows and columns and obeys (Aᵀ)ᵀ = A, (A+B)ᵀ = Aᵀ+Bᵀ and the reversal law (AB)ᵀ = BᵀAᵀ; multiplication (AB)ᵢⱼ = Σₖ aᵢₖbₖⱼ is associative and distributive but never commutative, and AB = O tolerates non-zero factors. Determinants — ad − bc in 2×2, cofactor expansion in 3×3 — satisfy |Aᵀ| = |A| and |AB| = |A||B|, with zero/equal rows forcing zero. The inverse theorem: A⁻¹ exists ⟺ |A| ≠ 0, computed as adj A/|A| (adj = transposed cofactors — NEB 2023: A = [[2,1],[3,4]] gives |A| = 5 and A⁻¹ = (1/5)[[4,−1],[−3,2]], verified by AA⁻¹ = I). Inverses reverse order too: (AB)⁻¹ = B⁻¹A⁻¹ — socks-before-shoes logic. Linear systems become X = A⁻¹B, unique exactly when the determinant stands guard ≠ 0 (x = 2, y = 3 for the sample system).

Important Concepts

  • Reversal laws share one reason: undoing "A then B" means undoing B first - transpose and inverse both read right to left.

Important Statements

  • "A is invertible iff |A| != 0; A^-1 = adj A/|A|; (AB)^-1 = B^-1 A^-1; (AB)^T = B^T A^T."

Important Tasks

  • Find the transpose and the determinant of a 2x2 or 3x3 matrix, expanding a 3x3 determinant along the row or column with the most zeros.
  • Find A^-1 for a 2x2 matrix by the adjoint method, then verify the result by multiplying A A^-1 to obtain the identity matrix.
  • Solve a pair of linear equations by Cramer's rule, forming Dx and Dy by replacing the appropriate column with the constants.
  • Classify a given matrix as square, diagonal, identity, zero, symmetric or skew-symmetric, and confirm that a skew-symmetric matrix has a zero diagonal.

Key Points

  • Matrix: rectangular array, order m x n; addition entrywise for equal orders. Transpose theorems: (A^T)^T = A; (A + B)^T = A^T + B^T; (AB)^T = B^T A^T (reversal); (kA)^T = kA^T. Multiplication: (AB)_ij = sum_k a_ik b_kj, needs cols(A) = rows(B); associative, distributive, NOT commutative; AB = O does not force A = O or B = O. Determinants: 2x2 ad - bc; |A^T| = |A|; |AB| = |A||B|; row swap flips sign; zero or equal rows give 0. Inverse theorem: A invertible iff |A| != 0; A^-1 = adj A/|A| with adj A = transpose of cofactor matrix; (AB)^-1 = B^-1 A^-1; (A^-1)^-1 = A; |A^-1| = 1/|A|. Solving AX = B: X = A^-1 B, unique iff |A| != 0.

Special Notes

  • A skew-symmetric matrix can also be symmetric only in the trivial case A = 0, since A = A^T = -A^T forces every entry to be zero.
  • Interchanging any two rows, or any two columns, of a matrix changes the sign of its determinant.
  • Multiplying one whole row of an n x n matrix by k multiplies its determinant by k, not by k^n.
  • The determinant of an odd-order skew-symmetric matrix is zero, even though the matrix itself need not be zero.
  • If |A| = 5 for a 3x3 matrix then |adj A| = 5^2 = 25, not 5, because the exponent is n - 1.

Exam Short Tricks

  • 2x2 inverse: swap diagonal, negate off-diagonal, divide by |A|. |AB| = |A||B|. Solve AX = B: find |A|, adj A, multiply. Transpose and inverse: reverse the order.

Exam Notes

  • Always verify A A^-1 = I after computing an inverse - the check is quick and catches transpose/cofactor slips.

Practice Questions

  • NEB 2023 (verified PYQ): If A = [[2, 1], [3, 4]], find det(A) and A⁻¹. (3m) — Determinant: |A| = (2)(4) − (1)(3) = 8 − 3 = 5 ≠ 0 ⟹ A is non-singular and invertible. Cofactors: C₁₁ = +4, C₁₂ = −3, C₂₁ = −1, C₂₂ = +2 ⟹ cofactor matrix [[4, −3], [−1, 2]]; adj A = its transpose = [[4, −1], [−3, 2]]. Inverse: A⁻¹ = adj A/|A| = (1/5)[[4, −1], [−3, 2]]. (2×2 shortcut: swap the diagonal entries, negate the off-diagonal ones, divide by |A| — same result.) Verification: AA⁻¹ = (1/5)[[2·4 + 1·(−3), 2·(−1) + 1·2], [3·4 + 4·(−3), 3·(−1) + 4·2]] = (1/5)[[5, 0], [0, 5]] = I ✓.
  • NEB-style (2m): Verify the reversal law (AB)ᵀ = BᵀAᵀ for A = [[1, 2], [0, 1]] and B = [[1, 0], [3, 1]]. — Left side: AB = [[1·1 + 2·3, 1·0 + 2·1], [0·1 + 1·3, 0·0 + 1·1]] = [[7, 2], [3, 1]]; its transpose: (AB)ᵀ = [[7, 3], [2, 1]]. Right side: Bᵀ = [[1, 3], [0, 1]], Aᵀ = [[1, 0], [2, 1]]; BᵀAᵀ = [[1·1 + 3·2, 1·0 + 3·1], [0·1 + 1·2, 0·0 + 1·1]] = [[7, 3], [2, 1]]. Both sides agree ✓ — the reversal law holds: transposing a product reverses the order of the factors, never preserves it.
  • NEB-style (3m): Solve the system x + y = 5, 2x − y = 1 by the matrix (inverse) method. — Matrix form: A = [[1, 1], [2, −1]], X = [x, y]ᵀ, B = [5, 1]ᵀ, so AX = B. Determinant: |A| = (1)(−1) − (1)(2) = −3 ≠ 0 ⟹ unique solution exists. Adjoint: cofactor matrix [[−1, −2], [−1, 1]] ⟹ adj A = [[−1, −1], [−2, 1]]. Solution: X = A⁻¹B = (1/−3)[[−1, −1], [−2, 1]]·[5, 1]ᵀ = (1/−3)[(−5 − 1), (−10 + 1)]ᵀ = (1/−3)[−6, −9]ᵀ = [2, 3]ᵀ. Answer: x = 2, y = 3. Check in both equations: 2 + 3 = 5 ✓ and 2(2) − 3 = 1 ✓ — the inverse method's uniqueness guarantee means no other solution can exist.

Mcs

1.

If A = [[2,3],[1,4]], then the determinant |A| is

Options
  • 5
  • -5
  • 11
  • 1
Answer

A

Explanation

|A| = ad - bc = 2(4) - 3(1) = 8 - 3 = 5. The value 11 comes from wrongly adding ad + bc.

2.

(AB)^T is equal to

Options
  • A^T B^T
  • B^T A^T
  • AB
  • BA
Answer

B

Explanation

Transposition reverses the order of a product, because ((AB)^T)_ij = (AB)_ji = sum over k of B_jk A_ki, which is the ij entry of B^T A^T.

3.

The inverse of the matrix A = [[1,2],[3,5]] is

Options
  • [[5,-2],[-3,1]]
  • [[-5,2],[3,-1]]
  • [[5,2],[3,-1]]
  • [[-5,-2],[-3,-1]]
Answer

B

Explanation

|A| = 1(5) - 2(3) = -1 and adj A = [[5,-2],[-3,1]], so A^-1 = (1/-1) adj A = [[-5,2],[3,-1]]. Multiplying A by this gives the identity matrix.

4.

If A is a 3x3 matrix with |A| = 5, then |adj A| equals

Options
  • 25
  • 5
  • 15
  • 125
Answer

A

Explanation

The general rule is |adj A| = |A|^(n-1) for an n x n matrix, so with n = 3 this is 5^2 = 25 and not 5 or 5^3.

5.

A square matrix A has an inverse if and only if

Options
  • |A| = 0
  • |A| != 0
  • A is symmetric
  • A is diagonal
Answer

B

Explanation

A^-1 = (1/|A|) adj(A) requires a non-zero determinant. When |A| = 0 the matrix is singular and the division is impossible, while symmetry or diagonality says nothing about the determinant.
