Notes

  • 1. Topic Introduction — Reading Graphs Like a Pro

    Before calculus, curve sketching extracts everything from the formula by classification: symmetry (odd/even), periodicity, monotonicity, and intercepts. Each is a theorem-shaped test applied to f's formula.

  • 2. Fundamental Concepts

    2.1 Symmetry tests (the theorems)

    • Even function: f(−x) = f(x) ⟺ graph symmetric about the y-axis (cos x, x²).
    • Odd function: f(−x) = −f(x) ⟺ symmetric about the origin (sin x, x³); consequence: f(0) = 0 for odd functions defined at 0.
    • Neither is the common case (e.g. x + x²). Symmetry about x-axis (y²-forms) fails the function test unless restricted.

    2.2 Periodicity

    • f(x + T) = f(x) for all x, T > 0 minimal ⟹ period T. sin, cos: 2π; tan: π; |sin x|: π.
    • Theorem: if f has period T, then f(ax + b) has period T/|a| — horizontal compression divides the period.

    2.3 Monotonicity (pre-calculus version)

    • Increasing on I: a < b ⟹ f(a) < f(b); decreasing: f(a) > f(b). Test by algebra on f(b) − f(a) (or later by the derivative's sign).
    • Theorem: a strictly monotone function is one-to-one — hence invertible; this is the standard proof route for invertibility.

    2.4 Intercepts and the sketching protocol

    • y-intercept: f(0) (if 0 ∈ domain). x-intercepts: solve f(x) = 0. Protocol: domain → symmetry → periodicity → intercepts → asymptotes → monotonic shape → sketch.

  • 4. Detailed Explanation

    4.1 Why symmetry halves the work

    • An even graph needs sketching only for x ≥ 0 — mirror the rest. An odd graph needs a quarter's work rotated. Symmetry is labour-saving, not decoration.

    4.2 The period-shift theorem at work

    • sin 2x has period 2π/2 = π: doubling the frequency halves the period. |sin x| has period π because the fold makes negative humps positive — the folded wave repeats twice as fast.

    4.3 Monotonicity as invertibility certificate

    • Showing f(b) − f(a) keeps a fixed sign for a < b proves strict monotonicity, which forces one-to-one, which licenses an inverse — a three-step logical chain worth memorising.

  • 6. Common Confusions

    Odd ⟹ f(0) = 0: only when 0 is in the domain — 1/x is odd but undefined at 0.

  • Products of parities: even×even = even, odd×odd = even, even×odd = odd — parity multiplies like signs.
  • Period of f(ax): T/|a|, not aT — compression shrinks the period.

  • 7. Exam Application

    NEB-style (2m): Determine whether f(x) = x³ + x is even, odd or neither, and interpret geometrically. — f(−x) = (−x)³ + (−x) = −x³ − x = −(x³ + x) = −f(x) ⟹ odd: the graph is symmetric about the origin (a 180° rotation maps it onto itself). Consequences visible on the graph: f(0) = 0 passes through the origin, and every point (a, b) has the partner (−a, −b).

  • NEB-style (2m): Find the period of (i) sin 3x, (ii) |sin x|. — (i) sin has period 2π; by the period-shift theorem f(ax) has period 2π/|a|: π·... 2π/3 for sin 3x. (ii) folding negatives up, |sin(x + π)| = |−sin x| = |sin x|, and no smaller positive T works: period π — the fold doubles the repetition rate.
  • NEB-style (3m): Show that f(x) = x³ is strictly increasing on ℝ and deduce that it has an inverse. — Take a < b; then b³ − a³ = (b − a)(b² + ab + a²). The first factor is positive; the second equals (b² + ab + a²) = (a + b/2)²·... always positive since b² + ab + a² = ½[(a+b)² + a² + b²] > 0 unless a = b = 0 (excluded as a < b). Hence b³ − a³ > 0 ⟹ f strictly increasing on ℝ. Strictly monotone ⟹ one-to-one ⟹ invertible — the inverse is the cube root x^{1/3}, defined on all of ℝ (note: unlike x², the cube keeps negatives negative, so no domain restriction is needed).

Practice Questions

  • NEB-style (2m): Determine whether f(x) = x³ + x is even, odd, or neither, and state the geometric meaning. — Test: replace x by −x: f(−x) = (−x)³ + (−x) = −x³ − x = −(x³ + x) = −f(x). The odd-function identity holds ⟹ f is odd. Geometry: the graph is symmetric about the origin — rotating the plane by 180° maps the curve onto itself. Visible consequences: f(0) = 0 (the graph passes through the origin) and each point (a, b) on the curve forces (−a, −b) onto it as well. (Both terms x³ and x are odd, and odd + odd = odd — parity addition follows the sign rule.)
  • NEB-style (2m): Find the period of (i) f(x) = sin 3x and (ii) g(x) = |sin x|. — (i) sin x has period 2π. By the period-shift theorem, f(ax + b) has period T/|a|: sin 3x has period 2π/|3| = 2π/3 — tripling the frequency thirds the period. (ii) Check T = π: |sin(x + π)| = |−sin x| = |sin x| ✓, so π is a period. No smaller positive T works (on (0, π/2) the folded sine is strictly monotone), so the period of |sin x| is π — taking absolute values folds the negative humps upward, making the wave repeat twice as often as the unfolded sine.
  • NEB-style (3m): Show that f(x) = x³ is strictly increasing on ℝ, and deduce that it possesses an inverse function. — Monotonicity: take any a < b and form b³ − a³ = (b − a)(b² + ab + a²). The first factor b − a > 0. The second: b² + ab + a² = ½[(a + b)² + a² + b²] ≥ 0, with equality only when a = b = 0 — impossible since a < b. Hence b² + ab + a² > 0, so b³ − a³ > 0, i.e. a < b ⟹ f(a) < f(b): f is strictly increasing on all of ℝ. Deduction: strictly monotone functions are one-to-one (unequal inputs give unequal outputs in the same order), and one-to-one functions are exactly those that possess inverses. Hence x³ is invertible on ℝ with inverse x^{1/3} — no domain restriction needed, because the cube preserves sign (contrast x², which folds ±a together and must be restricted to [0, ∞) before inversion).
