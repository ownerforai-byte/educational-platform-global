Notes

  • 1. Topic Introduction — The Function Zoo, Classified

    This topic catalogues the algebraic functions — linear, quadratic, polynomial, rational, composite — and the graph-reading theorems attached to each: slope as rate, vertex as extremum, asymptotes as forbidden lines.

  • 2. Fundamental Concepts

    2.1 Linear functions

    • f(x) = mx + c: graph a line; m = slope = rate of change = (f(b) − f(a))/(b − a) — constant for lines. m > 0 rising, m < 0 falling, m = 0 constant.
    • Two-point theorem: a line is determined by two points; parallel lines share slope, perpendicular lines multiply slopes to −1.

    2.2 Quadratic functions

    • f(x) = ax² + bx + c (a ≠ 0); completing the square gives f(x) = a(x − h)² + k with vertex V(h, k), h = −b/2a.
    • Theorem (extremum): the vertex is the minimum if a > 0 (parabola opens up) and the maximum if a < 0; the extremal value is k = c − b²/4a.
    • Axis of symmetry: x = h; the graph is symmetric about it.

    2.3 Polynomial and rational functions

    • Polynomial degree n: at most n real roots, at most n − 1 turning points; end behaviour ruled by the leading term axⁿ.
    • Rational p/q: vertical asymptotes at zeros of q (denominator); horizontal asymptote y = (leading ratio) when degrees match; y = 0 when deg p < deg q; slant asymptote when deg p = deg q + 1 (obtained by division).

    2.4 Piecewise and composite behaviour

    • Piecewise functions adopt each piece's rule on its interval; continuity at the joints demands matching limits. Compositions inherit domain restrictions (see the function topic).

  • 4. Detailed Explanation

    4.1 Slope as the universal rate

    • For any function the difference quotient (f(b) − f(a))/(b − a) measures average rate; for lines it is constant — that constancy is linearity, and calculus will generalise it.

    4.2 Completing the square does triple duty

    • Rewriting ax² + bx + c = a(x − h)² + k reveals the vertex (h, k), the axis x = h, and the extremal value k — one algebraic move, three graph facts.

    4.3 Asymptotes as behaviour at extremes

    • Vertical asymptotes describe blow-up near forbidden x; horizontal/slant asymptotes describe the far-field trend. Together they frame the graph without plotting a single point.

  • 6. Common Confusions

    Vertex x-coordinate is −b/2a: not b/2a — the minus sign survives from completing the square.

  • Holes vs asymptotes: a common factor (x − 2)/(x − 2) leaves a hole at x = 2; an unfactorable zero of q gives an asymptote.
  • Perpendicular slopes multiply to −1: not "reciprocal" — the reciprocal alone gives parallel-looking errors.

  • 7. Exam Application

    NEB 2024 (verified PYQ): Solve x² − 5x + 6 = 0. (2m) — Factor: x² − 5x + 6 = (x − 2)(x − 3) — two numbers multiplying to 6 and adding to −5 are −2, −3. Roots: x = 2, 3. (Check: 4 − 10 + 6 = 0 ✓, 9 − 15 + 6 = 0 ✓.) Equivalently by the quadratic formula: x = (5 ± √(25 − 24))/2 = (5 ± 1)/2.

  • NEB 2023 (verified PYQ): Solve 2√(x + 1) = x − 3. (3m) — Isolate and square: 2√(x+1) = x − 3 requires x − 3 ≥ 0 (the right side must be non-negative since the left is). Squaring: 4(x + 1) = x² − 6x + 9 ⟹ x² − 10x + 5 = 0 ⟹ x = (10 ± √(100 − 20))/2 = 5 ± 2√5. Filter by x ≥ 3: 5 − 2√5 ≈ 0.53 fails; x = 5 + 2√5 ≈ 9.47 ✓ — the squaring trap caught by the sign condition.
  • NEB-style (2m): Find the vertex and extremum of f(x) = 2x² − 8x + 5. — h = −b/2a = 8/4 = 2; k = f(2) = 8 − 16 + 5 = −3. Vertex (2, −3); since a = 2 > 0 the parabola opens up and −3 is the minimum value, attained at x = 2. Axis of symmetry x = 2.

Practice Questions

  • NEB 2024 (verified PYQ): Solve x² − 5x + 6 = 0. (2m) — Factoring route: seek two numbers with product 6 and sum −5: they are −2 and −3, so x² − 5x + 6 = (x − 2)(x − 3). A product is zero iff a factor is zero: x − 2 = 0 or x − 3 = 0 ⟹ x = 2 or x = 3. Verification: x = 2: 4 − 10 + 6 = 0 ✓; x = 3: 9 − 15 + 6 = 0 ✓. (Formula cross-check: x = (5 ± √(25 − 24))/2 = (5 ± 1)/2 = 3 or 2 — the discriminant 1 > 0 confirms two distinct real roots.)
  • NEB 2023 (verified PYQ): Solve for x: 2√(x + 1) = x − 3. (3m) — Step 1 — sign condition: the left side 2√(x+1) is non-negative, so any solution must satisfy x − 3 ≥ 0, i.e. x ≥ 3 — stated before squaring. Step 2 — square: 4(x + 1) = (x − 3)² = x² − 6x + 9 ⟹ x² − 10x + 5 = 0. Quadratic formula: x = (10 ± √(100 − 20))/2 = 5 ± 2√5. Step 3 — filter: 5 − 2√5 ≈ 0.53 < 3 fails the sign condition (substituting gives a negative right side against a positive left) — extraneous, born of squaring. x = 5 + 2√5 ≈ 9.47 ✓ (check: 2√(10.47) ≈ 6.47 and 9.47 − 3 = 6.47 ✓). Answer: x = 5 + 2√5.
  • NEB-style (2m): Find the vertex, axis of symmetry and extreme value of f(x) = 2x² − 8x + 5. — Vertex x-coordinate: h = −b/2a = −(−8)/(2·2) = 2. Vertex y-coordinate: k = f(2) = 2(4) − 16 + 5 = −3. Vertex (2, −3); axis of symmetry x = 2. Extreme value: since a = 2 > 0 the parabola opens upward, so the vertex is the global minimum: the least value of f is −3, attained at x = 2. (Completing the square confirms: 2x² − 8x + 5 = 2(x − 2)² − 3 — the squared term is never negative and vanishes exactly at x = 2.)

Summary

The algebraic-function zoo sorts by rule. Linear f = mx + c: slope m is the constant rate (f(b)−f(a))/(b−a); perpendicular slopes multiply to −1. Quadratic ax² + bx + c: completing the square yields a(x − h)² + k with vertex (h, k), h = −b/2a — minimum for a > 0, maximum for a < 0 (2x² − 8x + 5 → vertex (2, −3), minimum −3). Polynomials of degree n: ≤ n roots, ≤ n − 1 turning points, end behaviour from the leading term. Rationals p/q: vertical asymptotes at zeros of q (holes where factors cancel), horizontal y = leading-ratio when degrees tie, y = 0 when deg p < deg q, slant when deg p = deg q + 1. Equation-solving theorems: factor-and-zero (NEB 2024: x = 2, 3) and the squaring trap — state the sign condition first, filter after (NEB 2023: 2√(x+1) = x−3 keeps only 5 + 2√5). Vertex, asymptote, trap: the three graph-reading habits this topic drills.
