Practice Questions

  • NEB 2023 (verified PYQ): If A = {1, 2, 3} and B = {2, 3, 4}, find A ∪ B, A ∩ B and A − B. (3m) — Union — elements in at least one set: A∪B = {1, 2, 3, 4}. Intersection — elements common to both: A∩B = {2, 3}. Difference — elements of A not in B: A−B = {1} (note B−A would be {4} — difference is not commutative). Consistency check: the inclusion–exclusion theorem |A∪B| = |A| + |B| − |A∩B| gives 3 + 3 − 2 = 4 = |{1,2,3,4}| ✓ — the counts agree, so no element was missed or double-counted.
  • NEB 2022 (verified PYQ): Prove that A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C). (3m) — Membership-table proof. Every element x is in one of 8 patterns w.r.t. A, B, C. Build the columns: B∩C (T iff both T); LHS = A∪(B∩C); A∪B; A∪C; RHS = (A∪B)∩(A∪C). Checking the 8 rows: x∈A,∈B,∈C: LHS T, RHS T∩T = T ✓; x∈A only: LHS T (in A), RHS (A∪B=T)∩(A∪C=T) = T ✓; x∈B only: B∩C = F so LHS F; RHS T∩F = F ✓; x∈C only: LHS F, RHS F∩T = F ✓; x∈none: F = F∩F = F ✓; x∈B,C not A: B∩C = T so LHS T; RHS T∩T = T ✓; remaining rows (A with B not C; A with C not B) both give T = T ✓. All 8 rows agree ⟹ A ∪ (B∩C) = (A∪B)∩(A∪C) — the distributive law of union over intersection. ∎
  • NEB 2022 (verified PYQ): If a + b + c = 0, then a³ + b³ + c³ is equal to: (a) abc (b) 3abc (c) −abc (d) 0 (1m) — Key identity: a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca). Apply the hypothesis: a + b + c = 0 makes the right-hand side zero, hence a³ + b³ + c³ − 3abc = 0, i.e. a³ + b³ + c³ = 3abc — option (b). (Conversely, a³ + b³ + c³ = 3abc forces a + b + c = 0 or a = b = c — the identity cuts both ways, which is why it is a favourite factorisation tool.)

Key Points

  • Statement: definite truth value. Connectives: not, and, or, implies, iff; p -> q false only when p T and q F (vacuously true otherwise). Tautology (always true), contradiction (always false), contingency. Power set has 2^n members. Inclusion-exclusion: |A u B| = |A| + |B| - |A n B|. De Morgan: (A u B)' = A' n B', (A n B)' = A' u B'. Distributive: A u (B n C) = (A u B) n (A u C) and the dual. Absorption: A u (A n B) = A. Proof method: membership table over the 8 in/out patterns of A, B, C. Logic-set dictionary: not-complement, and-intersection, or-union. Material implication: p -> q equivalent to (not p) or q. Conditional identity: a^3 + b^3 + c^3 = 3abc when a + b + c = 0.

Summary

Logic and sets share one grammar. A statement has a definite truth value; connectives build compound statements whose truth tables obey fixed conventions — crucially p → q is false only for T→F (vacuous truth elsewhere), and p → q ≡ ¬p ∨ q. Tautologies are always true, contradictions always false. On the set side, the membership table — 8 in/out patterns for A, B, C — proves every identity finitely: De Morgan ((A∪B)′ = A′∩B′), distributivity (A∪(B∩C) = (A∪B)∩(A∪C), verified row-by-row), absorption A∪(A∩B) = A, and inclusion–exclusion |A∪B| = |A| + |B| − |A∩B| (NEB 2023's {1,2,3}/{2,3,4} operations check out: union {1,2,3,4}, intersection {2,3}, difference {1}). The logic–set dictionary (¬↔′, ∧↔∩, ∨↔∪) makes one table serve both subjects, and the conditional identity a³+b³+c³ = 3abc when a+b+c = 0 (NEB 2022) is algebra's most-quoted bonus.

Notes

  • 1. Topic Introduction — Logic Meets Sets

    Statements, connectives and truth tables are the grammar of reasoning; sets are the nouns the grammar talks about. The theorems: the algebra of sets — De Morgan's laws, distributive laws, absorption — proved by membership tables, with truth tables as the logical twin.

  • 2. Fundamental Concepts

    2.1 Statements and connectives

    • A statement is a declarative sentence that is definitively true or false. Connectives: ¬ (not), ∧ (and), ∨ (or), → (implies), ↔ (if and only if).
    • Truth-table conventions: ¬ flips T/F; p ∧ q is true only when both are true; p ∨ q is false only when both are false; p → q is false only when p is T and q is F (vacuously true otherwise); p ↔ q true when both agree.

    2.2 Tautology, contradiction, contingency

    • Tautology: true for every assignment (e.g. p ∨ ¬p); contradiction: false for every assignment (p ∧ ¬p); contingency: mixed.

    2.3 Sets and operations

    • Union A∪B, intersection A∩B, difference A−B, complement A′, and the power set P(A) with 2ⁿ members for |A| = n.
    • Inclusion–exclusion (theorem): for two sets |A∪B| = |A| + |B| − |A∩B|; for three, add pairwise intersections, subtract the triple.

    2.4 The algebra of sets (theorems)

    • De Morgan: (A∪B)′ = A′∩B′ and (A∩B)′ = A′∪B′ — negation flips the connective.
    • Distributive: A∪(B∩C) = (A∪B)∩(A∪C); A∩(B∪C) = (A∩B)∪(A∩C).
    • Absorption: A∪(A∩B) = A; Idempotent: A∪A = A; Complement laws: A∪A′ = U, A∩A′ = φ.
    • Proof method: membership (element) table — each x is in/out of A, B, C (8 rows); both sides agree in every row ⟺ the identity holds.

  • 4. Detailed Explanation

    4.1 Why the membership table proves everything

    • Two sets are equal iff they contain exactly the same elements. Tabulating membership for every element-type (in/out of each of A, B, C) exhausts all cases — a finite proof of an infinite statement.

    4.2 The logic–set dictionary

    • ¬ ↔ complement, ∧ ↔ intersection, ∨ ↔ union, → ⊂-style inclusion: every tautology is a set identity in disguise. Learning one table serves both subjects.

    4.3 Implication's oddity

    • p → q is vacuously true when p is false — "if the moon is cheese then 2 = 2" is true. This convention makes proofs by implication coherent.

  • 6. Common Confusions

    p → q with false p is true: the only false case is T→F — students mark false antecedent rows wrong.

  • A − B ≠ B − A: difference is not commutative; A−B = A∩B′ is the working form.
  • De Morgan's flip: complementing a union gives an intersection of complements — the connective changes too.

  • 7. Exam Application

    NEB 2023 (verified PYQ): If A = {1, 2, 3} and B = {2, 3, 4}, find A ∪ B, A ∩ B and A − B. (3m) — Union (elements in either): A∪B = {1, 2, 3, 4}. Intersection (elements in both): A∩B = {2, 3}. Difference (in A, not in B): A−B = {1}. Check: |A∪B| = |A| + |B| − |A∩B| = 3 + 3 − 2 = 4 ✓ — inclusion–exclusion confirms the count.

  • NEB 2022 (verified PYQ): Prove A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C). (3m) — Membership table with rows for x in/out of A, B, C. Columns: B∩C (T only when both B, C are T); left A∪(B∩C); A∪B; A∪C; right (A∪B)∩(A∪C). Comparing columns row by row: for every one of the 8 membership patterns, A∪(B∩C) and (A∪B)∩(A∪C) agree — e.g. x ∈ A only: both T (left: in A; right: in both unions); x ∉ A, x ∈ B only: left = B∩C = F, right = (T)∩(F) = F. All 8 rows agree ⟹ the sets are equal ∎ (distributive law of union over intersection).
  • NEB-style (2m): Construct the truth table of p → q and (¬p) ∨ q and show they are logically equivalent. — Rows (p, q): (T,T), (T,F), (F,T), (F,F). p→q: T, F, T, T. ¬p∨q: F→T gives T; T→F gives F; F→T gives T; F→F gives T — column T, F, T, T. Identical columns ⟹ p → q ≡ ¬p ∨ q, the material-implication equivalence that converts implications into disjunctions.
  • NEB 2022 (verified PYQ): If a + b + c = 0, then a³ + b³ + c³ equals: (1m) — Identity: a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca). With a + b + c = 0 the right side vanishes, so a³ + b³ + c³ = 3abc → option (b). (This is the algebra's most-quoted conditional identity.)
