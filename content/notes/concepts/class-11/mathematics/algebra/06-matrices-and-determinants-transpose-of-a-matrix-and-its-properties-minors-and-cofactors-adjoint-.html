Notes

  • 1. Topic Introduction — The Determinant's Inner Machinery

    Minors, cofactors and the adjoint are the moving parts inside every determinant: the expansion theorem, the product rule |AB| = |A||B|, and the inverse formula A⁻¹ = adj A/|A|. This topic builds them carefully for 3×3 and beyond.

  • 2. Fundamental Concepts

    2.1 Minors and cofactors

    • Minor Mᵢⱼ: the determinant of the submatrix left after deleting row i and column j.
    • Cofactor: Cᵢⱼ = (−1)^(i+j) Mᵢⱼ — the checkerboard sign pattern (+ − + / − + − / + − +).
    • Theorem (Laplace expansion): |A| = Σⱼ aᵢⱼCᵢⱼ along any row or column — all choices give the same value; pick the row with the most zeros.

    2.2 Adjoint

    • adj A = transpose of the cofactor matrix: (adj A)ᵢⱼ = Cⱼᵢ.
    • Theorem (the adjoint identity): A·adj A = adj A·A = |A|·I — the master identity from which the inverse formula falls out: A⁻¹ = adj A/|A| when |A| ≠ 0.

    2.3 Determinant theorems

    • |Aᵀ| = |A|; |AB| = |A||B|; |kA| = kⁿ|A| for n×n; row swap flips sign; adding a multiple of one row to another changes nothing; identical/zero rows ⟹ 0.
    • Cramer's rule: for AX = B with |A| ≠ 0, xᵢ = |Aᵢ|/|A| where Aᵢ replaces column i by B.

    2.4 Singularity

    • |A| = 0 ⟺ rows are linearly dependent ⟺ A has no inverse ⟺ AX = 0 has non-trivial solutions — one condition, four faces.

  • 4. Detailed Explanation

    4.1 Why the checkerboard sign

    • The sign (−1)^(i+j) compensates for the row/column swaps hidden in the submatrix; without it, expansions along different rows would disagree.

    4.2 The adjoint identity as the keystone

    • A·adj A = |A|I is simultaneously: the inverse formula (divide by |A|), the reason singular matrices have no inverse (division by zero), and a fast check on adj computations.

    4.3 Expansion strategy

    • Create zeros first (row operations that don't change |A|), then expand along the zero-rich row — the 3×3 slog becomes a 2×2 snap.

  • 6. Common Confusions

    Sign pattern starts with + at (1,1): (−1)^(1+1) = +1; the alternating pattern is + − + / − + − / + − +.

  • adj A transposes the cofactor matrix: using cofactors untransposed poisons every inverse computation.
  • |kA| = kⁿ|A|: the scalar crosses each of n rows — for 3×3, |2A| = 8|A|, not 2|A|.

  • 7. Exam Application

    NEB-style (3m): Find the cofactors of all entries of A = [[1, 2, 3], [4, 5, 6], [7, 8, 10]] and hence |A|. — C₁₁ = +(5·10 − 6·8) = 2; C₁₂ = −(4·10 − 6·7) = −(40−42) = 2; C₁₃ = +(4·8 − 5·7) = −3; C₂₁ = −(2·10 − 3·8) = −(20−24) = 4; C₂₂ = +(1·10 − 3·7) = −11; C₂₃ = −(1·8 − 2·7) = 6; C₃₁ = +(2·6 − 3·5) = −3; C₃₂ = −(1·6 − 3·4) = 6; C₃₃ = +(1·5 − 2·4) = −3. |A| = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃ = 2 + 4 − 9 = −3 (expanding along row 1). Any row/column gives −3 — the expansion theorem's consistency.

  • NEB-style (3m): Verify A·adj A = |A|I for A = [[2, 1], [3, 4]]. — Cofactors: C₁₁ = 4, C₁₂ = −3, C₂₁ = −1, C₂₂ = 2 ⟹ adj A = [[4, −1], [−3, 2]]. A·adj A = [[2·4 + 1·(−3), 2·(−1) + 1·2], [3·4 + 4·(−3), 3·(−1) + 4·2]] = [[5, 0], [0, 5]] = 5I = |A|I ✓ — the master identity, and the reason A⁻¹ = adj A/|A| works.
  • NEB-style (3m): Solve by Cramer's rule: 2x + 3y = 8, x − y = −1. — |A| = 2(−1) − 3(1) = −5. |A₁| (replace column 1 by B) = 8(−1) − 3(−1) = −5 ⟹ x = −5/−5 = 1. |A₂| = 2(−1) − 8(1) = −10 ⟹ y = −10/−5 = 2. Check: 2 + 6 = 8 ✓, 1 − 2 = −1 ✓.

Practice Questions

  • NEB-style (3m): Find all cofactors of A = [[1, 2, 3], [4, 5, 6], [7, 8, 10]] and evaluate |A| by expansion. — Cofactors (sign × minor): C₁₁ = +(5·10 − 6·8) = +2; C₁₂ = −(4·10 − 6·7) = −(−2) = +2; C₁₃ = +(4·8 − 5·7) = −3; C₂₁ = −(2·10 − 3·8) = +4; C₂₂ = +(1·10 − 3·7) = −11; C₂₃ = −(1·8 − 2·7) = +6; C₃₁ = +(2·6 − 3·5) = −3; C₃₂ = −(1·6 − 3·4) = +6; C₃₃ = +(1·5 − 2·4) = −3. Expansion along row 1: |A| = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃ = (1)(2) + (2)(2) + (3)(−3) = 2 + 4 − 9 = −3. Consistency check along column 1: (1)(2) + (4)(4) + (7)(−3) = 2 + 16 − 21 = −3 ✓ — the Laplace theorem guarantees every row/column choice yields the same determinant.
  • NEB-style (3m): Verify the adjoint identity A·adj A = |A|·I for A = [[2, 1], [3, 4]]. — Cofactors: C₁₁ = +4, C₁₂ = −3, C₂₁ = −1, C₂₂ = +2 ⟹ cofactor matrix [[4, −3], [−1, 2]] ⟹ adj A = transpose = [[4, −1], [−3, 2]]. Product: A·adj A = [[2·4 + 1·(−3), 2·(−1) + 1·2], [3·4 + 4·(−3), 3·(−1) + 4·2]] = [[8 − 3, −2 + 2], [12 − 12, −3 + 8]] = [[5, 0], [0, 5]]. Compare: |A| = 8 − 3 = 5, and |A|·I = 5I = [[5, 0], [0, 5]] ✓ — the identity holds. Why it matters: dividing the identity by |A| gives A⁻¹ = adj A/|A| = (1/5)[[4, −1], [−3, 2]]; and when |A| = 0 the equation A·adj A = 0 admits no inverse — singularity in one line.
  • NEB-style (3m): Solve the system 2x + 3y = 8, x − y = −1 using Cramer's rule. — Coefficient determinant: |A| = |2 3; 1 −1| = (2)(−1) − (3)(1) = −5 ≠ 0 ⟹ Cramer applies. x-determinant (replace column 1 with B = [8, −1]): |A₁| = |8 3; −1 −1| = (8)(−1) − (3)(−1) = −8 + 3 = −5 ⟹ x = |A₁|/|A| = −5/−5 = 1. y-determinant (replace column 2): |A₂| = |2 8; 1 −1| = (2)(−1) − (8)(1) = −10 ⟹ y = −10/−5 = 2. Verification: 2(1) + 3(2) = 8 ✓ and 1 − 2 = −1 ✓. Cramer's rule works because each unknown is the ratio of two "volumes": the numerator measures how far B tilts the corresponding column.

Key Points

  • Minor M_ij: determinant after deleting row i, column j. Cofactor C_ij = (-1)^(i+j) M_ij (checkerboard + - + / - + - / + - +). Laplace expansion: |A| = sum a_ij C_ij along any row or column - all agree; choose the zero-rich row. Adjoint: transpose of the cofactor matrix, (adj A)_ij = C_ji. Master identity: A adj A = adj A A = |A| I, giving A^-1 = adj A/|A| for |A| != 0. Determinant theorems: |A^T| = |A|; |AB| = |A||B|; |kA| = k^n |A|; row swap flips sign; row-addition changes nothing; zero/equal rows give 0. Cramer's rule: x_i = |A_i|/|A|. |A| = 0 iff rows dependent iff no inverse iff AX = 0 has non-trivial solutions.

Summary

Determinants have anatomy. The minor Mᵢⱼ deletes row i and column j; the cofactor Cᵢⱼ = (−1)^(i+j)Mᵢⱼ stamps the checkerboard sign (+−+/−+−/++- pattern starting + at (1,1)); and the Laplace expansion |A| = Σ aᵢⱼCᵢⱼ works along any row or column — all choices agree (the 3×3 with cofactors 2, 2, −3, … expands to −3 along row 1 and column 1 alike). The adjoint transposes the cofactor matrix and satisfies the keystone identity A·adj A = |A|·I, verified directly for [[2,1],[3,4]] — from which A⁻¹ = adj A/|A| follows, and whose failure at |A| = 0 is exactly singularity. Supporting theorems: |Aᵀ| = |A|, |AB| = |A||B|, |kA| = kⁿ|A|, row-swap sign flips, row-addition neutrality. Cramer's rule xᵢ = |Aᵢ|/|A| solves systems as volume ratios (x = 1, y = 2 for the sample pair). Sign, transpose, identity: the three places errors and marks live.
