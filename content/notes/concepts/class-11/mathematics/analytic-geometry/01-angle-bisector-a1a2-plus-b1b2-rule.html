Angle Bisector Between Two Lines — The a₁a₂ + b₁b₂ Rule

Class 11MathematicsAnalytic Geometry

Notes

  • 1. Topic Introduction — The Angle Bisector Rule a₁a₂ + b₁b₂

    This canonical carries the angle-bisector machinery: normalised distance equations, the sign convention, the a₁a₂ + b₁b₂ acute/obtuse rule, and the built-in perpendicularity check. The bisectors of two lines are the locus of points equidistant from both — one definition, two equations, one sign decision.

  • 2. Theorem Mirror

    • Normalised distance: dividing aᵢx + bᵢy + cᵢ by √(aᵢ² + bᵢ²) turns the line's equation into "signed distance = 0"; its absolute value at any point is the true distance to the line.
    • Bisector equations: (a₁x + b₁y + c₁)/√(a₁² + b₁²) = ±(a₂x + b₂y + c₂)/√(a₂² + b₂²) — the (+) and (−) pair, always perpendicular to each other.
    • Sign convention: first rewrite both equations so c₁, c₂ > 0; then a₁a₂ + b₁b₂ < 0 ⟹ the (+) bisector is the acute one; > 0 ⟹ the (+) bisector is obtuse.
    • Origin side: the bisector containing the origin is found by making both constants positive and taking the (+) sign.

  • 3. Deep Conceptual — Bisectors as an Equal-Distance Locus

    • The defining idea: points equidistant from two lines. Normalising converts each line's equation into a signed distance, and "distance₁ = distance₂" is exactly the ± pair — the absolute values create two equations because "equal magnitude" admits two sign arrangements.
    • The sign decision is bookkeeping: with c₁, c₂ > 0, the (+) equation equates the same-signed distances — the region where the point lies on the same side of both lines. Whether that region is the acute or obtuse wedge is decided by the dot product a₁a₂ + b₁b₂: negative normal vectors (obtuse angle between normals) mean the same-side wedge is the acute one. The rule is the dot product read as geometry.
    • Perpendicularity for free: the two bisectors of any angle are perpendicular — a consequence the equations exhibit automatically (their normal vectors (a₁/√±…) satisfy the dot-product zero condition), and a built-in verification for every computation.

  • 4. Deep Conceptual — Why the Constants' Signs Must Be Standardised First

    • The a₁a₂ + b₁b₂ rule is not sign-invariant: multiplying one equation by −1 flips both the constants and the rule's verdict. The convention "make c₁, c₂ > 0 first" pins the normal vectors' directions so the rule's statement is unambiguous — the rule without the convention is a coin flip.
    • The origin-side corollary is the same machinery: with constants positive, the origin has both signed distances negative... equivalently it lies on the same side of both lines, so the (+) bisector passes through the region containing it. One convention, two corollaries.

  • 5. Worked Example Types

    • Type A — write the bisector pair: normalise, present ±, done.
    • Type B — classify acute/obtuse: standardise constants, compute a₁a₂ + b₁b₂, assign.
    • Type C — origin-side selection: constants positive, (+) sign.
    • Type D — perpendicularity check: slopes multiply to −1 as the built-in audit.

  • 6. Common Confusions

    "The rule works on the given equations as-is": only after the constants are made positive. "The two bisectors are parallel": they are perpendicular — always, by the angle's own geometry.

Summary

Angle bisectors are the equal-distance locus made algebraic: normalise each line into a signed distance, equate up to ±, and the two equations fall out — perpendicular to each other by an identity, not a coincidence. The a₁a₂ + b₁b₂ rule classifies acute versus obtuse, but only after the constants-positive convention pins the normals' directions; the origin-side corollary rides the same convention. Standardise, normalise, apply the rule, and verify with the built-in right angle.

Universal Facts

  • The two angle bisectors are perpendicular for every pair of intersecting lines.

Examples

  • The convention's teeth - the same two lines with one equation multiplied by -1 flip the rule's verdict - the constants-positive convention is what makes a1a2 + b1b2 decisive.

Practice Questions

  • NEB-style (5m): Write the equations of the bisectors of the angles between the lines x + 2y − 5 = 0 and 2x + y − 3 = 0. — Normalisers: √5 and √5 (both lines have the same √(a²+b²) — a happy accident). Bisector pair: (x + 2y − 5)/√5 = ±(2x + y − 3)/√5 ⟹ x + 2y − 5 = ±(2x + y − 3). (+): x + 2y − 5 = 2x + y − 3 ⟹ x − y + 2 = 0. (−): x + 2y − 5 = −2x − y + 3 ⟹ 3x + 3y − 8 = 0. Perpendicularity check: x − y + 2 = 0 ⟹ y = x + 2 (slope 1); 3x + 3y − 8 = 0 ⟹ y = −x + 8/3 (slope −1) ⟹ product −1 ✓. Deep point: equal normaliser lengths collapse the ± into plain linear equations — when √(a₁²+b₁²) = √(a₂²+b₂²) the bisectors come out with integer coefficients, a structure worth noticing before any arithmetic.
  • NEB-style (6m): Find the bisectors of x + y − 1 = 0 and x − y − 1 = 0 and determine which contains the origin. — Standardise: c₁ = −1 < 0 ⟹ rewrite L₁ as −x − y + 1 = 0; c₂ = −1 < 0 ⟹ L₂ as −x + y + 1 = 0. Now both constants positive. Normalisers: both √2. Bisector pair: (−x−y+1)/√2 = ±(−x+y+1)/√2. (+): −x−y+1 = −x+y+1 ⟹ y = 0. (−): −x−y+1 = x−y−1 ⟹ x = 1. Origin test: (0, 0) lies on y = 0 ⟹ the (+) bisector y = 0 contains the origin — consistent with the corollary (constants positive, (+) sign). Rule check: a₁a₂ + b₁b₂ = (−1)(−1) + (−1)(1) = 1 − 1 = 0 ⟹ the lines are perpendicular (slopes −1 and +1) — for perpendicular lines the "acute/obtuse" distinction dissolves (both angles 90°) and the two bisectors are the axis-parallel pair. Deep point: the a₁a₂ + b₁b₂ = 0 case is the rule's boundary — perpendicular lines have no acute/obtuse wedge to distinguish, and their bisectors bisect the right angles into 45° each; recognising the zero case saves the meaningless classification step.
  • NEB-style (6m): For the lines 3x + 4y − 5 = 0 and 5x + 12y − 13 = 0, find the acute angle bisector. — Standardise: c₁ = −5 < 0 ⟹ rewrite L₁: −3x − 4y + 5 = 0; L₂: c₂ = −13 < 0 ⟹ −5x − 12y + 13 = 0. Normalisers: 5 and 13. Rule: a₁a₂ + b₁b₂ = (−3)(−5) + (−4)(−12) = 15 + 48 = 63 > 0 ⟹ the (+) bisector is obtuse ⟹ the (−) bisector is acute. (−) bisector: (−3x−4y+5)/5 = −(−5x−12y+13)/13 ⟹ 13(−3x−4y+5) = −5(−5x−12y+13) ⟹ −39x − 52y + 65 = 25x + 60y − 65 ⟹ 64x + 112y − 130 = 0 ⟹ 32x + 56y − 65 = 0. Perpendicularity partner: the (+) bisector: 13(−3x−4y+5) = 5(−5x−12y+13) ⟹ −39x−52y+65 = −25x−60y+65 ⟹ −14x + 8y = 0 ⟹ 7x − 4y = 0; slopes: −4/7 and 7/4 ⟹ product −1 ✓. Deep point: both constants were negative — the standardisation step was not optional decoration but the rule's licence; skipping it would have used the raw dot product 3·5 + 4·12 = 63 (same here by luck of the double negation) with no way to know the verdict was trustworthy.
  • NEB-style (6m): Show that the two bisectors of any two intersecting lines are perpendicular, using their equations. — Setup: bisectors B₊: (N₁ = N₂) and B₋: (N₁ = −N₂) where Nᵢ = (aᵢx+bᵢy+cᵢ)/√(aᵢ²+bᵢ²) are the normalised forms. Expand: B₊: (a₁/√d₁ − a₂/√d₂)x + (b₁/√d₁ − b₂/√d₂)y + (const) = 0; B₋: (a₁/√d₁ + a₂/√d₂)x + (b₁/√d₁ + b₂/√d₂)y + (const) = 0. Normal vectors: u = (a₁/√d₁ − a₂/√d₂, b₁/√d₁ − b₂/√d₂) and v = (a₁/√d₁ + a₂/√d₂, b₁/√d₁ + b₂/√d₂). Dot product: u·v = (a₁²/d₁ − a₂²/d₂) + (b₁²/d₁ − b₂²/d₂) = (a₁² + b₁²)/d₁ − (a₂² + b₂²)/d₂ = 1 − 1 = 0 ∎. Deep point: the perpendicularity is not an accident to check numerically but an identity — the normalised coefficients' squares are exactly 1, so the cross terms cancel and the dot product vanishes for every pair of lines; the general proof is shorter than most numerical verifications.

Formulas

    • (a₁x+b₁y+c₁)/√(a₁²+b₁²) = ±(a₂x+b₂y+c₂)/√(a₂²+b₂²)
    • c₁, c₂ > 0 and a₁a₂ + b₁b₂ < 0 ⟹ (+) bisector is acute

Key Points

  • Normalise: (ax+by+c)/sqrt(a^2+b^2) is the signed distance. Bisectors: normalised forms equal up to +-; the pair is always perpendicular. Convention first: make c1, c2 > 0; then a1a2 + b1b2 < 0 => (+) bisector is acute, > 0 => obtuse. Origin side: constants positive, take (+). The rule is the dot product of the normal vectors read as wedge geometry.
