Notes

  • 1. Topic Introduction — The Companion Doorway to Continuity of a Function

    This canonical is the short-form doorway to continuity of a function: the three-part test, the closure theorems, and the interval workflow in one page. The parent canonical carries the full treatment; this companion mirrors the machinery, adds the audit-economy reading, and drills four heavy-mark problems.

  • 2. Theorem Mirror

    • Three-part test at a: (1) f(a) exists; (2) lim_{x→a} f(x) exists; (3) f(a) = limit. All three ⟹ continuous at a.
    • Interval continuity: continuous on an interval ⟺ continuous at every interior point + one-sided continuity at the included endpoints.
    • Closure theorems: sums, products, quotients (where defined), and compositions of continuous functions are continuous; polynomials continuous everywhere; rationals continuous off their denominator's zeros; sin, cos, exp continuous everywhere; ln continuous on (0, ∞); roots on their domains.
    • Workflow: domain ⟹ suspects ⟹ closure-certify the rest ⟹ triage each suspect (limit, value, classify, repair).

  • 3. Deep Conceptual — Continuity as Cost Accounting

    • Testing continuity is expensive per point (limit + value + comparison) but cheap per interval (one closure theorem certifies infinitely many points). The workflow is an economy: spend closure theorems on intervals, spend tests only on the finite suspect list.
    • The suspect list is complete by construction: undefined points (denominator zeros, domain edges, log arguments ≤ 0) and piecewise joints are the only possible failure sites. This completeness is what converts a local test into a global verdict — "continuous on ℝ \ {suspects}" is a statement about every point, earned by finitely much work.
    • The three parts are independent: f(a) is set by the definition, the limit by the neighbourhood, and continuity is their coincidence. Each part can fail alone, and which part fails determines the classification — the test is a diagnostic, not a pass/fail stamp.

  • 4. Deep Conceptual — What Continuity Buys

    • The IVT: a continuous function on [a, b] attains every value between f(a) and f(b) — existence certificates for roots (sign change ⟹ root) come free from continuity.
    • The EVT: a continuous function on a closed bounded interval attains its max and min — the guarantee that "find the extreme value" always has an answer.
    • Composition insurance: continuous functions commute with limits — the licence behind every substitution. Locating discontinuities is locating where that licence expires.

  • 5. Worked Example Types

    • Type A — closure certification: name the families present (polynomial, rational, root, trig, exp, log, composition) and state the continuous intervals.
    • Type B — suspect triage: at each undefined point or joint, run the three-part test and classify.
    • Type C — parameter welding: find constants making a piecewise joint continuous (one linear equation per seam).
    • Type D — IVT certificate: sign change + continuity ⟹ root in the interval.

  • 6. Common Confusions

    "Not defined ⟹ discontinuous": 1/x is continuous on its domain; x = 0 is an exclusion, not a break. "Continuous ⟹ differentiable": |x| is the standing counterexample.

Confusion

  • A function can be continuous at a point but not differentiable there (e.g., f(x)=∣x∣ at x=0). Continuity is a weaker condition than differentiability.
  • A function can have a limit at a point without being continuous there — the function might be undefined at that point, or its value might differ from the limit.

Practice

  • State where f(x) = √(x − 2)/(x − 3) is continuous.
  • Find k making f(x) = (e^{3x} − 1)/x (x ≠ 0), f(0) = k continuous at 0.
  • Show x³ + x − 5 = 0 has a root between 1 and 2.

Universal Facts

  • Continuity is the hypothesis that converts "should exist" into "does exist" in every existence theorem of calculus.

Practice Questions
  • NEB-style (6m): State where f(x) = √(x − 2)/(x − 3) is continuous, with reasons. — Domain: radicand x − 2 ≥ 0 ⟹ x ≥ 2; denominator x ≠ 3 ⟹ domain [2, 3) ∪ (3, ∞). Closure: the numerator √(x−2) is continuous on [2, ∞) (root family, one-sided at the edge 2); the denominator is continuous and nonzero on the domain ⟹ the quotient is continuous wherever defined — on [2, 3) ∪ (3, ∞), with right-continuity at the edge x = 2. Suspects: x = 3 is an exclusion (not in the domain — no continuity claim, and a wall: numerator → 1 ≠ 0). Deep point: the domain's edge converts the continuity claim at 2 to one-sided automatically — interval continuity's fine print in action.
  • NEB-style (5m): Find k so that f(x) = (e^{3x} − 1)/x for x ≠ 0, f(0) = k is continuous at 0. — Limit (star (eᵘ−1)/u → 1, u = 3x → 0): (e^{3x} − 1)/x = 3·(e^{3x} − 1)/(3x) → 3. Repair value: continuity needs f(0) = limit ⟹ k = 3. Elsewhere: e^{3x} and x continuous, x ≠ 0 ⟹ quotient continuous on ℝ \ {0} by closure. Verdict: with k = 3, f is continuous on all of ℝ. Deep point: the repair value is the exponential star's slope — defining f(0) = 3 is exactly defining (e^{3x})′(0) = 3; continuity repairs and derivative definitions are the same computation.
  • NEB-style (6m): For f(x) = x² for x < 1, f(x) = mx + 2 for x ≥ 1: find m for continuity at 1 and verify the three parts. — LHL: lim x² = 1. RHL: lim (mx + 2) = m + 2. Value: f(1) = m + 2 (≥ owns the point). Continuity: m + 2 = 1 ⟹ m = −1. Verify: Part 1 — f(1) = 1 exists ✓; Part 2 — LHL = RHL = 1 ⟹ limit 1 ✓; Part 3 — 1 = 1 ✓ ⟹ continuous at 1. Deep point: one seam ⟹ one linear equation ⟹ one unknown resolved; continuity conditions are always linear in the parameters, which is why welding questions are algebra systems in disguise.
  • NEB-style (6m): Use the IVT to show that x³ + x − 5 = 0 has a root in (1, 2), and explain continuity's role. — Setup: f(x) = x³ + x − 5, continuous everywhere (polynomial — closure theorem). Endpoints: f(1) = 1 + 1 − 5 = −3 < 0; f(2) = 8 + 2 − 5 = 5 > 0. IVT: 0 lies between −3 and 5 ⟹ ∃c ∈ (1, 2) with f(c) = 0. Continuity's role: without it the conclusion fails — a discontinuous function can step over 0 between its endpoint values; continuity forces the graph to pass through every intermediate height. Deep point: the certificate cost two evaluations; continuity (certified free by closure) supplied the guarantee — the audit economy applies to existence theorems too.

Summary

Continuity at a point is the three-part coincidence — value exists, limit exists, they match — and continuity on an interval is that test at every interior point plus one-sided tests at included endpoints. Closure theorems make the test cheap: certify whole intervals by family membership and spend effort only on the finite suspect list of zeros, edges and joints. The prize is substantial: the IVT's existence certificates and the EVT's attained extrema are continuity's dividends, and every substitution in limit work is its composition licence.
