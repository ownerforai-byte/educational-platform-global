Notes

  • 1. Topic Introduction — The Introductory Limits Drill

    This canonical is the introductory limits drill: first-contact problems that build the substitution-then-transform reflex gently, mirroring the parent limit-system canonical's opening. The drill's discipline is the four-line rhythm done slowly and completely.

  • 2. Theorem Mirror — The Starter Kit

    • Substitution: licensed wherever the function is continuous — polynomials, roots at interior points, |x|, rational functions off zeros.
    • 0/0 recognition: substitute first; a 0/0 result is the signal to transform, never a verdict.
    • Basic transforms: difference of squares/cubes factoring; single conjugate; the two simplest stars (sin u/u → 1, (eᵘ−1)/u → 1).
    • The rhythm: form ⟹ transform ⟹ licence ⟹ value.

  • 3. Deep Conceptual — Why Beginners Must Write All Four Lines

    • The four-line rhythm is training wheels for the theorems: the form line practices diagnosis, the transform line practices identities, the licence line practices the x ≠ a justification, the value line practices continuity-licensed substitution. Skipping lines skips the theorems.
    • The licence line is where understanding lives: "for x ≠ 2" is the entire reason cancellation is legal — the limit's excluded point is what makes the rewritten expression equivalent for the limit's purposes. Students who internalise this line have internalised the definition.
    • Slow drills build the cross-check reflex: verifying (x² − 9)/(x − 3) → 6 against the star naⁿ⁻¹ = 2·3 costs one line and builds the habit that later saves marks on harder problems.

  • 4. Deep Conceptual — The First Contact With "Approach"

    • Introductory drills should be narrated: at x = 2.9, 2.99, 2.999 the function reads 5.9, 5.99, 5.999 — the approach is visible numerically before it is formal. The numeric preview (f(a ± h) for small h) is the bridge from intuition to definition, and it doubles as an error-catching cross-check.
    • Value vs limit, first taste: f(2) undefined next to lim = 6 is the subject's first surprise; the drill's job is to make the surprise familiar — the road and the destination sign are different objects.

  • 5. Worked Example Types

    • Type A — pure substitution: polynomials and continuous pieces; cite continuity.
    • Type B — first 0/0: difference of squares, cancel, substitute, star-check.
    • Type C — first conjugate: single radical, one multiplication, one cancellation.
    • Type D — numeric preview: table the approach, then confirm algebraically.

  • 6. Common Confusions

    "0/0 means the limit is 0": it means transform — the answer could be anything. "Cancelling changes the function": only at the excluded point, which the limit never visits.

Confusion

  • Substituting the point and stopping — the limit asks what the function APPROACHES, not what it equals there.
  • Concluding the limit exists because both sides are 'big' — they must be the SAME FINITE number; 0/0 or −∞/+∞ is a jump.
  • Writing lim=∞ as a result — a divergent limit says the function is unbounded, not that it reached a value.

Practice

  • Evaluate lim_{x→7} (2x − 3) and cite the theorem.
  • Evaluate lim_{x→1} (x² − 1)/(x − 1) with all four lines.
  • Evaluate lim_{h→0} ((2 + h)² − 4)/h.

Universal Facts

  • Every hard limit technique is a faster version of a rhythm learned on these starter problems.

Practice Questions

  • NEB-style (4m): Evaluate lim_{x→7} (2x − 3), citing the theorem. — Theorem: every polynomial is continuous on ℝ ⟹ lim_{x→a} P(x) = P(a) — direct substitution licensed. Value: 2(7) − 3 = 11. Deep point: "just plug in" is the continuity theorem in action; naming it converts a habit into a justification, and the same licence covers roots and |x| at interior points of their domains.
  • NEB-style (5m): Evaluate lim_{x→1} (x² − 1)/(x − 1) with the four-line rhythm. — Form: (1 − 1)/0 = 0/0 — indeterminate, transform required. Transform: x² − 1 = (x − 1)(x + 1) ⟹ expression = x + 1 for x ≠ 1. Licence: the cancellation is valid for x ≠ 1 — exactly the punctured neighbourhood the limit reads. Value: 1 + 1 = 2. Cross-check: the star gives 2·1 = 2 ✓. Deep point: the form line diagnosed, the transform line cured, the licence line justified, the value line finished — four theorems, four lines, one habit.
  • NEB-style (5m): Evaluate lim_{h→0} ((2 + h)² − 4)/h and connect the answer to a derivative. — Form: (4 − 4)/0 = 0/0 ✓. Transform: (2 + h)² − 4 = 4 + 4h + h² − 4 = h(4 + h) ⟹ expression = 4 + h for h ≠ 0. Value: lim = 4. Connection: this is exactly the difference quotient [f(2+h) − f(2)]/h for f(x) = x² — the limit is f′(2) = 4, the derivative met later as the slope of the tangent. Deep point: the introductory drill's h-form is the derivative's native habitat — every first-principles derivative is this rhythm with f's algebra substituted in; the limits unit and the derivative unit are one continuous story.
  • NEB-style (6m): For f(x) = (x³ − 1)/(x − 1), make a numeric preview table near x = 1, state the limit, and verify algebraically. — Preview: f(0.9) = (0.729 − 1)/(−0.1) = 2.71; f(0.99) = (0.970299 − 1)/(−0.01) = 2.9701; f(1.01) = (1.030301 − 1)/(0.01) = 3.0301 ⟹ the values bracket 3 from both sides. Algebraic: x³ − 1 = (x − 1)(x² + x + 1) ⟹ expression = x² + x + 1 for x ≠ 1 ⟹ limit = 1 + 1 + 1 = 3 ✓ — matching the preview. Deep point: the numeric preview is a legitimate cross-check — it catches sign slips and wrong-factor errors before they reach the answer line, and it makes "approach" tangible: the function is heading to 3 through values it never needs to reach.

Formulas

    • x² − a² = (x − a)(x + a); x³ − a³ = (x − a)(x² + ax + a²)
    • sin u/u → 1; (eᵘ − 1)/u → 1 (u → 0)

Key Points

  • Starter kit: substitution where continuous; 0/0 as the transform signal; difference-of-powers factoring; single conjugate; first stars sin u/u and (e^u-1)/u. Four-line rhythm: form, transform, licence, value - each line is a theorem. Numeric preview (f(a +- h)) bridges intuition and definition and doubles as a cross-check.

Summary

The introductory drill builds the subject's reflexes slowly: substitute where continuity is licensed, read 0/0 as a transform signal, run the four-line rhythm — form, transform, licence, value — and cross-check against the matching star or a numeric preview. The licence line carries the definition's deepest idea (the excluded point makes rewriting legal), and the h-form problems are the derivative unit arriving early. Master the rhythm here and every harder limit is the same four lines at speed.

Special Notes

  • The exclusion of x=a in the epsilon-delta definition is the key subtlety: it is what makes a limit independent of the function's value at the point.
  • limx→0​xsinx​=1 holds only in radians; in degrees the value is 180π​.

Important Statements

  • 0/0 is a signal to transform, never a verdict.

Level 1 — Foundation: the idea

Subtopics
1.
Name

Definition

Points
  • The limit of f(x) as x tends to a is L if f(x) gets arbitrarily close to L as x approaches a
  • x approaches a but never needs to equal a
  • The function may be undefined at a and still have a limit there
2.
Name

One-sided limits

Points
  • Left-hand limit uses x approaching from below a
  • Right-hand limit uses x approaching from above a
  • The two-sided limit exists only if both one-sided limits exist and are equal

Level 2 — Core: evaluating limits

Subtopics
1.
Name

Algebraic methods

Points
  • Direct substitution first — if it gives a finite value, that is the limit
  • Factorisation and cancellation for 0/0 forms
  • Rationalisation for limits involving square roots
2.
Name

Standard limits

Points
  • lim (x to 0) sin x / x = 1
  • lim (x to 0) (e^x - 1)/x = 1 and lim (x to 0) log(1+x)/x = 1
  • lim (x to 0) (a^x - 1)/x = log a

The seven indeterminate forms

Points
  • 0/0, infinity/infinity, 0 x infinity, infinity - infinity
  • 1^infinity, 0^0, infinity^0

Advanced tools

Frequently missed
