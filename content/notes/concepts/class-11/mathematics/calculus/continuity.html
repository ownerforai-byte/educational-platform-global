Notes

  • 1. Topic Introduction — The Companion Doorway to Continuity Overall

    This canonical is the catch-all continuity companion: the definition, the three-point audit, the discontinuity catalogue, and the repair programme in one page. It mirrors the parent continuity canonicals and exists so learners entering through this door meet the same theorems.

  • 2. Theorem Mirror

    • Definition: f is continuous at a ⟺ lim_{x→a}f(x) = f(a) — three facts: the limit exists (both sides agree), the value exists, and they match.
    • The audit: limit? value? match? — each question's failure names the discontinuity.
    • Catalogue: removable (limit exists, value missing or mismatched — hole or detached dot); jump (both one-sided limits exist, disagree — the cliff); infinite (one or both sides → ±∞ — the wall); oscillatory (no approach settles — sin(1/x) at 0).
    • Continuity of standard functions: polynomials everywhere; rationals off denominator zeros; roots on their domains; sin, cos everywhere; exp everywhere; ln on (0, ∞).

  • 3. Deep Conceptual — Continuity Is a Contract Between Limit and Value

    • The definition welds two independent objects — the approach behaviour (limit) and the anchored behaviour (value) — into one demand. The audit's three questions are independent: each can fail alone, and the failure pattern is the classification.
    • The catalogue is a taxonomy of mismatches: removable = the approach is fine but the anchor is wrong (repairable by re-anchoring); jump = the two approaches disagree with each other (no single limit to anchor); infinite/oscillatory = the approach itself fails (nothing to anchor). Repair is possible exactly when the limit exists.
    • Continuity is local, and functions are continuous almost everywhere they exist: the standard functions fail only at their suspect points (denominator zeros, domain edges, piecewise joints) — the audit is always a pointwise question.

  • 4. Deep Conceptual — The Repair Programme and the Extension Idea

    • Removable repair: define f(a) = lim_{x→a}f — one value re-anchors the function; the graph's hole is filled. This is the simplest instance of extension: enlarging a function's domain to make it continuous.
    • Jump and wall are unrepairable: no value at a can reconcile two different one-sided limits or an infinite one — the failure is in the approach, not the anchor. Knowing which failures are repairable is the practical payoff of the taxonomy.
    • Piecewise welding: for f defined by cases, the joint a is the only suspect — compute LHL and RHL from each formula, compare with the assigned value, and solve for any unknown parameter that makes the weld smooth. The audit becomes an equation for the parameter.

  • 5. Worked Example Types

    • Type A — three-question audit: limit, value, match at a named point.
    • Type B — classification: name the discontinuity from the failure pattern.
    • Type C — repair: re-anchor a removable discontinuity.
    • Type D — parameter weld: find k (or a, b) making a piecewise function continuous.

  • 6. Common Confusions

    "Continuous means you can draw it without lifting the pen": the folk picture — the definition is the three-point match, and it is local. "A hole breaks continuity forever": removable means one re-definition repairs it.

Confusion

  • Checking only that f(a) is defined and declaring continuity — the limit must exist and match.
  • Conflating continuity with differentiability — ∣x∣ at 0 is continuous but not differentiable.
  • Using a one-sided limit in place of the two-sided one at a join point.

Universal Facts

  • Continuity is local: every standard function is continuous everywhere except its named suspects.

Summary

Continuity is a three-fact contract at each point — limit exists, value exists, they match — and the failure pattern classifies the discontinuity: removable (repairable by re-anchoring), jump (sides disagree), infinite (the approach itself fails), oscillatory. Repair is possible exactly when the limit exists, which is why the audit's order is the diagnosis. Standard functions fail only at their suspects, and piecewise welds convert the audit into an equation for the parameter — continuity problems are algebra wearing the limit's clothes.

Mcs

1.

At x=0, f(x)=∣x∣ is:

Options
  • continuous and differentiable
  • continuous but not differentiable
  • discontinuous
  • differentiable but not continuous
Answer

B

Explanation

Both one-sided limits equal f(0)=0 so it is continuous; the left derivative −1 and right derivative +1 disagree, so no derivative exists.

2.

f(x)=x−2x2−4​ at x=2 fails which continuity condition?

Options
  • the limit does not exist
  • f(2) is undefined
  • the limit is infinite
  • none fails
Answer

B

Explanation

The limit exists and equals 4; the failing condition is that f(2) is not defined.

3.

If f is continuous on [a,b], which must be true?

Options
  • it is differentiable
  • it is bounded
  • it is increasing
  • it is linear
Answer

B

Explanation

The extreme value theorem guarantees it attains a maximum and minimum, hence boundedness. Differentiability does not follow.

Practice

  • Audit f(x) = (x² − 4)/(x − 2) at x = 2.
  • Classify the discontinuity of f(x) = 1/(x + 3) at x = −3.
  • Find k making f continuous: f = x + k for x ≤ 2, 3x − 1 for x > 2.

Examples

  • The weld equation - f = x+k for x<=2, 3x-1 for x>2: continuity demands 2+k = 5, so k = 3 - the audit becomes algebra for the parameter.

Practice Questions

  • NEB-style (6m): Audit f(x) = (x² − 4)/(x − 2) at x = 2 and repair if possible. — Limit: 0/0 ⟹ factor: (x−2)(x+2)/(x−2) = x + 2 for x ≠ 2 ⟹ lim = 4 (both sides agree). Value: f(2) is undefined (0/0 was evaluated literally) ⟹ the value fails. Classification: removable — the limit exists, the anchor is missing. Repair: define f(2) = 4 ⟹ continuous; the graph's hole at (2, 4) is filled by one point. Deep point: the audit's order mattered — the limit succeeded first, which is exactly the condition that makes repair possible; had the sides disagreed, no re-anchoring could have helped.
  • NEB-style (5m): Classify the discontinuity of f(x) = 1/(x + 3) at x = −3 and describe the graph's behaviour there. — Numerator at −3: 1 ≠ 0 ⟹ a genuine wall. Sides: as x → −3⁺, denominator → 0⁺ ⟹ f → +∞; as x → −3⁻, → −∞. Classification: infinite discontinuity — splitting wall (the denominator's zero is simple, so the sides run opposite). Repairability: none — the approach itself fails; no value at −3 reconciles ±∞. Deep point: the numerator's nonzero value certified the wall before any sign work — the same c/0 diagnosis as the limits unit, now completing a continuity classification.
  • NEB-style (6m): Find k so that f is continuous everywhere: f(x) = x + k for x ≤ 2, f(x) = 3x − 1 for x > 2. — The suspect: the joint x = 2 (both formulas are polynomials — continuous on their own patches). LHL (x → 2⁻): 2 + k. RHL (x → 2⁺): 3(2) − 1 = 5. Value: f(2) = 2 + k (the first formula's patch). Weld equation: LHL = value = RHL ⟹ 2 + k = 5 ⟹ k = 3. Check: with k = 3, f(2) = 5 = RHL ✓ — continuous at 2, hence everywhere. Deep point: the weld turned the audit into one linear equation — the parameter is the unknown in "LHL = value = RHL"; piecewise continuity problems are always this equation with richer algebra on either side.
  • NEB-style (6m): For f(x) = (x³ − 8)/(x − 2) for x ≠ 2 and f(2) = 9, run the full audit at x = 2 and classify. — Limit: 0/0 ⟹ x³ − 8 = (x − 2)(x² + 2x + 4) ⟹ simplified form x² + 2x + 4 ⟹ lim = 4 + 4 + 4 = 12 (both sides agree — the simplified form is continuous). Value: f(2) = 9 (assigned). Match? 12 ≠ 9 ⟹ discontinuous — removable (mismatch): a detached dot at (2, 9) hovering over the hole at (2, 12). Repair: re-define f(2) = 12. Deep point: the assigned value made the audit three-step instead of two — the limit existed (repair possible), the value existed but mismatched; the classification "removable" covers both the missing-anchor and wrong-anchor cases, and the repair is the same single re-definition.
