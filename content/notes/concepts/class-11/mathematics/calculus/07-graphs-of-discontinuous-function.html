Notes

  • 1. Topic Introduction — The Companion Doorway to Discontinuity Graphs

    This canonical is the short-form doorway to graphs of discontinuous functions: how each break type looks on paper and how to read a graph back into a classification. The parent canonical carries the full gallery; this companion mirrors the visual vocabulary, adds the graph-reading discipline, and drills four heavy-mark problems.

  • 2. Theorem Mirror — The Visual Vocabulary

    • Hole (removable, value missing): open dot on an otherwise continuous curve — the branches meet where the point should be.
    • Detached dot (removable, mismatch): open dot at the limit's height plus a filled dot elsewhere at x = a — the value was assigned away from the approach.
    • Jump: two branches ending at different heights; the dot sits on the side that owns f(a) (filled), the other end open.
    • Wall (infinite): branches hugging a vertical line, arrows up/down; odd-power zeros send arrows opposite ways, even-power zeros send them the same way.
    • Oscillatory: infinitely dense folding near the point — the graph never settles (sin(1/x) at 0).

  • 3. Deep Conceptual — Reading Graphs as Evidence, Not Decoration

    • A graph is a witness: every classification claim should be checkable against it. The hole says "limit exists, value missing"; the detached dot says "limit exists, value moved"; the gap says "sides disagree"; the wall says "a side is unbounded." Each visual feature maps to exactly one line of the decision tree.
    • Dots are assignments, branches are approaches: filled/open dots record f(a); the branches' endpoints record the one-sided limits. Confusing the two is how students "see" continuity where there is a removable break — the branch can meet the dot's x-position without matching its height.
    • The floor function's lesson: infinitely many jumps can still be drawable — the discontinuity set ℤ is infinite but orderly (isolated breaks). Graphs scale: zoom in anywhere and the local picture is one of the standard types.

  • 4. Deep Conceptual — Sketching Strategy: Skeleton First, Suspects Last

    • Draw the continuous skeleton first (the formula's curve on its domain intervals), then decorate the suspects: holes, dots, gaps, walls. This ordering prevents the classic error of drawing the exception and forgetting the rule.
    • Walls need side arrows: a wall without arrows is unfinished evidence — the arrows encode which side goes to +∞ and which to −∞, i.e. the sign reading that classifies splitting vs unifying.
    • Piecewise graphs are branch-and-weld pictures: draw each branch on its condition's interval, then mark the seam with the three quantities (LHL endpoint, RHL endpoint, f(a) dot). The seam's visual is the entire continuity verdict.

  • 5. Worked Example Types

    • Type A — sketch from formula: rational function ⟹ skeleton + holes at cancelled roots + walls at surviving roots with side arrows.
    • Type B — read from graph: given the picture, name each feature's type and the side continuity of each dot.
    • Type C — piecewise sketch: branches on their intervals, seam annotated with LHL/RHL/dot.
    • Type D — repair the picture: state which dot to move to make the graph continuous.

  • 6. Common Confusions

    "Open dot means discontinuous": yes at that point — but the type depends on whether the branches meet (removable) or not (jump). "The curve touching the wall means the limit exists": hugging a vertical line is blow-up, not approach to a value.

Confusion

  • Checking only that f(a) is defined and declaring continuity — the limit must exist and match.
  • Conflating continuity with differentiability — ∣x∣ at 0 is continuous but not differentiable.
  • Using a one-sided limit in place of the two-sided one at a join point.

Practice

  • Sketch-reason f(x) = (x² − 4)/(x − 2) and mark the feature at x = 2.
  • Describe the graph of f(x) = 1/(x − 3)² near x = 3.
  • For f(x) = ⌊x⌋, describe the graph's behaviour at each integer.

Universal Facts

  • Zooming into any neighbourhood of any discontinuity shows exactly one of the standard types.

Examples

  • The misleading meeting - branches can meet at x = a while the dot sits elsewhere: the approaches agree, the assignment does not - removable, not continuous.

Practice Questions

  • NEB-style (5m): Describe the graph of f(x) = (x² − 4)/(x − 2) near x = 2, including the feature's type and coordinates. — Simplify: f(x) = x + 2 for x ≠ 2 ⟹ the graph is the line y = x + 2 with a hole at (2, 4). Feature type: the branches meet at x = 2 (both approach height 4) but f(2) is undefined ⟹ removable discontinuity, value missing — an open dot at (2, 4). Repair picture: filling the dot (defining f(2) = 4) makes the line complete. Deep point: the visual and the algebra agree perfectly — the cancelled root predicted a meeting of branches, and the missing value predicted the open dot; sketch and classification are one computation.
  • NEB-style (6m): Describe the graph of f(x) = 1/(x − 3)² near x = 3, and contrast with 1/(x − 3). — For 1/(x−3)²: the denominator is a square ⟹ positive from both sides ⟹ both branches rise along the vertical line x = 3 toward +∞ — a unifying wall (arrows both up). For 1/(x−3): the denominator changes sign across 3 ⟹ the right branch rises to +∞ while the left branch dives to −∞ — a splitting wall (arrows opposite). Classification: both are infinite discontinuities; the parity of the denominator's zero decides the geometry. Deep point: the side arrows are the classification — same-direction arrows (even power) vs opposite arrows (odd power) is the visual form of the sign reading; a sketch without arrows has not answered the question.
  • NEB-style (6m): For f(x) = x + 1 for x < 1, f(x) = 5 − x for x ≥ 1: sketch-reason the seam at x = 1 and give the continuity verdict. — Left branch: y = x + 1 on (−∞, 1), approaching height 2 at x = 1⁻ (open end — the branch's condition excludes 1). Right branch: y = 5 − x on [1, ∞), starting at height 4 at x = 1 (filled dot — the ≥ condition owns the point, f(1) = 4). Seam picture: the left branch ends at (1, 2) open, the right branch begins at (1, 4) filled ⟹ a jump of size 2. Verdict: discontinuous at 1 (sides disagree), right-continuous (dot matches RHL). Deep point: the three seam quantities — LHL endpoint 2, RHL endpoint 4, dot at 4 — are the entire verdict; the graph's geometry and the decision tree are the same audit.
  • NEB-style (5m): A graph shows a curve with an open dot at (1, 3), a filled dot at (1, 5), and continuous branches meeting at the open dot. Classify and give the repair. — Reading the features: branches meeting at height 3 ⟹ LHL = RHL = 3 (limit exists); filled dot at (1, 5) ⟹ f(1) = 5. Classification: limit exists, value differs ⟹ removable discontinuity (mismatch). Repair: move the dot to (1, 3), i.e. redefine f(1) = 3 ⟹ continuous. Deep point: this is the detached-dot signature — the approaches are healthy and meet; only the assignment is away from them. The graph reading (branches vs dots) is exactly the two-question tree: sides first, value second.

Formulas

    • Hole at (a, L): lim = L, f(a) undefined ⟹ open dot at (a, L)
    • Jump at a: branch ends at (a, LHL) and (a, RHL), LHL ≠ RHL

Key Points

  • Visual vocabulary: hole = open dot on meeting branches (removable, value missing); detached dot = open dot + filled dot at different heights (removable, mismatch); jump = branch ends at different heights, dot on the owning side; wall = hugging vertical line with side arrows (odd splits, even unifies); oscillatory = infinite folding. Dots record f(a), branch endpoints record one-sided limits. Sketch skeleton first, decorate suspects last.

Summary

Discontinuity graphs speak the decision tree's language: holes and detached dots for the removable pair, branch-end gaps for jumps, arrowed vertical walls for infinities, dense folding for oscillation. Dots record assignments, branch endpoints record approaches — reading them separately is the whole skill. Sketch the continuous skeleton first and decorate the suspects with labelled coordinates and side arrows; a finished graph is an audit trail in which every feature testifies to one line of the classification.

Special Notes

  • Where a formula is quoted it is valid only under the conditions stated; Checking only that f(a) is defined and declaring continuity — the limit must exist and match.
  • Every result here follows from the definitions, so a first-principles derivation is always a valid fallback in the exam.

Mcs

1.

At x=0, f(x)=∣x∣ is:

Options
  • continuous and differentiable
  • continuous but not differentiable
  • discontinuous
  • differentiable but not continuous
Answer

B

Explanation

Both one-sided limits equal f(0)=0 so it is continuous; the left derivative −1 and right derivative +1 disagree, so no derivative exists.

2.

f(x)=x−2x2−4​ at x=2 fails which continuity condition?

Options
  • the limit does not exist
  • f(2) is undefined
  • the limit is infinite
  • none fails
Answer

B

Explanation

The limit exists and equals 4; the failing condition is that f(2) is not defined.

3.

If f is continuous on [a,b], which must be true?

Options
  • it is differentiable
  • it is bounded
  • it is increasing
  • it is linear
Answer

B

Explanation

The extreme value theorem guarantees it attains a maximum and minimum, hence boundedness. Differentiability does not follow.
