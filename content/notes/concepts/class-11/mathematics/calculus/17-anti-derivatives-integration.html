Notes

  • 1. Topic Introduction — The Companion Doorway to Anti-Derivatives and Integration

    This canonical is the short-form doorway to anti-derivatives and basic integration: the reverse of differentiation, the standard integral table, and the constant of integration in one page. The parent canonical carries the full treatment; this companion mirrors the theorems, adds the deep readings, and drills four heavy-mark problems.

  • 2. Theorem Mirror

    • Definition: F is an anti-derivative of f on an interval if F′ = f there; ∫f(x)dx = F(x) + C.
    • Constant of integration: all anti-derivatives differ by a constant (MVT corollary: equal derivatives ⟹ equal up to constant) — the indefinite integral is a family of parallel curves.
    • Linearity: ∫(af + bg) = a∫f + b∫g — integration inherits differentiation's linearity.
    • Standard table (mirror of the derivative table): ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1); ∫dx/x = ln|x| + C; ∫eˣdx = eˣ + C; ∫sin x dx = −cos x + C; ∫cos x dx = sin x + C; ∫sec²x dx = tan x + C; ∫dx/(1+x²) = tan⁻¹x + C; ∫dx/√(1−x²) = sin⁻¹x + C.

  • 3. Deep Conceptual — Integration Is Differentiation Read Backwards

    • Every integral table entry is a derivative table entry reversed: ∫cos = sin because (sin)′ = cos. The table is not new mathematics but the old table with the arrows flipped — and the + C is the price of reversing (derivatives erase constants, so anti-differentiation must restore a whole family).
    • The verification habit: every integral is checked by differentiating the answer — the Fundamental Theorem's daily use before it is formally met. d/dx[answer] = integrand is the proof; no integration answer is complete without it.
    • The n = −1 gap: the power rule fails at n = −1 because x⁰ = 1's derivative is 0 — the logarithm fills the gap, and the |x| in ln|x| is the domain repair letting one formula serve both signs.

  • 4. Deep Conceptual — The Family Picture and Initial Conditions

    • ∫f dx = F + C draws parallel curves: vertical translates sharing one slope field. An initial condition (F(0) = 3) selects one member — this is exactly how velocity + initial position determines position, the first differential equation every student solves.
    • Differential equations in embryo: given f′ = 2x and f(1) = 4, integrate to f = x² + C, then C = 3 — one constant, one condition. Each further derivative condition would pin further constants, the pattern that generalises to higher-order equations.

  • 5. Worked Example Types

    • Type A — table direct: single entries with + C written every time.
    • Type B — linearity splits: polynomials and sums term by term.
    • Type C — initial conditions: integrate, then pin C from given data.
    • Type D — verification by differentiation: prove the answer, don't assert it.

  • 6. Common Confusions

    "Forgetting + C": the family is the answer; one curve is not. "∫x⁻¹dx = x⁰/0": the gap is real — the logarithm is a different species, not a special case.

Confusion

  • Omitting the constant of integration on a definite integral, where it must be absent because the bounds cancel it.
  • Forgetting that ∫x−1dx=ln∣x∣, which breaks the power rule's pattern.
  • Sign error when reversing dxd​cosx=−sinx.

  • Find f given f′(x) = 6x² − 2 and f(1) = 3.

Universal Facts

  • The |x| in ln|x| is the domain repair that lets one antiderivative serve both half-lines.

Practice Questions

  • NEB-style (5m): Evaluate ∫(3x² − 4x + 5)dx and verify by differentiation. — Linearity + power rule (n + 1 over n + 1): ∫3x²dx = x³; ∫4x dx = 2x²; ∫5dx = 5x ⟹ x³ − 2x² + 5x + C. Verification: d/dx[x³ − 2x² + 5x + C] = 3x² − 4x + 5 ✓ — the integrand returns exactly. Deep point: the power rule reversed divides by the new exponent because differentiation multiplied by it; the verification line is the Fundamental Theorem in daily clothes — every indefinite integral is a claimed anti-derivative until differentiated.
  • NEB-style (5m): Evaluate ∫(2eˣ + 1/x)dx for x > 0. — Table entries: ∫2eˣdx = 2eˣ (the exponential's self-replication); ∫dx/x = ln x on x > 0 (the |x| unnecessary on a positive domain) ⟹ 2eˣ + ln x + C. Verification: 2eˣ + 1/x ✓. Deep point: the domain statement travels with the answer — on x < 0 the same integral reads 2eˣ + ln|x|; the absolute value is not pedantry but the record of which half-line the antiderivative lives on.
  • NEB-style (6m): Find f(x) given f′(x) = 6x² − 2 and f(1) = 3. — Integrate: f(x) = ∫(6x² − 2)dx = 2x³ − 2x + C — the parallel family. Pin C: f(1) = 2 − 2 + C = 3 ⟹ C = 3 ⟹ f(x) = 2x³ − 2x + 3. Verification: f′ = 6x² − 2 ✓ and f(1) = 2 − 2 + 3 = 3 ✓ — both conditions check. Deep point: the two-step (integrate, then pin) is the first boundary-value problem: the derivative condition narrowed the answer to a family, the value condition selected the member; every initial-value problem in later mathematics is this pattern with more constants.
  • NEB-style (6m): A particle moves with velocity v(t) = 3t² − 6t (m/s) and s(0) = 2 m. Find s(t) and the times when the particle is at rest. — Integrate: s(t) = ∫(3t² − 6t)dt = t³ − 3t² + C; s(0) = 2 ⟹ C = 2 ⟹ s(t) = t³ − 3t² + 2. At rest: v = 3t² − 6t = 3t(t − 2) = 0 ⟹ t = 0 and t = 2 s. Verification: s′ = 3t² − 6t = v ✓. Deep point: the physical reading — velocity is the derivative of position, so position is the anti-derivative of velocity with the initial position as the pinning condition; the rest times are the velocity's zeros, the same critical-point machinery from monotonicity now narrating a journey.

Formulas

    • ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1); ∫dx/x = ln|x| + C
    • ∫dx/(1+x²) = tan⁻¹x + C; ∫dx/√(1−x²) = sin⁻¹x + C

Key Points

  • Anti-derivative: F' = f; the indefinite integral is a FAMILY F + C (equal derivatives differ by a constant - MVT corollary). Linearity carries over. Table = derivative table reversed: x^(n+1)/(n+1) (n != -1), ln|x|, e^x, -cos, sin, sec^2, tan^-1, sin^-1. The n = -1 gap is filled by the logarithm. Verify every integral by differentiating the answer. Initial conditions pin C - the first differential equations.

Summary

Anti-differentiation is differentiation with the arrows flipped: the table is the derivative table reversed, the + C restores the family that differentiation erased, and linearity carries over intact. The n = −1 gap is the logarithm's home, initial conditions pin the family to a single curve, and every answer is verified by differentiating it back. Position from velocity is the pattern's physical face — the first differential equation, solved with one integration and one condition.

Special Notes

  • Where a formula is quoted it is valid only under the conditions stated; Omitting the constant of integration on a definite integral, where it must be absent because the bounds cancel it.
  • Every result here follows from the definitions, so a first-principles derivation is always a valid fallback in the exam.
