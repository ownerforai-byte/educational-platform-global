  • 1. Topic Introduction — Differentiation in Reverse

    Anti-derivatives and integration: the basic integral table, integration by substitution, and integration by parts — running the derivative machinery backwards.

  • 2. Fundamental Concepts

    2.1 Anti-derivative and the indefinite integral

    • F is an anti-derivative of f ⟺ F′ = f. ∫f(x)dx = F(x) + C — the whole family, since constants differentiate to 0. Uniqueness theorem: two anti-derivatives of the same f differ by a constant.
    • Basic table (reverse of the derivative table): ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n ≠ −1); ∫dx/x = ln|x| + C; ∫eˣdx = eˣ + C; ∫aˣdx = aˣ/ln a + C; ∫sin x dx = −cos x + C; ∫cos x dx = sin x + C; ∫sec²x dx = tan x + C; ∫1/(1+x²)dx = tan⁻¹x + C; ∫1/√(1−x²)dx = sin⁻¹x + C.

    2.2 Linearity

    • ∫(af + bg)dx = a∫f dx + b∫g dx — term-by-term integration with constants carried.

    2.3 Integration by substitution

    • Theorem: ∫f(g(x))g′(x)dx = ∫f(u)du with u = g(x) — the chain rule reversed. Procedure: spot the inner function, let u = g(x), compute du = g′(x)dx, transform, integrate, substitute back.
    • Workhorses: ∫f(ax+b)dx = (1/a)F(ax+b) + C; ∫f′/f dx = ln|f| + C; ∫fⁿf′dx = fⁿ⁺¹/(n+1) + C.

    2.4 Integration by parts

    • Theorem: ∫u·v dx = u·v − ∫u′·v dx (from the product rule integrated). LIATE ordering for choosing u: Log, Inverse trig, Algebraic, Trig, Exponential — differentiate the earlier class.
    • Classic cycles: ∫x·eˣdx = xeˣ − eˣ + C; ∫ln x dx = x ln x − x + C; ∫x·sin x dx = −x cos x + sin x + C; repeated parts for ∫eˣ sin x dx (two cycles then solve linearly).

  • 4. Detailed Explanation

    4.1 Why + C is not decoration

    • Differentiation destroys constants; integration must restore the whole family. Initial conditions (a point the curve passes through) pin C — the constant is where physical initial data enters calculus.

    4.2 Substitution as pattern recognition

    • The integrand must contain the inner function's derivative (up to a constant): ∫2x·e^{x²}dx has g = x², g′ = 2x present ⟹ u = x² gives ∫eᵘdu = e^{x²} + C. When g′ is absent, rescale constants; when absent entirely, substitution fails.

    4.3 Parts as rearrangement

    • Parts trades one integral for another: choose u so that u′ simplifies (LIATE) and dv so that ∫v dx is doable. Cyclic integrands (eˣ sin x) return to themselves after two applications — solve the resulting linear equation.

    Forgetting + C: the indefinite integral is a family; omitting C loses a mark every time. ∫dx/x = ln|x|: the absolute value is part of the answer (domain symmetry). Parts u-choice: differentiate the LIATE-earlier factor — choosing u = eˣ in ∫xeˣdx loops forever.

  • 7. Exam Application

    NEB 2023 (verified PYQ): Evaluate ∫(3x² + 2x − 1)dx. (3m) — Linearity + power rule reversed: ∫3x²dx = x³; ∫2x dx = x²; ∫(−1)dx = −x. Result: x³ + x² − x + C. (Check: d/dx(x³ + x² − x + C) = 3x² + 2x − 1 ✓.)

  • NEB-style (3m): Evaluate ∫2x·e^{x²}dx. — Substitution: u = x², du = 2x dx ⟹ ∫eᵘdu = eᵘ + C ⟹ e^{x²} + C. The integrand contains the inner function's derivative exactly — the substitution licence is complete.
  • NEB-style (3m): Evaluate ∫x·ln x dx. — Parts (LIATE: Log before Algebraic ⟹ u = ln x, dv = x dx): du = dx/x, v = x²/2. ∫x ln x dx = (x²/2)ln x − ∫(x²/2)(1/x)dx = (x²/2)ln x − (1/2)∫x dx = (x²/2)ln x − x²/4 + C.

  • 8. Deep Conceptual — The Substitution Licence and Its Limits

    • The licence: substitution u = g(x) is legal exactly when the integrand contains g′(x)dx — i.e. the integrand has the shape f(g(x))·g′(x) (up to a constant). The constant is absorbable (multiply by 1/a), the absence is fatal.
    • Why the constant is absorbable: ∫f(g)·c·g′dx = c∫f(g)g′dx — pull the constant out, substitute, push it back. Why absence is fatal: without g′ inside, the substitution introduces an x-dependence (dx = du/g′(x)) that cannot be eliminated — the method stalls by design, signalling a different technique is needed.
    • The reverse-chain test: after any substitution answer, differentiate it back — if the chain rule reproduces the integrand, the substitution was legal. Verification is the substitute for certainty.

  • 9. Deep Conceptual — Parts as Strategic Regression

    • Parts trades integrals: ∫u dv = uv − ∫v du. The trade is good when the new integral is simpler — which the LIATE choice of u engineers (differentiate the factor that simplifies fastest: logs → algebraic; inverse trig → algebraic; algebraic → constant; trig → itself; exponential → itself).
    • The leaderboard logic: LIATE ranks factor types by how fast differentiation tames them. u must come from the earlier class so that u′ drops a rank while dv stays integrable. Choosing u from the later class (e.g. u = eˣ in ∫xeˣdx) regresses — the new integral is harder and the method loops.
    • Cyclic integrands are the exception: eˣ sin x returns to itself after two parts applications — the "regression" becomes an equation I = expression − kI, solved algebraically. Parts can also create structure: ∫ln x dx uses dv = dx (no real partner) and still wins.

  • 10. Deep Conceptual — Integration as Pattern Recognition, Not Algorithm

    • No algorithm exists: unlike differentiation (mechanical rules), integration is a search over patterns — the tables encode the known patterns, and the methods (substitution, parts, partial fractions, trig identities) are transformations that reshape unknown integrands into known ones.
    • The three questions: does the integrand contain an inner derivative? (substitute) Is it a product of unlike types? (parts) Can an identity split it? (trig/algebraic reduction). Every technique answers one of these.
    • Verification culture: because no algorithm guarantees success, differentiate your answer back — the only universal correctness test in integration, and a habit that catches every sign and coefficient slip.

Practice Questions

  • NEB 2023 (verified PYQ): Evaluate ∫(3x² + 2x − 1)dx. (3m) — Linearity: split into three integrals with constants carried: ∫3x²dx + ∫2x dx + ∫(−1)dx. Power rule reversed term by term: ∫3x²dx = 3·x³/3 = x³; ∫2x dx = 2·x²/2 = x²; ∫(−1)dx = −x. Result: x³ + x² − x + C — the constant C is mandatory (the anti-derivative is a family). Verification: d/dx(x³ + x² − x + C) = 3x² + 2x − 1 ✓ — differentiation returns the integrand exactly.
  • NEB-style (3m): Evaluate ∫2x·e^{x²}dx. — Spot the composite: e^{x²} is e^u with u = x², and the integrand contains u′ = 2x as a factor — the substitution licence is complete. Transform: let u = x², du = 2x dx; the integral becomes ∫eᵘdu. Integrate: eᵘ + C. Substitute back: e^{x²} + C. Verify: d/dx e^{x²} = e^{x²}·2x ✓ (chain rule) — the answer differentiates back to the integrand. This is the chain rule reversed in its purest recognisable form: inner function present, inner derivative attached.
  • NEB-style (3m): Evaluate ∫x·ln x dx. — Method selection: a product of unlike types (algebraic × logarithmic) ⟹ integration by parts. LIATE ordering: Log ranks before Algebraic ⟹ choose u = ln x (differentiate the logarithm) and dv = x dx (integrate the power). Compute pieces: du = dx/x; v = ∫x dx = x²/2. Apply the formula ∫u dv = uv − ∫v du: ∫x ln x dx = (x²/2)·ln x − ∫(x²/2)·(1/x)dx = (x²/2)ln x − (1/2)∫x dx = (x²/2)ln x − x²/4 + C. Verify: d/dx[(x²/2)ln x − x²/4] = x ln x + x/2 − x/2 = x ln x ✓. The LIATE choice is what made the new integral simpler — the whole art of parts.
  • NEB-style (6m): Evaluate ∫x²·eˣ dx using integration by parts (applied twice), and verify your answer. — First parts (LIATE: Algebraic before Exponential ⟹ u = x², dv = eˣdx): du = 2x dx, v = eˣ ⟹ ∫x²eˣdx = x²eˣ − ∫2x·eˣdx. Second parts (u = x, dv = eˣdx): du = dx, v = eˣ ⟹ ∫2x·eˣdx = 2[xeˣ − ∫eˣdx] = 2xeˣ − 2eˣ. Assemble: ∫x²eˣdx = x²eˣ − 2xeˣ + 2eˣ + C = eˣ(x² − 2x + 2) + C. Verification (differentiate back): d/dx[eˣ(x² − 2x + 2)] = eˣ(x² − 2x + 2) + eˣ(2x − 2) = eˣ(x² − 2x + 2 + 2x − 2) = x²eˣ ✓. Deep point: each parts application drops the polynomial's degree by one (x² → x → constant) — repeated parts always terminates on polynomial × exponential products, with the answer eˣ times a polynomial of the same degree (here the pattern n!Σ(−x)ᵏ/k! begins to show).
  • NEB-style (5m): Evaluate ∫dx/(x·ln x). — Spot the nested structure: the integrand is (1/ln x)·(1/x) — and 1/x is exactly the derivative of ln x. Substitute: u = ln x, du = dx/x ⟹ the integral becomes ∫du/u. Integrate: ln|u| + C. Substitute back: ln|ln x| + C (x > 0, x ≠ 1 for the original domain). Verification: d/dx[ln|ln x|] = (1/ln x)·(1/x) ✓ — the chain rule returns the integrand exactly. Deep points: (1) a nested substitution — the inner function's derivative is itself a standard integrand; the log-of-a-log answer is the signature of f′/f patterns stacked twice; (2) the f′/f master pattern (∫f′/f dx = ln|f| + C) applies with f = ln x here — recognising the pattern, not computing, is the entire skill.
  • NEB-style (6m): Evaluate ∫eˣ·sin x dx using integration by parts twice and solving the resulting equation. — Let I = ∫eˣ sin x dx. First parts (LIATE: Trig before Exponential ⟹ u = sin x, dv = eˣdx): I = eˣ sin x − ∫eˣ cos x dx. Second parts (u = cos x, dv = eˣdx): ∫eˣ cos x dx = eˣ cos x − ∫eˣ(−sin x)dx = eˣ cos x + I. Substitute back: I = eˣ sin x − [eˣ cos x + I] = eˣ(sin x − cos x) − I. The cyclic equation: the original integral has returned — collect it: 2I = eˣ(sin x − cos x) ⟹ I = eˣ(sin x − cos x)/2 + C. Verification: d/dx{eˣ(sin x − cos x)/2} = ½[eˣ(sin x − cos x) + eˣ(cos x + sin x)] = ½eˣ·2 sin x = eˣ sin x ✓. Deep point: the cyclic integrand is the one case where parts' "regression" becomes progress — returning to I converts the method into a linear equation, and the solve is the finish. The factor 1/2 arises because eˣ and sin x each contribute a factor √2 of phase shift — the amplitude bookkeeping of the product-to-sum identity agrees.
  • NEB-style (5m): Evaluate ∫(2x + 3)/(x² + 3x + 5) dx. — Recognise the f′/f pattern: the denominator's derivative is d/dx(x² + 3x + 5) = 2x + 3 — exactly the numerator. Apply the master pattern: ∫f′(x)/f(x) dx = ln|f(x)| + C with f(x) = x² + 3x + 5 ⟹ the integral = ln(x² + 3x + 5) + C (absolute value unnecessary: the discriminant 9 − 20 < 0 ⟹ the quadratic is always positive). Verification: d/dx[ln(x²+3x+5)] = (2x+3)/(x²+3x+5) ✓. Extension — the near-miss case: for ∫(2x + 1)/(x² + 3x + 5)dx the numerator is not f′; split it: (2x+1) = (2x+3) − 2 ⟹ integral = ln(x²+3x+5) − 2∫dx/[(x+3/2)² + 11/4] = ln(x²+3x+5) − (4/√11)tan⁻¹((2x+3)/√11) + C — the f′/f recognition is always the first move; the remainder goes to the arctangent pattern.

Summary

Integration runs differentiation backwards. An anti-derivative satisfies F′ = f, and ∫f dx = F + C — the +C restores the family constants destroyed by differentiation (two anti-derivatives differ by a constant). The basic table mirrors the derivative table (power rule reversed, ln|x|, eˣ, −cos x, tan⁻¹x, sin⁻¹x), and linearity integrates term by term (NEB 2023: 3x² + 2x − 1 → x³ + x² − x + C). Substitution reverses the chain rule: spot the inner function with its derivative attached (2x·e^{x²} → e^{x²} + C), with the workhorses f(ax+b), f′/f → ln|f|, fⁿf′. Parts reverses the product rule — ∫u dv = uv − ∫v du — with LIATE choosing u so the new integral simplifies (∫x ln x dx → (x²/2)ln x − x²/4 + C); cyclic integrands like eˣ sin x need two passes and a linear solve. Method selection is the exam skill: spot f′, or multiply unlike types, or differentiate the LIATE-earlier factor — then verify by differentiating back.

Practice Questions
  • NEB 2023 (verified PYQ): Evaluate ∫(3x² + 2x − 1)dx. (3m) — Linearity: split into three integrals with constants carried: ∫3x²dx + ∫2x dx + ∫(−1)dx. Power rule reversed term by term: ∫3x²dx = 3·x³/3 = x³; ∫2x dx = 2·x²/2 = x²; ∫(−1)dx = −x. Result: x³ + x² − x + C — the constant C is mandatory (the anti-derivative is a family). Verification: d/dx(x³ + x² − x + C) = 3x² + 2x − 1 ✓ — differentiation returns the integrand exactly.
  • NEB-style (3m): Evaluate ∫2x·e^{x²}dx. — Spot the composite: e^{x²} is e^u with u = x², and the integrand contains u′ = 2x as a factor — the substitution licence is complete. Transform: let u = x², du = 2x dx; the integral becomes ∫eᵘdu. Integrate: eᵘ + C. Substitute back: e^{x²} + C. Verify: d/dx e^{x²} = e^{x²}·2x ✓ (chain rule) — the answer differentiates back to the integrand. This is the chain rule reversed in its purest recognisable form: inner function present, inner derivative attached.
  • NEB-style (3m): Evaluate ∫x·ln x dx. — Method selection: a product of unlike types (algebraic × logarithmic) ⟹ integration by parts. LIATE ordering: Log ranks before Algebraic ⟹ choose u = ln x (differentiate the logarithm) and dv = x dx (integrate the power). Compute pieces: du = dx/x; v = ∫x dx = x²/2. Apply the formula ∫u dv = uv − ∫v du: ∫x ln x dx = (x²/2)·ln x − ∫(x²/2)·(1/x)dx = (x²/2)ln x − (1/2)∫x dx = (x²/2)ln x − x²/4 + C. Verify: d/dx[(x²/2)ln x − x²/4] = x ln x + x/2 − x/2 = x ln x ✓. The LIATE choice is what made the new integral simpler — the whole art of parts.
  • NEB-style (6m): Evaluate ∫x²·eˣ dx using integration by parts (applied twice), and verify your answer. — First parts (LIATE: Algebraic before Exponential ⟹ u = x², dv = eˣdx): du = 2x dx, v = eˣ ⟹ ∫x²eˣdx = x²eˣ − ∫2x·eˣdx. Second parts (u = x, dv = eˣdx): du = dx, v = eˣ ⟹ ∫2x·eˣdx = 2[xeˣ − ∫eˣdx] = 2xeˣ − 2eˣ. Assemble: ∫x²eˣdx = x²eˣ − 2xeˣ + 2eˣ + C = eˣ(x² − 2x + 2) + C. Verification (differentiate back): d/dx[eˣ(x² − 2x + 2)] = eˣ(x² − 2x + 2) + eˣ(2x − 2) = eˣ(x² − 2x + 2 + 2x − 2) = x²eˣ ✓. Deep point: each parts application drops the polynomial's degree by one (x² → x → constant) — repeated parts always terminates on polynomial × exponential products, with the answer eˣ times a polynomial of the same degree (here the pattern n!Σ(−x)ᵏ/k! begins to show).
  • NEB-style (5m): Evaluate ∫dx/(x·ln x). — Spot the nested structure: the integrand is (1/ln x)·(1/x) — and 1/x is exactly the derivative of ln x. Substitute: u = ln x, du = dx/x ⟹ the integral becomes ∫du/u. Integrate: ln|u| + C. Substitute back: ln|ln x| + C (x > 0, x ≠ 1 for the original domain). Verification: d/dx[ln|ln x|] = (1/ln x)·(1/x) ✓ — the chain rule returns the integrand exactly. Deep points: (1) a nested substitution — the inner function's derivative is itself a standard integrand; the log-of-a-log answer is the signature of f′/f patterns stacked twice; (2) the f′/f master pattern (∫f′/f dx = ln|f| + C) applies with f = ln x here — recognising the pattern, not computing, is the entire skill.
  • NEB-style (6m): Evaluate ∫eˣ·sin x dx using integration by parts twice and solving the resulting equation. — Let I = ∫eˣ sin x dx. First parts (LIATE: Trig before Exponential ⟹ u = sin x, dv = eˣdx): I = eˣ sin x − ∫eˣ cos x dx. Second parts (u = cos x, dv = eˣdx): ∫eˣ cos x dx = eˣ cos x − ∫eˣ(−sin x)dx = eˣ cos x + I. Substitute back: I = eˣ sin x − [eˣ cos x + I] = eˣ(sin x − cos x) − I. The cyclic equation: the original integral has returned — collect it: 2I = eˣ(sin x − cos x) ⟹ I = eˣ(sin x − cos x)/2 + C. Verification: d/dx{eˣ(sin x − cos x)/2} = ½[eˣ(sin x − cos x) + eˣ(cos x + sin x)] = ½eˣ·2 sin x = eˣ sin x ✓. Deep point: the cyclic integrand is the one case where parts' "regression" becomes progress — returning to I converts the method into a linear equation, and the solve is the finish. The factor 1/2 arises because eˣ and sin x each contribute a factor √2 of phase shift — the amplitude bookkeeping of the product-to-sum identity agrees.
  • NEB-style (5m): Evaluate ∫(2x + 3)/(x² + 3x + 5) dx. — Recognise the f′/f pattern: the denominator's derivative is d/dx(x² + 3x + 5) = 2x + 3 — exactly the numerator. Apply the master pattern: ∫f′(x)/f(x) dx = ln|f(x)| + C with f(x) = x² + 3x + 5 ⟹ the integral = ln(x² + 3x + 5) + C (absolute value unnecessary: the discriminant 9 − 20 < 0 ⟹ the quadratic is always positive). Verification: d/dx[ln(x²+3x+5)] = (2x+3)/(x²+3x+5) ✓. Extension — the near-miss case: for ∫(2x + 1)/(x² + 3x + 5)dx the numerator is not f′; split it: (2x+1) = (2x+3) − 2 ⟹ integral = ln(x²+3x+5) − 2∫dx/[(x+3/2)² + 11/4] = ln(x²+3x+5) − (4/√11)tan⁻¹((2x+3)/√11) + C — the f′/f recognition is always the first move; the remainder goes to the arctangent pattern.

Important Concepts

  • Integration is differentiation reversed: substitution reverses the chain rule, parts reverses the product rule - every method is a derivative theorem read backwards.

Important Statements

  • "F' = f defines the anti-derivative; substitution reverses the chain rule; parts: uv - integral v du with LIATE choosing u."
