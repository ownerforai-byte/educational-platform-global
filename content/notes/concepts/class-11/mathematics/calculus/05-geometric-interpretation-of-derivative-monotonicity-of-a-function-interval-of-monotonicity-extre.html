  • 1. Topic Introduction — Reading Slopes, Finding Peaks

    Geometric interpretation of the derivative, monotonicity intervals, and extreme values — the derivative as an analyst's instrument on graphs.

  • 2. Fundamental Concepts

    2.1 Geometric interpretation

    • f′(c) = slope of the tangent to y = f(x) at x = c. f′ > 0: rising; f′ < 0: falling; f′ = 0: horizontal tangent (stationary). f′′ > 0: concave up (holds water); f′′ < 0: concave down; f′′ = 0 candidates: inflection points (concavity change).

    2.2 Monotonicity theorem

    • Theorem: f′ > 0 on an interval ⟹ f is strictly increasing there; f′ < 0 ⟹ strictly decreasing. (Proof via the Mean Value Theorem: f(b) − f(a) = f′(c)(b − a) inherits the sign.)
    • Procedure: find f′, solve f′ = 0 and f′ undefined points, test signs between them (sign chart), read intervals of increase/decrease.

    2.3 Extreme values

    • Local maximum: f′ changes + → − across c; local minimum: − → +. First-derivative test reads the sign chart; second-derivative test: f′(c) = 0 and f′′(c) > 0 ⟹ local min; f′′(c) < 0 ⟹ local max; f′′(c) = 0 ⟹ inconclusive.
    • Absolute extrema on [a, b]: compare f at critical points and endpoints (closed-interval method).

    2.4 Critical points

    • Critical point: f′(c) = 0 or f′(c) undefined — the only places local extrema can hide (Fermat's theorem). Not every critical point is an extremum: x³ at 0 has f′ = 0 but no extremum (inflection).

  • 4. Detailed Explanation

    4.1 Why the sign of f′ governs rise and fall

    • The MVT converts a pointwise sign into an intervalwise statement: every secant slope equals some tangent slope, so positive tangents force positive secants — increasing. The derivative's sign is the function's direction.

    4.2 Why f′ = 0 is necessary, not sufficient

    • Fermat's theorem: at a local extremum (interior, differentiable) f′ = 0 — the tangent must be horizontal. But horizontal tangents also occur at inflections (x³): the sign change across the critical point, not the zero itself, decides.

    4.3 The cubic case study

    • y = x³ − 6x² + 9x − 2: f′ = 3x² − 12x + 9 = 3(x − 1)(x − 3) ⟹ critical points 1, 3; sign chart: + below 1 (rising), − between (falling), + above 3 (rising) ⟹ local max at x = 1, local min at x = 3 — the full machinery in one polynomial.

    Critical ≠ extremum: x³ at 0 — f′ = 0 but the sign does not change; no extremum, only an inflection.

  • Endpoints are candidates: local-extremum tests ignore endpoints; absolute extrema on [a, b] must include them.
  • f′′ = 0 is not an inflection verdict: the sign change of f′′ decides, not the zero.

  • 7. Exam Application

    NEB 2024 (verified PYQ): The curve y = x³ − 6x² + 9x − 2 is given. Find (i) its stationary points, (ii) classify each, (iii) the intervals of increase and decrease. (4m) — (i) dy/dx = 3x² − 12x + 9 = 3(x − 1)(x − 3) = 0 ⟹ x = 1, x = 3; y(1) = 1 − 6 + 9 − 2 = 2 ⟹ (1, 2); y(3) = 27 − 54 + 27 − 2 = −2 ⟹ (3, −2). (ii) Second derivative: y′′ = 6x − 12; y′′(1) = −6 < 0 ⟹ local maximum at (1, 2); y′′(3) = 6 > 0 ⟹ local minimum at (3, −2). (iii) Sign chart of y′ = 3(x−1)(x−3): increasing on (−∞, 1) ∪ (3, ∞); decreasing on (1, 3).

  • NEB-style (2m): Show that f(x) = x³ is increasing on all of ℝ despite f′(0) = 0. — f′ = 3x² ≥ 0 with equality only at the single point 0 ⟹ f′ > 0 on (−∞, 0) and (0, ∞) ⟹ increasing on each; and f(b) > f(a) for a < b across 0 as well (x³ is strictly increasing — check directly: b³ − a³ = (b−a)(b²+ab+a²) > 0 since b² + ab + a² > 0 for a ≠ −b... for a < b it is positive). Moral: isolated zeros of f′ do not break monotonicity — only sign changes matter.
  • NEB-style (3m): Find the absolute maximum and minimum of f(x) = x³ − 3x on [−2, 2]. — Critical points: f′ = 3x² − 3 = 0 ⟹ x = ±1. Candidates: x = −2, −1, 1, 2. Values: f(−2) = −8 + 6 = −2; f(−1) = −1 + 3 = 2; f(1) = 1 − 3 = −2; f(2) = 8 − 6 = 2. Absolute max = 2 at x = −1 and x = 2; absolute min = −2 at x = −2 and x = 1 — ties are legal; compare all candidates.

  • 8. Deep Conceptual — Derivatives Prove Inequalities

    • The monotonicity engine for inequalities: to show f(x) > g(x) for x > a, define h = f − g, check h(a) = 0 and h′ > 0 ⟹ h > 0 beyond a. The derivative's sign converts a static inequality into a dynamic growth statement.
    • Classic certificates: eˣ > 1 + x (h = eˣ − 1 − x, h′ = eˣ − 1 > 0 for x > 0, h(0) = 0); sin x < x for x > 0 (h = x − sin x, h′ = 1 − cos x ≥ 0 with equality isolated); ln x < x for x > 0 (h = x − ln x, h′ = 1 − 1/x, minimum at 1 with h(1) = 1 > 0).
    • Why this is deep: it is the first method that proves global statements from local data — the derivative at each point controls the whole ray. The MVT is the bridge: h(b) − h(a) = h′(c)(b − a) inherits h′'s sign.

  • 9. Deep Conceptual — The Second Derivative's Three Personalities

    • Curvature reading: f′′ > 0 ⟹ concave up (the tangent line lies below the curve — supporting line); f′′ < 0 ⟹ concave down (tangent above — covering line). Concavity is the derivative's own monotonicity: f′′ = (f′)′.
    • Extremum classification: at a stationary point, f′′(c) > 0 means f′ crosses from − to + (the slope climbs through zero) ⟹ minimum; f′′ < 0 ⟹ maximum. The second-derivative test is the first-derivative test compressed into one sign.
    • Inflection subtlety: f′′(c) = 0 is not an inflection — the sign change of f′′ decides (y = x⁴ at 0 has f′′ = 0 but stays concave up). Conversely an inflection can occur where f′′ does not exist (y = x^{1/3} at 0). Sign change, not zero, is the criterion.

  • 10. Deep Conceptual — Why Endpoints Need Separate Treatment

    • Fermat's theorem is interior-only: at an endpoint the function has no two-sided neighbourhood, so the f′ = 0 necessity argument collapses. Absolute extrema on [a, b] therefore live at critical points or endpoints — the closed-interval method's candidate list is exactly these.
    • Worked economy: for f on [a, b], compare f at (i) interior critical points, (ii) a and b. Nothing else can win: any interior non-critical point has neighbours beating it on one side.
    • Open intervals break the guarantee: f(x) = x on (0, 1) attains neither max nor min — the sup/inf exist but are not attained. Closedness is the hypothesis that converts "least upper bound" into "maximum" — the EVT's fine print in action.

(ii) Classification (second-derivative test): y′′ = 6x − 12; y′′(1) = −6 < 0 ⟹ concave down ⟹ local maximum at (1, 2); y′′(3) = 6 > 0 ⟹ concave up ⟹ local minimum at (3, −2). (iii) Monotonicity (sign chart of y′): test x = 0: 3(−1)(−3) = +9 > 0; x = 2: 3(1)(−1) = −3 < 0; x = 4: 3(3)(1) = +9 > 0 ⟹ increasing on (−∞, 1) ∪ (3, ∞), decreasing on (1, 3). The full cubic analysis — stationary points, classification, monotonicity — in one sign chart.
  • NEB-style (2m): Show that f(x) = x³ is increasing on all of ℝ even though f′(0) = 0. — Derivative: f′(x) = 3x² ≥ 0 everywhere, with equality only at the isolated point x = 0. On (−∞, 0) and (0, ∞), f′ > 0 ⟹ strictly increasing on each side. Across 0: for a < 0 < b, b³ − a³ = (b − a)(b² + ab + a²); here b − a > 0 and b² + ab + a² = ½[(a+b)² + a² + b²] > 0 (not both a, b zero) ⟹ b³ > a³. Conclusion: f is strictly increasing on all of ℝ — the single stationary point is an inflection, not an extremum, because f′ does not change sign there. Moral: monotonicity is governed by the sign of f′, and isolated zeros without sign change are harmless.
  • NEB-style (3m): Find the absolute maximum and minimum values of f(x) = x³ − 3x on the closed interval [−2, 2]. — Critical points: f′(x) = 3x² − 3 = 3(x−1)(x+1) = 0 ⟹ x = ±1 (both interior). Closed-interval method — candidate list: the critical points x = −1, 1 plus the endpoints x = −2, 2. Evaluate: f(−2) = −8 + 6 = −2; f(−1) = −1 + 3 = 2; f(1) = 1 − 3 = −2; f(2) = 8 − 6 = 2. Verdict: absolute maximum value 2, attained at x = −1 and x = 2; absolute minimum value −2, attained at x = −2 and x = 1. Lessons: endpoints are mandatory candidates (a local-extremum test would miss x = ±2), and ties are legal — two points may share the extreme value.
  • NEB-style (6m): Fully analyse y = 2x³ − 9x² + 12x − 3: stationary points, their classification, intervals of increase/decrease, and concavity. — First derivative: y′ = 6x² − 18x + 12 = 6(x − 1)(x − 2) ⟹ stationary points at x = 1, 2. Points: y(1) = 2 − 9 + 12 − 3 = 2 ⟹ (1, 2); y(2) = 16 − 36 + 24 − 3 = 1 ⟹ (2, 1). Classification (second-derivative test): y′′ = 12x − 18; y′′(1) = −6 < 0 ⟹ local maximum at (1, 2); y′′(2) = 6 > 0 ⟹ local minimum at (2, 1). Monotonicity (sign chart of y′): x = 0: +; x = 1.5: −; x = 3: + ⟹ increasing on (−∞, 1) ∪ (2, ∞), decreasing on (1, 2). Concavity: y′′ = 12x − 18 = 0 at x = 3/2; y′′ < 0 on (−∞, 3/2) (concave down), > 0 on (3/2, ∞) (concave up) ⟹ inflection at (3/2, 3/2) — check: y(3/2) = 2(27/8) − 9(9/4) + 18 − 3 = 27/4 − 81/4 + 15 = −54/4 + 15 = 3/2 ✓. Complete graph certificate: every feature — peaks, valleys, turn of curvature — located and classified.
  • NEB-style (5m): Prove that eˣ > 1 + x for all x ≠ 0. — Construct the gap function: h(x) = eˣ − 1 − x; the claim is h(x) > 0 for x ≠ 0. Anchor: h(0) = e⁰ − 1 − 0 = 0 — equality exactly at the origin. Monotonicity: h′(x) = eˣ − 1. For x > 0: eˣ > 1 ⟹ h′ > 0 ⟹ h is strictly increasing on (0, ∞); since h(0) = 0, h(x) > 0 for all x > 0. For x < 0: eˣ < 1 ⟹ h′ < 0 ⟹ h is strictly decreasing on (−∞, 0); moving leftward from h(0) = 0 while decreasing means h(x) > 0 for x < 0 as well (as x increases to 0, h falls to 0 — so it was above 0 before). Conclusion: h(x) > 0 for all x ≠ 0, i.e. eˣ > 1 + x ∎. Deep point: the inequality is the statement that the exponential curve lies strictly above its tangent line at 0 — strict convexity in action — and the proof is pure monotonicity bookkeeping: anchor at the point of equality, then let the derivative's sign carry the claim to both rays.
  • NEB-style (5m): Prove that sin x < x for all x > 0. — Construct: h(x) = x − sin x; the claim is h(x) > 0 for x > 0. Anchor: h(0) = 0 − 0 = 0. Derivative: h′(x) = 1 − cos x. Key observation: cos x ≤ 1 for all x, with equality only at isolated points x = 2kπ ⟹ h′(x) ≥ 0 everywhere and h′ > 0 except at those isolated points. Monotonicity argument: h is increasing on every interval (2kπ, 2(k+1)π) since h′ > 0 there; at the isolated points h′ = 0 causes no change of sign (h stays increasing through them — isolated zeros of the derivative do not break strict monotonicity, as x³ showed). Hence h is strictly increasing on [0, ∞), and h(0) = 0 ⟹ h(x) > 0 for x > 0, i.e. sin x < x ∎. Deep points: (1) the geometric meaning — the arc of the sine curve stays below the line y = x because its slope never exceeds 1 and starts equal; (2) this inequality is exactly the squeeze bound |sin u| ≤ |u| that powered sin u/u → 1 — the limits unit's most-used estimate is this theorem restated; (3) the isolated-critical-point subtlety (h′ = 0 at multiples of 2π without sign change) is the same phenomenon as x³ at 0.
  • NEB-style (6m): Find the absolute maximum and minimum of f(x) = x⁴ − 4x² + 2 on [−2, 3]. — Critical points: f′(x) = 4x³ − 8x = 4x(x² − 2) = 0 ⟹ x = 0, ±√2 (all interior to [−2, 3]). Candidate list (closed-interval method): x = −2, −√2, 0, √2, 3. Evaluate: f(−2) = 16 − 16 + 2 = 2; f(−√2) = 4 − 8 + 2 = −2; f(0) = 2; f(√2) = −2; f(3) = 81 − 36 + 2 = 47. Verdict: absolute maximum = 47 at x = 3 (an endpoint — the quartic escapes upward on the right); absolute minimum = −2 at x = ±√2 (the double valley). Classification check: f′′ = 12x² − 8; f′′(±√2) = 16 > 0 ⟹ local minima ✓; f′′(0) = −8 < 0 ⟹ local max at (0, 2) — but 2 is not the absolute maximum (the endpoint beats it). Deep point: local and absolute extrema are independent titles — (0, 2) is a genuine peak of the graph yet loses the global contest to the endpoint x = 3; only the closed-interval candidate comparison ranks them.

Key Points

  • Geometric reading: f'(c) = tangent slope; f' > 0 rising, f' < 0 falling, f' = 0 stationary; f'' > 0 concave up, f'' < 0 concave down, f'' sign change = inflection. Monotonicity theorem: f' > 0 on interval => strictly increasing (MVT proof); procedure: solve f' = 0/undefined, sign chart, read intervals. Critical point: f' = 0 or undefined (Fermat: interior extrema need f' = 0); critical != extremum (x^3 at 0 - inflection). First-derivative test: sign change + to - = local max, - to + = local min. Second-derivative test: f'(c) = 0, f''(c) > 0 => min, < 0 => max, = 0 inconclusive. Closed-interval method: compare f at critical points AND endpoints for absolute extrema.

Summary

The derivative becomes an analytical instrument: f′(c) is the tangent's slope — positive rising, negative falling, zero stationary — and f′′ reads concavity (up/down, with sign changes marking inflections). The monotonicity theorem (f′ > 0 ⟹ strictly increasing, via the MVT) powers the sign-chart procedure: solve f′ = 0 or undefined, test between, read intervals. Fermat's theorem makes f′ = 0 necessary for interior extrema but never sufficient — the sign change decides (x³'s stationary point is an inflection, and x³ still increases on all of ℝ). The first-derivative test (+ → − max, − → + min) and second-derivative test (f′′(c) > 0 min, < 0 max) classify; the closed-interval method adds endpoints for absolute extrema (x³ − 3x on [−2, 2]: max 2, min −2, with ties). NEB 2024's cubic — stationary points (1, 2), (3, −2), classified by y′′, monotonicity read from 3(x−1)(x−3) — is the whole machinery in one exam question.

    • Fermat's theorem is interior-only: at an endpoint the function has no two-sided neighbourhood, so the f′ = 0 necessity argument collapses. Absolute extrema on [a, b] therefore live at critical points or endpoints — the closed-interval method's candidate list is exactly these.
    • Worked economy: for f on [a, b], compare f at (i) interior critical points, (ii) a and b. Nothing else can win: any interior non-critical point has neighbours beating it on one side.
    • Open intervals break the guarantee: f(x) = x on (0, 1) attains neither max nor min — the sup/inf exist but are not attained. Closedness is the hypothesis that converts "least upper bound" into "maximum" — the EVT's fine print in action.
Key Points
  • Geometric reading: f'(c) = tangent slope; f' > 0 rising, f' < 0 falling, f' = 0 stationary; f'' > 0 concave up, f'' < 0 concave down, f'' sign change = inflection. Monotonicity theorem: f' > 0 on interval => strictly increasing (MVT proof); procedure: solve f' = 0/undefined, sign chart, read intervals. Critical point: f' = 0 or undefined (Fermat: interior extrema need f' = 0); critical != extremum (x^3 at 0 - inflection). First-derivative test: sign change + to - = local max, - to + = local min. Second-derivative test: f'(c) = 0, f''(c) > 0 => min, < 0 => max, = 0 inconclusive. Closed-interval method: compare f at critical points AND endpoints for absolute extrema.
Important Concepts
  • The sign of f' is the function's direction and the sign change across a critical point - not the zero itself - is the extremum verdict.

Practice Questions
  • NEB 2024 (verified PYQ): For y = x³ − 6x² + 9x − 2, find (i) the stationary points, (ii) classify each, (iii) the intervals of increase and decrease. (4m) — (i) Stationary points: dy/dx = 3x² − 12x + 9 = 3(x − 1)(x − 3); setting zero: x = 1 and x = 3. Points: y(1) = 1 − 6 + 9 − 2 = 2 ⟹ (1, 2); y(3) = 27 − 54 + 27 − 2 = −2 ⟹ (3, −2). (ii) Classification (second-derivative test): y′′ = 6x − 12; y′′(1) = −6 < 0 ⟹ concave down ⟹ local maximum at (1, 2); y′′(3) = 6 > 0 ⟹ concave up ⟹ local minimum at (3, −2). (iii) Monotonicity (sign chart of y′): test x = 0: 3(−1)(−3) = +9 > 0; x = 2: 3(1)(−1) = −3 < 0; x = 4: 3(3)(1) = +9 > 0 ⟹ increasing on (−∞, 1) ∪ (3, ∞), decreasing on (1, 3). The full cubic analysis — stationary points, classification, monotonicity — in one sign chart.
  • NEB-style (2m): Show that f(x) = x³ is increasing on all of ℝ even though f′(0) = 0. — Derivative: f′(x) = 3x² ≥ 0 everywhere, with equality only at the isolated point x = 0. On (−∞, 0) and (0, ∞), f′ > 0 ⟹ strictly increasing on each side. Across 0: for a < 0 < b, b³ − a³ = (b − a)(b² + ab + a²); here b − a > 0 and b² + ab + a² = ½[(a+b)² + a² + b²] > 0 (not both a, b zero) ⟹ b³ > a³. Conclusion: f is strictly increasing on all of ℝ — the single stationary point is an inflection, not an extremum, because f′ does not change sign there. Moral: monotonicity is governed by the sign of f′, and isolated zeros without sign change are harmless.
  • NEB-style (3m): Find the absolute maximum and minimum values of f(x) = x³ − 3x on the closed interval [−2, 2]. — Critical points: f′(x) = 3x² − 3 = 3(x−1)(x+1) = 0 ⟹ x = ±1 (both interior). Closed-interval method — candidate list: the critical points x = −1, 1 plus the endpoints x = −2, 2. Evaluate: f(−2) = −8 + 6 = −2; f(−1) = −1 + 3 = 2; f(1) = 1 − 3 = −2; f(2) = 8 − 6 = 2. Verdict: absolute maximum value 2, attained at x = −1 and x = 2; absolute minimum value −2, attained at x = −2 and x = 1. Lessons: endpoints are mandatory candidates (a local-extremum test would miss x = ±2), and ties are legal — two points may share the extreme value.
  • NEB-style (6m): Fully analyse y = 2x³ − 9x² + 12x − 3: stationary points, their classification, intervals of increase/decrease, and concavity. — First derivative: y′ = 6x² − 18x + 12 = 6(x − 1)(x − 2) ⟹ stationary points at x = 1, 2. Points: y(1) = 2 − 9 + 12 − 3 = 2 ⟹ (1, 2); y(2) = 16 − 36 + 24 − 3 = 1 ⟹ (2, 1). Classification (second-derivative test): y′′ = 12x − 18; y′′(1) = −6 < 0 ⟹ local maximum at (1, 2); y′′(2) = 6 > 0 ⟹ local minimum at (2, 1). Monotonicity (sign chart of y′): x = 0: +; x = 1.5: −; x = 3: + ⟹ increasing on (−∞, 1) ∪ (2, ∞), decreasing on (1, 2). Concavity: y′′ = 12x − 18 = 0 at x = 3/2; y′′ < 0 on (−∞, 3/2) (concave down), > 0 on (3/2, ∞) (concave up) ⟹ inflection at (3/2, 3/2) — check: y(3/2) = 2(27/8) − 9(9/4) + 18 − 3 = 27/4 − 81/4 + 15 = −54/4 + 15 = 3/2 ✓. Complete graph certificate: every feature — peaks, valleys, turn of curvature — located and classified.
  • NEB-style (5m): Prove that eˣ > 1 + x for all x ≠ 0. — Construct the gap function: h(x) = eˣ − 1 − x; the claim is h(x) > 0 for x ≠ 0. Anchor: h(0) = e⁰ − 1 − 0 = 0 — equality exactly at the origin. Monotonicity: h′(x) = eˣ − 1. For x > 0: eˣ > 1 ⟹ h′ > 0 ⟹ h is strictly increasing on (0, ∞); since h(0) = 0, h(x) > 0 for all x > 0. For x < 0: eˣ < 1 ⟹ h′ < 0 ⟹ h is strictly decreasing on (−∞, 0); moving leftward from h(0) = 0 while decreasing means h(x) > 0 for x < 0 as well (as x increases to 0, h falls to 0 — so it was above 0 before). Conclusion: h(x) > 0 for all x ≠ 0, i.e. eˣ > 1 + x ∎. Deep point: the inequality is the statement that the exponential curve lies strictly above its tangent line at 0 — strict convexity in action — and the proof is pure monotonicity bookkeeping: anchor at the point of equality, then let the derivative's sign carry the claim to both rays.
  • NEB-style (5m): Prove that sin x < x for all x > 0. — Construct: h(x) = x − sin x; the claim is h(x) > 0 for x > 0. Anchor: h(0) = 0 − 0 = 0. Derivative: h′(x) = 1 − cos x. Key observation: cos x ≤ 1 for all x, with equality only at isolated points x = 2kπ ⟹ h′(x) ≥ 0 everywhere and h′ > 0 except at those isolated points. Monotonicity argument: h is increasing on every interval (2kπ, 2(k+1)π) since h′ > 0 there; at the isolated points h′ = 0 causes no change of sign (h stays increasing through them — isolated zeros of the derivative do not break strict monotonicity, as x³ showed). Hence h is strictly increasing on [0, ∞), and h(0) = 0 ⟹ h(x) > 0 for x > 0, i.e. sin x < x ∎. Deep points: (1) the geometric meaning — the arc of the sine curve stays below the line y = x because its slope never exceeds 1 and starts equal; (2) this inequality is exactly the squeeze bound |sin u| ≤ |u| that powered sin u/u → 1 — the limits unit's most-used estimate is this theorem restated; (3) the isolated-critical-point subtlety (h′ = 0 at multiples of 2π without sign change) is the same phenomenon as x³ at 0.
  • NEB-style (6m): Find the absolute maximum and minimum of f(x) = x⁴ − 4x² + 2 on [−2, 3]. — Critical points: f′(x) = 4x³ − 8x = 4x(x² − 2) = 0 ⟹ x = 0, ±√2 (all interior to [−2, 3]). Candidate list (closed-interval method): x = −2, −√2, 0, √2, 3. Evaluate: f(−2) = 16 − 16 + 2 = 2; f(−√2) = 4 − 8 + 2 = −2; f(0) = 2; f(√2) = −2; f(3) = 81 − 36 + 2 = 47. Verdict: absolute maximum = 47 at x = 3 (an endpoint — the quartic escapes upward on the right); absolute minimum = −2 at x = ±√2 (the double valley). Classification check: f′′ = 12x² − 8; f′′(±√2) = 16 > 0 ⟹ local minima ✓; f′′(0) = −8 < 0 ⟹ local max at (0, 2) — but 2 is not the absolute maximum (the endpoint beats it). Deep point: local and absolute extrema are independent titles — (0, 2) is a genuine peak of the graph yet loses the global contest to the endpoint x = 3; only the closed-interval candidate comparison ranks them.
