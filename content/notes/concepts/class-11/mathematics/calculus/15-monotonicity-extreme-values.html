Notes

  • 1. Topic Introduction — The Companion Doorway to Monotonicity and Extreme Values

    This canonical is the short-form doorway to monotonicity and extreme values: sign tables, critical points, and the two tests in one page. The parent canonical carries the full treatment; this companion mirrors the theorems, adds the deep readings, and drills four heavy-mark problems.

  • 2. Theorem Mirror

    • Monotonicity: f′ > 0 on an interval ⟹ strictly increasing; f′ < 0 ⟹ strictly decreasing (MVT converts local signs to global behaviour).
    • Critical points: interior points where f′ = 0 or f′ fails to exist — the only candidates for local extrema.
    • First-derivative test: f′ changes + → − at c ⟹ local max; − → + ⟹ local min; no change ⟹ neither (terrace point).
    • Second-derivative test: f′(c) = 0 and f″(c) > 0 ⟹ local min; f″(c) < 0 ⟹ local max; f″(c) = 0 ⟹ inconclusive.
    • Absolute extrema: compare critical-point values and endpoint values (on closed intervals); extrema may live at endpoints or non-differentiable points.

  • 3. Deep Conceptual — The Sign Table Is the Theorem Made Mechanical

    • The first-derivative test is the MVT wearing a table: f′ > 0 on (a, c) means f climbs on that whole stretch; the sign change at c means the climb stops and a descent begins — a summit. The table's columns are intervals, its entries are the MVT's verdicts.
    • Critical ≠ extreme: f′ = 0 is necessary for a smooth interior extremum (Fermat) but not sufficient — y = x³ at 0 is stationary and monotone. The sign change is the sufficient condition; the zero is only the candidate list.
    • Non-differentiable candidates: |x| has a minimum at 0 with no derivative there — critical points include corners, cusps and vertical tangents. The candidate list is "f′ = 0 or f′ fails", and skipping the second half loses marks.

  • 4. Deep Conceptual — Absolute vs Local, Closed vs Open

    • Local is a neighbourhood verdict (the highest nearby); absolute is a global verdict (the highest everywhere). On a closed interval, continuity guarantees both exist (Extreme Value Theorem) and the candidate list is critical points plus endpoints — forgetting endpoints is the classic error.
    • On open intervals nothing is guaranteed: x² on (0, ∞) has no maximum. Existence must be argued (closedness, or limits at the ends), then the candidates compared.
    • Optimisation grammar: translate → constraint → reduce to one variable → differentiate → critical points → classify → answer in context with units and a justification sentence.

  • 5. Worked Example Types

    • Type A — sign table + classification: full monotonicity map with max/min verdicts.
    • Type B — second-derivative test: quick classification where f″ is easy.
    • Type C — absolute extrema on [a, b]: candidates + endpoints compared.
    • Type D — optimisation story: constraint, reduction, critical point, contextual answer.

  • 6. Common Confusions

    "f′ = 0 ⟹ extremum": x³ forever. "Endpoints can't be extrema": on closed intervals they are first-class candidates.

Confusion

  • Treating every solution of f′=0 as a maximum or a minimum.
  • Forgetting the two endpoints when finding absolute extrema on a closed interval.
  • Checking f′ at a single point instead of across the interval when deciding monotonicity.

Practice

  • Find the intervals of increase and decrease for f(x) = x³ − 3x.
  • Classify the critical points of f(x) = x⁴ − 4x³ using the second-derivative test.
  • Find the absolute maximum and minimum of f(x) = x³ − 3x on [−2, 2].

Universal Facts

  • |x| has its minimum at a point where the derivative does not exist - the candidate list must include derivative failures.

Practice Questions

  • NEB-style (6m): Find the intervals of increase/decrease and classify the critical points of f(x) = x³ − 3x. — Derivative: f′ = 3x² − 3 = 3(x − 1)(x + 1); zeros at x = ±1; f′ exists everywhere ⟹ candidates {−1, 1}. Sign table: f′ > 0 on (−∞, −1) (test x = −2: 9 > 0); f′ < 0 on (−1, 1) (test 0: −3); f′ > 0 on (1, ∞) (test 2: 9). Verdicts: increasing on (−∞, −1) ∪ (1, ∞); decreasing on (−1, 1); local max at (−1, 2) (sign + → −); local min at (1, −2) (sign − → +). Deep point: the sign table's test values are MVT applications in disguise — each interval's uniform sign certifies uniform behaviour, and the sign change at the boundary is the classification, not the zero itself.
  • NEB-style (6m): Classify the critical points of f(x) = x⁴ − 4x³ using the second-derivative test, noting any inconclusive cases. — Derivative: f′ = 4x³ − 12x² = 4x²(x − 3); candidates x = 0 and x = 3. Second derivative: f″ = 12x² − 24x = 12x(x − 2). At x = 3: f″(3) = 36 > 0 ⟹ local min at (3, −27). At x = 0: f″(0) = 0 ⟹ inconclusive — fall back to the first-derivative test: f′ = 4x²(x − 3) ≤ 0 on both sides of 0 (x² ≥ 0, x − 3 < 0) ⟹ no sign change ⟹ terrace point (neither max nor min; a horizontal flattening on a descent). Deep point: the second-derivative test's inconclusive case is not a failure but a referral — the first-derivative test (sign change) is the court of final appeal, and x⁴'s flat quartic bottom... here a cubic's inflection-terrace, shows why.
  • NEB-style (6m): Find the absolute maximum and minimum of f(x) = x³ − 3x on [−2, 2]. — Candidates: critical points from the previous analysis: x = −1, 1; plus endpoints x = −2, 2 (the EVT guarantees absolute extrema exist on the closed interval, and they may sit at the ends). Compare values: f(−2) = −8 + 6 = −2; f(−1) = −1 + 3 = 2; f(1) = 1 − 3 = −2; f(2) = 8 − 6 = 2. Verdict: absolute maximum 2 attained at both x = −1 and x = 2; absolute minimum −2 attained at both x = 1 and x = −2. Deep point: the tie (local max value = endpoint value) shows absolute and local classifications are independent — x = 2 is an endpoint, not a critical point, yet it shares the absolute maximum; comparing all candidates is the only safe protocol.
  • NEB-style (6m): A rectangle has perimeter 40 cm. Find the dimensions that maximise its area, justifying the maximum. — Translate: sides x and y with 2x + 2y = 40 ⟹ y = 20 − x, 0 < x < 20. Objective: A(x) = x(20 − x) = 20x − x². Critical point: A′ = 20 − 2x = 0 ⟹ x = 10. Classify: A″ = −4 < 0 ⟹ concave down everywhere ⟹ the critical point is the absolute maximum (a concave-down parabola's vertex is its global top). Answer: x = 10, y = 10 — the square of side 10 cm, area 100 cm². Context sentence: among all rectangles with perimeter 40, the square encloses the most area. Deep point: the optimisation grammar — constraint eliminates a variable, the derivative finds the critical point, the second derivative (or sign change) justifies, and the answer returns to the problem's units; the justification sentence is worth as much as the computation.

Formulas

    • f′(c) = 0 and f″(c) > 0 ⟹ local min

Key Points

  • f' > 0 => increasing; f' < 0 => decreasing (MVT promotes local signs to global). Critical points: f' = 0 OR f' fails - corners and cusps are candidates too. First-derivative test: the SIGN CHANGE classifies (+ to - max, - to + min, no change terrace). Second-derivative test: f''(c) > 0 min, < 0 max, = 0 inconclusive. Absolute extrema on [a,b]: compare critical values AND endpoints (EVT guarantees existence).

Summary

Monotonicity and extrema run on one machine: the MVT promotes local derivative signs to global increase/decrease, the critical-point list (f′ = 0 or f′ fails) supplies the candidates, and the sign change — with the second-derivative test as a quick shortcut — classifies them. Absolute extrema on closed intervals add the endpoints to the comparison list, and optimisation problems wrap the same machinery in a story: translate, reduce, differentiate, classify, and close with a contextual sentence.

A stationary point of f is necessarily:

f′(c)=0 is necessary but not sufficient; y=x3 at 0 is stationary with no extremum.

2.

For the absolute maximum of a continuous f on [a,b], consider:

Options
  • only critical points
  • only the endpoints
  • critical points AND both endpoints
  • the midpoint
Answer

C

Explanation

A maximum can sit at an endpoint, so critical values must be compared with f(a) and f(b).

3.

If f′(x)<0 throughout (a,b) then f is:

Options
  • increasing
  • decreasing
  • concave
  • constant
Answer

B

Explanation

A negative derivative over the whole interval means strictly decreasing there.
