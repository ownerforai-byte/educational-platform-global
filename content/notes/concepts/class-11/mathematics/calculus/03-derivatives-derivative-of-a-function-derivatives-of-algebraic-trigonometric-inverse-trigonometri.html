  • 1. Topic Introduction — The Extended Derivative Table

    Derivatives of inverse trigonometric, exponential and logarithmic functions — completing the standard table that every chain-rule computation consumes.

  • 2. Fundamental Concepts

    2.1 Inverse trigonometric derivatives

    • d/dx sin⁻¹x = 1/√(1 − x²) (|x| < 1); d/dx cos⁻¹x = −1/√(1 − x²); d/dx tan⁻¹x = 1/(1 + x²); d/dx cot⁻¹x = −1/(1 + x²); d/dx sec⁻¹x = 1/(|x|√(x² − 1)); d/dx cosec⁻¹x = −1/(|x|√(x² − 1)).
    • Memory pattern: co-functions carry minus signs; sin/cos and tan/cot pairs are ± of each other.

    2.2 The inverse-derivation engine

    • Theorem: if f is invertible with f′ ≠ 0, then (f⁻¹)′(y) = 1/f′(x) at y = f(x) — the inverse's slope is the reciprocal. Applied to sin⁻¹: x = sin y ⟹ dy/dx = 1/cos y = 1/√(1 − sin²y) = 1/√(1 − x²).

    2.3 Exponential and logarithmic derivatives

    • d/dx eˣ = eˣ (from (eʰ − 1)/h → 1 — the star that defines e). d/dx aˣ = aˣ ln a. d/dx ln x = 1/x (from (ln(1+h))/h → 1). d/dx log_a x = 1/(x ln a).
    • Memory pattern: base e kills the constant; general bases carry ln a.

    2.4 The exponential–log inverse pair

    • eˣ and ln x are inverses: their derivatives are reciprocals — (eˣ)′ = eˣ at x = ln y matches (ln y)′ = 1/y. The inverse-engine theorem in its cleanest instance.

  • 4. Detailed Explanation

    4.1 Why e is the natural base

    • (eˣ)′ = eˣ means the exponential's rate equals its value — self-replication. Every other base pays the ln a tax. This uniqueness is why calculus is written in e.

    4.2 Deriving tan⁻¹ geometrically

    • x = tan y ⟹ dy/dx = 1/sec²y = cos²y; with tan y = x, cos²y = 1/(1 + tan²y) = 1/(1 + x²) ⟹ dy/dx = 1/(1 + x²) — no |x| needed since sec² > 0 always.

    4.3 The table as chain-rule feedstock

    • These derivatives are rarely used bare: the chain rule wraps them — d/dx sin⁻¹(u) = u′/√(1−u²), d/dx ln(u) = u′/u, d/dx e^{u} = e^{u}·u′. The table is the alphabet; the chain rule writes the words.

  • 7. Exam Application

    NEB 2020 (verified PYQ): d/dx [log_a(sin x)] equals: (a) 1/(sin x·log_e a) (b) cot x/... (MCQ, 1m) — Chain rule: d/dx log_a(sin x) = [1/(sin x·ln a)]·cos x = cot x/ln a. Compare with the options: the form matching cot x/(ln a) — i.e. cos x/(sin x·log_e a) — is correct; option (a) 1/(sin x log_e a) misses the cos x factor, so the correct choice is the one carrying cot x/ln a (the option displaying cos x/(sin x·log_e a)).

  • NEB 2022 (verified PYQ): Find dy/dx for y = ln(sin x). (3m) — Chain rule: dy/dx = (1/sin x)·d/dx(sin x) = (1/sin x)·cos x = cot x. (Equivalently: ln(sin x) = ln|sin x| on the domain sin x > 0; the derivative is cot x wherever defined.)
  • NEB-style (2m): Differentiate y = tan⁻¹(3x) and y = e^{−x²}. — Chain rule: d/dx tan⁻¹(3x) = 3/(1 + 9x²) (u′ = 3 over 1 + u²). d/dx e^{−x²} = e^{−x²}·(−2x) = −2x·e^{−x²} (u′ = −2x). The table supplies the outer derivatives; the chain rule supplies the inner.

  • 8. Deep Conceptual — The Inverse-Engine Rule in Full

    • Theorem: if f is invertible and differentiable with f′(x) ≠ 0, then (f⁻¹)′(f(x)) = 1/f′(x). Proof: differentiate the identity f⁻¹(f(x)) = x by the chain rule: (f⁻¹)′(f(x))·f′(x) = 1 ⟹ the result. Geometrically: the inverse's graph is the reflection in y = x, and reflection tilts every tangent by the reciprocal angle — slopes reciprocate.
    • Why f′ ≠ 0 matters: where the tangent is horizontal (f′ = 0), the reflected tangent is vertical — the inverse's derivative blows up. sin x at π/2 has f′ = 0, which is exactly why sin⁻¹x's derivative blows up at x = ±1 (the domain edges). Every singularity of an inverse derivative is a horizontal tangent of the original.
    • The whole inverse-trig table from one engine: sin⁻¹ via 1/cos y = 1/√(1−x²); tan⁻¹ via 1/sec²y = cos²y = 1/(1+x²); sec⁻¹ via 1/(sec y tan y) = 1/(|x|√(x²−1)). One theorem, six derivatives, zero memorisation.

  • 9. Deep Conceptual — Why e Is Uniquely Self-Replicating

    • Theorem: (eˣ)′ = eˣ, and e is the unique base with this property: (aˣ)′ = aˣ ln a, so self-replication forces ln a = 1, i.e. a = e.
    • First-principles engine: [a^{x+h} − aˣ]/h = aˣ·[(aʰ − 1)/h] → aˣ·ln a — the limit (aʰ−1)/h → ln a is the general-base star, and a = e gives 1 because ln e = 1. The defining property of e (its own rate) and the star (eʰ−1)/h → 1 are the same fact seen twice.
    • Consequence chain: eˣ's ODE y′ = y gives y = Ceˣ (natural growth); ln x = ∫₁ˣ dt/t (the log as accumulated reciprocal); 1/x's anti-derivative is ln|x| — the natural base is woven through every natural rate.

  • 10. Deep Conceptual — The Chain Rule as Rate Composition

    • dy/dx = dy/du · du/dx is not fraction cancellation but a theorem: rates compose multiplicatively because small changes compound — a 2% change in u producing a 3% change in y means a 6% chain.
    • The gear-train picture: outer derivative = gear ratio, inner derivative = input speed; the chain rule multiplies them. Dropping u′ is claiming the gears don't turn — the classic error is exactly a missing gear.
    • Deep pattern: every "differentiate the composite" answer has the shape (outer table entry evaluated at u) × u′ — write both factors explicitly in working, and the chain rule can never be forgotten.

  • NEB 2020 (verified PYQ): d/dx [log_a(sin x)] equals: (choose the correct option). (1m) — Chain rule, outer first: the outer function is log_a(u) with u = sin x; its derivative is 1/(u ln a) (the general-base log derivative, carrying the ln a tax). Inner: (sin x)′ = cos x. Compose: d/dx log_a(sin x) = [1/(sin x·ln a)]·cos x = cos x/(sin x·ln a) = cot x/ln a. Option matching: the correct option is the one displaying cot x (equivalently cos x/(sin x·log_e a)); any option lacking the cos x factor (such as a bare 1/(sin x·log_e a)) is the classic incomplete-chain distractor. Moral: compute the full chain, then match — never pattern-match half-differentiated options.
  • NEB 2022 (verified PYQ): Find dy/dx for y = ln(sin x). (3m) — Chain rule: the outer function is ln(u) with derivative 1/u; the inner is u = sin x with derivative cos x. Compose: dy/dx = (1/sin x)·cos x = cos x/sin x = cot x. Domain note: ln requires sin x > 0 (x in intervals where sine is positive); on that domain cot x is defined and the answer stands. Cross-check: at x = π/2, y = ln 1 = 0 and dy/dx = cot(π/2) = 0 — the log curve flattens exactly where sin x peaks ✓. The composition ln ∘ sin is the archetype of "outer table, inner derivative".
  • NEB-style (2m): Differentiate (i) y = tan⁻¹(3x), (ii) y = e^{−x²}. — (i) Outer: (tan⁻¹u)′ = 1/(1 + u²); inner u = 3x, u′ = 3. Compose: dy/dx = 3/(1 + 9x²) — the coefficient lands in both numerator and inside the square. (ii) Outer: (eᵘ)′ = eᵘ (self-replicating); inner u = −x², u′ = −2x. Compose: dy/dx = −2x·e^{−x²} — the Gaussian bell's slope, negative for x > 0 and positive for x < 0, zero at the peak. Both are pure chain-rule applications: the extended table supplies the outer derivative, the inner function supplies u′.
  • NEB-style (5m): Derive d/dx (sin⁻¹x) = 1/√(1 − x²) using the inverse-function relation, stating the domain carefully. — Setup: let y = sin⁻¹x, so x = sin y with y ∈ [−π/2, π/2] (the principal branch — this is what makes the inverse a function). Differentiate implicitly with respect to x: cos y·(dy/dx) = 1 ⟹ dy/dx = 1/cos y. Express in x: on the principal branch cos y ≥ 0 (y ∈ [−π/2, π/2]), so cos y = +√(1 − sin²y) = √(1 − x²) — the positive root is forced by the branch. Result: dy/dx = 1/√(1 − x²), valid for |x| < 1 ∎. Domain depth: at x = ±1 the denominator vanishes ⟹ the derivative blows up — these are exactly where sin y has horizontal tangents (y = ±π/2), the inverse-engine rule's warning made visible. The formula is the trig table plus the reciprocal, with the branch supplying every sign.
  • NEB-style (5m): Using first principles, prove that d/dx (aˣ) = aˣ ln a, and deduce the derivative of eˣ. — Definition: f′(x) = lim_{h→0} [a^{x+h} − aˣ]/h = lim aˣ·[aʰ − 1]/h = aˣ · lim_{h→0} (aʰ − 1)/h (the constant aˣ factors out — the constant-multiple limit theorem). The general-base star: (aʰ − 1)/h → ln a as h → 0 (proved by writing a = e^{ln a}, so aʰ − 1 = e^{h ln a} − 1 ~ h ln a via the exponential star). Result: d/dx (aˣ) = aˣ ln a ∎. Deduction: for a = e, ln e = 1 ⟹ (eˣ)′ = eˣ — the self-replicating base. Deep point: the ln a factor is the "general-base tax"; e is the unique base that pays none, which is why natural logs are natural — calculus's algebra is simplest exactly in e's base, and every other base is e wearing a constant.
  • NEB-style (5m): Differentiate y = tan⁻¹((1 + x)/(1 − x)) and simplify the result. — Chain rule, outer first: with u = (1+x)/(1−x), dy/dx = [1/(1 + u²)]·u′. Inner derivative (quotient rule): u′ = [(1)(1−x) − (1+x)(−1)]/(1−x)² = [1 − x + 1 + x]/(1−x)² = 2/(1−x)². Simplify 1 + u²: 1 + (1+x)²/(1−x)² = [(1−x)² + (1+x)²]/(1−x)² = [1 − 2x + x² + 1 + 2x + x²]/(1−x)² = 2(1 + x²)/(1−x)². Compose: dy/dx = [(1−x)²/(2(1+x²))]·[2/(1−x)²] = 1/(1 + x²) (for x ≠ 1). The deep reveal: 1/(1+x²) is exactly the derivative of tan⁻¹x — and indeed (1+x)/(1−x) = tan(π/4 + tan⁻¹x) (tangent addition), so the function is tan⁻¹x shifted by the constant π/4 on its domain: same derivative, different branch. The algebra accidentally re-derived a trigonometric identity — chain-rule computations often expose hidden structure.
  • NEB-style (6m): Differentiate y = (tan x)^{x} using logarithmic differentiation, and state where the method is mandatory. — Why mandatory: both base (tan x) and exponent (x) vary — the power rule needs a constant exponent, the exponential rule a constant base; neither applies alone. Take logs: ln y = x·ln(tan x). Differentiate both sides (chain rule on the left; product rule on the right): y′/y = 1·ln(tan x) + x·[sec²x/tan x]. Simplify the inner term: sec²x/tan x = (1/cos²x)·(cos x/sin x) = 1/(sin x cos x) = 2/(2 sin x cos x) = 2/sin 2x = 2 cosec 2x. Solve: y′ = (tan x)ˣ[ln(tan x) + 2x·cosec 2x]. Deep points: (1) the log converts the power into a product — every u^v question becomes a product-rule question after one ln; (2) the pattern y′ = y(…) is universal: the original function always multiplies back, so the answer's shape is predictable before the details are.

Exp/log: (e^x)' = e^x (from (e^h-1)/h -> 1); (a^x)' = a^x ln a; (ln x)' = 1/x; (log_a x)' = 1/(x ln a). Base e kills the constant; general bases pay ln a. Chain rule wraps everything: d/dx sin^-1(u) = u'/sqrt(1-u^2), d/dx ln(u) = u'/u, d/dx e^u = e^u u'.
Important Concepts
  • The inverse-engine rule (f^-1)' = 1/f' derives the entire inverse-trig table from the trig table - one theorem, six derivatives.
Examples
  • The self-replicating base - e^x is the unique function equal to its own derivative: the (e^h - 1)/h -> 1 star is the whole story of why e rules calculus.
Universal Facts
  • Population growth and radioactive decay are a^t curves; only e^t has growth rate proportional to itself with constant 1 - nature's default is e.

Practice Questions
  • NEB 2020 (verified PYQ): d/dx [log_a(sin x)] equals: (choose the correct option). (1m) — Chain rule, outer first: the outer function is log_a(u) with u = sin x; its derivative is 1/(u ln a) (the general-base log derivative, carrying the ln a tax). Inner: (sin x)′ = cos x. Compose: d/dx log_a(sin x) = [1/(sin x·ln a)]·cos x = cos x/(sin x·ln a) = cot x/ln a. Option matching: the correct option is the one displaying cot x (equivalently cos x/(sin x·log_e a)); any option lacking the cos x factor (such as a bare 1/(sin x·log_e a)) is the classic incomplete-chain distractor. Moral: compute the full chain, then match — never pattern-match half-differentiated options.
  • NEB 2022 (verified PYQ): Find dy/dx for y = ln(sin x). (3m) — Chain rule: the outer function is ln(u) with derivative 1/u; the inner is u = sin x with derivative cos x. Compose: dy/dx = (1/sin x)·cos x = cos x/sin x = cot x. Domain note: ln requires sin x > 0 (x in intervals where sine is positive); on that domain cot x is defined and the answer stands. Cross-check: at x = π/2, y = ln 1 = 0 and dy/dx = cot(π/2) = 0 — the log curve flattens exactly where sin x peaks ✓. The composition ln ∘ sin is the archetype of "outer table, inner derivative".
  • NEB-style (2m): Differentiate (i) y = tan⁻¹(3x), (ii) y = e^{−x²}. — (i) Outer: (tan⁻¹u)′ = 1/(1 + u²); inner u = 3x, u′ = 3. Compose: dy/dx = 3/(1 + 9x²) — the coefficient lands in both numerator and inside the square. (ii) Outer: (eᵘ)′ = eᵘ (self-replicating); inner u = −x², u′ = −2x. Compose: dy/dx = −2x·e^{−x²} — the Gaussian bell's slope, negative for x > 0 and positive for x < 0, zero at the peak. Both are pure chain-rule applications: the extended table supplies the outer derivative, the inner function supplies u′.
  • NEB-style (5m): Derive d/dx (sin⁻¹x) = 1/√(1 − x²) using the inverse-function relation, stating the domain carefully. — Setup: let y = sin⁻¹x, so x = sin y with y ∈ [−π/2, π/2] (the principal branch — this is what makes the inverse a function). Differentiate implicitly with respect to x: cos y·(dy/dx) = 1 ⟹ dy/dx = 1/cos y. Express in x: on the principal branch cos y ≥ 0 (y ∈ [−π/2, π/2]), so cos y = +√(1 − sin²y) = √(1 − x²) — the positive root is forced by the branch. Result: dy/dx = 1/√(1 − x²), valid for |x| < 1 ∎. Domain depth: at x = ±1 the denominator vanishes ⟹ the derivative blows up — these are exactly where sin y has horizontal tangents (y = ±π/2), the inverse-engine rule's warning made visible. The formula is the trig table plus the reciprocal, with the branch supplying every sign.
  • NEB-style (5m): Using first principles, prove that d/dx (aˣ) = aˣ ln a, and deduce the derivative of eˣ. — Definition: f′(x) = lim_{h→0} [a^{x+h} − aˣ]/h = lim aˣ·[aʰ − 1]/h = aˣ · lim_{h→0} (aʰ − 1)/h (the constant aˣ factors out — the constant-multiple limit theorem). The general-base star: (aʰ − 1)/h → ln a as h → 0 (proved by writing a = e^{ln a}, so aʰ − 1 = e^{h ln a} − 1 ~ h ln a via the exponential star). Result: d/dx (aˣ) = aˣ ln a ∎. Deduction: for a = e, ln e = 1 ⟹ (eˣ)′ = eˣ — the self-replicating base. Deep point: the ln a factor is the "general-base tax"; e is the unique base that pays none, which is why natural logs are natural — calculus's algebra is simplest exactly in e's base, and every other base is e wearing a constant.
  • NEB-style (5m): Differentiate y = tan⁻¹((1 + x)/(1 − x)) and simplify the result. — Chain rule, outer first: with u = (1+x)/(1−x), dy/dx = [1/(1 + u²)]·u′. Inner derivative (quotient rule): u′ = [(1)(1−x) − (1+x)(−1)]/(1−x)² = [1 − x + 1 + x]/(1−x)² = 2/(1−x)². Simplify 1 + u²: 1 + (1+x)²/(1−x)² = [(1−x)² + (1+x)²]/(1−x)² = [1 − 2x + x² + 1 + 2x + x²]/(1−x)² = 2(1 + x²)/(1−x)². Compose: dy/dx = [(1−x)²/(2(1+x²))]·[2/(1−x)²] = 1/(1 + x²) (for x ≠ 1). The deep reveal: 1/(1+x²) is exactly the derivative of tan⁻¹x — and indeed (1+x)/(1−x) = tan(π/4 + tan⁻¹x) (tangent addition), so the function is tan⁻¹x shifted by the constant π/4 on its domain: same derivative, different branch. The algebra accidentally re-derived a trigonometric identity — chain-rule computations often expose hidden structure.
  • NEB-style (6m): Differentiate y = (tan x)^{x} using logarithmic differentiation, and state where the method is mandatory. — Why mandatory: both base (tan x) and exponent (x) vary — the power rule needs a constant exponent, the exponential rule a constant base; neither applies alone. Take logs: ln y = x·ln(tan x). Differentiate both sides (chain rule on the left; product rule on the right): y′/y = 1·ln(tan x) + x·[sec²x/tan x]. Simplify the inner term: sec²x/tan x = (1/cos²x)·(cos x/sin x) = 1/(sin x cos x) = 2/(2 sin x cos x) = 2/sin 2x = 2 cosec 2x. Solve: y′ = (tan x)ˣ[ln(tan x) + 2x·cosec 2x]. Deep points: (1) the log converts the power into a product — every u^v question becomes a product-rule question after one ln; (2) the pattern y′ = y(…) is universal: the original function always multiplies back, so the answer's shape is predictable before the details are.
