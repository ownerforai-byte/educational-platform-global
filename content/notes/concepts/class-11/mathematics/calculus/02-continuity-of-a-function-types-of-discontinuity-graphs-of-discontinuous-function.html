  • 1. Topic Introduction — Continuity and Its Graphs

    The calculus-unit continuity canonical: the three-part test, the discontinuity taxonomy with graphs, and the classification workflow — now with the graphical gallery as the centrepiece.

  • 2. Fundamental Concepts

    2.1 Continuity at a point and on intervals

    • Three-part test: f(a) exists; lim_{x→a} f(x) exists; f(a) = lim. Continuous on an interval ⟺ continuous at every interior point + one-sided at endpoints.
    • Closure families: polynomials (ℝ), rational (q ≠ 0), roots (domain), sin/cos (ℝ), eˣ (ℝ), ln x (x > 0); sums/products/quotients/compositions inherit.

    2.2 The discontinuity taxonomy (with graphs)

    • Removable: limit exists, value missing or wrong — open dot (hole) or detached dot; repairable by f(a) = L.
    • Jump: finite one-sided limits that differ — vertical gap; non-removable.
    • Infinite: a one-sided limit is ±∞ — vertical asymptote; odd multiplicity splits, even unifies.
    • Oscillatory (fourth species): no one-sided limit at all — sin(1/x) near 0 wiggles infinitely fast.

    2.3 Graphs of discontinuous functions

    • Hole: open dot on a continuous curve. Mismatch: closed dot elsewhere. Jump: two horizontal rays with a vertical gap, dots assigned by f(a). Wall: curve hugging a vertical line, arrows to ±∞. Oscillator: infinite folding near the point.

    2.4 The classification workflow

    • Domain → closure certification → suspect triage (limit vs value) → full report: continuity set, each break's type, repair verdict.

  • 4. Detailed Explanation

    4.1 Why the taxonomy has four species

    • The three-part test has exactly three failure modes, but "limit does not exist" splits into two graphically distinct ways — finite disagreement (jump) and unboundedness (infinite) — plus the no-limit-at-all case (oscillation). Four species, one test.

    4.2 Reading graphs diagnostically

    • Exam graphs show dots and gaps: an open dot asks "what limit fills me?"; a gap asks "how far apart are the sides?"; an asymptote asks "which side blows up?". Each graphical feature maps to one test condition.

    4.3 Discontinuity sets can be infinite

    • ⌊x⌋ jumps at every integer; Dirichlet-type functions (1 on rationals, 0 on irrationals) are discontinuous everywhere — the taxonomy scales from one point to the whole line.

  • 6. Common Confusions

    "Discontinuous" ≠ "the limit DNE": a removable break has a perfectly good limit — only the value is wrong.

  • One-sided continuity at jumps: f can be right-continuous at a jump (Heaviside) — discontinuity and one-sided continuity coexist.
  • Graphs can mislead at scale: near-invisible holes are still discontinuities; zoom is not a proof — compute.

  • 7. Exam Application

    NEB 2024 (verified PYQ): What does it mean for a function to be continuous at x = a? Check if f(x) = x² is continuous at x = 1. (3m) — Definition: f is continuous at a iff (1) f(a) exists, (2) lim_{x→a} f(x) exists, (3) f(a) = lim_{x→a} f(x) — value, limit, agreement. Check: f(1) = 1 exists ✓; lim_{x→1} x² = 1² = 1 (polynomial ⟹ direct substitution by continuity of powers) ✓; f(1) = 1 = limit ✓. Verdict: continuous at x = 1. (In fact x² is continuous on all of ℝ by closure.)

  • NEB-style (3m): Classify the discontinuities of f(x) = (x² − 1)/(x² − 1)·... f(x) = (x + 1)/(x² − 1) with graphs. — Factor: (x + 1)/[(x−1)(x+1)] = 1/(x − 1) for x ≠ ±1. At x = −1: limit 1/(−2) = −1/2 finite ⟹ removable hole at (−1, −1/2) — open dot. At x = 1: surviving zero, numerator 2 ≠ 0 ⟹ infinite — wall at x = 1, sides split (odd power): −∞ left, +∞ right. Continuity set: ℝ \ {−1, 1}.
  • NEB-style (2m): Sketch and classify g(x) = sin(1/x) for x ≠ 0, g(0) = 0. — For x → 0, 1/x → ±∞ and sin oscillates in [−1, 1] infinitely often — no one-sided limit ⟹ oscillatory discontinuity at 0 (non-removable). The graph folds infinitely many times near the origin; away from 0, closure (composition of continuous functions) certifies continuity.

  • 8. Deep Conceptual — The Damping Hierarchy

    • One factor of x tames one order of wildness: sin(1/x) at 0 is discontinuous (no limit, oscillatory); x·sin(1/x) with f(0) = 0 is continuous (squeeze: |x sin(1/x)| ≤ |x| → 0); x²·sin(1/x) is even differentiable at 0 (f′(0) = lim h·sin(1/h) = 0) — but its derivative x ↦ 2x sin(1/x) − cos(1/x) is discontinuous at 0.
    • The ladder: oscillation → damping by x gives continuity; damping by x² gives differentiability with discontinuous derivative; each extra power of x buys one more layer of regularity.
    • Exam moral: continuity, differentiability and continuous-differentiability are three separate rungs — a function can occupy any one without the next. Counterexamples climb this ladder.

  • 9. Deep Conceptual — IVT + Monotonicity = Root Certificates

    • The IVT alone gives existence: sign change + continuity ⟹ a root exists. Adding strict monotonicity (f′ > 0) gives uniqueness: two distinct roots a < b would force f(a) = f(b) = 0, contradicting strict increase. Together: exactly one root — a complete certificate.
    • Why this pairing is deep: existence needs no formula for the root (IVT is non-constructive); uniqueness needs only the derivative's sign. Neither tool needs to find the root — analysis certifies what algebra cannot locate.
    • Extension: x³ + x − 1 = 0 has f′ = 3x² + 1 > 0 everywhere ⟹ strictly increasing on ℝ ⟹ at most one root; f(0) = −1 < 0, f(1) = 1 > 0 ⟹ exactly one root, and it lies in (0, 1). Two one-line arguments, one complete theorem.

  • 10. Deep Conceptual — Continuity as an Interchange Licence

    • The deepest use of continuity is swapping limits with other operations: lim_{x→a} f(g(x)) = f(lim_{x→a} g(x)) (limit through composition), lim f(xₙ) = f(lim xₙ) (limit through sequences), ∫f = f·length for constant limits (limit through integration).
    • Each swap is illegal for discontinuous f — and the failure modes are exactly the four species. Continuity is the licence to interchange, and most of analysis is the study of when such interchanges are legal.
    • Practical reading: whenever a solution moves a limit "inside" a function without comment, the missing step is precisely a continuity citation — writing that citation is the difference between a computed answer and a proved one.

Confusion

  • ❌ answer with no steps → ✅ show each step and box the result.
  • ❌ skip the key fact → ✅ indeterminate forms 0/0, ∞/∞, 0·∞ → l'hôpital: lim f/g = lim f'/g' (when applicable)..
  • A removable discontinuity can be "fixed" by redefining the function at one point. Jump and infinite discontinuities cannot be removed this way.
  • The function f(x)=sin(1/x) for x=0 and f(0)=0 has an essential discontinuity at x=0 — no matter how you define f(0), the limit does not exist.
  • A vertical asymptote always indicates an infinite discontinuity, but not all discontinuities involve vertical asymptotes.
  • A function can be continuous at a point but not differentiable there (e.g., f(x)=∣x∣ at x=0). Continuity is a weaker condition than differentiability.
  • A function can have a limit at a point without being continuous there — the function might be undefined at that point, or its value might differ from the limit.

Practice Questions

  • NEB 2024 (verified PYQ): What does it mean for a function to be continuous at x = a? Check whether f(x) = x² is continuous at x = 1. (3m) — Definition (three-part test): f is continuous at x = a iff (1) f(a) is defined, (2) lim_{x→a} f(x) exists, and (3) the two are equal: f(a) = lim_{x→a} f(x) — the function's value must agree with the neighbourhood's consensus. Check for f(x) = x² at a = 1: (1) f(1) = 1² = 1, exists ✓. (2) lim_{x→1} x² = 1 — polynomials are continuous on ℝ (closure theorem), so direct substitution is licensed ✓. (3) f(1) = 1 = limit ✓. Verdict: f is continuous at x = 1 — all three parts hold. (Stronger: x² is continuous on all of ℝ by the closure theorem; the point check is the definition made concrete.)
  • NEB-style (3m): Find and classify the discontinuities of f(x) = (x + 1)/(x² − 1), describing the graph at each. — Factor: denominator (x − 1)(x + 1); numerator x + 1 shares the zero at −1. Cancel: f(x) = 1/(x − 1) for x ≠ ±1. At x = −1 (shared zero): lim_{x→−1} f(x) = 1/(−2) = −1/2, finite, but f(−1) undefined ⟹ removable discontinuity — the graph shows an open dot at (−1, −1/2); repair f(−1) = −1/2. At x = 1 (surviving zero): numerator 2 ≠ 0, denominator → 0 ⟹ infinite discontinuity — a vertical asymptote x = 1; the odd power of (x − 1) splits the sides: −∞ from the left, +∞ from the right; non-removable. Continuity set: ℝ \ {−1, 1} — one hole, one wall, both visible in the graph of 1/(x−1) with the dot at −1.
  • NEB-style (2m): Sketch and classify g(x) = sin(1/x) for x ≠ 0 with g(0) = 0. — Behaviour near 0: as x → 0⁺ (or 0⁻), 1/x → +∞ (or −∞), and sin(1/x) sweeps the full range [−1, 1] infinitely many times — between any two points near 0 the function crosses 0, 1 and −1 repeatedly. Consequence: neither lim_{x→0⁻} nor lim_{x→0⁺} exists ⟹ the two-sided limit does not exist, and this is not a jump (the sides are not finite numbers) nor infinite (no blow-up) — it is the fourth species: an oscillatory discontinuity at x = 0, non-removable. Graph: the curve folds infinitely often as it approaches the origin, where the single point (0, 0) sits — the classic "infinite folding" picture. Away from 0: g is a composition of continuous functions ⟹ continuous on ℝ \ {0}.
  • NEB-style (6m): Find the constants a and b so that f is continuous on ℝ, where f(x) = ax + b for x ≤ 1, f(x) = x² + 1 for 1 < x < 3, and f(x) = 3x − a − b for x ≥ 3. — Seam 1 (x = 1): LHL = a(1) + b = a + b; RHL = 1² + 1 = 2; f(1) = a + b. Continuity ⟹ a + b = 2. Seam 2 (x = 3): LHL = 3² + 1 = 10; RHL = 3(3) − a − b = 9 − a − b; f(3) = 9 − a − b. Continuity ⟹ 9 − a − b = 10 ⟹ a + b = −1. Contradiction: a + b cannot be both 2 and −1 ⟹ no constants work — f cannot be made continuous on ℝ. Deep conceptual point: each seam contributes one linear equation; two seams give two equations in two unknowns, and here the system is inconsistent — the middle branch's heights (2 at x = 1, 10 at x = 3) fix the required side-values, and the outer branches cannot meet both demands. Continuity conditions are equations, and equations can have no solution — the honest answer is "impossible", with the inconsistency exhibited.
  • NEB-style (5m): Show that the equation x³ + x − 1 = 0 has exactly one real root, located in (0, 1). — Existence (IVT): f(x) = x³ + x − 1 is a polynomial ⟹ continuous on [0, 1]; f(0) = −1 < 0 and f(1) = 1 > 0 ⟹ by the Intermediate Value Theorem a root exists in (0, 1). Uniqueness (monotonicity): f′(x) = 3x² + 1 ≥ 1 > 0 for all x ⟹ f is strictly increasing on ℝ; a strictly increasing function takes each value at most once, so two distinct roots are impossible. Conclusion: exactly one real root, and it lies in (0, 1) ∎. Deep conceptual pairing: the IVT is non-constructive — it certifies existence without locating the root; strict monotonicity certifies uniqueness without finding it. Together they produce a complete existence-and-uniqueness theorem from two sign arguments — the standard template for "show the equation has exactly one solution".
  • NEB-style (5m): Compare f₁(x) = sin(1/x) (f₁(0) = 0), f₂(x) = x·sin(1/x) (f₂(0) = 0) and f₃(x) = x²·sin(1/x) (f₃(0) = 0) at x = 0. — f₁: sin(1/x) oscillates in [−1, 1] infinitely often near 0 with no damping ⟹ no one-sided limit ⟹ oscillatory discontinuity at 0. f₂: |x sin(1/x)| ≤ |x| → 0 (squeeze) ⟹ lim = 0 = f₂(0) ⟹ continuous at 0 — the single factor x damps the oscillation into convergence. f₃: |x² sin(1/x)| ≤ x² → 0 ⟹ continuous at 0; moreover f₃′(0) = lim_{h→0} [h² sin(1/h) − 0]/h = lim h·sin(1/h) = 0 (squeeze again) ⟹ differentiable at 0 with f₃′(0) = 0. The damping hierarchy: one power of x buys continuity; two powers buy differentiability; but f₃′(x) = 2x sin(1/x) − cos(1/x) (x ≠ 0) still oscillates near 0 ⟹ f₃′ is not continuous at 0 — three rungs (continuous, differentiable, continuously differentiable) are genuinely distinct, and each extra factor of x climbs exactly one rung.
  • NEB-style (4m): State the Intermediate Value Theorem and use it to show that f(x) = x − cos x has a root between 0 and π/2. — Theorem: if f is continuous on the closed interval [a, b] and u lies between f(a) and f(b), then some c ∈ (a, b) satisfies f(c) = u. Application: f(x) = x − cos x is continuous on [0, π/2] (difference of continuous functions — closure). Endpoint signs: f(0) = 0 − cos 0 = −1 < 0; f(π/2) = π/2 − cos(π/2) = π/2 − 0 = π/2 > 0. Since 0 lies between −1 and π/2, the IVT supplies c ∈ (0, π/2) with f(c) = 0 — the equation x = cos x has a solution in (0, π/2) ∎. Bonus depth: f′ = 1 + sin x ≥ 1 > 0 ⟹ f is strictly increasing ⟹ the root is unique — the Dottie number ≈ 0.739, the fixed point of cosine, certified by exactly this pair of arguments.

Summary

Continuity in the calculus unit is the three-part test plus the full species atlas. The test — value, limit, agreement — has three failure modes, but the "limit does not exist" branch splits graphically: removable (open or detached dot; repair f(a) = L), jump (finite unequal sides; vertical gap), infinite (±∞ side; vertical asymptote, odd multiplicity splitting, even unifying), and the fourth species oscillatory (sin(1/x)'s infinite folding — no side limit at all). Graphs are diagnostic: open dots ask for limits, gaps measure jump sizes, walls demand side-signs, folding forbids repair. The workflow — domain, closure certification, suspect triage, full report (continuity set, types, repairs) — turns every function into a classified map, from one hole in a rational to the floor function's infinite staircase to the Dirichlet function's total discontinuity.   • NEB 2024 (verified PYQ): What does it mean for a function to be continuous at x = a? Check whether f(x) = x² is continuous at x = 1. (3m) — Definition (three-part test): f is continuous at x = a iff (1) f(a) is defined, (2) lim_{x→a} f(x) exists, and (3) the two are equal: f(a) = lim_{x→a} f(x) — the function's value must agree with the neighbourhood's consensus. Check for f(x) = x² at a = 1: (1) f(1) = 1² = 1, exists ✓. (2) lim_{x→1} x² = 1 — polynomials are continuous on ℝ (closure theorem), so direct substitution is licensed ✓. (3) f(1) = 1 = limit ✓. Verdict: f is continuous at x = 1 — all three parts hold. (Stronger: x² is continuous on all of ℝ by the closure theorem; the point check is the definition made concrete.)
  • NEB-style (3m): Find and classify the discontinuities of f(x) = (x + 1)/(x² − 1), describing the graph at each. — Factor: denominator (x − 1)(x + 1); numerator x + 1 shares the zero at −1. Cancel: f(x) = 1/(x − 1) for x ≠ ±1. At x = −1 (shared zero): lim_{x→−1} f(x) = 1/(−2) = −1/2, finite, but f(−1) undefined ⟹ removable discontinuity — the graph shows an open dot at (−1, −1/2); repair f(−1) = −1/2. At x = 1 (surviving zero): numerator 2 ≠ 0, denominator → 0 ⟹ infinite discontinuity — a vertical asymptote x = 1; the odd power of (x − 1) splits the sides: −∞ from the left, +∞ from the right; non-removable. Continuity set: ℝ \ {−1, 1} — one hole, one wall, both visible in the graph of 1/(x−1) with the dot at −1.
  • NEB-style (2m): Sketch and classify g(x) = sin(1/x) for x ≠ 0 with g(0) = 0. — Behaviour near 0: as x → 0⁺ (or 0⁻), 1/x → +∞ (or −∞), and sin(1/x) sweeps the full range [−1, 1] infinitely many times — between any two points near 0 the function crosses 0, 1 and −1 repeatedly. Consequence: neither lim_{x→0⁻} nor lim_{x→0⁺} exists ⟹ the two-sided limit does not exist, and this is not a jump (the sides are not finite numbers) nor infinite (no blow-up) — it is the fourth species: an oscillatory discontinuity at x = 0, non-removable. Graph: the curve folds infinitely often as it approaches the origin, where the single point (0, 0) sits — the classic "infinite folding" picture. Away from 0: g is a composition of continuous functions ⟹ continuous on ℝ \ {0}.
  • NEB-style (6m): Find the constants a and b so that f is continuous on ℝ, where f(x) = ax + b for x ≤ 1, f(x) = x² + 1 for 1 < x < 3, and f(x) = 3x − a − b for x ≥ 3. — Seam 1 (x = 1): LHL = a(1) + b = a + b; RHL = 1² + 1 = 2; f(1) = a + b. Continuity ⟹ a + b = 2. Seam 2 (x = 3): LHL = 3² + 1 = 10; RHL = 3(3) − a − b = 9 − a − b; f(3) = 9 − a − b. Continuity ⟹ 9 − a − b = 10 ⟹ a + b = −1. Contradiction: a + b cannot be both 2 and −1 ⟹ no constants work — f cannot be made continuous on ℝ. Deep conceptual point: each seam contributes one linear equation; two seams give two equations in two unknowns, and here the system is inconsistent — the middle branch's heights (2 at x = 1, 10 at x = 3) fix the required side-values, and the outer branches cannot meet both demands. Continuity conditions are equations, and equations can have no solution — the honest answer is "impossible", with the inconsistency exhibited.
  • NEB-style (5m): Show that the equation x³ + x − 1 = 0 has exactly one real root, located in (0, 1). — Existence (IVT): f(x) = x³ + x − 1 is a polynomial ⟹ continuous on [0, 1]; f(0) = −1 < 0 and f(1) = 1 > 0 ⟹ by the Intermediate Value Theorem a root exists in (0, 1). Uniqueness (monotonicity): f′(x) = 3x² + 1 ≥ 1 > 0 for all x ⟹ f is strictly increasing on ℝ; a strictly increasing function takes each value at most once, so two distinct roots are impossible. Conclusion: exactly one real root, and it lies in (0, 1) ∎. Deep conceptual pairing: the IVT is non-constructive — it certifies existence without locating the root; strict monotonicity certifies uniqueness without finding it. Together they produce a complete existence-and-uniqueness theorem from two sign arguments — the standard template for "show the equation has exactly one solution".
  • NEB-style (5m): Compare f₁(x) = sin(1/x) (f₁(0) = 0), f₂(x) = x·sin(1/x) (f₂(0) = 0) and f₃(x) = x²·sin(1/x) (f₃(0) = 0) at x = 0. — f₁: sin(1/x) oscillates in [−1, 1] infinitely often near 0 with no damping ⟹ no one-sided limit ⟹ oscillatory discontinuity at 0. f₂: |x sin(1/x)| ≤ |x| → 0 (squeeze) ⟹ lim = 0 = f₂(0) ⟹ continuous at 0 — the single factor x damps the oscillation into convergence. f₃: |x² sin(1/x)| ≤ x² → 0 ⟹ continuous at 0; moreover f₃′(0) = lim_{h→0} [h² sin(1/h) − 0]/h = lim h·sin(1/h) = 0 (squeeze again) ⟹ differentiable at 0 with f₃′(0) = 0. The damping hierarchy: one power of x buys continuity; two powers buy differentiability; but f₃′(x) = 2x sin(1/x) − cos(1/x) (x ≠ 0) still oscillates near 0 ⟹ f₃′ is not continuous at 0 — three rungs (continuous, differentiable, continuously differentiable) are genuinely distinct, and each extra factor of x climbs exactly one rung.
  • NEB-style (4m): State the Intermediate Value Theorem and use it to show that f(x) = x − cos x has a root between 0 and π/2. — Theorem: if f is continuous on the closed interval [a, b] and u lies between f(a) and f(b), then some c ∈ (a, b) satisfies f(c) = u. Application: f(x) = x − cos x is continuous on [0, π/2] (difference of continuous functions — closure). Endpoint signs: f(0) = 0 − cos 0 = −1 < 0; f(π/2) = π/2 − cos(π/2) = π/2 − 0 = π/2 > 0. Since 0 lies between −1 and π/2, the IVT supplies c ∈ (0, π/2) with f(c) = 0 — the equation x = cos x has a solution in (0, π/2) ∎. Bonus depth: f′ = 1 + sin x ≥ 1 > 0 ⟹ f is strictly increasing ⟹ the root is unique — the Dottie number ≈ 0.739, the fixed point of cosine, certified by exactly this pair of arguments.

Important Concepts

  • The three-part test has three failure modes, but the limit-failure splits graphically into jump, wall and oscillator - four species, one test.

Important Statements

  • "Continuous at a iff f(a) = lim_{x->a} f(x) with both existing; the species are removable, jump, infinite, oscillatory."
