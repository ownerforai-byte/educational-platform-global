Notes

  • 1. Topic Introduction — The Four-Number Address of Every Electron

    The quantum mechanical model replaced orbits with orbitals; quantum numbers are the postal address system that labels each electron inside them. Four numbers — n, l, mₗ, mₛ — fix an electron's shell, subshell, orientation and spin. NEB examines them two ways every cycle: define and give values (3m) and test which sets are possible (2m). Master the rules and both are free marks.

  • 2. Fundamental Concepts — The Four Quantum Numbers

    2.1 Principal quantum number (n)

    • Meaning: main energy shell; size and energy of the orbital.
    • Values: n = 1, 2, 3, 4, … (K, L, M, N).
    • Consequences: max electrons in a shell = 2n²; energy rises with n; distance from nucleus rises with n.

    2.2 Azimuthal (angular momentum) quantum number (l)

    • Meaning: shape of the orbital — the subshell.
    • Values: l = 0 to (n − 1).
    • Names: l = 0 → s (sharp, spherical); l = 1 → p (principal, dumbbell); l = 2 → d (diffuse, cloverleaf); l = 3 → f (fundamental).
    • Consequences: number of subshells in a shell = n; angular momentum = √(l(l+1))·h/2π.

    2.3 Magnetic quantum number (mₗ)

    • Meaning: orientation of the orbital in space.
    • Values: −l to +l including 0 — i.e. (2l + 1) values.
    • Consequences: number of orbitals in a subshell = 2l + 1 → s: 1, p: 3, d: 5, f: 7; max electrons in a subshell = 2(2l + 1) → s: 2, p: 6, d: 10, f: 14.

    2.4 Spin quantum number (mₛ)

    • Meaning: intrinsic spin of the electron.
    • Values: +1/2 or −1/2 only.
    • Consequences: Pauli's exclusion principle — no two electrons in one orbital share all four numbers; an orbital holds at most 2 electrons of opposite spin.

  • 4. Detailed Explanation

    4.1 Worked example — NEB 2024 (3m, verified PYQ)

    Q: Write the four quantum numbers for the valence electron of sodium (Z = 11).

    Configuration: Na = 1s² 2s² 2p⁶ 3s¹ — the valence electron is in 3s.

    Quantum numberValueReason
    n3Third shell
    l0s subshell
    mₗ0s has only one orientation
    mₛ+1/2The single electron takes spin-up by convention

    Answer: n = 3, l = 0, mₗ = 0, mₛ = +1/2.

    4.2 Worked example — NEB 2023 (2m, verified PYQ)

    Q: Which set is not possible: (a) 3, 1, +1, +1/2 (b) 3, 1, +2, −1/2 (c) 3, 1, −1, −1/2 (d) 3, 0, 0, +1/2?

    Rules: l ≤ n − 1; −l ≤ mₗ ≤ +l; mₛ = ±1/2.

    • (a) l = 1 allows mₗ = −1, 0, +1 → possible (3p).
    • (b) mₗ = +2 exceeds l = 1 → not possible — the answer.
    • (c) mₗ = −1 is allowed → possible (3p).
    • (d) l = 0 forces mₗ = 0 → possible (3s).

    4.3 Why the rules exist

    • l ≤ n − 1: a wave in shell n needs at least one wavelength of curvature; you cannot have a p-shaped (l = 1) wave in a shell too small to hold it.
    • (2l + 1) orientations: angular momentum has 2l + 1 allowed projections along an axis — the geometric root of the magnetic quantum number.
    • Pauli: two identical fermions cannot share one quantum state — the deepest reason an orbital holds exactly two opposite-spin electrons.

    4.4 Electron addresses for common atoms (practice loop)

    • H (Z = 1): 1, 0, 0, +1/2.
    • C (Z = 6) valence p electron: 2, 1, −1 (or 0, +1), +1/2.
    • Na (Z = 11): 3, 0, 0, +1/2.
    • Fe (Z = 26) last electron (3d⁶): 3, 2, −2, +1/2 (by convention filling starts at mₗ = −2).

  • 6. Common Confusions

    l range vs mₗ range: l runs 0 to n − 1; mₗ runs −l to +l. For n = 3, l = 2 is legal (3d) but mₗ = 2 with l = 1 is not — the two ranges are different rules.

  • "n = 3, l = 3" trap: l can never equal n; the highest l in shell n is n − 1 (3f does not exist).
  • mₛ values: only ±1/2 — never ±1. Spin "up/down" is shorthand for the two signs, not a literal direction.

  • 7. Exam Application

    NEB-style (2m): How many orbitals and electrons can the M shell hold? — Orbitals = n² = 9 (one 3s, three 3p, five 3d); electrons = 2n² = 18.

  • NEB-style (2m): Write the quantum numbers of the last electron of nitrogen (Z = 7). — Configuration 1s² 2s² 2p³; last electron: n = 2, l = 1, mₗ = −1, mₛ = +1/2 (Hund's rule: the three p electrons occupy the three p orbitals singly with parallel spins).
  • NEB-style (3m): State the significance of each quantum number. — n: shell, size and energy (2n² capacity); l: subshell shape (s, p, d, f); mₗ: spatial orientation, 2l + 1 orbitals; mₛ: spin direction, ±1/2, basis of Pauli's exclusion principle.

Confusion

  • l ≤ n − 1, always: "3f" (n = 3, l = 3) and "2d" (n = 2, l = 2) are impossible — the shape cannot outrun its shell.
  • mₗ range depends on l, not n: mₗ = ±2 is legal only when l ≥ 2 (d or f), whatever n is.

Practice

  • Why can no subshell hold more than 2(2l + 1) electrons?
  • Write all four quantum numbers for every electron of helium.
  • Why does mₗ have no effect on the energy of an orbital in the absence of a magnetic field?

Formulas

    • l = 0, 1, 2, …, (n − 1)
    • mₗ = −l, …, 0, …, +l → orbitals per subshell = 2l + 1
    • Max electrons: shell 2n²; subshell 2(2l + 1); orbital 2
    • Angular momentum = √(l(l+1))·h/2π

Universal Facts

  • Quantum numbers emerged from spectroscopy: Zeeman splitting (mₛ/mₗ) and fine structure could not be explained until each electron needed four coordinates instead of one orbit.

Examples

  • Fe's last electron: 3, 2, −2, +1/2 — a 3d electron (n = 3, l = 2); filling starts at mₗ = −2 with spin-up, per Hund's rule and the conventional mₗ ordering.

Summary

Every electron in an atom carries a four-number address: n (principal — shell, size, energy, 2n² capacity), l (azimuthal — subshell shape, 0 to n−1: s, p, d, f), mₗ (magnetic — orientation, −l to +l, 2l + 1 orbitals per subshell) and mₛ (spin — ±1/2, the basis of Pauli's exclusion principle). Sodium's valence electron (NEB 2024) is 3, 0, 0, +1/2; the impossible-set test (NEB 2023) runs three checks — l ≤ n−1, |mₗ| ≤ l, mₛ = ±1/2 — and catches mₗ = +2 with l = 1 instantly. The numbers are not bookkeeping: n, l, mₗ, mₛ are exactly the coordinates the Schrödinger equation needs, and each one repairs a defect of Bohr's model.
