Notes

  • 1. Topic Introduction — Naming the Table's Empty Seats

    New superheavy elements spend years with only an atomic number and no agreed name. IUPAC's solution: a systematic temporary name built from the digits of Z, so every element — named or not — has an unambiguous label and a definite place in the table. The scheme also fixes the group-numbering system (1–18) that replaced the old IA/VIIIA maze.

  • 2. Fundamental Concepts

    2.1 IUPAC group numbering (1–18)

    • The old split notation (IA, IIA, IIIB… VIIIB, zero group) is replaced by consecutive numbering 1 to 18.
    • Mapping: old IA → 1, IIA → 2, IIIB → 3 … VIIIB (iron family) → 8, 9, 10, IB → 11, IIB → 12, IIIA → 13 … VIIA → 17, zero → 18.
    • Advantage: one number per column, no A/B ambiguity between national conventions (old US vs European labels differed).

    2.2 Systematic naming of elements with Z > 100

    Digits → roots:

    Digit0123456789
    Rootnilunbitriquadpenthexseptoctenn
    • Name = roots of the digits (in order) + -ium.
    • Symbol = first letters of the roots (first letter capital), two or three letters.
    • When two 'n' sounds meet, drop one: enn + nil → ennil (not enn-nil).

    2.4 Why the scheme exists

    Discoveries from rival labs (e.g. 104–107: Dubna vs Berkeley) produced competing names that stalled for decades. IUPAC's digit-name is automatic and neutral — no scientist's name, no nationality — and lasts only until the confirmed permanent name is ratified.

  • 4. Detailed Explanation

    4.1 Building a name — the 3m drill

    Q: Derive the IUPAC temporary name and symbol for Z = 117. Digits: 1, 1, 7 → un, un, sept → Ununseptium, symbol Uus (now permanently Tennessine, Ts). The method: split Z into digits, translate each to its root, append -ium, take initials for the symbol.

    4.2 The special rules (where marks are lost)

    1. enn + nil → ennil: Z = 190 → un-enn-nil-ium = Unennilium (not Unennnilium).
    2. enn + oct keeps both n's? No — the rule applies only before nil: Z = 139 → un-tri-enn-ium = Untriennium (enn before ium keeps its n).
    3. All names end in -ium, even for elements expected to be gases — they are temporary stand-in names, not chemistry.

    4.3 The completed seventh period

    With the naming of Nh (113), Mc (115), Lv (116), Ts (117) and Og (118) in 2016, period 7 is complete with 118 elements — the f-block actinoids and the final p-block row are filled. Any future element (Z = 119, 120) opens period 8 and would start with 8s.

  • 6. Common Confusions

    Symbol vs name initials: the symbol comes from the root initials in order — Z = 107 → Un-nil-Septium → Uus; taking 'U' + element meaning loses the mark.

  • enn before nil vs before oct: drop the duplicate n only before nil (ennil); before other roots and before -ium the full "enn" stays.
  • Temporary names never use capital roots: Unnilquadium — only the first letter is capital; "unNilquadium" is wrong.

    NEB-style (2m): Write the IUPAC name and symbol for the element with Z = 121. — Digits 1, 2, 1 → un, bi, un → Unbiunium, symbol Ubu (a hypothetical period-8 element).

  • NEB-style (2m): Why did IUPAC introduce systematic nomenclature? — Rival discovery claims (Z = 104–109) created naming disputes; a rule-based name derived from Z is neutral and unambiguous until priority is settled and a permanent name ratified.
  • NEB-style (2m): Convert old group VIIA and group 0 to IUPAC numbering. — VIIA → group 17 (halogens); group 0 → group 18 (noble gases).

Summary

IUPAC replaced the tangled IA/VIIIB/zero labels with consecutive group numbers 1–18 and gave every not-yet-named element a mechanical stand-in name: split the atomic number into digits, translate each through the roots nil-un-bi-tri-quad-pent-hex-sept-oct-enn, append -ium, and take the roots' initials as the symbol (Unnilquadium, Unq, for Z = 104; Ununoctium, Uuo, for Z = 118). One special rule — enn + nil → ennil — prevents double n's. The scheme is neutral in discovery disputes and works for elements that do not yet exist (Unbiunium for Z = 121). With Nh, Mc, Lv, Ts and Og ratified in 2016, period 7 is complete at 118 elements; the next element will open period 8.
