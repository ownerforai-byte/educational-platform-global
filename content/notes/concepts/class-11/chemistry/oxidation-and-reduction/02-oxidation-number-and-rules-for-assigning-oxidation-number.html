Notes

  • 1. Topic Introduction — The Charge Ledger of Every Atom

    The oxidation number is a formal charge — the value an atom would carry if every bond were fully ionic. It is not a physical charge, but it is the most useful fiction in chemistry: it tracks electron control through any reaction, flags the redox pair in an instant, and supplies the balancing engine of topic 40. Learn the nine rules and a page of worked values, and no oxidation number can hide.

  • 2. Fundamental Concepts

    2.1 The rules (in checking order)

    1. Free element = 0: O₂, H₂, Fe, S₈, P₄ — all zero.
    2. Monatomic ion = its charge: Na⁺ +1, Ca²⁺ +2, Cl⁻ −1, Al³⁺ +3.
    3. Fluorine = −1 always — the only element with no exceptions (even in OF₂ it stays −1, forcing O to +2).
    4. Oxygen = −2 normally; −1 in peroxides (H₂O₂, Na₂O₂); −½ in superoxides (KO₂); +2 in OF₂; 0 in O₂.
    5. Hydrogen = +1 normally; −1 in binary hydrides with metals (NaH, CaH₂).
    6. Sum of all oxidation numbers = the species' charge: 0 for molecules, the ion charge for polyatomic ions.
    7. Maximum positive = group number (group 1 → +1, group 2 → +2, Al → +3); negative states reach down to group number − 8.
    8. More electronegative atom takes the negative share of a shared pair.
    9. Fractional values are allowed — they are averages over inequivalent atoms (Fe₃O₄, Na₂S₄O₆).

    2.2 Worked values (the exam gallery)

    • Mn in KMnO₄: +1 + Mn + 4(−2) = 0 → Mn = +7 (NEB 2024).
    • Cr in K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → 2Cr = +12 → Cr = +6 (NEB 2024).
    • S in H₂SO₄: 2(+1) + S + 4(−2) = 0 → S = +6; in SO₄²⁻ also +6.
    • N in HNO₃: +1 + N + 3(−2) = 0 → N = +5; in NH₄⁺: N = −3.
    • Cl in HClO₄: +7; in HClO: +1; in ClO₃⁻: +5.
    • C in CH₄: −4; in CO₂: +4; in CH₃OH: −2 (the C–H pairs count for H).
    • Fe in [Fe(CN)₆]³⁻: Fe + 6(−1) = −3 → Fe = +3.
    • Fractional: Fe₃O₄ → 3Fe + 4(−2) = 0 → Fe = +8/3; Na₂S₄O₆ → S = +2.5 (two S at 0, two at +5).
    • Mn in MnO₄²⁻: Mn + 4(−2) = −2 → +6 — one step below permanganate's +7.

    2.3 What oxidation numbers are for

    • Spotting redox: compare every element's number on both sides; movers mark the redox pair.
    • Classifying: oxidation = increase (Fe²⁺ +0.67… wait — Fe²⁺ → Fe³⁺ is +2 → +3); reduction = decrease.
    • n-factor and equivalents: the electron change per formula unit — K₂Cr₂O₇ (Cr +6 → +3 ×2) has n = 6; KMnO₄ in acid (Mn +7 → +2) has n = 5.
    • Nomenclature: FeCl₂ iron(II) chloride, FeCl₃ iron(III) chloride; the stock notation is built on oxidation numbers.

  • 4. Detailed Explanation

    4.1 Verified PYQ (NEB 2024): state the rules; find Mn in KMnO₄ and Cr in K₂Cr₂O₇

    • Rules (section 2.1, quoted compactly): free elements 0; monatomic ions = charge; F always −1; O −2 except peroxides −1 and OF₂ +2; H +1 except metal hydrides −1; the sum equals the species' charge.
    • KMnO₄: K is +1 (group 1), O is −2. +1 + Mn + 4(−2) = 0 → Mn = +7.
    • K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → 2Cr = +12 → Cr = +6. Both values explain why these salts are premier oxidising agents: +7 and +6 are the top of their ladders, with plenty of room to fall.

    4.2 The peroxide trap and its cousins

    • H₂O₂: H is +1 (×2), so O averages −1 — not −2. Na₂O₂ likewise (2(+1) + 2O = 0 → O = −1).
    • KO₂ (superoxide): K +1, O −½. OF₂: F −1 (×2) forces O = +2 — oxygen's only positive oxide-state with fluorine.
    • Metal hydrides flip hydrogen: NaH → Na +1, H = −1.

    4.3 Fractional numbers mean mixed sites

    • Fe₃O₄ is FeO·Fe₂O₃: one Fe²⁺ and two Fe³⁺ — the average is +8/3, a bookkeeping artifact, not a real charge.
    • Na₂S₄O₆ (tetrathionate): the two inner sulphurs sit at 0, the two terminal ones at +5; the average 2.5 only emerges from the sum rule.

    4.4 From numbers to n-factor

    • KMnO₄ in acid: Mn +7 → +2, 5 electrons per Mn → n = 5, equivalent mass = 158/5 = 31.6.
    • K₂Cr₂O₇ in acid: each Cr +6 → +3, two Crs → 6 electrons → n = 6, equivalent mass = 294/6 = 49 (the NEB 2021 value, fully worked in topic 40).
    • I₂ → 2I⁻: n = 2; Na₂S₂O₃ → S₄O₆²⁻: each of two S climbs by ½ → n = 1 per thiosulphate (iodometry's engine).

  • 6. Common Confusions

    Oxidation number ≠ ionic charge: Mn(+7) in KMnO₄ is bookkeeping; there is no free Mn⁷⁺ ion. Charges belong to actual ions; numbers belong to atoms inside any species.

  • The peroxide exception is the favourite exam trap: defaulting O to −2 in H₂O₂ wrecks the sum — check for O–O bonds first.
  • Fractional answers are correct answers: +8/3 and +2.5 are legitimate averages; do not "fix" them into integers.

  • 7. Exam Application

    Verified PYQ (NEB 2024): State the rules for assigning oxidation numbers. Find the oxidation number of Mn in KMnO₄ and Cr in K₂Cr₂O₇. — Rules: (1) free elements 0; (2) monatomic ions equal their charges; (3) fluorine −1 in all compounds; (4) oxygen −2 except −1 in peroxides and +2 in OF₂; (5) hydrogen +1 except −1 in metal hydrides; (6) the sum equals the net charge. KMnO₄: +1 + Mn + 4(−2) = 0 → Mn = +7. K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → Cr = +6.

  • NEB-style (2m): Find the oxidation number of S in Na₂S₄O₆ and Fe in Fe₃O₄. — Tetrathionate: 2(+1) + 4S + 6(−2) = 0 → 4S = +10 → S = +2.5 (an average: two S at 0, two at +5). Magnetite: 3Fe + 4(−2) = 0 → Fe = +8/3 (FeO·Fe₂O₃: one +2, two +3).
  • NEB-style (2m): Identify the redox pair in 2KI + Cl₂ → 2KCl + I₂. — Iodine: −1 in KI → 0 in I₂ (increase — oxidised; Cl₂ is the oxidising agent). Chlorine: 0 → −1 (decrease — reduced; I⁻ is the reducing agent). K⁺ and the chloride counterions are spectators at +1 throughout.

Confusion

  • Check O for peroxides before anything else: the −1 default-breaker appears in H₂O₂, Na₂O₂, BaO₂ — and in every H₂O₂ redox question.
  • Group number caps: group 1 metals cannot show +2; the maximum positive oxidation number is the group number (Al stops at +3, Mn's ceiling is +7).

Practice

  • Assign oxidation numbers to every atom in K₂MnO₄, CrO₅, and Na₂S₂O₃.
  • Why does CrO₅ contain a peroxide pair, and what is chromium's oxidation number there?
  • Identify the species oxidised and reduced in 3CuO + 2NH₃ → 3Cu + N₂ + 3H₂O using oxidation numbers.

Universal Facts

  • The Mars rover hunts haematite (Fe₂O₃, Fe +3) because iron's oxidation states record a planet's water history — oxidation numbers as geological fingerprints.

Practice Questions

  • NEB 2024 (3m): State the rules for assigning oxidation numbers. Find the oxidation number of Mn in KMnO₄ and Cr in K₂Cr₂O₇. — Rules: (1) atoms in a free element have oxidation number 0 (O₂, H₂, Fe); (2) a monatomic ion's number equals its charge (Na⁺ +1, Cl⁻ −1); (3) fluorine is −1 in all its compounds; (4) oxygen is −2 except −1 in peroxides (H₂O₂) and +2 in OF₂; (5) hydrogen is +1 except −1 in binary metal hydrides (NaH); (6) the sum of all oxidation numbers equals the charge of the species (0 for molecules, the ionic charge for ions). KMnO₄: potassium is +1 and each oxygen −2, so +1 + Mn + 4(−2) = 0, giving Mn = +7. K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → 2Cr = +12, giving Cr = +6. Both elements sit at the top of their oxidation-state ladders, which is why these compounds are strong oxidising agents in acid medium.
  • NEB-style (2m): Calculate the oxidation numbers of sulphur in Na₂S₄O₆ and iron in Fe₃O₄, commenting on any fractional values. — Na₂S₄O₆ (tetrathionate): 2(+1) + 4S + 6(−2) = 0 → 4S = +10 → S = +2.5. The fraction is an average: the two inner sulphur atoms (S–S linked) are at 0 while the two terminal ones bonded to oxygen are at +5. Fe₃O₄ (magnetite): 3Fe + 4(−2) = 0 → Fe = +8/3 ≈ +2.67 — magnetite is a mixed oxide, FeO·Fe₂O₃, containing one Fe²⁺ and two Fe³⁺ per formula unit; the fractional number is the statistical average, not a real charge on any single ion.
  • NEB-style (2m): Using oxidation numbers, identify what is oxidised and what is reduced in 2KI + Cl₂ → 2KCl + I₂. — Iodine moves from −1 (in KI) to 0 (in I₂): its oxidation number increases, so iodide is oxidised and acts as the reducing agent. Chlorine moves from 0 (Cl₂) to −1 (in KCl): its number decreases, so chlorine is reduced and acts as the oxidising agent. Potassium stays at +1 throughout — a spectator. The reaction is a single-displacement redox driven by chlorine's position above iodine in the electrochemical series of halogens.

Formulas

    • KMnO₄: +1 + Mn + 4(−2) = 0 → Mn = +7
    • K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → Cr = +6
    • Fe₃O₄: 3Fe + 4(−2) = 0 → Fe = +8/3
    • Na₂S₄O₆: 2(+1) + 4S + 6(−2) = 0 → S = +2.5
    • Equivalent mass = formula mass / n-factor (KMnO₄ 158/5 = 31.6; K₂Cr₂O₇ 294/6 = 49)

Key Points

  • Nine rules: free 0; ion = charge; F −1 always; O −2 (−1 peroxide, −½ superoxide, +2 in OF₂); H +1 (−1 in metal hydrides); sum = charge; max positive = group number; EN atom negative; fractional averages allowed. Values: Mn/KMnO₄ +7, Cr/K₂Cr₂O₇ +6, S/H₂SO₄ +6, N/HNO₃ +5, Cl/HClO₄ +7, C: CH₄ −4, CO₂ +4. Fractional: Fe₃O₄ +8/3, Na₂S₄O₆ +2.5. n-factor: KMnO₄ acid 5, K₂Cr₂O₇ 6, I₂ 2.

Summary

The oxidation number is chemistry's universal charge ledger: a formal value assigned by nine rules — free elements 0, ions their charge, fluorine locked at −1, oxygen −2 (with the peroxide −1, superoxide −½ and OF₂ +2 exceptions), hydrogen +1 (−1 in metal hydrides), and the sum always equal to the species' charge. Applied, it produces the exam gallery: Mn at +7 in KMnO₄, Cr at +6 in K₂Cr₂O₇, S +6 in H₂SO₄, N +5 in HNO₃, C from −4 in methane to +4 in CO₂ — and tolerates honest fractions like Fe₃O₄'s +8/3 and tetrathionate's +2.5, which are averages over mixed sites. Its three jobs: detect redox (whichever number moves), quantify it (n-factor — 5 for acid permanganate, 6 for dichromate — feeding equivalent masses of 31.6 and 49), and name compounds (iron(II) versus iron(III)). Master the sum-rule algebra and the exception table, and every balancing question downstream becomes arithmetic.

Values: Mn/KMnO₄ +7, Cr/K₂Cr₂O₇ +6, S/H₂SO₄ +6, N/HNO₃ +5, Cl/HClO₄ +7, C: CH₄ −4, CO₂ +4. Fractional: Fe₃O₄ +8/3, Na₂S₄O₆ +2.5. n-factor: KMnO₄ acid 5, K₂Cr₂O₇ 6, I₂ 2.
Important Concepts
  • Oxidation number is the bridge topic: it detects redox (numbers move), measures extent (n-factor and equivalents), and powers the balancing methods of topic 40 — one bookkeeping system, three jobs.
Examples
  • The +7 summit — Mn in KMnO₄ sits at the highest state a 3d element reaches; its fall to +2 in acid (5 electrons) is why permanganate titrations dominate quantitative analysis.
Universal Facts
  • The Mars rover hunts haematite (Fe₂O₃, Fe +3) because iron's oxidation states record a planet's water history — oxidation numbers as geological fingerprints.
Important Statements
  • "The oxidation number of an atom is the formal charge it would carry if the bonds were entirely ionic — the sum of oxidation numbers equals the charge of the species."
Important Notes
  • Verified PYQ: NEB 2024 — rules for assigning oxidation numbers with Mn in KMnO₄ (+7) and Cr in K₂Cr₂O₇ (+6), solved above. The NEB 2021 equivalent-mass question belongs to topic 40. Other items are NEB-style practice.
Exam Short Tricks
  • Sum-rule algebra: "charge of other atoms, subtract from total". Traps: peroxides −1, hydrides −1, OF₂ +2. Fractional = mixed sites. n-factor: count electrons per formula (Cr₂O₇²⁻ → 2Cr³⁺ = 6e).
Exam Notes
  • Quote at least five rules explicitly before the calculation — the rules carry marks of their own. Show the sum equation with every term, then solve; a bare answer of +7 without the algebra earns half.
Formulas
    • KMnO₄: +1 + Mn + 4(−2) = 0 → Mn = +7
    • K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → Cr = +6
    • Fe₃O₄: 3Fe + 4(−2) = 0 → Fe = +8/3
    • Na₂S₄O₆: 2(+1) + 4S + 6(−2) = 0 → S = +2.5
    • Equivalent mass = formula mass / n-factor (KMnO₄ 158/5 = 31.6; K₂Cr₂O₇ 294/6 = 49)

Practice Questions
  • NEB 2024 (3m): State the rules for assigning oxidation numbers. Find the oxidation number of Mn in KMnO₄ and Cr in K₂Cr₂O₇. — Rules: (1) atoms in a free element have oxidation number 0 (O₂, H₂, Fe); (2) a monatomic ion's number equals its charge (Na⁺ +1, Cl⁻ −1); (3) fluorine is −1 in all its compounds; (4) oxygen is −2 except −1 in peroxides (H₂O₂) and +2 in OF₂; (5) hydrogen is +1 except −1 in binary metal hydrides (NaH); (6) the sum of all oxidation numbers equals the charge of the species (0 for molecules, the ionic charge for ions). KMnO₄: potassium is +1 and each oxygen −2, so +1 + Mn + 4(−2) = 0, giving Mn = +7. K₂Cr₂O₇: 2(+1) + 2Cr + 7(−2) = 0 → 2Cr = +12, giving Cr = +6. Both elements sit at the top of their oxidation-state ladders, which is why these compounds are strong oxidising agents in acid medium.
  • NEB-style (2m): Calculate the oxidation numbers of sulphur in Na₂S₄O₆ and iron in Fe₃O₄, commenting on any fractional values. — Na₂S₄O₆ (tetrathionate): 2(+1) + 4S + 6(−2) = 0 → 4S = +10 → S = +2.5. The fraction is an average: the two inner sulphur atoms (S–S linked) are at 0 while the two terminal ones bonded to oxygen are at +5. Fe₃O₄ (magnetite): 3Fe + 4(−2) = 0 → Fe = +8/3 ≈ +2.67 — magnetite is a mixed oxide, FeO·Fe₂O₃, containing one Fe²⁺ and two Fe³⁺ per formula unit; the fractional number is the statistical average, not a real charge on any single ion.
  • NEB-style (2m): Using oxidation numbers, identify what is oxidised and what is reduced in 2KI + Cl₂ → 2KCl + I₂. — Iodine moves from −1 (in KI) to 0 (in I₂): its oxidation number increases, so iodide is oxidised and acts as the reducing agent. Chlorine moves from 0 (Cl₂) to −1 (in KCl): its number decreases, so chlorine is reduced and acts as the oxidising agent. Potassium stays at +1 throughout — a spectator. The reaction is a single-displacement redox driven by chlorine's position above iodine in the electrochemical series of halogens.
