Resolution of Vectors — Finding Components

Notes

  • Standard formulas: for a vector F of magnitude F making angle θ with the x-axis, the components are Fx​=Fcosθ (along x-axis) and Fy​=Fsinθ (along y-axis). The vector form is F=Fx​i^+Fy​j^​.
  • Angle measured from y-axis: if the angle ϕ is measured from the y-axis, the formulas become Fy​=Fcosϕ (adjacent to y) and Fx​=Fsinϕ (opposite to y). The component adjacent to the angle uses cosine; the opposite uses sine.
  • Figure (i) — 10 N at 30° from y-axis: Fy​=Fcos30°=10⋅(3​/2)=53​≈8.66N, Fx​=Fsin30°=10⋅0.5=5N. The y-component is larger because the angle is closer to the y-axis.
  • Figure (ii) — 10 N at 45° from y-axis: Fx​=Fsin45°=10⋅(1/2​)=52​≈7.07N, Fy​=Fcos45°=52​≈7.07N. At 45° from y-axis (or from x-axis), both components are equal.
  • Why the formulas change: when the angle is from the x-axis, the x-component is 'adjacent' and uses cosine. When the angle is from the y-axis, the y-component is 'adjacent' and uses cosine. Always identify which axis the angle is measured from.
  • SOH-CAH-TOA: Sine = Opposite/Hypotenuse, Cosine = Adjacent/Hypotenuse, Tangent = Opposite/Adjacent. Apply this to identify which trig function to use for each component.
  • Special angle values to memorize: sin30°=cos60°=1/2, cos30°=sin60°=3​/2, sin45°=cos45°=1/2​, tan30°=1/3​, tan60°=3​.
  • Components in 3D: for a vector F in 3D, Fx​=Fcosα, Fy​=Fcosβ, Fz​=Fcosγ where α,β,γ are angles with x, y, z axes. The direction cosines satisfy cos2α+cos2β+cos2γ=1.
  • Components for an inclined plane: for a plane tilted at angle θ, the component of gravity along the plane is gsinθ (down the slope) and perpendicular is gcosθ. This is a standard NEB problem.
  • Sign convention for components: components are positive in the direction of the positive axis. If a force points in the negative x direction, Fx​ is negative. This is essential for solving equilibrium problems.
  • Negative components: if the angle θ is between 90° and 180° (second quadrant), cosθ<0, so Fx​ is negative. Similarly, in the third and fourth quadrants, appropriate components become negative.
  • Adding resolved components: to find the resultant of multiple forces, resolve each into x and y components, then add: Rx​=∑Fix​, Ry​=∑Fiy​, R=Rx2​+Ry2​​.
  • Vector magnitude from components: F=Fx2​+Fy2​+Fz2​​. This is the 3D extension of the Pythagorean theorem.
  • Example 1 (10 N at 60° from x-axis): Fx​=10cos60°=5N, Fy​=10sin60°=53​≈8.66N. Compared to 30° from y-axis (which equals 60° from x-axis), the components are the same.
  • Example 2 (15 N at 37° from x-axis, with sin37°≈0.6, cos37°≈0.8): Fx​=15⋅0.8=12N, Fy​=15⋅0.6=9N. The 3-4-5 triangle appears here, useful in physics problems.
  • Component along an arbitrary direction: to find the component of A along a unit vector u^ (any direction), use the dot product: Au​=A⋅u^=∣A∣cosα, where α is the angle between A and u^.
  • Two key rules: (1) Component along an axis = magnitude × cos(angle with axis). (2) If the angle is with the OTHER axis, use sine (since the two axes are perpendicular).
  • Practical example — pulling a lawn roller: pulling with force F at angle θ to the ground, the effective horizontal force is Fcosθ and the vertical lift is Fsinθ. Pulling at an angle reduces ground reaction.
  • Projectile launch at angle θ: initial velocity v0​ resolves into v0x​=v0​cosθ (horizontal) and v0y​=v0​sinθ (vertical). These are the foundation of projectile motion analysis.
  • Direction cosines in 3D: for a vector A making angles α, β, γ with the x, y, z axes: Ax​=Acosα, Ay​=Acosβ, Az​=Acosγ. The direction cosines satisfy cos2α+cos2β+cos2γ=1.
  • Unit vector from components: if A=Ax​i^+Ay​j^​+Az​k^, then A^=∣A∣A​=AAx​​i^+AAy​​j^​+AAz​​k^=cosαi^+cosβj^​+cosγk^.
  • Component along a line: to find the component of A along a line with direction cosines (l,m,n), use Aline​=Ax​l+Ay​m+Az​n=A⋅u^, where u^ is the unit vector along the line.
  • Vector resolution is unique for rectangular components: for a given set of perpendicular axes, the rectangular components Rx​ and Ry​ are uniquely determined. However, oblique components (along non-perpendicular directions) are not unique without additional constraints.

Confusion

  • Component formula is always Fcosθ — The component along the axis the angle is measured from uses cosine. The component along the perpendicular axis uses sine. Both formulas change based on reference axis.
  • The angle 30° means the x-component is Fsin30° — It depends on which axis 30° is measured from. If 30° is from the x-axis, Fx​=Fcos30° and Fy​=Fsin30°. If 30° is from the y-axis, the formulas swap.
  • Components are always positive — Components can be negative if the vector points in the negative direction of an axis. Sign indicates direction along that axis, not magnitude.
  • Angle is always from the x-axis — The angle can be from any reference axis. You must state which axis the angle is measured from, or use unambiguous notation (e.g., '30° above the horizontal').
  • cos and sin can be used interchangeably for components — No. The component ALONG the axis the angle is measured from uses cos. The component PERPENDICULAR to that axis uses sin. This is fixed.
  • A force at 30° above the horizontal has Fy​=Fsin30° — Correct if 30° is from horizontal. If 30° is from vertical, Fy​=Fcos30°. Always verify the reference axis.
  • Components are independent of the choice of axes — Components DEPEND on the choice of axes. The same vector has different components in different coordinate systems, but the same magnitude and direction.
  • Resolving a vector into components changes the vector — No, it gives an EQUIVALENT representation. The vector is unchanged; we just describe it in a different way. F and (Fx​,Fy​) are two descriptions of the same vector.
  • The component along an axis is always Fcosθ — Only if θ is measured from that axis. If θ is measured from the perpendicular axis, the component along the first axis is Fsinθ.
  • Components and the original vector have different physical dimensions — No. Components and the original vector always have the same dimensions. If F is a force, both Fx​ and Fy​ are forces.

Practice

  • A force of 20 N acts at 60° above the horizontal. Find its horizontal and vertical components. [Solution: Fx​=20cos60°=10N. Fy​=20sin60°=20⋅(3​/2)=103​≈17.32N.]
  • A force of 50 N acts at 30° to the vertical. Resolve it into horizontal and vertical components. [Solution: Vertical (along which 30° is measured): Fy​=50cos30°=50⋅(0.866)=43.3N. Horizontal: Fx​=50sin30°=50⋅0.5=25N.]
  • Find the components of a 100 N force at 45° below the horizontal (third quadrant). [Solution: Fx​=100cos45°=70.7N (positive, along +x). Fy​=−100sin45°=−70.7N (negative, since below x-axis).]
  • A vector makes angles 60°, 45°, and 60° with the x, y, and z axes respectively. If its magnitude is 20, find its components. [Solution: Fx​=20cos60°=10, Fy​=20cos45°=20/2​=102​≈14.14, Fz​=20cos60°=10. Check: 100+200+100=400=202 ✓]
  • A body of 5 kg is pushed with horizontal force 30 N. Find the normal reaction from the ground. [Solution: W=mg=5⋅9.8=49N (down). N=W=49N (up). The horizontal force doesn't affect the vertical equilibrium since there is no vertical component.]
  • Resolve a force of 40 N at 53° above the horizontal into components, using sin53°=0.8 and cos53°=0.6. [Solution: Fx​=40⋅0.6=24N, Fy​=40⋅0.8=32N. This is a 3-4-5 right triangle scaled by 8.]
  • A force of 60 N is applied at 30° to the horizontal. Find (a) the horizontal component, (b) the vertical component, and (c) verify that F2=Fx2​+Fy2​. [Solution: (a) Fx​=60cos30°=60⋅(0.866)=51.96N. (b) Fy​=60sin30°=30N. (c) 51.962+302=2700+900=3600=602 ✓]
  • A 2 kg ball is thrown at 30° above the horizontal with speed 20 m/s. Find the initial horizontal and vertical velocity components. [Solution: vx​=20cos30°=20⋅(0.866)=17.32m/s. vy​=20sin30°=10m/s.]
  • A vector A has magnitude 10 and makes angles 60°, 60°, and 90° with the x, y, and z axes respectively. Find its components. [Solution: Ax​=10cos60°=5, Ay​=10cos60°=5, Az​=10cos90°=0. Check: 25+25+0=50=100. This is inconsistent — the given angles are impossible for a single vector. Valid angles must satisfy cos2α+cos2β+cos2γ=1.]
  • Find the components of the vector r=3i^+4j^​+12k^ along the directions of the unit vectors u^1​=2​i^+j^​​ and u^2​=2​j^​+k^​. [Solution: Component along u^1​: r⋅u^1​=2​3+4+0​=2​7​≈4.95. Component along u^2​: r⋅u^2​=2​0+4+12​=2​16​=82​≈11.31.]
  • A force of 100 N makes angles of 60° with the x-axis and 45° with the y-axis. Find the angle with the z-axis and the z-component. [Solution: cos2α+cos2β+cos2γ=1. cos260°+cos245°+cos2γ=1. 0.25+0.5+cos2γ=1. cos2γ=0.25, so γ=60° or 120°. Taking γ=60°: Fz​=100cos60°=50N. The components are Fx​=50N, Fy​=70.7N, Fz​=50N. Universal Facts

  • Resolution of vectors is the backbone of mechanics. Almost every NEB problem in vectors, statics, dynamics, and projectile motion requires resolving a vector into perpendicular components.
  • NEB exam tip: when a problem says 'a force of X N at angle θ to the horizontal' or 'to the vertical', identify the reference axis first. Then use cos for the axis the angle is from, and sin for the perpendicular axis.
  • In engineering, the resolution of forces allows stress analysis in materials. Forces along structural members (axial) and perpendicular to them (shear) are determined by resolution.
  • The famous 3-4-5 right triangle appears frequently: sin37°≈0.6, cos37°≈0.8, sin53°≈0.8, cos53°≈0.6. Memorize this to speed up problem-solving in NEB exams.
  • In GPS navigation, the velocity of a vehicle is resolved into north-south and east-west components to track position over time. Position updates are vector additions of resolved velocity components.
  • The choice of axes in resolution is strategic. For inclined plane problems, axes along and perpendicular to the plane minimize the number of forces that need to be considered in each direction.
  • Resolution and addition are inverse operations: resolution takes one vector and gives multiple, addition takes multiple and gives one. The formulas Rx​=Rcosθ,Ry​=Rsinθ and R=Rx2​+Ry2​​ are the two sides of the same coin.
  • Rope-pulling problems (like dragging a sled) are classic resolution applications. The pulling force at an angle is resolved into a useful component (horizontal motion) and a wasted component (lifting up).
  • Direction cosines (cosα,cosβ,cosγ) are the components of the unit vector along the given direction. They completely specify the direction of a vector in 3D space.
  • The dot product A⋅u^ gives the component of A along u^ — this is the most general way to find a component along any direction, not just the coordinate axes.
