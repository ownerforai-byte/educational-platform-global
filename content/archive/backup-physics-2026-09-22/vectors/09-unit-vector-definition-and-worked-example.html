Unit Vector — Definition and Worked Example

Notes

  • Definition: a unit vector is a vector with magnitude exactly 1 that specifies a direction. It is denoted by a letter with a hat/circumflex overhead, e.g., n^, A^, u^. The hat indicates that the magnitude is unity.
  • Mathematical relation: any non-zero vector A can be written as A=∣A∣A^, where A^ is the unit vector in the same direction. The unit vector is A^=A/∣A∣.
  • Property: since A^ has magnitude 1, A^⋅A^=∣A^∣2cos0°=1. This makes unit vectors the 'building blocks' for expressing other vectors with direction and magnitude as scalars times direction.
  • Standard unit vectors i^,j^​,k^: these are unit vectors along the x, y, and z axes of a Cartesian coordinate system. They satisfy i^⋅i^=j^​⋅j^​=k^⋅k^=1 and i^⋅j^​=j^​⋅k^=k^⋅i^=0.
  • Any 3D vector in terms of standard unit vectors: A=Ax​i^+Ay​j^​+Az​k^. The components are the projections of A on the axes, and the magnitude is ∣A∣=Ax2​+Ay2​+Az2​​.
  • Worked example: find the unit vector of A=3i^+2j^​+5k^. Magnitude: ∣A∣=32+22+52​=9+4+25​=38​. Unit vector: A^=A/∣A∣=(3i^+2j^​+5k^)/38​=(3/38​)i^+(2/38​)j^​+(5/38​)k^.
  • Verification: A^⋅A^=(3/38​)2+(2/38​)2+(5/38​)2=(9+4+25)/38=38/38=1 ✓. So A^ is indeed a unit vector.
  • Approximating 38​: 38​≈6.164. So A^≈0.487i^+0.324j^​+0.811k^. The sum of squares of these coefficients: 0.237+0.105+0.658=1.0 ✓.
  • Direction in spherical coordinates: in 3D, the unit vector at angles (θ,ϕ) (polar and azimuthal) is r^=sinθcosϕi^+sinθsinϕj^​+cosθk^. This represents the direction from the origin to the point on a unit sphere.
  • Unit normal vector n^: a unit vector perpendicular to a surface. For a surface f(x,y,z)=0, the gradient ∇f gives a vector perpendicular to the surface, and n^=∇f/∣∇f∣ is the unit normal.
  • Unit tangent vector t^: a unit vector along the direction of motion of a particle along a curve. If position is r(t), then t^=dr/dt/∣dr/dt∣.
  • Application in dot product: the component of A along u^ is A⋅u^=∣A∣cosθ. This is how unit vectors simplify extracting directional information.
  • Application in cross product: the vector component of A perpendicular to u^ is A×u^, which gives a vector perpendicular to both A and u^, with magnitude ∣A∣sinθ.
  • Position vector as a unit vector: a point at distance r from origin in direction r^ has position vector r=rr^. This is the cleanest way to express a position.
  • Unit vector in terms of components: if A=Ax​i^+Ay​j^​+Az​k^, then A^=(Ax​/∣A∣)i^+(Ay​/∣A∣)j^​+(Az​/∣A∣)k^. The coefficients are the direction cosines.
  • Direction cosines of A^: cosα=Ax​/∣A∣, cosβ=Ay​/∣A∣, cosγ=Az​/∣A∣. They satisfy cos2α+cos2β+cos2γ=1 (since A^ is a unit vector).
  • Zero vector has no defined unit vector: you cannot find a unit vector along 0 because the direction is indeterminate. The formula 0/∣0∣ is undefined.
  • Unit vector notation: in textbooks, unit vectors are written with hats (i^), tildes (A~), or in bold (e). All represent the same concept. The hat is most common in NEB curriculum.
  • Negative unit vector: −A^ is also a unit vector (magnitude 1) but in the opposite direction. Unit vectors come in pairs, one for each direction along a line.

Confusion

  • A unit vector has zero magnitude — A unit vector has magnitude EXACTLY 1, not 0. The zero vector 0 has magnitude 0 and indeterminate direction; a unit vector has magnitude 1 and a specific direction.
  • Every vector is a unit vector — Only vectors with magnitude 1 are unit vectors. A general vector A=3i^ has magnitude 3, not 1. To get a unit vector, you must divide by the magnitude: A^=A/∣A∣.
  • There is only one unit vector in space — There are infinitely many unit vectors, one for each direction in space. In 3D, unit vectors form a unit sphere (all vectors of magnitude 1).
  • Unit vectors add to give a vector with the sum of magnitudes — Unit vectors add via the parallelogram law, considering their direction. i^+j^​ has magnitude 2​, not 2.
  • The unit vector is just the direction — The unit vector encodes ONLY the direction, but it is itself a vector (with magnitude 1). Saying 'just the direction' is informal — formally, the unit vector is a vector in 3D space with magnitude 1.
  • The unit vector A^ equals A — A^ equals A only if ∣A∣=1. For a general vector, A^=A/∣A∣, which is the unit vector in the same direction.
  • Direction cosines are the same as components — Direction cosines are the components of a unit vector. They are the cosines of the angles the vector makes with the coordinate axes, and their squares sum to 1.
  • A unit vector along an axis is the same as the axis — The unit vector along the x-axis is i^, which has magnitude 1. The x-axis itself is an infinite line, not a vector.

Universal Facts

  • Unit vectors are the foundation of vector calculus — the gradient ∇f, divergence ∇⋅F, and curl ∇×F are defined using unit vectors and partial derivatives.
  • NEB exam tip: problems asking to 'find the unit vector' are extremely common. The steps are always: (1) find the magnitude, (2) divide each component by the magnitude. Always verify the answer has unit magnitude (sum of squares of components = 1).
  • The notation i^,j^​,k^ was introduced by Josiah Willard Gibbs in his 1881 vector analysis textbook, building on earlier work by Hamilton and Heaviside. The choice of 'i, j, k' (not 'i, j, l' to avoid confusion with '1') is intentional.
  • In computer graphics, unit vectors are called normalized vectors or direction vectors. The 'normalize' function in any graphics library converts a vector to a unit vector to preserve direction while simplifying calculations.
  • Spherical and cylindrical coordinates use unit vectors r^,θ^,ϕ^​ and r^,ϕ^​,z^ respectively. These unit vectors change direction as you move, unlike the constant i^,j^​,k^ of Cartesian coordinates.
  • The direction cosines of a unit vector give the angles it makes with the coordinate axes. They are useful in crystallography for specifying the orientation of crystal planes (Miller indices).
  • In electromagnetic wave theory, the unit vector along the direction of propagation k^ and the polarization unit vectors E^0​,B^0​ form an orthonormal basis. They are mutually perpendicular and unit magnitude.
  • Any rotation matrix R has the property that its columns are unit vectors (in 3D) and they are mutually perpendicular. This makes rotation matrices a powerful tool for describing orientation changes.
