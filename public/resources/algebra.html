Function: domain and range of a function, inverse function

#Concept
1### 1. Function Definition
2A function f from set A to set B is a rule that assigns to each element of A exactly one element of B. Written as f: A -> B, where A is the domain and B is the codomain.
3### 2. Domain and Range
4- Domain: All possible input values (x-values) for which f is defined
5- Range: All possible output values (y-values) that f produces
6- Example: f(x) = sqrt(x-2) -> Domain: x >= 2, Range: y >= 0
7### 3. Types of Functions
8- One-to-one (Injective): Each output has exactly one input
9- Onto (Surjective): Every element of codomain is mapped
10- Bijective: Both one-to-one and onto
11### 4. Inverse Function
12If f: A -> B is bijective, the inverse f^-1: B -> A satisfies f^-1(f(x)) = x and f(f^-1(y)) = y.
13To find f^-1: (1) Replace f(x) with y, (2) Solve for x, (3) interchange x and y.
14### 5. Condition for Inverse to Exist
15f must be one-to-one (horizontal line test) AND onto (range = codomain).
16### 6. Graphical Property
17The graph of f^-1 is the reflection of f across the line y = x.
18### 7. Composite Function
19(f o g)(x) = f(g(x)). Note: f o g != g o f in general.
20### 8. Entrance Exam Formulas
21- f(x) = ax + b -> f^-1(x) = (x-b)/a
22- f(x) = x^2 (x>=0) -> f^-1(x) = sqrt(x)
23- (f o f^-1)(x) = x and (f^-1 o f)(x) = x

Key Points

Point
f^-1 denotes the inverse function, never the reciprocal 1/f(x).
Domain and range are generally different sets; the range of f is the domain of f^-1.
An inverse exists only for a bijective function, so a restriction is often needed first, as with x^2 on x >= 0.
Composition does not commute, since f o g and g o f are different functions in general.
Solving f(x) = k for x is the same work as finding f^-1(k), so the two skills are really one skill.

Common Confusions

❌ / ✅
x Every function has an inverse. x Only bijective functions have inverses.
x f^-1(x) = 1/f(x). x f^-1 is the inverse function, not reciprocal.
x Domain = Range always. x They can be different sets.

Summary: A function f: A -> B assigns to every element of A exactly one element of B, where A is the domain and B the codomain, while the range is the set of outputs actually attained. Injective (one-to-one), surjective (onto) and bijective describe how far the outputs avoid collisions and cover the codomain, and only a bijective function has an inverse f^-1, satisfying f^-1(f(x)) = x and f(f^-1(y)) = y, whose graph is the reflection of f in the line y = x. The inverse is obtained by writing y = f(x), solving for x and interchanging x and y, and composition obeys (f o g)(x) = f(g(x)) with f o g generally different from g o f.

Sequence and series: arithmetic, geometric, harmonic sequences

#Concept
1### 1. Sequence Definition
2An ordered list of numbers following a pattern: a1, a2, a3, ..., an, ...
3### 2. Arithmetic Progression (AP)
4- Common difference: d = an - a(n-1)
5- nth term: an = a + (n-1)d
6- Sum of n terms: Sn = n/2[2a + (n-1)d] = n/2(a + l)
7- Arithmetic Mean: A = (a+b)/2
8### 3. Geometric Progression (GP)
9- Common ratio: r = an/a(n-1)
10- nth term: an = ar^(n-1)
11- Sum of n terms: Sn = a(r^n - 1)/(r-1) for r != 1
12- Infinite GP (|r| < 1): S_infinity = a/(1-r)
13- Geometric Mean: G = sqrt(ab)
14### 4. Harmonic Progression (HP)
15Reciprocals of an AP: 1/a, 1/(a+d), 1/(a+2d), ...
16- Harmonic Mean: H = 2ab/(a+b)
17- Relation: A x H = G^2 (AM x HM = GM^2)
18### 5. Important Relations
19- For AP: an - a(n-1) = d (constant)
20- For GP: an/a(n-1) = r (constant)
21- AM >= GM >= HM for positive numbers
22### 6. Entrance Exam Focus
23MCQs: Find nth term, sum, GM/HM; Word problems on AP/GP; relation between AM, GM, HM.

Key Points

Point
A difference signals an AP and a ratio signals a GP, so subtract a(n-1) to get d and divide by a(n-1) to get r.
S_n = n/2(a + l) is often the quickest AP sum, because l is usually given directly in the question.
For a GP with r < 1, write S_n as a(1 - r^n)/(1 - r) so that the bracket stays positive.
Never use S_infinity = a/(1 - r) without first confirming that |r| < 1.
AM, GM and HM are means of two numbers; they are not obtained by averaging the terms of a progression.

Common Confusions

❌ / ✅
x HP has a direct sum formula. x Take reciprocals, use AP sum.
x r can be any value in infinite GP. x Must have |r| < 1 for convergence.
x AM = GM always. x AM >= GM, equality only when all terms equal.

Summary: A sequence is an ordered list a1, a2, a3, ... following a pattern, and a series is the sum of its terms. In an arithmetic progression the difference d = a_n - a_(n-1) is constant, giving a_n = a + (n-1)d and S_n = n/2[2a + (n-1)d] = n/2(a + l); in a geometric progression the ratio r = a_n/a_(n-1) is constant, giving a_n = a r^(n-1) and S_n = a(r^n - 1)/(r - 1), which reduces to a/(1 - r) only when |r| < 1. A harmonic progression is the reciprocal of an AP, and for two positive numbers the means satisfy A >= G >= H with A x H = G^2.

Matrices and determinants: transpose, properties, inverse

#Concept
1### 1. Matrix Definition
2A rectangular array of numbers arranged in rows and columns. Order: m x n (m rows, n columns).
3### 2. Types of Matrices
4- Square: m = n
5- Diagonal: All non-diagonal elements are zero
6- Identity (I): Diagonal elements = 1, others = 0
7- Zero matrix: All elements = 0
8- Symmetric: A = A^T
9- Skew-symmetric: A = -A^T (diagonal elements = 0)
10### 3. Transpose
11Interchanging rows and columns: (A^T)_ij = A_ji
12- Properties: (A^T)^T = A, (A+B)^T = A^T + B^T, (AB)^T = B^T A^T
13### 4. Determinant (2x2 and 3x3)
14- |A| = ad - bc for A = [[a,b],[c,d]]
15- |A| = 0 -> singular matrix (no inverse)
16- |A| != 0 -> non-singular (inverse exists)
17### 5. Inverse of a Matrix
18A^-1 = (1/|A|) x adj(A) where adj(A) is the adjoint (transpose of cofactor matrix).
19### 6. Cramer's Rule
20For system ax + by = e, cx + dy = f:
21x = Dx/D, y = Dy/D where D = |A|, Dx replaces column 1 with constants, Dy replaces column 2.
22### 7. Entrance Exam Formulas
23- |AB| = |A| x |B|
24- |A^T| = |A|
25- A x adj(A) = |A| x I
26- (A^-1)^T = (A^T)^-1

Key Points

Point
Matrix multiplication is not commutative, and (AB)^T = B^T A^T reverses the order for exactly the same reason.
Only square matrices can have an inverse, and only when |A| != 0; a rectangular matrix has neither determinant nor inverse.
The adjoint is the transpose of the cofactor matrix, not the cofactor matrix itself.
|A^T| = |A|, and a 3x3 determinant uses the cofactor signs + - + along the first row.
For an n x n matrix, |adj A| = |A|^(n-1), so for a 3x3 matrix the power is 2.

Common Confusions

❌ / ✅
x (AB)^T = A^T B^T. x (AB)^T = B^T A^T (order reverses!).
x Every matrix has an inverse. x Only square, non-singular matrices.
x AB = BA always. x Matrix multiplication is NOT commutative.

Summary: A matrix is a rectangular array of numbers of order m x n, and the special types that matter here are square, diagonal, identity, zero, symmetric (A = A^T) and skew-symmetric (A = -A^T, whose diagonal entries are all zero). The transpose interchanges rows and columns, (A^T)_ij = A_ji, with (AB)^T = B^T A^T, so the order reverses. The determinant of A = [[a,b],[c,d]] is ad - bc; |A| = 0 makes the matrix singular, and only a square matrix with |A| != 0 has an inverse, obtained as A^-1 = (1/|A|) adj(A), the same tool that gives Cramer's rule.

Established academic fact

A function’s domain is part of its definition. For real formulas, denominators cannot be zero and even roots require non-negative radicands; inverse functions require a one-to-one restriction on the chosen domain.

Open research question — The Riemann Hypothesis

This unsolved conjecture concerns the non-trivial zeros of the zeta function and has deep connections to the distribution of prime numbers. Checking many cases computationally cannot replace a proof for all cases.
